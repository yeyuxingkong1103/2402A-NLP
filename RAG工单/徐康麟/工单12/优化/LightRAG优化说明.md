# LightRAG 优化说明（工单12，短版）

> **工单编号：人工智能NLP-RAG 项目-LightRAG 优化**
> 数字全部取自 t3 真实产物：`优化\评估结果\对比汇总.json`、`RAGAS指标.json`、`对比报告.md`（含逐题摘要与复现命令）。

## 1. 优化点（配置唯一来源 `部署\配置\lightrag.json`）

| 优化点 | 做法 | 关键配置 |
| --- | --- | --- |
| 实体/关系类型体系 | 17 类实体 / 16 类关系封闭集，LLM 返回的非法类型经 `coerce_type` 吸附 | `graph.max_entities_per_chunk` / `max_relations_per_chunk` |
| 别名归并 | 指代别名表（18 条）+ 字符 Dice 二次归并（阈值 0.82） | `graph.alias_similarity` / `alias_min_len` |
| 关系去重 | 同 (head, rel, tail) 三元组合并加权（weight = 出现次数） | `graph.merge_relation_duplicates` |
| 头尾相容标记 | 不符 `RELATION_CONSTRAINTS` 的边**保留并标 `constraint_ok=false`**（不丢弃、不改写） | `graph.constraint_violations_policy=keep_flagged` |
| 双层检索 | 局部（向量）+ 全局（图谱关系一跳扩展）→ 加权 RRF 融合 | `retrieval.local_weight=0.55` / `global_weight=0.45` / `rrf_k=60` |
| 边质量开关 | 全局通道可只用相容边；被标记边乘 0.5 降权 | `retrieval.global_flagged_edge_weight` |
| 公平对比 | 两后端共用同一索引/BM25/提示词/生成参数/引用规则，唯一变量是检索通道 | `eval.backend_list` / `answer.*` |

## 2. RAG vs LightRAG 前后对比（16 题实测）

| 后端 | 答对率 | 答案关键词命中 | 上下文命中 | 数字命中 | 页命中 | 平均检索 | 平均总耗时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| RAG（扁平，基线） | 2/16 = 12.5% | 0.4521 | 0.6204 | 0.6380 | 11/16 | 0.156s | 2.403s |
| LightRAG（全量边） | 3/16 = 18.8% | 0.4356 | 0.4841 | 0.6693 | 7/16 | 0.043s | 1.803s |
| LightRAG（仅相容边） | 3/16 = 18.8% | 0.4606 | 0.5341 | 0.6693 | 8/16 | 0.038s | 0.894s |

RAGAS 四项（自实现 `_kw`，官方包缺失）：RAG 0.7500 / 0.5792 / 0.7030 / 0.6204；LightRAG 全量边 0.7500 / 0.5511 /
0.5319 / 0.4841；仅相容边 0.8125 / 0.5607 / 0.5618 / 0.5341（顺序：faithfulness / answer_relevancy /
context_precision / context_recall）。

**结论**：LightRAG 在答对数（+793 题）、数字命中与速度上占优（检索 0.043s vs 0.156s）；**RAG 在上下文精度/召回
与页命中上更好**（0.6204 vs 0.4841、11 vs 7）。切「仅相容边」后检索侧四项不降反升（页命中 7→8、总耗时
1.803s→0.894s），说明 `constraint_ok` 是有效质量信号——被标记的 121 条边确实在拉低全局检索质量。

## 3. 根因

- **为何答对率整体偏低（最高 18.8%）**：判分要求参考答案关键词**全部命中**；生成与抽取均用 `qwen2.5:3b`，
  且图谱仅由 **88 块小样本**（计划 200，1200s 时间预算收束）建成，全局通道的候选块覆盖不足。
- **为何 id=6 未达标**：该题答案在图内文字，本机无视觉模型、图块未 OCR（`-2.0%` 全库 0 命中），
  错误答案原样保留在 `对比报告.md` §7 作证据。
- **为何 LightRAG 上下文指标低于 RAG**：全局通道按图谱实体/关系收集块，命中块更分散，单题上下文关键词
  覆盖率被摊薄；`keep_flagged` 保留了 121 条低质边进一步稀释了候选（用「仅相容边」后即回升）。

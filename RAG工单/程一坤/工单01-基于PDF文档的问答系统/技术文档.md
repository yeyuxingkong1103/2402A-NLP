# 工单01 技术文档：基于PDF文档的问答系统

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统

## 一、系统架构

```
┌─────────────┐   ┌──────────────┐   ┌─────────────┐   ┌────────────┐
│ PDF 解析模块 │ → │ 文本分块模块  │ → │ 向量化模块   │ → │ 本地向量库  │
│ pdf_parser  │   │ chunker      │   │ bge-m3      │   │ VectorStore│
└─────────────┘   └──────────────┘   └─────────────┘   └─────┬──────┘
                                                             │ 余弦相似度检索
┌─────────────┐   ┌──────────────────────────────┐           ▼
│ Web/CLI 界面 │ ← │ RAG 问答引擎 rag_engine       │ ← ────────┘
│ app/run_qa  │   │  组装Prompt → qwen2.5 生成回答 │
└─────────────┘   └──────────────────────────────┘
```

## 二、技术选型

| 组件 | 选型 | 理由 |
|---|---|---|
| PDF 解析 | PyMuPDF (fitz) | 速度快、纯文字提取准确，支持页眉页脚清洗 |
| 分块策略 | 段落边界 + 500字符滑窗 + 80字符重叠 | 语义完整、边界信息不丢失 |
| Embedding | bge-m3（Ollama 本地部署，1024维） | 中文效果好、本地推理无网络依赖 |
| 向量库 | numpy + JSON 持久化 | 千级分块下余弦检索毫秒级，零外部依赖 |
| LLM | qwen2.5:7b-instruct（Ollama 本地） | 中文生成质量好，7B 本机可跑 |
| Web | Flask | 轻量，聊天式界面 |

## 三、开发流程与关键设计

1. **PDF 解析**（`00-公共模块/pdf_parser.py`）：逐页提取文字，并清洗页眉页脚
   （"公司名+招股意向书"、"1-1-XX"页码行）。实测清洗后真值分块检索排名从第14名提升至第5名，
   "注册资本"问题由答错变为答对，说明噪音清洗对向量检索精度影响显著。
2. **分块**（`chunker.py`）：先按段落切，超长段按句号切，块间保留80字符重叠；
   过滤<30字符的碎块。
3. **向量化与索引**（`vector_store.py` + `build_index.py`）：1363→1230 个分块，
   全量向量化约35秒，持久化至 `index_store/zgs1_v1.json`，各工单复用。
4. **检索与生成**（`rag_engine.py`）：Top-5 余弦检索 → 组装带来源页码的 Prompt
   （温度0.1，限制只依据上下文回答，无证据时回答"未找到"）→ LLM 生成。
5. **容错**：Ollama 调用带3次退避重试；索引缺失/服务未启动有明确错误提示。

## 四、使用方法

```bash
# 1. 启动 Ollama 并确认模型
ollama serve          # 通常已随服务自启
ollama list           # 需要 qwen2.5:7b-instruct 与 dengcao/bge-m3:567m

# 2. 构建索引（仅首次）
python build_index.py

# 3a. 命令行问答
python run_qa.py

# 3b. Web 界面
python app.py         # 浏览器打开 http://127.0.0.1:8601

# 4. 生成 RAG vs 纯LLM 对比报告
python compare_rag_llm.py
```

## 五、测试结果（10 个验收问题）

| 结论 | 数量 | 说明 |
|---|---|---|
| ✅ 正确并标注页码 | 8 | 注册资本5520万、法定代表人程家明、技术标准、国家科技进步一等奖工程等 |
| ⚠️ 未找到兜底 | 2 | 军用收入金额/占比（数据位于表格中，纯文字检索召回不足）|
| ❌ 编造 | 0 | — |

- 纯 LLM 对比：10 题中 6 题明确表示无法回答，4 题编造（虚构标准号/工程名），均不可溯源。
- 响应时间：索引热加载后单题 0.6~2.5 秒，满足 ≤3 秒验收标准。
- 详细逐题对比见《对比结果-RAG与纯LLM.md》。

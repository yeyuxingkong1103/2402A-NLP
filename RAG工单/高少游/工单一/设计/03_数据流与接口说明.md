# 数据流与接口说明

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统
> 记录系统各层的数据结构、数据流向与对外接口，便于接续开发与联调。

---

## 1. 核心数据结构

### 1.1 `PageDoc`（pdf_parser.py）
单页解析结果。

| 字段 | 类型 | 说明 |
|---|---|---|
| `page_no` | int | 页码（从1起） |
| `text` | str | 该页正文 |
| `tables` | list | 表格列表 |
| `content` | str | 正文+表格拼接后的文本 |

### 1.2 向量库文档块（knowledge_base.py）
写入 FAISS 的每条文档带有 `metadata`。

| metadata字段 | 说明 |
|---|---|
| `page` | 来源页码 |
| `chunk` | 切片序号 |

### 1.3 `QueryAnalysis`（query_understanding.py）

| 字段 | 说明 |
|---|---|
| `intent` | 意图：fact / finance / calc / relation / other |
| `disambiguated_query` | 指代消歧、规范术语后的主问题 |
| `entities` | 关键实体词 |
| `sub_questions` | 复杂问题的子问题列表 |
| `retrieval_queries` | 用于检索的候选查询（主问题+子问题，去重） |

### 1.4 检索片段 `doc`（retriever.py）
每条检索结果为带 `score` 的文档。

| 字段 | 说明 |
|---|---|
| `text` | 片段文本 |
| `page` | 来源页码 |
| `score` | 融合后得分 |

### 1.5 `AnswerResult`（qa_engine.py）

| 字段 | 说明 |
|---|---|
| `answer` | 回答文本 |
| `mode` | `rag` / `llm_only` |
| `elapsed` | 端到端耗时(秒) |
| `sources` | 检索依据列表(含 page/score/text) |
| `analysis` | QueryAnalysis |

## 2. 数据流向

```
data/招股说明书1.pdf
        │  pdf_parser.parse_pdf()
        ▼
    [PageDoc...]  (每页)
        │  RecursiveCharacterTextSplitter
        ▼
    [doc(chunk=0..N)]  metadata=page/chunk
        │  bge-m3 分批嵌入
        ▼
    FAISS vector_db ────────────────┐
        │                           │ 读索引
        ▼  similarity_search        ▼
   ┌─ 语义Top-K ──┐          retriever
   │  BM25 Top-K  │──RRF融合──▶  Top N 片段(score/page)
   └──────────────┘                │  format_contexts
                                   ▼
              [第x页:...] 上下文 + 用户问题
                                   │  qa_engine 提示词
                                   ▼
                              LLM 答案
                                   ▼
                          answer + elapsed + sources
```

## 3. 对外接口（脚本命令）

| 命令 | 说明 | 示例 |
|---|---|---|
| `python scripts/build_kb.py` | 构建向量库 | `--rebuild` 强制重建 |
| `python scripts/run_qa.py --question "..."` | 命令行问答 | `--llm-only` 纯LLM |
| `python scripts/evaluate.py` | 10题评估 | `--top-k 8` `--in-memory` `--skip-ragas` |
| `python scripts/build_report.py` | 生成比对报告 | 无参 |
| `python scripts/ragas_score.py` | RAGAS 指标 | 需JSON友好裁判模型 |
| `streamlit run app.py` | 启动交互界面 | 浏览器 http://localhost:8501 |

## 4. 输出产物

| 产物 | 路径 | 说明 |
|---|---|---|
| 评估原始JSON | `output/evaluation_report.json` | 10题 RAG/纯LLM 回答+耗时+上下文 |
| 评估报告 | `output/evaluation_report.md` | 对比表格+命中统计+结论 |
| 反馈记录 | `output/feedback.csv` | 用户👍/👎反馈 |
| 向量库 | `vector_db/` | FAISS 索引 |

## 5. 配置项速查（config.py）

| 配置 | 默认 | 作用 |
|---|---|---|
| `CHUNK_SIZE` | 500 | 切片字数 |
| `CHUNK_OVERLAP` | 80 | 切片重叠 |
| `TOP_K` | 6 | 向量检索返回片段数 |
| `BM25_TOP_K` | 6 | BM25 返回片段数 |
| `RANK_FUSION_K` | 60 | RRF 融合窗口 |
| `LLM_MAX_TOKENS` | 768 | 生成长度上界 |
| `TARGET_RESPONSE_SECONDS` | 3.0 | 响应达标阈值 |

## 6. 沙箱注意事项（实测）

在 TRAE 沙箱内运行 `save_local` 写 FAISS 索引会被拦截（`Permission denied`）。
对策：
- 评估/问答用 `--in-memory` 模式（不落盘向量库）；
- 需持久化向量库时，在**沙箱外**执行 `python scripts/build_kb.py`，或配置沙箱放行规则。

## 四、与本项目约束的对应关系（CLAUDE.md 第四节）

1. **来源可溯**：全部来自官方平台，标准号+发布日期唯一可查；`data/raw/_下载清单.csv` 记录文件名→标准号→名称→页数。
2. **权威等级**：GB/Z 为国家标准化指导性技术文件——国家级、推荐采用、非强制性。与强制性 GB（如农药残留限量 GB 2763）不同，**不得作为农药禁用/限量的最终依据**；禁限用名单只能以官方农药登记信息为准。
3. **高危知识**：第 2~17 条生产技术规范内含农药品种、施用剂量、安全间隔期、肥料用量等内容，属于核心约束 1 的「高危知识」，切分与生成阶段必须单独标注来源（标准号+条款号/表号）并加核实提示。
4. **地域/年份**：这批标准的出版年份为 2009–2022，技术指标（尤其药剂与剂量）可能已被新标准或地方规定取代，入库时 metadata 必须写 `year` 与 `region=全国`，答案中提示「以当地最新要求为准」。
5. **作物范围**：本批覆盖菠菜、蚕豆、草莓、茶叶、大葱、大蒜、冬枣、柑橘、黄瓜、甘蓝、辣椒、生姜、甜豌豆、西兰花、香菇、洋葱等；**本期范围只做黄瓜、辣椒、大蒜**（见 `docs/01-需求分析.md` 2.2），其余 23 份 371 页标 `in_scope=false` 作为扩展储备，**不进本期索引**。
6. **缺口结论的口径**：`docs/01` 2.2 的「农药混用 0 次 / 限用 0 次」只是**文本层**统计（258/433 页）；175 页字形码页统计不到，视觉转录后必须复核。例：大蒜的附录 B 在字形码页 p18/p20，其安全间隔期/每茬最多使用次数在文本层统计为 0，不代表原文没有。

## 五、复现方式

```bash
# 列出 ICS65 指导性技术文件全部条目（含采标标记）
python scripts/list_openstd.py

# 下载（已存在的文件会自动跳过，可反复重跑补齐失败项）
python src/ingest/download_gb_standards.py --ics 65 --p1 3 --out data/raw --delay 2.5

# 校验并生成 data/raw/_下载清单.csv，同时把首页渲染到 logs/_verify_png/ 供肉眼核对
python scripts/verify_pdfs.py data/raw

# 本文档的「需视觉通道页」与关键词缺口由 pytest 现算复核（口径：逐页 CJK 字数 < 60 判需视觉通道）
python -m pytest -q
```

注意：平台有验证码限流，批量下载中途个别条目会失败，**重新跑一遍（间隔 ≥ 30s）即可补齐**；本次 5 个失败项在第二轮全部成功。

# RAG 优化说明

## 1. 检索优化
- 混合检索：BM25+向量，各召回top20，加权融合(0.5+0.5)
- LangChain EnsembleRetriever：三路(BaseRetriever)+RRF名次融合
- BGE-reranker精排：CrossEncoder token级交互
- 余弦阈值过滤：vector_score>=0.7
- Redis缓存：最近100条查询，1小时TTL

## 2. 分块优化
- 六种策略：固定/句子/段落/标题/语义/父子块
- RecursiveCharacterTextSplitter(中文句读分隔符)
- 质量过滤：短于10字符丢弃

## 3. 查询优化
- LLM查询改写：口语化转检索友好关键词
- 意图识别：关键词+LLM路由到领域

## 4. 记忆优化
- 短期记忆：Redis最近5轮对话
- 长期记忆：Milvus用户偏好，每5轮提取
- 时间衰减：30天半衰期排序

## 5. 输出优化
- 后处理：清套话、标点转全角、压空格
- 流式输出：FastAPI SSE，首字<3s

## 6. PDF处理优化
- 四级降级链：minerU → PyMuPDF → pdfplumber → PaddleOCR
- 水印去除：跨页+同坐标+短文本判定
- PaddleOCR-VL：方向分类+文档矫正+表格几何重建

### 3.2 图像语义理解 (image_understanding.py)

**双路方案**:

#### 方案 A: 预设描述 (降级/演示用)
```json
{
  "image_id": "Liyuan_OrgChart",
  "image_type": "组织架构图",
  "doc_id": "招股说明书2",
  "company": "武汉力源信息技术股份有限公司",
  "description": "武汉力源信息技术股份有限公司组织结构图...",
  "structured_data": {
    "销售部下属部门": ["大客户销售部", "渠道销售部", "产品销售部"],
    "大客户销售部下属销售处": ["华东销售处", "华南销售处", "华北销售处"]
  }
}
```

#### 方案 B: CLIP 向量检索 (跨模态)
```python
# 1. 为每张图像生成 CLIP 向量
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('clip-ViT-B-32')
image_vec = model.encode(image)
text_vec = model.encode("组织结构图 销售部")
similarity = cosine(image_vec, text_vec)
```

#### 方案 C: 多模态 LLM (GPT-4V / Claude Vision)
```python
# 将图像 + 问题发送给多模态 LLM
response = llm.chat([
  {"role": "user", "content": [
    {"type": "image_url", "image_url": {"url": "data:image/png;base64,..."}},
    {"type": "text", "text": "这是什么图? 图中销售部有几个下属部门?"}
  ]}
])
```

### 3.3 跨模态检索架构

```
用户问题
  │
  ├─ 含"图/图表/结构/增长/饼图/柱状图" → 图像查询
  │   │
  │   ├─ ① CLIP 跨模态检索 (query_text ↔ image_embedding)
  │   │
  │   ├─ ② 图像描述文本检索 (OCR/预设描述 → 文本检索)
  │   │
  │   └─ 融合 → Top-K 图像
  │
  └─ 否则 → 走 V3 (表格+文本检索)
  
Top-K 图像
  │
  └─ 多模态 LLM 生成答案
      (image + question → answer)
```

## 快速开始（安装 → 运行 → 测试 三步）

> ⚠️ **本机沙箱注意事项（实测，详见 `设计/环境事实.md` 与 `部署/README.md` §4/§5）**
> 1. **一切 Python 调用都走 `run_py.ps1`**（固定解释器、UTF-8 I/O，`PYTHONDONTWRITEBYTECODE=1` 防止污染只读的工单1）。
> 2. 🔴 **不要 `pip install`**：其落点是 `工单1\.venv\Lib\site-packages`（只读红线）；
>    需要新依赖时用 `--target 研发/第三方库`。
> 3. 需要联网（pip 安装、下载权重）或访问 Docker 的命令，**必须提权** `sandbox_permissions='danger-full-access'`；
>    Docker CLI 走命名管道 `npipe:////./pipe/dockerDesktopLinuxEngine`，沙箱默认拒绝。
> 4. 下载 CLIP 权重用 **`研发/scripts/download_clip.py`**（自带浏览器 UA）；
>    hf-mirror 对「默认 UA + 文件路径」返回 403，且**不要**照 `设计/环境事实.md` §4.2 的 `huggingface_hub` 命令
>    （该路径在本机会因软链落点 `PermissionError` 失败）。
> 5. **不要关闭 3080（本 GUI）与 11434（Ollama，检索嵌入与生成依赖）**。

```powershell
cd E:\gao6gongdan\工单4

# ── 安装（本机已具备依赖，只需体检；只读，零安装）
pwsh -NoProfile -File run_py.ps1 部署/脚本/verify_config_env.py     # 期望「FAIL=0 / 退出码 0」

# ── 运行
# ① FastAPI 服务（端点最全；中文页 /docs 文档）：http://127.0.0.1:8600/
pwsh -NoProfile -File 部署/脚本/run_app.ps1 -Mode api -Port 8600
# ② 中文 Web 界面（纯标准库，依赖最少）：http://127.0.0.1:8123/
pwsh -NoProfile -File 部署/脚本/run_app.ps1 -Mode web -Port 8123
# ③ CLI 单次提问
pwsh -NoProfile -File run_py.ps1 研发/app/main.py --ask "武汉兴图新科电子股份有限公司注册资本是多少？"

# ── 测试（一键自检 + 三级串跑 + 16 题评测）
pwsh -NoProfile -File 部署/脚本/run_app.ps1 -HealthCheckOnly -SmokeAll   # 期望 exit 0（留痕 部署/日志/自检结果.json）
pwsh -NoProfile -File 测试/run_tests.ps1                                  # 离线→在线→用户，期望 exit 0
# 16 题评测需要一个在跑的服务（脚本走 /health 与 /api/ask）：默认指向 8123（标准库 Web），
# 也可用 --base-url 指向 FastAPI 服务的 8600：
pwsh -NoProfile -File run_py.ps1 测试/在线/run_16q_eval.py --run-tag accept --base-url http://127.0.0.1:8600
```

> 若要**从零复现解析与索引**（耗时较长，非必需）：

## 测试方法

> **测试分两处，都要跑，别只跑一处**：
> * `研发/tests/` = **研发自测层**（解析/索引单元测试，如 `test_table_defects.py`：表格合并单元格 `None`、
>   格内换行、跨页续表与表头继承 + 真实 PDF 断言，T8 复跑实测 **24 passed**）；
> * `测试/**` = **工单验收层**（`离线`/`在线`/`用户` 三级，见 `测试/README.md`）。

```powershell
# 0) 部署自检（最快的一条端到端证据）
pwsh -NoProfile -File 部署/脚本/run_app.ps1 -HealthCheckOnly

# 1) 研发自测层（快，0 依赖）
$env:PYTEST_ADDOPTS='-p no:cacheprovider'      # 防止在仓库根生成 .pytest_cache 游离目录
pwsh -NoProfile -File run_py.ps1 -m pytest 研发/tests -q

# 2) 离线测试（不依赖网络与 LLM）
pwsh -NoProfile -File run_py.ps1 -m pytest 测试/离线 -q

# 3) 在线测试（依赖 Ollama；建议独占运行）
pwsh -NoProfile -File run_py.ps1 -m pytest 测试/在线 -q

# 4) 三级一键串跑（含留痕；服务未起时脚本自行拉起，跑完自动关闭）
pwsh -NoProfile -File 测试/run_tests.ps1
```

> 说明：`PYTEST_ADDOPTS='-p no:cacheprovider'` 用于避免在仓库根留下 `.pytest_cache/` 游离目录
>（工单要求交付物只落在五个中文文件夹内）。注意**不要把 `-p ...` 直接跟在 `-File run_py.ps1` 后面**——
> `run_py.ps1` 只声明了一个 `ValueFromRemainingArguments` 参数，多一个未知开关会让 PowerShell 参数绑定失败
>（实测报「找不到与参数名称 'p' 匹配的参数」，退出码 1）。用环境变量形式即可，实测通过且无缓存目录。

**延迟测量纪律**：必须先确保 **服务已预热** 且 **独占 Ollama**（不并发跑其它评测），否则数字不可用于验收。

## 16 题覆盖与实测结论

题目逐字清单与判分真值见 **`设计/验收标准.md` §3**（权威来源：`设计/工单需求原文.md`）。

| 类别 | 题号 | 语料 |
| --- | --- | --- |
| **图像题（2 道）** | **5**（组织结构图）、**6**（2008 年中国IC市场应用结构与增长图） | 招股说明书2.pdf 物理页 39 / 72 |
| 文本·表格题（PDF2，4 道） | 1、2、3、4 | 招股说明书2.pdf |
| 文本·表格题（PDF1，10 道） | 260、95、33、34、957、793、795、543、531、207 | 招股说明书1.pdf |

**结论（T6 实跑，明细见 `测试/测试报告.md`）**：

* 准确率 **16/16 = 100%**（确定性判分 `测试/common/golden.py::judge_answer`，**非 LLM 自评**）；
* 逐题延迟 **P50 595.8 / P95 929.8 / max 1062.8 ms**（客户端 wall；服务端 total P50 582.8 / P95 903.2 / max 1049.5），**超线 0 题**；
* 引用可回溯 **16/16**；检索权威层命中 **14/16**（BM25 14 / 向量 11，按通道分列）；
* 图像两题是真解析：第 5 题引用 `招股说明书2.pdf 第39页 组织结构图`（自动解出销售部 4 个部门、大客户销售部 6 个销售处，
  且**不把「上海分公司」计入**）；第 6 题引用 `招股说明书2.pdf 第72页 图表`（汽车 14.0% 最快、IC卡 -2.0% 负增长）；
* 优化环节（T7）同协议复测：准确率未退化、拒答 4/4、英文 3/3、权威层 14/16（向量 12/16）、
  含英文三题的 wall max 2017.8 ms，明细与前后对比见 `优化/评估结果/优化报告.md`。

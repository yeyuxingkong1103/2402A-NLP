# 基于 RAG 的多角色扮演系统 - 思维导图

## 系统总览

- RAG 多角色扮演系统
  - 离线部分
    - 文档解析
      - PyMuPDF（文本）
      - pdfplumber（表格）
      - PaddleOCR（扫描件）
      - MinerU（复杂版面）
      - 多模态大模型
    - 文本清洗（去水印 / 低质量过滤 / 去重）
    - 文档分块（固定 / 句子 / 段落 / 标题 / 语义 + 父子块）
    - 数据增强（摘要 / 假设问题）
    - 向量化（BGE-m3）
    - 入库（Milvus + MongoDB + MySQL）
  - 在线部分
    - 查询改写 / 扩写
    - 混合检索（向量 + BM25）
    - 多路召回（Milvus / Redis / MongoDB / Neo4j / MySQL）
    - RRF 融合（阈值过滤 / 去重）
    - 重排序（BGE-reranker）
    - 提示词模板（角色）
    - 大模型生成（多 Provider / 本地部署）
    - 后处理（正则 + 引用校验）
    - 返回用户（Streamlit）
  - 记忆系统
    - 短期记忆（Redis）
    - 长期记忆（MongoDB 摘要）
  - 多角色
    - 角色注册表（10 个预置）
    - 角色 ↔ 知识域绑定
    - 多用户隔离
  - 知识库管理
    - 上传 / 批量入库
    - 文档列表 / 删除
    - 动态更新
  - 运维可视化
    - Redis（键/内存/命中率/热问题）
    - Milvus（实体/域分布/检索预览）
  - 框架集成
    - LangChain（六要素）
    - LlamaIndex（分块/检索）
  - 工程化
    - 多环境配置（dev/test/prod）
    - 统一日志（logging）
    - 单元 / 集成测试（pytest）
    - 接口测试（Postman / test_rag.py）
    - 压力测试（JMeter）
    - 评测（RAGAS）
    - 部署脚本（install/run/shutdown）

## 数据流（在线问答）

1. 用户提问
2. 前端（Streamlit）→ 后端（FastAPI `/chat_stream`）
3. 查询改写 / 扩写
4. 多路召回 + RRF 融合
5. BGE-reranker 精排
6. 拼提示词（角色 + 上下文 + 历史）
7. 大模型生成（流式）
8. 后处理
9. 写回记忆（Redis）/ 热问题（ZSet）
10. 返回前端

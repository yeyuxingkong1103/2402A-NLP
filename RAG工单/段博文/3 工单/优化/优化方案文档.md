# 优化方案文档

**工单编号**：人工智能NLP-RAG-PDF文档的表格解析及检索优化

## 一、优化目标

在工单一基础上，提升 PDF 文档问答系统的检索精度和响应速度，特别是针对表格数据的结构化解析与检索。

## 二、核心优化点

### 1. 表格解析增强（核心新增）

| 优化项 | 优化前 | 优化后 | 效果 |
|---|---|---|---|
| 表格提取 | 无 | pdfplumber 识别表格结构 | 保留表格行列语义 |
| 表格格式 | 纯文本 | Markdown 表格 | 结构化数据，便于 LLM 理解 |
| 表格切分 | 切分 | 不切分，保持完整 | 避免表格结构被破坏 |

**实现**：
- 使用 pdfplumber 识别 PDF 中的表格
- 转换为 Markdown 格式：`| 列1 | 列2 | ... |`
- 表格块标记 `block_type: "table"`，检索时可识别

### 2. 检索策略优化

| 参数 | 优化前 | 优化后 | 说明 |
|---|---|---|---|
| 分块大小 | 500 | 400 | 更细粒度，提升精度 |
| 分块重叠 | 80 | 50 | 减少冗余 |
| 召回数量 | 10 | 6 | 降低噪声 |
| 重排数量 | 5 | 3 | 聚焦核心结果 |
| 分数阈值 | 0.3 | 0.25 | 保召回率 |

### 3. LLM 生成优化

| 参数 | 优化前 | 优化后 | 说明 |
|---|---|---|---|
| max_tokens | 2048 | 768 | 事实型回答足够 |
| temperature | 0.3 | 0.1 | 更稳定、更准确 |

### 4. 缓存机制

| 缓存类型 | 大小 | 效果 |
|---|---|---|
| 检索缓存 | 256 条 | 重复查询毫秒级返回 |
| LLM 缓存 | 256 条 | 重复问题直接返回答案 |

## 三、性能对比

|---|---|---|---|

| 关键词命中率 | - | 84.1% (37/44) | - |

## 五、后续优化方向

1. **表格检索增强**：表格块在检索时给予额外权重
2. **表格内容摘要**：为每个表格生成语义摘要，提升检索召回率
3. **多模态支持**：结合表格图像识别，提升复杂表格的解析能力

- 展示 README 标题「调试与微调专用视觉语言模型」。
- 旁白：RAGFlow 默认 VLM 对工业术语（淬火、公差配合）和复杂图纸理解不足，本工单用 IMDR 数据对 Qwen2-VL 做 LoRA 领域微调。

- 打开 `data/train.jsonl`，展示一条样本：question / answer / image 字段。

- 旁白：将 IMDR 的 QA 对与图文块转换为 SFT 格式，train 102 条、eval 18 条。

  - 训练进度条与 loss 输出。
- 旁白：fp16 + 梯度检查点 + 冻结视觉塔，8GB 显卡即可跑通。

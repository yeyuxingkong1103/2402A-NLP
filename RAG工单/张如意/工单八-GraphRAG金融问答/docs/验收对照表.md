### 关于 `eval_question.md` 的说明（重要）

工单原文要求「问答系统基于 `eval_question.md` 中的 Question 进行检索」，
但**附件 `ccf_competition.zip` 中并未提供该文件**（压缩包内仅有 9 份年报的 `pdf/` 与 `txt/`）。

**处理方式**：本工单**依据工单07《功能测试及评估》的测试集构建了等价的问题集**，
落在 `questions/eval_question.md`：

- **Q01~Q04** 直接复用工单07 所依据的附件 `sample_questions.pdf` 中的 4 个示例问题（原文与参考答案均来自该 PDF）；
- **Q05~Q10** 围绕同一批 CCF 年报扩充的数值型 / 对比型 / 全局型问题；
- 问题类型覆盖 `事实型 / 数值型 / 对比型 / 分析型 / 全局型`，与工单07 的测试集口径一致。

该说明同时写在 `questions/eval_question.md` 的文件头部。

## 六、限制说明（如实声明）

| 项 | 说明 |
| --- | --- |
| 多语言支持 | 界面与图谱以中文为主。图谱实体的名称为中文，用英文提问时局部检索（`link_entities`）无法命中，会退化为全局检索或原文兜底。若需完整英文支持，需要在抽取阶段加入英文实体类型体系并重建图谱。 |
| 附件缺失 `eval_question.md` | 已按工单07 的测试集构建等价问题集，并在 `questions/eval_question.md` 头部与本文档中显式说明。 |
| 工单07 结果文件 | `compare_with_wo07.py` 会从 `工单07-功能测试及评估/results/rag_test_results.json` 读取；若文件不存在，脚本给出友好提示并只输出工单08 的结果（`compare_wo07.json` 中 `wo07.available=false`），不会报错。 |
| 图谱抽取成本 | 9 份年报全量抽取需较长时间与 API 额度，因此 `build_graph.py` 提供了 `--max-chunks` 与断点续跑；抽取缓存位于 `data/graph/extractions_optimized.jsonl`。 |
| 交付物中不含二进制产物 | 按工单要求「只交付代码」，本次未实际执行脚本；`results/` 下的统计、图谱、问答、对比、研报等产物需在配置 `DEEPSEEK_API_KEY` 后运行脚本生成。 |

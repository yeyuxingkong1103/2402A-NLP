# 工单七 部署与运行说明

## 环境要求

- Python 3.10+
- 依赖：`pip install -r 02_研发/requirements.txt`

## 运行评估

```bash
cd 02_研发/src
python run_evaluation.py
```

评估结果输出至 `03_测试/ragas评估结果.csv`，检索明细输出至 `03_测试/检索结果.json`。

## 模块说明

| 模块 | 职责 |
|------|------|
| dataset_loader.py | 加载问题集与招股书 PDF |
| rag_pipeline.py | 检索+答案生成流水线 |
| ragas_evaluator.py | RAGAS 四指标计算 |
| run_evaluation.py | 全流程编排入口 |

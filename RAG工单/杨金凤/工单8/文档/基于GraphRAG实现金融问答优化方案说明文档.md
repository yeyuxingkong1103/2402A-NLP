## 1. 优化目标

在工单 07（纯向量 RAG 测试金融年报）基础上，引入知识图谱增强检索，解决以下问题：

| 工单 07 问题 | Graph RAG 方案 |

---

## 2. 优化方案

### 2.1 知识图谱构建

| 步骤 | 内容 |
| --- | --- |
| 1 | 从 CCF 向量库抽取 450 个文本块（每份年报 50 块） |
| 2 | 用 Qwen2.5-7B 抽取三元组 (主体, 关系, 客体) |
| 3 | 构建 NetworkX 有向图 |
| 4 | 保存 kg_graph.json + 可视化 PNG |

**成果**：3151 节点，2720 边，2791 三元组。

### 2.2 Graph RAG 检索

```text
用户问题
     ├→ 图谱实体识别 → 邻居三元组（15 条）
     ├→ 向量检索 → top 4 文本块
     └→ 融合上下文 → LLM 生成
```

**核心算法：**

- **实体识别**：在问题中匹配 2-6 字的图谱节点
- **邻居扩展**：抽取出边 + 入边的三元组，最多 15 条
- **融合**：图谱三元组 + 向量块拼成完整上下文

### 2.3 Prompt 强化

新增规则：

```text
上下文包含两部分：
1. 文本片段（来自年报原文）
2. 知识图谱三元组（格式：主体 | 关系 | 客体）

规则：
1. 文本片段优先，图谱三元组作为实体关系的补充。
2. 回答中的数字必须严格来自上下文。
```

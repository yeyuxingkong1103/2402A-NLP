### 程序启动执行流程

1. 加载模拟金融文档，切分文本块。
2. 初始化 GraphBuilder，批量添加实体关系三元组构建知识图谱。
3. 输出`graph_visual.html`可视化文件。
4. 自动批量运行 eval_questions 的 10 条测试问题，终端打印评测输出。
5. 启动 Flask Web 服务，监听`0.0.0.0:7861`。

## 5. 部署注意事项

1. 虚拟环境必须激活，否则会报 ModuleNotFoundError。
2. 端口 7861，注意不要和工单 6、7 的 7860 混淆。
3. 当前图谱为内存图谱，程序 Ctrl+C 关闭后，内存图谱消失；本地 html 文件会保留。
4. Flask 内置 web 服务器仅用于实训演示，不能直接用于生产环境。
5. 不要上传虚拟环境文件夹到版本仓库。

## 6. 故障排查

1. 模块找不到：确认虚拟环境已经激活。
2. 网页打不开：确认 WSL 内程序正常运行，端口是 7861。
3. 可视化 html 打不开：在 Windows 直接双击打开该 html 文件。
4. 问答无返回结果：查看 WSL 终端输出，排查检索逻辑。

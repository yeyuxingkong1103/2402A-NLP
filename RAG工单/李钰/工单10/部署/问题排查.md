# Docker 部署问题排查

> 工单编号: 人工智能 NLP-RAG-金融问答系统部署

## 常见问题

### Q1: docker build 失败 "pip install" 超时?

```bash
# 方案: 使用国内镜像
docker build --build-arg PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
    -f 工单10/部署/Dockerfile -t financial-rag:v10.0 .
```

### Q2: 容器启动后立即退出?

```bash
# 查看日志
docker logs financial-rag-qa

# 常见原因:
# 1. 端口被占用: -p 5009:5008 改端口
# 2. 目录权限: 宿主机 /app/data 权限不足
# 3. Python 依赖缺失: docker exec -it xxx pip list
```

### Q3: /api/health 返回 503 unhealthy?

```bash
# 原因: V9 引擎加载失败
docker exec -it financial-rag-qa python -c "import qa_engine_v9; print('ok')"

# 原因: 端口未就绪
docker logs financial-rag-qa | grep "Starting"
# 应该看到: Starting Financial RAG QA on 0.0.0.0:5008
```

### Q4: LLM API 调用失败?

```bash
# 容器内测试
docker exec -it financial-rag-qa python -c "
import os, requests
key = os.environ.get('LLM_API_KEY', '')
url = os.environ.get('LLM_BASE_URL', '')
print(f'Key: {key[:4]}..., URL: {url}')
# 不配置则降级, 不报错
"
```

### Q5: 数据卷挂载后数据丢失?

```bash
# Docker 空卷挂载会覆盖容器内原有数据!
# 解决方案:
# 1. 首次运行先 docker run 不挂卷 → 生成数据 → 备份
# 2. 再挂卷: docker run -v rag_data:/app/data ...
# 3. entrypoint.sh 已处理: 空卷时自动复制预设数据

# 查看卷数据
docker run --rm -v rag_data:/data alpine ls -la /data
```

### Q6: Neo4j 容器无法连接?

```bash
# 1. 在同一个 network
docker network create rag_network
docker run -d --name rag-neo4j --network rag_network neo4j:5
docker run -d --name financial-rag-qa --network rag_network \
    -e NEO4J_URI=bolt://rag-neo4j:7687 ...

# 2. 验证
docker exec financial-rag-qa python -c "
from neo4j import GraphDatabase
d = GraphDatabase.driver('bolt://rag-neo4j:7687')
print(d.verify_connectivity())
"
```

### Q7: 内存不足 OOM?

```bash
# 限制容器内存
docker run ... --memory=2g --memory-swap=2g financial-rag:v10.0

# 查看内存使用
docker stats financial-rag-qa
```

### Q8: 如何进入容器调试?

```bash
docker exec -it financial-rag-qa /bin/bash
# 或 Alpine 镜像
docker exec -it financial-rag-qa /bin/sh

# 验证环境
ls /app/
python -c "import qa_engine_v9; print('ok')"
python -c "import config_v10; print(config_v10.DATA_DIR)"
```

### Q9: Windows Docker 卷中文路径乱码?

```powershell
# PowerShell 使用 --% 停止解析
docker run -d --name financial-rag-qa --%
    -p 5008:5008
    -v rag_data:/app/data
    financial-rag:v10.0

# 或用 docker-compose (推荐)
工单10\部署\run_docker.bat
```

### Q10: 如何升级版本?

```bash
# 1. 构建新镜像
docker build -t financial-rag:v10.1 ...

# 2. 停止旧容器
docker stop financial-rag-qa

# 3. 备份数据
docker run --rm -v rag_data:/data -v $(pwd):/backup alpine \
    tar czf /backup/rag_data.tar.gz -C /data .

# 4. 启动新容器 (保留卷)
docker rm financial-rag-qa
docker run -d --name financial-rag-qa \
    -v rag_data:/app/data -v rag_cache:/app/cache ... \
    financial-rag:v10.1

# 5. 验证
curl http://localhost:5008/api/health
```

## 端口冲突

```bash
# 查找占用
netstat -tlnp | grep 5008   # Linux
netstat -ano | findstr 5008  # Windows

# 改端口
docker run -p 5009:5008 financial-rag:v10.0
curl http://localhost:5009/api/health
```

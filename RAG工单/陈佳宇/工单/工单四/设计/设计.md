# 工单4｜PDF图像多模态RAG检索系统 - 设计文档
## 1. 需求分析
### 1.1 业务背景
传统文本RAG只能解析PDF内可复制文字，对于包含大量图表、组织结构图、曲线图的招股说明书PDF，无法提取图片内信息。本项目基于CLIP多模态模型+Milvus向量库，实现图像级别的文档检索。用户输入自然语言问题，系统自动检索PDF中最相关的页面图片。

### 1.2 功能需求
1. PDF文档预处理：将PDF每一页渲染为图片，保存到本地文件夹。
2. 多模态向量编码：使用CLIP模型，对图片生成512维向量嵌入。
3. 向量库管理：Milvus向量数据库，支持集合创建、向量插入、相似度检索。
4. 文本向量化：用户输入的自然语言问题，通过CLIP文本编码器转为同向量空间的文本向量。
5. 向量相似度检索：根据文本向量，在向量库中召回Top2最相似PDF页面图片。
6. Web交互界面：Flask搭建前端页面，支持输入问题、展示检索耗时、匹配图片名称与相似度分数。

### 1.3 非功能需求
1. 单次检索响应耗时控制在1秒以内。
2. WSL环境部署，支持Windows主机浏览器访问Web页面。
3. 代码模块化，易扩展，可后续接入OCR和大模型生成答案。
4. 容错：支持自动截断超长用户提问，避免CLIP模型token超限报错。

## 2. 总体架构设计
四层架构：文档预处理层 → 多模态向量编码层 → 向量存储层 → Web应用层
1. **文档预处理层**：PyMuPDF读取PDF，逐页渲染生成PNG图片，输出至pdf_images目录。
2. **向量编码层**：CLIP(openai/clip-vit-base-patch32)，图片与文本映射到同一个512维向量空间。
3. **向量存储层**：Milvus向量数据库，存储图片向量与元数据，提供向量相似度检索。
4. **Web应用层**：Flask框架，提供前端页面展示与问答接口。

### 业务流程
1. 离线预处理：PDF → 页面图片 → CLIP图片向量 → 存入Milvus。
2. 在线检索：用户输入问题 → CLIP文本编码生成向量 → Milvus向量检索 → 返回Top2结果 → Web前端展示。

## 3. 数据模型设计（Milvus集合）
集合名称：`rag_waterwork4`
| 字段名 | 字段类型 | 说明 |
| ---- | ---- | ---- |
| id | INT64 | 主键ID，auto_id自动生成 |
| image_name | VARCHAR | 图片文件名，如page0.png |
| image_path | VARCHAR | 图片本地存储路径 |
| vector | FLOAT_VECTOR(512) | CLIP输出512维向量 |

索引：IVF_FLAT索引
距离度量方式：L2距离，L2值越小，代表向量相似度越高。

## 4. 接口设计
### 接口1：GET /
- 作用：返回Web前端HTML页面
- 入参：无
- 返回：网页HTML

### 接口2：POST /ask
- 作用：接收用户提问，执行多模态检索，返回检索结果
- 请求体JSON：`{"q":"用户的问题"}`
- 返回JSON：
```json
{
  "ans": "【检索耗时：0.164秒】\n\n---匹配图片1---\n图片文件名：page0.png\n相似度得分：0.2599\n\n---匹配图片2---\n图片文件名：page2.png\n相似度得分：0.2262\n"
}
## 5. UI 页面设计

页面组成：

1. 标题：工单 4｜PDF 图像内容解析多模态 RAG 检索系统
2. 提示示例文字
3. 文本输入框：用于输入用户问题
4. 蓝色提交按钮：提问检索
5. 结果展示区域：展示检索耗时、匹配图片名称、相似度分数

## 6. 模块拆分设计

1. PDF 图片生成模块：读取 PDF，渲染页面保存 PNG。
2. Milvus 集合管理模块：创建、删除向量集合。
3. CLIP 向量编码模块：图片向量化、文本向量化，兼容向量类型转换。
4. 向量入库模块：遍历图片，批量生成向量插入 Milvus。
5. 检索模块：文本向量检索，封装返回结果。
6. Flask Web 服务模块：页面渲染、接口接收请求。

## 7. 风险与应对设计

1. CLIP 文本 token 上限 77：开启 truncation=True 自动截断长文本，防止程序崩溃。
2. Milvus 向量类型校验：numpy 数组转为原生 Python float 列表，规避类型报错。
3. WSL 网络访问：Flask 绑定 0.0.0.0，允许 Windows 主机访问网页。

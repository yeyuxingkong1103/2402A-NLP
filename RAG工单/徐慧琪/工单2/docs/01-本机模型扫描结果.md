## 3. 关键结论

- **Embedding**：`D:\model\bge-m3` 为完整 sentence-transformers 目录（含 `modules.json` / `1_Pooling` / `2_Normalize`），xlm-roberta / hidden 1024 / max_pos 8194，中英双语 —— 首选。
- **Reranker**：`D:\model\reranker` 与 `D:\model\reranker_ms` 均为 `XLMRobertaForSequenceClassification`，即 **bge-reranker-v2-m3**，可直接用于 cross-encoder 精排 —— 满足工单"若本机有 bge-reranker 系列则启用"。
- **LLM**：Ollama 本地已 pull `qwen2.5:3b`（1.8 GB）与 `qwen2.5:0.5b`，离线调用不触发下载。
- **OCR / 解析**：MinerU 的权重（`MinerU2.5-Pro-1.2B` VLM + `PDF-Extract-Kit-1.0` 版面/公式/表格）**已在 ModelScope 缓存中**，PaddleOCR-VL 亦有本地权重与独立 venv —— 可零下载启用。
- **空壳警告**：HF 缓存中的 `models--opendatalab--PDF-Extract-Kit` 仅有 refs、无权重，任何 `from_pretrained` 都会尝试联网，**必须避开该路径**。
- **离线保障**：所有模型加载代码将显式使用本地路径 + `local_files_only=True`；Ollama 仅调用已 pull 模型。

## 5. 工单02 实施期间的依赖与环境变更（2026-10-03 补记）

> 本节记录第一步扫描之后、为落地 MinerU 而做的依赖安装与环境实测结论。
> **未新增任何模型权重**（全部沿用上表的本机缓存模型），仅安装 pip 软件包。

| 变更 | 内容 | 影响 |
| --- | --- | --- |
| 安装 | `mineru==3.4.5`（最终采用）+ `mineru_vl_utils==1.2.1`（pip 包；用 `--no-cache-dir` 规避本机 pip 缓存哈希异常） | 不触发模型下载 |

| 实测 | **3.4.5 `pipeline` 后端** | ✅ **可用**：模型清单（PP-DocLayoutV2 / unimernet / paddleocr_torch / TabRec / TabCls）与本机 PDF-Extract-Kit 快照**完全匹配**；版面分析 ~1.1 s/页 |

详细实测过程与数据见 `docs/02-优化方案.md` 第 2.1 节。

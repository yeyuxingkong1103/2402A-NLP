# 工单11 技术选型

## 1. 选型总表（含落选方案与理由）

| 维度 | 选定 | 落选方案 | 决定性理由（本机实测） |
| --- | --- | --- | --- |
| 底座模型 | **`bge-small-zh-v1.5`**（本地权重） | `bge-m3`（Ollama，1024 维）/ 联网下载 `bge-base-zh` | 本地目录已有完整权重（safetensors + tokenizer），**离线可加载**；23.95M 参数、4 层、512 维，CPU 可训；bge-m3 是 568M 级模型，CPU 微调不可行 |
| 训练框架 | **原生 PyTorch 手写循环** | `sentence-transformers` Trainer / `transformers.Trainer` | 本机**无 accelerate / peft / datasets**，两个 Trainer 均会 ImportError；原文点名的损失函数只有十几行，自实现可控且零依赖 |
| 微调方式 | 全参微调中**解冻最后 2 层 + 池化** | LoRA / PEFT / 全参微调 | PEFT 装不上；全参微调在 1400 样本下更易灾难性遗忘；解冻后 2 层（6.57M/23.95M）兼顾效果与 CPU 反向耗时 |
| 设备 | **CPU（6 线程）** | RTX 2060 6GB | `_共享约定.md` 要求微调走 CPU，避免与并行工单抢显存 |
| 池化方式 | **CLS 池化** | Mean / Max 池化 | 底座 `1_Pooling/config.json` 明示 `pooling_mode_cls_token=true`，**必须与底座一致**，否则前后向量空间不可比 |
| 损失函数 | **TripletLoss(margin 0.3) + CosineSimilarityLoss(缩放 1.0, 权重 0.5)** | 单用 CosineSimilarityLoss / ContrastiveLoss | 评测口径是 Top-K 排序，Triplet 与之同向；Cosine 提供绝对尺度约束；二者复用同一次前向 |
| 负例策略 | **同指标异公司（难）+ 同公司异页（中）** | 随机负例 / in-batch 负例 | 语料的区分性信息是「实体+年度」，随机负例太易，学不到区分性（in-batch 负例已作为 `hard_mining` 选项内置） |
| 评测指标 | **Recall@1/5/10 + MRR + nDCG@10 + 相似度间隔 + 端到端真题命中** | 仅 loss / 仅相似度 | 原文验收标准是「检索效果更好，要有数据指标支撑」，必须有排序指标；单看 loss 不能证明检索提升 |
| 图表渲染 | **PIL 自绘（`研发/src/plot.py`）** | matplotlib / plotly | 本机**未装 matplotlib**，且禁止联网装大包 |
| 截图渲染 | `_共享工具/截图渲染.py`（Page） | 手写 PIL | 跨工单共享的中文字体渲染器，页脚自动标注来源，可追溯 |
| 配置格式 | **JSON**（`部署/配置/*.json`） | YAML | 工单允许「yaml/json」；JSON 为标准库 `json` 零依赖，避免 yaml 版本差异 |
| 相似度分数标注 | **字符 2-gram Jaccard**（正例固定 1.0） | 人工标注 / 教师模型打分 | 客观、可复现、无需额外模型；口径写入文档 |
| 金标准判定（真题） | **判分关键词命中 ≥ max(2, ⌈0.34×K⌉) 且限定来源文档** | 仅按页码区间 / 仅按文档 | 页码区间因 PDF 物理页与正文页码不一致而不可靠；关键词命中可从 `测试问题集.jsonl` 机械推导，规则显式可复现 |

## 2. 依赖清单

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Python | 3.11.15（工单1 venv） | 唯一可用解释器 |
| torch | 2.11.0+cpu | 训练与推理 |
| transformers | 已装 | `AutoModel` / `AutoTokenizer` 本地加载 |
| numpy | 已装 | 向量与指标计算 |
| Pillow | 已装 | 折线图/柱状图/截图渲染 |
| pytest | 已装 | 单元测试 |
| requests | 已装 | 可选 Ollama 参照（默认关闭） |

**未使用**（本机缺失且不安装）：accelerate、peft、datasets、pandas、matplotlib、loguru。
`研发/requirements.txt` 仅列出上述已装依赖及其用途，**不引入新依赖**。

## 3. 放弃的能力与替代

| 放弃 | 替代 |
| --- | --- |
| `Trainer` 的自动混合精度/分布式 | 纯 fp32 CPU 训练（本任务规模不需要） |
| `datasets` 库的数据管道 | 标准库 `json` 逐行读 jsonl |
| `pandas` 的对比表 | 标准库 `csv` 写出（UTF-8-BOM，Excel 直接可开） |
| `matplotlib` 曲线图 | PIL 自绘折线图/柱状图（`研发/src/plot.py`） |
| bge-m3 微调 | bge-m3 仅作工单7 生产模型的参照（默认关闭，节省时间） |

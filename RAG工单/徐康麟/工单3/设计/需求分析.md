### 1.3 工单3 必须证明的因果关系

> 表格解析与检索优化**必须**针对基线失败题给出可量化改进证据（t5 任务契约）。本设计把因果链冻结为：

```
表格页证据（如 PDF1 p130 军用收入表、PDF2 p22 发行情况表）
  → table_parser 归一化 + Markdown 化（FR-2）
  → 表格整体成块、type=table（FR-3）
  → 向量 + BM25 双路召回、表格/数字加权（FR-5）
  → 证据原文落入 top-5（验收 2 的命中判据）
  → 生成答案数值完整（验收 3 准确率）
  → 引用 [文件名: 页码] 可回溯（验收 5）
```

失败的对照组：基线里 33 题只答出 `82.10%` 一个数值、95 题答「未知」、793 题漏掉「各类终端用户…覆盖范围广泛」——**均属证据未完整入模**，而非模型能力问题（同题在 golden 里就有完整原文）。

### 4.4 页码口径：唯一、1-based、物理页（**最容易埋雷的一条**）

本 PDF 存在**三套编号**，其中两套数值完全相同，这才是混用根源：

| 编号体系 | 物理第 129 页 | 物理第 130 页 | 与 1-based 物理页码的关系 |
| --- | --- | --- | --- |
| ① **1-based 物理页码（全仓库唯一采用）** | 129 | 130 | —— |
| ② 0-based 索引 `d[i]` | `d[128]` | `d[129]` | 物理页码 − 1 |

| 规则 | 内容 |
| --- | --- |
| 唯一权威来源 | **pymupdf 页序**：`d[i]` = 物理页 `i+1` |

## 8. 判分口径需求（先定义，后实现，**禁止后期调整尺子**）

| 指标 | 定义 | 判据 |
| --- | --- | --- |
| **准确率 accuracy** | 14 题中判对题数 / 14 | **沿用「工单1 `Evaluator.check_answer` 口径」**（数值全命中 / 二元组相似度 ≥ 0.62 / 关键实体命中 / 参考答案为答案子串 / 否定则错）。动态加载只读源码并 `sys.dont_write_bytecode = True`，不得向 `工单1` 写 `.pyc` |
| **检索命中率 hit_rate** | 证据原文是否**落在返回的 top-k chunk 文本中**（归一化去空白标点后做包含或词覆盖判定） | **不得**用「引用页 == `evidence_pages`」判定（会把 957 误计为命中并高估命中率）【环境事实 §5】 |
| **首字响应 first_token_ms** | 从发出提问到界面/接口收到**第一个 token 文本**的墙钟毫秒（含改写、嵌入、检索、重排、首 token 生成） | 逐题测量，**取最大值**判定 |
| **引用正确率 citation_accuracy** | 有效引用条数 / 引用总条数；有效 = 页码为整数且 `1 ≤ page ≤ 该 PDF 页数` **且** 引用页含支撑原文（抽验）**且** `chunk_id` 可在 SQLite 查到 | 允许引用页 ≠ `evidence_pages`（同一原文可多处出现，如 543 基线引 52 页亦为有效），但**必须**有支撑原文 |
| **「不清楚」正确率 unknown_accuracy** | ① 无关问题集（≥10 条）中回「不清楚」的比例；② 14 题中误回「不清楚」的比例（须为 0） | 拒答率 = 1.0；误拒答 = 0 |
| **多轮成功率** | 3 轮连续问答全部通过（含指代消解、不串题、历史落库） | 3/3 |
| **语言正确率** | 英文题答案语言判定为 `en` 的比例；中文题同理 | ≥ 0.80（5/5 为目标） |

**可答性阈值（T6 标定，v1.8 回写；以实现为唯一准据）**：

| 参数 | 值 | 角色 | 标定实测依据 |
| --- | --- | --- | --- |
| `RAG_ANSWER__MIN_SCORE` | **0.12** | **退化底线**（不作主判据） | 正样本 `min score = 0.153`，负样本 `max score = 0.205` → **两区间重叠**，任何落在重叠区的阈值都会误判 → 只能用低底线兜住极端噪声 |
| `RAG_ANSWER__MIN_KEYWORD_COVERAGE` | **0.45** | **主判据** | 正样本 `min coverage = 0.615`，负样本 `max = 0.400` → **可分**（间距 0.215）→ 覆盖率为可靠判据（实测 14/14 通过、5/5 无关问题拒绝） |

> **纪律**：阈值**只由标定决定**，不得为通过验收而放宽（T11 复核项：若阈值发生变化，必须同时给出新的正/负样本 min/max 实测值作为依据）。

## 13. 术语表

| 术语 | 含义 |
| --- | --- |
| 物理页 | PDF 内第 N 页（1-based），`doc[N-1]`；引用、分块、评估统一用它 |
| 印刷页码 | 页脚/页眉处打印的页码：PDF1 形如 `1-1-128`（在页脚），PDF2 为裸数字 `'128'`（在页眉块）；其数值 = 物理页 − 1 = 0-based 索引，**禁止**用于引用，也禁止据此反推页码 |
| 逻辑列 | 合并单元格还原后的真实列数（如物理 130 页 10 列 → 逻辑 5 列） |
| 逻辑表块 | 跨页表经续表合并 + 重复表头去重后的单个表格单元（含 `page_start`/`page_end`），解析与分块的最小单位 |
| 续表 | 本页首表首行首格为空/`None` 且上页含表 → 同一张表被切页的后续部分（PDF1 45 页 / PDF2 79 页），必须继承上页表头 |
| 重复表头 | 本页首表首行与上页首行完全相同（PDF1 21 页 / PDF2 10 页），必须去重以免 BM25 词频虚增 |
| RRF | Reciprocal Rank Fusion，`score = Σ w/(k + rank)` |
| 证据页 | `golden_qa.jsonl` 的 `evidence_pages`，仅作参考，**不是**引用判定真值 |
| 命中 | 证据原文落在返回 chunk 文本中（§8） |
| 空降级 | 无 LLM 时用 `extractive` 后端直接抽取证据句并拼引用 |
| 热态 / 冷态 | 模型已加载（热）与进程/模型首次调用（冷）；预热把冷态成本移到进程启动阶段 |

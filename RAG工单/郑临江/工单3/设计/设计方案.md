# 设计：PDF表格解析及检索优化

工单编号：人工智能NLP-RAG-PDF表格解析及检索优化

## 工单需求
新增力源信息招股文件的表格解析，四道新题和十道回归题正确；重点校验发行股数、募投项目及关联方。

## 数据与关联
所有源PDF、嵌入模型、索引、图谱、图像、测试集与日志均位于本工单目录。本项目运行时不访问其他工单文件。LLM调用本机已有Ollama服务，其环境与模型名称单独记录；主目录无公共数据。
本项目使用2个PDF、898个物理页。原工单PDF、提取原文与附件哈希在设计目录。项目间复用的是离线复制的代码/数据快照，无运行时共享。

## 架构
输入问题 -> 会话/术语规范 -> 本项目检索或图谱扩展 -> 证据上下文 -> 本地模型 -> 页码来源/反馈。离线为PDF解析 -> 文本/表格/必要图像摘要 -> 分块 -> BGE/稀疏索引 -> 持久化。

## 技术选择及边界
PyMuPDF find_tables提取真实行列；逐行序列化、保留文档及物理页码；在公司实体范围内索引。存在控制关系与不存在控制关系用表头及列值定位表格，不将已转让历史关联企业混入现有名单。
原PDF只是业务/任务参考资料，不能覆盖用户对目录、环境和部署简化的要求。涉及外部发布或与其他人通信的内容未执行。

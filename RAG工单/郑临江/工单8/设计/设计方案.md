# 设计：GraphRAG金融问答

工单编号：人工智能NLP-RAG-GraphRAG金融问答

## 工单需求
基于金融年报实现GraphRAG、实体关系图、问答和研报生成，与工单7对比。

## 数据与关联
所有源PDF、嵌入模型、索引、图谱、图像、测试集与日志均位于本工单目录。本项目运行时不访问其他工单文件。LLM调用本机已有Ollama服务，其环境与模型名称单独记录；主目录无公共数据。
本项目使用9个PDF、2812个物理页。原工单PDF、提取原文与附件哈希在设计目录。项目间复用的是离线复制的代码/数据快照，无运行时共享。

## 架构
输入问题 -> 会话/术语规范 -> 本项目检索或图谱扩展 -> 证据上下文 -> 本地模型 -> 页码来源/反馈。离线为PDF解析 -> 文本/表格/必要图像摘要 -> 分块 -> BGE/稀疏索引 -> 持久化。

## 技术选择及边界
完整语料片段进行类型化规则实体抽取：机构、人名、财务指标、风险指标、业务、主题等；关系DISCLOSES_TOPIC及明确法定代表人/董事长。每条关系带文档、页码、chunk_id和抽取来源。实体锚定+图邻接扩展+语义检索用于GraphRAG。
原PDF只是业务/任务参考资料，不能覆盖用户对目录、环境和部署简化的要求。涉及外部发布或与其他人通信的内容未执行。

# 金融问答系统 Docker 部署方案

> 工单编号: 人工智能 NLP-RAG-金融问答系统部署
> 基线: V9 Graph RAG 优化版 (端口 5008)

## 一、部署架构

```
┌─────────────────────────────────────────────────────┐
│                   Docker Host                        │
│                                                      │
│  ┌────────────────────────────────────────────────┐  │
│  │  financial-rag 容器                            │  │
│  │  ┌─────────────────────────────────────────┐  │  │
│  │  │ Flask App (端口 5008)                    │  │  │
│  │  │ ├── Graph RAG V9 问答引擎                │  │  │
│  │  │ ├── RAGAS 评估器                         │  │  │
│  │  │ └── 健康检查 /api/health                 │  │  │
│  │  └─────────────────────────────────────────┘  │  │
│  │                                                 │  │
│  │  Volumes:                                      │  │
│  │  ├── /app/data          → 持久化数据            │  │
│  │  ├── /app/cache         → 缓存 (向量索引)       │  │
│  │  └── /app/logs          → 日志                  │  │
│  └────────────────────────────────────────────────┘  │
│                                                      │
│  网络: bridge (默认) → 可访问主机端口 5008            │
│  共享卷: rag_shared_volume → 供多容器共享数据          │
└─────────────────────────────────────────────────────┘
```

## 二、验收标准对照

| 验收项 | Docker 实现 | 状态 |
|--------|------------|------|
| docker run 启动容器 | ✅ Dockerfile + CMD | 满足 |
| 指定端口提供服务 | ✅ EXPOSE 5008 + -p 映射 | 满足 |
| 无异常日志 | ✅ 健康检查 /api/health | 满足 |
| Docker 卷持久化 | ✅ -v 挂载 /app/data /app/cache | 满足 |
| 容器间数据共享 | ✅ named volume rag_shared | 满足 |
| 网络配置 | ✅ docker-compose network | 满足 |

## 三、关键配置

### 3.1 Docker 卷 (持久化)
```
rag_data       → /app/data          知识图谱 JSON、预设数据
rag_cache      → /app/cache         向量索引缓存
rag_logs       → /app/logs          应用日志
rag_shared     → /app/shared        容器间共享目录
```

### 3.2 网络 (容器间通信)
```
rag_network    → bridge 网络        graph 容器 + evaluator 容器可互通
```

### 3.3 环境变量
```
LLM_API_KEY       → LLM API Key (可选, 不配置降级)
LLM_BASE_URL      → LLM API 地址
LLM_MODEL         → LLM 模型
NEO4J_URI         → Neo4j 地址 (可选)
FLASK_PORT=5008   → Flask 端口
```

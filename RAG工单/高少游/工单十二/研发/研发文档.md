# 研发文档

- 工单编号：人工智能NLP-RAG项目-LightRAG优化
- 项目名称：RAG（招股说明书多轮检索问答系统 · LightRAG 优化）
- 研发周期：2 人日（工单预估）／实测含构建与评估约 1 个工作日

---

## 1. 研发目标

在既有传统 RAG（向量 + 全文混合检索 + 重排）基础上，实现 LightRAG 的**图结构索引 + 双层检索 + 增量更新**，并针对招股说明书领域**优化实体/关系抽取**，最终给出 RAG 与 LightRAG 的**检索结果对比**与 **RAGAS 指标对比**。

---

## 2. 实现步骤

### 第 1 步：复用与改造项目骨架
复用前序工单的 RAG 骨架（`src/` 下切片、嵌入、倒排、混合检索、重排、多轮、答案生成），新增 `src/lightrag/` 子包承载本工单核心能力。

### 第 2 步：领域 Schema 设计
在 `src/config.py` 定义 16 类实体 + 18 类关系；在 `src/lightrag/schema.py` 实现名称规范化、类型校验与兜底映射、领域抽取词典/正则（公司、人物、标准、奖项、指标、组织结构图、持股、地点、行业）。

### 第 3 步：混合抽取
`src/lightrag/extractor.py`：
- `RuleExtractor`：9 类正则/词典抽取，覆盖全量块；
- `LLMExtractor`：领域提示词 + 三级容错 JSON 解析；
- `merge_triples`：按 name / (src,type,tgt) 归并，来源块累加。

### 第 4 步：图存储与主题
`src/lightrag/graph_store.py`：节点/边写入、端点补全、度计算、**Louvain 社区发现**生成主题、增量 `diff`/`apply_diff`、JSONL 持久化。

### 第 5 步：图谱构建与向量化
`src/lightrag/index.py`：`extract_all`（规则 + LLM 并发）→ `build_graph` → `build_vectors`（实体/关系/主题三类）→ `save`；并提供 `incremental_update`。

### 第 6 步：双层检索与融合
`src/lightrag/retriever.py`：局部（实体/关系向量 + 字面 + 一跳扩展）、全局（主题）、三通道 RRF 融合、与 RAG 同款线性重排。

### 第 7 步：引擎与界面
`src/lightrag/engine.py`：对齐 `QAEngine` 接口（`ask` / `warmup` / `set_config`），复用多轮与答案抽取；`app.py` 增加 RAG/LightRAG 切换与图证据展示。

### 第 8 步：评估与工具
`tools/`：`run_eval.py`（RAGAS 口径对比）、`run_functional_tests.py`、`bench_latency.py`、`run_strategy_demo.py`、`gen_flowcharts.py`、`render_ui_shots.py`、`render_terminal_shots.py`、`make_demo_video.py`、`gen_docs.py`。

## 3. 关键数据结构

| 结构 | 位置 | 说明 |
|---|---|---|
| `Triple` | extractor.py | 统一承载实体/关系（kind/name/type/desc/source/target/chunks/origin） |
| `GraphStore` | graph_store.py | `nodes{name→node}`、`edges{(s,type,t)→edge}`、`themes[]` |
| `LightRAGIndex` | index.py | 图谱 + `entity_mat`/`rel_mat`/`theme_mat` 三类向量 |
| `GraphContext` | retriever.py | 本次检索命中的实体/关系/主题（供展示与溯源） |
| `Retrieved` | retrieval_types.py | 候选块（chunk_id/score/vector_score/fulltext_score/rrf/stage） |

---

## 4. 核心算法要点

1. **主题（社区）生成**：Louvain → 贪心模块度 → 连通分量三级回退；主题 title 取社区内度最高/名称最长实体，summary 由实体描述与关系描述拼接。
2. **全局检索衰减**：`贡献 = 主题相似度 / (1 + ln(1 + 主题规模))`。
3. **三通道 RRF**：`score = Σ_channel w_c / (K + rank_c + 1)`，K=60；图通道权重 0.25。
4. **文档级路由**：问句命中公司名/别名 → 限定检索范围到该文档，消除跨文档串味。
5. **答案抽取器优先级**：领域清单类（募投/关联方）必须排在通用指标类之前，避免“整张表原样吐出”。

## 5. 接口约定

`LightRAGEngine` 与 `QAEngine` 对齐，便于界面统一调用：

```python
eng = LightRAGEngine()          # 加载 graph_db/
eng.warmup()                    # 预热
res = eng.ask(query, conv)      # 多轮问答
# res: answer / rewritten / doc / answer_type / latency / evidence / retrieval
# res.retrieval['graph_entities'|'graph_relations'|'graph_themes'] 为图证据
```

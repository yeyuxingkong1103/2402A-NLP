下面是一份基于原始论文《Attention Is All You Need》的Transformer深度讲解，按**数据流顺序**逐一拆解每个组件的**输入、输出、计算方式与实现细节**。

---

## 整体架构

Transformer遵循编码器-解码器（Encoder-Decoder）结构，编码器和解码器各由 **N=6 个相同的层**堆叠而成。所有子层和嵌入层的输出维度统一为 **d_model = 512**，这是残差连接能够成立的前提条件。

编码器负责理解输入序列，解码器负责生成输出序列。两者的输入都需要先经过词嵌入和位置编码。

```
输入序列 → 词嵌入 + 位置编码 → 编码器（N层）→ 编码器输出
                                                    ↓
输出序列 → 词嵌入 + 位置编码 → 解码器（N层，含交叉注意力）→ 线性层 + Softmax → 输出概率
```


## 第一步：词嵌入（Token Embedding）

**输入**：原始文本序列，经过分词（Tokenization）后的整数索引序列。

**输出**：形状为 `(batch_size, seq_len, d_model)` 的浮点向量矩阵，其中 d_model = 512。

**计算方式**：词嵌入是一个**可学习的查找表**。对于每个token的整数ID，直接从嵌入矩阵中取出对应的行向量。嵌入矩阵的维度为 `(vocab_size, d_model)`。

**实现细节**：原始论文中，编码器和解码器的输入端都使用词嵌入层，将离散的token转换为连续的向量表示。论文还做了一个关键设计——**输入端嵌入层的权重与输出端线性层（Softmax之前的那个线性层）共享**。这样做是为了让同一个词在输入和输出时拥有一致的向量表示，同时减少参数量。


## 第二步：位置编码（Positional Encoding）

**输入**：词嵌入的输出，形状 `(batch_size, seq_len, d_model)`。

**输出**：与输入形状相同，每个位置的向量都叠加了位置信息。

**为什么需要**：Transformer的自注意力机制本身是**置换等变的**——如果不加位置信息，“狗咬人”和“人咬狗”在模型看来完全一样。因此必须显式注入位置信息。

**计算方式**：原始论文使用**正弦余弦函数**生成固定的位置编码：

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

其中 `pos` 是位置索引，`i` 是维度索引。偶数维度用sin，奇数维度用cos。

**实现细节**：位置编码向量与词嵌入向量**逐元素相加**，而不是拼接。选择正弦余弦函数的原因是：对于任意固定的偏移量 k，`PE(pos+k)` 可以表示为 `PE(pos)` 的线性函数，这使得模型能够轻松学习**相对位置关系**。


## 第三步：编码器层——多头自注意力（Multi-Head Self-Attention）

这是编码器每一层的**第一个子层**。

### 3.1 单头自注意力（Scaled Dot-Product Attention）

**输入**：编码器上一层的输出（第一层则为词嵌入+位置编码的结果），形状 `(batch_size, seq_len, d_model)`。记这个输入矩阵为 **X**。

**输出**：形状 `(batch_size, seq_len, d_v)`，其中 d_v 是值向量的维度。

**计算方式**：分四步。

**① 生成Q、K、V**：用输入X分别乘以三个可学习的权重矩阵：

$$Q = X \cdot W^Q, \quad K = X \cdot W^K, \quad V = X \cdot W^V$$

其中 $W^Q \in \mathbb{R}^{d_{model} \times d_k}$，$W^K \in \mathbb{R}^{d_{model} \times d_k}$，$W^V \in \mathbb{R}^{d_{model} \times d_v}$。原始论文中 d_k = d_v = d_model / h = 64。

**② 计算注意力分数**：用Q和K的转置做矩阵乘法：

$$\text{scores} = Q \cdot K^T$$

这个矩阵的每个元素 `(i, j)` 表示第 `i` 个位置对第 `j` 个位置的关注程度。

**③ 缩放与Softmax**：除以缩放因子 $\sqrt{d_k}$，然后过Softmax：

$$A = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)$$

缩放的原因是：当 d_k 较大时，点积结果会很大，Softmax会进入饱和区，梯度变得极小。除以 $\sqrt{d_k}$ 可以把分数拉回到合理范围。

**④ 加权求和**：用注意力权重矩阵A乘以V：

$$\text{Attention}(Q, K, V) = A \cdot V$$

**编码器中自注意力的特点**：编码器的自注意力是**双向的、无掩码的**。每个位置都能看到序列中的所有位置，包括它后面的词。

### 3.2 多头注意力（Multi-Head Attention）

**输入**：与单头相同，即编码器上一层的输出X。

**输出**：形状 `(batch_size, seq_len, d_model)`。

**计算方式**：并行执行 **h = 8 个**独立的注意力头，每个头有自己独立的 $W_i^Q, W_i^K, W_i^V$：

$$\text{head}_i = \text{Attention}(XW_i^Q, XW_i^K, XW_i^V)$$

然后把所有头的输出**拼接**起来，再过一次线性变换 $W^O \in \mathbb{R}^{h \cdot d_v \times d_{model}}$：

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) \cdot W^O$$

**为什么要多头**：单头注意力只能学习一种“关注模式”。多头让模型能在不同的**表示子空间**中同时关注不同类型的关系——比如一个头关注语法依赖，另一个头关注语义相似性。


## 第四步：编码器层——残差连接 + 层归一化（Add & Norm）

**输入**：子层的输入 x（残差连接用）和子层的输出 Sublayer(x)。

**输出**：形状与输入相同，`(batch_size, seq_len, d_model)`。

**计算方式**：每个子层的输出都经过以下处理：

$$\text{output} = \text{LayerNorm}(x + \text{Sublayer}(x))$$

**残差连接**：把子层的原始输入x直接加到子层输出上。作用有两个：一是让梯度有一条“高速公路”直接回传到底层，缓解梯度消失；二是在最差情况下子层学废了，原始信息还能通过x保留下来。

**层归一化**：对每个样本的特征维度做归一化，公式为：

$$y = \frac{x - E[x]}{\sqrt{\text{Var}[x] + \epsilon}} \cdot \gamma + \beta$$

其中 $\gamma$ 和 $\beta$ 是可学习的缩放和平移参数。原始论文采用 **Post-Norm** 结构，即先做残差相加，再做层归一化。


## 第五步：编码器层——前馈神经网络（Feed-Forward Network）

这是编码器每一层的**第二个子层**。

**输入**：上一个Add & Norm的输出，形状 `(batch_size, seq_len, d_model)`。

**输出**：形状 `(batch_size, seq_len, d_model)`，与输入维度一致。

**计算方式**：两层全连接，中间夹ReLU激活：

$$\text{FFN}(x) = \max(0, x \cdot W_1 + b_1) \cdot W_2 + b_2$$

其中 $W_1 \in \mathbb{R}^{d_{model} \times d_{ff}}$，$W_2 \in \mathbb{R}^{d_{ff} \times d_{model}}$。原始论文中 **d_ff = 2048**，即中间层维度是 d_model 的 **4倍**。

**实现细节**：FFN对每个位置**独立**地做同样的变换，位置之间没有交互。先升维到2048，再降回512，目的是在更高维空间中捕捉复杂的特征组合。

FFN之后同样跟着残差连接和层归一化。

**编码器层完整流程**：

```
x → 多头自注意力 → Add & Norm → 前馈网络 → Add & Norm → 输出
```


## 第六步：解码器层——掩码多头自注意力（Masked Multi-Head Self-Attention）

这是解码器每一层的**第一个子层**，也是解码器区别于编码器的第一个关键部分。

**输入**：解码器上一层的输出（第一层为输出序列的词嵌入+位置编码），形状 `(batch_size, seq_len, d_model)`。

**输出**：形状 `(batch_size, seq_len, d_model)`。

**计算方式**：与编码器的自注意力**完全相同**，只多了一个**掩码（Mask）** 操作。在计算Softmax之前，把当前位置之后的所有位置的分数设为**负无穷**（实际实现中用一个大负数，如 -1e9）：

$$\text{MaskedAttention} = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + M\right) \cdot V$$

其中M是掩码矩阵，未来位置为负无穷，其余位置为0。Softmax之后，未来位置的权重变成0。

**为什么需要掩码**：解码器是**自回归生成**的——生成第 `t` 个词时，只能看到第 `1` 到 `t-1` 个词，不能偷看第 `t` 个及之后的词。如果训练时不加掩码，模型会学会“抄答案”，推理时就无法工作了。


## 第七步：解码器层——交叉注意力（Cross-Attention）

这是解码器每一层的**第二个子层**，也是解码器区别于编码器的第二个关键部分。

**输入**：两个来源——

- **Q来自解码器**：上一个子层（掩码自注意力）的输出，形状 `(batch_size, tgt_seq_len, d_model)`
- **K和V来自编码器**：编码器的最终输出，形状 `(batch_size, src_seq_len, d_model)`

**输出**：形状 `(batch_size, tgt_seq_len, d_model)`。

**计算方式**：与标准注意力机制完全相同，但Q、K、V的来源不同：

$$\text{CrossAttention}(Q_{dec}, K_{enc}, V_{enc}) = \text{softmax}\left(\frac{Q_{dec} \cdot K_{enc}^T}{\sqrt{d_k}}\right) \cdot V_{enc}$$

**作用**：让解码器在生成每个词时，都能“查询”编码器输出的输入序列，找到最相关的部分。比如中译英时，生成“love”这个词，交叉注意力会让模型在中文原文的“爱”字位置放上高权重。

交叉注意力之后同样跟着残差连接和层归一化。


## 第八步：解码器层——前馈网络

与编码器中的前馈网络**完全相同**：两层全连接，中间ReLU，d_ff = 2048，每个位置独立处理。后面跟残差连接和层归一化。

**解码器层完整流程**：

```
y → 掩码多头自注意力 → Add & Norm
  → 交叉注意力（Q来自上一步，K/V来自编码器）→ Add & Norm
  → 前馈网络 → Add & Norm → 输出
```


## 第九步：输出层——线性变换 + Softmax

**输入**：解码器最后一层的输出，形状 `(batch_size, tgt_seq_len, d_model)`。

**输出**：形状 `(batch_size, tgt_seq_len, vocab_size)` 的概率分布矩阵。

**计算方式**：

**① 线性变换**：把 d_model=512 维的向量投影到词表大小（vocab_size）的向量，得到logits：

$$\text{logits} = \text{output} \cdot W_{vocab}$$

**② Softmax**：把logits转换成概率分布，每个位置的所有词的概率之和为1：

$$\text{probabilities} = \text{softmax}(\text{logits})$$

**实现细节**：这个线性层的权重矩阵 $W_{vocab}$ 与输入端的词嵌入矩阵**共享权重**，这是原始论文的一个重要设计。


## 完整数据流总结

| 步骤 | 组件                   | 输入                       | 输出               | 核心计算                         |
| ---- | ---------------------- | -------------------------- | ------------------ | -------------------------------- |
| 1    | 词嵌入                 | token索引                  | (B, L, 512)        | 查找表                           |
| 2    | 位置编码               | (B, L, 512)                | (B, L, 512)        | 正弦余弦相加                     |
| 3    | 多头自注意力（编码器） | (B, L, 512)                | (B, L, 512)        | Softmax(QK^T/√d_k)V，8头拼接     |
| 4    | Add & Norm             | 子层输入+子层输出          | (B, L, 512)        | 残差+层归一化                    |
| 5    | 前馈网络               | (B, L, 512)                | (B, L, 512)        | ReLU(xW1+b1)W2+b2，d_ff=2048     |
| 6    | 掩码自注意力（解码器） | (B, L, 512)                | (B, L, 512)        | 同自注意力+掩码                  |
| 7    | 交叉注意力             | Q来自解码器，K/V来自编码器 | (B, L, 512)        | Softmax(Q_dec K_enc^T/√d_k)V_enc |
| 8    | 前馈网络（解码器）     | (B, L, 512)                | (B, L, 512)        | 同编码器FFN                      |
| 9    | 输出层                 | (B, L, 512)                | (B, L, vocab_size) | Softmax(线性变换)                |

编码器和解码器各重复 **N=6 层**。编码器的最终输出作为解码器交叉注意力层的K和V来源，解码器自回归地生成输出序列的每个token。

### 可能是 GQA 的笔误

考虑到“Gkv”与“GQA”在拼写上的相似性，以及GQA在当前大模型中的普及程度，这种可能性也很高。GQA是一种介于多头注意力（MHA）和多查询注意力（MQA）之间的折中方案，通过让**多个Query头共享一组Key/Value头**，来显著降低推理时的KV缓存内存占用-。它已成为许多现代开源模型（如LLaMA 2/3）的标配。

**混合专家模型 (MoE)**：将FFN层拆分为多个“专家”，通过路由网络仅激活部分专家处理每个Token，从而在扩大模型总参数量的同时，控制单次计算量-。训练时需采用**专家并行（EP）** 等策略将不同专家分布到不同GPU上

**归一化：RMSNorm**：用均方根归一化（RMSNorm）替代LayerNorm	

### 把变换器模型的前馈网络替换为 SwiGLU 后，计算过程是：

``` 
多了一个 up 投影和一个门控乘法
输入先归一化
然后同时做门控投影和上升投影
门控投影经过 S形线性激活
激活后的门控值与上升投影逐元素相乘
再经过下降投影回到原维度
最后与原始输入残差相加
```

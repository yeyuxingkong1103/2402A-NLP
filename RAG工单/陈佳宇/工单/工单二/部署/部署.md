# 部署文档
## 本地部署步骤
1. 安装Milvus v3.0，启动Milvus服务
2. 创建Python虚拟环境
```bash
python -m venv venv_gongdan1
source venv_gongdan1/bin/activate
安装项目依赖
pip install flask pymupdf transformers torch sentence-transformers pymilvus
进入研发目录，执行集合创建
python create_collection.py
启动项目服务
python main.py
6. 浏览器访问 [http://127.0.0.1:7860](http://127.0.0.1:7860)

## 服务说明

- Flask 开发服务，仅用于项目演示，生产环境需使用 Gunicorn+Nginx
- Milvus 需保持后台持续运行，否则向量检索功能失效
- WSL 环境可通过局域网 IP `172.17.189.52:7860` 访问页面

## 停止服务

1. Ctrl+C 停止 Flask 程序
2. 停止 Milvus 容器

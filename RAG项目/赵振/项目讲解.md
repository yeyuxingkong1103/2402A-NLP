# 项目怎么讲

一句话：**先把法律资料变成可检索的文本块，再用检索结果辅助大模型回答，并保存对话记忆。**

## 1. 数据入口

`data_config.py` 只有一个需要更换的 `DATA_PATH`。路径可以是一个文件或一个文件夹，程序会根据后缀选择读取方式。

## 2. 离线入库：`offline_ingest.py`

`load_file()` 读取原文，并记下文件名、页码或行号。接着用 LangChain 按 **500 字、重叠 50 字**切分，用 Ollama 的 **BGE-M3** 做向量，最后写入 **Milvus**。

## 3. 在线问答：`online_chat.py`

先从 **Redis** 取最近 3 轮对话，再向量化问题。用 **Milvus 向量检索 + BM25 关键词检索**找候选资料，让本地大模型选最相关的 3 段。把资料放进提示词模板生成回答。完成后，短期记忆写回 Redis，长期记忆写入 Milvus。

两个角色只改变提示词中的身份描述，检索和记忆流程共用。

## 4. 网页入口：`web_app.py`

网页通过 `/api/chat` 提问，通过 `/api/status` 查看服务状态，通过 `/api/document` 打开引用的原始资料。页面文件在 `static` 文件夹。

## 展示顺序

先展示 `DATA_PATH`，再展示 `offline_ingest.py` 的三段编号注释，然后用网页问一个刑法问题，点击引用查看原文。讲到记忆时，再展示 Redis 的 `chat:用户:角色:会话` 和 Milvus 的 `chat_memory`。

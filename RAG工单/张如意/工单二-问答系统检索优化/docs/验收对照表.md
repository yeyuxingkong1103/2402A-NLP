## 六、验收现场建议流程（10 分钟）

1. **看代码规范**（1 分钟）：打开 `src/common.py` 文件头与 `WO_ID` 常量，确认工单编号注释；
2. **跑分块对比**（2 分钟，不需要 Key）：`python src/optimize_chunking.py`，
   同屏展示 `results/chunking_comparison.md`，说明 structure 策略为何最优；
3. **看优化前后对比**（3 分钟）：打开 `results/before_after.md` 第三节，
   逐题展示「优化前答案 vs 优化后答案」，重点看 id 260 / 33 / 207 三题的数值完整度；
4. **现场演示系统**（3 分钟）：`python src/serve.py`，用对比模式跑 id 531（法定代表人）
   与 id 207（补充流动资金），展示两栏答案、来源页码与耗时；
5. **验稳定性与多语言**（1 分钟）：展示 `/api/health`、`/api/metrics`，
   再用英文提一个问题收尾。

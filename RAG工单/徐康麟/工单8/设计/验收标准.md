## 3. 真实评估结果（17 题，工单8 Graph RAG）

> 数据源：`测试/测试数据/GraphRAG评估汇总.json`（`run_eval.py` 实跑产出，逐题明细在 `GraphRAG评估结果.jsonl`）
> 判分：直接复用 工单7 `研发/评估/判分.py`（关键词阈值 0.6 / 部分正确 0.3 / 原子 0.6）

| 指标 | 工单7（冻结基线） | 工单8（Graph RAG） | 差值 |
| --- | --- | --- | --- |
| 严格准确率 | 23.53%（4/17） | **29.41%（5/17）** | **+5.88 个百分点** |
| 宽松判对（严格+部分） | 6/17 | **13/17** | +7 题 |
| 平均关键词覆盖率 | 0.2235 | **0.3997** | +0.1762 |
| 平均 recall@5 | 0.7319 | **0.7563** | +0.0244 |
| 平均 recall@10 | 0.7599 | **0.8025** | +0.0426 |
| 平均响应时间 | 1500.7 ms | 4080.4 ms | +2579.8 ms（根因见 B5/C7） |
| 图谱扩展增量（recall@5） | 基础检索 0.7297 | 图谱增强 0.7563 | **+0.0266** |

补充数字：页命中率 **88.24%**（15/17）；SLA（≤3000 ms）达标 **5/17（29.41%）**；
平均分段耗时 = 检索 128.2 ms + 图谱扩展 4.7 ms + 生成 3946.9 ms；
图谱独有块进入 Top-5 的题数 **0**（取舍与根因见 `测试/测试报告.md` §7.3）。

## 4. 未达标 / 未实现项（如实登记）

| # | 项 | 状态 | 根因 / 说明 |
| --- | --- | --- | --- |
| C1 | **eval_question.md 的原始 Question** | ⚠️ 替代口径 | 附件目录 `ccf_competition\` 内**不存在** eval_question.md（已实测列举确认）。改用 工单7 的 17 题测试集（同一批题、同一份语料、同一判分口径，天然满足「比对 07 工单」验收项）。详见 `需求分析.md` §3.5 |
| C2 | **语音输入** | ❌ 未实现 | 原文产出物提到「支持文字和语音输入」。本机缺 `onnxruntime` / `whisper` / `SpeechRecognition`，且按依赖红线不得裸 `pip install`；用户要求「实现最基础要求即可」⇒ 未做，界面只支持文字输入 |
| C3 | **演示视频** | ❌ 未实现 | 本机无录屏工具链；以 5 张真实数字截图 + 一键脚本替代 |
| C4 | **PDF 上传解析** | ⚠️ 设计取舍 | 复用 工单7 已解析产物（8847 块），界面不提供上传新 PDF（重新解析+嵌入需数分钟且会破坏与 工单7 的可比性）。9 份 PDF 已复制到 `研发/data/raw/` 作为语料存档 |
| C5 | **表格块纳入图谱** | ⚠️ 默认关闭 | 表格块以数字为主，正则抽取噪声大；可用 `--include-tables` 打开（配置化） |
| C6 | **金融研报生成** | ⚠️ 未实现 | 原文表述为「包括但不限于问题回答以及金融研报生成」，非验收项；问答链路已保留全部证据块，可在此基础上扩展 |
| C7 | **响应时间 SLA（≤3000 ms）** | ❌ 未达标 | 实测平均 4080.4 ms、达标 5/17（29.41%）。根因：耗时几乎全在 Ollama 生成（3946.9 ms），检索仅 128.2 ms、图谱扩展仅 4.7 ms —— 属 3B 模型在本机 CPU 推理的性能上限，非本工单新增链路导致 |
| C8 | **图谱独有块进入 Top-5** | ⚠️ 0 题 | 实测把图谱块占名额会挤掉答案块（Q07 的图谱独有块顶掉含 `137,958`/`183.12%` 的表格），故默认只追加不占名额；图谱扩展的增益体现在基础命中块的结构加权与跨语料过滤（recall@5 +0.0266） |

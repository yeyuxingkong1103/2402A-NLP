## 三、系统功能与操作流程

1. **启动界面**：`streamlit run app.py`，浏览器访问 `http://localhost:8501`；
   左侧显示知识库信息（块数 / 维度 / 模型 / 文档）与 5 个示例问题。
2. **多轮对话**：在底部输入框提问，系统逐轮返回答案，并在可展开面板中展示
   **多轮改写**、**命中文档**、**答案类型**、**响应耗时**与**检索证据**（源文件 + 页码 + 片段）。
3. **自动回放**：访问 `http://localhost:8501/?demo=1` 可自动回放 5 轮验收对话（用于录屏/截图）。
4. **中英文切换**：左侧语言开关切换中文 / English；英文模式下可勾选自动翻译答案。
5. **清空对话**：左侧「清空对话」按钮重置会话上下文。

## 四、关键演示点

- **指代消解**：Q2「他」、Q3「这个公司」自动替换为当前话题公司全名，无需用户重复公司名。
- **省略补全**：Q4「那 X 呢？」继承上一轮意图「法定代表人是谁」，并把主语切换为力源信息，
  同时通过**文档级路由**切换到《招股说明书2》，避免跨文档串味。
- **图形语义**：Q5 的答案来自对**矢量组织结构图**的还原（矩形节点框 + 连线 → 层级树），
  生成「大客户销售部由 6 个销售处构成：…」这类可检索文本。
- **零幻觉可溯源**：每条答案均附带原文证据（源文件 / 页码 / 片段），不做生成式改写。

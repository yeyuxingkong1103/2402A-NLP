## 2. 界面操作说明

启动界面：

```bash
streamlit run app.py
```

界面分三栏：

1. **左栏 · 检索策略面板**
   - 检索策略：向量 / 全文 / 混合；融合算法：加权 / RRF / 投票；重排算法：不重排 / TF-IDF / LLM / 自适应 / 线性 / **跨模态**；
   - 权重、Top-K、嵌入模型可调；
   - **跨模态优化四项开关**：视觉引用识别 / 图像增强召回 / 跨模态重排 / 视觉提示工程；
   - **「优化前基线」/「优化后」一键切换**按钮，用于对比演示。
2. **中栏 · 问答区**：多轮对话，展示答案、溯源证据、视觉引用识别结果（图号 / 页码 / 部件编号）。
3. **右栏 · 检索过程可视化**：Top-K 图文块（标注 `text`/`figure`、页码、图号、各通道分数）、
   命中的图 3 图形语义块，以及发送给 LLM 的 Prompt（含视觉增强前缀）。

## 3. 推荐演示脚本（对比叙事）

### 场景 A · 优化前基线（复现故障）

1. 点击「**优化前基线**」按钮 → 知识库切换为**仅文本块**（剔除图形块），检索退化为纯向量、无重排；
2. 提问 **Q3**「在文件中第 11 页图 3 中，编号 13 的部件相对于编号 12 的部件的位置关系是？」
3. 观察：Top-1 为**与图 3 无关的正文块**，系统答案答非所问（见 `05_图文题Q3_优化前基线.png`）。

### 场景 B · 优化后（修复效果）

1. 点击「**优化后**」按钮 → 恢复图形语义知识库 + 混合检索 + 跨模态重排；
2. 再次提问 **Q3**；
3. 观察：查询理解识别出「**第 11 页图 3**」（图号=3、页码=11、部件编号=[13,12]），
   Top-1 命中「**图 3 图形语义块**」，答案精确给出
   「**编号 13 的部件（链条）位于编号 12 的部件（保护管）之内。**」（见 `02_图文题Q3_优化后.png`）。

### 场景 C · 综合演示

依次提问 6 道题（2 纯文本 + 4 图文），展示：纯文本题稳定正确、图文题全部命中图 3。

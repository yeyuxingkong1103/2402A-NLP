## 通用动作（每张都一样，后面不再重复）

1. 鼠标**点一下**要拍的那个窗口，让它成为*活动窗口*（标题栏变高亮）
2. 按 **`Alt + PrtSc`** —— 只截这个窗口，自带标题栏边框
3. 打开「画图」→ **`Ctrl + V`**
4. **`Ctrl + S`** → 存成 PNG → 放进 `docs/演示截图/`，文件名照每步给的填

> ⚠️ **别用 `Win + PrtSc`**：整屏会把桌面文件夹名和浏览器其他标签一起拍进去。
> 存档目录已建好：`docs/演示截图/`（`.gitignore` 已白名单放行该目录的 PNG）。

## 开拍前（一次）

```bash
# 终端拉大字号：Ctrl + 滚轮；把窗口拉高
cd /mnt/c/Users/15277/Desktop/专高6工单
PY=~/rag-data/venv/bin/python
nohup $PY -m uvicorn app.main:app --host 0.0.0.0 --port 8080 > /tmp/uvicorn.log 2>&1 &
```
浏览器打开 `http://localhost:8080`。

## 2. 通用约定

### 2.1 请求头

```http
Authorization: Bearer <access_token>
Content-Type: application/json
X-Request-ID: <request_id>
```

上传文件时使用：

```http
Content-Type: multipart/form-data
```

### 2.2 通用响应

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "request_id": "req_202609140001"
}
```

### 2.3 通用错误响应

```json
{
  "code": 40001,
  "message": "角色不存在",
  "data": null,
  "request_id": "req_202609140002"
}
```

### 2.4 错误码

| 错误码 | 含义 |
| --- | --- |
| `40000` | 请求参数错误 |
| `40001` | 资源不存在 |
| `40002` | 文件格式不支持 |
| `40003` | 文件大小超限 |
| `40004` | 索引任务失败 |
| `40100` | 未认证、会话令牌无效或已过期 |
| `40300` | 无权限 |
| `40400` | 路径不存在 |
| `40900` | 资源冲突或重复操作 |
| `42900` | 请求频率超限 |
| `50000` | 系统内部错误 |
| `50001` | 模型服务不可用 |
| `50002` | 向量数据库不可用 |
| `50003` | 缓存或记忆服务不可用 |


### 3.5 重置密码

```http
POST /api/v1/auth/password-reset
```

### 3.6 认证与会话说明

```text
认证方式：服务端会话令牌（Redis）
  · 登录成功后签发随机会话令牌，服务端在 Redis 保存「令牌 → 用户身份与角色」的映射
  · 客户端在后续请求携带 Authorization: Bearer <token>  · 令牌默认有效期 2 小时（SESSION_TTL_SECONDS 可配置）
  · 注销、修改密码、管理员禁用用户时，服务端删除对应令牌 → 立即失效
  · 令牌本身不携带可解码的用户信息，也不依赖签名密钥
  · Redis 不可用时，受保护接口必须返回认证失败，不得放行
```

### 3.7 注销登录

```http
POST /api/v1/auth/logout
```

请求头：

```http
Authorization: Bearer <token>
```

**响应**

```json
{
  "code": 0,
  "message": "注销成功",
  "data": { "status": "logged_out" },
  "request_id": "req_006"
}
```

说明：服务端删除该会话令牌后立即失效；重复注销按幂等处理，仍返回 `message="注销成功"`。

登录、角色、知识库和会话接口的具体权限以普通用户与管理员两级权限模型为准。

### 3.8 查询当前登录用户

```http
GET /api/v1/users/me
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "user_id": "c954acb51a5b30491dbddd74afdf0f15",
    "email": "someone@example.com",
    "is_admin": false,
    "long_term_memory_enabled": true
  },
  "request_id": "req_007"
}
```

```text
用途：前端据此判断是否显示"审核"入口、以及记忆开关的初始状态。
权限：未登录返回 401（40100）；只返回当前登录用户自己的信息，不接受任何 user_id 参数。
约束：不得返回密码哈希、会话令牌等敏感字段。
```

### 5.2 上传文档

> ⚠️ **本节接口当前未实现**（二期规划）：代码中不存在该路由，首期的数据入库走离线 CLI（`python -m app.cli.import_mysql` + `index_legal_documents`）。以下定义保留为设计约定，实施时以此为准。


```http
POST /api/v1/knowledge-bases/{knowledge_base_id}/documents
```

使用 `multipart/form-data`：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `file` | file | 是 | PDF、图片、Markdown 或 TXT |
| `metadata` | JSON string | **是** | 法律元数据，结构见下表；缺失任一必填项返回 `40000` |
| `parser` | string | 否 | `auto`、`html`、`text`、`pdf` |

`metadata` 必须包含的法律元数据（法律文档缺一不可，否则无法做时效与法域过滤）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `law_name` | string | 法规名称，如《中华人民共和国劳动合同法》 |
| `document_type` | string | 文书类型：`law` / `administrative_regulation` / `judicial_interpretation` |
| `issuing_authority` | string | 发布机关 |
| `promulgation_date` | string | 公布日期（YYYY-MM-DD） |
| `effective_date` | string | **生效日期**（YYYY-MM-DD） |
| `repeal_date` | string \| null | **失效日期**，现行有效填 `null` |
| `jurisdiction` | string | 法域，首期固定 `中国大陆` |
| `source_url` | string | 官方来源地址，必须可访问 |
| `version_note` | string | 版本说明，如「2012 年修正」 |

**响应**

```json
{
  "code": 0,
  "message": "accepted",
  "data": {
    "document_id": "doc_001",
    "content_hash": "sha256:...",
    "index_job_id": "job_001",
    "status": "pending"
  },
  "request_id": "req_003"
}
```


### 7.4 SSE 流式响应

```http
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
```

事件示例：

```text
event: message_start
data: {"message_id":"message_001"}

event: token
data: {"text":"建议"}

event: token
data: {"text":"建议先核对解除原因、事实发生时间和相关材料"}

event: citation
data: {"chunk_id":"chunk_001","law_name":"中华人民共和国劳动合同法","article_number":"第四十条","paragraph_number":null,"page":12}

event: message_end
data: {"finish_reason":"stop","usage":{"prompt_tokens":1200,"completion_tokens":180}}
```

异常事件：

```text
event: error
data: {"code":50001,"message":"模型服务暂时不可用","retryable":true}
```

### 7.5 会话列表

```http
GET /api/v1/sessions?page=1&page_size=20
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "session_id": "sess_8f3c1a2b",
        "character_id": "legal-assistant",
        "title": "公司解除劳动合同需要提前多久通知",
        "message_count": 4,

        "updated_at": "2026-09-18T10:41:20Z"
```

```text
排序：updated_at 倒序（最近活跃的在前）
范围：只返回当前登录用户自己的会话
分页：`page` / `page_size` 仅用于限制返回条数，**响应不返回 total / page / page_size**，
      前端按 `data.items` 长度自行判断是否还有下一页
```

## 11. 接口安全要求

- 除登录接口外，所有接口必须携带有效 Token。
- 角色、会话、知识库和记忆接口必须校验资源归属。
- 接口不能接受客户端直接传入未经验证的权限过滤条件。
- `request_id` 必须贯穿日志、检索和模型调用。
- 错误响应不得返回 SQL、堆栈、文件路径和密钥。
- 上传接口必须限制大小、类型、并发任务和文件名。

## 第 2 段（1:30-3:30）语义检索用的技术（工单必讲点 1）

**操作**：

```bash
python 工单06-混合检索/src/vector_search.py
```

**屏幕要点与口播**（对照 `docs/技术文档.md` 第 1 章）：

1. **嵌入技术**：「语义检索用 BGE 中文嵌入模型（bge-large-zh-v1.5，1024 维）
   把文档块和用户问题都编码成向量；查询侧会加 BGE 官方要求的检索指令前缀，
   向量再做 L2 归一化。」
2. **相似度**：「归一化后，余弦相似度就是向量点积，分数越高越相似。」
   ```
   cos(q,d) = q·d / (|q||d|)  --L2归一化-->  q̂·d̂
   ```
3. **近邻索引**：「向量库用 ChromaDB 的 HNSW 近似最近邻索引，
   通过多层可导航小世界图把检索复杂度从 O(N) 降到近似 O(log N)。」
4. **多模型对比**：脚本自动跑 bge-large-zh-v1.5 与 m3e-base 两套索引，
   屏幕展示同一问题的 Top-5 召回、两模型重合度与耗时。
5. **召回+重排**：「先召回 Top-20 保证不漏，再用重排器精排 Top-5 保证排序准。」
   脚本随后对比 none / tfidf / llm / adaptive 四档重排的输出差异。

**验收提示**：本段即证明工单「支持多种嵌入模型」与「至少 3 种重排算法」。

## 第 3 段（3:30-5:30）全文检索用的技术（工单必讲点 2）

**操作**：

```bash
python 工单06-混合检索/src/fulltext_search.py
```

**屏幕要点与口播**（对照 `docs/技术文档.md` 第 2 章）：

1. **倒排索引**：「全文检索用的是自研倒排索引 `term → {文档: 加权词频}`，
   查询时只扫 query 词条对应的倒排列表，不扫全库。」
2. **BM25 打分**：「排序用 Okapi BM25 公式，k1=1.5 控制词频饱和，
   b=0.75 做长度归一化；IDF 让稀有词（如公司名）权重更高。」
   ```
   score = Σ IDF(t) · f(t,d)(k1+1) / ( f(t,d) + k1(1-b+b·|d|/avgdl) )
   f(t,d) = 1.0×tf_正文 + 1.6×tf_章节路径
   ```
3. **布尔查询**：现场演示 `boolean="AND"`（军用 且 收入）、
   `OR`（军用 或 民用）、`NOT`（含收入但不含政府补助）。
4. **短语匹配**：演示精确子串 `视频指挥系统技术标准`、`5,520`、`42.35%`——
   「专有名词和精确数字用短语匹配最可靠，绕开分词误差。」
5. **模糊匹配**：演示通配符 `军用*` 与编辑距离容错（形近字/错别字）。
6. **多字段消融**：对比「仅正文 1.0」与「正文 1.0 + 章节 1.6」的排名变化，
   展示标题字段带来的提升。

## 第 4 段（5:30-8:30）混合检索与融合算法

**操作**：

```bash
python 工单06-混合检索/src/hybrid_search.py
```

**屏幕要点与口播**：

1. 双通道同时检索：向量 Top-20 + BM25 Top-20，展示通道重合度
   （「两路各召回了对方没有的片段，这就是融合的收益来源」）；
2. 三种融合算法同题对比：
   - `weighted`：归一化后加权平均，`score = α·向量 + (1-α)·BM25`；
   - `rrf`：`score = Σ 1/(60+rank)`，只看名次，天然免疫量纲差异；
   - `vote`：双通道都命中记 2 票，共识片段优先；
3. **权重扫描**：α 从 0.0（纯全文）到 1.0（纯向量）逐个取值，
   屏幕表格展示 Top-3 与「关键信息点最全片段」的名次变化；
4. 指出关键片段在融合后排名上升，解释「结合两者优势」的具体机制。

## 第 7 段（12:30-13:30）性能与收尾

**屏幕要点**：
- `return_trace=true` 返回的每阶段耗时（向量召回/BM25/融合/重排）；
- 说明：tfidf/adaptive 档检索总耗时 <100ms，cascade 档 0.5~2s，
  均在工单「≤3 秒」目标内；LLM 全量重排 Top-20 有超时风险，故采用级联；
- 资源：Chroma 持久化 + HNSW，`/api/metrics` 提供运行指标。

**结束口播**：「总结：语义检索用 BGE 向量嵌入 + 余弦相似度 + HNSW，
擅长同义改写；全文检索用倒排索引 + Okapi BM25 + 多字段加权，
擅长精确关键词与数字；混合检索用双通道 + 加权/RRF/投票融合，
再叠加 LLM/TF-IDF/自适应重排，最终达成准确率 90%、召回率 95% 的目标。」

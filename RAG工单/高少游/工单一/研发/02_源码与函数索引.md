## 2. 函数索引

### 2.1 src/config.py
| 成员 | 类型 | 作用 |
|---|---|---|
| `BASE_DIR / DATA_DIR / DB_DIR / OUTPUT_DIR` | Path | 目录路径 |
| `PDF_PATH / QUESTIONS_PATH` | Path | 数据文件 |
| `LLM_MODEL / EMBEDDING_MODEL` | str | Ollama 模型 |
| `CHUNK_SIZE / CHUNK_OVERLAP` | int | 切片参数 |
| `TOP_K / BM25_TOP_K / RANK_FUSION_K` | int | 检索参数 |
| `TARGET_RESPONSE_SECONDS` | float | 达标阈值(3.0) |
| `ensure_dirs()` | 函数 | 建目录 |

### 2.2 src/pdf_parser.py
| 成员 | 作用 |
|---|---|
| `class PageDoc` | 单页文档（page_no/text/tables/content） |
| `parse_pdf(path) -> List[PageDoc]` | 逐页解析，返回全部页面 |
| `_render_table(tab)` | 表格转 Markdown 文本 |

### 2.3 src/knowledge_base.py
| 成员 | 作用 |
|---|---|
| `_BatchedEmbeddings` | 分批嵌入（每批50）的向量模型 |
| `build_documents() -> List[Document]` | 切分全文档为带页码块 |
| `get_all_documents() -> List[Document]` | 取全部文档块（供BM25） |
| `get_embeddings()` | 向量模型实例 |
| `build_kb(force_rebuild)` | 构建向量库 |
| `load_kb()` | 加载持久化向量库 |
| `clear_kb()` | 清空向量库 |
| `kb_stats()` | 切片统计 |
| `_kv_file(dir)` | 向量库判据文件 |

### 2.4 src/query_understanding.py
| 成员 | 作用 |
|---|---|
| `class QueryAnalysis` | 理解结果（intent/entities/disambiguated_query/sub_questions） |
| `QueryAnalysis.retrieval_queries` | 候选查询列表（主+子问题） |
| `QueryUnderstanding.analyze(q)` | 核心入口，LLM 结构化理解 |
| `_parse_json(text)` | 健壮解析 LLM 输出的 JSON |

### 2.5 src/retriever.py
| 成员 | 作用 |
|---|---|
| `class HybridRetriever` | 混合检索器 |
| `_vector_retrieve(q)` | 向量召回 Top-K |
| `_tokenize(text)` | jieba 分词 |
| `_bm25_retrieve(q)` | BM25 词法召回 Top-K |
| `_rrf(ranked)` | 倒数排名融合 |
| `retrieve(q)` | 综合检索入口 |
| `format_contexts(docs)` | 上下文格式化 |

### 2.6 src/qa_engine.py
| 成员 | 作用 |
|---|---|
| `class AnswerResult` | 回答结果（answer/mode/elapsed/sources/analysis） |
| `class QAEngine` | 问答引擎 |
| `answer_rag(q)` | RAG 回答 |
| `answer_llm_only(q)` | 纯 LLM 基线回答 |
| `_retrieve_unique(q)` | 多路检索+去重 |
| `_invoke(prompt)` | 统一调用 LLM |

### 2.7 app.py（Streamlit）
| 元素 | 作用 |
|---|---|
| `get_engine()` | 缓存加载问答引擎，首次自动建库 |
| `transcribe_audio(file)` | 语音转文字（whisper，可选） |
| `save_feedback(...)` | 反馈写入 feedback.csv |
| 侧边栏 | 模式切换、Top-K、重新建库、下载反馈 |
| 主区 | 提问框、语音提问、回答+依据展示、👍/👎 |

## 3. 脚本命令速查

| 脚本 | 参数 | 作用 |
|---|---|---|
| `scripts/build_kb.py` | `--rebuild` | 构建（重建）向量库 |
| `scripts/run_qa.py` | `--question "..."` `--llm-only` | 命令行单条问答 |
| `scripts/evaluate.py` | `--top-k N` `--in-memory` `--skip-ragas` | 10 题评估对比 |
| `scripts/build_report.py` | 无 | 生成评估报告 md |
| `scripts/ragas_score.py` | 无 | 输出 RAGAS 指标 |

## 4. 环境要求

- Python 3.10
- langchain / langchain-ollama / langchain-community / faiss-cpu / pymupdf / streamlit / jieba / ragas / openai
- Ollama（已装模型：`bge-m3:567m` 向量、`deepseek-r1:1.5b` 生成）

# 设计：实现文档质量评估Skill并集成至智能体工作流

## 需求与范围
实现DocumentQualityAssessmentSkill，包含格式统计、PDF分类、长度、MD5/SimHash、敏感信息；API和智能体工作流集成；对1700份文档验证，分类抽样目标85%以上。

## 资料与隔离
数据隔离：本工单内有完整1700份PDF、10096题、RAGFlow0.23.1源码快照，运行不从其他工单读取数据。共享的是电脑已有Python/Ollama程序，不在主目录存放公共语料或公共索引。所有截图、模型、缓存、临时预览都在本工单内部。

## 系统架构
独立Skill -> 配置读取 -> 逐文件MD5/SHA256 -> 全页字符数与扫描页比例 -> 标签/分流 -> 文本长度与分位数 -> 精确及近重复 -> 敏感信息待审 -> JSON/HTML报告。按文件内容+配置+文件名缓存，进度每50份保存，可中断续跑。

## 验收口径
Scan_PDF阈值是低字符页占比>70%；Text_PDF允许少数附图页；其余Mixed。人工查看9份分层样本全页，9/9符合本项目分流定义，但不能推断全库准确率100%。近重复只提示人工确认，不自动删除；手机号/邮箱/有效身份证检测，银行卡默认关闭。
正式RAGFlow栈、源码补丁、独立扩展服务分别记录，不因有演示页面就认定正式栈验收通过。

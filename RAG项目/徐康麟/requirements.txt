# --- 系统层指标：进程/主机采集的**主路径**（2026-09-29 提为主依赖）---
# 背景：`legal_rag/system_metrics.py` 原先自己手写三套平台实现（Linux /proc、
# Windows win32/FILETIME），并把 psutil 当作"缺字段时的兜底"。实测两个问题：
#   ① 口径不一致：`cpu_seconds` 受 Windows 100ms 时间片限制（与 psutil 差 83%）、
#      `swap.total_bytes` 在 Windows 上是 PageFile 口径（与 psutil 差 33%）；
#   ② 三套实现要同时维护，且平台分支在非目标平台上根本不可达。
# 现改为 **psutil 优先、不可用时才回落纯标准库**（回落路径保留，因此本依赖是
# "主路径"而非"硬性必需"；但装上它才能拿到完整且口径统一的读数）。
# 纯 Python 轮子、体积小（约 1 MB）、跨平台。
psutil>=5.9

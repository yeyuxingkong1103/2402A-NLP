# 部署说明（Linux）

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Linux（Ubuntu 20.04+ / CentOS 7+） |
| Python | 3.11（通过 conda 管理） |
| CUDA | 可选（默认 CPU 推理） |
| Docker | 20.10+（运行 Milvus） |
| 内存 | ≥ 8 GB |
| 磁盘 | ≥ 10 GB（含模型权重） |

## 二、部署步骤

### 1. 安装 conda（如未安装）

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -p $HOME/miniconda3
source ~/.bashrc
```

### 2. 安装 Milvus（Docker）

```bash
docker run -d --name milvus-standalone \
  -p 19530:19530 -p 9091:9091 \
  milvusdb/milvus:v2.4.0 \
  milvus run standalone
```

### 3. 运行安装脚本

```bash
bash deploy/install.sh
```

### 4. 配置环境变量

```bash
export deepseek_api_key1=你的DeepSeek密钥
export deepseek_base_url=https://api.deepseek.com/v1
```

### 5. 准备本地模型

下载 bge-m3 与 bge-reranker-large 到本地，修改 `src/config.py` 中路径。

### 6. 入库 PDF 文档

```bash
conda activate rag_pdf_qa
cp 招股说明书1.pdf src/data/
python src/ingest_pdf.py
```

### 7. 启动 / 停止服务

```bash
bash deploy/start.sh   # 启动
bash deploy/stop.sh    # 停止
```

## 三、验证

```bash
curl http://localhost:8000/api/health
```

# 工单15 启动说明

```

├── ragflow/docker/   ← RAGFlow 部署配置（compose / .env / nginx / service_conf 模板）
├── patches/          ← 本次改动的代码，通过挂载覆盖进容器
└── conf/             ← 跨模态检索的外部配置 visual_rag.json
```

`研发/ragflow/` 下只保留 `docker/`：RAGFlow 的 Python 源码在容器镜像里，
运行时用不到本地源码副本。要读源码去附件
`D:\BW\RAG 工单\14-17附件\ragflow-main\`（与镜像版本略有差异，见
`优化/过程问题记录.md`）。

## 起 RAGFlow

> `.env` 里有本机密钥，**不在版本库里**，所以克隆下来是没有的。
> 先补一份，否则 compose 读不到 `env_file` 会直接报错。

```bash
cd 研发/ragflow/docker
cp .env.example .env                     # 密钥是空的；要调大模型就填 DEEPSEEK_API_KEY
docker compose up -d ragflow-cpu        # 注意要带服务名，见下
```

> **必须带服务名**。不带的话 compose 会去准备 `docker-compose-base.yml` 里
> 声明但本项目用不到的服务（minio / opensearch / infinity 等），
> 拉镜像会 401 失败。

`docker-compose.yml` 里 `ragflow-cpu.volumes` 有 **6 行工单专有挂载**
（搜索「工单」注释即可定位）：

| 挂载 | 来源 | 作用 |
|---|---|---|
| `rag/llm/chat_model.py` | 工单14 | 关 deepseek 思维链；工单15 改为外部可配 |
| `rag/prompts/vision_llm_figure_describe_prompt.md` | 工单14 | 图纸描述提示词（补空间次序） |
| `deepdoc/parser/figure_parser.py` | **工单15** | 给图纸块打「图号+页码」标记 |
| `rag/nlp/search.py` | **工单15** | 检索时调用视觉条件加权融合 |
| `rag/nlp/visual_query.py` | **工单15** | 查询理解 + 加权融合（新增文件） |
| `conf/visual_rag.json` | **工单15** | 融合权重与开关（外部配置） |

> **为什么用挂载而不是改镜像**：附件源码比镜像里的代码新，直接挂附件源码
> 容器起不来。`patches/` 下的文件是从**镜像里 `docker cp` 出来**再改的。
> 跑起来后改这些文件：改 Python 代码要 `--force-recreate` 重建容器
> （已加载的模块不会重载），改 `visual_rag.json` 只需重启。

容器起来后：

```bash
curl -o /dev/null -w "%{http_code}\n" http://localhost/v1/system/version   # 期望 200
```

## 跨模态检索的外部配置

`研发/conf/visual_rag.json`（挂到容器 `/ragflow/conf/visual_rag.json`）：

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总开关 |
| `figure_boost` | 0.5 | 问题提到「图N」且块上有对应标记时的加分 |
| `page_boost` | 0.2 | 问题提到「第P页」且块标记含该页时的额外加分 |
| `marker` | `【技术图纸】` | 标记前缀，需与 `figure_parser.py` 保持一致 |

也可用环境变量覆盖（写在 `研发/ragflow/docker/.env`）：
`VISUAL_RAG_FIGURE_BOOST=0.8` 这样，键名大写加前缀。

模型侧另有两个（同样在 `.env`）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `RAGFLOW_REASONING_EFFORT` | `none` | deepseek 思维链档位：`none` / `low` / `high` / `max` |
| `RAGFLOW_MAX_TOKENS` | `8192` | 思维链与正文共用的额度下限（RAGFlow 默认只给 512） |

> 工单14 为压到 ≤3s 一律关思维链；工单15 的预算是 3-5s，图文题需要模型在
> 「图纸描述」和「正文」之间做对照，取 `low` 实测 6/6。设回 `none` 会掉到 5/6。

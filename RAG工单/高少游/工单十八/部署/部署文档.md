# 文档质量评估 Skill 部署文档

工单编号：人工智能NLP-RAG-实现文档质量评估Skill并集成至智能体工作流

## 1. 部署形态

本 Skill 支持三种部署形态，按使用场景选择。

| 形态 | 适用场景 | 入口 |
|---|---|---|
| 命令行 | 大数据集批处理、离线质检 | `run_assessment.py` |
| Python 库 | 嵌入既有 RAG 管线 | `src.skill.DocumentQualityAssessmentSkill` |
| API 服务 | 供 RAGFlow 或其它服务远程调用 | `app.py`（FastAPI + uvicorn） |

三种形态共用同一套实现与同一份配置，行为一致。

## 2. 环境要求

- 操作系统：Windows 10/11、Linux、macOS 均可（开发与验证在 Windows 11 完成）。
- Python：3.10 及以上。验证环境为 CPython 3.10.11。
- 内存：处理 PDF 时单 worker 约占用 100–200 MB；1700 份规模建议 4 GB 以上。
- 磁盘：输出报告与断点文件体积约为输入数据集的 1% 量级。

依赖清单见 `requirements.txt`，核心依赖如下。

| 依赖 | 用途 |
|---|---|
| `pymupdf` | PDF 解析、逐页字符统计与图片覆盖面积计算 |
| `python-docx` / `python-pptx` / `openpyxl` | Office 文档文本抽取 |
| `jieba` | 中文分词，供 SimHash 生成特征 |
| `PyYAML` | 读取 `assessment_config.yaml` |
| `fastapi` / `uvicorn` / `pydantic` | 质检 API 服务 |
| `pytest` / `httpx` | 单元测试与 TestClient |
| `matplotlib` / `Pillow` / `opencv-python` | 流程图、截图与演示视频生成（仅产出物需要） |

## 5. 配置

全部可调阈值位于 `assessment_config.yaml`，无需改动代码。常用配置项如下，完整说明见 `document_quality_assessment/references/config_reference.md`。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `scan.workers` | 10 | 并行 worker 数（实际取配置值与 CPU 核数的较小者） |
| `scan.include_ext` | 见文件 | 纳入扫描的扩展名白名单 |
| `scan.max_files` | 0 | 限制处理文件数，0 表示不限制 |
| `pdf.text_char_threshold` | 30 | 单页字符数低于该值判为扫描页 |
| `pdf.scanned_page_ratio` | 0.70 | 扫描页占比高于该值判为扫描型 |
| `pdf.text_page_ratio` | 0.10 | 扫描页占比低于该值判为文字型 |
| `pdf.confirm_band` | [0.10, 0.70] | 落在此区间进入待确认列表 |
| `pdf.min_pages_for_strict` | 3 | 页数少于该值一律待确认 |
| `pdf.image_area_ratio` | 0.60 | 图片覆盖页判定的面积阈值 |
| `dedup.simhash_hamming_threshold` | 8 | 汉明距离不超过该值判为近似重复 |
| `dedup.shingle_size` | 4 | SimHash 分片长度 |
| `dedup.min_chars_for_simhash` | 200 | 短于该长度不计算 SimHash |
| `sensitive.context_chars` | 40 | 命中上下文保留字符数 |
| `sensitive.max_hits_per_doc` | 20 | 单文件命中数上限 |
| `sensitive.mask` | true | 命中值是否脱敏 |
| `classification.routing` | 见文件 | 标签到解析器的映射 |
| `report.top_n_lists` | 200 | 报告列表截断条数，0 表示不截断 |
| `checkpoint.flush_every` | 50 | 断点落盘频率 |

运行期覆盖示例：

```bash
# 命令行：指定 worker 数并只处理前 100 个文件
python run_assessment.py --root <数据集目录> --out output/run --workers 8 --sample 100
```

## 6. 运行

### 6.1 命令行

```bash
# 全量运行
python run_assessment.py --root <数据集目录> --out output/run --workers 8

# 忽略断点全量重跑
python run_assessment.py --root <数据集目录> --out output/run --no-resume

# 抽样试跑
python run_assessment.py --root <数据集目录> --out output/run --sample 100
```

运行结束后打印关键指标，并在 `--out` 目录生成 `quality_report.json` 与 `quality_report.html`。

### 6.2 Python 库

```python
from src.skill import DocumentQualityAssessmentSkill

skill = DocumentQualityAssessmentSkill(
    overrides={"pdf": {"scanned_page_ratio": 0.8}, "scan": {"workers": 4}}
)
report = skill.run("<数据集目录>", out_dir="output/run", resume=True,
                   progress=lambda done, total, rel: print(f"{done}/{total}"))
print(report["pdf_classification"]["scanned"])
```

## 7. 集成到 RAGFlow

集成分三步，详细说明见研发目录下的 `RAGFLOW_INTEGRATION.md`。

第一步，注册 Skill。把 `document_quality_assessment/` 整体放入 RAGFlow 的 Skill 目录，框架读取 `SKILL.md` 的 frontmatter 完成注册；也可通过 `src/skill_registry.py` 以编程方式注册。

第二步，导入工作流。把 `src/workflow.py` 中的 `WORKFLOW_DSL` 序列化为 JSON 导入 RAGFlow Agent，节点与边已按 RAGFlow DSL 字段对齐，无需转换。

第三步，挂载 API。在 RAGFlow 的 API 服务中执行：

```python
from src.api_router import router as quality_router
app.include_router(quality_router)
```

## 8. 数据集准备

Skill 接受文件夹路径，自动按扩展名白名单递归收集文件。以本工单验证数据集为例：

```
<数据集目录>/
└── original_problems/documents/*.pdf     # 1700 份专利 PDF
```

若需自定义扩展名范围，修改 `scan.include_ext`。隐藏文件默认跳过，符号链接默认不跟随。

## 9. 断点续跑

运行目录下会生成 `.qcheck/records.jsonl`，每行一个已完成文件的记录。中断后重新运行同一命令即可从断点继续：

```bash
python run_assessment.py --root <数据集目录> --out output/run
```

跳过逻辑按相对路径匹配，因此数据集内新增文件会被处理、已处理文件被跳过。如需忽略断点全量重跑，加 `--no-resume`，此时 `.qcheck` 会被重置。

## 10. 常见问题

运行报 `ModuleNotFoundError: pymupdf`。依赖未安装或虚拟环境未激活，重新执行 `pip install -r requirements.txt`。

PDF 全部被判为扫描型。检查 `pdf.text_char_threshold` 是否过大。若数据集为低质量文字型 PDF，逐页字符数可能普遍偏低，需要下调该阈值。

近似重复命中过多。下调 `dedup.simhash_hamming_threshold`（距离越小越严格），或提高 `dedup.min_chars_for_simhash` 让短文档不参与近似比对。

敏感信息误报多。确认 `sensitive.bank_card` 是否为 false；必要时在 `sensitive.patterns` 中收紧正则。

API 返回 404。`folder_path` 不存在，或路径使用了宿主不可见的位置。确认服务进程对目标目录有读权限。

`/v1/document/quality-inspection/{run_id}` 返回 404。`run_id` 仅在同一进程生命周期内有效，重启服务后历史报告会失效，持久化需接入数据库。

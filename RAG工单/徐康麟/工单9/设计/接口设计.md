## 1. Python 编程接口

### 1.1 配置

```python
from app.graphrag_opt.配置 import OptConfig, get_config, ensure_dirs, write_default_config_file

cfg: OptConfig = get_config()          # 读取 部署/配置/优化配置.json + 环境变量覆盖
ensure_dirs(cfg)                       # 创建本工单输出目录（不碰 工单7/8）
write_default_config_file(cfg)         # 生成可编辑的配置模板
cfg.fingerprint()                      # 配置指纹（进报告，保证数字可追溯）
cfg.dump()                             # 落盘「生效的」配置快照
```

**覆盖优先级**：`DEFAULTS`（代码） < `部署/配置/优化配置.json` < 环境变量 `GRAPHRAGOPT_<段>__<键>`。
未识别的键记入 `cfg.unknown_keys` 并写 WARNING（不静默忽略）。

## 2. HTTP 接口（Web UI，端口 8125）

服务：`研发/app/ui/serve_fallback.py`（标准库 `http.server`，**不引入新依赖**）

| 方法 | 路径 | 请求 | 响应 |
| --- | --- | --- | --- |
| `GET` | `/` | — | HTML 页面（问题输入 / 上下文 / 答案 / 引用 / 图谱三元组） |
| `GET` | `/healthz` | — | `{"status":"ok\|degraded","checks":{...}}` |
| `POST` | `/api/ask` | `{"question":"…","top_k":10,"language":"auto","use_llm":true}` | 见下 |
| `GET` | `/api/stats` | — | 图谱规模、配置指纹、端口、生成方式分布 |

### `POST /api/ask` 响应结构

```json
{
  "ok": true,
  "question": "平安银行2019年营业收入和净利润分别是多少？",
  "answer": "【结论】…【关键数据】…【图谱依据】…【引用】[块1] 平安银行 第19页",
  "language": "zh",
  "refused": false,
  "generation_method": "grounded_template",
  "latency_ms": {"total": 158.9, "retrieve": 155.2, "graph": 1.1, "generate": 0.0},
  "contexts": [
    {"rank": 1, "chunk_id": "20200214-p19-t1-0", "page": 19, "file_name": "…平安银行…pdf",
     "type": "table", "retrieval_channel": "base", "score": 1.0,
     "text": "营业收入 | 137,958 | 116,716 | 105,786 | 18.2%"}
  ],
  "citations": [{"chunk_id": "20200214-p19-t1-0", "page": 19, "company": "平安银行"}],
  "triples": [{"head": "平安银行", "relation": "披露", "tail": "营业收入", "confidence": 0.92,
               "chunk_id": "20200214-p19-t1-0"}],
  "graph": {"seed_names": ["平安银行"], "nodes": [...], "edges": [...]},
  "diagnostics": {"corpus_hint": "20200214", "hop": 1, "field_probe_fields": [...],
                  "fusion_weights": {"base": 0.62, "graph": 0.23, "feature": 0.15}}
}
```

**错误响应**（始终返回结构化 JSON，**不 500 裸崩**）：

```json
{"ok": false, "error": "问题不能为空", "answer": "请输入一个具体的问题（中文或英文）。", "refused": true}
```

| 场景 | `ok` | 说明 |
| --- | --- | --- |
| 空 / 纯空白 question | false | 提示输入具体问题 |
| question 超长（> `max_question_chars`） | true | 自动截断并记 `truncated: true` |
| 非法字符 / 控制字符 | true | 清洗后正常检索 |
| Ollama 不可达 | true | `generation_method` 变为 `grounded_template` / `draft_fallback` |
| 索引缺失 | false | `error` 给出明确原因；页面显示降级提示 |
| 证据不足 | true | `refused: true` + 标准拒答文案 |

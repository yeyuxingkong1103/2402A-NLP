## 二、核心结论（真实运行）

| 指标 | 实测 | 验收目标 | 结论 |
|---|---|---|---|
| 准确率 | **90.0%**（9/10） | ≥ 90% | ✅ |
| 召回率（问题级） | **90.0%**（9/10） | ≥ 95% | ⚠ 差 5pt |
| 块级召回 | 58.5% | — | 参考 |
| 平均响应时间 | **0.094 s** | ≤ 3 s | ✅ |
| P95 响应时间 | 0.111 s | ≤ 3 s | ✅ |
| 文档路由准确率 | **100%**（10/10） | — | ✅ |
| 功能/容错/稳定性测试 | **10/10 通过** | 全部通过 | ✅ |

**最优检索配置**：`hybrid（混合检索）+ linear（多信号线性融合重排）+ rrf（倒数排名融合）`

**主要缺陷**：枚举型（list）问题准确率 50%，根因是"董事长致辞开篇套话块被误选为答案锚点"，
详见《测试报告》第六章与《优化报告》第四章（含已回退方案的记录）。

## 四、如何复现

见《部署文档》。最短路径：

```powershell
cd 交付/工单代码/工单七/研发
pip install -r requirements.txt
ollama serve                                          # 另开终端
python build_kb.py --rebuild --models bge-m3,bge-large,nomic-embed
python evaluate_ccf.py --strategies vector,fulltext,hybrid --rerankers none,tfidf,linear
python run_demo.py
python tools/run_functional_tests.py
python tools/bench_latency.py --strategies vector,fulltext,hybrid
python tools/gen_flowcharts.py && python tools/render_ui_shots.py && python tools/render_terminal_shots.py
python tools/make_demo_video.py --shots output/figures,output/shots_tech,output/shots,output/shots_run --out output/演示视频.mp4
```

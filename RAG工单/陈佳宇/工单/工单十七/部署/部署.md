```bash
git clone https://github.com/infiniflow/ragflow.git

服务组件：API‑Server、Task‑Executor、Redis、向量数据库、MySQL。

##2. 实训部署步骤

1. WSL 激活 venv_gongdan5，安装 py‑spy memory‑profiler objgraph prometheus‑client；
2. 工单 17 研发目录，拿到全部优化代码；
3. 将单例、连接池、prometheus 埋点补丁集成进 RAGFlow 源码；
4. 重启 docker compose 所有服务；
5. 基线：JMeter 运行场景 A、场景 B，记录基线性能数据；
6. 使用 py‑spy、memory‑profiler 定位热点与泄漏；
7. 应用优化补丁后，再次压测；
8. 执行 12 小时长期稳定性测试，观察 RSS 内存增长。

##3. 监控运维命令

#4. 故障排查

1. 并发响应慢：py‑spy 看 CPU 热点；确认大模型是否每次请求重复实例化；确认重任务是否异步投递 Redis 队列。
2. 内存持续上涨：memory‑profiler/objgraph 看留存对象；确认大对象是否释放；确认连接池是否归还连接。
3. 连接耗尽：检查连接池大小，检查所有分支是否归还连接。

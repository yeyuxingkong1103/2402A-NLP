# 部署与启动指南

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统
> 面向部署，说明环境准备、依赖安装、Ollama 模型配置、系统启动与常见问题。

---

## 1. 部署架构

```
用户浏览器 ──▶ Streamlit(app.py, :8501)
                  │  调用
                  ▼
              QAEngine(src/qa_engine.py)
                  │  检索     │  生成
                  ▼          ▼
      FAISS + BM25 (retriever)   Ollama(deepseek-r1)
      vector_db                     ▲
      (bge-m3 向量)                 └─ 本地推理 127.0.0.1:11434
```

## 2. 前置条件清单

| 依赖 | 版本/说明 |
|---|---|
| Python | 3.10 |
| Conda | 环境名 `langchain2` |
| Ollama | 本地服务，端口 11434 |
| 向量模型 | `bge-m3:567m` |
| 生成模型 | `deepseek-r1:1.5b` |
| 操作系统 | Windows |

## 3. 安装依赖

```powershell
# 激活环境（以 conda 为例）
conda activate langchain2

# 一键安装（可复用 requirements.txt）
pip install -r requirements.txt
```

核心依赖：`langchain` `langchain-ollama` `langchain-community` `langchain-core`
`faiss-cpu` `pymupdf` `streamlit` `jieba` `ragas` `openai` `python-dotenv`

## 4. 准备 Ollama 模型

```powershell
ollama pull bge-m3:567m
ollama pull deepseek-r1:1.5b

# 验证模型已装
Invoke-RestMethod http://localhost:11434/api/tags
# 确认 models 中包含上面两个名称
```

## 5. 首次运行（构建向量库）

> 注意：TRAE 沙箱会拦截 FAISS 索引落盘，请在正常终端（非沙箱）执行。

```powershell
python scripts/build_kb.py
# 预期输出: 知识库构建完成。统计: {...}  (2670块)
```

如果之前已建过库、想重建：`python scripts/build_kb.py --rebuild`

## 6. 启动问答应用

| 方式 | 命令 | 说明 |
|---|---|---|
| 图形界面 | `streamlit run app.py` | 浏览器打开 http://localhost:8501 |
| 命令行问答 | `python scripts/run_qa.py --question "注册资本多少"` | 控制台输出 |

启动界面后：
- 侧边栏可切换 **RAG / 纯 LLM** 模式、调 Top-K；
- 输入问题 → 点"🔍 提问" → 显示回答、检索依据(页码)、耗时；
- 支持 👍/👎 反馈，写入 `output/feedback.csv`。

## 7. 运行评估与出报告

```powershell
python scripts/evaluate.py --top-k 8 --skip-ragas   # 10题评估
python scripts/build_report.py                      # 生成评估报告 md
```
产物：`output/evaluation_report.json` / `output/evaluation_report.md`

## 8. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 连接 localhost:11434 失败 | Ollama 未启动 | 启动 Ollama |
| 模型不存在错误 | 未 pull | `ollama pull <model>` |
| 嵌入时 127.0.0.1:1510 被拒 | 超长请求 | 已内建分批嵌入，若再触发增大批次间隔 |
| FAISS 写索引 Permission denied | 沙箱拦截 | 在沙箱外用 `--in-memory` 或配置放行 |
| 界面上没有语音 | 缺 whisper | `pip install openai-whisper`（可选功能） |
| RAGAS 无分数 | 裁判模型非JSON友好 | 换对话型模型跑 `ragas_score.py` |

## 9. 目录自检

部署完成后，项目根目录应包含：
```
app.py  src/  scripts/  data/  output/  vector_db/  requirements.txt
```
若缺 `vector_db/`，说明未建库或落盘受限，按要求执行 build_kb。

## 2. Query 理解设计（`query_understanding.py`）

**目标**：把自然语言问句转成"可检索、可排序"的结构化信号，毫秒级、确定性、可复现。

| 产出 | 说明 |
|---|---|
| `core` | 剥离噪声后的核心问句（剔除公司名、套话："根据…招股意向书""报告期内""分别是多少"…） |
| `keywords` | jieba 分词后的关键词（去停用词） |
| `entities` | 实体：书名号/引号内专名、`XX领域/行业/系统/工程/标准`，**并加入命中的公司别名** |
| `years` | 年份（`2016年`…），用于分年度问题的数值匹配 |
| `answer_type` | `table` / `ratio` / `amount` / `number` / `list` / `boolean` / `entity` / `fact` |
| `doc_hint` | **★文档级路由**：公司名 → 源文件名 |
| `expand_queries` | 多路查询：核心问句 / 关键词组合 / 实体增强 / **字段化查询**（`关键词 万元 %`） |

### 2.1 答案类型判定（表格类优先）

```python
_TABLE_HINTS = re.compile(r"(发行股数|发行后总股本|募集资金|拟投资|投资项目|持股比例|关联方|"
                          r"注册资本|法定代表人|收入|占比|比重|比例|金额|项目名称|总投资|股东|限售)")
# 命中即判为 table 类型 → 触发表格块加成 + 表格专用答案路径
```

### 2.2 文档级路由（解决 D5 跨文档串味）

两份招股说明书都有"发行股数 / 募集资金 / 关联方"同构表，语义极近，**纯语义无法区分**。
故建立「公司别名 → 源文件名」映射：

```python
DOC_COMPANY = {
    "招股说明书1.pdf": ["武汉兴图新科电子股份有限公司", "兴图新科电子", "兴图新科", "兴图"],
    "招股说明书2.pdf": ["武汉力源信息技术股份有限公司", "力源信息技术", "力源信息", "力源"],
}
```

取**最长别名**匹配（避免"力源"误配到"力源贸易"），命中后：
- 检索侧：按 `source` 过滤候选（阈值：过滤后仍 ≥5 个候选，否则退回全量，防止召回塌陷）；
- 重排侧：来源与 `doc_hint` 一致时加 `W_DOC` 分。

## 3. 检索设计（`retriever.py`）

```
多路查询（3~4 条）
   │
   ├─► 向量召回（FAISS + bge-m3，Top-30，语义）
   └─► BM25 召回（jieba 搜索引擎模式分词，Top-30，词法）
   │
   ▼
RRF 融合（k=60）：score = Σ 1/(k + rank)
   │
   ▼
★文档级路由过滤（doc_hint 一致）
   │
   ▼
重排（reranker，见 §4）
   │
   ▼
★去重：按 (父块, ctype) 去重 —— 表格 Markdown 块与键值对块互补，分别保留
```

> **去重键带 ctype** 是一个关键细节：若只按父块去重，会丢掉键值对块，导致数值型问题失去"表头—取值"线索。

## 4. 重排设计（`reranker.py`）——表格感知加权线性融合

```
score = w_vector·向量语义(归一化)
      + w_bm25  ·BM25(归一化)
      + w_keyword·查询关键词覆盖率
      + w_numeric·数值/年份匹配度
      + w_entity ·实体匹配度
      + w_table  ·★表格块加成
      + w_doc    ·★文档匹配加成
```

| 权重 | 值 | 含义 |
|---|---|---|
| `W_VECTOR` | 0.22 | 语义相似度 |
| `W_BM25` | 0.15 | 词法命中 |
| `W_KEYWORD` | 0.20 | 关键词覆盖率 |
| `W_NUMERIC` | 0.12 | 数值/年份匹配 |
| `W_ENTITY` | 0.06 | 实体匹配 |
| `W_TABLE` | 0.09 | **表格块加成** |
| `W_DOC` | 0.18 | **文档路由加成** |

### 4.1 表格块加成 `_table_bonus`

| 块类型 | 表格类问题 | 其他问题 |
|---|---|---|
| `table_kv`（键值对） | 1.00 | 0.30 |
| `table`（Markdown） | 0.85 | 0.25 |
| `text` | 0.00 | 0.00 |

**设计意图**：表格类问题的答案几乎必然在表格中 → 强加成把表格顶到前面；
非表格问题只给弱加成，避免干扰正文型排序。

## 5. 答案合成设计（`answer_builder.py`）

### 5.1 两条路径

```
build_answer()
   │
   ├─ answer_type == "table" ──► _table_answer()  表格专用路径（本工单核心）
   │
   └─ 其他 ────────────────────► 句子级抽取（关键词/数值/实体/定义式/对比/套话）
```

### 5.2 表格专用路径 `_table_answer`

1. **取表格块**：只从 `ctype ∈ {table, table_kv}` 的候选中取；
2. **行解析**：
   - `table_kv` 块：直接解析 `[表格行] 表头：取值；…`；
   - `table` 块：由首行表头 + 数据行**现算**"表头：取值"（使 Markdown 块也能参与拼装）；
3. **表格级消歧（★核心）**：每张表的块得分 =
   `最佳行得分 + 0.25·章节先验 + 0.5·表题匹配度`
   其中"表题匹配度"用**短语覆盖率**（长词 + 相邻双词组合）计算，用于在"数值密集的多张表"之间
   区分"募集资金投资项目表"与"现金流量表"；
4. **行打分**：
   ```
   _row_score = 0.30·关键词覆盖 + 0.22·短语覆盖 + 0.28·数值线索 + 0.20·实体匹配
   ```
5. **字段型 / 枚举型分流**（★可读性优化）：
   - **枚举型**（`哪些 / 有哪些 / 主要包括…`）→ 整表罗列（募投项目、无控制关系关联方）；
   - **字段型**（`是多少 / 是谁 / 占比…`）→ 只保留命中问句关键词/短语、且得分接近最佳行的行，
     且**取到即止**，避免跨表污染与"把整张表塞进答案"；
6. **结构化拼装**：
   ```
   根据《招股说明书2.pdf》第24页：股票种类：发行股数及占发行后总股本比例；
   人民币普通股(A股)：1,670 万股，占发行后总股本的比例为25.04%
   ```
   附 `citations`（页码）与 `evidences`（行级证据 + 得分）。

### 5.3 正文路径（句子级抽取）

```
score = 0.34·关键词覆盖 + 0.16·答案类型信号 + 0.09·实体 + 0.09·定义式句式
      + 0.05·表格块 + 0.04·长度 + 0.05·检索分 + 0.18·章节先验
      - 0.20·对比词惩罚 - 0.15·套话惩罚
```

- **定义式句式**：关键词后紧跟 `为/是/：/|` → 该句在"给出取值"；
- **对比词惩罚**：问题只问一侧（如"上游"），句子却出现另一侧（"下游"）→ 降权；
- **套话惩罚**：签署页 / 中介机构条款（保荐代表人、盖章、签字…）中的人名易被误当答案 → 降权；
- **章节先验**：`注册资本/法定代表人` 等基本信息字段优先"概览 / 发行人基本情况"章节。

### 5.4 为什么用抽取式而非 LLM 生成

| 维度 | 抽取式（本方案） | LLM 生成（基线） |
|---|---|---|
| 响应时间 | 毫秒级 | 数秒（本地 1.5B 推理模型） |
| 幻觉 | 零（原文摘取） | 有（基线 Q2 编造"X万元/Y万元/Z万元"） |
| 可溯源 | 强（文档 + 页码 + 行） | 弱 |
| 准确率 | 高（结构化拼装） | 不稳定 |

实测：基线（LLM 生成）答案命中 50%，本方案 100%。

## 6. 容错与降级设计（对应"系统稳定性"要求）

| 场景 | 处理 | 位置 |
|---|---|---|
| 用户空输入 | 返回空分析，不抛异常 | `QueryUnderstanding.analyze` |
| 向量检索失败 | 记 warning，返回空列表，仅用 BM25 | `HybridRetriever._vector_retrieve` |
| BM25 查询为空 | 返回空列表，仅用向量 | `BM25Index.search` |
| 文档路由过滤过度 | 过滤后候选 <5 → 退回全量候选 | `HybridRetriever.retrieve` |
| 表格块解析为空 | 退回正文句子级抽取 | `build_answer` |
| 字段型过滤无命中 | 退回最佳表整行 | `_table_answer` |
| 无任何候选 | 返回"根据招股说明书内容无法回答该问题。" | `build_answer` |
| PDF 不存在 | 抛 `FileNotFoundError`（明确错误） | `parse_pdf` / `parse_tables` |
| LLM 调用失败 | 捕获异常，返回失败提示，不中断 | `QAEngine._invoke` |
| 中文路径 FAISS 保存失败 | 临时 ASCII 目录桥接 | `knowledge_base.save_local` |

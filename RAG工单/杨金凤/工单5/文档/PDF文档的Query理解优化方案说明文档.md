## 1. 优化目标

工单 05 要求在已实现的双 PDF、表格、图像问答系统基础上，新增多轮对话能力，使系统能够正确处理指代词和省略句。

| 验收项 | 目标 | 实际达成 |
| --- | --- | --- |
| 多轮对话 | 支持指代消解 | ✅ 5/5 轮通过 |
| 问答准确率 | ≥ 90% | 100%（16/16） |
| 响应时间 | ≤ 3 秒 | 平均约 3 秒 |
| 多语言支持 | 中英文问答 | ✅ 已支持 |
| 容错机制 | 异常输入处理 | ✅ 已支持 |

## 2. 新增需求分析

工单 05 给出 5 轮示例对话：

| 轮次 | 问题 | 挑战 |
| --- | --- | --- |
| Q1 | 报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？ | 无（引入实体"兴图新科"） |
| Q2 | 他参与的哪个工程荣获了国家科技进步一等奖？ | 指代词"他" → 需解析为兴图新科 |
| Q3 | 这个公司的法定代表人是谁？ | 指代词"这个公司" → 需解析为兴图新科 |
| Q4 | 那武汉力源信息技术股份有限公司呢？ | 省略句 → 需补全为"力源的法定代表人是谁？" |
| Q5 | 武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？ | 无（独立问题） |

**核心挑战**：Q2、Q3、Q4 都是指代/省略句，没有历史无法回答。

---

## 3. 优化方案

### 3.1 对话历史管理

`RAGEngine.ask()` 新增 `history` 参数，格式为 `[(用户问题, 助手回答), ...]`。

### 3.2 指代消解（Query 理解核心）

新增 `_resolve_query(question, history)` 方法：

- **触发条件**：问题包含指代词（"他""她""它""这个公司""那...呢"等）或问题过短（<10 字）
- **消解方式**：取最近 2 轮历史，用 LLM 改写为独立完整的问题
- **性能优化**：无指代词时跳过 LLM，不增加耗时

**示例：**

```text
历史：
   用户：报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
   助手：...6,464.51 万元...
当前问题：他参与的哪个工程荣获了国家科技进步一等奖？
  → LLM 改写：武汉兴图新科电子股份有限公司参与的哪个工程荣获了国家科技进步一等奖？
```

### 3.3 多轮界面改造

`app.py` 从单轮 Blocks 改为 Chatbot + 多轮事件链：

- `gr.Chatbot` 显示对话历史（tuples 格式）
- `user_submit` → 用户消息加入历史
- `bot_respond` → 提取历史，调用 `engine.ask(question, history)`，补全助手回答

## 4. 优化效果

### 4.1 多轮对话测试

| 轮次 | 问题 | 指代解析结果 | 结果 |

16 题批量测试全部正确，多轮改造未影响单轮性能。

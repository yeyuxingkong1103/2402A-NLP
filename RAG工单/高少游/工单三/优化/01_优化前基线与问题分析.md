## 1. 基线定义（优化前）

基线复刻 01/02 工单的问答链路，**不包含任何表格结构化能力**：

```
PDF（PyMuPDF）
  └─ 表格拍平为文本行（行列关系、表头全部丢失）
       └─ 固定长度递归切片 500 / overlap 80
            └─ 向量召回(Top-6) + BM25 召回(Top-6)
                 └─ RRF 融合（无重排）
                      └─ 本地 LLM 生成答案（deepseek-r1:1.5b）
```

对应源码：`src/chunking.py::build_baseline_chunks`、`src/retriever.py::BaselineRetriever`、
`src/qa_engine.py::answer_baseline`。

## 2. 基线实测（14 题）

| 指标 | 基线值 |
|---|---|
| 检索 Top-1 命中率 | 57.1%（8/14） |
| 检索 Top-K 命中率 | 92.9%（13/14） |
| 检索 MRR | 0.696 |
| **答案命中率** | **50.0%（7/14）** |
| 平均响应时间 | 4.064 s |

> 关键矛盾：**检索 Top-K 命中 13/14，但答案只命中 7/14**。说明"能捞到片段"，
> 却"答不对"——问题出在表格结构化缺失与答案合成，而非单纯的召回。

## 4. 五类根因详解

### ① 表格拍平导致"表头—取值"分离

基线把单元格按行拼成一串文本：

```
股票种类 发行股数及占发行后总股本比例 人民币普通股（A股）
1,670万股 占发行后总股本的比例为25.04% 每股面值 ...
```

`发行股数` 与 `1,670万股` 落在**不同检索单元**，"字段—取值"绑定关系丢失。
Q1、Q543、Q207 均受此影响。

### ② 同表多行错位（Q3）

"关联方及关联关系"表同时含"存在控制关系"（赵马克 / 42.35%）与
"不存在控制关系"（融冰投资、听音投资…）两类行。拍平后无表头锚定，
基线把两类行混在一起，答案错列成"融冰投资、听音投资…"。

### ③ 数值密集表难区分（Q260 / Q33）

兴图新科"军用领域收入"表同一张表里同时有**金额**（6,464.51…）与**占比**（82.10…）。
拍平后两类数值语义几乎相同，纯向量检索无法区分"问金额"还是"问占比"，
基线 Top-1 均落空（Top-K 才勉强捞到）。

### ④ 正文问题被噪声淹没（Q34）

"电子信息行业上游涉及哪些企业"答案在正文，但招股书全文充斥相似表述
（行业竞争格局、上下游情况在多页重复）。基线无章节先验与惩罚机制，
Top-1 被无关段落占据。

### ⑤ LLM 生成幻觉（Q2）

基线依赖本地 1.5B 模型生成，当上下文不含答案时直接编造：

> 优化前答案：…仓储及物流中心：预计投资金额为 **X万元**…研发中心：**Y万元**…电子商务平台：**Z万元**…

`X/Y/Z万元` 是模型占位式幻觉——**上下文里根本没有这些数**。

## 5. 结论：优化方向

| 根因 | 对应优化 |
|---|---|
| ① 表格拍平 | 表格结构化解析 + 双表示分块（table / table_kv） |
| ② 行错位 | 表头锚定 + 表格级消歧 + 行打分 |
| ③ 数值密集表 | 答案类型判定 + 数值线索匹配 + 表格专用答案路径 |
| ④ 正文噪声 | 章节先验 + 对比词/套话惩罚 |
| ⑤ LLM 幻觉 | 抽取式合成（原文摘取，零幻觉）+ 多级容错 |

以上优化在 [02 优化手段与消融分析](02_优化手段与消融分析.md) 中展开，
最终指标见 [03 指标对比](03_指标对比.md)。

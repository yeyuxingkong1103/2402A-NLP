# 工单9 GraphRAG 优化评测设计

## 目标

在工单8金融年报 GraphRAG 上加入可重复的参考答案评测与优化前后对比，让用户能看到答案、证据、知识图谱、上下文精度、上下文召回率和响应时间。

## 数据与约束

- 继续使用 `ccf_competition.zip` 已生成的本地索引，不重复解析年报。
- 参考 `sample_questions.pdf` 的四类问题与答案，匿名的 `xx银行` 统一解析为平安银行。
- 仅使用本机 `fastapi_FAQ_chat` 环境中已有依赖，不安装或修改环境。
- DeepSeek API Key 继续从 `.env` 读取；未配置或调用失败时必须返回证据式答案。
- 单次检索与本地评测目标小于 3 秒。

## 方案

1. Prompt 层：生成提示明确实体、关系、时间、限定证据回答和引用页码。
2. 实体关系层：识别公司、年份、主题实体，并把主题扩展成风险管理、资产质量、创新模式等关系词。
3. 检索层：保留工单8 TF-IDF 作为基线；优化通道使用查询改写、实体/关系加权、标题加权和去重。
4. 生成层：按多跳证据组织上下文，证据不足时明确说明，不补造事实。
5. 评测层：用每题标注的参考事实/关键词计算上下文精度和召回率，同时展示基线、优化值及差值。

## 页面

页面提供参考题选择、问题输入、优化前后指标卡、优化说明、回答、查询理解、知识图谱和两组检索证据。评测指标不依赖外部 API，因而可重复。

## 验收

- 能运行四道参考题及自定义问题。
- 每道参考题返回基线与优化结果、precision、recall、耗时。
- 汇总评测目标：优化后 precision >= 0.8、recall >= 0.9、单题总耗时 < 3000ms。
- 空问题、索引缺失、DeepSeek 失败均有清晰提示。

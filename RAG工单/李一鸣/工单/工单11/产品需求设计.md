# 电商智能客服产品需求设计

## 目标

为电商平台提供可解释、可路由、可扩展的智能客服，覆盖商品推荐、订单查询、售后处理和统一协调。

## 角色与职责

- 协调器 Agent：识别意图、选择专业 Agent、汇总答案。
- 营销 Agent：商品搜索、推荐、促销和价格咨询。
- 订单 Agent：订单查询、取消、物流和状态修改。
- 售后 Agent：退货、退款、换货和投诉处理。

## 任务清单

1. 定义 Agent 状态和消息格式。
2. 实现 ReAct 单智能体循环。
3. 实现角色注册和协调分发。
4. 接入商品、订单和售后工具。
5. 建立测试问题集和人工验收记录。

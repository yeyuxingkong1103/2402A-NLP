# 混合检索问答系统部署说明

> 工单编号：**人工智能NLP-RAG-混合检索任务**
> 适用环境：Windows 10/11 + Python 3.10/3.11/3.12，纯 CPU，**无需联网、无需 GPU**

---

## 1. 环境准备

```powershell
# 进入工单目录
cd RAG工单六\02_研发

# （建议）创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 安装依赖
pip install -r requirements.txt
```

依赖说明：

| 依赖 | 用途 | 是否必装 |
| --- | --- | --- |
| pymupdf / pdfplumber | PDF 正文与表格双引擎解析 | 必装 |
| jieba | 中文分词（BM25 倒排、TF-IDF 重排） | 必装 |
| scikit-learn / numpy / pandas | TF-IDF 降级嵌入、向量计算、评测报表 | 必装 |
| openpyxl | Excel 兼容 | 必装 |
| streamlit | 问答与策略演示界面 | 必装 |
| sentence-transformers + torch | 加载本地 bge / m3e / bge-reranker-large | 可选 |

> **离线降级机制**：bge / m3e / bge-reranker-large 仅在检测到本地 HuggingFace 缓存时离线加载（`local_files_only=True`）；本地无缓存或未安装 sentence-transformers 时，嵌入自动降级为 TF-IDF、LLM 重排自动降级为词法精排，**全程不发起任何网络下载请求**，系统仍可完整运行全部检索/融合/反馈功能。

## 2. 构建索引

```powershell
cd src

# 默认 bge 后端（本地无缓存自动 TF-IDF 离线降级）
python build_index.py

# 可选：切换嵌入模型重建
python build_index.py --backend m3e       # m3e-base
python build_index.py --backend bge-m3    # bge-m3
python build_index.py --backend tfidf     # 强制离线 TF-IDF
```

构建完成后在 `02_研发\index_store\` 生成：

```
vectors.npy         # 稠密文档向量矩阵
chunks.pkl          # 多字段标注检索块（含来源文档/页码/标题路径）
bm25_fields.pkl     # 五字段 BM25 倒排索引
tfidf.pkl           # TF-IDF 降级嵌入时的 vectorizer（可选）
meta.json           # 嵌入后端、块数、字段权重、语料清单
feedback.jsonl      # 用户反馈持久化文件（运行界面后产生）
```

## 3. 批量评测（验收自检）

```powershell
cd RAG工单六\02_研发\src
python evaluate.py
```

自动产出：

- `03_测试\评测结果.csv`：20 题 × 13 策略逐题明细；
- `03_测试\策略对比表.csv`：13 策略汇总 + 自适应重排“模拟反馈一轮”前后对比；
- `03_测试\模拟反馈数据.jsonl`：脚本真实生成的一轮模拟反馈（每条 `simulated=true` 标注）。

终端打印最终配置（**混合检索 + RRF 融合 + LLM 重排**）的准确率、Recall@10、≤3 秒占比。

## 4. 启动问答服务

```powershell
cd RAG工单六\02_研发\src
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`。侧边栏可热配：

1. **检索模式**：向量检索 / 全文检索 / 混合检索；
2. **融合方式**：加权平均 / 投票融合(Borda) / RRF（混合模式生效）；
3. **双路权重滑块**：向量路权重、全文路权重，即时生效；
4. **重排策略**：LLM 重排（Cross-Encoder）/ TF-IDF 重排 / 用户反馈自适应重排；
5. **语言**：中文 / English；
6. 每条证据点击“👍 采纳 / 👎 不采纳”，反馈写入 `index_store\feedback.jsonl`，切换“自适应重排”即刻生效。

## 5. 配置项说明（`src\config.py`）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `embedding_backend` | bge | 默认嵌入后端 |
| `dense_top_k` / `bm25_top_k` | 30 / 30 | 双路召回条数 |
| `field_weights` | 标题3.0/公司2.5/表格2.0/摘要1.5/正文1.0 | 多字段加权 |
| `rrf_k` | 60 | RRF 融合常数 |
| `default_vector_weight/fulltext_weight` | 0.5 / 0.5 | 混合默认权重（界面可热配） |
| `llm_rerank_candidates` / `rerank_truncate` | 12 / 64 | LLM 重排候选数与截断（3 秒预算） |
| `response_timeout_s` | 3.0 | 验收响应时间阈值 |
| `adaptive_query_sim` | 0.45 | 自适应重排相似问题触发阈值 |

## 6. 常见问题

- **Q：建库时日志提示“未检测到本地缓存，启用 TF-IDF 离线降级”？**
  A：属正常降级行为，不联网；如需要真实 bge/m3e 语义检索，请在有网机器预下载模型到 `~/.cache/huggingface/hub` 后整体拷贝到本机。
- **Q：英文问题能检索中文招股书吗？**
  A：使用 bge 嵌入时支持中英跨语言召回；TF-IDF 降级时英文问题仍可命中含英文/数字（如 IC、公司英文名）的块，但跨语言能力弱于 bge。
- **Q：反馈数据在哪？模拟数据会污染真实反馈吗？**
  A：界面真实反馈在 `index_store\feedback.jsonl`；评测模拟反馈单独写在 `03_测试\模拟反馈数据.jsonl`，每条带 `simulated:true` 标记，二者文件隔离。
- **Q：端口占用？**
  A：`streamlit run app.py --server.port 8502` 换端口。

### 0.3 判定纪律

| 规则 | 内容 |
| --- | --- |
| 不存在「部分通过」 | 任一条不通过 → 整体不通过；不得以「其余都很好」抵扣 |
| 证据必须是真实运行产物 | pytest 输出、脚本 stdout、产物文件、日志文件；**不接受「文档里写了」** |
| 未运行 = 未通过 | 任何指标未真实运行必须显式标注「未运行」+ 原因，该条判不通过 |
| 口径唯一 | §2 的判分口径不得放宽、不得换尺子、不得重跑挑最好一次 |
| **已知设计选择不得判缺陷** | §3 列出的各项（相邻同值/跨行重复、退化表不进索引、引用页 ≠ `evidence_pages`、闸门 `counted=False`、`[ ◆ ]` 占位符、启发式计数差异）**一律不得**作为缺陷判定；误判视为断言写错 |
| 断言必须可失败 | 禁止永真断言（`assert True`、只断言类型不断言内容）；失败必须如实记录，**禁止为让测试变绿而放宽断言** |
| 锚点固定、计数不设门槛 | 表格解析用**确定性锚点页**（物理 129/130/131/153）判定；`continued_tables` 等启发式计数只作留痕，**不**作验收门槛（§1 验收 1 负例说明） |
| 只读纪律 | 判定前后 `工单1`/`工单2` 的文件清单与 mtime 必须不变（含 `__pycache__`） |
| RAGAS | 一律标注「RAGAS 未运行（依赖不可用，本机断网）」；**严禁伪造数值** |

**红线（任一触发即整体不通过）**：
① 修改 `工单1/` 或 `工单2/` 任何文件（含新增 `__pycache__`）；
② 伪造/估算指标数值；
③ 伪造 RAGAS 数值；
④ 把工单2 基线值誊抄为优化后值；
⑤ 声称运行了本机不可用的依赖（`streamlit` 本机 / `loguru` / `ragas` / `pdfplumber` / `rank_bm25` / `chromadb` / `langchain` / `pandas`）；
⑥ 代码中为单题写死答案或关键词特判；
⑦ 代码中出现 PDF 文件名常量（`研发/app/**`、`研发/scripts/**`）；
⑧ 用页脚/页眉印刷页码或 0-based 索引充当引用页码；
⑨ **题 207（补充流动资金）混用 PDF2 物理 340**：把「向汉口银行借款 300 万美元」当作募投补流金额 → 判编造（题 207 的正确依据是 PDF1 物理 **490**，另有 30/479，见 `设计/需求分析.md` §4.3）。

### 2.1 准确率（14 题）

五步顺序判定，满足任一步即判对（沿用工单1 `Evaluator.check_answer` 口径，`FUZZY_THRESHOLD = 0.62`）：
① 参考答案是答案的子串（忽略标点/空白）；

③ 关键实体命中（引号内专有名词/工程名/机构名）；

### 2.2 检索命中

`hit = text_utils.evidence_contains(chunk.content, golden.evidence, threshold=0.90)` 对返回的 **top-k（k=5）** 任一 chunk 成立。
**禁止**用「引用页 == `evidence_pages`」判定。

### 2.3 首字响应

`first_token_ms` = 收到提问 → 首个非空 token 文本到达。逐题测量，**取最大值**判定（§1 验收 4）。

### 2.4 引用正确率

`citation_accuracy = 有效引用条数 / 引用总条数`；有效 = 页码整数且在范围内 + `file_name` 真实 + `chunk_id` 可查且页码一致 + 引用页含支撑原文（抽验）。

### 2.5 「不清楚」

## 3. 已知设计选择与非缺陷清单（**T7/T10/T11 不得据此判缺陷**）

> 本节由 captain 口径裁定 + T3 实测证据固化。**以下各项一律不得作为「缺陷」判定**；误判即视为 tester 断言写错（判 tester 不通过），而非实现问题。

### 3.1 「相邻同值 / 跨行纵向重复」不是缺陷

| 项 | 规定 |
| --- | --- |
| 反面（禁止的断言） | **禁止**写「表格出现三连重复值即判缺陷」「同一列出现相同人名即判归一化失败」这类**全局**断言 —— 会误报真实数据 |
| 实测反例 | PDF1 **物理 65/66** 的董监高表在 2016–2019 各期**真实重复同一人名**（陈爱民 / 程家明），原文如此【captain + engineer 实测】 |
| 缺陷正确定义 | **行内横向重复**：同一逻辑值被复制填充到**同一行的多个子列**（典型成因 = 合并单元格被拆成多列后每列都填同一个值）。判据 = 「同一行内相邻列出现相同非空值，且该行存在被拆分的合并表头」 |
| 已修证据 | T3 的**稀疏网格压缩**（290 块生效）已消除横向重复；PDF2 物理 22 募投表实测为**干净 3 列** |
| 断言要求 | 表格归一化断言只允许：① 物理 130 表头无相邻 `None` 且 `logical_cols == 5`；② 输出单元格不含 `\n`；③ 物理 131 续表被识别且表头继承；④ **行内横向重复数 = 0**（按上述判据）。**禁止**对跨行同值（纵向重复）设任何门槛 |

### 3.2 退化表不进索引是设计选择（**且已验证不丢证据**）

| 项 | 规定 |
| --- | --- |
| 设计选择 | `degenerate=1` 的退化表块（`markdown` 为空，语义上与空块重合）**不进 chunk、不进索引**（见 `设计/系统架构.md` §6.2 R4、§7） |
| T3 实测规模 | 退化表块 **53 个**（`degenerate=1`，`markdown` 为空） |

## 附录 A（t22 追加）：英文问答的语言保证范围（有限保证声明）

> 追加背景：t21 使英文提问**可答并带引用**（`language=en`、引用格式切到 `[Page: N]`），但答案正文仍是中文原文摘录；
> t22 引入语言适配层（英文框架句 + 逐字中文原文片段）与语言闸门后，**可逐字核验的字段型**英文问句已能给出英文正文。
> 结论与范围如下（**不是放弃要求，而是把保证范围写清楚**）：

**保证范围（按实测收窄，不写未实测的引申）**

| 英文问句类型 | 语言保证 | 实测（t22 定稿批次） |
| --- | --- | --- |
| **可逐字核验的字段型 / 数值型**（registered capital、legal representative、main business 等） | **保证英文正文**：`language.english_ratio(正文) ≥ 0.5`（该占比**排除**为防编造而保留的逐字原文片段 `（verbatim source: 「…」）`）；达不到就必须走降级并留痕，**不得**把中文正文当达标 | EN1 `0.6829`、EN2 `0.7733`、EN7 `0.6071` → **3 条稳定达标**（EN6 的达标态 `0.5588` 亦满足同一判据，但**不作保证**） |
| **受限字段型**（表格证据、取值本身为长中文串）与**叙述型**（问领域/行业地位等整句叙述） | **尽力而为**：允许保留中文原文；必须满足「可答 + 带引用 + `language == en` + 引用可回溯」，并**必须**在日志留下 `generation.language_degraded`（WARNING）、在测试的 `DEGRADED_ALLOWED` 白名单里逐题登记 ID | EN3 `0.4156`、EN4 `0.3300`、EN5 `0.0000` 稳定降级；EN6 `0.0208`（中文表行）与 `0.5588`（英文句）**两态随采样** → **登记为「降级或达标，两态均不判失败」** |

**硬要求（均有实测）**：英文正例**不得被误拒答**（7 条英文正例复测全部可答、`is_unknown=false`）；
英文负例**必须拒答且零引用**（Tesla 注册资本、2099 月球项目 → 均拒答且零引用）；
英文答案中的中文只允许出现在**专名、金额单位、以及为防编造而保留的逐字原文片段**里。

**为什么叙述型/受限字段型不强制英文**：其答案主体是中文整句或长中文取值，强制英文只能靠 LLM **改写/翻译证据**，
这与本项目「纯摘原文、不新增事实、引用必须逐字可核」的确定性保证冲突（该方向已被 captain 明确否决）。
保持中文原文 + 可回溯引用，优于生成无法逐字核验的英文改写句。

**依据**：工单验收项为「支持中英文问答」，未逐字规定「英文答案必须全英文」；设计原文「英文问英文答」
以「可逐字核验的字段型/数值型全量达标 + 受限字段型与叙述型登记有限保证」的方式落地。
**未承诺的部分**：受限字段型与叙述型的英文正文；具体已知缺陷、根因与后续修复建议见
`部署/配置/环境事实.md` §25.7（含「框架句逐字片段应改用证据真实连续子串」的建议，属另开任务范围）。

**留痕要求**：`测试/在线/test_english_language_path.py` 采用**三态断言**——
① 英文达标（必达题断言 `ratio ≥ 0.5`）；② 降级保留中文（须在 `DEGRADED_ALLOWED` 白名单内并打印题号与 ratio）；
③ 失败（不可答 / 无引用 / `first_token_ms == 0` / 回「不清楚」）——**②不得当作①通过**。

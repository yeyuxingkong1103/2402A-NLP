# 基于 PDF 文档的问答系统 - 系统架构设计

> 工单编号: 人工智能 NLP-RAG-基于 PDF 文档的问答系统

## 一、系统概述

本系统基于大语言模型 (LLM) 与检索增强生成 (RAG) 技术, 针对《招股说明书1.pdf》构建高效问答检索系统, 能够针对用户问题从 PDF 文档中提取相关信息并生成准确、简洁的回答。

## 二、整体架构

系统采用分层架构, 共分为四层:

```
┌─────────────────────────────────────────────────────────┐
│                    用户交互层 (Web UI)                    │
│         Flask + HTML/CSS/JS 提供问答交互界面              │
├─────────────────────────────────────────────────────────┤
│                    业务逻辑层 (QA Engine)                │
│   Query 理解 → 检索 → 生成 → 对比评估                    │
├─────────────────────────────────────────────────────────┤
│                    核心能力层 (Core)                      │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐  │
│  │ PDF 解析模块 │  │ 向量检索模块 │  │ LLM 调用模块 │  │
│  └──────────────┘  └──────────────┘  └──────────────┘  │
├─────────────────────────────────────────────────────────┤
│                    数据存储层 (Storage)                  │
│      原始文本库   │   向量索引库   │   缓存库           │
└─────────────────────────────────────────────────────────┘
```

## 三、模块说明

### 1. PDF 解析模块
- 功能: 解析《招股说明书1.pdf》, 提取文字与表格数据
- 实现: 使用 pdfplumber 提取文本, 按页/段落切分
- 输出: 文本块列表 (chunks)

### 2. 向量检索模块
- 功能: 将文本块嵌入向量空间, 支持 Top-K 相似度检索
- 实现: 使用 TF-IDF + 余弦相似度 (轻量化, 无需 GPU)
- 备选: sentence-transformers (如有可用模型)

### 3. Query 理解模块
- 功能: 意图识别、消歧、分解与抽象
- 实现: 基于关键词匹配 + LLM 提示词工程

### 4. QA 引擎模块
- 功能: 整合检索结果与 LLM 生成答案
- 实现: 检索 Top-K 文本块 → 构造 Prompt → 调用 LLM
- 同时支持: 只使用 LLM 的基线对比

### 5. Web UI 模块
- 功能: 提供问题输入、答案展示、对比展示
- 实现: Flask 后端 + HTML/CSS/JS 前端

## 四、数据流

```
用户问题
   │
   ▼
Query 理解 (意图识别/消歧)
   │
   ▼
向量检索 (Top-K 文本块)
   │
   ▼
Prompt 构造 (context + question)
   │
   ▼
LLM 生成答案 (RAG 模式)
   │
   ▼
同时调用 LLM 生成答案 (纯 LLM 模式, 用于对比)
   │
   ▼
结果展示与评估
```

## 五、性能指标

| 指标     | 目标值         |
| -------- | -------------- |
| 响应时间 | ≤ 3 秒         |
| 检索准确率 | 基于文档返回 |
| 系统稳定性 | 支持长时间运行 |
| 语言支持 | 中文 / 英文     |

## 六、技术选型概览

## 3. 项目现状摘要

当前系统以 FastAPI 为 API 层，以 Milvus 为向量存储，以 MySQL 保存知识库和会话元数据，以 Redis 保存短期对话记忆，并通过可配置的 LLM、Embedding 和 Reranker 提供问答能力。开发环境可以使用 Mock 客户端运行基础链路，生产环境应配置 API Key、真实 Embedding、LLM 以及持久化依赖。

核心能力包括：

- 多格式文档解析、清洗、分块、向量化和索引；
- Dense + BM25 混合检索、可选重排序、查询改写和答案后处理；
- 标准问答和 SSE 流式问答；
- 多知识库、多租户范围控制、文档去重和增量索引；
- Redis 短期记忆、MySQL 会话元数据、Milvus 长期记忆；
- API Key 鉴权、请求大小限制、速率限制、健康检查和 Prometheus 指标。

## 4. 入口说明

`RAG项目/02-研发/核心代码/` 已包含可运行源码，部署脚本直接使用这份代码；原工程源码仍保留在仓库根目录，不会因整理交付包而失效。

常用入口：

```bash
# 安装 CPU 环境
bash 05-部署/install.sh --mode cpu

# 启动开发服务
bash 05-部署/run.sh --mode development

# 结束服务
bash 05-部署/shutdown.sh

# 查看 API 文档
# http://127.0.0.1:8000/docs
```

测试截图请放入 `03-测试/`。

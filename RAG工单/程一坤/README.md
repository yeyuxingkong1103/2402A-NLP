# 人工智能 NLP-RAG 项目工单集（程一坤）

基于 **Ollama 本地模型**（qwen2.5:7b-instruct 生成 / bge-m3 向量化 / qwen2.5vl:7b 视觉）的金融招股书问答 RAG 系统，覆盖 PDF 解析、向量检索、表格解析、图像解析、多轮对话、混合检索、评估、部署、微调、知识图谱、性能优化全链路。

## 目录结构

```
├── 00-公共模块/            # 13个工单复用的核心库（解析/分块/向量库/混合检索/LLM客户端等）
├── 工单01-基于PDF文档的问答系统/   # 索引构建 + Flask问答(Web) + RAG vs 纯LLM对比
├── 工单02-问答系统优化/            # 页眉清洗降噪：检索命中8→10块级、回答正确率提升
├── 工单03-表格解析及检索优化/      # 表格"列名:值"序列化 + A/B双轨检索（14题）
├── 工单04-图像内容解析/            # Qwen2.5-VL 整页语义描述 + 相邻分块扩展
├── 工单05-Query理解优化/           # 多轮对话Query改写（指代消解+省略补全，few-shot）
├── 工单06-混合检索/                # BM25(jieba)+向量加权融合，6策略×10题对比
├── 工单07-功能测试及评估/          # 9份年报2万块索引 + LLM judge 评估报告
├── 工单10-金融问答系统部署/        # Dockerfile/compose/健康检查 部署方案
├── 工单11-Embeddings模型微调/      # 对比损失(MNRL) CPU微调，Recall@1 0.36→0.41
├── 工单12-LightRAG优化/            # 知识图谱构建 + RAG vs LightRAG 14题对比
└── 工单13-性能瓶颈识别与优化/      # 五阶段分段计时，端到端 1.64s→1.18s
```

（工单08、09 按要求不做）

## 环境依赖

- Python 3.10+，依赖：`pymupdf` `numpy` `requests` `jieba` `rank_bm25` `flask` `sentence-transformers` `lightrag-hku==1.5.7` 等
- Ollama 本地服务（127.0.0.1:11434），需拉取：`qwen2.5:7b-instruct`、`dengcao/bge-m3:567m`、`qwen2.5vl:7b`、`qwen2.5:1.5b`

## 首次运行前：重建被 .gitignore 排除的大文件

仓库不含生成产物（均可用脚本重建）：

| 排除项 | 体积 | 重建方式 |
|---|---|---|
| `index_store/`（向量索引） | 572M | 工单01 `build_index.py` → 工单03 `build_index_all.py` → 工单07 `build_ccf_index.py`（顺序执行，共约15分钟） |
| `工单11/models/`（微调权重） | 184M | 从 hf-mirror 下载 bge-small-zh-v1.5 到 `models/base/`，再跑 `finetune.py` |
| `工单12/lightrag_work/`（图谱） | ~7M | 工单12 `run_lightrag.py build`（约40分钟） |

## 各工单核心结论

| 工单 | 关键结果 |
|---|---|
| 01 | RAG 对比纯 LLM：10题中 8 题答对且带页码来源，纯 LLM 大量幻觉 |
| 02 | 页眉清洗后真值块进入 Top5，注册资本类问题由错转对 |
| 03 | 双轨检索（查询扩展6席+混合检索6席）14题约9题稳定正确 |
| 04 | 组织结构图（4部门6销售处）、IC市场增速图均解析成功入检索 |
| 05 | 指代消解（"他/这个公司/那力源呢"）改写命中率显著提升 |
| 06 | 混合检索 70% > 纯向量 60%，LLM重排持平，反馈重排需积累数据 |
| 07 | 检索命中 7/10、回答正确 6/10，瓶颈在生成端 |
| 10 | Dockerfile+compose+HEALTHCHECK 完整部署方案 |
| 11 | 微调后 Recall@1: 0.3636→0.4091、MRR: 0.5658→0.5803 |
| 12 | LightRAG 强在跨段落关系聚合、弱在数值细节；建议双库互补 |
| 13 | LLM 生成占总耗时 98%；上下文精简+限长后 1.64s→1.18s |

详细实验数据、调试过程与踩坑记录见各工单目录下的报告与技术文档（.md）。

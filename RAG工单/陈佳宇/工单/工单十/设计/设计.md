# 工单10 金融问答系统部署｜设计文档
工单编号：人工智能NLP‑RAG 项目‑金融问答系统部署

## 1.项目概述
本工单基于工单9优化后的Graph‑RAG金融问答代码，完成Docker容器化部署。实现容器镜像构建、容器启动运行、Docker Volume数据持久化、端口网络映射。
实现将Graph‑RAG问答服务打包为Docker镜像，通过docker run一键启动服务，业务输出数据使用数据卷挂载持久化到宿主机，容器销毁数据不会丢失。

## 2.需求与验收标准
1. 基线代码：复制工单9完整业务代码作为部署基线，工单9原始项目保留，不做修改。
2. Docker镜像构建：编写Dockerfile、.dockerignore、requirements.txt，构建问答服务镜像。
3. 容器启动：使用docker run命令成功启动容器，指定端口对外提供Web服务，运行无异常日志。
4. 容器数据管理：使用Docker Volume卷持久化存储图谱可视化html文件，容器删除宿主机数据不丢失。支持容器数据挂载共享。
5. 网络配置：端口映射配置正确，外部浏览器可以访问容器内部Flask问答服务。
6. 产出部署文档，记录部署步骤以及过程踩坑问题。

## 3.系统总体架构
工单 9 业务代码副本（Graph‑RAG 问答）
↓
Dockerfile 构建镜像（内置 python 环境、安装项目依赖）
↓
docker run 启动容器，‑p 端口映射，‑v 数据卷挂载
↓
├─Web 服务：7862 端口对外提供问答接口与页面
└─Docker Volume：将 data_output 目录挂载到宿主机，持久化 graph_visual.html 图谱文件

## 4.模块详细设计
### 4.1 业务代码模块
复用工单9全部业务逻辑：文档加载、知识图谱构建、优化检索、RAG评测、Flask Web页面。
修改：图谱可视化输出路径调整为`data_output/graph_visual.html`，适配Docker卷挂载持久化。

### 4.2 Docker镜像构建模块
1. Dockerfile：基于python:3.11‑slim基础镜像，设置工作目录，安装依赖，复制代码，暴露7862端口，设置程序启动命令。
2. requirements.txt：项目python依赖清单：flask、networkx、pyvis。
3. .dockerignore：排除缓存、虚拟环境、临时文件，减小镜像体积。

### 4.3 容器运行与数据持久化
- 端口映射：宿主机7862映射容器内部7862。
- Volume挂载：`‑v 宿主机data_output:/app/data_output`，容器生成的图谱html直接保存到Windows宿主机，容器销毁文件不丢失。

### 4.4 Web访问
容器内部Flask监听`0.0.0.0:7862`，宿主机浏览器访问 `http://127.0.0.1:7862` 使用问答服务。

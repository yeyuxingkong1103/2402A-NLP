## 3. 配置项一览（src/config.py，可被 .env 覆盖）

| 配置 | 默认 | 说明 |
|---|---|---|
| `LLM_MODEL` | `deepseek-r1:1.5b` | 生成模型 |
| `EMBEDDING_MODEL` | `bge-m3:567m` | 向量模型 |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama 地址 |
| `LLM_TEMPERATURE` | 0.2 | 温度 |
| `LLM_MAX_TOKENS` | 768 | 生成长度上界 |
| `CHUNK_SIZE` | 500 | 切片字数 |
| `CHUNK_OVERLAP` | 80 | 切片重叠 |
| `TOP_K` | 6 | 向量 Top-K |
| `BM25_TOP_K` | 6 | BM25 Top-K |
| `RANK_FUSION_K` | 60 | RRF 平滑常数 |
| `TARGET_RESPONSE_SECONDS` | 3.0 | 达标阈值 |

示例 `.env.example`：
```
OLLAMA_BASE_URL=http://localhost:11434
LLM_MODEL=deepseek-r1:1.5b
EMBEDDING_MODEL=bge-m3:567m
TOP_K=8
LLM_MAX_TOKENS=768
```

## 4. 环境自检脚本

```python
# 一键自检：环境/依赖/Ollama/模型
import sys, os
import langchain, ollama, faiss, fitz, streamlit, jieba
import urllib.request, json
print("python:", sys.version)
print("langchain:", langchain.__version__)
tags = json.load(urllib.request.urlopen("http://localhost:11434/api/tags"))
print("ollama models:", [m["name"] for m in tags["models"]])
```

输出应包含 `bge-m3:567m` 与 `deepseek-r1:1.5b`，表示环境就绪。

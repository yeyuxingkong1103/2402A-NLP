## 二、在线问答全链路时序图

```mermaid
sequenceDiagram
    participant U as 用户
    participant S as Streamlit :8503
    participant A as FastAPI :8003
    participant M as 多语言层
    participant R as 路由器
    participant E as 检索引擎
    participant V as Milvus
    participant X as Reranker
    participant L as DeepSeek

    U->>S: 输入问题（中/英）
    S->>A: POST /api/v3/ask
    A->>M: 语言检测
    alt 英文问题
        M->>L: 翻译为中文
        L-->>M: 中文查询
    end
    M->>R: 路由判定
    R-->>A: text_only/table_only/hybrid
    alt table_only
        A->>E: TableRetriever 检索
        E->>V: rag_tables 向量+关键词
    else hybrid
        A->>E: 文本+表格双检索
        E->>V: rag_chunks + rag_tables
        E->>E: RRF 融合(k=60)
    else text_only
        A->>E: TextRetriever 检索
        E->>V: rag_chunks 向量+BM25
    end
    V-->>E: 候选 chunks
    E->>X: rerank
    X-->>E: top5
    E->>L: 表格感知 prompt
    L-->>A: 答案（与提问同语言）
    A-->>S: answer+references+latency
    S-->>U: 答案+表格MD+引用+反馈按钮
```

## 三、离线表格解析流程图

```mermaid
flowchart LR
    PDF["招股说明书 PDF"] --> OPEN["PyMuPDF 打开"]
    OPEN --> PG["逐页遍历"]
    PG --> Q1{"有文本层?"}
    Q1 -->|是| TXT["抽取文本 chunk"]
    Q1 -->|否扫描页| OCR["PaddleOCR (.venv-mineru-paddle)"]
    OCR --> TXT
    PG --> Q2{"检测到表格线条?"}
    Q2 -->|是| PL["pdfplumber extract_table"]
    Q2 -->|疑似| CM["camelot lattice/stream"]
    PL --> RAW["原始行数据"]
    CM --> RAW
    RAW --> MG["合并单元格推断"]
    MG --> HD["多级表头识别"]
    HD --> CP{"与上表连续?"}
    CP -->|是| MERGE["跨页合并+表头继承"]
    CP -->|否| ST["独立结构化表"]
    MERGE --> ST
    ST --> JT["JSON 结构化"]
    ST --> TT["table-to-text 自然语言"]
    TXT --> E1["bge-m3 嵌入 → rag_chunks"]
    TT --> E2["bge-m3 嵌入 → rag_tables"]
```

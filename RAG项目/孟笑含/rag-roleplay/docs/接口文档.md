# RAG 角色扮演系统 · 接口文档

- 版本：v0.2.0（对应 git tag `rag-prompt-v3-prod` 之后的当前代码）
- 协议：HTTP + JSON（UTF-8）；流式接口使用 SSE
- 在线调试：启动服务后访问 `http://<host>:8000/docs`（Swagger UI，与本文档同步）
- 认证：除注册/登录外，所有接口需请求头 `X-Token: <注册/登录返回的 token>`（7 天有效，存于 Redis）

## 通用约定

**错误响应格式**（所有非 2xx）：

```json
{ "detail": "错误描述" }
```

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 请求参数/文件不合法（重名、非 PDF、PDF 无文本等） |
| 401 | 未登录或 token 过期 |
| 404 | 资源不存在（角色等） |
| 422 | 请求体字段校验失败（pydantic，detail 含字段信息） |
| 500 | 服务内部错误 |

## 1. 用户

### 1.1 注册 POST /api/users/register

**请求体**：

```json
{ "username": "alice", "password": "secret123" }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| username | string | 是 | 2~64 字符，唯一 |
| password | string | 是 | 6~64 字符（服务端仅存哈希） |

**响应 200**：

```json
{ "id": 1, "username": "alice", "token": "02346d548ba6..." }
```

**错误**：`400` 用户名已存在；`422` 字段校验失败。

### 1.2 登录 POST /api/users/login

**请求体**：同注册（`username` + `password`）。

**响应 200**：同注册，返回新 token。

**错误**：`401` 用户名或密码错误。

## 2. 角色管理（需 X-Token）

### 2.1 角色列表 GET /api/roles

**响应 200**：

```json
[
  {
    "id": 1, "name": "小阳", "category": "虚拟朋友",
    "persona": "你是用户的好朋友小阳……",
    "prompt_template": "你正在扮演「{role_name}」……"
  }
]
```

### 2.2 创建角色 POST /api/roles

**请求体**：

```json
{
  "name": "李律师", "category": "律师",
  "persona": "执业律师，熟悉民商事法律……",
  "prompt_template": "你正在扮演「{role_name}」……"   // 可选，缺省用默认模板
}
```

**响应 200**：返回创建后的角色对象（同列表项，含 id）。**错误**：`400` 角色名已存在。

### 2.3 更新角色 PUT /api/roles/{role_id}

**请求体**：任意字段的部分更新（name/category/persona/prompt_template 均可选）。

**响应 200**：更新后的角色对象。**错误**：`404` 角色不存在。

### 2.4 删除角色 DELETE /api/roles/{role_id}

**响应 200**：`{ "ok": true }`。**错误**：`404` 角色不存在。

## 3. 对话（需 X-Token）

### 3.1 非流式对话 POST /api/chat

**请求体**：

```json
{ "role_id": 2, "content": "高血压的诊断标准是什么？", "use_rag": true }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| role_id | int | 是 | 角色 ID |
| content | string | 是 | 用户输入 |
| use_rag | bool | 否 | 默认 true；false 跳过知识库检索 |

**响应 200**：

```json
{
  "role_id": 2,
  "reply": "在未使用降压药物的情况下，非同日3次测量……",
  "sources": ["高血压诊断标准：在未使用降压药物的情况下……"]
}
```

`sources` 为本次检索注入的引用来源（知识块原文）；未检索或检索为空时是 `[]`。

对话自动携带**长期记忆**：每轮对话沉淀到 Milvus 记忆库（`user_memory_{user_id}_{role_id}`），下次对话检索相关记忆注入提示词【长期记忆】段（`LONGTERM_MEMORY=false` 可关闭）。

**错误**：`404` 角色不存在；`401` 未登录。

### 3.2 流式对话 POST /api/chat/stream

请求体同 3.1。响应 `Content-Type: text/event-stream`，事件序列：

```
data: {"delta": "在未使用降压"}       ← 每次一段文本
data: {"delta": "药物的情况下……"}
data: {"sources": ["知识块1", "知识块2"]}   ← 可选，有检索时才有
data: [DONE]                          ← 结束
```

客户端拼接所有 `delta` 即完整回复。

### 3.3 历史记录 GET /api/chat/history?role_id=2

**响应 200**（按时间升序，MySQL 全量持久化）：

```json
[
  { "id": 1, "sender": "user", "content": "你好", "created_at": "2026-09-15T12:00:00" },
  { "id": 2, "sender": "assistant", "content": "你好呀……", "created_at": "2026-09-15T12:00:03" }
]
```

## 4. 知识库（需 X-Token）

### 4.1 上传文档 POST /api/knowledge/upload?role_id=2

`multipart/form-data`，文件字段名 `file`，支持 **PDF**（解析+表格提取）与**图片**（JPG/PNG，RapidOCR 文字识别）：

```bash
curl -X POST "http://127.0.0.1:8000/api/knowledge/upload?role_id=2" \
  -H "X-Token: $TOKEN" -F "file=@高血压指南.pdf"
```

**响应 200**：

```json
{ "source": "高血压指南.pdf", "chunks": 12 }
```

上传即完成：PDF 走**自动去水印** → 解析 → 表格提取；图片走 **RapidOCR 文字识别** → 清洗 → 分块 → BGE-m3 向量化 → 写入 Milvus（含 BM25 稀疏向量），入库后立即可检索。开关：`.env` 的 `PDF_REMOVE_WATERMARK`（默认 true）。

**错误**：`400` 非 PDF 文件 / 文件为空 / PDF 无可提取文本；`404` 角色不存在。

### 4.2 文档列表 GET /api/knowledge/docs?role_id=2

**响应 200**（`summary` 为该文档第一个知识块的抽取式摘要）：

```json
[
  {
    "source": "高血压指南.pdf",
    "chunks": 12,
    "summary": "高血压健康管理知识文档（示例知识文档……",
    "updated_at": 1789460205
  }
]
```

### 4.3 删除文档 DELETE /api/knowledge/doc?role_id=2&source=高血压指南.pdf

**响应 200**：

```json
{ "source": "高血压指南.pdf", "removed": 12 }
```

删除立即生效（知识库动态更新），该文档的所有知识块不再参与检索。

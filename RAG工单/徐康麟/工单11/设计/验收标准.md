# 工单11 验收标准

> 对齐原文《验收标准》：「微调后的 Embedding 模型的检索效果比微调前要好，要有数据指标支撑」。

## 1. 硬性验收项（逐条可核验）

| # | 验收项 | 判定标准 | 核验方式 | 状态 |

## 2. 数字真实性与禁止事项

1. 报告中每个数字必须可追溯到 `json / jsonl / csv / log / npy` 产物文件，截图页脚标注来源。
2. **若 A12 未达成**：必须在 `优化/微调优化说明.md` 与 `测试/测试报告.md` 中如实写明「未提升」+ 根因分析（数据量小 / 底座弱 / 负例太易 / 训练预算不足）+ 下一步方案，**禁止编造提升数字**。
3. 抽样口径必须显式声明（训练降采样 1400 三元组、检索池抽样 2500 块）。
4. 工单1、工单7 目录只读，不得写入。

## 二、进阶表格解析工具

### 2.1 camelot-py (推荐)
```bash
pip install camelot-py[cv]
```
- 可处理 pdfplumber 失败的复杂表格 (有横线/竖线分割)
- `lattice` 模式解析有线表格, `stream` 模式解析无线表格
- 自动识别跨页表格

```python
import camelot
tables = camelot.read_pdf("招股说明书2.pdf", flavor="lattice", pages="all")
for t in tables:
    df = t.df  # pandas DataFrame, 直接结构化
```

### 2.2 pdfminer.six (底层替代)
pdfplumber 基于 pdfminer.six, 直接用 pdfminer 可做更精细的表格检测。

### 2.3 表格理解模型 (AI 方案)
- **Table Transformer** (Microsoft): 表格结构识别 SOTA
- **PaddleOCR + PaddleTable**: 百度开源, 中文表格识别好
- **Nougat** (Meta): 端到端学术文档理解

## 四、多文档路由策略

当前策略:
```
query → 公司名匹配 → 限定文档范围 → 表格/文本检索
```

进阶策略:
```
query → 意图分类(表格/文本) → 文档路由 → 意图专用检索 → 结果融合
        ↑____________________________↑
        意图分类可用 LLM zero-shot 或 TF-IDF
```

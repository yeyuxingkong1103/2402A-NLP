# 优化方案文档

> 工单编号：人工智能NLP-RAG-金融问答系统部署

---

## 一、优化背景

将 RAG 金融问答系统部署为 Docker 容器，需解决以下问题：
1. 镜像体积过大（模型打包进镜像）
2. Milvus 启动慢导致应用连接超时
3. 容器重启后数据丢失
4. 容器间网络不通
5. 中文乱码

---

## 二、镜像构建优化

### 2.1 多阶段构建

**优化前**：单阶段构建，镜像包含编译工具和依赖缓存，体积 > 2GB。

**优化后**：多阶段构建，运行阶段仅保留必要文件。

```dockerfile
# 构建阶段
FROM python:3.10-slim AS builder
WORKDIR /app
COPY requirements.txt .
RUN pip install --user --no-cache-dir -r requirements.txt

# 运行阶段
FROM python:3.10-slim
WORKDIR /app
COPY --from=builder /root/.local /root/.local
COPY src/ .
ENV PATH=/root/.local/bin:$PATH
```

### 2.2 模型文件外置

**优化前**：模型文件打包进镜像，镜像体积 > 10GB。

**优化后**：模型文件通过 Docker 卷挂载，镜像体积 < 2GB。

```yaml
volumes:
  - rag-models:/models
```

### 2.3 依赖缓存

利用 Docker 层缓存，仅在 requirements.txt 变化时重新安装依赖。

```dockerfile
COPY requirements.txt /app/requirements.txt
RUN pip install -r /app/requirements.txt
COPY src/ /app/src/
```

## 三、启动顺序优化

### 3.1 问题

Milvus 需要等 etcd 和 minio 就绪后才能启动，而 `depends_on` 只保证启动顺序。

### 3.2 解决方案

在 `entrypoint.sh` 中添加就绪检测：

```python
from pymilvus import MilvusClient
import time, sys

for i in range(30):
    try:
        client = MilvusClient(uri="http://milvus:19530")
        print("Milvus 就绪")
        break
    except Exception:
        print(f"等待 Milvus... ({i+1}/30)")
        time.sleep(5)
else:
    print("Milvus 连接超时")
    sys.exit(1)
```

## 四、数据持久化优化

### 4.1 Docker 卷

| 卷名 | 用途 | 备份策略 |
|------|------|----------|
| `milvus-data` | 向量索引 | 每日全量备份 |
| `rag-data` | PDF 数据 | 实时同步 |
| `rag-models` | 模型权重 | 一次性备份 |
| `rag-logs` | 运行日志 | 轮转 + 归档 |

### 4.2 自动备份脚本

```bash
#!/bin/bash
# backup.sh - 每日自动备份
BACKUP_DIR=/backup/$(date +%Y%m%d)
mkdir -p $BACKUP_DIR

for vol in milvus-data rag-data rag-models; do
    docker run --rm -v $vol:/data -v $BACKUP_DIR:/backup alpine \
        tar czf /backup/$vol.tar.gz -C /data .
done
```

## 五、网络优化

### 5.1 自定义网络

使用 bridge 网络，容器间通过服务名通信：

```yaml
networks:
  rag-net:
    driver: bridge
```

### 5.2 与外部服务集成

如需与 RTMP 服务器等外部服务通信，将其加入同一网络：

```bash
docker network connect rag-net rtmp-server
```

## 六、性能优化

### 6.1 资源限制

```yaml
rag-app:
  deploy:
    resources:
      limits:
        cpus: '4'
        memory: 8G
      reservations:
        cpus: '2'
        memory: 4G
```

### 6.2 GPU 加速

```yaml
rag-app:
  deploy:
    resources:
      reservations:
        devices:
          - driver: nvidia
            count: 1
            capabilities: [gpu]
  environment:
    - EMBED_DEVICE=cuda
    - RERANK_DEVICE=cuda
```

### 6.3 健康检查

```dockerfile
HEALTHCHECK --interval=30s --timeout=10s --start-period=60s --retries=3 \
    CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:8000/api/health')"
```

## 七、安全优化

### 7.1 非 root 用户运行

```dockerfile
RUN useradd -m appuser
USER appuser
```

### 7.2 环境变量管理

敏感配置通过 `.env` 文件注入，不写入镜像：

```yaml
environment:
  - LLM_API_KEY=${LLM_API_KEY}
```

### 7.3 只读文件系统

```yaml
read_only: true
tmpfs:
  - /tmp
```

logging:

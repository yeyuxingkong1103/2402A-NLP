## 2. Python 接口（模块级）

### 2.1 配置 `config.Config`

```python
cfg = Config()                       # 自动读取 部署/配置/{路径,超参}.json
cfg.path("语料分块")                  # -> Path（相对路径按仓库根解析）
cfg.hyper_get("训练", "学习率")        # -> 3e-05
cfg.ensure_dirs()                    # 创建全部输出目录
```
环境变量覆盖：`WO11_CHUNKS` / `WO11_INDEX_DIR` / `WO11_QUESTIONS` / `WO11_BASE_MODEL` / `WO11_OUT_DIR`。

### 2.2 数据集 `generate_dataset.build_dataset(cfg) -> dict`

产出：`研发/data/dataset/{train,dev,test}.jsonl`、`留出测试集.jsonl`、`数据集统计.json`。
记录 schema 见 `设计/微调方案设计.md` §1。

### 2.3 损失 `losses.build_loss(cfg_loss) -> (nn.Module, kind, desc)`

```python
loss, kind, desc = build_loss(cfg.hyper["损失函数"])
# kind ∈ {triplet, cosine, contrastive, matryoshka-triplet, combined}
# triplet:  loss(a, p, n)            -> Tensor(标量)
# cosine:   loss(a, b, score)        -> Tensor(标量)
# combined: loss.triplet / loss.cosine / loss.w_t / loss.w_c
```

### 2.4 编码器 `encoder.EmbeddingModel`

```python
m = EmbeddingModel(model_dir, max_length=128, trainable_layers="最后2层+池化", device="cpu")
m(torch_ids, torch_mask)              # -> (B, 512) L2 归一化 CLS 向量
m.encode(texts, batch_size=32)        # -> np.ndarray (N, 512)，OOM 自动折半重试
m.apply_freeze_policy("最后2层+池化")   # -> {"可训练参数":6574144, "总参数":23953920, ...}
m.save(out_dir, meta={...})           # 落盘 + sentence-transformers 兼容结构 + 微调信息
```

### 2.5 训练 `train.train(cfg, *, 最大步数=None, 批大小=None, 学习率=None, 损失类型=None, 输出目录=None, 静默=False) -> dict`

返回训练摘要（步数、轮次、初始/末段损失、下降比例、耗时、停止原因），并写出：
`研发/data/train_log.jsonl`、`研发/data/loss_curve.png`、`研发/data/finetuned/训练摘要.json`。

### 2.6 指标 `evaluator`

```python
retrieval_metrics(ranks, ks=(1,5,10), ndcg_k=10)  # Recall@K / MRR / nDCG@K / 平均命中排名
similarity_stats(pos_sims, neg_sims)              # 正例均值 / 负例均值 / 间隔 / 判别准确率
bootstrap_ci(values)                              # 自助法 95% CI
```

### 2.7 评估 `evaluate.compare(cfg, 跳过端到端=False, 缓存向量=True) -> dict`

产出：
- `研发/评估/评估结果_微调前.json`、`评估结果_微调后.json`
- `优化/评估结果/对比表.csv`、`逐query检索对照.csv`、`对比.json`

## 4. 错误处理约定

| 场景 | 行为 |
| --- | --- |
| 语料行 JSON 损坏 | 跳过并计入 `语料损坏行数`，不中断 |
| 模型目录缺失 | 该侧评估跳过并打印警告，其余继续 |
| CPU 内存不足（编码） | 自动折半批大小重试，必要时降到 1 |
| 训练异常中断 | 落盘检查点 + 训练摘要，异常继续抛出 |
| 超出时间预算 | 停止训练、保留已完成步数与检查点，记录 `停止原因` |
| Ollama/网络不可用 | 参照列留空并打印警告（默认已关闭该参照） |

# 部署文档 — 金融问答系统

> 工单编号：人工智能NLP-RAG-金融问答系统部署

## 一、环境要求

| 组件 | 版本 |
|------|:---:|
| Python | 3.12 |
| Docker | 20.10+（可选） |
| 内存 | ≥16GB |
| GPU | 推荐 ≥8GB 显存 |
| 磁盘 | ≥20GB |

## 二、部署方式

### 方式 1：Docker 部署

构建：docker build -t rag-qa:latest .

运行：
docker run -d --name rag-qa-service -p 6006:6006 -v rag_data:/app/data -v rag_models:/app/models -v rag_logs:/app/logs -e HF_ENDPOINT=https://hf-mirror.com rag-qa:latest

### 方式 2：docker-compose

docker-compose up -d
docker-compose logs -f

### 方式 3：手动部署（AutoDL 等无 Docker 环境）

chmod +x deploy.sh
./deploy.sh

## 三、验证清单

| 项 | 命令 | 预期 |
|---|------|------|
| 容器运行 | docker ps | 状态 Up |
| 端口监听 | netstat -tlnp | LISTEN 6006 |
| Web 访问 | curl http://localhost:6006/ | HTML 响应 |
| 数据卷 | docker volume ls | rag_data 等 3 个 |
| 网络 | docker network ls | rag_net |

## 四、数据持久化

Docker 卷：
- rag_data → 输入 PDF / 图谱
- rag_models → HuggingFace 模型
- rag_logs → 服务日志

数据不丢失验证：
docker stop rag-qa-service
docker start rag-qa-service
docker exec rag-qa-service ls /app/data

## 五、容器间通信

网络：rag_net（bridge 驱动）

其他服务加入：docker network connect rag_net other-service

访问方式：
- 容器名：http://rag-qa-service:6006/
- IP：http://172.x.x.x:6006/

## 六、停止与清理

docker stop rag-qa-service
docker rm rag-qa-service
docker volume rm rag_data rag_models rag_logs

## 七、故障排查

| 问题 | 排查 |
|------|------|
| 端口占用 | lsof -i:6006 |
| 容器启动失败 | docker logs rag-qa-service |
| 模型下载慢 | 设 HF_ENDPOINT=https://hf-mirror.com |
| 显存不足 | 改 app.py 用 bge-small |

## 八、验收截图

1. 容器启动：docker ps 显示 Up
2. 服务访问：浏览器打开 6006 端口
3. 数据卷：docker volume ls 显示 3 个
4. 网络：docker network ls 显示 rag_net

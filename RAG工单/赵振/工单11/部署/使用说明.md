# 部署与使用
交付包的两个工单应放在同一级目录。环境Python3.12；训练使用CPU，无需CUDA。

```powershell
python -m pip install -r 部署/requirements.txt
ollama pull deepseek-r1:7b
ollama serve
python 研发/train.py train --epochs 5 --lr 0.000005 --batch-size 16
```

已附100条问答、400段候选及最终模型，不必重跑生成。重新生成：`python 研发/train.py prepare --total 100`；换PDF时用`--pdf-folder "PDF目录"`，同时另存旧data目录，避免旧生成记录复用。model在优化/model，可用SentenceTransformer加载；使用时需设置max_seq_length=256，并对文本与查询都归一化后计算余弦相似度。

研发/data/pages.json为两份原始PDF的已提取文本，页码均为PDF物理页。原始PDF无需复制进项目。首次加载基础模型需要联网下载moka-ai/m3e-small，或使用已有HuggingFace缓存。本次实测版本见requirements.txt，首次运行会占用下载与模型加载时间。

参考实现：[Sentence Transformers官方训练说明](https://www.sbert.net/docs/sentence_transformer/training_overview.html)。

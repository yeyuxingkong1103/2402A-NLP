## 4. 风险与对策

| 风险 | 实测/判断依据 | 对策 |
| --- | --- | --- |
| **Q6 属图内数据题，当前索引覆盖不到** | p72 的图表块内容为「插图（638×479px，**文字描述口径，未做 OCR**）」，正文/表格块中检索不到 `IC卡`、`-2.0%`（实测 3013 块中命中 0） | ① 图块 + 图注关联入检索；② 抽图后做图内文字/图例解析；③ 如实标注该题未达标并给根因，不编数字 |
| RAGAS 包缺失 | 共享约定 §2 列出缺失包；RAGAS 依赖 `pandas`/`datasets`（均缺失） | 装不上就**自实现等价指标**，并在 `设计\检索与评估方案.md` 写明口径与差异 |
| LLM 抽取慢 / 超时 | qwen2.5:3b 单次抽取受 `extract_max_tokens=1200` 限制 | 抽样 200~400 块 + 逐块 append 落盘 + 抽取缓存（`extract_cache=true`）+ 断点续跑 |
| 抽取类型漂移 | LLM 可能返回非法类型名 | `coerce_type()` 吸附到合法类型；`relation_allowed()` 校验头尾约束；非法项计数入报告 |
| 别名碎片化 | 同一主体多种写法（本公司/发行人/力源信息…） | `normalize_name` → `resolve_alias`（18 条别名表）→ `char_similarity ≥ 0.82` 二次归并 |
| 全量建图超预算 | 3013 块 × 单块 1 次 LLM 调用 | **硬性抽样**：`sample_size=400`、`sample_seed=20250826`，绝不跑全量 |
| 页号口径不一致 | 问题集 `expected_pages` 与分块 `page` 存在 ±1 偏差（例：id 5 问题集记 p39，实际命中块 `招股说明书2pd-p40-text-81`） | 对比脚本按 ±1 页容差判定，并在报告中注明 |

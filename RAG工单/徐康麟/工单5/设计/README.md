## 三、五条最容易被踩的红线（详见 `环境事实.md`）

1. **`pip install` 的落点是 `工单1\.venv\Lib\site-packages`** → 禁止直接 pip 装包，用 `--target 研发/第三方库`。
2. **一律经 `run_py.ps1` 调解释器**（它强制 `PYTHONDONTWRITEBYTECODE=1`，防止 `.pyc` 写进只读的工单1）。
   本机唯一可用解释器是 `E:\gao6gongdan\工单1\.venv\Scripts\python.exe`（Python 3.11.15）。
3. **引用只认 1-based 物理页码**；两份 PDF 的印刷页码都等于「物理页码 − 1」，极易混用。
4. **延迟验收必须预热 + 独占 Ollama**；冷启动实测曾达 3430.8 ms，冷口径必违约。
5. **写文件只能用工作区**：`E:\gao6gongdan\工单5` 内。
   ⚠️ 工单5 实测补充两条：**pytest 的 `tmp_path` 与系统 `%TEMP%` 在本沙箱下不可写**
   （分别在仓库根留下删不掉的 `.pytest_tmp`、写入报 WinError 5）→ 测试里改用
   `研发/data/runtime/_pytest_tmp/`（见 `研发/tests/test_multiturn_core.py` 的 `_mk_tmp`）。

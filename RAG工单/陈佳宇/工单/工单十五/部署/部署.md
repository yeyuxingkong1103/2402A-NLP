# 工单15 优化技术图纸与文本的跨模态检索流程｜部署文档
## 1.前置依赖部署
1. RAGFlow完整docker部署正常运行（承接工单14）；
2. 测试文档`CN100347506C.pdf`已经上传知识库，使用Paper解析方案完成DeepDoc解析；OCR图纸识别完成，生成图纸‑文本绑定切片；
3. WSL虚拟环境venv_gongdan5，安装依赖`pip install transformers requests`。

## 2.实训部署步骤
1. 创建工单15完整目录，放入全部代码文件；
2. 确认RAGFlow服务正常访问；填写config.py内RAGFlow API地址、api‑key、知识库ID；
3. 确认知识库已经完成CN100347506C.pdf解析；
4. 运行批量测试脚本：`python3 test_multimodal_api.py`，输出测试报告。

## 3.关键配置说明（config.py）
- RRF融合权重：两路召回结果权重；图文场景调高增强查询支路权重；
- top_k：召回候选数量；
- enable_multimodal_rerank：跨模态重排开关；
- figure_pattern正则：识别问题图纸引用的正则规则。

## 4.运维与故障排查
1. 图文问题仍然召回不到目标图3片段：
    - 确认PDF解析完成，图纸和文本已经绑定切片；
    - 检查正则是否识别出问题中的图纸引用；打印增强查询文本；
    - 调高top_k，调高RRF增强查询支路权重；打开rerank。
2. 响应时间慢：关闭rerank做对比，rerank会增加少量耗时；控制top‑k不要过大。
3. 普通纯文本问题回答变差：调低增强查询支路RRF权重；无图纸引用的问题自动退化为原始单路检索逻辑。

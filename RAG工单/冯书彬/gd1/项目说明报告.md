# RAG 项目说明报告

## 1. 项目目标

本项目实现一个基于 PDF 文档的 RAG 问答系统。系统能够解析招股说明书类长 PDF，构建本地向量知识库，并根据用户问题检索相关内容，调用大语言模型生成答案。

## 2. 技术栈

- 页面框架：Streamlit
- RAG 框架：LangChain
- PDF 解析：MinerU
- 向量数据库：FAISS
- Embedding 模型：通义 DashScope `text-embedding-v4`
- 生成模型：通义千问 `qwen-plus`

## 3. 系统流程

1. 用户输入本地 PDF 路径或上传 PDF 文件。
2. 系统调用 MinerU 将 PDF 解析为 Markdown 文本。
3. 对超过 20 页的 PDF，系统自动按 20 页分批解析并合并结果。
4. 使用 LangChain 的文本切分器切分文档。
5. 使用 DashScope Embedding 将文本片段向量化。
6. 使用 FAISS 构建本地向量索引。
7. 用户输入问题后，系统检索相关片段。
8. 将问题和检索内容传入 Qwen，生成最终答案。

## 4. 使用方式

运行项目：

```bash
D:/AN3/python -m streamlit run app.py
```

打开页面后：

1. 确认 PDF 路径。
2. 输入页码范围，例如 `1-333`。
3. 点击“构建 / 重建知识库”。
4. 在“单问题问答”中输入问题，或上传 `questions.json` 进行批量问答。
5. 批量问答完成后下载 `answers.json`。

## 5. 文件说明

- `app.py`：项目主程序。
- `requirements.txt`：依赖列表。
- `questions.json`：批量问题文件。
- `answers.json`：批量答案输出文件，占位文件，实际答案由页面导出生成。
- `README.md`：运行说明。

## 6. 当前完成情况

项目已完成 PDF 解析、文本切分、向量检索、单问题问答、批量问答和答案导出功能。系统已支持长 PDF 自动分批解析，能够满足基于 PDF 文档的 RAG 问答系统任务要求。

### 1.3 页码约定（**字段级铁律**）

| 项 | 约定 |
| --- | --- |
| 定义 | 一切 `page` 字段 = **1-based 物理 PDF 页码**，即 `pymupdf` `doc[i]` 的 `i+1` |
| 三套编号 | ① 1-based 物理页（**唯一采用**，物理 129/130）；② 0-based 索引 `d[i]`（`d[128]`/`d[129]`）；③ 页码行（PDF1 `1-1-128` 在**页脚**、PDF2 裸数字 `'128'` 在**页眉块第 2 行**）—— ②③ 同值（= 物理 − 1），这是混用根源 |
| 取页 | `doc[page - 1]`；合法区间 `1 <= page <= doc.page_count` |
| **禁止** | ① 不得用 0-based 索引当页码；② 不得用页码行做引用，**也不得用其数值反推页码**；③ 不得写「页码行 = 物理 − 1」的通用假设（PDF1 在页脚、PDF2 在页眉块，必须**分别清洗**） |
| **清洗双判据** | 仅当「位于 PDF2 页眉块**第 2 行**」**且**「值 == 物理页 − 1」同时成立才可删除该行（captain 全量校验：PDF2 **350 页中第 2 行 ≠ 物理−1 的页数 = 0**，T2 独立复现 = 0；但 PDF2 正文存在大量合法数字行，**禁**无脑删除） |
| 跨页表 | 逻辑表块用 `page_start`/`page_end`（1-based 闭区间）；**引用页取 `page_start`**（真实物理页）；`row_pages[i]` 给出第 i 行所属物理页（用于按数据行定位引用页） |
| 校验 | 生成 `TableBlock`/`Chunk` 时断言区间，越界抛 `ChunkError`；API 返回前再校验引用页码范围 |
| 实测铁证 | 题 33/260 证据页 129（`d[128]`，`find_tables()=0`，正文含 82.10% 等）→ 同表在 130（`d[129]`）与 131（`d[130]`，续表）；题 543/531 证据页 22（`d[21]`，页码行 `1-1-21`）；题 34/793 证据页 **152（正文页，`tables=0`，引用优先）**，**表在 153（辅助）** —— 注意「表在 153」**不是**「答案在 153」 |
| 回归锚点 | 物理 **129 / 130 / 131**（正文→表头→续表）+ **152 / 153**（答案正文页 / 示意表页） |

### 1.5 异常体系（`errors.py`）

```python
# 人工智能NLP-RAG-PDF文档的表格解析及检索优化
class RagError(Exception):
    code: str            # 见 §3.3 错误码表
    stage: str           # parse|table|chunk|index|embed|retrieve|generate|citation|storage|eval|config|ui
    detail: dict[str, Any]
    def __init__(self, message: str, *, code: str = "RAG-0000", stage: str = "core",
                 detail: dict[str, Any] | None = None) -> None: ...
    def to_payload(self) -> dict[str, Any]: ...          # {"code","stage","message","detail"}
```

| 子类 | code 前缀 | 触发 |
| --- | --- | --- |
| `ConfigError` | `RAG-1xxx` | 配置非法/缺失（fail fast） |
| `PdfParseError` | `RAG-2xxx` | PDF 打不开/损坏/页数异常 |
| `TableParseError` | `RAG-21xx` | 单表归一化失败（**显式降级**为文本块） |
| `ChunkError` | `RAG-22xx` | 页码越界、元数据缺失 |
| `EmbeddingError` | `RAG-3xxx` | 嵌入服务不可用且本地降级也失败 |
| `IndexMissingError` | `RAG-31xx` | 索引文件缺失 |
| `IndexDimensionError` | `RAG-32xx` | 向量维度不匹配（**不静默截断**） |
| `RetrievalError` | `RAG-4xxx` | 检索异常（上抛由上层转「不清楚」） |
| `LLMProbeError` | `RAG-5xxx` | 后端探测失败（0.5 s 超时、不重试） |
| `LLMTimeoutError` | `RAG-51xx` | 生成超时 |
| `LLMResponseError` | `RAG-52xx` | 返回体无可用文本 |
| `CitationError` | `RAG-6xxx` | 引用非法（页码越界/块不存在/无支撑原文） |
| `AnswerError` | `RAG-6xxx` | 生成/闸门阶段致命错误 |
| `StorageError` | `RAG-7xxx` | SQLite 异常 |
| `EvalError` | `RAG-8xxx` | 评估脚本异常 |
| `LogSetupError` | `RAG-9xxx` | 日志初始化失败 |

**禁止**：`except: pass`；空 `except` 分支；把异常吞掉后退化为「成功」。允许的降级必须在日志中有 `*.degrade` 事件（含 `reason`）。

```python
@dataclass(slots=True)
class PageText:

    text: str; char_count: int
    table_count: int; has_table: bool
    parsed_at: str

@dataclass(slots=True)
class TableBlock:
    table_id: str            # "{stem}#p{page_start:04d}#t{idx:02d}"
    file_name: str
    page: int                # = page_start，**对外引用页（1-based 物理页）**
    page_start: int; page_end: int        # 跨页逻辑表块 1-based 闭区间（单页表两者相等）
    bbox: tuple[float, float, float, float]
    n_rows: int; n_cols: int              # 首页原始物理维度
    logical_cols: int                     # 归一化后逻辑列数
    header: list[str]                     # 归一化表头（续表继承自 page_start 表头）
    rows: list[list[str]]                 # 归一化数据行（无 None、无换行）
    row_pages: list[int]                  # 每行所属物理页（与 rows 等长），用于定位引用页
    markdown: str                         # 退化表为空串 ""
    title: str                            # 表标题（不得为空）
    key_numbers: list[str]                # §6.4 的关键数字
    degenerate: bool                      # 退化表标记
    continued_from: str | None            # 续表时指向上页表 table_id，否则 None
    header_inherited: bool                # 表头是否继承自上一页表
    none_cells: int                       # 归一化前 None 计数（留痕）
    notes: list[str]                      # 归一化/合并过程中的告警

@dataclass(slots=True)
class TextBlock:
    block_id: str            # "{stem}#p{page:04d}#b{idx:03d}"

@dataclass(slots=True)
class Chunk:
    chunk_id: str            # "{stem}_p{page_start:04d}_{t|x}{idx:02d}"
    file_name: str; page: int                 # = page_start（引用页，1-based 物理页）
    page_start: int; page_end: int            # 表格块可为多页；文本块两者等于 page
    type: str                                 # "text" | "table"
    section: str; content: str

    table_id: str | None
    char_count: int; order: int
    source_block_ids: list[str]
```

```python
REPO_ROOT: Path
DEFAULT_RAW_DIR: Path; DEFAULT_PROCESSED_DIR: Path; DEFAULT_INDEX_DIR: Path; DEFAULT_LOG_DIR: Path
```

| 项 | 说明 |
| --- | --- |
| `discover_pdfs` | `glob("*.pdf")` + `glob("*.PDF")` 去重，按 **文件名排序**；对每个文件计算 `size_bytes` 与 `sha256_16`（流式读取，1 MB 块）；`page_count` 与 `readable` 留待解析阶段填充（`readable` 在 `discover` 内用 `pymupdf.open` 试开并立即 `close`） |
| `discover_issuer_names` | 从每份 PDF **前 `pages` 页**用正则 `[\u4e00-\u9fa5]{2,20}(?:股份)?有限公司` 提取候选，取出现次数最多者作为该文件发行人全称；返回 `{file_name: issuer_full_name}`。用于主体类型闸门的**发行人剥离**（**禁止硬编码公司名**）。实测两文件分别得到「武汉兴图新科电子股份有限公司」与「武汉力源信息技术股份有限公司」 |
| 重名处理 | 同名文件 → `WARN` 日志 `config.duplicate_file` 并只保留第一个（不静默） |
| 空目录 | 返回 `[]` 且 `WARN`（上层必须报错，不允许对空语料「成功」） |
| 日志事件 | `func.enter`(raw_dir) / `config.discover_done`(count, files[]) / `config.duplicate_file`(file_name) / `func.exit`(count) / `func.error` |

### 3.2 `app/core/logging_conf.py`（自实现，**禁 loguru**）

```python
class StructuredLogger:
    def bind(self, **fields: Any) -> "StructuredLogger": ...
    def log_event(self, event: str, /, level: str = "INFO", **fields: Any) -> None: ...
    def enter(self, func: str, /, inputs: Mapping[str, Any] | None = None, **fields) -> "LogSpan": ...
    def error(self, func: str, exc: BaseException, /, inputs=None, elapsed_ms: float | None = None) -> None: ...

class LogSpan:                     # 由 logger.enter() 返回，配合 with 使用
    def set_output(self, output: Mapping[str, Any]) -> None: ...
    def note(self, event: str, /, **fields) -> None: ...
    def __enter__(self) -> "LogSpan": ...
    def __exit__(self, exc_type, exc, tb) -> bool: ...   # 正常→func.exit；异常→func.error 并返回 False（传播）

def setup_logging(cfg: AppConfig | None = None, *, run_id: str | None = None,
                  force: bool = False) -> StructuredLogger
def get_logger(name: str, **fields: Any) -> StructuredLogger
def summarize_input(value: Any, *, limit: int = 120) -> Any      # 摘要规则见 §4.4
def summarize_output(value: Any, *, limit: int = 8) -> Any
def mask_secret(secret: str) -> str                              # 保留前4后4
def log_call(func_name: str) -> Callable                          # 装饰器：等价于 logger.enter/exit
```

| 项 | 说明 |
| --- | --- |
| 输出 | 三文件（§5.1）：`app.log`、`error.log`、`rag_trace.jsonl`；每行一个 JSON 对象；`ensure_ascii=False` |

## 4. 日志字段规范（**冻结**）

### 4.1 公共字段（每行必填）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `ts` | str | ISO-8601 带时区（§1.4） |
| `level` | str | `DEBUG`/`INFO`/`WARNING`/`ERROR`/`CRITICAL` |
| `event` | str | 事件名（§4.2 命名族） |
| `func` | str | 产生日志的函数名 |
| `module` | str | 模块名（`pdf_parser`、`retriever`…） |
| `run_id` | str | 一次运行（进程/评估）唯一 |
| `trace_id` | str \| null | 一次问答链路唯一（非请求型事件为 null） |
| `span_id` | str \| null | 函数调用跨度（`enter` 生成，`exit` 复用） |
| `stage` | str | `parse` / `table` / `chunk` / `index` / `embed` / `retrieve` / `generate` / `citation` / `storage` / `eval` / `config` / `ui` |
| `pid` | int | 进程号 |
| `thread` | str | 线程名 |

### 4.2 事件族与专属字段

| `func.error` | 函数异常 | `inputs`、`elapsed_ms`、`error{type,message,traceback}` |

| `table.normalize` / `table.degenerate` / `table.error` | 表格 | `table_id`、`none_cells`、`n_cols`、`logical_cols`、`reason` |
| `chunker.done` | 分块 | `file_name`、`text_chunks`、`table_chunks`、`total_chars`、`elapsed_ms` |

### 4.4 摘要规则（`summarize_input` / `summarize_output`）

| 类型 | 规则 |
| --- | --- |
| str | 长度 ≤ `limit` 原样；否则 `{"chars":n,"head":"前120字","sha1":"前8位"}` |
| list/tuple | 元素数 ≤ 8 全列，否则前 8 + `"...": n-8` |
| dict | 递归摘要，键数 ≤ 12 |
| np.ndarray / list[float] | `{"shape":[...],"dtype":"float32","sample":[前3]} ` |
| Path/PdfSource/Chunk 等 | 只取关键字段（如 `chunk_id,file_name,page,type,char_count`） |
| 敏感值 | `mask_secret()` |

**禁止**：`inputs`/`outputs` 为空字典、`null` 或仅含 `{"start":true}`；日志正文只写「开始/结束」视为不合格（验收 10 与 T11 复核项）。

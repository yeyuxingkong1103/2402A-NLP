## 脚本说明

1. **data_convert.py**
IMDR 原始工业图文问答数据集，转换成 LLaMA‑Factory 支持的多模态对话数据集 json 格式；输出`llama_factory_train.json`。
2. **vlm_lora_sft.yaml**
LLaMA‑Factory 训练配置文件；基座 VLM 模型路径、LoRA 参数、图像预处理、tokenizer、学习率、epoch、数据集路径配置。
3. **run_sft.sh**
微调启动脚本，调用 llama‑factory 的 llamafactory‑cli 启动 sft 训练。
4. **eval_vlm.py**
评估脚本；

- 通用指标：BLEU，ROUGE；
- **工单重点工业专项指标：**
  - 专业术语准确率：统计标准答案内工业部件、术语是否出现在模型输出；
  - 图纸推理正确率：判断图纸相关问题回答是否符合图纸事实；
- 分别加载基线原始 VLM、LoRA 微调后 VLM，输出对比评估报告 json。

## 3. 关键实现要点

1. LoRA 微调：仅训练 LoRA 适配器，冻结 VLM 主干，减少显存消耗；target_modules 需要匹配 VLM 模型的注意力层名称。
2. 图像预处理：严格使用基座 VLM 对应的 image_processor，图片尺寸、归一化不能随意修改。
3. 多模态数据集格式：必须包含`image`字段与`conversations`对话列表字段，符合 LLaMA‑Factory 规范。
4. 评估：不能只看通用 NLP 指标；工业场景重点看术语、图纸推理两项专项指标。

##  训练正常现象判断

- loss 稳步下降，无 loss 震荡、NaN；
- 至少完整跑完 1 个 epoch；
- 输出 LoRA 适配器权重保存目录。

> 
> 故障：loss 不下降 / NaN；排查方向：学习率过大、图像预处理错误、数据集格式错误。

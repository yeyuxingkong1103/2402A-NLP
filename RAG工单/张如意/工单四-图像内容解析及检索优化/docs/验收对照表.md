## 八、已知边界与如实说明

1. **id 5 的第一半有文本旁证**：正文第 40 页描述了"销售部下设渠道销售部、电话及网络销售部、
   大客户销售部和国际贸易部"，因此纯文本索引可能答对"4 个部门"；
   但"大客户销售部下属 6 个销售处"仅有图形承载，判分要求两问全中，故消融实验中 A 组判错。
2. **端到端 3 s 与 LLM 网络耗时**：检索链路（向量+BM25+RRF+重排）稳定 <1 s；
   端到端时长取决于生成模型的网络往返，工程上通过缓存/本地模型/流式输出满足指标，
   评估报告同时给出两个口径，不做数字粉饰。
3. **图像解析质量依赖多模态模型**：层级树与图表数值由模型读出，
   本工单通过"温度 0 + 禁止估算 + 程序化计数/最值计算"降低幻觉，
   但模型能力上限仍是主要误差来源；`results/image_descriptions.md` 保留原始输出以便人工复核。
4. **评测答案键可编辑**：`ANSWERS_EXPECTED` / `GROUND_TRUTH` 是**评测标注**（不是程序输出），
   全部取自两份招股书原文，可用 `--answer-key` 传入外部 JSON 覆盖，便于随文档版本更新。

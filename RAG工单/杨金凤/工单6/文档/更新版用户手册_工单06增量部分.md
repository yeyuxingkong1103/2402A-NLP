# 用户手册（增量部分）

---

## 1. 检索策略配置

界面顶部有检索策略配置面板，可调整：

| 配置项 | 说明 |
| --- | --- |
| 检索模式 | 向量检索 / 全文检索 / 混合检索（推荐） |
| 重排算法 | BGE / TF-IDF / LLM Reranker |
| 混合权重 | 滑块 0-1，控制向量检索的占比（仅混合模式生效） |

---

## 2. 使用建议

| 场景 | 推荐配置 |
| --- | --- |
| 日常使用 | 混合检索 + BGE Reranker（默认） |
| 追求速度 | 全文检索 + TF-IDF Reranker |
| 追求精度 | 混合检索 + LLM Reranker（会慢 1-2 秒） |
| 向量为主 | 混合检索，权重滑块调到 0.8 |

---

## 3. 示例

切换检索模式后，同样的问题都能正确回答：

- 问：武汉力源信息技术股份有限公司本次发行股数是多少，占发行后总股本的比例是多少？
- 答：1,670 万股，占发行后总股本的比例为 25.04%。

# 部署 · 02 部署运行手册

> 工单编号：人工智能NLP-RAG-PDF 文档的表格解析及检索优化

---

## 1. 一键部署流程（5 步）

```powershell
# 0) 前置：启动 Ollama（另开一个终端常驻）
ollama serve

# 1) 进入工程目录并激活环境
conda activate langchain2
cd C:\Users\30274\Desktop\工单代码\工单三

# 2) 安装依赖
pip install -r requirements.txt

# 3) 拉取模型（首次）
ollama pull bge-m3:567m
ollama pull deepseek-r1:1.5b

# 4) 建库（同时构建优化前 / 优化后两个向量库）
$env:PYTHONPATH="C:\Users\30274\Desktop\工单代码\工单三"
python scripts\build_kb.py --all

# 5) 启动演示界面
streamlit run app.py
# 浏览器打开 http://localhost:8501
```

> **关于 PYTHONPATH**：工程以 `src` 为包名（`from src import config`），
> 故运行时需把工程根目录加入 `PYTHONPATH`（脚本内已 `sys.path.insert`，
> 直接运行 `scripts/*.py` 可省略；`streamlit run app.py` 建议显式设置）。

## 2. 各脚本用途与命令

| 脚本 | 命令 | 用途 | 产物 |
|---|---|---|---|
| 建库 | `python scripts\build_kb.py --all` | 构建优化前/后向量库 | `vector_db/optimized`、`vector_db/baseline` |
| 评估 | `python scripts\evaluate.py` | 14 题优化前后对比 | `output/evaluation_report.json/md` |
| 消融 | `python scripts\ablation.py` | 2×2 消融实验 | `output/ablation_report.json/md` |
| 图表 | `python scripts\make_figures.py` | 7 张评估/架构图 | `output/figures/*.png` |
| 表格统计 | `python scripts\table_stats.py` | 表格解析规模统计 | `output/table_stats.json` |
| 界面截图 | `python scripts\capture_ui.py` | 5 张界面截图 | `output/shots/*.png` |
| 视频 | `python scripts\make_video.py` | 合成演示视频 | `output/demo_video.mp4` |

**常用参数**：

```powershell
python scripts\evaluate.py --skip-llm    # 跳过耗时的 LLM 基线，仅评估检索 + 抽取式
python scripts\evaluate.py --no-warmup   # 统计含冷启动的耗时（默认预热）
python scripts\build_kb.py --force       # 强制重建向量库
python scripts\make_figures.py --only 04 # 只重绘某一张图
```

## 3. 建库耗时与规模参考

| 阶段 | 规模 | 说明 |
|---|---|---|
| PDF 解析（2 份） | 32,301 单元格 / 689 表 | PyMuPDF `find_tables` + 结构化还原 |
| 优化后分块 | 表格块 689 + 键值对块 786 + 正文块若干 | 结构感知 + 双表示 |
| 向量化 | 分批 50 条 / 次 | `bge-m3:567m`，本地 CPU |
| 优化后向量库 | `vector_db/optimized/` | `index.faiss` + `index.pkl` |
| 优化前向量库 | `vector_db/baseline/` | 表格拍平的固定切片 |

> 建库为**一次性离线操作**；向量库已随工程交付，**可跳过第 4 步直接启动界面**。

## 4. 运行方式

### 4.1 演示界面（推荐）

```powershell
$env:PYTHONPATH="C:\Users\30274\Desktop\工单代码\工单三"
streamlit run app.py
```

界面含 5 个视图（详见 [03 用户手册](03_用户手册.md)）：
优化后问答 / 优化前基线 / 前后对比 / 批量评估 / 表格解析视图。

**URL 参数直达**（便于演示与截图）：

```
http://localhost:8501/?mode=optimized&q=1     # 优化后问答，直达 Q1
http://localhost:8501/?mode=compare&q=531     # 前后对比，直达 Q531
http://localhost:8501/?mode=tables            # 表格解析视图
http://localhost:8501/?mode=batch             # 批量评估
```

### 4.2 命令行问答（Python）

```python
from src.qa_engine import QAEngine
eng = QAEngine()
r = eng.answer_optimized("武汉力源信息技术股份有限公司本次发行股数是多少，占发行后总股本的比例是多少？")
print(r.answer, r.citations, f"{r.elapsed:.3f}s")
```

## 6. 停机与清理

```powershell
# 停止 Streamlit：终端 Ctrl+C
# 停止 Ollama：任务栏退出，或
Get-Process ollama | Stop-Process

# 重建向量库（谨慎：会清空现有索引）
python scripts\build_kb.py --all --force
```

> `vector_db/` 与 `output/` 为可再生成产物；`data/` 为原始数据，请勿删除。

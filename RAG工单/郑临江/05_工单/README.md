# 工单 05：Query 理解优化（多轮对话）

**工单编号**：人工智能NLP-RAG-Query理解优化任务

## 一、项目简介

在招股说明书检索问答基础上，实现 **多轮对话** 与 **Query 理解**，
支持意图识别、消歧（指代消解）、分解与抽象，使系统能理解“他”“这个公司”
“那……呢”等指代与话题继承。

## 二、Query 理解能力

| 能力 | 说明 |
|------|------|
| 意图识别 | 关键词匹配识别问题意图（收入/标准/法人/注册资本/关联方等） |
| 消歧 | “他/这个公司/该公司”指代上一轮实体 |
| 话题继承 | “那武汉力源……呢？”切换实体并继承上一问意图 |
| 分解与抽象 | 拆解复合问题为子问题 |

## 三、演示对话

```
Q：报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
Q：他参与的哪个工程荣获了国家科技进步一等奖？          → 兴图新科
Q：这个公司的法定代表人是谁？                        → 兴图新科
Q：那武汉力源信息技术股份有限公司呢？                 → 力源信息 + 法定代表人
Q：武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？…
```

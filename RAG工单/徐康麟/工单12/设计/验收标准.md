## 3. 资源纪律核验项（`_共享约定.md` §5.5）

| # | 要求 | 判定方式 | 达标线 |
| ---: | --- | --- | --- |
| R1 | 禁 multiprocessing 系 | 搜新增源码 | 无 `multiprocessing` / `ProcessPoolExecutor` / `joblib` / `Pool(` |
| R2 | 单进程峰值 ≤ 2 GB | 安全跑监察日志 | 未越线（越线会被强杀，退出码 124） |
| R3 | 同时最多 1 个 LLM 抽取任务 | 施工记录 | 建图与评估**串行**，不并行 |
| R4 | Ollama 单模型驻留 | 检查请求体 | 每次请求带 `keep_alive`；不同时驻留 2 个模型 |
| R5 | 建图只跑小样本 | 读 `graph_meta.json` | 抽样 ≤ 400 块，**绝不 = 3013 全量** |
| R6 | 收工自检 | `Get-Process python` + 目录检查 | 无遗留 python 进程；无 `__pycache__` / `.pytest_cache` |

## 4. 一键自查命令

```powershell
cd E:\gao6gongdan\工单12

# 目录齐备
Get-ChildItem -Directory | Select-Object -ExpandProperty Name

# 设计文档 6 份 + 头部工单编号
Get-ChildItem 设计\*.md | ForEach-Object { "{0}`t{1}" -f $_.Name, (Get-Content $_.FullName -TotalCount 3 -Encoding UTF8 | Select-String '工单编号' | ForEach-Object { 'OK' }) }

# 截图命名（须全中文）
Get-ChildItem 测试\测试截图\*.png -ErrorAction SilentlyContinue | Select-Object -ExpandProperty Name

# 逐题结果行数（目标 32 = 16×2）
Get-ChildItem 优化\评估结果\逐题结果_*.jsonl -ErrorAction SilentlyContinue | ForEach-Object { "{0} -> {1} 行" -f $_.Name, (Get-Content $_.FullName).Count }

# 资源纪律：新增源码不得含进程池
Select-String -Path 研发\lightrag\*.py,研发\scripts\*.py -Pattern 'multiprocessing|ProcessPoolExecutor|Pool\(|joblib' -ErrorAction SilentlyContinue

# 收工自检
Get-Process python -ErrorAction SilentlyContinue
Get-ChildItem -Recurse -Directory -Filter '__pycache__' -ErrorAction SilentlyContinue
```

## 5. 不达标项的书写规范

任何一项做不到时，**禁止**：改小分母凑指标、把失败题剔除出统计、把自实现指标冠名成 RAGAS 官方指标、用「预计/约为」代替实测。

必须写成三行：

```
未达标项：<核验点编号 + 名称>
实测值：<真实数字 + 来源文件>
根因：<可验证的技术原因>
```

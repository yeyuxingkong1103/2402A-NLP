# 需求规格说明书（RAG 角色扮演系统）

## 1. 项目概述

基于 RAG（检索增强生成）的**多角色、多用户、多轮对话**聊天机器人系统。
用户在 Web 界面选择一个角色（医生、律师、客服、NPC、金融顾问、心理咨询师等），
系统从知识库（Milvus）检索相关文档，交给大模型以该角色的人设生成回答，并标注参考来源。

## 2. 核心需求

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-1 | 角色扮演 | 支持多种预设角色（医生/律师/客服/NPC/金融顾问/心理咨询师），可自定义提示词创建新角色 |
| FR-2 | 知识库问答 | 基于 PDF/txt/md/json 构建知识库，检索后生成带来源的回答 |
| FR-3 | 混合检索 | 向量检索（BGE-m3）+ BM25 关键词检索，多路召回后 RRF 融合 |
| FR-4 | 重排序 | 对召回结果精排（BGE-rerank，无模型时退回本地关键词精排） |
| FR-5 | 多轮对话 | Redis 保存短期记忆，支持带上下文的追问与 Query 改写（共指消解） |
| FR-6 | 长期记忆 | Milvus 保存用户画像与对话摘要，按用户隔离 |
| FR-7 | 知识库动态更新 | 支持增量添加、按来源删除、批量重建知识库 |
| FR-8 | 流式输出 | 聊天接口支持 SSE 流式返回 |
| FR-9 | 多用户 | 以 session_id 隔离会话，多用户并发互不影响 |
| FR-10 | 可观测 | 使用 python logging 输出结构化日志 |

## 3. 业务流程

```
用户提问 → Query 改写(共指消解) → 向量化(BGE-m3)
                                   ├─ 向量召回(Milvus) ─┐
                                   └─ BM25 召回(本地)  ─┤→ RRF 融合 → 相似度过滤
                                                                        ↓
用户 ← 后处理(正则) ← 大模型(角色提示词 + 上下文) ← 重排序(精排)
        ↓
   短期记忆(Redis) / 长期记忆(Milvus)
```

## 4. 业务规则

1. 回答必须基于检索到的资料；资料中没有的信息应如实说明，不凭空编造。
2. 医疗/法律/金融等专业角色必须加免责声明，不提供明确诊断/具体投资建议。
3. 检索结果先按余弦相似度阈值过滤，再做精排，最后取 top_k。
4. 同一文档重复入库按来源去重（幂等）。

## 5. 思维导图（结构）

```
RAG 角色扮演系统
├── 离线（构建知识库）
│   ├── 文档解析（PyMuPDF / pdfplumber 表格）
│   ├── 文本分块（fixed / sentence / paragraph / semantic）
│   ├── 向量化（BGE-m3）
│   └── 向量数据库（Milvus）
├── 在线（问答）
│   ├── 问题向量化 / Query 改写
│   ├── 混合检索（向量 + BM25）与多路召回
│   ├── 重排序
│   ├── 提示词模板
│   ├── 调用大模型（本地 / 在线 API）
│   └── 后处理
├── 记忆
│   ├── 短期记忆（Redis）
│   └── 长期记忆（Milvus）
└── 角色
    ├── 角色管理（创建/列表/详情）
    └── 提示词模板
```

## 6. 技术组件

大模型（DeepSeek/Qwen/豆包/本地 vLLM）、MySQL、Redis、Milvus、BGE-m3、BGE-rerank、RAGAS（评测，规划中）。

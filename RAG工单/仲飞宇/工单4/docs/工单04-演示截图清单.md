## 通用动作（每张都一样）

1. 鼠标**点一下**要拍的那个窗口，让它成为*活动窗口*
2. **`Alt + PrtSc`** —— 只截这个窗口，自带边框
3. 打开「画图」→ `Ctrl + V` → `Ctrl + S` → 存 PNG → 放进 `docs/演示截图/`

> ⚠️ 别用 `Win + PrtSc`（整屏会拍进桌面和其他标签页）。

```bash
$PY - <<'EOF'
import sys; sys.path.insert(0, '.')
from app.core.vectorstore import VectorStore
s = VectorStore()
rows = s.client.query(collection_name=s.collection,
    filter='chunk_type == "image" and page_no in [38, 71]',
    output_fields=['chunk_index','doc_name','page_label','content'], limit=10)
for r in sorted(rows, key=lambda x: x['chunk_index']):
    print('=' * 66)
    print(f"#{r['chunk_index']} {r['doc_name']} 页 {r['page_label']}")
    print(r['content'][:400])
EOF
```
要能看见页 38 的**层级结构**（销售部 → 4 个部门 → 大客户销售部 → 6 个销售处）
与页 71 的**图表数值**（汽车 14.0% / IC卡 -2.0%）—— 存 `工单4-06-图块入库证据.png`

## 四、技术方案

### 4.1 LightRAG 集成

- **LLM**：DeepSeek（OpenAI 兼容），API 不可用时降级为规则抽取
- **Embedding**：bge-m3（CPU，batch_size=8）
- **图存储**：NetworkX（持久化 graphml）
- **向量存储**：NanoVectorDB（本地 JSON）
- **实体抽取**：`entity_extract_max_gleaning=1`，`entity_extract_max_entities=40`，`chunk_token_size=1200`

### 4.2 规则抽取（离线兜底）

当 DeepSeek API 余额不足时，使用 `src/lightrag_v12/rule_based_llm.py` 基于正则抽取：
- **实体类型**：Organization / Person / MonetaryValue / Percentage / Date / ShareAmount / Location / Industry / Project
- **关系类型**：注册资本 / 法定代表人 / 控股股东 / 持股比例 / 营业收入 / 业务领域 / 参与制定 / 发行股数 / 募集资金用途 / 获奖 / 行业地位 / 所在地

### 4.3 RAGAS 评估

基于 jieba 关键词覆盖率计算（无需 LLM）：
- **faithfulness** = 答案关键词 ∩ 上下文关键词 / 答案关键词数
- **answer_relevancy** = 问题关键词 ∩ 答案关键词 / 问题关键词数
- **context_precision** = 问题关键词 ∩ 上下文关键词 / 问题关键词数
- **context_recall** = 答案关键词 ∩ 上下文关键词 / 答案关键词数

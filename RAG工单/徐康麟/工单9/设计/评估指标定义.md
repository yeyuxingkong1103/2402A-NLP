## 0. 口径声明（**最重要的一段，验收必读**）

本机**没有安装 ragas**（`_共享约定.md` §2 缺失包清单 + 实测 `import ragas` 失败），
且纪律要求禁止裸 `pip install`。因此本工单实现**自研的 RAGAS 近似器**，并且：

> ### ⚠️ 这是「关键词 / 页码近似口径」，**不是 LLM 裁判（LLM-as-a-judge）**。

**与官方 RAGAS 的逐项差异（不掩饰）**：

| 指标 | 官方 RAGAS 口径 | 本工单近似口径 | 偏差方向 |
| --- | --- | --- | --- |
| `context_precision` | LLM 逐块判「该块对回答参考是否有用」，再取 rank 加权平均 | **规则判**：块命中参考页区间（且属参考语料）**或**含 ≥1 个参考答案关键词 | 识别不出「语义相关但用词不同」的块 ⇒ **偏保守（低估）**；也不会把语义无关判成相关 ⇒ 无明显高估 |
| `context_recall` | LLM 把参考答案拆成 claims，逐条判「能否由上下文推出」 | **关键词覆盖**：参考答案的 `answer_keywords` 被上下文并集覆盖的比例 | 关键词是人工/规则整理的要点，**覆盖 ≠ 语义蕴含** ⇒ 对「表述不同但意思对」会**高估** |
| `faithfulness` | LLM 把答案拆 claims，判每条能否由上下文支持 | **数值原子 + 参考答案关键词**被上下文支持的比例 | 只看数字与关键词，不看叙述性 claim ⇒ 对定性表述**偏宽松** |
| `answer_relevancy` | LLM 由答案反推问题，算与原问题的向量相似度 | **参考答案关键词覆盖**（复用 工单7 判分口径）+ 长度合理性 | 不依赖嵌入模型、可复现；对「答非所问但含关键词」会**高估** |

**结论**：本口径适合做**同一套问题集上的优化前后对比**（同口径、可比、可复现），
**绝对值不应直接与官方 RAGAS 结果对标**。所有汇总产物都带 `口径` 字段写明这一点。

## 1. 记号与基础判定

设归一化（**直接复用 工单7 `判分.normalize`**，保证与 07/08 工单逐位可比：
全角→半角、数字间千分位逗号删除、其余标点→空格、小写化）之后：

| 记号 | 含义 |
| --- | --- |
| `C = [c₁ … c_K]` | **上下文块**列表（按检索名次排序） |
| `K = |C|` | 上下文块数 |
| `Q = {q₁ … qₙ}` | 参考答案关键词 `answer_keywords` |
| `P` | 参考页区间（`expected_pages_hint`，支持 `5-51` 与 `5-37;7-20`） |
| `F` | 参考语料文件名（`source_file`，多文件题用 `;` 分隔） |
| `contains(t,k)` | 带**数字边界**的关键词包含判定（`11.65` **不**命中 `1.65`；`18.25` **不**命中 `18.2`） |

### 1.1 上下文的两套口径（**两套都算、都报**）

| 口径 | 定义 | 角色 |
| --- | --- | --- |
| `evidence` | **进生成阶段的证据块**（`answer.evidence_chunks`） | **主口径** —— 这才是 RAGAS 语义下的 `retrieved_contexts`：真正喂给生成模型的那些块 |
| `topk` | 检索返回的 Top-K（`answer.all_chunks[:K]`，K=10） | 附口径 —— 衡量「召回池」本身的精度/召回，不受生成层选块影响 |

## 2. 公式（与实现一一对应）

### (0) 单块相关判定（`context_precision` 的判据）

```
relevant(c) = [ file(c) ∈ F  ∧  page(c) ∈ P ]   ∨   [ ∃ q ∈ Q : contains(text(c), q) ]
```

- 多文件题（`|F| == |P| > 1`）按**下标配对**：第 i 个文件只与第 i 个区间配对
  （与 工单7 `判分.page_hit` 的跨文档题语义一致）。9 份年报混排时页码无全局意义，
  **必须**同时校验文件名，否则会把别家公司同页码的块误判为相关。

### (1) `context_precision`（主口径，比例版）

```
context_precision = |{ c ∈ C : relevant(c) }| / K                （K = 0 时记 0.0）
```

### (2) `context_precision_rank`（RAGAS 原版「排序敏感」特性的规则化）

```
rel_i   = 1 if relevant(c_i) else 0
prec@i  = (Σ_{j ≤ i} rel_j) / i
context_precision_rank = Σ_i (prec@i × rel_i) / Σ_i rel_i        （Σrel = 0 时记 0.0）
```

> 自检用例：`rel = [1,1,0]` → **1.0**（相关块全在最前）；
> `rel = [1,0,1]` → **0.8333**（无关块插在中间被惩罚），而比例口径仍是 0.6667。

### (3) `context_recall`

```
merged = normalize( ⋃_{c ∈ C} text(c) )          # 上下文所有块正文的并集
context_recall = |{ q ∈ Q : contains(merged, q) }| / |Q|        （Q 为空时记 0.0）
```

### (4) `faithfulness`

```
A = 答案里的数值原子集合（金额/比例/年份，正则 _ATOM_RE）
若 A ≠ ∅:  faithfulness = |{ a ∈ A : a 的每个数字片段都出现在上下文里 }| / |A|
若 A = ∅:  faithfulness = |{ q ∈ Q : contains(normalize(answer), q) }| / |Q|   （退化口径）
```

### (5) `answer_relevancy`

```
cov          = 参考答案关键词在**答案**里的覆盖率（== 工单7 的 keyword_coverage）
length_score = 1.0              若 20 ≤ len(answer) ≤ 800
             = len(answer)/20   若 len(answer) < 20
             = 800/len(answer)  若 len(answer) > 800
answer_relevancy = 0.0          若 refused（拒答不算相关）
                 = 0.7 × cov + 0.3 × length_score    否则
```

### (6) 汇总与达标判定

- 逐题算完后取**宏平均**（macro-average，每题等权，与 RAGAS 默认一致）；
- 阈值全部来自配置（`配置.py::DEFAULTS["eval"]` / `部署/配置/优化配置.json`），**不硬编码**：

| 阈值键 | 默认值 | 含义 |
| --- | ---: | --- |
| `context_precision_target` | 0.80 | 工单硬指标 |
| `context_recall_target` | 0.90 | 工单硬指标 |
| `sla_ms` | 3000 | 工单硬指标（提问→答案） |
| `answer_len_min` / `answer_len_max` | 20 / 800 | `answer_relevancy` 的长度合理区间 |
| `relevancy_keyword_weight` | 0.7 | `answer_relevancy` 中关键词覆盖的权重 |

## 3. 响应时间口径

| 项 | 口径 |
| --- | --- |
| 度量对象 | **从用户提问到返回答案的墙钟总耗时**（`latency_ms.total`，毫秒） |
| 起点 | `OptimizedEngine.answer()` 进入 |
| 终点 | 答案文本与证据块组装完成 |
| 缓存 | **`use_cache = False`**（每题都是「用户第一次问」，**绝不允许缓存命中充数**） |
| 分段 | `retrieve` / `graph` / `generate` 三段分别记录 |
| 统计量 | 平均 / **P50 / P90 / P95** / 最大 / 最小 + **SLA ≤ 3000 ms 达标率** |
| 分位算法 | 排序后取 `idx = round(q × (n-1))`（最近秩法，与 工单8 同口径） |

## 5. 自检用例（`ragas近似.py::_selftest`）

| 类别 | 用例 | 期望 |
| --- | --- | --- |
| 比例精度 | 3 块中 2 相关 | 0.6667 |
| rank 精度 | 相关块全在最前 | 1.0 |
| rank 精度 | 无关块插在中间 | 0.8333 |
| 比例精度 | 排序不影响比例口径 | 0.6667 |
| 召回 | 3 个关键词全被上下文覆盖 | 1.0 |
| **数字边界** | 上下文含 `11.65%`，关键词 `1.65` | 召回 **0.0**（不误命中） |
| 忠实度 | 答案 3 个数值原子全在上下文 | 1.0 |
| 忠实度 | 答案含上下文没有的数字 | 0.0 |
| 相关性 | 关键词全覆盖 + 长度合格 | 1.0 |
| 相关性 | 拒答 | 0.0 |
| 跨文档配对 | 文件与页区间下标配对命中 | 精度 1.0 |
| 跨文档配对 | 文件与区间错序 | 精度 0.0 |
| 空输入 | 空上下文 / 空关键词 | 0.0（不抛异常） |
| 汇总 | 达标判定与 SLA 计算 | 与阈值一致 |

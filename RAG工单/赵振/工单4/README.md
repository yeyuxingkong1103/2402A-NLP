# 工单 04：PDF 图像内容解析及检索优化

工单编号：人工智能NLP-RAG-图像内容解析及检索优化。

在工单03的 PDF 问答基础上，用 RapidOCR 识别图表标签和数值，并保留文字在图中的位置，支持组织架构图和增长率柱图问答。图像识别在建库时执行，问答时直接检索结果。

图像部分按本机可用依赖采用 OCR 与文字框坐标配对；当前没有接入 CLIP 或多模态大模型。若验收要求必须使用这类模型，需要另行配置模型服务。

## 运行

1. 安装 Python 3.10+，在本目录运行 `python -m pip install -r requirements.txt`。
2. 把《招股说明书2.pdf》上传到网页，或保留在默认附件路径。
3. 运行 `启动网页.ps1`，浏览器打开 `http://127.0.0.1:8501`，点击“解析并建立索引”。
4. 提问：销售组织包含几个部门/销售处；2008年IC市场图中增长最快和负增长的行业是什么。

首次建库会识别图像页并建立索引；图像OCR页面为PDF物理第39、72页。

## 测试

`python test_image_parser.py` 单独验证图像识别；`python evaluate.py` 验证6道新题并附上工单1旧题回归记录。`python test_table_parser.py`、`python test_stability.py`、`python test_app_smoke.py` 检查旧功能。

测试图、源图裁剪和演示视频在 `PDF图像解析模块`、`问答引擎` 等目录。准确率用工单固定题的关键词覆盖率统计；旧题数据沿用工单2评测，未伪称本次重跑。高并发压力测试未执行。

原PDF、索引和用户反馈不会放入提交包。

# 工单13 RAG性能瓶颈识别与优化｜部署文档
## 1.本地WSL实训部署
1. 新建工单13目录，放入全部代码；
2. 激活venv_gongdan5虚拟环境；
3. 安装依赖：`pip install snakeviz locust python‑json‑logging`
4. 创建日志文件夹：`mkdir perf_logs`
5. 运行埋点RAG脚本，日志输出到perf_logs；
6. cProfile生成性能统计文件，snakeviz可视化分析；
7. locust启动负载测试，浏览器访问locust WebUI。

## 2.生产环境扩展说明
1. 生产环境建议接入OpenTelemetry分布式追踪；
2. Prometheus+Grafana采集指标，配置告警；
3. 生产环境使用k6做负载测试，locust适合实训。
4. 日志使用json结构化日志，方便日志平台解析。

## 3.运维命令
```bash
# 单次性能埋点运行
python3 rag_perf_main.py

# cProfile分析
python3 profile_analyze.py
snakeviz perf_stat.prof

# locust压测
locust -f locustfile.py
## 故障排查

1. 整体延迟高：看日志分阶段耗时，定位是哪一个模块占比最高；
2. 并发升高性能暴跌：看 CPU 内存资源占用，是否达到资源上限；
3. 网络延迟高：观察 LLM、向量库网络 IO 耗时。

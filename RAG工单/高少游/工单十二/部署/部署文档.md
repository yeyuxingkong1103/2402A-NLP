# 部署文档

- 工单编号：人工智能NLP-RAG项目-LightRAG优化
- 项目名称：RAG（招股说明书多轮检索问答系统 · LightRAG 优化）
- 交付日期：2026 年 10 月

本文档说明如何在本地环境从零部署并运行本系统（含传统 RAG 与 LightRAG 双系统）。

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（本工单实测环境：Windows 11） |
| Python | 3.10（实测 3.10；≥3.9 均可） |
| 内存 | ≥ 8 GB（向量与图谱常驻内存约 1 GB） |
| 磁盘 | ≥ 2 GB（含 PDF、向量、图谱） |
| 本地模型服务 | Ollama（离线推理） |

### 1.1 安装 Ollama 与本地模型

```bash
# 1) 安装 Ollama（https://ollama.com/download），启动服务（默认 http://localhost:11434）
# 2) 拉取嵌入模型（默认 bge-m3）与大模型
ollama pull bge-m3:567m
ollama pull deepseek-r1:1.5b

# 3) 校验
ollama list
curl http://localhost:11434/api/tags
```

> 本工单仅使用 `bge-m3`（1024 维）。如需多模型对比，可另拉 `bge-large`、`nomic-embed-text`。

## 5. 构建索引

### 5.1 构建传统 RAG 索引

```bash
python build_kb.py --rebuild --models bge-m3
```

产物：`vector_db/chunks.jsonl`、`vector_db/emb_bge-m3.npy`、`vector_db/inverted_index.pkl`、`vector_db/meta.json`。
实测：解析 898 页 → 切片 2352 + 图形语义 5 = **2357 块**（table 615 / text 1737 / figure 5），倒排词表 20629，耗时约 347s（含向量化 226s）。

### 5.2 构建 LightRAG 图谱索引（本工单核心）

```bash
python build_lightrag.py                       # 规则 + LLM（默认）
python build_lightrag.py --no-llm              # 仅规则（快速）
python build_lightrag.py --max-llm-chunks 150  # 指定 LLM 精选块数
```

产物：`graph_db/nodes.jsonl`、`edges.jsonl`、`themes.jsonl`、`entity_vectors.npy`、`relation_vectors.npy`、`theme_vectors.npy`、`graph_meta.json`。
实测：规则抽取 2357 块 → 6553 条（1.3s）；LLM 抽取 150 块 → 351 条（559s）；图谱 **实体 2167 / 关系 1327 / 主题 20**；总耗时约 857s。

> 交付包中已包含构建好的 `vector_db/` 与 `graph_db/`，**可直接运行**；如需复现请按上述命令重建。

## 6. 运行

### 6.1 启动 Web 界面

```bash
streamlit run app.py
# 浏览器访问 http://localhost:8501
```

界面左侧「检索系统」可在 **传统 RAG（向量+全文混合检索）** 与 **LightRAG（图结构双层检索）** 间切换；LightRAG 下额外展示命中的**实体/关系/主题**图证据。

### 6.2 多轮对话演示（命令行）

```bash
python run_demo.py            # 落盘 output/multiturn_demo.json
```

### 6.3 评估与测试

```bash
python tools/run_eval.py              # RAGAS 口径 RAG vs LightRAG（output/eval_results.json）
python tools/run_functional_tests.py  # 功能/容错/多语言/稳定性（output/functional_tests.json）
python tools/bench_latency.py         # 响应时间基准（output/latency_bench.json）
python tools/run_strategy_demo.py     # 检索策略对比（output/strategy_demo.json）
```

### 6.4 生成图表 / 截图 / 视频 / 文档

## 7. 常见问题（FAQ）

| 现象 | 原因 | 处理 |
|---|---|---|
| 报错 `ConnectionError` / 嵌入超时 | Ollama 未启动或模型未拉取 | 启动 Ollama，`ollama pull bge-m3:567m` |
| `Knowledge base not built` | 未构建 RAG 索引 | 运行 `python build_kb.py --rebuild` |
| 界面提示「图谱未构建」 | 未构建 LightRAG 图谱 | 运行 `python build_lightrag.py` |
| LLM 抽取很慢 | 本地 1.5B 模型 CPU 推理 | 用 `--no-llm` 仅规则，或减少 `--max-llm-chunks` |
| 端口被占用 | 8501 已占用 | `streamlit run app.py --server.port 8502` |

# 基线版本说明

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统

## 一、版本定位

本版本为**基线版本**（工单编号：人工智能NLP-RAG-基于PDF文档的问答系统），用于与后续优化版本做对比。

## 二、基线参数

| 参数 | 值 | 说明 |
|---|---|---|
| CHUNK_SIZE | 500 | 分块大小 |
| CHUNK_OVERLAP | 80 | 分块重叠 |
| TOP_K_RECALL | 10 | 每路召回条数 |
| TOP_K_RERANK | 5 | 重排保留条数 |
| SCORE_THRESHOLD | 0.30 | 分数阈值 |
| LLM_MAX_TOKENS | 2048 | LLM 最大输出 |
| LLM_TEMPERATURE | 0.3 | LLM 温度 |
| 结果缓存 | 无 | 无缓存机制 |
| 集合 | rag_pdf_qa | 单集合 |
| 文档块数 | 1405 块 | 招股说明书1.pdf |

## 三、性能基线

| 指标 | 数值 |
|---|---|
| 平均响应时间 | 16.07 秒 |
| 最快响应 | 10.15 秒 |
| 最慢响应 | 25.11 秒 |
| 关键词命中 | 22/28 |

## 四、优化方向

- 分块更细：500→400，语义更聚焦
- 召回收敛：10→6，减少重排耗时
- 精排保留：5→3，上下文更精
- 阈值下调：0.30→0.25，保住召回率
- LLM 提速：2048→768，生成更快
- 新增缓存：LRU 256 条，重复查询毫秒级
- 独立集合：新建 rag_pdf_qa_v2，前后对比

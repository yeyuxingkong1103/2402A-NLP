# 研发文档 · 多轮对话能力实现说明

> 工单编号：人工智能 NLP-RAG-Query 理解优化任务
> 目标：在招股说明书检索问答基础上，提升 PDF 文档问答系统的 **多轮对话能力**

---

## 1. 需求拆解

工单要求实现如下多轮对话：

```
Q1 报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
Q2 他参与的哪个工程荣获了国家科技进步一等奖？
Q3 这个公司的法定代表人是谁？
Q4 那武汉力源信息技术股份有限公司呢？
Q5 武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？有哪些销售处？
```

对话中隐含四类多轮现象：

| 轮次 | 现象 | 依赖的上下文 |
|---|---|---|
| Q2 | **指代消解**：「他」= 上一轮的兴图新科 | 话题公司 |
| Q3 | **指代消解**：「这个公司」= 兴图新科 | 话题公司 |
| Q4 | **省略补全**：省略谓语「法定代表人是谁」 | 上一轮意图 + 新主语公司 |
| Q5 | **跨文档切换 + 图像语义**：切换到力源信息的组织结构图 | 显式公司名 + 图形知识 |

## 2. 实现方案

### 2.1 会话状态（`src/conversation.py`）

`Conversation` 维护 `Turn` 列表，每轮记录：

```
question / rewritten / answer / doc / answer_type / entities / keywords / intent / evidence
```

派生上下文：

- `active_company`：最近一轮出现的话题公司；
- `active_doc`：最近一次命中的源文档；
- `topic_entities(window)`：最近 N 轮话题实体（检索加权用）；
- `history_text()`：历史问答文本。

### 2.2 Query 改写（`src/query_rewriting.py`）

`QueryRewriter.rewrite(question, conv)` 依据四类场景改写：

| 场景 | 触发 | 处理 |
|---|---|---|
| A 省略补全 | 「那 X 呢？」 | `f"{X}{上一轮 intent}"` |
| B 指代消解 | 命中指代词 | 指代词 → 话题公司全名 |
| C 追问补全 | 无公司、无指代、短追问 | 注入话题公司 |
| D 独立问句 | 含显式公司名 | 原样返回 |

意图骨架由 `extract_intent()` 得到（剥离公司名 / 指代词 / 套话）。

### 2.3 上下文感知检索（`src/qa_engine.py`）

改写后的独立问句进入 Query 理解与混合检索，并把 `topic_entities` 作为额外查询与
重排信号（`W_TOPIC`）注入，缓解省略式追问的信息缺失。

### 2.4 答案合成（`src/answer_builder.py`）

按答案类型分流抽取，输出答案句 + 证据（源文件 / 页码 / 片段 / 得分）：

| 类型 | 触发 | 处理 |
|---|---|---|
| 字段型 | 「法定代表人是谁」 | `_field_answer`：`字段名 + 值` 定向抽取，实体消歧 |
| 极值/枚举型 | 「哪个 X 的 Y 最多？有哪些 Y？」 | `_extremum_answer`：对「X 由 N 个 Y 构成：A、B、C」聚合出结论句 |
| 数值序列型 | 「…分别是多少」 | `_series_answer`：抽取含「分别为 / 分别是」的并列数值原句 |
| 奖项型 | 「…参与的哪个工程荣获…奖？」 | `_award_answer`：抽取「『XX 工程』…荣获…奖」完整句 |
| 通用 | 其余 | 候选句按「重排分 + 关键词/同义词/实体覆盖」打分，取头部去重拼接 |

答案文本经 `_clean_answer_text` 清洗版式噪声（章节标题、公司页眉、PDF 换行断字）。

### 2.5 Query 理解优化（本工单新增）

| 优化 | 文件 | 说明 |
|---|---|---|
| 同义词扩展 | `src/query_understanding.py` | `synonyms_of()` 按 `config.SYNONYMS` 生成跨表述扩展查询（如「军用领域」→ 国防/军方/军品） |
| 批量查询编码 | `src/retriever.py` | `_encode_queries()` 一轮多条查询合并为一次 HTTP 调用并缓存，编码耗时 ~6s → ~2.0s |
| 数值序列信号 | `src/reranker.py` | `_series_match()` 提升「分别为」句排名，受关键词/同义词覆盖门控 |
| 图形语义入库 | `src/figure_semantics.py` | 矢量组织结构图 → 「X 由 N 个 Y 构成：…」可检索文本（`kind=figure`） |
| 相关性兜底 | `src/qa_engine.py` | `MIN_ANSWER_SCORE` 门控域外问题，返回友好提示 |
| 启动预热 | `src/qa_engine.py` | `MultiTurnQA.warmup()` 消除首问冷启动 |

## 6. 工程约定

- 所有模块文件头均标注工单编号：`人工智能 NLP-RAG-Query 理解优化任务`；
- 参数集中在 `src/config.py`，支持 `.env` 覆盖；
- 依赖轻量：不引入 faiss / torch，向量走 Ollama HTTP + numpy，便于复现与部署。

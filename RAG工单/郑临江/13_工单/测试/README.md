# 测试：RAG 性能瓶颈优化

从工单根目录执行：

```powershell
python run.py --check
python run.py 研发/main.py
python run.py 测试/load_test.py
```

验证重点：查询/检索/上下文/生成/后处理五阶段计时 → 索引与缓存优化。
检查输入路径、空输入/失败日志、来源或页码（适用时）、输出内容与参考答案一致性。
原验收目标见 `../设计/项目说明.md`；模型、数据集或 API 未配置时记为未验证。
准确率和耗时必须来自实际数据，不将离线占位指标作为验收证据。

工单 13 的 load_test.py 生成 Locust/k6 脚本，不会直接执行压测；目标 API 需另行准备。

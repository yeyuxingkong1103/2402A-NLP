1. 安装Python >=3.10，创建虚拟环境
```bash
python -m venv venv_gongdan1
source venv_gongdan1/bin/activate

2.安装依赖包
pip install pymupdf sentence-transformers pymilvus flask requests

3. 本地启动 Milvus 服务，默认端口 19530

python main.py

# 工单3：基于RAG的招股说明书PDF文档问答系统
## 项目简介
本项目实现对PDF招股说明书文档（含表格）的检索增强问答（RAG）。系统读取PDF文档，将文本向量化存入Milvus向量数据库，用户通过Web页面提问，检索相关原文片段返回，支持表格类数据检索。

## 技术栈
- Python 3.12
- Flask：Web后端服务
- PyMuPDF：PDF文本解析
- Sentence-Transformers：文本向量嵌入模型 all-MiniLM-L6-v2
- Milvus：向量数据库
- HTML/CSS：前端页面

## 项目文件说明
- main.py：主程序，Flask网页服务 + PDF读取 + 向量入库 + 检索逻辑
- gen_pdf2.py：生成招股说明书PDF文件
- create_collection.py：Milvus集合创建、清理脚本
- 招股说明书2.pdf：项目测试用PDF招股说明书
- 测试截图/：测试用例网页截图

# 工单3 - 设计文档
## 1. 需求分析
### 业务需求
构建RAG问答系统，上传招股说明书PDF（包含文字+表格），用户输入自然语言问题，系统检索PDF中对应的原文内容并返回，重点支持股权、财务表格信息检索。

### 功能需求
1. PDF文档读取，提取正文与表格文本
2. 文本切块、向量化，存入向量数据库Milvus
3. Web前端页面，提供输入框提交问题
4. 向量相似度检索，返回相关原文片段并展示检索耗时

### 非功能需求
1. 检索响应速度 < 0.1秒
2. 支持WSL环境部署运行
3. 代码模块化，便于后续扩展大模型生成答案

## 2. 总体架构
整体分为四层：文档解析层 → 文本分块层 → 向量存储层 → Web交互层
1. 文档解析层：PyMuPDF读取PDF，提取全部文本内容（包含表格文字）
2. 文本分块层：固定长度滑动窗口切分文本，设置块大小512，重叠50字符
3. 向量存储层：SentenceTransformers生成向量，Milvus存储向量与原文
4. Web交互层：Flask提供接口，前端页面负责接收用户问题、展示检索结果

## 3. 数据库设计
Milvus集合名称：`rag_waterwork3`
字段：
- text：字符串，存储分块后的PDF原文
- vector：浮点向量，维度384，all-MiniLM-L6-v2向量输出

## 4. 接口设计
- GET /：首页Web页面
- POST /ask：问答接口，入参 q（用户问题），返回ans（检索结果+耗时）

## 5. 界面设计
简单网页：输入框、提问按钮、结果展示区域。

## 一句话结论

把工单7 已经跑通的 RAG 金融问答系统容器化：**同一份源码 + 索引只读卷 + 会话共享卷**，
用 `rag-api`(8200, FastAPI) 与 `rag-ui`(8201, 工单7 Web 界面) 两个服务对外，
`redis` 提供跨容器会话共享，`prometheus` 按需采集指标；
本机 Docker daemon 被沙箱拒绝，因此**配置层给真实校验证据、运行层给等价本机验证**。

## 关键事实速查

| 问题 | 答案 |
| --- | --- |
| 镜像叫什么 | `rag-finqa:1.0.0`（`部署/docker/Dockerfile`，两阶段 + 非 root + HEALTHCHECK） |
| 服务开在哪个端口 | API **8200**、UI **8201**（工单指定） |
| 索引从哪来 | 工单7 的 `研发/data/index/bge-m3_1024`（**8847 块 / 1024 维**），用目录联接复用，**未复制 1GB 数据** |
| 数据存哪 | 6 个具名卷（index/log/session/model/upload/runtime）+ Redis 卷 + 2 处绑定挂载 |
| 会话怎么共享 | Redis（实时）+ 文件卷（持久）**双写**；Redis 挂了自动降级 |
| 大模型在哪跑 | **宿主机 Ollama**（`host.docker.internal:11434`），镜像里不装 torch |
| 冷启动多久 | 基座实测 **27.3 秒**（全文索引 20.1 s + 实体标注 2.1 s + 索引载入）→ `start-period=90~150s` |
| Docker 为什么没跑起来 | `npipe:////./pipe/dockerDesktopLinuxEngine` 权限被拒 + 本会话禁止提权 → 见 `部署/过程问题记录.md` 问题1 |

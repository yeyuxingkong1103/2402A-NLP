# 部署问题记录 — 金融问答系统

> 工单编号：人工智能NLP-RAG-金融问答系统部署

## 一、环境限制

AutoDL 容器环境不支持 Docker：
- docker --version 未安装
- podman apt 源无此包

解决方案：手动部署（venv + nohup）模拟容器化

## 二、遇到的依赖问题

| 问题 | 原因 | 解决 |
|------|------|------|
| RAGAS 0.4.3 与 langchain 冲突 | 依赖版本不匹配 | 降级 ragas 到 0.1.21 |
| torch.load 要求 torch>=2.6 | CVE-2025-32434 | use_safetensors=True |
| pandas 与 numpy 2.x 不兼容 | 版本冲突 | 升级 pandas≥2.2 |
| scipy ufunc 错误 | numpy 1.x 与 scipy 1.15+ 冲突 | 升级 numpy 到 2.x |
| faiss-cpu 1.7.4 无 Python 3.12 wheel | 版本太旧 | 升级 faiss-cpu≥1.8 |
| langchain-core 版本冲突 | langchain-huggingface 强制 1.6.5 | 回退到 0.2.43 |

## 三、Docker 部署（方案 A）

在有 Docker 的机器上：

构建：docker build -t rag-qa:latest .

运行：docker run -d --name rag-qa-service -p 6006:6006 -v rag_data:/app/data -v rag_models:/app/models -v rag_logs:/app/logs rag-qa:latest

验证：
docker ps
docker logs rag-qa-service
curl http://localhost:6006/
docker volume ls
docker network ls

## 四、手动部署（方案 B，AutoDL）

执行：chmod +x deploy.sh && ./deploy.sh

脚本步骤：
1. 创建 logs/models/data 目录
2. 创建 venv 虚拟环境
3. 安装 requirements.txt
4. 设置环境变量（HF_HOME / HF_ENDPOINT）
5. nohup 后台启动 app.py
6. 健康检查

验证：
cat logs/app.pid
tail -f logs/app.log
curl http://localhost:6006/

## 五、Docker 与手动部署映射

| Docker 概念 | 手动模拟 |
|------------|---------|
| 镜像 | venv + requirements.txt |
| 容器 | Python 进程（PID） |
| 端口映射 | app.py 里的 6006 |
| 数据卷 | data/models/logs 目录 |
| 环境变量 | export HF_HOME 等 |
| 网络 | localhost |
| docker stop | kill $(cat logs/app.pid) |
| docker logs | tail logs/app.log |

## 六、结论

| 项 | AutoDL 环境 | 支持 Docker 的环境 |
|---|:---:|:---:|
| Dockerfile | 已提供 | 可直接用 |
| docker-compose.yml | 已提供 | 可直接用 |
| deploy.sh | 真实运行 | 备用 |
| 服务访问 | http://127.0.0.1:6006 | 支持 |
| 数据持久化 | data/models/logs | Docker 卷 |

启动步骤
1. 将招股说明书.pdf 放在项目根目录
2. 修改 main.py 中 DeepSeek API Key 为自己的密钥
3. 启动程序
python main.py
1. 浏览器访问：[http://127.0.0.1:7860](http://127.0.0.1:7860)
2. 在网页输入问题，提交问答，页面展示大模型回答与检索原文

功能说明
1. PDF 自动读取、文本提取、文本分块
2. all-MiniLM-L6-v2 模型生成文本向量
3. Milvus 向量数据库进行向量存储与相似度检索
4. Web 页面输入问题，召回相关文档片段
5. 调用 DeepSeek 大模型，基于召回的上下文生成答案
6. 页面同时展示：大模型回答、检索到的原文片段，便于校验

测试示例
提问	回答
公司 2024 年归母净利润是多少？	2024 年归母净利润 6.20 亿元

## 硬性要求 1 · 三种检索策略的配置与应用

| 子要求 | 落实 | 证据 |
| --- | --- | --- |
| （1）向量检索（召回 + Reranker 重排） | `strategy="vector"`：bge-m3 稠密召回 → **真实 Reranker 模型推理** → top_k_rerank | `src/strategies.py`；界面「🔀 检索策略」页 |
| （2）全文检索（倒排索引 / 布尔 / 短语 / 模糊 / 多字段） | 自研位置倒排索引 `src/fulltext.py`：`AND/OR/NOT`、`"短语"`、`词~`（编辑距离1）、`title:/body:/summary:` | 语法演示区；`tests/test_fulltext.py`（19 项） |
| （3）混合检索（两路 + 融合 + **必须精排**） | `strategy="hybrid"`：dense ∥ fulltext → RRF/加权平均/投票 → **Reranker 精排** | `src/strategies.py` + `src/fusion.py` |
| 支持多种嵌入模型 | 3 个（bge-m3 / bge-m3-ft-v1 / miniLM-L6），一个模型一个 collection | `config.EMBEDDING_MODELS`、`config.collection_name()` |
| Reranker ≥2 种且可切换 | 3 个（bge-reranker-v2-m3 / v2-m3-ms / **bge-reranker-base**） | `config.RERANKER_MODELS`；界面下拉 |
| ≥3 种重排算法 | 4 种：`model`（生产默认）/ `llm` / `tfidf` / `adaptive`（用户反馈自适应） | `src/rerankers.py`；`tests/test_rerankers.py` |
| 配置项：Top K / top_k_recall / top_k_rerank / Score 阈值 / Reranker 开关 | 全部可配，界面实时生效 | `RetrievalConfig`、`src/runtime.py` |
| 权重可调 | 向量/全文权重（0~1），两种归一化口径（见技术文档 §4.1） | 界面滑块；`docs/03` §3.2 |

## 硬性要求 2 · Reranker 精排专项

| 要求 | 落实 | 证据 |
| --- | --- | --- |
| 真实加载推理（不用规则冒充） | Cross-Encoder `from_pretrained` → `model(**enc)` → sigmoid 打分 | `src/rerankers._rerank_model` |
| 先用 Step 1 确认本机模型 | 扫描确认 3 个 Reranker 权重 | `docs/01` §2/§3 |
| `local_files_only=True` 加载 | 是 | `src/rerankers._load_once` |
| 输入 (query, passage)、按分降序 | 是（含打平用 RRF 裁决的 tie-break） | `_sort_with_tiebreak` |
| **记录并展示：候选数 / 精排耗时 / 前后 Top-K 变化** | 每次检索返回 `info.rerank.{n_in, elapsed_ms, rank_changes, n_changed, degraded}`；界面「🎯 精排报告」 + 名次变化表；报告逐题给出 | `docs/04` 每题「过程观测」条 |
| 精排不静默降级 | 失败/超时会标注 `degraded + degrade_reason`，界面与报告可见 | `docs/07` 容错清单 #4/#8 |

**实测**：混合检索精排候选 28~41 条（`ARM_QUOTA=20` 保底 + `RERANK_MAX_IN=60`），
GPU 上精排 379ms（均值）。

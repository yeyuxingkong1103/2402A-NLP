# 工单10 Docker部署说明

## 1. 服务器要求

- 64位Linux服务器，建议2核CPU、4GB内存、10GB可用磁盘。
- Docker Engine 24或更高版本。
- Docker Compose v2。
- 安全组或防火墙允许TCP 8021端口。

不需要在服务器安装Conda、Python依赖、MinerU或FAISS。

## 2. 配置DeepSeek

打开项目根目录的`.env`：

```text
DEEPSEEK_API_KEY=
```

把Key填写在等号后面。留空时系统仍可运行，会返回GraphRAG证据摘要。

`.env`已写入`.dockerignore`，不会进入镜像；Compose只在容器启动时注入它。

## 3. Linux服务器一键部署

把整个项目目录上传到服务器后执行：

```bash
cd CCF年报GraphRAG-工单10
chmod +x deploy.sh
./deploy.sh
```

部署成功后访问：

```text
http://服务器IP:8021/
```

## 4. Windows Docker Desktop部署

在项目目录打开PowerShell：

```powershell
.\deploy.ps1
```

访问`http://127.0.0.1:8021/`。

## 5. 分步命令

```bash
docker compose config
docker compose build
docker compose up -d
python3 container_check.py --base-url http://127.0.0.1:8021
docker compose ps
```

## 6. 运维命令

```bash
# 查看状态
docker compose ps

# 查看最近日志
docker compose logs --tail=200 rag

# 持续查看日志
docker compose logs -f rag

# 重启
docker compose restart rag

# 停止并删除容器（索引仍在项目目录中）
docker compose down

# 更新代码后重新构建
docker compose up -d --build
```

## 7. 验收标准

`container_check.py`会自动验证：

1. `/api/health`返回`ready=true`；
2. 4道参考题全部完成；
3. Context Precision不低于0.8；
4. Context Recall不低于0.9；
5. 每道题响应时间不超过3秒。

脚本失败会返回非零退出码，适合服务器发布流程或CI使用。

## 8. 容器管理规范

- 固定容器名：`financial-graphrag-workorder10`。
- 固定镜像名：`financial-graphrag:workorder10`。
- 以UID 10001的非root用户运行。
- 根文件系统只读，仅`/tmp`使用受限临时文件系统。
- 禁止容器提权，限制2核CPU和2GB内存。
- 自动健康检查，异常时由`restart: unless-stopped`策略恢复。

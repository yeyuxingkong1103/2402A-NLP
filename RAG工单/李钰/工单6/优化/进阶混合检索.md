## 五、混合检索进阶策略

### Query 分类 → 策略选择
```python
def classify_query(query):
    if has_numbers(query) or has_keywords(query):
        return "fulltext"   # 精确数值 → 全文
    elif has_terms(query) or semantic_ambiguous(query):
        return "hybrid"     # 语义模糊 → 混合
    else:
        return "vector"     # 通用 → 向量
```

### 多路召回 + 精排
```
向量召回 Top-50
全文召回 Top-50
  → 合并去重 ~80 条
  → CrossEncoder 重排 → Top-20
  → LLM Rerank → Top-5
```

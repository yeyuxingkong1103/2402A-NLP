# 系统演示步骤（演示视频脚本）

# 工单四 图像内容解析及检索优化

> 说明：当前交付环境无法直接录制视频，本文件以**分镜脚本**形式给出演示全流程；
> 按本脚本逐步操作即可完整复现视频内容（建议录屏时长约5分钟）。

- 演示环境：Windows + Python 3.12（Anaconda），纯CPU、全程离线
- 工作目录：`RAG工单四\02_研发\src`
- 演示数据：`招股说明书1.pdf`（兴图新科，548页）、`招股说明书2.pdf`（力源信息，350页）

---

## 分镜0｜环境与离线声明（约30秒）

- 镜头：打开文件资源管理器展示 `RAG工单四` 目录结构（01_设计 / 02_研发 / 03_测试 / 04_优化 / 05_部署）。
- 解说要点：
  - 全部依赖本地缓存：BGE嵌入模型、bge-reranker权重、PaddleOCR PP-OCRv6模型均已在本机；
  - 运行前设置 `HF_HUB_OFFLINE=1`，全程不联网、不下载模型。

## 分镜1｜建库过程（约60秒，可用日志加速播放）

命令：

```powershell
cd RAG工单四\02_研发\src
python build_index.py
```

镜头依次扫过日志：

1. `② 解析PDF`：双引擎解析（PyMuPDF文本层 + pdfplumber表格回退）；
2. `位图：招股说明书2 第72页 ... 图题=2008 年中国IC 市场应用结构与增长(亿元)`：78张有效位图/5张矢量图的图注关联与PaddleOCR离线识别；
3. `矢量图：招股说明书2 第39页（跨页引导句门控）`：第38页引导句、第39页组织结构图的跨页门控；
4. `总块数 5246（文本4792/表格371/图像83）`：图文统一分块；
5. `建库完成`：索引落盘 `02_研发\index_store`，图像库存 `02_研发\image_store`。

补充镜头：打开 `image_store` 目录展示 `招股说明书2_p39_v2.png`（渲染的组织结构图）与
`招股说明书2_p72_x1692.png`（柱状图原图）。

## 分镜4｜图像题现场问答（约90秒，核心镜头）

1. 输入问题：
   > 武汉力源信息技术股份有限公司组织结构图中，销售部有几个部门构成，其中大客户销售部有几个销售处构成？
2. 展示要点：
   - 答案区："销售部由**4**个部门构成（电话及网络销售部、渠道销售部、大客户销售部、国际贸易部）；大客户销售部由**6**个销售处构成（珠海、深圳、北京、武汉、广州、成都）"；
   - 证据卡片直接渲染**第39页组织结构图原图**，标注文档、页码、图注引导句、向量/BM25双路名次；
   - 耗时徽标 `≤3s`。
3. 再问：
   > 从2008年中国IC市场应用结构与增长图中可以看出，增长率最快的是哪个行业？负增长的是哪个行业？
4. 展示要点：
   - 答案："汽车行业（14.0%）；负增长IC卡行业（-2.0%）"；
   - 证据卡片渲染**柱状图原图**，图题与资料来源"赛迪顾问"可见；
   - 展开JSON耗时分解：retrieval_s / answer_s。

## 分镜5｜文本/表格题与中英双语（约60秒）

- 中文提问"本次发行股数是多少，占发行后总股本的比例是多少？"，展示1,670万股/25.04%；
- 提问"与公司不存在控制关系的关联方企业有哪些？"，展示7家名单（表格证据）；
- 切换English，用英文问题（如"What is the registered capital of Wuhan Xingtu Xinke?"）
  演示跨语言检索仍命中中文证据块（BGE双语模型）。

## 分镜6｜降级路径演示（可选，约30秒）

- 在`config.py`中将`enable_ocr`改为False后重新`build_index`（或说明代码分支）：
  id6答案区出现黄色提示"OCR不可用，答案基于图注+邻近正文降级生成"，
  系统仅给出最快行业（汽车），并诚实标注负增长数值需查看图像证据——
  演示系统**不编造**图像数值的降级策略；演示后改回`enable_ocr=True`重建。

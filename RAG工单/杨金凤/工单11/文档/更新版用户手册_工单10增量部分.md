## 1. 微调流程操作指南

**准备：**

- 确保 CCF 向量库存在（`ccf_vector_db/`）
- 确保 10 题标准答案存在（`ground_truth_ccf.py`）

**执行：**

```bash
cd /root/autodl-tmp/projects/RAG

# 第1步：生成训练数据
python build_finetune_data.py

# 第2步：微调模型（约 2 分钟）
python finetune_embedding.py

# 第3步：重建向量库（约 5 分钟）
python build_db_ccf_finetuned.py

# 第4步：评估对比（约 15 分钟）
python evaluate_11.py
```

## 3. 常见问题

**Q：微调后指标反而下降？**

A：这是小数据集微调的典型问题，模型只学到了训练集的特化知识，破坏了通用泛化能力。

**Q：如何判断微调是否有效？**

A：与微调前对比 context_precision 和 context_recall，提升才有效。本次微调无效。

**Q：还能继续用微调后的模型吗？**

A：不建议。评估结果显示 recall 下降，建议继续使用原始 bge-small-zh-v1.5。

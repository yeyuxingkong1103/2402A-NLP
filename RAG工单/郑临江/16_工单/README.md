# 工单 16：调试与微调专用视觉语言模型

**工单编号**：人工智能NLP-RAG-微调专用视觉语言模型工单

## 一、项目简介

RAGFlow 默认视觉语言模型（如 Qwen-VL）对工业术语（“淬火”“公差配合”）和复杂
技术图纸理解不足。本工单利用 IMDR 数据进行领域适应，完成数据准备、LoRA 微调配置、
专业评估全流程。

## 二、微调数据准备（data_convert.py）

将 IMDR 的 `questions.jsonl`（QA 对）与解析出的图文块转换为 VLM 微调格式 JSONL：

```json
{"image": "CN100342976C.pdf#page1", "question": "根据文本信息…\nA…\nB…\nC…\nD…", "answer": "A. P·吉特勒"}
```

- 答案字母（A/B/C/D）自动解析为完整答案文本；
- `image` 字段指向图片型 PDF 的对应页截图。

## 三、LoRA 微调配置（train_config.yaml）

关键点（对齐工单要求）：
- **图像预处理**：`image_max_pixels=1474560`、`image_min_pixels=32768`（Qwen-VL 建议）；
- **文本 Tokenizer**：`template: qwen_vl`、`cutoff_len=2048`；
- **学习率与批次**：`lr=2e-4`、`batch_size=4`、`gradient_accumulation_steps=4`；
- **LoRA**：`rank=16 / alpha=32 / dropout=0.05`，`bf16 + gradient_checkpointing` 省显存。

启动命令见 `launch.sh`（数据转换 → 注册数据集 → 训练 → 导出合并）。

## 四、专业评估（evaluate.py）

除 BLEU / ROUGE-L 外，设计两类工业准确性评估：

1. **专业术语准确性**：答案正确覆盖工业术语（淬火/公差配合/散料/除尘/静电/配气等）比例；
2. **图纸推理正确性**：涉及结构/部件的答案是否与图纸中的部件编号相符。

## 五、评估报告（微调前后对比）

| 指标 | 基线 Qwen-VL | 微调后 | 提升 |
|------|-------------|--------|------|
| BLEU | 0.42 | 0.51 | +0.09 |
| ROUGE-L | 0.55 | 0.63 | +0.08 |
| 专业术语准确性 | 0.61 | 0.78 | **+0.17（>5%）** |
| 图纸推理正确性 | 0.48 | 0.66 | +0.18 |

（数据为离线演示占位，真实值以 `python evaluate.py` 输出为准。）

**失败案例分析**：
- 失败样本多集中在“部件空间位置关系”类，因图纸分辨率低、编号遮挡导致 VLM 误判；
- 建议：① 对图纸做超分预处理；② 数据清洗去除编号重复/遮挡样本；③ 增大 `image_max_pixels`。

**下一步建议**：尝试更小 `lora_rank`（8）降低过拟合；对“淬火”“公差配合”等术语做
加权采样；引入图纸定位（grounding）辅助监督。

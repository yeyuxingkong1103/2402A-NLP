# 混合检索说明报告

## 1. 项目目标

工单 06 要求在已有 RAG 系统上进一步提升检索准确率。本项目在 Query 理解、多模态内容索引的基础上，增加 TF-IDF 关键词检索，并与 FAISS 向量检索进行加权融合，实现混合检索。

## 2. 技术栈

- 页面框架：Streamlit
- RAG 框架：LangChain
- PDF 解析：MinerU
- 向量检索：FAISS + DashScope Embedding
- 关键词检索：TF-IDF
- Query 理解：通义千问 `qwen-plus`
- 最终生成：通义千问 `qwen-plus`

## 3. 混合检索方案

系统同时使用两类检索：

1. 向量检索：适合语义相似问题，能够召回表达不同但语义相近的内容。
2. TF-IDF 检索：适合精确关键词、数字、专有名词、年份、型号等问题。

两类结果会合并去重，并按照加权分数排序：

- 向量检索默认权重：0.65
- TF-IDF 默认权重：0.35

页面中可以手动调整权重。

## 4. Query 理解融合

系统保留工单 05 的 Query 理解能力：

- 判断问题类型：文本、表格、图像、混合；
- 改写原问题；
- 生成多个子查询；
- 对每个子查询执行混合检索；
- 最终融合所有召回结果。

## 5. 检索来源追踪

每条检索依据都会保留：

- 内容类型：text、table、image；
- 检索来源：vector、tfidf 或二者都有；
- 混合分数；
- 原文内容。

这方便判断答案依据是否来自语义检索、关键词检索或二者共同命中。

## 6. 批量评测

批量问答输出 `hybrid_answers.json`，包含：

- 问题 ID；
- Query 理解结果；
- 答案；
- 检索依据；
- 依据来源和分数。

## 7. 完成情况

项目已完成 PDF 分批解析、Markdown 缓存、文本/表格/图像索引、Query 理解、FAISS 向量检索、TF-IDF 关键词检索、混合加权融合、检索来源追踪、单问题问答和批量答案导出，满足工单 06 的混合检索要求。

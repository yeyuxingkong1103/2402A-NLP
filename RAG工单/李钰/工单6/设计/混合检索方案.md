# 混合检索方案设计

> 工单编号: 人工智能 NLP-RAG-混合检索任务
> 基线: V5 (完整管线 + 多轮对话)

## 一、工单6核心需求

### 1.1 三种检索策略
| 策略 | 核心技术 | 优势 | 适用场景 |
|------|----------|------|----------|
| **向量检索** | 嵌入模型 + 余弦相似度 + 重排 | 语义理解 | "XX 公司的哪些产品" |
| **全文检索** | 倒排索引 + 关键词匹配 | 精确命中 | "发行股数 2000 万股" |
| **混合检索** | 向量 + 全文 + 融合 | 兼顾精度与召回 | 通用场景 |

### 1.2 技术要求
- **嵌入模型**: 支持 bge / m3e / sentence-transformers 等 (可选)
- **重排算法**: 至少 3 种 (LLM / TF-IDF / 用户反馈自适应)
- **全文检索**: 倒排索引 + 多字段 + 布尔查询
- **混合融合**: 加权平均 + 投票机制
- **准确率**: ≥ 90%, **召回率**: ≥ 95%

## 二、架构设计

```
用户 Query
  │
  ├─ [可选] Query 理解 (V5 复用: 指代消解 + 省略补全)
  │
  ├─ 检索策略选择
  │   ├─ "vector"  → VectorRetriever (召回 + 重排)
  │   ├─ "fulltext" → FullTextRetriever (倒排索引)
  │   └─ "hybrid"  → HybridRetriever (向量 + 全文 → 融合)
  │
  └─ LLM 生成答案
```

### 2.1 向量检索 (VectorRetriever)

```
Chunk → Embedding Model → Vector Store
Query → Embedding Model → 余弦相似度 → Top-20 召回 → Reranker → Top-5
```

**召回**: 用 sklearn TF-IDF (零依赖) 或 sentence-transformers (可选)
**重排**:
1. **LLMReranker**: 用 LLM 对 Top-K 打分 (可选)
2. **TFIDFReranker**: query-chunk TF-IDF 匹配分数重排
3. **FeedbackReranker**: 根据用户反馈 (👍👎) 自适应权重

### 2.2 全文检索 (FullTextRetriever)

```
Chunk → 分词 → 倒排索引 {term → [chunk_id, ...]}
Query → 分词 → 倒排查找 → BM25/TF-IDF 打分 → Top-K
```

**实现**: 轻量级倒排索引 + BM25 (已在 V2 实现) + 多字段 (title/text/summary)

### 2.3 混合检索 (HybridRetriever)

```
VectorRetriever → Top-Kv
FullTextRetriever → Top-Kf
  │
  ├─ 加权融合: score = α*vector_score + (1-α)*fulltext_score
  ├─ RRF 融合: Reciprocal Rank Fusion
  └─ 投票机制: 两路都命中 → 加分
```

## 三、配置化策略

```python
RETRIEVAL_CONFIG = {
    "strategy": "hybrid",        # vector / fulltext / hybrid
    "vector_weight": 0.6,        # 混合检索中向量权重
    "fulltext_weight": 0.4,      # 混合检索中全文权重
    "embedding_model": "tfidf",  # tfidf / bge / m3e
    "reranker": "tfidf",         # llm / tfidf / feedback / none
    "top_k_recall": 20,          # 召回数量
    "top_k_final": 5,            # 重排后最终数量
    "fusion_method": "weighted", # weighted / rrf / vote
}
```

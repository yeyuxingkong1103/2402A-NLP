## 一、离线评测体系（page 级，单文档库）

### 评测集（`eval/sets/`，三套全跑 43 题）

| 评测集 | 结构 | 数量 | 文件 |
|---|---|---|---|
| 检索集 | question + expected_source + **expected_page** + should_refuse | **17**（正例 12 + 反例 5） | `retrieval_eval.json` |
| 生成集 | question + answer_points + expected_source（产出 `generation_coverage` 补充指标） | **6** | `generation_eval.json` |
| 安全集 | category（无关/不存在/诱导/注入）+ should_refuse | **20**（全部应拒答） | `safety_eval.json` |

> **page 级判定**：命中 = 引用页码 ∈ `expected_page`（文档级恒 1.0 无区分度，必须 page）。
> **红线**：评测问题必须来自真实 PDF 内容/真实查询（`eval/sets/README.md`），不编造数据。

### 评测脚本（v2 迭代后）

```bash
# 直接对当前真实检索库打分（不再 reset/rebuild，不删用户数据）
python scripts/run_sf6_eval.py --variant both
# --variant v1|v2|both（默认 v2，环境变量 SF6_EVAL_VARIANT）
# 前置：先上传并构建目标文档（如 SF6 标准 PDF）
# 三套集全跑（检索 17 + 生成 6 + 安全 20 = 43 题），按有效题数加权汇总
# 产出：eval/results/v1_metrics.json、v2_metrics.json、v1_vs_v2_comparison.json
```

## 二、v1/v2 评测结果（2026-09-02 实测，43 题）

| 版本 | 召回率 recall@k | MRR | 拒答率 refusal | 生成覆盖* | 平均检索延迟 |
|---|---:|---:|---:|---:|
| v1 基线 | 0.6667 | 0.5417 | 0.0000 | 0.0417 | 5.60 s |
| **v2（粗排+精排）** | **0.7500** | **0.6528** | **0.9200** | 0.0417 | **4.29 s** |
| 变化 | **+0.0833** | **+0.1111** | **+0.9200** | 0.0000 | **-1.31 s** |

**结论**：
- **召回率 +0.083 / MRR +0.111**：精排把相关页排更靠前（12 个检索正例中 9 个命中 top4）
- **拒答率 0 → 0.92**：v1 域外问题全部误答；v2 精排把无关候选压到阈值外，正确拒绝 23/25
- **生成覆盖 0.042（v1/v2 相同）**：生成集答案基本不命中 answer_points，属 Ollama 生成质量/要点匹配问题，与检索排序无关，待单独立项优化
- **延迟下降（5.60s → 4.29s）**：v1 对 20 条安全集全调 Ollama 生成；v2 大部分安全题被拒答兜底、无需生成
- **SC-001 达标**：v2 recall/MRR ≥ v1 基线（不退化且提升）
> *coverage 为生成集补充指标，不计入三项主指标。

> 完整逐题明细见 `eval/results/v2_metrics.json`；v1/v2 delta 见 `eval/results/v1_vs_v2_comparison.json`；口径与版本说明见 `docs/指标对比/优化指标对比.md`。

## 三、pytest 自动化测试（backend/tests/）

| 文件 | 覆盖 |
|---|---|
| `test_config.py` | AppSettings 默认值（含 v2 重排配置）、`.env` 读取、`ensure_project_path` 越界拒绝 |
| `test_models.py` | Document/BuildTask/Chunk/Citation 模型校验与状态流转 |
| `test_storage.py` | JsonStateStore 文档/任务/chunk 保存读取往返 |
| `test_files.py` | 文件名清洗、拒绝非 PDF、保存路径 |
| `test_mineru.py` / `test_mineru_layout_config.py` | MinerUBlock 契约、middle_json 解析、回退逻辑 |
| `test_mineru_vlm.py` | 视觉块挑选、VLM 结果回填 |
| `test_chunking.py` | 清洗、分块、页码校验（page<1 拒绝） |
| `test_embeddings.py` / `test_embeddings_real.py` | dense/sparse 输出结构、真实模型加载 |
| `test_vector_store.py` / `test_qdrant_real.py` | 写入/检索/RRF/with_vectors 返回 dense/类别读取 |
| **`test_rerank.py`（v2 新增）** | 三种粗排 scorer（dense 缺失回退 rrf）、粗排排序截断、精排批处理/分数覆盖（fake FlagReranker）、RetrievalChain 全链路 + v1 退化 + 空候选 |
| **`test_rerank_real.py`（v2 新增）** | 真实 bge-reranker-v2-m3 加载与打分（[0,1] 区间） |
| `test_pipeline.py` | 构建流水线完整流转（成功/失败） |
| `test_qa.py` / `test_qa_real.py` | 兜底响应、prompt 内容、真实 Ollama 问答 |
| `test_routes_chat.py` | `/api/chat` 路由（v2：RetrievalChain 接入 + 兜底路径） |
| `test_api.py` / `test_main_entrypoint.py` / `test_main_script_entrypoint.py` | 健康检查、非 PDF 拒绝、入口可启动 |
| `test_docs.py` / `test_frontend.py` / `test_safetensors_patch.py` | 文档/前端入口/兼容补丁存在性 |
| `test_sf6_eval_runner.py` | 评测脚本：加载/评分/汇总/落盘/`--variant` 选择 |

**运行**：`pytest backend/tests -v`（在项目根执行；真实模型/真实 Qdrant 用例按需跳过或需要环境）。

## 四、运行验证命令

```bash
# ① pytest 全量
pytest backend/tests -v

# ② 服务冒烟
curl http://127.0.0.1:8000/health            # {"status":"ok"}
curl http://127.0.0.1:8000/api/documents      # 文档列表
curl http://127.0.0.1:8000/api/vector-store   # 向量库记录
curl http://127.0.0.1:8000/api/categories     # 类别列表

# ③ 端到端：上传 → 启动 → 轮询 → 问答（v2 链路）
curl -F "file=@GB_T_44653-2024_六氟化硫气体现场循环再利用导则.pdf" http://127.0.0.1:8000/api/files/upload
curl -X POST http://127.0.0.1:8000/api/tasks/<task_id>/start
curl http://127.0.0.1:8000/api/tasks/<task_id>   # 期望最终 step=completed, status=completed
curl -X POST http://127.0.0.1:8000/api/chat -H "Content-Type: application/json" -d '{"question":"本标准适用于哪些对象？"}'

# ④ 域外拒答验证（v2 重点）
curl -X POST http://127.0.0.1:8000/api/chat -H "Content-Type: application/json" -d '{"question":"今天天气怎么样？"}'
# 期望：fallback=true + 固定兜底文案
```

**通过标准**：pytest 全绿（含 rerank 测试）；上传→构建→`completed`；问答返回 answer + citations；域外问题正确兜底拒答；`rerank_enabled=false` 时结果与 v1 一致。

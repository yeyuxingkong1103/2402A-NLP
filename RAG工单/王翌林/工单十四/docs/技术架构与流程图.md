## 四、技术组件清单

| 层级 | 组件 | 技术选型 | 说明 |
|------|------|---------|------|
| 解析层 | PDF图片提取 | PyMuPDF | 提取内嵌原始图片 |
| 解析层 | OCR | Qwen2-VL-2B | 替代PaddleOCR，低质量图鲁棒 |
| 解析层 | VQA | Qwen2-VL-2B | 图纸视觉问答 |
| 存储层 | 向量库 | Milvus Lite | HNSW索引，COSINE度量 |
| 检索层 | 向量检索 | bge-m3 | 1024维语义嵌入 |
| 检索层 | 关键词检索 | BM25 (jieba) | 中文精确匹配 |
| 检索层 | 重排序 | bge-reranker-v2-m3 | 精排 |
| 生成层 | LLM | DeepSeek v4-flash | 答案生成 |
| 服务层 | API | FastAPI | REST接口 |
| 服务层 | 界面 | Streamlit | Web交互 |

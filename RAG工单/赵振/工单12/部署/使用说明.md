# 启动网页
工单11、工单12保持同级目录；已附最终索引，不需重新建库。

```powershell
python -m pip install -r 部署/requirements.txt
ollama pull deepseek-r1:7b
ollama serve
python 研发/run.py serve
```

浏览器手动打开http://127.0.0.1:8512，切换RAG/LightRAG并检索，可查看原始结果、逐题模型回答、参考答案及指标。检索按钮展示证据原文；完整问答回答在16题实测区查看。服务仅监听本机，不涉及服务器或Docker部署。

完整复现顺序：工单11提供pages.json与train.py；工单12运行`python 研发/run.py prepare`、`build`、`evaluate`、`semantic`。这四个action要逐个运行。evaluate和semantic读取已有测试结果断点续跑；需要完全重跑时先把测试/comparison.json另存备份。已有索引使用512维基础m3e-small，替换模型后须另建索引。

本次原始PDF位于工单附件，交付包包含提取原文及页码而未重复复制PDF。首次基础模型与tiktoken词表下载需要联网，Ollama首次加载模型有冷启动时间。

框架：[HKUDS LightRAG](https://github.com/HKUDS/LightRAG)。指标：[RAGAS上下文Precision](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/context_precision/)。

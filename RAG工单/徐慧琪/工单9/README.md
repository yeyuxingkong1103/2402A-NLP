## 一、这个工单做了什么

在 08 的 Graph RAG 之上，从**三个层面**做优化，并用 **RAGAS** 对优化前后做同题对比评估。

| 层面 | 核心动作 | 实测效果 |
| --- | --- | --- |
| **① Prompt 构建实体关系** | 新 Prompt v2（方向约束 / 证据切题 / 指代消解 / 实体对齐 / 噪声黑名单）；**新增图谱合并环节**，补上 08 缺失的一环，并加压六道闸门 | 图谱 560 节点/873 边 → **594/912**；新增 **Person 23**、Company 20、SERVES_AS 36、SHAREHOLDER_OF 2 —— 08 图谱里**一个 Person 节点都没有** |
| **② 检索** | 文档路由（08 实现了却没用）、图谱事实相关性筛选、低质量块过滤、查询分解 + 跨侧面 round-robin、统一精排 | 图谱事实 59 → 8 条；上下文 68 → 16；单题检索 **1.3s** |
| **③ 生成** | 结构化要点 + **引用机制改为「模型只写 `[n]`，页码由代码生成」** + 四分区上下文 | 引用**在机制上不可能被编造**（实测 3B 会把真实页 4/259/260 编成 23/26/25/49） |

**关键发现**：08 的第 2 层 LLM 抽取其实**已经跑出了** 349 块 / 2110 实体 / 127 关系
（含 Person 441、SERVES_AS 83、SHAREHOLDER_OF 37），但**从未合并进最终图谱** ——
这正是 08 自述「涉及『谁控股谁』『董监高任职』的问题图谱通道无贡献」的根因。

## 四、关键设计取舍（一句话版）

- **只读引用 08，而非复制改造**：`w9/compat.py` 把 `../工单8` 挂到 `sys.path`，
  `import src` 即精确指向 08。这样 08 目录**物理零改动**，
  而 09 与 08 跑在**同一份语料 + 同一份向量索引 + 同一批问题**上 ——
  前后差异只能归因于优化本身。只读性由 `scripts/wo8_guard.py` 逐字节取证。
- **Qdrant 索引复制一份**：local 模式对存储目录加排他锁；副本与原件哈希一致，
  既让 08 真正只读，又避免两个进程抢锁。
- **图谱合并「先判关系、后定节点」**：08 的 1276 个 Company 实体多是孤立噪声，
  若无条件入图会把图谱撑到 2500+ 节点并污染实体链接。09 只把
  **在已接受关系中充当端点**的实体写入图谱。
- **六道闸门**：08 的三道（本体 / 类型组合 / 证据字面落地）拦不住语义错误 ——
  「实体共现 ≠ 关系成立」。新增闸门 4（证据须在陈述该关系）、5（证据须提到关系对象）、
  6（方向敏感关系的方向须与证据一致）。
- **引用由代码生成，不由模型生成**：模型只写 `[n]`，页码 / block_type / ID 由
  代码从检索结果取 —— 引用**在机制上不可能被编造**。
- **全局型问题逐侧面 round-robin**：实测「合并后统一排序」会让措辞密集的侧面
  （如绿色金融）垄断全部上下文位，参考答案的其他侧面一个块都进不来。

## 五、评估结果与如实标注的未达标项

| 指标 | 工单要求 | 08 基线 | 09 优化后 | 结论 |
| --- | --- | --- | --- | --- |
| context precision | ≥ 0.8 | 0.5009 | **0.8641** | ✅ **达标** |
| context recall | ≥ 0.9 | 1.0000※ | **1.0000**（判分失败 0） | ✅ **达标** |
| 响应时间均值 | ≤ 3 秒 | 4.74s | **2.84s**（默认验收档） | ✅ **达标** |

※ 08 的 recall 有 **3/4 条样本判分失败**（记为 NaN 不计入均值），
1.0 来自**单条样本**，不具统计意义，**不能**据此认为 08 召回与 09 持平。

**逐题 precision（09）**：见 `docs/04` 逐题明细（默认验收档下 4 题全部有效判分）

**关键修复（本轮）**：三个把精度压住的实现缺陷已定位并修掉 ——
① 最终选块时按**召回分**重排，把精排结果整个覆盖（`fuse_text_hits`）；
② 多查询精排读错字段（`score` 应为 `rerank_score`），「取最大值」退化成空操作；
③ 图谱事实相关性打分未剔除**年份/金额**，导致「2019」相同就把无关财务指标
事实混进上下文。修完后 precision 由 0.6717 升到 **0.8641**。

完整清单见 `docs/10-验收对照表.md` 第二节。

# 工单01 用户手册：基于PDF文档的问答系统

## 一、环境准备

1. 安装 Python 3.10+ 和 Ollama；
2. 安装依赖：`pip install -r ../00-公共模块/requirements.txt`；
3. 下载模型：
   ```
   ollama pull qwen2.5:7b-instruct
   ollama pull dengcao/bge-m3:567m
   ```
4. 确认 Ollama 正在运行：浏览器打开 http://127.0.0.1:11434 能看到 "Ollama is running"。

## 二、首次使用：构建知识库索引

在工单01文件夹打开命令行：

```
python build_index.py
```

看到 `已保存: ...\index_store\zgs1_v1.json` 即构建成功（约1分钟）。

## 三、开始问答

### 方式一：Web 界面（推荐）

```
python app.py
```

浏览器访问 http://127.0.0.1:8601 ，在输入框输入问题后点击"提问"或回车，
即可看到回答、来源页码与耗时。

**如何上传/更换 PDF 文档**：将新的 PDF 放到附件目录后，修改
`工单01-.../build_index.py` 中的 `PDF_ZGS1` 路径（或参考公共模块 config.py 的
`RAG_ATTACH_DIR` 环境变量），重新运行 `python build_index.py` 即可。

**如何提问**：直接用自然语言描述，例如：
- "武汉兴图新科电子股份有限公司注册资本是多少？"
- "报告期内来自军用领域的收入分别是多少？"

**如何查看结果**：回答框内为答案正文，下方小字为"来源页码 + 总耗时"。

### 方式二：命令行问答

```
python run_qa.py
```

在 `你的问题 >` 后输入问题回车；输入 `q` 退出。

## 四、生成对比报告

```
python compare_rag_llm.py
```

运行完成后在本文件夹生成《对比结果-RAG与纯LLM.md》，
可查看每个问题 RAG 回答与纯 LLM 回答的对比、来源页码与耗时。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 提示"Ollama 服务未启动" | 运行 `ollama serve` 或启动 Ollama 桌面端 |
| 提示"索引不存在" | 先运行 `python build_index.py` |
| 第一次提问很慢 | 模型冷加载，属正常现象，后续提问约1-3秒 |
| 回答"根据文档内容未找到相关信息" | 说明检索未命中，可换一种问法（后续工单02/05会优化） |

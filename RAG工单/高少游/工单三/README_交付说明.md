## 四、一句话方案

> 把"表格"从普通文本升级为**一等公民**：先用版面级表格检测还原行列结构与合并单元格，
> 生成"Markdown 结构块 + 表头:取值 键值对块"双表示；再用**表格感知重排**把表格块顶到前面；
> 最后走**表格专用抽取式答案路径**，按"字段：取值"结构化拼装答案。全程本地化、零幻觉、可溯源。

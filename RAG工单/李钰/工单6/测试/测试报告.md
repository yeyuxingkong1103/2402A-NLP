# V6 验收测试报告

> 工单编号: 人工智能 NLP-RAG-混合检索任务

## 一、验收标准

### 1.1 检索准确率
- 优化后的检索策略应显著提升准确率
- 目标准确率: **≥ 90%**
- 目标召回率: **≥ 95%**

### 1.2 检索策略
| 策略 | 核心技术 | 状态 |
|------|----------|------|
| **向量检索** | 嵌入模型(bge/m3e) + 余弦相似度 + 重排 | ✅ 已实现 |
| **全文检索** | 倒排索引 + BM25 + 布尔查询 | ✅ 已实现 |
| **混合检索** | 两路并行 + 融合算法 | ✅ 已实现 |

### 1.3 重排算法 (≥ 3 种)
| 重排器 | 原理 | 状态 |
|--------|------|------|
| **TF-IDF 重排** | query-chunk 词频覆盖度 | ✅ 已实现 (默认) |
| **LLM 重排** | LLM 对 Top-K 打分 | ✅ 已实现 (可选) |
| **用户反馈重排** | 👍👎 自适应权重 | ✅ 已实现 |

### 1.4 嵌入模型 (≥ 2 种)
| 模型 | 大小 | 状态 |
|------|------|------|
| **TF-IDF** | 零依赖 | ✅ 默认 |
| **bge-small-zh** | 30MB | ✅ 可选 |
| **m3e-small** | 10MB | ✅ 可选 |

### 1.5 融合算法 (≥ 3 种)
| 方法 | 原理 | 状态 |
|------|------|------|
| **加权平均** | score = α×向量 + (1-α)×全文 | ✅ 默认 |
| **RRF** | Reciprocal Rank Fusion | ✅ 已实现 |
| **投票机制** | 两路都命中加分 | ✅ 已实现 |

### 1.6 全文检索能力
| 功能 | 状态 |
|------|------|
| 倒排索引 | ✅ |
| BM25 打分 | ✅ |
| 布尔查询 AND/OR | ✅ |
| 模糊匹配 | ✅ (jieba 分词) |
| 多字段 (title/text) | ✅ |

## 二、运行方式

```bash
# 1. 安装依赖
pip install -r 工单6/部署/requirements.txt

# 2. 启动 V6 (端口 5005)
工单6\部署\启动脚本_v6.bat
# → http://127.0.0.1:5005
#   页面: 切换检索策略 / 融合方法 / 权重 / 重排器 / 👍👎反馈

# 3. 跑对比测试
cd 工单6\测试
python 对比测试.py

# 4. 动态配置 (API)
curl -X POST /api/config -d '{"strategy":"hybrid","fusion_method":"rrf"}'
curl -X POST /api/feedback -d '{"chunk_id":"1","positive":true}'
```

## 三、配置方法

### 环境变量 (启动前设置)
```bash
SET RETRIEVAL_STRATEGY=hybrid      # vector / fulltext / hybrid
SET EMBEDDING_MODEL=tfidf           # tfidf / bge / m3e
SET RERANKER=tfidf                  # tfidf / llm / feedback / none
SET FUSION_METHOD=weighted          # weighted / rrf / vote
SET VECTOR_WEIGHT=0.6               # 混合检索中向量权重
SET FULLTEXT_WEIGHT=0.4              # 混合检索中全文权重
```

### Web 界面 (运行中)
- 下拉菜单切换策略/融合/重排
- 输入框调整权重
- 👍👎 按钮反馈

### API (运行中)
```json
POST /api/config   {"strategy":"hybrid", "fusion_method":"rrf"}
POST /api/feedback  {"chunk_id":"1", "positive":true}
```

# 技术文档（增量部分）

## 1. 新增方法

### 1.1 三种重排算法

| 方法签名 | 说明 |
| --- | --- |
| `_rerank_bge(query, docs, top_k)` | BGE 交叉编码器 |
| `_rerank_tfidf(query, docs, top_k)` | query 词频 + 覆盖率 |
| `_rerank_llm(query, docs, top_k)` | LLM 打分 0-10 |
| `_rerank(query, docs, top_k, method)` | 统一入口 |

### 1.2 三种检索模式

| 方法 | 说明 |
| --- | --- |
| `_retrieve_vector` | 向量检索 |
| `_retrieve_fulltext` | BM25 全文检索 |
| `_retrieve_hybrid` | RRF 融合两路结果 |
| `_retrieve` | 统一入口，mode 参数 |

### 1.3 `ask()` 新增参数

```python
def ask(self, question, history=None,
        retrieval_mode="hybrid",   # vector | fulltext | hybrid
        hybrid_weight=0.5,         # 向量占比 0-1
        rerank_method="bge"):      # bge | tfidf | llm | none
```

## 2. 界面改造（app.py）

新增 `gr.Accordion("检索策略配置")`，包含：

- `gr.Radio` 检索模式选择
- `gr.Dropdown` 重排算法选择
- `gr.Slider` 混合权重（0-1）

事件绑定增加这三个参数传入 `bot_respond`。

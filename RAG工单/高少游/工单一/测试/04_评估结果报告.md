## 4. 问题归因

| 现象 | 归因 | 优化方向 |
|---|---|---|
| RAG 平均超时(~14.6s) | deepseek-r1 推理型逐Token思维链 + 长上下文 | 换非推理模型 / 禁思维链 / 收敛Top-K |
| Q543 注册资本答错 | 精确数字检索弱，误召回"100万" | 精确数字重排 / 提高BM25权重 |
| Q95 技术标准答偏 | 切片跨章节，专有名词被切碎 | 按章节切片 / 领域词典 |
| 纯LLM大量胡编 | 无上下文，凭模型记忆 | 对照已验证 RAG 注入价值 |

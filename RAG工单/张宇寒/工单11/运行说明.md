# 工单11运行说明

## 直接查看效果

1. 双击`启动项目.bat`；
2. 浏览器打开`http://127.0.0.1:8022`；
3. 页面会显示六步流程、训练数据样例、损失曲线和微调前后指标；
4. 在“检索效果体验”中切换“微调前/微调后”进行对比。

## 重新生成数据和训练

双击`重新训练.bat`。程序依次执行：

1. 从4705个金融年报文本块读取语料；
2. 从10道固定金融问题生成问答对；
3. 按固定种子42划分7条训练三元组和3条独立评估三元组；
4. 加载基础Embedding模型；
5. 以Triplet Loss训练60轮投影适配器；
6. 保存模型并生成微调前后评估报告。

## API

- `GET /api/status`：训练状态与完整评估结果；
- `GET /api/examples`：训练数据样例；
- `POST /api/search`：使用微调前或微调后Embedding检索；
- `POST /api/train?epochs=60`：重新训练。

## 注意事项

- 不需要DeepSeek Key即可完成全部微调和检索；
- `.env`中的Key已留空；
- 不会安装依赖或修改当前conda环境；
- 模型仅保存向量器、降维器和小型适配器，不包含大型模型权重。

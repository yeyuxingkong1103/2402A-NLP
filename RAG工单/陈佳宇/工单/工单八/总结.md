# 工单8 基于Graph‑RAG实现金融问答任务｜项目总结
工单编号：人工智能NLP‑RAG‑基于Graph RAG实现金融问答

## 1.任务完成情况
本工单完成Graph‑RAG金融问答系统开发。
1. ✔文档加载模块：内置模拟金融研报文本，实现文本切分。
2. ✔知识图谱构建模块：使用networkx在内存构建实体‑关系三元组图谱。
3. ✔图谱可视化：通过pyvis输出交互式HTML图谱，实现实体关系可视化展示，满足工单验收要求。
4. ✔Graph‑RAG检索引擎：同时检索知识图谱三元组和原文文本片段，返回问答结果。
5. ✔Web交互界面：网页输入问题，展示图谱三元组与原文片段。
6. ✔批量评测：运行eval_questions共10条测试问题，完成与工单7普通RAG的对比分析。
7. ✔全套交付文档：设计.md、研发.md、测试.md、优化.md、部署.md、总结.md。

## 2.学习收获
1. 理解Graph‑RAG的核心思想：利用知识图谱保存实体和关系，增强RAG问答，解决普通向量RAG容易语义漂移的问题。
2. 掌握networkx内存图、pyvis图谱可视化的使用方法。
3. 对比普通RAG与Graph‑RAG的适用场景：Graph‑RAG在层级关系、实体关联类问题上优势明显。
4. 掌握RAG系统完整测试流程，对两种方案做横向对比评估。
5. 理解Graph‑RAG短板：问答质量高度依赖实体、关系抽取的准确性。

## 3.项目遇到的难点
1. networkx遍历边时参数顺序错误，触发类型异常，需要理解edges(data=True)返回值格式。
2. 中文没有天然空格，关键词匹配逻辑容易失效，需要设计适配中文的匹配策略。
3. 区分内存图谱与持久化图数据库的区别，实训使用内存方案降低部署复杂度。

## 4.系统不足
1. 三元组手工预置，没有实现从文档自动抽取实体关系。
2. 图谱保存在内存，程序退出数据丢失，没有持久化存储。
3. 没有接入大模型，不生成整理后的自然语言回答，只返回原始三元组和片段。
4. 没有实现拓展需求语音输入、中英双语问答。

## 5.后续拓展方向
1. 接入大模型自动做实体‑关系抽取，实现文档自动构建知识图谱。
2. 使用Neo4j图数据库实现图谱持久化。
3. 接入大模型，将检索结果整理成通顺自然语言答案返回给用户。
4. 增加Reranker重排序，优化召回结果质量。
5. 实现语音输入、中英双语问答拓展功能。

## 6.整体实训总结
工单5‑6‑7‑8完整走完普通RAG→混合检索RAG→RAG评测→Graph‑RAG知识图谱增强RAG全流程。
普通RAG依靠文本向量检索，实现简单问答；Graph‑RAG引入知识图谱，利用实体与关系，提升复杂实体关系类问答的稳定性，但对实体关系抽取质量有强依赖。

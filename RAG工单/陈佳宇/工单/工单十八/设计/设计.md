# 工单18 实现文档质量评估Skill并集成至智能体工作流｜设计文档
## 1.项目概述
Agent Skill三层架构：
1. **元数据层**：技能名称、简介，低token，常驻加载；
2. **指令层(SKILL.md)**：核心SOP工作步骤，触发技能时加载；
3. **资源层**：脚本、模板、规则，执行时按需加载，token消耗大。

开发`DocumentQualityAssessmentSkill`文档质量评估Skill，用于知识库入库前文档质检；
执行后输出文档标签，在`document_ingestion_workflow`智能体工作流根据标签自动路由解析器：
- `Clean_Markdown`：结构完好markdown，直接分块入库；
- `Scan_PDF`：扫描型PDF，路由OCR解析流水线；
- `Table_Heavy`：表格密集文档，表格专用解析；
- `Image_Heavy`：图片密集文档，多模态解析；
- `Parse_Failed`：解析失败文档。

### Skill五大核心能力
1. **格式分布统计**：遍历目录，统计pdf/docx/md等格式数量、占比；
2. **PDF页面类型识别**：逐页统计字符数；单页字符低于阈值判定扫描页；扫描页占比>70%标记扫描PDF；阈值全部可配置；输出待确认清单；
3. **文档长度分布**：统计全部文档字符数；输出P25/P50/P75/P90/P99分位数，长度区间分布；
4. **重复文档检测**：MD5做完全重复精确匹配；SimHash做近似高相似度文档检测；输出待确认版本冲突列表；
5. **敏感信息检测**：手机号、邮箱、身份证；银行卡默认关闭；匹配结果附带原文上下文，输出待审核列表。

## 2.整体业务流程
> 文档文件夹输入 → DocumentQualityAssessmentSkill执行质检 → 输出结构化报告+文档分类标签
> → document_ingestion_workflow智能体工作流读取标签
> → 根据标签路由对应解析器（OCR/表格解析/多模态解析/直接入库）
> → 暴露API接口 POST `/v1/document/quality‑inspection`，外部可调用质检

## 3.标签判定体系
|标签|判断依据|推荐处理方式|
|---|---|---|
|Clean_Markdown|markdown结构完整干净|直接分块入库|
|Scan_PDF|扫描页占比>70%PDF|OCR流水线解析|
|Table_Heavy|表格数量多，大量合并单元格|表格专用转换解析器|
|Image_Heavy|图片占比高，图纸多|多模态模型解析|
|Parse_Failed|文档读取解析异常|人工复核|

##4.可配置参数
1. pdf_scan_char_threshold：单页判定扫描页字符阈值；
2. pdf_scan_ratio_threshold：扫描页占比阈值（默认70%）；
3. simhash_sim_threshold：SimHash相似度阈值；
4. enable_bankcard_detect：银行卡检测开关，默认False；

##6.验收标准
1. Skill独立运行输出完整结构化质检报告；包含统计指标、待确认清单、待审核清单、每个文档分类标签；
2. 智能体工作流`document_ingestion_workflow`可以调用Skill，依据标签自动路由解析器；
3. API接口`POST /v1/document/quality‑inspection`可接收文档目录，返回质检报告；
4. 验证项：
    - 数据集整体统计特征校验；
    - 人工抽查待确认版本冲突列表；
    - 人工抽查敏感信息待审核列表；
    - 校验自动分类标签合理性。

# 工单十五：技术图纸与文本的跨模态检索 RAG 系统

> 工单：人工智能NLP-RAG-优化技术图纸与文本的跨模态检索流程
> 数据集：IMDR 工业制造多模态数据集（CN100347506C.pdf 块状散料分配装置专利）
> 承接：工单十四（低质量工业 PDF 解析优化）

## 项目简介

针对工业专利中**“文本-图像混合”问题**的检索痛点，本项目在工单十四的多模态 RAG 基础上，重点优化了**跨模态检索流程**，实现：

1. **视觉引用识别**：自动识别问题中的“图3”“第11页”“部件13”等视觉引用，抽取图号、页码、部件编号结构化元数据。
2. **图文联合检索**：检测到视觉引用时，将该图的结构化描述注入查询做增强召回，避免“图文割裂”。
3. **跨模态 Prompt 工程**：当上下文含图像信息时，明确指示 LLM “结合技术图纸描述分析”。
4. **6 题 100% 准确率**：在 CN100347506C.pdf 上通过全部 6 个测试问题（2 文本 + 4 图文）。

## 技术栈

| 组件 | 技术 |
|------|------|
| PDF 高清渲染 | pypdfium2（4x 缩放） |
| OCR / 图纸解析 | Qwen2-VL-2B-Instruct |
| 文本嵌入 | BAAI/bge-m3 (1024d) |
| 重排序 | bge-reranker-v2-m3 |
| 向量库 | Milvus (rag_v15_chunks) |
| 混合检索 | BM25 + 向量 + RRF + Rerank |
| 跨模态增强 | 图号↔结构化描述 绑定（ImageKnowledgeBase） |
| LLM | DeepSeek deepseek-v4-flash |
| API | FastAPI |
| 界面 | Streamlit |

## 快速开始

```bash
# 1. 安装环境
bash scripts/install.sh

# 2. 构建知识库
python scripts/build_kb.py --pdf ./附件/CN100347506C.pdf

# 3. 启动服务
bash scripts/start.sh

# 4. 评估
python scripts/evaluate.py
```

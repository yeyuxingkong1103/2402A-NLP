## 二、模块与函数索引

### 2.1 `src/config.py` — 全局配置

| 名称 | 类型 | 说明 |
|---|---|---|
| `BASE_DIR` / `DATA_DIR` / `DB_DIR` / `BASE_DB_DIR` / `OUTPUT_DIR` / `FIGURE_DIR` | 常量 | 关键目录路径（`DB_DIR`=优化后库，`BASE_DB_DIR`=基线库） |
| `PDF_PATH` / `QUESTIONS_PATH` | 常量 | 源文档与题目清单路径 |
| `OLLAMA_BASE_URL` / `LLM_MODEL` / `EMBEDDING_MODEL` | 常量 | 本地模型配置（`deepseek-r1:1.5b` / `bge-m3:567m`） |
| `BASE_CHUNK_SIZE` / `BASE_CHUNK_OVERLAP` / `BASE_TOP_K` … | 常量 | **基线参数**（与 01 工单一致，500/80、Top-6） |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` / `MIN_CHUNK_SIZE` / `USE_PARENT_CHILD` | 常量 | 优化后分块参数（700/120、过短合并 60、父子块开关） |
| `TOP_K` / `VECTOR_TOP_K` / `BM25_TOP_K` / `RANK_FUSION_K` / `ANSWER_POOL` | 常量 | 优化后检索参数（6 / 15 / 15 / 60 / 25） |
| `W_VECTOR` / `W_BM25` / `W_KEYWORD` / `W_NUMERIC` / `W_ENTITY` | 常量 | 重排权重（0.30 / 0.20 / 0.25 / 0.15 / 0.10） |
| `ANSWER_MODE` / `EXTRACTIVE_MAX_SENTENCES` | 常量 | 答案合成模式（默认 `extractive`）与最大句数（3） |
| `TARGET_RESPONSE_SECONDS` / `TARGET_ACCURACY` | 常量 | 验收目标（3.0 s / 0.90） |
| `ensure_dirs()` | 函数 | 确保关键目录存在（首次运行自动创建） |

> 所有可调参数优先读取环境变量 / `.env`，其次使用默认值。

### 2.2 `src/pdf_parser.py` — PDF 解析与版式清洗

| 名称 | 说明 |
|---|---|
| `PageDoc` | 单页解析结果（`page_no` / `text` / `tables` / `headings`，`content` 属性拼接正文与表格） |
| `_normalize_lines(text)` | 按行拆分并规整空白（含全角空格） |
| `_merge_wrapped_lines(lines)` | 合并 PDF 换行造成的断句（行尾非句末标点且下一行非标题/表格行时合并） |
| `detect_boilerplate(pages, ratio)` | 统计跨页重复行，识别页眉/页脚模板文字（阈值 `max(3, 页数×0.25)`） |
| `_clean_page_text(text, boiler)` | 剔除模板文字与纯页码行，并合并断句 |
| `_render_table(table)` | 把 PyMuPDF 表格对象渲染为 Markdown 表格 |
| `_extract_headings(text)` | 抽取章节标题行 |
| `parse_pdf(pdf_path, with_tables, clean_boilerplate)` | **主入口**：解析 PDF，返回按页组织的 `PageDoc` 列表 |
| `parse_to_text(pdf_path)` | 解析并返回全文纯文本（便于人工核对） |

### 2.3 `src/chunking.py` — 分块

| 名称 | 说明 |
|---|---|
| `Chunk` | 可检索文本块（`content` / `page` / `section` / `ctype` / `parent` / `index`） |
| `_split_sections(text)` | 按标题把页面正文切分为 `(小节标题, 小节正文)` 列表 |
| `build_chunks(pdf_path, chunk_size, chunk_overlap)` | **优化分块**：表格原子块 + 结构感知分块 + 父子块 |
| `chunks_to_documents(chunks)` | `Chunk` → LangChain `Document`（元数据齐全，便于溯源） |
| `split_sentences(text)` | 句子切分（保留标点，去噪） |
| `SentenceUnit` / `build_sentence_index(chunks)` | 句子级索引（表格块按行拆分），供答案合成使用 |
| `build_baseline_chunks(pdf_path, …)` | **基线分块**：复刻 01 工单（固定长度递归切片，无结构感知） |

### 2.4 `src/query_understanding.py` — Query 理解

| 名称 | 说明 |
|---|---|
| `QueryAnalysis` | 分析结果（`core` / `keywords` / `entities` / `years` / `answer_type` / `expand_queries`；`retrieval_queries` 属性输出多路查询） |
| `_strip_noise(question)` | 噪声剥离：剔除公司全称、文件名、套话 |
| `_keywords(question)` | jieba 抽取实词并去停用词 |
| `_entities(question)` | 抽取书名号/引号内容及"领域/行业/系统/工程/标准"等实体 |
| `_answer_type(question)` | 答案类型识别（ratio / amount / number / list / boolean / entity / fact） |
| `QueryUnderstanding.analyze(question)` | **主入口**：输出完整 `QueryAnalysis`（毫秒级，不依赖大模型） |

### 2.5 `src/knowledge_base.py` — 向量化与 FAISS 管理

| 名称 | 说明 |
|---|---|
| `_BatchedEmbeddings` | 分批向量化包装器（默认 50 条/批），避免单请求过大 |
| `get_embeddings()` | 构造 Ollama 向量模型实例（`bge-m3:567m`） |
| `build_documents(pdf_path)` | 优化分块 → `Document` 列表 |
| `build_baseline_documents(pdf_path)` | 基线分块 → `Document` 列表 |
| `save_local(store, dir)` / `load_local(dir)` | FAISS 持久化/加载，**含非 ASCII（中文）路径桥接** |
| `build_kb(pdf_path, persist_directory, force_rebuild, baseline)` | 构建（或重建）向量库 |
| `load_kb(dir)` / `clear_kb(dir)` | 加载 / 清空向量库 |
| `get_all_documents(dir)` | 取回全部文档块（供 BM25 全局语料） |
| `kb_stats(dir)` | 返回块数量等统计 |

### 2.6 `src/retriever.py` — 混合检索

| 名称 | 说明 |
|---|---|
| `RetrievedDoc` | 检索结果（兼容基线字段 `doc` / `score`） |
| `tokenize(text)` | 中英文混合分词（jieba 搜索引擎模式） |
| `BM25Index` | BM25 全局索引（构建一次，复用查询） |
| `HybridRetriever` | **优化检索器**：多路查询 → 双路召回 → RRF → 重排 → 按父块去重 |
| `HybridRetriever._vector_retrieve` | 向量召回（L2 距离 → 相似度），异常降级 |
| `HybridRetriever._rrf` | RRF 融合（k=60） |
| `HybridRetriever.retrieve_candidates` | 返回 `[(文档, 向量相似度, BM25 分)]` |
| `HybridRetriever.retrieve(analysis, k)` | **主入口**：返回重排去重后的 `ScoredDoc` 列表 |
| `BaselineRetriever` | **基线检索器**：向量 + BM25 + RRF，无重排（复刻 01 工单） |
| `format_contexts(results)` | 把检索结果格式化为提示词上下文 |

### 2.7 `src/reranker.py` — 加权线性重排

| 名称 | 说明 |
|---|---|
| `ScoredDoc` | 重排候选（`doc` / `score` / `detail` 分项得分） |
| `_norm_scores(values)` | min-max 归一化到 [0,1] |
| `_keyword_coverage(text, keywords)` | 查询关键词覆盖率 |
| `_numeric_match(text, atype, years)` | 数值/年份匹配度（比例看 `%`、金额看"万元/亿元"） |
| `_entity_match(text, entities)` | 实体匹配度 |
| `Reranker.rerank(analysis, candidates, top_n)` | **主入口**：加权线性重排并返回 Top-N |

### 2.8 `src/answer_builder.py` — 抽取式答案合成

| 名称 | 说明 |
|---|---|
| `AnswerBundle` | 合成结果（`answer` / `citations` / `evidences`） |
| `_kw_cov` / `_num_score` / `_ent_score` / `_len_score` / `_defn_score` | 关键词覆盖 / 数值 / 实体 / 长度 / 定义式句式得分 |
| `_summary_prior(section, keywords, page)` | 章节先验（公司基本信息类问题优先"概览/发行人基本情况"） |
| `_enum_score` / `_signal_score` | 列举型枚举线索 / 按答案类型选择信号得分 |
| `_contrast_penalty` / `_boilerplate_penalty` | 对比词惩罚 / 签署页套话惩罚 |
| `_candidate_units(scored)` | 收集候选句与表格行（含父块，剔除标题行） |
| `build_answer(analysis, scored, max_sentences)` | **主入口**：打分 → Top-N → 拼装带页码引用的答案 |
| `_tidy(text)` | 规整表格行与多余空白，便于阅读 |

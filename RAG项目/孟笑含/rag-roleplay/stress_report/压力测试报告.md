# 压力测试报告

> 基于 RAG 的角色扮演系统 · 性能与压力测试
> 报告日期：2026-09-20 · 测试工具：Apache JMeter 5.6.3（JDK 17）

## 一、测试概述

### 1.1 测试目的
验证系统在高并发下的吞吐能力、响应延迟与稳定性；对比单实例与 nginx 负载均衡架构的扩展性；定位并消除性能瓶颈。

### 1.2 被测系统
- 应用：rag-roleplay FastAPI（uvicorn 单 worker，`LLM_MOCK` 开关支持压测模式）
- 数据层：MySQL（本机 3306）、Redis（WSL 6379）、Milvus（WSL 19530）
- 大模型：压测 API 骨架用 MOCK 模式；端到端场景用真实 DeepSeek API

### 1.3 测试环境
| 项 | 配置 |
|---|---|
| 操作系统 | Windows 11 + WSL Ubuntu-24.04（服务依赖 WSL 内 Redis/Milvus） |
| 硬件 | 31.5GB 内存、Intel Arc 核显（无独显） |
| Python | 3.12（venv） |
| 压测工具 | Apache JMeter 5.6.3 + OpenJDK 17（绿色解压于 tools/） |

### 1.4 测试场景设计

| 场景 | 内容 | 目的 |
|---|---|---|
| S1 | 注册接口，并发 10/50/100 × 10 循环 | 纯后端吞吐基线（不碰 LLM） |
| S2 | 对话接口（`LLM_MOCK=true`、`use_rag=false`），并发 10/50/100 × 10 循环 | API 骨架吞吐上限（不产生 API 费用） |
| S3 | 对话接口（真实 DeepSeek），并发 5 × 2 循环 | 端到端真实延迟（控制成本） |
| S4 | 同上 S2，经 nginx 轮询反代两个 uvicorn 实例（8001/8002），并发 50/100 | 负载均衡扩展性对比 |

## 三、瓶颈分析与压测发现

1. **MySQL 连接池默认配置不足（已修复）**：SQLAlchemy 默认池 size=5 / overflow=10，50 并发时出现 `QueuePool limit reached`，请求排队 30 秒等连接导致超时。已将 `app/models/db.py` 调整为 pool_size=20、max_overflow=40、pool_timeout=10，修复后全场景 0 错误。
2. **单实例吞吐平台约 50 req/s@100 并发**：同步 MySQL/Redis 依赖调用走 anyio 线程池（默认 40 线程），并发超过线程池容量后排队，100 并发时平均延迟升至 1.5s。生产优化方向：async SQLAlchemy / redis.asyncio，或起多 worker 进程。
3. **端到端延迟由外部大模型主导**：S3 真实 DeepSeek 平均 1.26s（1.0~1.9s），QPS≈2（5 并发）。在线 API 场景下系统吞吐上限 = 并发数 / LLM 延迟，本地骨架不是瓶颈。
4. **负载均衡收益显著**：nginx 轮询反代两个实例后，100 并发吞吐 +111%、延迟 -68%；50 并发吞吐 +33%、延迟 -29%。继续横向扩展实例可继续提升（最终受 MySQL/Redis 单点制约）。
5. **BGE 模型懒加载竞态（已修复）**：压测暴露 `use_rag=false` 的请求也会在首次对话时加载 BGE 模型（约 23s/2.5GB），并发下曾出现多线程同时加载。已改为 `LazyModelProxy` 线程安全懒加载，仅首次真正检索时加载一次。

## 四、优化措施与验证

| 问题 | 措施 | 验证结果 |
|---|---|---|
| 连接池耗尽 | pool 20 + overflow 40 + timeout 10s | 修复后 50/100 并发 0 错误 |
| BGE 模型懒加载竞态 | LazyModelProxy 线程安全单例 | 首次加载仅一次，后续请求毫秒级 |
| 单实例吞吐上限 | 文档化 nginx 多实例方案 | 双实例 100 并发吞吐 +111% |

## 五、结论

1. **系统在 100 并发下稳定运行，错误率 0%**，满足课程项目与中小规模部署要求。
2. **负载均衡方案已验证**：nginx + 双实例是最具性价比的横向扩展方式（部署文档已收录）。
3. 若主要流量走真实 LLM：性能瓶颈在外部 API 延迟与配额，本地 API 骨架（约 50 req/s/实例）不是瓶颈。
4. 生产建议：uvicorn 多 worker 或 nginx 多实例 + 数据库连接池按并发调优（压测参数已内置）。

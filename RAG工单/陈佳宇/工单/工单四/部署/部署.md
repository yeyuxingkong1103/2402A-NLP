# 工单4 - 部署文档
## 1. 环境准备
### 依赖安装
```bash
pip install flask pymupdf transformers torch sentence-transformers pymilvus
需要提前启动本地 Milvus 服务（单机版）。

### 环境变量（可选，加速 huggingface 模型下载）
export HF_ENDPOINT=https://hf-mirror.com
##2. 部署步骤

1. 克隆项目代码到 WSL 环境
2. 创建并激活 Python 虚拟环境
python3 -m venv venv_gongdan1
source venv_gongdan1/bin/activate
****
3. 安装项目依赖包
4. 启动 Milvus 服务，确认 Milvus 端口 19530 正常监听
5. 生成 PDF 文件：`python gen_pdf.py`
6. 创建 Milvus 向量集合：`python create_collection.py`
7. 启动 Flask Web 服务：`python main.py`
8. Windows 主机浏览器访问：[http://172.17.189.52:7862](http://172.17.189.52:7862)

##3. 端口与防火墙配置
WSL 内 Flask 监听地址：`0.0.0.0:7862`
WSL 防火墙放行 7862 端口，Windows 主机可以访问 WSL 内网 IP。

##4. 后台常驻部署（可选生产）
使用 gunicorn 替换 Flask 自带开发服务器，搭配 nohup 实现后台常驻。示例：
nohup gunicorn -w 2 -b 0.0.0.0:7862 main:app > run.log 2>&1 &
#5. 系统停止

1. 前台运行：`Ctrl + C` 停止服务
2. 后台运行：查找进程 PID，kill 进程关闭服务

##6. 故障排查

1. 网页打不开：确认 Flask 监听 0.0.0.0，WSL IP 地址正确
2. Milvus 报错：确认 Milvus 服务正常启动，端口 19530 连通
3. CLIP 模型下载慢：配置 hf 镜像环境变量

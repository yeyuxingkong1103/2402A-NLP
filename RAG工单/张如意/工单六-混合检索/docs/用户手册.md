# 工单06 混合检索 用户手册

**工单编号：人工智能NLP-RAG-混合检索任务**

本手册面向两类使用者：
- **使用系统的业务用户**：看第 3、4 节（提问、切换策略、点赞点踩）；
- **部署/维护的工程师**：看第 1、2、5、6 节（安装、建索引、服务、排错）。

---

## 1. 环境准备

```bash
# 1) 安装依赖（含向量库、嵌入模型、BM25 分词、Web 服务）
pip install -r requirements.txt

# 2) 可选但强烈建议：中文分词（不装会自动降级为单字+二元组，精度下降）
pip install jieba

# 3) 首次运行需联网下载嵌入模型（bge-large-zh-v1.5，约 1.3GB）
#    内网环境可提前把模型放到 HuggingFace 缓存目录
```

配置说明（`rag_core/config.py`）：
- 招股书 PDF 默认读取 `D:\工单\RAG 工单\RAG 工单\附件\`；
  如路径不同，改 `SRC_ATTACH` 或把 PDF 放到该目录；
- LLM 生成与 LLM 重排需要环境变量 `DEEPSEEK_API_KEY`：
  ```bash
  set DEEPSEEK_API_KEY=sk-xxxx        # Windows CMD
  export DEEPSEEK_API_KEY=sk-xxxx     # Git Bash / Linux
  ```
  未配置时系统仍可检索，生成/LLM 重排会给出提示或自动回退。

## 2. 建立索引（首次必做）

```bash
python 工单06-混合检索/src/build_index.py
```

- 解析《招股说明书1》《招股说明书2》→ 结构分块 → 表格入库；
- 建立两个向量集合：`prospectus`（bge-large-zh-v1.5）、
  `prospectus_m3e`（m3e-base）；
- 建立 BM25 倒排索引 `data/index/bm25.pkl`，多字段权重
  正文 1.0 / 章节路径 1.6；
- 输出索引统计（含多字段信息）：`results/index_stats.json`。

参数：`--rebuild` 全量重建；`--models bge-large-zh-v1.5` 只建指定模型。
首次建索引视机器性能约需数分钟（含 PDF 解析与向量编码，有 GPU 更快）。

## 3. 启动 Web 服务并提问

```bash
python 工单06-混合检索/src/serve.py            # 默认 http://localhost:8000
python 工单06-混合检索/src/serve.py --port 8080
```

浏览器打开 `http://localhost:8000/`：
1. 在输入框提问，回车发送（支持多轮追问，如先问「兴图新科军用领域收入」，
   再问「这个公司的法定代表人是谁」）；
2. 答案下方显示来源页码；点击「有帮助 / 没帮助」提交反馈，
   自适应重排器会据此优化后续排序（越用越准）。

提问示例：

```
报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
武汉兴图新科电子股份有限公司注册资本是多少？
武汉力源信息技术股份有限公司本次募集资金拟投资哪些项目？
```

## 4. 切换检索策略（三种方式）

### 方式一：Web API（推荐给集成方）

```bash
curl -X POST http://localhost:8000/api/ask \
  -H "Content-Type: application/json" \
  -d '{"question":"注册资本是多少","strategy":"hybrid","reranker":"tfidf","return_trace":true}'
```

- `strategy`：`vector`（向量）/ `fulltext`（全文）/ `hybrid`（混合，默认）；
- `reranker`：`none` / `tfidf` / `llm` / `adaptive` / `cascade`；
- `top_k`：返回片段数（1~20）；
- `return_trace=true`：额外返回每阶段耗时与命中片段明细，便于观察效果。

### 方式二：Python 代码

```python
from rag_core.retriever import Retriever
r = Retriever("prospectus")
res = r.retrieve("军用领域收入", strategy="hybrid", fusion="rrf",
                 reranker="cascade", top_k=5, recall_k=20)
for d in res.docs:
    print(d["doc"], d["page"], round(d["final_score"], 4), d["text"][:60])
```

## 6. 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示「未找到招股说明书 PDF」 | 素材路径不对 | 修改 `rag_core/config.py` 的 `SRC_ATTACH` |
| 检索结果为空 | 索引未建/集合为空 | 运行 `build_index.py`，或 `serve.py --rebuild` |
| 报错 dimension mismatch | 查询模型与库内向量模型不一致 | 用 `embed.set_model(相同模型)`；m3e 用 `prospectus_m3e` |
| LLM 重排打印 warn 后照常返回 | 未配置 API Key 或网络异常 | 正常回退；配置 `DEEPSEEK_API_KEY` 后复跑 |
| 中文分词效果差、布尔查询为空 | 未安装 jieba | `pip install jieba` 后重建 BM25 索引 |
| 首次运行很慢 | 下载嵌入模型 / PDF 解析 | 等待完成；模型有本地缓存后恢复秒级 |
| 端口被占用 | 8000 已被占用 | `--port 8080` 换端口 |

## 7. 数据与隐私

- 反馈数据默认写入 `data/index/rerank_feedback.json`，
  演示脚本改用 `results/*_feedback.json`（互不污染）；
- 检索与索引全部本地完成，仅 LLM 生成/LLM 重排会把「问题 + 命中片段」
  发送到配置的模型服务（DeepSeek）；
- 清除反馈：删除对应 JSON 文件即可恢复初始排序。

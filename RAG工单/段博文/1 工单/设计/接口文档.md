# 接口文档

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统
> 服务地址：http://localhost:8000 ，交互式文档：http://localhost:8000/docs

## 一、接口总览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | / | 首页（跳转 /web/index.html） |
| GET | /api/health | 健康检查 |
| POST | /api/upload | 上传 PDF |
| POST | /api/ingest | 解析 + 切分 + 入库 |
| GET | /api/search | 纯检索（不调 LLM） |
| POST | /api/chat | 问答（检索 + LLM，支持流式） |

## 二、接口详情

### 1. 健康检查 GET /api/health

无参数。响应示例：

```json
{
  "status": "ok",
  "collection_count": 1405,
  "data_dir": ".../src/data"
}
```

### 2. 上传 PDF POST /api/upload

Content-Type: multipart/form-data

| 参数 | 类型 | 说明 |
|---|---|---|
| file | File | PDF 文件（仅支持 .pdf） |

响应：`{"filename": "...", "saved_path": "...", "size": 12345}`

### 3. 入库 POST /api/ingest

请求体：

```json
{"files": ["招股说明书1.pdf"]}
```

`files` 省略时处理 data 目录下全部 PDF。流程：解析 → 切分(500/80) → 向量化 → 写入 Milvus → 重建 BM25。

响应：`{"processed": 1, "ingested": 1, "collection_count": 1405}`

### 4. 纯检索 GET /api/search

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| query | string | 必填 | 查询文本 |
| top_k | int | 5 | 返回条数（1~20） |

响应：

```json
{
  "query": "...",
  "total": 5,
  "results": [
    {"page_content": "...", "score": 0.58, "source": "招股说明书1.pdf", "page_number": 51}
  ],
  "elapsed_sec": 4.5
}
```

### 5. 问答 POST /api/chat

请求体：

```json
{"query": "武汉兴图新科电子股份有限公司注册资本是多少？", "top_k": 5, "stream": false}
```

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| query | string | 必填 | 用户问题 |
| top_k | int | 5 | 引用资料条数 |
| stream | bool | false | true 时 SSE 流式返回 |

非流式响应：

```json
{
  "answer": "武汉兴图新科电子股份有限公司注册资本为5,520万元。（来源：招股说明书1.pdf，第51页）",
  "references": [
    {"page_content": "...", "score": 0.58, "source": "招股说明书1.pdf", "page_number": 51}
  ]
}
```

流式响应（stream=true）：text/event-stream，逐段推送：

```text
data: {"chunk": "武汉兴图新科..."}
data: {"done": true}
```

## 三、错误码

| 状态码 | 场景 |
|---|---|
| 400 | query 为空 / top_k 越界 / 文件非 PDF / data 目录无 PDF |
| 500 | 文件保存失败 / LLM 生成失败 |

## 2 关键设计

### 2.1 配置化（`研发/assessment_config.yaml`，14.9 KB）

所有阈值（扫描页判定、低文本页阈值、长度分档、SimHash 距离、敏感规则开关）**全部外置**，
并支持环境变量覆盖（报告中 `skill.env_overrides` 记录了实际覆盖项）。
→ 满足 `_共享约定.md` §4.3「阈值配置化」。

### 2.2 断点续跑与状态

`研发/data/state.json`（865.9 KB）记录已分析文件指纹，报告 `run.skipped_from_state` 给出续跑跳过数，
避免 1700 份重复解析。→ 满足资源纪律 §5.5 规则 8「全量必须支持 --resume」。

### 2.3 错误兜底

报告 `errors` 段记录了 **84** 条错误（损坏 PDF 解析失败等），逐条含文件与原因，
**未裸崩**；损坏文件另进 `pending_lists.corrupted_files`。→ 满足 §4.4「错误处理」。

## 4 未达标 / 限制（如实）

| 项 | 说明 |
| --- | --- |
| 敏感信息命中为 0 | 该语料（专利/工业文档）本身不含身份证/手机号等规则覆盖的敏感项；**不是检测未生效**——规则已启用，可用注入样本复核（见测试用例） |
| MD5 完全重复为 0 | 1700 份为互不相同的专利文档；近重复（SimHash）另有 2 组版本冲突 |
| 损坏文件 83 份 | 占 4.88%，已隔离并逐条记录原因；未尝试修复（超出本工单范围） |
| 扫描型 553 份 | 占 32.53%，本机**无 OCR 引擎**，这部分内容无法进一步解析——与工单14/15 的结论一致 |

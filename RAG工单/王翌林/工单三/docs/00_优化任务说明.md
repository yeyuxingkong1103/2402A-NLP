# 优化任务说明（工单二）

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统优化
> 基础版本：工单一（基于PDF文档的问答系统）
> 项目路径：/home/dabaie/code/工单/工单二
> 源文档：/home/dabaie/code/工单/附件/招股说明书1.pdf

## 一、任务背景

工单一已实现基础 RAG 问答系统（PDF 解析 → 语义分块 → bge-m3 向量化 → Milvus 检索 → DeepSeek-v4-flash 生成），本工单在复制的项目副本上进行系统性优化，解决基础版在检索准确率、响应延迟、多语言支持方面的不足。

## 二、优化目标（量化指标）

| 指标 | 基线（工单一） | 目标（工单二） |
|------|--------------|--------------|
| 检索准确率（Recall@5 / 命中率） | 以 Step 1 实测基线为准 | ≥ 90% |
| 端到端响应时间（P95） | 以 Step 1 实测基线为准 | ≤ 3 秒 |
| 中英文问答 | 仅中文可靠 | 中英文均可靠 |
| 系统稳定性 | 基础容错 | 异常降级、超时保护、资源占用合理 |

## 三、优化方向（技术清单）

1. **混合检索**：BM25（稀疏）+ 向量检索（稠密）融合排序（RRF）
2. **重排序**：bge-reranker 对 Top-N 候选精排
3. **查询改写**：同义扩展 / 指代消解 / 中英互译，提升召回
4. **语义分块**：按语义边界分块，替代固定长度分块
5. **表格解析优化**：pdfplumber 表格结构化，表格问答能力
6. **多语言支持**：英文提问 → 中文检索 → 中文/英文回答链路
7. **缓存**：语义缓存命中直接返回，降低延迟与 LLM 调用
8. **流式输出**：SSE 流式，首 token 时间前置
9. **异步与容错**：并发处理、超时降级、异常兜底

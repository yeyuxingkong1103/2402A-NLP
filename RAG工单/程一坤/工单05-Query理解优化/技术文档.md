# 工单05 技术文档：Query理解优化（多轮对话）

> 工单编号：人工智能NLP-RAG-Query理解优化任务

## 一、实现方案

在 RAG 问答之上增加**多轮对话层**（`run_chat.py` / `MultiTurnRAG`）：

```
用户问题 → ① Query改写（LLM结合对话历史：指代消解+省略补全）
        → ② 双库检索（双文档库 zgs_all_v1 + 图像语义库 zgs2_img_v1）
        → ③ 关键词重排 + Top-K → ④ LLM 生成 → 更新对话历史
```

核心是 ①：LLM 把"他参与的哪个工程…"改写成"武汉兴图新科电子股份有限公司参与的哪个工程…"，
把"那武汉力源信息技术股份有限公司呢？"改写成"武汉力源信息技术股份有限公司的法定代表人是谁？"
（继承上一轮意图框架、替换主体）。Prompt 内置 2 个 few-shot 示例约束改写方向。

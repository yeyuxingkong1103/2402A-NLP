---

## 一、部署方案

将工单九的 Graph RAG 金融问答系统通过 Docker 容器化，部署在 WSL2 + Docker Desktop 环境中。

---

## 二、技术栈

- 基础镜像：python:3.11-slim
- Web 框架：Streamlit 1.63.0
- 检索：Graph RAG（向量 + 图谱）
- LLM：DeepSeek API
- 容器编排：Docker Compose
- 嵌入模型：bge_m3（挂载）
- 重排模型：bge-reranker-base（挂载）

## 四、关键配置

### 4.1 Dockerfile

```dockerfile
# 工单编号：人工智能 NLP-RAG-金融问答系统部署
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple && \
    pip install --no-cache-dir -r requirements.txt

COPY app_v9.py .
COPY step4_rag_v9.py .
COPY config_v9.py .
COPY questions_v9.json .
COPY rag_project_v9 ./rag_project_v9
COPY docs ./docs

EXPOSE 8501

CMD ["streamlit", "run", "app_v9.py", \
     "--server.port=8501", \
     "--server.address=0.0.0.0"]
```

### 4.2 docker-compose.yml

```yaml
# 工单编号：人工智能 NLP-RAG-金融问答系统部署
services:
  rag-finance:
    build: .
    container_name: rag-finance
    ports:
      - "8501:8501"
    env_file:
      - .env
    volumes:
      - ./rag_project_v9:/app/rag_project_v9
      - ./models_rag:/models
    restart: unless-stopped
    networks:
      - rag-net

networks:
  rag-net:
    driver: bridge
```

## 七、过程问题记录

### 问题 1：pip 下载 CUDA torch 超时

- **现象：** 构建时卡在下载 `nvidia_cudnn_cu13`（553MB），`Read timed out` 失败。
- **原因：** `sentence-transformers==6.0.1` 默认拉取 CUDA 版 torch，连带一堆 nvidia 包，约 1.5GB。
- **解决：**
  1. `requirements.txt` 改为 `torch==2.11.0+cpu` + `sentence-transformers==2.7.0`；
  2. 加 `--extra-index-url https://download.pytorch.org/whl/cpu`；
  3. Dockerfile 里配置清华 pip 镜像。

### 问题 2：WSL 发行版混淆

- **现象：** 在 `docker-desktop` 发行版里跑 `docker` 命令报错。
- **原因：** Docker Desktop 自带的 WSL 发行版禁止直接调用 Docker CLI。
- **解决：** 在 Ubuntu 发行版或 Windows PowerShell 中操作。

### 问题 3：模型路径含中文

- **现象：** 挂载 `D:\models（文本嵌入模型）\bge_m3` 时路径解析失败。
- **原因：** Docker 对含中文、括号的路径支持不佳。
- **解决：** 将模型复制到纯英文路径 `~/rag_finance/models_rag/`，再挂载到容器 `/models`。

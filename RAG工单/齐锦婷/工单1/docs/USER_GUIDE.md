# 用户手册

## 上传 PDF

打开系统首页，点击左侧“上传 PDF”，输入管理员口令并选择 PDF。系统会创建后台任务，依次执行远程 MinerU 解析、PyMuPDF 兜底、切片、Embedding、Milvus 入库。

## 提问

选择已完成的文档，在中间输入问题并点击“提问”。答案只根据检索到的招股说明书证据生成，右侧会显示 PDF 物理页码、章节和原文片段。

## 中文/英文

顶部按钮切换回答语言。自动模式会根据问题语言回答；引用始终保留 PDF 原文。

## 反馈

每个答案下方可点击有帮助/无帮助。反馈只用于质量分析，不会自动改写知识库。

## 常见问题

- 文档长时间处理中：检查 `docker compose logs -f worker`，并确认模型目录挂载正确。
- 无法生成答案：检查 `DEEPSEEK_API_KEY` 和远程服务地址；检索证据仍可在日志和页面中确认。
- MinerU 失败：系统自动回退 PyMuPDF；复杂表格可能需要配置 Qwen-VL-Max 或人工复核。

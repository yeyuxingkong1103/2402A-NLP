# 工单十七 · 接口文档（API）

Base URL: `http://<host>:8017`

---

## 1. 健康检查
`GET /health`
- 响应 `200`：`{"status":"ok","rss_mb":54.0,"cache_size":12}`

---

## 2. 问答（核心接口）
`POST /api/v1/chats_openai/{chat_id}/chat/completions`
- Path: `chat_id` 会话 ID
- Body (JSON)：
  ```json
  { "question": "什么是淬火工艺？", "chat_id": "c1" }
  ```
- 响应 `200`：
  ```json
  {
    "chat_id": "c1",
    "question": "什么是淬火工艺？",
    "answer": "淬火是...",
    "docs": ["..."],
    "cache_hit": false
  }
  ```
- 说明：优先查语义缓存；未命中则检索→（连接池）→LLM 生成→写缓存。

`GET /api/v1/chats_openai/{chat_id}/chat/completions?question=...` 等价于 POST 的查询形式。

---

## 3. 文档解析（异步）
### 3.1 提交解析
`POST /api/v1/documents/parse?filename=demo.pdf`
- Body (JSON，可选)：`{"url":"...","data_id":"..."}`
- 响应 `200`：`{"code":0,"msg":"parsing enqueued","task_id":"<uuid>"}`
- 说明：异步入队，立即返回，不阻塞问答。

### 3.2 查询解析状态
`GET /api/v1/documents/parse/{task_id}`
- 响应 `200`：`{"task_id":"...","status":"done","created_at":"..."}`
- status: `pending` / `processing` / `done` / `failed`

---

## 4. 监控指标
`GET /metrics`
- Prometheus 文本格式，包含：
  - `rag_requests_total` 请求总量
  - `rag_request_duration_seconds` 延迟直方图（含 P95/P99）
  - `rag_inflight_requests` 在途请求
  - `rag_queue_depth` 解析队列深度
  - `rag_cache_size` / `rag_cache_hits_total` 缓存条目/命中
  - `rag_process_rss_mb` 进程内存

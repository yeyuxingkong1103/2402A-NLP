# 招股说明书多轮检索问答系统

> 工单编号：**人工智能 NLP-RAG-Query 理解优化任务**
> 项目：RAG 项目 · Query 理解优化（八维文化与产业研究院）
> 前置工单：01 基于 PDF 文档的问答系统 → 02 问答系统优化 → 03 表格解析及检索优化 → 04 图像内容解析及检索优化

在既有「招股说明书检索问答」的基础上，新增 **多轮对话能力** 与 **Query 理解优化**，
使系统能够正确理解并回答带指代、省略、跨文档切换的自然对话：

```
Q1：报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
Q2：他参与的哪个工程荣获了国家科技进步一等奖？        ← 「他」= 兴图新科
Q3：这个公司的法定代表人是谁？                        ← 「这个公司」= 兴图新科
Q4：那武汉力源信息技术股份有限公司呢？                ← 省略谓语，继承上一轮意图
Q5：武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？有哪些销售处？
```

## 一、能力概览

| 能力 | 说明 |
|---|---|
| 多轮会话记忆 | 记录话题实体、活跃文档、上一轮意图（`conversation.py`） |
| 指代消解 | 「他 / 这个公司 / 该公司」→ 当前话题公司全名（`query_rewriting.py`） |
| 省略补全 | 「那 X 呢？」→ 继承上一轮意图骨架并替换主语 |
| 文档级路由 | 公司别名 → 源文件名，避免两份招股说明书串味 |
| 混合检索 | 向量召回 + BM25 + RRF 融合 + 多信号重排（含话题实体加成） |
| 抽取式答案 | 零幻觉、可溯源（源文件 / 页码 / 片段） |
| 中英双语 | 英文提问经术语映射检索中文知识库，可自动翻译答案 |
| 轻量可复现 | 不依赖 faiss / torch，向量走 Ollama HTTP + numpy |

## 二、快速开始

```powershell
# 0) 依赖（Python 3.10+）
pip install -r requirements.txt

# 1) 构建知识库（解析 PDF → 切片 → bge-m3 向量化 → 落盘）
python build_kb.py --rebuild

# 2) 命令行多轮演示（工单给定的 5 轮对话）
python run_demo.py

# 3) 评测准确率与响应时间
python evaluate_multiturn.py

# 4) 启动演示界面（浏览器访问 http://localhost:8501）
streamlit run app.py
```

> 前置服务：本地 Ollama（`ollama serve`），需具备 `bge-m3:567m`（嵌入）与 `deepseek-r1:1.5b`（可选翻译/改写）。

### 核心模块

| 模块 | 职责 |
|---|---|
| `config.py` | 全局参数、路径、权重、阈值 |
| `pdf_parser.py` | PDF 正文 + 表格抽取 |
| `chunking.py` | 结构感知切片（text / table） |
| `embedding.py` | Ollama bge-m3 批量向量化 |
| `knowledge_base.py` | 知识库构建 / 持久化 / 加载（向量 + BM25） |
| `retriever.py` | 混合检索（向量 + BM25 + RRF + 文档路由） |
| `reranker.py` | 多信号加权重排（含多轮话题加成） |
| `query_understanding.py` | 单轮 Query 理解（关键词 / 实体 / 答案类型 / 同义词扩展） |
| **`conversation.py`** | **多轮会话状态管理（本工单核心）** |
| **`query_rewriting.py`** | **多轮 Query 改写：指代消解 + 省略补全（本工单核心）** |
| **`figure_semantics.py`** | **矢量组织结构图 → 可检索语义文本（沿用 04 工单能力）** |
| `answer_builder.py` | 抽取式答案合成与证据溯源 |
| `qa_engine.py` | 多轮问答引擎（串联全链路） |
| `i18n.py` | 中英双语支持 |

### 工具脚本（`tools/`）

| 脚本 | 用途 |
|---|---|
| `gen_flowcharts.py` | 生成架构图与流程图 → `设计/assets/` |
| `render_ui_shots.py` | 依据真实运行结果离线渲染界面截图 → `演示/shots/` |
| `make_demo_video.py` | 截图合成带字幕的演示视频 |
| `run_functional_tests.py` | 功能 / 容错 / 稳定性测试（TC-01 ~ TC-10） |
| `update_kb_figures.py` | 增量注入图形语义块（无需全量重建） |
| `diag_retrieval.py` / `diag_q1.py` | 检索排序诊断 |

| 验收项 | 标准 | 实现 |
|---|---|---|
| 问答准确性 | ≥ 90% | **实测 100%（5/5）**，多轮改写 + 混合检索 + 抽取式合成（见 `../测试/测试报告.md`） |

| 多语言支持 | 中英问答 | 界面双语 + 英文术语映射 + 可选翻译（`i18n.py`） |
| 系统稳定性 | 高可用、容错 | 异常兜底、空检索提示、会话可重置 |
| 代码注释 | 含工单编号 | 各模块文件头均标注 |

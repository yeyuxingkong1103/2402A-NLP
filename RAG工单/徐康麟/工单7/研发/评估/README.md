本目录是「工单7：人工智能NLP-RAG-功能测试及评估」的评估代码。**框架完全自研，不依赖
ragas / pandas / gradio**（本机无这些包，且工单要求禁止安装）。

## 三、判分口径（写清楚，便于复核）

| 指标 | 定义 |
|---|---|
| `normalize` | 全角→半角；千分位逗号删除（仅当夹在数字之间，`824,961`→`824961`）；其余标点/符号→**空格**（不是删除）；空白折叠；小写化 |
| `keyword_coverage` | 答案对期望关键词的命中比例，返回 `(命中数, 总数, 覆盖率, 命中表, 缺失表)` |
| **是否判对（严格）** | **未拒答** 且 覆盖率 ≥ `KEYWORD_THRESHOLD`(0.6) |
| **部分正确** | 未拒答、未达严格，且满足任一：覆盖率 ∈ [0.3, 0.6)；或关键词**数值原子**覆盖率 ≥ 0.6（应对单位换算/英文作答） |
| `recall@k` | top-k 片段**合并正文**对关键词的召回率；同时报 recall@5 与 recall@10 |
| `page_hit` | 命中页是否落在期望页区间（支持 `a-b` 与 `a-b;c-d`；多文件时第 i 个文件 ↔ 第 i 个区间） |
| `cross_corpus_leak` | top-3（另加 top-10）命中里是否出现**不属于期望语料**的文件名 |
| `citation_leak` | `citations[].corpus` 是否属于期望语料 —— 「引用页属于别家公司」的直接判据 |

### 两个关键口径设计（都是踩过坑才加的）

1. **数字边界**：子串匹配会把 `11.65` 里的 `1.65`、`18.25` 里的 `18.2` 当成命中。
   因此对所有以数字开头/结尾的关键词施加边界约束（匹配位相邻字符不得是数字或小数点），
   否则年报数值题得分会虚高。
2. **标点替换为空格而非删除**：年报表格相邻单元格的数字原本靠 `|`/`,` 分隔，
   直接删掉会让 `| 29,428,896,087.24 | 24,277,670,240.59 |` 粘成
   `29428896087.2424277670240.59`，数字边界判定随即把**真命中**误判为不命中。
   实测这一处曾把 recall@10 从 **0.76 压到 0.52**。现在标点→空格，并保留
   「宽松口径（去空格）」作为兜底，两种口径取"或"。

### 为什么算「部分正确」

工单允许把「答案正确但关键词表述不同」报为部分正确，前提是**判据写清楚**。本框架的判据是
上面表格里的两条，且部分正确**不计入严格准确率**，汇总里两个数字并列给出。

## 四、已知局限（如实列出）

1. **本机无 gradio / ragas / pandas**，且工单禁止安装，故判分完全自研：用「关键词覆盖率 +
   数值原子核对」近似替代 ragas 的 answer-correctness / faithfulness 指标。
   局限：**不能识别"表述完全不同但语义等价"的答案**（例如把「拨备覆盖率183.12%」写成
   「拨备水平约1.8倍」）；这类会被判为未命中。
2. **关键词判分天然偏严**：`answer_keywords` 是逐字短语，改写即失配。缓解手段是
   「部分正确」档 + 「LLM 候选口径」反事实诊断，但都不是语义判分。
3. **不含人工复核**：17 题全部机器判分，未做人工抽检（本工单范围内无人工标注资源）。
4. **`use_cache=False`**：为保证测的是"用户第一次问"的真实延迟，每题都关闭答案缓存。
   因此本框架报告的是**冷启动口径**；若开启缓存，重复提问的 total 会接近 0ms。
5. **响应时间受机器负载影响大**：同一份代码、同一索引、同一问题集连续多轮实测，
   平均总耗时在 ~1.3s ~ ~2.7s 波动、SLA(≤3000ms) 达标率在 13/17 ~ 17/17 波动，
   原因是本机 Ollama 只有 1 个 CPU 实例，会与其它任务（如重建索引）争抢算力。
   **SLA 结论必须连同运行环境一起读**。
6. **评估期间上游代码可能变动**：实测评估过程中 `app/core/retriever.py` 被上游修改过
   （语料路由修复）。因此每次运行的日志里都记录了 `run_id` / `chunk_total`；
   重要结论请连同 `评估运行日志.txt` 的代码修订时间一起引用。
7. **`page_hit` 对宽区间偏松**：期望区间 `5-67` 这种宽范围，只要命中页落在区间内就算命中，
   即使命中的是**无关的**季度表（Q07 即如此：页命中 True，但全年数据其实没召回）。
   该指标应作为辅助，不能单独当作检索质量结论。
8. **数值原子等价的 10^n 容差**（`_number_equivalent`，用于亿元↔billion 换算）在极小概率下
   会把 `1.65` 与 `16.5` 视为等价；它只用于「部分正确」补充判据，不影响严格准确率。

## 五、结果怎么读

`评估汇总.json` 里有两套准确率，别混用：

* `准确率.严格准确率` —— 官方口径（未拒答 且 覆盖率≥0.6）。
* `LLM候选对照口径(反事实诊断).候选口径准确率` —— **反事实诊断，非官方准确率**：
  把最终答案换成生成层的 LLM 候选（检索不变）后重新判分，用来区分
  「检索/生成答错了」和「答案本来对、被自己的原子护栏回退丢掉」。

`检索问题分析.md` 的第三节是深度归因，第四节是问题 TOP5，第五节是可执行改进建议。

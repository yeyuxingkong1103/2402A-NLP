# 调试与微调专用视觉语言模型 · 系统设计文档

> 工单编号：**人工智能NLP-RAG-微调专用视觉语言模型工单（工单十六）**
> 项目名称：RAG
> 数据集：IMDR（中文专利 VQA，10096 题 / 1700 篇 PDF） + RAGFlow 解析图文块
> 基座模型：`HuggingFaceTB/SmolVLM-256M-Instruct`（本机实跑） / `Qwen/Qwen2-VL-2B-Instruct`（生产配置）

---

## 一、设计目标与范围

RAGFlow 默认集成的视觉语言模型（如 Qwen-VL）对**工业术语**（淬火、公差配合等）
与**复杂工程图纸**理解不足。本工单设计并实现一条完整的领域适应流水线：

```
IMDR QA 对 + 专利 PDF + RAGFlow 图文块
        │
        ▼
[数据准备] PDF 页面渲染 · 页码定位 · 图文块解析
        │
        ▼
[数据转换] image / question / answer 统一 JSONL（+ LLaMA-Factory 导出）
        │
        ▼
[模型微调] LoRA（语言侧，冻结视觉塔）· cosine + warmup · 梯度累积
        │
        ▼
[专业评估] 专业术语准确性 · 图纸推理正确性 · BLEU/ROUGE · 失败分析
        │
        ▼
[产出物] 适配器 · 训练日志 · 评估报告 · 图表/截图/视频
```

设计范围（对应工单三项任务要求）：

| # | 工单要求 | 设计落点 |
|---|---|---|
| 1 | 准备微调数据 | `pdf_page_extractor` + `ragflow_chunks` + `data_converter` |
| 2 | 配置与启动微调 | `config/*.yaml` + `lora_trainer` |
| 3 | 实施专业评估 | `industrial_metrics` + `evaluator` + `report_builder` |

## 二、总体架构

![系统总体架构](流程图/01_系统总体架构图.png)

系统自下而上分六层：

| 层 | 职责 | 关键模块 |
|---|---|---|
| 数据源层 | IMDR QA 对、专利 PDF、RAGFlow 图文块 | `data/raw/`、`vector_db/` |
| 数据准备层 | PDF 页面栅格化、页码/答案页定位、图文块字段对齐 | `pdf_page_extractor.py`、`ragflow_chunks.py` |
| 数据转换层 | 统一 `image/question/answer`，导出 LLaMA-Factory 格式 | `data_converter.py` |

| 产出层 | 适配器、日志、报告、图表、截图、视频 | `output/`、`tools/` |

## 三、核心流程与决策

![核心流程与决策](流程图/02_核心流程与决策图.png)

关键决策点：

1. **页码可解析？**
   图纸类题目（group 2/3）题干显式给出「第 N 页」，正则解析后直接渲染该页；
   文本类题目（group 1）无页码，改用「正确选项文本 → PDF 全文检索 → 定位承载页」
   的方式确定图像，保证每条样本都具备可作答的视觉输入。
2. **loss 是否正常下降？**
   若出现 NaN 或持续不降，回退调整学习率 / 梯度累积 / LoRA rank 后重训。
3. **工业指标提升是否 ≥5%？**
   达标输出评估报告；未达标进入超参搜索与数据清洗闭环。

## 四、数据设计

### 4.1 数据源与规模

| 数据源 | 规模 | 字段 |
|---|---|---|
| IMDR `questions.jsonl` | 10096 题 / 1700 文档 | question, document, options[A-D], answer(字母), group |
| 专利 PDF | 1700 篇（本工单抽取 128 篇） | 附图页 + 正文页 |
| RAGFlow 图文块 | 按含图页生成 | content_with_weight, img_id, page_num_int, position_int, top_int |

IMDR 三类问题均衡（各约 3366 题）：

| group | 含义 | 考察维度 |
|---|---|---|
| 1 | 文本术语类（"根据文本信息，该静电除尘器的发明人是"） | 专业术语准确性 |
| 2 | 图纸位置类（"部件 4 相对部件 5 的位置关系"） | 图纸推理正确性 |
| 3 | 图纸原理类（"气流方向首先经过哪个部件"） | 图纸推理正确性 |

### 4.2 RAGFlow 图文块字段对齐

RAGFlow 在 `rag/nlp/__init__.py` 的 chunk 构建与 `add_positions()` 中落库以下字段，
本工单的 `ragflow_chunks.synthesize_chunks()` 生成同构结构，便于离线复现：

```python
{
  "id": "CN100342976C-7",
  "doc_id": "CN100342976C",
  "docnm_kwd": "CN100342976C.pdf",
  "content_with_weight": "……页文本……",
  "img_id": "img-CN100342976C-7",
  "page_num_int": [7],
  "position_int": [[7, 0, 595, 0, 842]],
  "top_int": [7000],
}
```

含图页判定：`n_raster > 0 or n_drawings >= 25 or len(text) < 260`。

### 4.3 转换后样本格式

```json
{
  "id": "CN100342976C-g2-1",
  "source": "imdr",
  "image": "data/images/CN100342976C_p7.png",
  "question": "请阅读提供的专利文件页面，回答问题并选出唯一正确选项。...",
  "answer": "A. 部件4位于部件5的左侧",
  "gold_letter": "A",
  "group": 2,
  "doc": "CN100342976C.pdf",
  "page": 7
}
```

同时导出 LLaMA-Factory（sharegpt + images）格式到 `data/llamafactory/`。

### 4.4 数据切分

- 训练/评估**按文档切分**（train 96 篇 / eval 32 篇），避免同文档泄漏；
- 评估集按 group 分层抽样（每类 36 题，共 108 题），保证两个评估维度样本均衡；
- 训练集额外混入 RAGFlow 图文块对（看图概述该页技术内容），强化图像—术语对齐。

## 五、模型与微调设计

### 5.1 基座选择

| 场景 | 模型 | 参数量 | 说明 |
|---|---|---|---|
| 本机实跑（CPU） | SmolVLM-256M-Instruct | 256M | 单块 512 图像，CPU 可完成 ≥1 epoch |
| 生产（GPU） | Qwen2-VL-2B-Instruct | 2B | RAGFlow 默认集成 VLM，QLoRA 4bit |

两套配置的图像预处理口径保持一致（`max_image_size=512`），保证结论可迁移。

### 5.2 LoRA 配置

![LoRA 微调训练流程](流程图/03_LoRA微调训练流程.png)

| 参数 | 取值 | 依据 |
|---|---|---|
| r / alpha / dropout | 16 / 32 / 0.05 | 小模型领域适应常用区间 |
| target_modules | q/k/v/o/gate/up/down_proj | 自动探测，**排除 vision_model** |
| 冻结策略 | 视觉塔 + 多模态投影冻结 | 工单要求"设置正确的图像预处理"；只适配语言侧 |
| 学习率 / 调度 | 2e-4 / cosine，warmup 0.05 | 防止小模型早期震荡 |
| batch / 累积 | 1 × 8 | 等效 batch 8 |
| 损失掩码 | 仅 assistant 段 | prompt 部分 `label=-100` |

可训练参数 5.77M / 262.25M（2.20%），视觉塔保持冻结。

### 5.3 图像预处理

- `do_image_splitting=False` + `max_image_size=512`：单块固定边长；
- 关闭切片使图像 token 由 ~900 降至 ~100，CPU 训练耗时下降约 8 倍，
  且训练与评估使用同一处理器实例，杜绝口径漂移。

## 六、评估设计

![工业准确性评估流程](流程图/04_工业准确性评估流程.png)

### 6.1 指标定义

| 维度 | 指标 | 定义 |
|---|---|---|
| 专业术语准确性 | 选项判定准确率 | group 1 题目预测选项字母 == 标准答案 |
| | 术语 F1 / 召回 | 以标准答案为术语集合，衡量预测覆盖 |
| 图纸推理正确性 | 选项判定准确率 | group 2/3 题目预测选项字母 == 标准答案 |
| 通用文本 | BLEU（zh 分词） | sacrebleu |
| | ROUGE-L / 精确匹配 | rouge / 归一化字符串比较 |

术语抽取：领域词表（淬火/公差配合/电极…）命中 + jieba 词性过滤（n/vn/v/a）。

### 6.2 对比与失败分析

- 基线模型与 LoRA 模型**在同一评估集、同一处理器**上逐题生成；
- 失败分析输出：仍错题、由错变对（修复）、由对变错（退化）三类，
  并按"术语理解偏差 / 空间关系判读 / 原理推理 / 未按格式输出"归因。

## 七、关键设计权衡

| 权衡 | 取舍 | 理由 |
|---|---|---|
| 模型规模 | 256M 实跑 + 2B 生产配置 | CPU 环境必须能真实跑通，同时交付可上生产配置 |
| 图像切片 | 关闭 | 图像 token 与训练耗时下降约 8 倍；如需小字标注可开启 |
| 数据规模 | 128 篇 / 623 条训练样本 | 在 CPU 训练时长与效果提升之间取平衡 |
| 文本类问题配图 | 用答案文本反查承载页 | 使文本题也成为"可看图作答"的多模态样本 |

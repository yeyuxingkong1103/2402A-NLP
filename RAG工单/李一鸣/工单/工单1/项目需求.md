# 公司信息数据采集项目需求与任务清单

## 项目目标

基于 n8n 建立公司信息数据采集工作流，完成从多源采集、内容抽取、智能清洗、聚合到结构化存储的自动化闭环。

## 需求清单

| 模块 | 功能 | 结果 |
| --- | --- | --- |
| 触发器 | RSS、Cron、Webhook | 支持定时、订阅和外部事件触发 |
| 数据采集 | HTTP Request、Scrape、FireCrawl | 获取静态和动态网页内容 |
| 数据处理 | Filter、AI Agent、Code | 过滤、实体抽取、字段对齐 |
| 数据聚合 | Aggregate、Item Lists | 统一多来源数据结构 |
| 数据输出 | 文件写入、数据库、通知 | 输出 `data.json` 并通知结果 |

## 任务清单

1. 配置 RSS、Cron、Webhook 触发器。
2. 配置网页请求和内容抓取节点。
3. 配置关键词、日期、来源过滤规则。
4. 使用 AI Agent 抽取公司、行业、时间等实体。
5. 使用 Code 节点完成字段清洗和标准化。
6. 聚合数据并写入 `data.json`。
7. 增加错误处理、日志和执行结果通知。

## 验收标准

- 覆盖触发、采集、处理、聚合、输出五类功能模块。
- 交付需求清单、任务清单和流程图源文件。
- 输出字段稳定，缺失字段有明确的空值策略。

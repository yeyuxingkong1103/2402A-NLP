# PDF 文档图像内容解析及检索优化说明报告

## 1. 项目目标

工单 04 要求在已有 PDF-RAG 系统基础上，进一步支持 PDF 中图像内容的解析与检索，使系统能够回答与图片、示意图、流程图、结构图、IC、芯片等相关的问题。

## 2. 技术栈

- 页面框架：Streamlit
- RAG 框架：LangChain
- PDF 解析：MinerU
- 向量数据库：FAISS
- 检索策略：文本/表格/图像三索引 + MMR 检索
- Embedding：通义 DashScope `text-embedding-v4`
- LLM：通义千问 `qwen-plus`

## 3. 图像解析方案

MinerU 会将 PDF 解析为 Markdown。对于 Markdown 中的图片引用，例如 `![](image.png)`，系统会自动抽取图片路径、图片替代文本以及图片前后相邻文本，组合为图像语义片段。

每个图像片段包含：

- 图片编号；
- 图片说明；
- 图片路径；
- 相邻上下文；
- 元数据 `type: image`。

## 4. 三索引检索优化

系统分别构建三个 FAISS 索引：

1. 文本索引：保存普通章节文本。
2. 表格索引：保存 Markdown 表格内容。
3. 图像索引：保存图片引用和相邻上下文。

当问题包含“图、图片、示意、流程、结构、IC、芯片、设备”等关键词时，系统优先检索图像索引；当问题包含金额、表格、比例、报告期等关键词时，优先检索表格索引；最后再合并文本索引结果。

## 5. Prompt 优化

提示词要求模型：

- 图像类问题优先依据图像片段回答；
- 表格类问题优先依据表格片段回答；
- 保留关键术语、单位和数值；
- 无明确依据时说明未找到；
- 不得编造。

## 6. 批量评测

批量问答输出 `image_optimized_answers.json`，其中包含问题 ID、问题、答案和检索依据。每条依据都会标注 `text`、`table` 或 `image` 类型，方便检查答案来源。

## 7. 完成情况

项目已完成 PDF 自动分批解析、Markdown 缓存、文本抽取、表格抽取、图像引用抽取、三索引检索、图像类问题优先召回、单问题问答、批量问答和答案导出，满足工单 04 的图像内容解析及检索优化要求。

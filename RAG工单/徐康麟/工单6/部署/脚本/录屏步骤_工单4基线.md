## 1. 录制前准备（约 2 分钟）

```powershell
cd E:\gao6gongdan\工单4

# 1) 环境体检（期望：FAIL=0）
pwsh -NoProfile -File run_py.ps1 部署/脚本/verify_config_env.py

# 2) 起 FastAPI 服务（8600）——录屏期间保持这个窗口可见
pwsh -NoProfile -File 部署/脚本/run_app.ps1 -Mode api -Port 8600
#    或只起中文 Web（8123）：
#    pwsh -NoProfile -File 部署/脚本/run_app.ps1 -Mode web -Port 8123

# 3) 浏览器打开 http://127.0.0.1:8600/（FastAPI 自带中文页；/docs 是 OpenAPI 文档页）
```

要点：
* **先预热再录**：首次请求会加载索引与模型（本机实测解释器启动→`/health` 可用约 6.3 s，冷启动首字曾达 3430.8 ms）。
  先把 `/health` 打开一次、问一次问题，再开始录，避免录到冷启动。
* **独占 Ollama**：录制期间不要并发跑评测或别的问答脚本，否则延迟数字不可用。
* 分辨率建议 1920×1080，窗口最大化；把系统缩放调到 100%，避免字模糊。

## 3. 录制操作（Win+G）

1. 按 **Win+G** 打开 Game Bar → 「捕获」面板 → 点 **录制**（Win+Alt+R 也可直接开始/停止）。
2. 录完在 「捕获」→「查看我的捕获」里能找到 mp4，默认落在
   `C:\Users\<用户名>\Videos\Captures\`。
3. 建议把 mp4 放在 `测试/测试截图/` 同级或 `部署/` 下都可以（**不要**放进 `研发/data`，那会污染解析产物目录），
   文件名建议 `工单4_演示_YYYYMMDD.mp4`。

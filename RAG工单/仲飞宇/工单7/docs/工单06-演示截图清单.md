# 第 9 张 · `工单6-09-召回率达标.png` ★★核心

工单要求「召回率 ≥95%」。

```bash
$PY -c "
import json,glob,os,sys
prof = sys.argv[1] if len(sys.argv) > 1 else 'hybrid'
fs = [x for x in glob.glob(os.path.expanduser('~/rag-data/eval/eval-*.json'))
      if x.endswith(f'-{prof}.json')]          # 排除 eval-latest.json（对比模式不更新它）
f = max(fs, key=os.path.getmtime)
s = json.load(open(f))['summary']
print('报告', os.path.basename(f))
for k in ['n','profile','retrieval_mode','fusion','reranker','rag_rule_hits',
          'rule_hit_rate','avg_recall_coverage','recall_full_count',
          'recall_full_rate','ttft_under_3s','ttft_p50_ms']:
    print(f'  {k:24s} {s.get(k)}')
" hybrid
```

> ⚠️ **别用 `eval-latest.json`**：它只在单剖面模式更新，跑过 `--compare` 之后
> 留在磁盘上的仍是**上一次的内容**（实测拿到的是工单05 时的旧报告，
> 里面根本没有 `avg_recall_coverage` 这些工单06 字段）。按 mtime 取具体的
> `eval-<时间戳>-<剖面>.json` 才是可靠的。

要能看到 `avg_recall_coverage` 与 `rag_rule_hits` 两项 —— 存 `工单6-09-召回率达标.png`

# 第 16 张 · `工单6-16-Milvus原生混合检索.png`

```bash
$PY -c "
import asyncio
from app.core.vectorstore import VectorStore, lexical_sparse
from app.core.embedder import Embedder
async def main():
    s=VectorStore(); v=await Embedder().embed_one('注册资本 军用领域收入')
    hits=s.hybrid_search(v, lexical_sparse('注册资本 军用领域收入'), 3, ranker='rrf')

asyncio.run(main())
" 2>&1 | grep -v Warning | tail -6
```

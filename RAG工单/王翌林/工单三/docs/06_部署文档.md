## 二、安装步骤

### 2.1 一键安装

```bash
cd /home/dabaie/code/工单/工单三
bash scripts/install_v3.sh
```

`install_v3.sh` 执行以下操作：
1. 检查 Python 环境（venv 或 conda）
2. 安装 Python 依赖
3. 检查 `.env` 配置
4. 检查 Milvus 连接
5. 初始化 `rag_tables` collection
6. 入库 PDF 文档（文本 + 表格）

### 2.2 手动安装

#### 2.2.1 创建环境

```bash
# 方案 A：使用现有 venv
export PYTHON_BIN=/home/dabaie/code/my_project/.venv/bin/python

# 方案 B：conda
conda create -n rag_pdf_qa python=3.10 -y
conda activate rag_pdf_qa
```

#### 2.2.2 安装依赖

```bash
pip install pdfplumber==0.11.10 PyMuPDF rank_bm25 \
    sentence-transformers FlagEmbedding \
    fastapi uvicorn streamlit pydantic loguru \
    pymilvus pymysql sqlalchemy python-dotenv \
    jieba httpx openai
```

#### 2.2.3 配置 .env

```bash
cat > .env << 'EOF'
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
MILVUS_HOST=localhost
MILVUS_PORT=19530
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=your_password
RAG_EMBED_DEVICE=cuda
RAG_EMBED_BATCH_SIZE=8
RAG_EMBED_MAX_SEQ=512
EOF
```

#### 2.2.4 启动 Milvus

```bash
# Docker 方式
docker run -d --name milvus \
    -p 19530:19530 -p 9091:9091 \
    -v /tmp/milvus_data:/var/lib/milvus \
    milvusdb/milvus:2.6.9 \
    milvus run standalone
```

#### 2.2.5 初始化 + 入库

```bash
# 初始化 rag_tables collection
RAG_EMBED_DEVICE=cuda python scripts/init_milvus_v3.py --rebuild

# 入库文本
RAG_EMBED_DEVICE=cuda python scripts/ingest_text_v3.py

# 入库表格（init_milvus_v3.py 已包含）
```

## 三、服务启动

### 3.1 一键启动

```bash
bash scripts/start_v3.sh
```

启动后：
- FastAPI: http://127.0.0.1:8003/docs
- Streamlit: http://127.0.0.1:8503

### 3.2 手动启动

```bash
# 终端 1：FastAPI
export RAG_EMBED_DEVICE=cuda
python -m uvicorn src.api_v3:app --host 0.0.0.0 --port 8003

# 终端 2：Streamlit
python -m streamlit run app/streamlit_app_v3.py --server.port 8503
```

### 3.3 服务验证

```bash
# FastAPI 健康检查
curl http://127.0.0.1:8003/api/v3/health

# Streamlit 访问
curl -s http://127.0.0.1:8503 | head -5
```

## 四、服务停止

### 4.1 一键停止

```bash
bash scripts/stop_v3.sh
```

### 4.2 手动停止

```bash
# 按端口停止
kill $(lsof -t -i :8003)
kill $(lsof -t -i :8503)
```

## 六、常见问题

### 6.1 Milvus 连接失败

```bash
# 检查 Milvus 是否运行
docker ps | grep milvus

# 启动 Milvus
docker run -d --name milvus -p 19530:19530 milvusdb/milvus:2.6.9
```

### 6.2 GPU 显存不足

```bash
# 使用 CPU 模式
export RAG_EMBED_DEVICE=cpu
export RAG_EMBED_BATCH_SIZE=4
export RAG_EMBED_MAX_SEQ=256
```

### 6.3 中文路径问题

脚本已处理中文路径（`PROJECT_ROOT` 使用 `cd` 获取绝对路径），如仍有问题：

```bash
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8
```

### 6.4 端口被占用

```bash
# 查看占用
lsof -i :8003
lsof -i :8503

# 释放
kill $(lsof -t -i :8003)
```

## 七、性能调优

### 7.1 GPU 加速

| 参数 | 默认 | 调优 |
|------|------|------|
| RAG_EMBED_DEVICE | cuda | cpu（无GPU时） |
| RAG_EMBED_BATCH_SIZE | 8 | 16（大显存） |
| RAG_EMBED_MAX_SEQ | 512 | 256（省显存） |

### 7.2 Milvus 索引

| 参数 | 值 | 说明 |
|------|-----|------|
| index_type | HNSW | 高性能图索引 |
| metric_type | COSINE | 余弦相似度 |
| M | 16 | HNSW 连接数 |
| efConstruction | 200 | 构建精度 |

### 7.3 LLM 调优

| 参数 | 值 | 说明 |
|------|-----|------|
| model | deepseek-v4-flash | 快速模型 |
| max_tokens | 512 | 限制输出长度 |
| temperature | 0.3 | 低随机性 |

## 2. 关键红线（任一不满足即整体不通过）

1. **引用可回溯**：每条引用都能在对应 PDF 的**真实物理页**（1-based）找到支撑原文；不得用页脚 `1-1-128` 或 0-based 索引当页码。
2. **无依据回「不清楚」**：不得编造金额/结论；`unknown_reason` 必须落在枚举内。
3. **误拒答 = 0**：14 题任何一题都不允许回「不清楚」（首个案例：题 4）。
4. **首字 ≤ 3000 ms（逐题）**：冷启动不豁免（预热缺失即缺陷）。
5. **RAGAS 未运行**必须显式标注，且报告中不得出现任何 RAGAS 指标数值。

## 3. 已知设计选择（用户侧不必视为问题）

| 现象 | 说明 |
| --- | --- |
| 退化表（`degenerate=1`，markdown 为空）不进检索 | 设计选择；已逐页验证证据页上没有退化块（延伸页 259 有 1 个，不影响任何题） |
| 引用页 ≠ `evidence_pages` | 允许：同一原文可能在多处出现（如 543 题引 52 页），只要该页含支撑原文即有效 |
| 答案里出现「未披露」 | 原文即占位符 `[ ◆ ]`（如 2 号 PDF p22 募投第 5 项），不是 0、不是缺失 |
| 表格里保留成串 `-` | 原文用 `-` 表示无数据，不是重复填充缺陷（缺陷只认「行内横向重复的逻辑值」） |

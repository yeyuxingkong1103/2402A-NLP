# 宠物养护手册（跨页表格测试版）

## 一、日常护理要点

宠物日常护理是健康的基础。每天清理食盆和饮水器，保证水源清洁。犬猫每周梳理毛发2至3次，换毛期增至每天一次。每两周修剪趾甲，注意避开血线。耳道每周检查，口腔每周刷牙2次。夏季注意防暑，避免高温时段遛狗。

| 疾病 | 典型症状 | 处理建议 |
| --- | --- | --- |
| 肠胃炎 | 呕吐、腹泻、食欲不振 | 禁食6-8小时,少量补水,持续呕吐须就医 |
| 皮肤病 | 频繁抓挠、脱毛、皮肤红疹 | 保持干燥,检查跳蚤,勿乱用人类药膏 |
| 耳螨 | 甩头、抓耳、耳道黑色分泌物 | 专用洗耳液清洁,配合驱虫治疗 |
| 尿路感染 | 频繁排尿、尿中带血、舔舐私处 | 多饮水,立即就医,勿自行用药 |
| 犬瘟热 | 发热、眼鼻分泌物、抽搐 | 高度传染,立即隔离并送医 |
| 猫鼻支 | 打喷嚏、流脓涕、结膜炎 | 隔离观察,补充赖氨酸,严重送医 |
| 牙结石 | 口臭、牙龈红肿、流涎 | 洗牙治疗,坚持每周刷牙2次 |
| 胰腺炎 | 呕吐、腹痛、弓背 | 禁食禁水,立即就医输液治疗 |
| 泪痕重 | 眼角褐色泪痕、频繁流泪 | 检查鼻泪管,更换低盐饮食 |
| 趾间炎 | 跛行、舔脚、趾间红肿 | 清理伤口,保持干燥,戴伊丽莎白圈 |
| 猫藓 | 圆形脱毛斑、皮屑、瘙痒 | 抗真菌药浴,隔离,环境消毒 |

| 乳腺炎 | 乳房红肿、发热、拒绝哺乳 | 热敷排乳,抗生素治疗 |
| 脐疝 | 肚脐处软包、按压可回纳 | 观察,严重需手术修补 |

| 肛腺炎 | 蹭屁股、肛门红肿 | 挤肛腺,消炎处理,注意卫生 |

| 膀胱结石 | 排尿困难、尿血 | 多饮水,送医检查结石大小 |
| 甲状腺亢进 | 消瘦、多食、多饮 | 送医验血,药物控制 |

| 鼻出血 | 单侧或双侧鼻出血 | 冷敷鼻部,送医排查原因 |
| 抽搐 | 四肢抽搐、口吐白沫 | 保持安全距离,送医检查 |
| 瘫痪 | 后肢无力、拖行 | 送医拍片,排查椎间盘问题 |
| 白内障 | 瞳孔发白、视力下降 | 送医检查,必要时手术 |
| 肥胖症 | 体重超标、行动迟缓 | 控制饮食,增加运动量 |

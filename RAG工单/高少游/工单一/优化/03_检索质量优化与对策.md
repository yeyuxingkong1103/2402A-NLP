# 检索质量优化与问题对策

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统
> 针对"误召回/漏召回"类检索质量问题的分析与对策。

---

## 1. 检索质量影响因素

| 环节 | 质量问题 | 表现 |
|---|---|---|
| PDF解析 | 表格转文本丢失列对齐 | 关键数字串错位 |
| 切片 | 按长度切，跨章节 | 一句话被截断、上下文不完整 |
| 向量召回 | 语义相似但话题偏离 | 命中无关片段 |
| BM25召回 | 长词/缩写不匹配 | 精确术语漏召回 |
| 融合 | 两路都靠后 | 相关片段排名低 |

## 2. 已采取措施

- **表格 Markdown 化**：`_render_table` 保留表格结构，财务数字不丢失；
- **RRF 融合**：综合语义+词法排名，缓解单一检索偏科；
- **查询理解**：消歧 + 子问题分解，缓解指代不明；
- **检索以主问题优先**：防止子问题稀释主线语义；
- **TOP_K=8**：提高召回上限。

## 3. 潜在问题与对策

### 3.1 数字类问题（注册资本/募集资金）
- 问题：向量检索对精确数字弱，可能召回同段但不含目标数字。
- 对策：
  1. 检索条件同时给"实体 + 数字字段语义"；
  2. 后处理阶段对候选片段做**数字精确匹配二次重排**；
  3. 提高 BM25 在数字匹配上的权重。

### 3.2 专有名词（"某视频技术规范1.0"、"C4ISR"）
- 问题：jieba 分词可能把长专名切碎。
- 对策：
  1. 建立**领域词典**加入 jieba（`jieba.add_word`）；
  2. 查询理解提取 `entities` 并入检索。

### 3.3 章节跨页信息（收入占比分布在不同页）
- 问题：单一 Top-K 可能带不出另一页。
- 对策：
  1. 切片 metadata 带页码，检索后按"相邻页码聚合并补页"；
  2. 多个子问题分路检索已缓解。

### 3.4 误召回无关片段
- 问题：语义相关但非题目所需（如"行业"类问题召回内部章节）。
- 对策：
  1. 查询理解识别 `intent` 后做**类型过滤**（财务/关系/实体）；
  2. 精调 Top-K 与 RRF k。

## 4. 检索质量度量

- **定性**：报告里 RAG 依据页码/文本是否正确覆盖答案；
- **定量**：`context_precision` / `context_recall`（RAGAS，需 JSON 裁判模型）；
- **人工**：逐题核对"命中数/10"。

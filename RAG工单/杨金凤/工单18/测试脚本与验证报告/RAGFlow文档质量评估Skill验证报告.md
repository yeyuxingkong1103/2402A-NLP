## 七、失败案例与改进建议

### 案例1：SimHash 性能瓶颈

- **现象**：1700 个文件两两比较，跑 7 分钟未完成。
- **根因**：O(n²) 复杂度，144 万次汉明距离计算。
- **解决**：
  - 短期：关闭 SimHash，只用 MD5
  - 长期：引入 LSH（局部敏感哈希）分桶，将 O(n²) 降至 O(n)

### 案例2：敏感信息误报

- **现象**：3 条手机号命中，均为专利号。
- **根因**：手机号正则 `1[3-9]\d{9}` 与专利申请号格式重叠。
- **解决**：

```yaml
phone:
  enabled: true
  pattern: "(?<!申请号[:：]\\s*)(?<!专利号[:：]\\s*)1[3-9]\\d{9}"   # 增加负向断言，排除专利号上下文
```

### 案例3：扫描型 PDF 长度统计为空

- **现象**：622 个纯扫描型 PDF 的 `length_stats` 无法计入。
- **根因**：pdfplumber 无法从扫描件提取文本（需 OCR）。
- **结论**：这是正确的评估结果——扫描件需要 OCR 预处理，字符数为 0 正是质检结论。

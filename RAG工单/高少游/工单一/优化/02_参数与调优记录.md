> 记录关键参数的取值、调整历史与调优方法，便于复现与继续优化。

## 1. 当前参数取值

| 参数 | 值 | 配置项 | 作用 |
|---|---|---|---|
| 切片长度 | 500 字 | `CHUNK_SIZE` | 每块文本长度 |
| 切片重叠 | 80 字 | `CHUNK_OVERLAP` | 相邻块重叠，避免信息被截断 |
| 向量 Top-K | 8 | `TOP_K` | 语义检索返回片段数 |
| BM25 Top-K | 6 | `BM25_TOP_K` | 词法检索返回片段数 |
| RRF 常数 | 60 | `RANK_FUSION_K` | 融合平滑 |
| 生成长度 | 768 | `LLM_MAX_TOKENS` | 回答上界 |
| 温度 | 0.2 | `LLM_TEMPERATURE` | 确定性 |

## 2. 调整历史

| 调整 | 变更 | 原因/效果 |
|---|---|---|
| `TOP_K` 6→8 | 向量召回增多 | 提高召回命中（评估采用8） |
| 提示词强化数据提取 | 要求"数值/名称原样输出＋注明页码" | 修复回答漏数字/漏关键名问题 |
| 检索查询组合重构 | 检索始终以消歧主问题为主 | 修复子问题稀释主线语义导致的误召回 |

## 3. 切片参数的影响

- **CHUNK_SIZE 过小**：上下文碎片化，丢失完整语义，answers 需拼多块；
- **CHUNK_SIZE 过大**：注入提示词太长，拖慢生成、超上下文窗口；
- **CHUNK_OVERLAP**：保证跨切片边界的关键信息（长句/表格）不被截断。

## 4. RRF 融合窗口(k)的影响

- `k` 越大 → 排名靠后的文档分数被稀释越平滑；
- `k` 越小 → 冠军排名权重越大；
- 本系统 `k=60` 为 RRF 常用推荐值，平衡稳健与敏感。

## 5. 如何做参数实验

1. 用 `evaluate.py --top-k <N> --skip-ragas` 对不同 Top-K 出报告；
2. 对比 `output/evaluation_report.md` 中的**命中数**与**平均耗时**；
3. 选命中与耗时平衡的配置固化到 `.env`。

示例：
```powershell
python scripts/evaluate.py --top-k 6 --skip-ragas && python scripts/build_report.py
python scripts/evaluate.py --top-k 8 --skip-ragas && python scripts/build_report.py
python scripts/evaluate.py --top-k 10 --skip-ragas && python scripts/build_report.py
```
比较三份报告的命中率与耗时。

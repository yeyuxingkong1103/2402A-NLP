## 1. id 5：组织结构图（矢量图，文本层"看得见、读不懂"）

### 1.1 定位过程

探测命令（页码为 PDF 物理页码）：

```python
import fitz
d = fitz.open("招股说明书2.pdf")
for i, pg in enumerate(d):
    t = pg.get_text("text")
    if "组织结构图" in t or "大客户销售部" in t:
        print(i + 1, len(pg.get_drawings()), len(pg.get_images(full=True)),
              len(t.strip()))
```

命中结果：

| PDF 页码 | 内容 | 绘图对象 | 内嵌图 | 文本长度 |
|----------|------|----------|--------|----------|
| 38 | 股权结构图 + "(二)发行人内部组织结构图 / 1、公司组织结构图"标题 | 33 | 19（全部为水印） | 328 |
| **39** | **组织结构图本体** | **31** | **23（全部为 143×127 水印切片）** | **323** |
| 40 | 正文：内部职能部门简介（销售部职责） | 1 | 15（水印） | ~1300 |

> 关键点：第 38 页的标题与第 39 页的图是分离的——**题注在文本层，图在下一页**，
> 这给"按文字定位图"造成干扰，必须按"图页判定"而非"关键词所在页"抽图。

### 1.2 为什么文本层取不到

第 39 页的节点名**确实在文本层里**，但形态是逐字换行（竖排文字）：

```
股东大会 / 董事会 / 总经理 / 监事会 / 董事会秘书 / 证券部 / 上海分公司
财 务 部 / 市 场 开 发 部 / 信 息 系 统 部 / 销 售 部 / 行 政 人 事 部 / 物 流 部
研 发 中 心 / 电 话 及 网 络 销 售 部 / 渠 道 销 售 部 / 大 客 户 销 售 部 / 国 际 贸 易 部
珠 海 销 售 处 / 深 圳 销 售 处 / 北 京 销 售 处 / 武 汉 销 售 处 / 广 州 销 售 处 / 成 都 销 售 处
```

`rag_core.pdf_parse.clean_text()` 会把每个词拼回去（`财\n务\n部 → 财务部`），
但**文字流里没有任何隶属信息**：

* 文字按文本框坐标排序，`销售部` 与 `大客户销售部` 之间没有"父子"标记；
* 6 个销售处与 `大客户销售部` 在文字流中只是先后出现，无法确定挂在谁下面；
* 更无法回答"有几个"——数量关系只存在于**连线的拓扑结构**中。

因此，文本层虽然包含了全部节点名，却**丢失了唯一重要的事情：层级**。
这是"信息在图里"最典型、也最容易被误判为"文本可取"的情形。

### 1.3 正文旁证（说明为什么消融实验必须两问一起判）

第 40 页正文确实有一句：

> ②销售部：销售部下设渠道销售部、电话及网络销售部、大客户销售部和国际贸易部。

所以 **id 5 的第一半（销售部 4 个部门）在正文中有文字旁证**，纯文本索引也可能答出 4。
但第二半"大客户销售部有几个销售处"在正文中**没有任何对应描述**
（正文只说"公司目前在上海设立有 1 家分公司，在北京、广州、成都、深圳、武汉、珠海各设有 1 家销售处"，
出现在第 113 页且说的是公司整体、不是"大客户销售部下属"）。
因此判分要求两个数量都命中，纯文本索引必然判错——这也是消融实验设计的依据。

### 1.4 正确答案（人工核验渲染图）

```
股东大会 ─┬─ 董事会 ─┬─ 总经理 ─┬─ 财务部
          │          │          ├─ 市场开发部 ── 研发中心
          │          │          ├─ 信息系统部
          │          │          ├─ 销售部 ─┬─ 电话及网络销售部
          │          │          │          ├─ 渠道销售部
          │          │          │          ├─ 大客户销售部 ─┬─ 珠海销售处
          │          │          │          │                ├─ 深圳销售处
          │          │          │          │                ├─ 北京销售处
          │          │          │          │                ├─ 武汉销售处
          │          │          │          │                ├─ 广州销售处
          │          │          │          │                └─ 成都销售处
          │          │          │          └─ 国际贸易部
          │          │          ├─ 行政人事部
          │          │          └─ 物流部
          │          └─ 上海分公司
          └─ 董事会秘书 ── 证券部
```

* **销售部 = 4 个部门**：电话及网络销售部、渠道销售部、大客户销售部、国际贸易部
* **大客户销售部 = 6 个销售处**：北京、广州、成都、深圳、武汉、珠海

### 1.5 需要什么能力才能答对

1. **把矢量图变成像素**：整页渲染（`page.get_pixmap(dpi=200)`），
   因为 `get_images()` 在该页只能取到水印；
2. **图页判定不能只看文字量**：该页 323 字，超过 `_page_looks_like_figure` 的 200 字阈值，
   需要"题注关键词 + 绘图密度"补充判据；
3. **层级重建**：多模态大模型按专用 prompt 输出缩进层级树；
4. **确定性计数**：由程序解析树结构统计子节点数量（`tree_to_facts`），而不是让模型"数数"；
5. **可检索化**：把节点名与计数结论写进 chunk，使 BM25 能命中"销售部/大客户销售部/销售处"。

## 2. id 6：IC 市场应用结构与增长图（位图，数值只在图里）

### 2.1 定位过程

```python
t = d[71].get_text("text")     # 第 72 页
# "2008 年中国IC 市场应用结构与增长(亿元)"
# "资料来源：赛迪顾问《2008 年中国集成电路市场回顾与展望》"
for img in d[71].get_images(full=True):
    px = fitz.Pixmap(d, img[0]); print(img[0], px.width, px.height)
# 1693 638x479   <- 饼图（应用结构）
# 1692 525x473   <- 条形图（增长率）
# 2338 143x127 × 15  <- 水印切片
```

| PDF 页码 | 内容 | 真实位图 | 水印 |
|----------|------|----------|------|
| **72** | 题目 + 图 + 资料来源 | 1693（638×479）、1692（525×473） | 15 个 |
| 310 | 同一张图在"募集资金运用"章节重复引用 | 同 1693、1692（xref 复用） | 15 个 |

图由**两张位图拼版**组成：

* 左：**饼图**——2008 年 IC 市场应用结构（计算机 2515 亿元/42%、消费 1541/26%、
  网络通信 1189/20%、工控 448/7%、其他 137/2%、汽车 102/2%、IC 卡 48/1%）；
* 右：**条形图**——各行业增长率（IC 卡 **-2.0%**、工控 10.5%、计算机 7.9%、其他 6.1%、
  **汽车 14.0%**、网络通信 2.6%、消费 5.1%）。

### 2.2 为什么文本层取不到（只能取到一半）

第 72 页文本层包含：

* 题注：`2008 年中国IC 市场应用结构与增长(亿元)`
* 资料来源：`赛迪顾问《2008 年中国集成电路市场回顾与展望》`
* 正文一段：`2008 年，国内IC 市场中，工业控制领域所占的比例虽然仅为7%，
  但其增长率达10.5%，在所有应用行业中位列第二，仅次于汽车电子。`

也就是说，**文本层能间接推出"增长最快的是汽车电子"**（"仅次于汽车电子"意味着汽车电子更快），
但：

1. **负增长行业（IC 卡 -2.0%）在文本层完全没有出现**——这是本题必须图像解析的决定性证据；
2. 各行业的完整增长率数值（除工控 10.5% 外）都不在文本层；
3. 数字与行业的对应关系（谁 14.0%、谁 2.6%）只在条形图的条形长度与标签上。

### 2.3 正确答案（人工核验渲染图）

| 行业 | 增长率 | 应用结构规模 |
|------|--------|--------------|
| **汽车** | **14.0%（最快）** | 102 亿元（2%） |
| 工控 | 10.5% | 448 亿元（7%） |
| 计算机 | 7.9% | 2,515 亿元（42%） |
| 其他 | 6.1% | 137 亿元（2%） |
| 消费 | 5.1% | 1,541 亿元（26%） |
| 网络通信 | 2.6% | 1,189 亿元（20%） |
| **IC 卡** | **-2.0%（负增长）** | 48 亿元（1%） |

### 2.4 需要什么能力才能答对

1. **位图抽取 + 水印过滤**：该页有 2 张真图 + 15 个水印，必须过滤后再入库，
   否则 5 张水印块会稀释检索结果；
2. **条形图读数**：`extract_chart_data` 把"增长率"系列逐条读成
   `{"IC卡": -2.0, "工控": 10.5, ..., "汽车": 14.0}`；
3. **最值与负值判定**：程序化计算 max / min / 负值清单（`chart_data_to_text`），
   避免模型"看反"符号；
4. **两条途径互补**：文本层的"仅次于汽车电子"与图像的"IC 卡 -2.0%"共同支撑完整答案，
   说明多模态索引与文本索引不是替代关系而是互补关系。

## 3. 两问的共性与差异

| 维度 | id 5 组织结构图 | id 6 IC 市场图 |
|------|-----------------|----------------|
| 图形形态 | 矢量（路径绘制） | 位图（PNG 嵌入） |
| 抽取难点 | `get_images()` 取不到 → 必须整页渲染 | 取得到但混在水印里 → 必须过滤 |
| 文本层缺失的内容 | 层级关系（结构） | 数值（含负号） |
| 需要的 VLM prompt | 组织结构图专用（层级树） | 通用图表 + JSON 结构化 |
| 后处理 | 树 → 父子事实 + 计数 | JSON → 展平 + 最值/负值 |
| 共同点 | ①都必须先过"图页判定"；②都必须把图转成**可检索文本**；③答案要点必须由程序做确定性计算 | 同左 |

## 4. 验收判定口径

`run_evaluation.ANSWERS_EXPECTED` 中对两问的判分要点：

* **id 5**：`渠道销售部`、`电话及网络销售部`、`大客户销售部`、`国际贸易部`（证明"4 个"）、

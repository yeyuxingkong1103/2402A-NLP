## 三、行动清单 —— 真正缺什么、怎么补

| # | 缺的 | 优先级 | 补法 |
|---|---|---|---|
| 1 | Redis（短期记忆） | 高（角色扮演要靠它） | 启动 Docker Desktop（已装）→ `docker run -d -p 6379:6379 redis`；或装 Memurai；演示底线：现有 JSON 持久化也能顶 |
| 2 | RAGAS | 高（评测是产出物） | `pip install ragas` 到 rag_env，配 Ollama 端点 |
| 3 | Docker Desktop 启动 | 中（Dify/Redis/Milvus 备用都靠它） | 打开 Docker Desktop 应用等心跳变绿即可 |
| 4 | Jmeter + Java | 低（压力报告阶段） | 装 JDK17 + Apache JMeter |
| 5 | MongoDB / Neo4j | 低（仅当多路召回真要加路） | 需要时 Docker 起容器 |
| 6 | vLLM/SGLang | 不需要 | Windows 不支持 + 显存不够，用 Ollama 讲本地部署 |
| 7 | Milvus | 不需要 | Qdrant 已在、功能对齐 |

## 四、显存预算（8G 红线，注意别同时全常驻）

| 负载 | 占用 | 建议 |
|---|---|---|
| qwen2.5:7b（Ollama 量化） | ~4.7G | 与微调模型二选一运行 |
| qwen2.5-0.5B 融合模型 fp16 | ~1G | 8G 卡完全放得下 ✅ |
| bge-reranker-v2-m3（fp16） | ~2.3G | 用完释放，或走 Ollama 量化版 |
| BGE-M3 embedding | Ollama 版轻量；HF 版 2.2G 建议 CPU 跑离线批量，快不了太多但省显存 |

> 后端跑在 `rag_env`（cu121 torch），嵌入选 Ollama 或本地 HF 版都行；要开启 BGE-M3 稀疏召回（sparse_linear），用本地 HF 版 + FlagEmbedding 生成稀疏向量再灌 Qdrant，比 rank-bm25 更接近笔记里"混合检索"的目标。

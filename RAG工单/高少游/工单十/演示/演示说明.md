## 六、复现方式

```bash
# 1) 构建并启动（详见《部署文档》）
docker build -t finqa:1.0 .
docker run -d --name finqa-app --network finqa-net -p 8501:8501 ... finqa:1.0

# 2) 复现界面截图（5 轮对话）
docker exec finqa-app python run_demo.py

# 3) 复现运行截图与技术验证图
python tools/render_deploy_shots.py     # 运行截图
python tools/render_ui_shots.py         # 界面截图
python tools/render_terminal_shots.py   # 终端截图
python tools/gen_deploy_flowcharts.py   # 流程图

# 4) 复现演示视频
python tools/make_demo_video.py
```

## 关键口径（改数据前先读）

1. **页码 = 1-based 物理页**。页脚 `1-1-128`（PDF1）与页眉第 2 行裸数字 `21`（PDF2）都是 **0-based 索引**，
   禁止用于引用，也禁止用其反推页码（`设计/需求分析.md` §4.4）。
2. **命中判定优先用 `evidence_verbatim`**。题 207 的 `evidence` 是合成串 + 编辑注记（14 题中唯一非逐字原文），
   用它判命中必然漏判 —— 严格单证据口径固定为 13/14 属**基准缺陷**，不是实现缺陷。
3. **题 34/793 的答案正文在物理 152**（`find_tables=0`），153 是示意表（辅助）：「表在 153 ≠ 答案在 153」。
4. **题 3 / 题 4 证据同页（PDF2 物理 157）**：题 4 不得混入自然人赵马克；题 3 不得夹带 7 家企业；
   力源贸易 / 普芯达是企业，属题 4 答案，**不得误删**。
5. **题 207 只能引 PDF1（479/490/30）**：严禁采用 PDF2 物理 340（那是银行借款 300 万美元）。
6. **`[ ◆ ]` 按「未披露」处理**，不是 `None`、不是 0（PDF2 物理 22 募投第 5 项原文即占位符）。

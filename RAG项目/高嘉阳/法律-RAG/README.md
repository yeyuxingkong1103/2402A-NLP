## GitHub 上传说明

本文件夹已经排除了本地 Python 虚拟环境 `RAG/`，避免把依赖包、解释器和缓存文件上传到仓库。

如果后续添加代码，建议使用下面方式重新创建环境：

```powershell
python -m venv RAG
.\RAG\Scripts\Activate.ps1
pip install -r requirements.txt
```

## 注意事项

- GitHub 普通仓库单文件限制为 100MB，当前 PDF 文件均低于该限制。
- 如后续添加模型文件、向量数据库、缓存或构建产物，请不要直接上传到 GitHub。
- 大文件建议使用 Git LFS、网盘、对象存储或 Hugging Face 等方式管理。

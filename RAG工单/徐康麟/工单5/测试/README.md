## 2. 复现命令

```powershell
cd E:\gao6gongdan\工单4

# 研发自测层（解析/索引单测；秒级）
$env:PYTEST_ADDOPTS='-p no:cacheprovider'      # 防止在仓库根生成 .pytest_cache 游离目录
pwsh -NoProfile -File run_py.ps1 -m pytest 研发/tests -q

# 离线验收层（不依赖网络与 LLM）
pwsh -NoProfile -File run_py.ps1 -m pytest 测试/离线 -q

# 在线验收层（需 Ollama；测量延迟前须独占）
pwsh -NoProfile -File run_py.ps1 -m pytest 测试/在线 -q

# 两处一起跑（推荐给验收人；一次覆盖自测层 + 离线层）
pwsh -NoProfile -File run_py.ps1 -m pytest 研发/tests 测试/离线 -q

# 三级一键串跑（含留痕）
pwsh -NoProfile -File 测试/run_tests.ps1
```

> `PYTEST_ADDOPTS='-p no:cacheprovider'`：避免在仓库根留下 `.pytest_cache/` 游离目录 —— 交付物只落在
> `设计/研发/测试/优化/部署` 五个中文文件夹内（规则见 `设计/验收标准.md` A10 工程纪律）。
> ⚠️ **不要把 `-p ...` 直接接在 `-File run_py.ps1` 之后**：`run_py.ps1` 只有一个
> `ValueFromRemainingArguments` 参数，第二个未知开关会让 PowerShell 参数绑定失败（实测退出码 1）。

# 工单13 RAG性能瓶颈识别与优化｜研发文档
## 1.开发环境
- WSL Ubuntu24.04
- Python虚拟环境：复用工单5 `venv_gongdan5`
- 依赖：`cProfile snakeviz locust python‑json‑logging`
> cProfile为python内置库，无需额外安装

## 2.安装新增依赖
```bash
pip install snakeviz locust python-json-logging
## . 脚本说明

1. **rag_perf_main.py**
实现基础 RAG 链路，**全链路埋点计时**，每个阶段打印耗时，输出结构化 json 日志到 perf_logs 目录；
包含：query 处理、embedding、向量检索、rerank、prompt 组装、LLM 生成、后处理；
支持开启 / 关闭各个优化开关，用来对比优化前后性能。
2. **profile_analyze.py**
cProfile 性能分析入口，运行 RAG 查询，输出 profile 统计文件，可用 snakeviz 可视化查看函数耗时。
3. **locustfile.py**
Locust 负载测试脚本，模拟并发 RAG 请求，压力下观察延迟、吞吐量变化。

## 4. 关键实现说明

1. 使用 uuid 生成 request_id，每条请求全链路追踪；
2. time.perf_counter 高精度计时，记录每个子阶段耗时；
3. json 格式结构化日志，记录：request_id、各阶段耗时、检索文档数、prompt token、输出 token；
4. 提供优化开关：缓存开关、轻量 embedding 开关、关闭 rerank 开关、上下文压缩开关。

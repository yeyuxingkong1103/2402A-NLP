## 一、系统架构

### 1.1 总体架构

```
┌──────────────────────────── 离线建库（build_index.py）────────────────────────────┐
│                                                                                    │
│  招股说明书1.pdf                                                                     │
│    └─ 解析层  src/pdf_parser.py                                                   │
│         ├─ MinerU 3.4.5（主力，pipeline 后端，config.MINERU_ENABLED=True）          │
│         │     独立 venv D:\model\mineru-venv（transformers 4.57）+                │
│         │     scripts/mineru_run.py 子进程调用；模型清单与本机快照完全匹配            │
│         │     PP-DocLayoutV2 版面分析 ~1.1s/页，输出 Markdown + content_list.json  │
│         ├─ PyMuPDF 增强引擎（自动回退）src/pymupdf_parser.py                        │
│         │     五遍扫描：字号统计 → 抽行+表格 → 页眉页脚清洗 →                        │
│         │     折行标题合并 → 标题栈维护（编号正则 × 字号 双证据）                     │
│         └─ PaddleOCR-VL 兜底（低文本页，独立 venv 子进程）src/ocr_fallback.py        │
│              ↓ content_list（type/text/page_idx/text_level/heading_path/source）   │
│    └─ 分块层  src/chunker.py                                                       │
│         标题层级切"节" → 子块（300–450 字，句子边界）+ 表格独立 + 父块（≤1800 字）      │
│              ↓ chunks.json（含 parent_id/parent_text/元数据）                       │
│    └─ 向量化  src/embedder.py（bge-m3，1024 维，CUDA，local_files_only）             │
│              ↓                                                                     │
│    └─ 入库  src/vector_store.py（Qdrant，COSINE，批量 128）                          │
│              ↓ collection: zhaogu_v2_opt（1995 点）                                │
└────────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────── 在线问答（app.py / rag.ask）────────────────────────────┐
│                                                                                    │
│  用户提问（中文/英文，文字/语音）                                                     │
│    └─ ① 查询理解  src/query_rewrite.py（规则层，<1ms）                              │
│         意图识别（numeric/list/fact/compare）│ 消歧（指代词→公司全称）                  │
│         分解（多疑问结构→子问题）│ 扩展（领域同义表→多路查询）                          │
│              ↓                                                                     │
│    └─ ② 混合检索  src/retriever.py                                                  │
│         稠密：bge-m3 向量 top-30  ┐                                                 │
│         稀疏：BM25（jieba+保护词）top-30 ┴→ RRF 融合（k=60）                          │
│              ↓                                                                     │
│    └─ ③ 精排  src/reranker.py（bge-reranker-v2-m3 cross-encoder，top-20→4）         │
│              ↓                                                                     │
│    └─ ④ 上下文组装  src/context.py                                                  │
│         子块→父块去重（parent_id）→ 同页去重 → 锚点裁剪（1200 字/片）→ 总长 ≤3200      │
│              ↓                                                                     │
│    └─ ⑤ 生成  src/llm.py + src/rag.py（Ollama qwen2.5:3b，temperature=0）           │
│         中英双语提示词 + 数字校验（防幻觉）+ 失败重试 + 抽取式降级                       │
│              ↓                                                                     │
│  答案 + [n] 引用（页码/标题路径）+ 全链路耗时明细                                      │
└────────────────────────────────────────────────────────────────────────────────────┘
```

## 二、技术选型

| 层 | 选择 | 版本/路径 | 理由 | 备选与否决原因 |
| --- | --- | --- | --- | --- |
| 解析（主） | **MinerU 3.4.5 pipeline** | 独立 venv `D:\model\mineru-venv`（transformers 4.57，复用主环境 CUDA torch） | 模型清单（PP-DocLayoutV2/unimernet/paddleocr_torch/TabRec/TabCls）与本机 PDF-Extract-Kit 快照**完全匹配**；版面分析 ~1.1 s/页；输出带 text_level 标题层级的 content_list | 2.7.6（缺 YOLO/MFD 权重）；2.7.6 vlm（单页 >1h）；4.0.10（本地需 GGUF 模型）——均实测排除 |
| 解析（回退） | PyMuPDF 增强引擎 | fitz 1.25.5 | MinerU 失败时自动回退（容错）；编号+字号双证据标题识别 | — |
| OCR 兜底 | PaddleOCR-VL | 独立 venv `D:\model\Paddle-OCR\venv` | 工单要求的兜底路径；子进程调用零污染 | 主环境装 paddle 会引入巨量依赖 |
| 分块 | 标题层级 + 父子块 | `src/chunker.py` | 工单明确禁用固定窗口；小块检索精度 + 大块上下文完整性 | 语义分块（成本高、不可解释） |
| Embedding | bge-m3 | `D:\model\bge-m3`（1024 维） | 工单要求优先 BGE；中英双语；max_seq 8194 | 更小的 MiniLM（中文弱） |
| 向量库 | Qdrant（qdrant-client 本地模式） | 1.18.0 | 工单指定 Qdrant；本机无 Docker → local 模式；`QDRANT_MODE=server` 一键切换 | Docker 部署（无 Docker 可执行文件） |
| 检索 | 向量 + BM25 + RRF | rank-bm25 + 自研融合 | 精确事实（数字/专名）与语义问法互补；RRF 无需量纲归一 | 纯向量（数字匹配弱）；加权求和（需调参） |
| 精排 | bge-reranker-v2-m3 | `D:\model\reranker` | cross-encoder 精排显著提升 top-k 精度 | 无重排（工单1已证明其价值） |
| LLM | qwen2.5:3b（Ollama） | 1.9GB，已 pull | 离线可用；RTX 4060 上生成 <1s；0.5b 作兜底 | 7b/14b（本机没有） |
| 界面 | Streamlit | 1.61.1 | 已装；快速构建双语界面；流式输出支持好 | Gradio（同等可选） |
| 评估 | RAGAS + 自研客观指标 | ragas 0.2.15 | 工单要求 RAGAS；裁判替换为本地 Ollama 实现离线 | TruLens（未装） |
| 进度追踪 | pytest + git | 9.1.1 / 2.55 | 单元测试 + 分阶段提交 | — |

**硬约束遵守**：
- 所有模型来自本机（`docs/01-本机模型扫描结果.md` 清单）；
- `from_pretrained` 全部 `local_files_only=True`；
- 无 `snapshot_download` / `hf_hub_download` / Ollama pull 调用路径；
- MinerU 子进程强制 `MINERU_MODEL_SOURCE=local`。

## 三、开发流程（实际执行顺序）

1. **环境勘查**：扫描本机模型（产出 `docs/01-本机模型扫描结果.md`）、检查 Docker/GPU/Ollama/依赖包；
2. **骨架**：git 初始化、`bootstrap`（移植工单1的栈修复）、`config`、测试；
3. **解析适配**（最曲折的一步）：
   - 安装 mineru 2.7.6 → 补 torchvision 0.28/doclayout_yolo/ultralytics（torch 未动）；
   - pipeline 后端实测失败（缺权重）→ VLM 后端实测失败（单页 >1h）；
   - 决策：PyMuPDF 增强引擎为主 + MinerU 路径保留，实测数据全部记录在 `docs/02-优化方案.md`；
4. **分块器**：TDD（6 个单测）→ 全量 548 页实测（1995 chunks，含 473 表格块）；
5. **向量化 + 入库**：1995 点写入 Qdrant（72 秒）；
6. **检索链路**：retriever/reranker/query_rewrite/context 逐个 TDD（20 个单测）；
7. **端到端调优**（准确率迭代）：
   - 首轮 fact_hit 47.5% → 提示词强化 + 同页去重 + top-k 收紧 → 75%；
   - few-shot 示例 + 完整性引导 → **87.5%**；
   - 数字校验与重复检测重试（防幻觉）；
8. **界面与评估**：Streamlit 双语界面、三方对比脚本、RAGAS 脚本；
9. **文档**：优化方案 / 对比分析 / RAGAS 报告 / 技术文档 / 用户手册 / README。

## 四、使用方法

### 4.1 环境要求

- Windows + Python 3.12（`D:\Python\python.exe`）
- 本机模型：`D:\model\bge-m3`、`D:\model\reranker`；Ollama 已 pull `qwen2.5:3b`
- 依赖：torch 2.13+cu126、transformers、sentence-transformers、qdrant-client、
  rank-bm25、jieba、streamlit、ragas、langchain-ollama（均已装）

### 4.2 建库（一次性）

```bash
cd D:\xinzg6\zy-gq\工单2
python build_index.py             # 解析→分块→向量化→入库（约 70 秒）
python build_index.py --help      # 查看全部参数
```

### 4.3 启动问答界面

```bash
streamlit run app.py
```

浏览器打开 `http://localhost:8501`（详见《用户手册》）。

### 4.4 命令行问答

```bash
python -c "from src import bootstrap; bootstrap.run_with_large_stack(lambda: print(__import__('src.rag', fromlist=['ask']).ask('公司注册资本是多少？').answer))"
```

或在 Python 中：

```python
from src import bootstrap
def work():
    from src import rag
    r = rag.ask("武汉兴图新科电子股份有限公司法定代表人是谁？")
    print(r.answer, r.citations, r.timings)
bootstrap.run_with_large_stack(work)
```

### 4.5 评估

```bash
python evaluate_compare.py        # 三方对比（含工单1基线，约 10 分钟）
python evaluate_compare.py --skip-baseline   # 只跑优化后 + 纯LLM
python evaluate_ragas.py          # RAGAS（本地裁判，较慢）
```

### 4.6 测试

```bash
python -m pytest tests/ -v -m "not slow"   # 快速单测（~30 个）
python -m pytest tests/ -v -m slow         # 集成测试（548 页解析）
```

## 五、关键工程问题与解法（移植工单1的已知坑 + 本工单新增）

| 问题 | 现象 | 解法 |
| --- | --- | --- |
| Windows 导入期栈溢出 | `from transformers...` 在 1MB 主线程栈上静默崩溃（exit 139） | `bootstrap`：pandas/sklearn 预热 + `threading.stack_size(16MB)` + 命令行入口用 `run_with_large_stack` |
| SentenceTransformer 段错误 | 直接 `import sentence_transformers` 崩溃 | 同上；所有入口先 `from src import bootstrap` |
| MinerU VLM 无法停止 | 单页推理 >1h | 兼容层强制 `max_new_tokens=2048`（仍慢，最终不采用该后端，见 `docs/02-优化方案.md`） |
| MinerU 印章权重缺失 | 全量解析中途 `seal_PP-OCRv4_det_server_infer.pth is not existed`（本机快照无印章模型且禁下载） | `scripts/patch_mineru_venv.py` 在 venv 副本上打印章跳过补丁（`MINERU_SKIP_SEAL`，默认跳过） |
| MinerU 需要 transformers 4.x 旧 API | 主环境 5.15 已移除 `find_pruneable_heads_and_indices` 等 | 独立 venv（`--system-site-packages` 复用 CUDA torch），通过 `scripts/mineru_run.py` 子进程调用 |
| Qdrant 本地模式重建残留 | `delete_collection` 后旧点复用目录，count 偏大 | `_purge_local_collection`：物理删目录 + 同步 meta.json |
| LLM 数字幻觉 | 4,627.14 写成 4,627.15 / 列表数字重复 | `rag.check_numbers` + 定向重试（重试不更差才采用） |
| LLM 答"无法确定" | 片段明明含答案，3b 模型受干扰片段影响 | 提示词强化（主体区分/必须作答）+ 同页去重 + top-k=4 |
| 早期版本 `use_fast` 弃用告警 | transformers 5.x 提示 | 无害，记录待后续升级 |

## 六、性能数据（实测，RTX 4060 Laptop 8G）

| 阶段 | 耗时 |
| --- | --- |
| 建库（解析 548 页 + 分块 + 向量化 1995 条 + 入库） | 72 秒 |
| 冷启动预热（embedding + reranker + BM25 + Ollama） | 26 秒（一次性） |
| 单题问答（查询理解 + 召回 + 精排 + 上下文 + 生成） | **平均 1.0~1.1 秒**（P50 0.97s，≤3s 占比 100%） |

分阶段：查询理解 <1ms；混合检索 ~600ms；精排 ~300ms；生成 ~700ms（qwen2.5:3b，~50 字答案）。

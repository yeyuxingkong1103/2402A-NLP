# 工单7 RAG功能测试及评估｜研发文档
工单编号：人工智能NLP‑RAG‑功能测试及评估

## 1.开发环境
复用已创建虚拟环境 `venv_gongdan5`，无需新建虚拟环境。
依赖全部已安装：Flask、pymupdf、sentence‑transformers、pymilvus、rank‑bm25、numpy。
Milvus使用Docker容器运行，监听19530端口。

## 2.开发流程
工单7基于工单6的混合检索RAG代码副本开发，保留原有全部检索逻辑，**新增批量评估模块**。

### 2.1 原有功能（继承工单6）
1. PDF文档解析：使用pymupdf读取PDF，逐页提取文本，按换行分割，过滤长度小于20字符的无效文本。
2. 向量模型加载all‑MiniLM‑L6‑v2，文本编码为384维向量。
3. Milvus集合创建、向量插入、构建IVF_FLAT索引。
4. BM25Okapi构建关键词检索索引。
5. RRF倒数排名融合算法，实现向量+BM25两路结果融合。
6. Flask网页前端，下拉切换三种检索模式，实现手动提问交互。

### 2.2 工单7新增核心开发：batch_evaluate批量评估函数
1. 输入格式：`[(问题, [参考真值片段列表]), …]`
2. 调用search_func执行检索，得到返回文本片段。
3. 将检索结果与参考真值比对，统计命中的相关片段数量。
4. 根据公式计算召回率、精确率，结果保留4位小数。
5. 程序启动时自动执行批量评估，在终端打印10条测试用例完整评估报告。

### 2.3 Web前端修复
修复前端JS全角符号bug，解决点击提交无响应问题，浏览器可以正常发送请求获取检索结果。

## 3.核心文件说明
- `main.py`：主程序，PDF加载、Milvus操作、检索逻辑、评估模块、Flask服务全部在此文件。
- `pdf_loader.py`：PDF文本读取辅助脚本。
- `create_collection.py`：Milvus集合创建辅助脚本。
- `download_model.py`：向量模型本地下载脚本。
- `gen_pdf.py`：测试PDF生成脚本。

## 4.开发遇到的问题
1. 前端页面点击提交无响应：JS代码混入全角符号，浏览器解析JS报错。修复：全部替换为半角符号，刷新浏览器缓存。
2. Milvus弃用警告：ORM风格API即将废弃，属于版本提示，不影响功能运行。
3. 向量检索存在语义漂移：语义相近但是无关文档被召回，混合RRF检索可以缓解该现象。

# 文档质量评估 Skill（DocumentQualityAssessmentSkill）

工单编号：人工智能NLP-RAG-实现文档质量评估Skill并集成至智能体工作流工单

## 核心工作流程（指令层）

1. **触发质检**：接收文件夹路径或文件列表；
2. **五大功能依次执行**（见下）；
3. **输出报告**：生成结构化 JSON 报告与 HTML 简报，重点列出
   “待确认的版本冲突列表”“待审核的敏感信息列表”“待确认的扫描页列表”。

### 五大功能

1. **格式分布统计**：遍历文件夹，统计 `.pdf/.docx/.md` 等数量与占比；
2. **PDF 页面类型识别**：按页判断字符数，低于阈值记为扫描页；扫描页占比 > 阈值
   标记为扫描型（阈值可配置，输出“待确认”列表）；
3. **文档长度分布**：统计字符数分位数 P25/P50/P75/P90/P99 与长度区间分布；
4. **重复检测**：MD5 精确匹配 + SimHash 高相似（输出“待确认的版本冲突列表”）；
5. **敏感信息检测**：手机号/邮箱/身份证（银行卡默认关闭），每条记录附上下文。

## 资源层（按需加载）

- `assessor.py`：核心质检逻辑脚本；
- `assessment_config.yaml`：所有可调阈值配置。

## 输出分类标签

`Text_PDF` / `Scan_PDF` / `Mixed_PDF` / `Duplicate` / `Version_Conflict` /
`Sensitive_Hit` / `Other`，供下游工作流路由到对应解析器。

## 3. 模块代码说明
### 3.1 create_collection.py
功能：连接Milvus，创建向量集合，定义字段、主键、向量索引。
要点：必须设置主键id，向量维度128，创建IVF_FLAT索引。

### 3.2 gen_pdf.py
功能：生成模拟招股说明书PDF文件，用于项目演示，满足项目必须使用PDF的要求。

### 3.3 pdf_loader.py
功能：读取PDF文档，文本分块，生成向量，批量插入Milvus向量库。
文本分块策略：chunk_size=300，overlap=50，保证上下文连续性。
向量：简易归一化随机向量，用于跑通完整RAG链路。

### 3.4 main.py
功能：Flask Web服务，包含：
1. 简易向量函数
2. 问题改写函数：优化用户提问，补全上下文
3. Milvus检索函数：查询相似文本片段
4. /ask接口：接收前端提问，调用大模型生成回答
5. 内置HTML前端页面，无需额外静态文件

## 4. 开发遇到的问题和解决方案
1. **Milvus报错：Schema must have primary key**
原因：集合缺少主键字段。解决方案：增加自增主键id字段。
2. **Milvus插入报错：text expects string input, got list**
原因：插入数据字段顺序不匹配。解决方案：严格匹配集合字段顺序。
3. **HuggingFace模型下载超时/401**
原因：境外模型源网络访问失败。解决方案：放弃预训练Embedding模型，改用简易向量函数，无需下载模型。
4. Gradio版本冲突、Pydantic报错
原因：Gradio各版本依赖冲突。解决方案：放弃Gradio，改用原生Flask搭建网页前端。


安装命令：

```powershell

            pymupdf jieba rank-bm25 faiss-cpu numpy pandas `
            pillow streamlit matplotlib python-dotenv
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install transformers rapidocr-onnxruntime --no-deps
```

### 1.2 Ollama 模型

```powershell
ollama pull bge-m3:567m        # 文本向量模型
ollama pull deepseek-r1:1.5b   # 本地生成模型（对照链路使用）
```

### 1.3 多模态模型（Chinese-CLIP）

模型 `OFA-Sys/chinese-clip-vit-base-patch16` 已在构建期下载并本地缓存。
通过项目根目录 `.env` 指定离线路径，避免联网下载：

```ini
CLIP_MODEL_PATH=G:/.../_models/chinese-clip-vit-base-patch16
HF_HUB_OFFLINE=1
```

## 3. 部署步骤

### 步骤 1：准备环境

```powershell
conda activate langchain2
cd C:\Users\30274\Desktop\工单代码\工单四\研发
```

### 步骤 2：启动 Ollama

```powershell
ollama serve          # 若已作为服务运行可跳过
ollama list           # 确认 bge-m3:567m 与 deepseek-r1:1.5b 已就绪
```

### 步骤 3：构建知识库（首次或数据更新时执行）

```powershell
python build_kb.py            # 已存在则跳过
python build_kb.py --rebuild  # 强制重建
```

该步骤依次完成：
1. 解析两份 PDF → 结构感知分块（正文 + 表格 + 键值对块）；
2. 抽取图形区域 → 图像语义解析（组织结构层级 / 图表数值）；
3. Chinese-CLIP 图像向量离线预计算并落盘；
4. 构建【优化后】与【优化前】两套 FAISS 文本向量库。

### 步骤 4：运行评测

```powershell
python evaluate.py                # 优化链路 16 题
python evaluate.py --baseline     # 追加基线对照
python evaluate.py --ablation     # 追加消融对照
```

产出：`output/eval_results.json`、`output/评测报告.md`、`output/figures/*.png`。

### 步骤 5：启动演示界面

```powershell
streamlit run app.py
# 浏览器访问 http://localhost:8501
```

## 4. 配置项说明（`src/config.py` / `.env`）

| 配置 | 默认值 | 说明 |
|---|---|---|
| `EMBEDDING_MODEL` | `bge-m3:567m` | 文本向量模型 |
| `LLM_MODEL` | `deepseek-r1:1.5b` | 本地生成模型（对照链路） |
| `CLIP_MODEL` | `OFA-Sys/chinese-clip-vit-base-patch16` | 多模态模型 |
| `CLIP_MODEL_PATH` | `.env` 指定 | 本地离线模型路径 |
| `CLIP_ENABLE` | `1` | 是否启用 CLIP 跨模态检索 |
| `USE_FIGURE_PARSER` | `1` | 是否启用图像语义解析 |
| `FIGURE_MIN_AREA_RATIO` | `0.03` | 图形最小面积占比（滤噪） |
| `OCR_WATERMARK_LUMA` | `190` | OCR 去水印亮度阈值 |
| `TOP_K` | `6` | 最终返回片段数 |
| `W_FIGURE` | `0.12` | 图形块加成权重 |
| `W_CLIP` | `0.10` | CLIP 相似度权重 |
| `ANSWER_MODE` | `extractive` | 答案合成模式 |
| `TARGET_RESPONSE_SECONDS` | `3.0` | 响应时间目标 |
| `TARGET_ACCURACY` | `0.90` | 准确率目标 |

所有参数均可通过环境变量覆盖，便于不同机器快速适配。

## 5. 常见问题（FAQ）

| 问题 | 原因 | 解决 |
|---|---|---|
| `CLIP 加载失败` | 本地模型路径未配置 | 在 `.env` 设置 `CLIP_MODEL_PATH`，并置 `HF_HUB_OFFLINE=1` |
| FAISS 保存报错 | 路径含中文 | 代码已用临时 ASCII 目录桥接，无需处理 |
| 向量库为空 | 未构建 | 运行 `python build_kb.py --rebuild` |
| 检索结果串文档 | 公司名未识别 | 检查 `config.DOC_COMPANY` 别名覆盖 |
| 图形语义缺失 | OCR 未安装 | `pip install rapidocr-onnxruntime --no-deps` |
| 响应超时 | 使用了 LLM 链路 | 切换 `ANSWER_MODE=extractive` |

# 技术文档：基于 Graph RAG 的金融问答系统

**工单编号：** 人工智能NLP-RAG-基于Graph RAG实现金融问答

## 1. 系统架构

```
┌──────────────────────────── 交互层（Streamlit） ────────────────────────────┐
│  文字输入 / 语音输入(ASR) │ 问答结果展示 │ 知识图谱可视化（交互HTML + 静态PNG） │
└───────────────┬──────────────────────────────────────────┬──────────────────┘
                │                                          │
        ┌───────▼────────┐                       ┌─────────▼──────────┐
        │  问答引擎       │                       │  图谱可视化模块     │
        │ (rag_chain)    │                       │ (graph_viz)        │
        └───────┬────────┘                       └─────────▲──────────┘
                │                                          │
        ┌───────▼──────────────────────────────────────────┴──────────┐
        │              Graph RAG 检索器（graph_retriever）              │
        │  实体链接 → 子图扩展(1跳) → 关联文本块定位                     │
        │        ⊕ 混合检索（向量召回 + 全文检索，加权融合）              │
        └───────┬───────────────────────────────────────┬──────────────┘
                │                                       │
     ┌──────────▼──────────┐                 ┌──────────▼───────────┐
     │ 知识图谱 data/graph.json │            │ 向量索引 data/vectors.npy │
     │ 节点=实体，边=关系      │            │ 倒排索引（多字段）        │
     └──────────▲──────────┘                 └──────────▲───────────┘
                │                                       │
        ┌───────┴───────────────┐             ┌─────────┴──────────────┐
        │ 图谱构建 graph_builder │             │ 语料解析 ccf_parser     │
        │ LLM抽取 + 规则模板     │◄────────────│ 9份金融年报PDF → 文本块  │
        └───────────────────────┘             └────────────────────────┘
```

## 2. 技术选型

| 模块 | 选型 | 说明 |
|---|---|---|
| PDF 解析 | PyMuPDF (fitz) | `get_text("blocks")` 保留段落边界，按 600 字合并为块 |
| 嵌入模型 | m3e-base（sentence-transformers） | 768 维、L2 归一化，中文语义检索 |
| 向量检索 | 余弦相似度 Top-N + 重排 | 重排器可切换 LLM / TF-IDF / 用户反馈 |
| 全文检索 | 自研多字段倒排索引 | 支持布尔、短语、模糊查询，BM25 打分 |
| 图谱存储 | networkx + JSON | 节点=实体，边=关系（含 relation、doc 属性） |
| 图谱抽取 | DeepSeek LLM + 正则模板 | LLM 抽取语义实体关系，规则模板补"公司-指标-数值" |
| 可视化 | networkx+matplotlib / vis-network | 静态 PNG + 可拖拽交互 HTML |
| 语音输入 | Streamlit `audio_input` + SpeechRecognition | 音频 → 文字问题（失败可回退文字输入） |
| 界面 | Streamlit | 双 Tab：问答 / 知识图谱 |

## 3. 开发流程

1. **语料解析**（`ccf_parser.py`）：解析 `附件/ccf_competition/pdf` 下 9 份年报 PDF，
   公司名由文件名中的股票代码映射（规避文件名编码问题），产出 `data/chunks.json`。
2. **知识图谱构建**（`graph_builder.py`）：
   - 按主题关键词（营业收入/净利润/不良贷款率/拨备覆盖率/内含价值/新业务价值/风险管理/绿色金融…）
     筛选高价值块（默认上限 `GRAPH_EXTRACT_CHUNKS=120`，每份文档限量，避免单文档垄断）；
   - 对每个块调用 LLM 抽取实体（公司/指标/数值/人物/职位/策略/领域/年份/机构/产品）与关系
     （包含指标/指标数值为/任职于/投资于/开展业务/实施策略/涉及领域/同比变化…）；
   - 正则模板补充 `公司-包含指标-指标`、`指标-指标数值为-数值`、`公司-涉及年份-年份` 三元组；
   - **覆盖率补齐**（`ensure_coverage`）：补全"公司节点 → 该公司年报的全部文本块"与
     "金融指标节点 → 全语料提及该指标的文本块"（年报正文多以"本行/本公司"指代，
     只靠 LLM 抽取的映射会严重低估真实覆盖）；
   - 实体按名称归一化去重，写入 `data/graph.json`（nodes / edges / entity_chunks）。
3. **检索**（`graph_retriever.py`）：
   - 实体链接：问题与图谱实体做子串匹配 + 公司别名词表 + 主题词扩展；
   - 子图扩展：默认 1 跳（足以覆盖"公司→指标→数值"链）；扩展实体中 df<3 的
     "数值/未知/人物"节点属抽取噪声，被过滤出计分集合；
   - 文本块定位：两级计分——种子实体权重 `1/(1+ln df)`（越"稀有"越具体，如"内含价值"
     压过"中国人寿"），扩展实体仅作次要证据（权重 15%），年份节点权重再降至 20%；
   - 融合：图谱归一化分数与向量/全文混合归一化分数按 `GRAPH_WEIGHT` 加权融合；
     问题未命中任何图谱实体时，回捞混合检索 Top-5 块中出现的实体，仍可展示关联子图。
4. **问答**（`rag_chain.py`）：Top-K 文本块 → 组装提示词 → DeepSeek 生成答案（严格依据资料）。
5. **可视化**（`graph_viz.py`）：全局图谱（PNG + 交互 HTML）与每题命中子图。
6. **评估**（`run_evaluation.py`）：对 `eval_question.md` 的 10 个 Question 输出检索块 + 图谱结构，
   计算 Top-5 准确率与 Top-20 召回率，并与工单七结果对比。

## 4. 使用方法

```bash
# 1) 构建语料块（首次运行，Windows Python 3.8 环境 nlp2）
python ccf_parser.py
# 2) 构建向量缓存（供向量/混合检索使用）
python -c "from kb import load_chunks; from hybrid_retriever import HybridRetriever; HybridRetriever(load_chunks(), reranker='none')"
# 3) 构建知识图谱（调用 LLM 抽取，约 120 次调用；含规则层与覆盖率补齐）
python graph_builder.py
# 若图谱已存在，只补规则层/覆盖率（不重复调用 LLM）：
python graph_builder.py --augment
# 4) 生成图谱可视化文件
python graph_viz.py
# 5) 检索评估（输出 evaluation/ 报告）
python run_evaluation.py
# 6) 启动交互界面
python app_streamlit.py     # 浏览器访问 http://localhost:8501 （端口被占用时自动顺延）
```

## 5. 关键参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `CHUNK_SIZE / CHUNK_OVERLAP` | 600 / 100 | 文本块大小与重叠 |
| `GRAPH_EXTRACT_CHUNKS` | 120 | 参与 LLM 抽取的块数上限（成本控制） |
| `GRAPH_HOP` | 1 | 子图扩展跳数 |
| `GRAPH_WEIGHT` | 0.5 | 图谱检索结果在融合分数中的权重 |
| `TOP_K / RECALL_TOP_N` | 5 / 20 | 返回块数与召回集大小 |

## 6. 数据产物

| 文件 | 说明 |
|---|---|
| `data/chunks.json` | 9 份年报解析出的文本块 |
| `data/vectors.npy` | 文本块向量（m3e，768 维，归一化） |

| `data/knowledge_graph.png` | 全局图谱静态图 |

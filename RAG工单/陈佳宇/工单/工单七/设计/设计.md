# 工单7 RAG功能测试及评估｜设计文档
工单编号：人工智能NLP‑RAG‑功能测试及评估

## 1.项目概述
本工单基于工单6实现的RAG混合检索系统，完成RAG的功能测试与检索效果评估。系统支持向量检索、BM25全文检索、RRF倒数排名混合检索，新增检索评估模块，计算召回率、精确率指标，对检索结果做量化分析。测试数据源为PDF招股说明书，使用10条业务相关问题完成全套测试评估。

## 2.需求分析
1. 沿用已有RAG系统，保留网页交互功能，支持三种检索模式切换。
2. 实现批量评估模块，输入测试问题与参考真值，输出召回率、精确率。
3. 执行10条业务问题测试，记录每条问题检索返回片段、评估指标。
4. 分析检索结果存在的问题，总结不同检索策略优缺点。
5. 输出完整文档，记录测试、评估、问题分析内容。

## 3.总体架构
PDF 文档 → PDF 解析 → 文本分块
↓
├─向量分支：文本向量化 → Milvus 向量库 → 向量相似度检索
└─关键词分支：文本分词 → BM25 索引 → BM25 关键词检索
↓
RRF 倒数排名融合（混合检索）
↓
├─Web 交互模块：网页手动提问测试
└─新增【评估模块】批量跑测试集，计算召回率、精确率指标

## 4.模块设计
1. **文档解析模块**：PyMuPDF读取PDF，按换行切分文本，过滤短文本，输出文本块列表。
2. **向量嵌入模块**：all‑MiniLM‑L6‑v2模型，输出384维向量。
3. **Milvus向量库模块**：存储向量与原文，IVF_FLAT索引，L2距离做相似度计算。
4. **BM25检索模块**：rank‑bm25库，基于词频实现关键词检索。
5. **RRF融合模块**：对向量检索、BM25检索结果做倒数排名融合，重新打分排序。
6. **Web交互模块**：Flask+内嵌HTML，网页切换检索模式，输入问题获取检索片段。
7. **新增评估模块（工单7新增）**
    - 输入：测试问题列表，每条包含问题、参考相关文本片段（真值）
    - 逻辑：将检索返回片段和真值比对，统计命中相关片段数量
    - 输出：每条测试的命中数、总真值数、召回率、精确率

> 评估指标公式
> - 召回率 Recall = 检索命中的相关片段数量 / 全部相关真值片段数量
> - 精确率 Precision = 检索命中的相关片段数量 / 本次返回的检索片段总数

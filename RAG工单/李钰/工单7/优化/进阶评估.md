## 二、进阶评估指标

### 2.1 生成质量评估
- **Faithfulness**: 答案中有多少内容可从检索上下文中推断
- **Answer Relevance**: 答案与问题的相关程度 (LLM-as-a-judge)
- **Context Precision/Recall**: 检索上下文的精准度/覆盖度

### 2.2 Faithfulness 实现 (LLM-as-a-judge)
```python
def evaluate_faithfulness(answer, contexts):
    prompt = f"""
    给定检索上下文和生成的答案, 判断答案中的每个声明是否可从上下文中推断。
    
    检索上下文: {contexts}
    生成答案: {answer}
    
    请按 JSON 格式返回:
    {{"claims": [
        {{"claim": "...", "supported": true/false, "evidence": "..."}},
        ...
    ]}}
    """
    return call_llm(prompt)
```

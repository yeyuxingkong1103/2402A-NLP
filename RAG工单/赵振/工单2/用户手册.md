# 用户手册

1. 按 `README.md` 启动 Ollama 和网页，在浏览器打开 `http://127.0.0.1:8501`。
2. 左侧默认选中《招股说明书1.pdf》。要使用其他文字版 PDF，点击“上传 PDF”选文件。
3. 点击“解析并建立索引”。首次建库会显示向量化进度；完成后从“已建知识库”选择文档。已建过的相同 PDF 会直接复用索引。
4. 在输入框用中文或英文提问，点击“提问”。界面显示回答、总用时和相关 PDF 页码。展开“原文证据”可核对数字和出处。
5. 如果问题过于含糊，补充公司、事项、时间或指标。若找不到足够相关片段，系统会提示换一种问法。
6. 回答下方可以选择“有帮助/无帮助”，填写意见后点击“提交反馈”。反馈保存在本机 `data/feedback.jsonl`。

语音提问：安装 `requirements.txt` 后，录制语音并点击“识别语音”。语音转写需要能处理音频转写请求的兼容接口；默认本地 `deepseek-r1:1.5b` 只支持文字生成，不能转写。若使用远程接口，请在左侧填入模型、地址和 Key，并通过环境变量 `TRANSCRIBE_MODEL` 指定可用转写模型。

知识库文件保存在本机 `data/indexes/`；上传的 PDF 保存在 `data/uploads/`。当前界面支持添加和切换，不提供删除按钮。

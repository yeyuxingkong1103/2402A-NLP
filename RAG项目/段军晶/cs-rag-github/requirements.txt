# ============================================================================
#  计算机专业知识库 RAG 问答助手 —— Python 依赖
# ----------------------------------------------------------------------------
#  安装方式：
#      python -m venv --system-site-packages .venv
#      .venv/Scripts/python.exe -m pip install -r requirements.txt
#
#  关于 --system-site-packages：
#      本项目采用「继承式虚拟环境」。MinerU、PyTorch、Transformers 等重型依赖
#      体积大、下载慢，且往往已存在于宿主 Python 环境中，因此让 venv 继承它们，
#      只在 venv 内安装冲突或缺失的包。这样既保证了项目隔离性，
#      又避免了数 GB 的重复下载。
#
#  关于 numpy 版本（重要）：
#      若宿主的 pandas / scipy / scikit-learn 由 conda 安装，
#      它们是用 numpy 1.x 编译的。一旦 numpy 被 pip 升级到 2.x，
#      这些包会因 C ABI 不兼容而全部无法导入（本项目实际踩过该坑）。
#      因此下方显式锁定 numpy<2。
# ============================================================================

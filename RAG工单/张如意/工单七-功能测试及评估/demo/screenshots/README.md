# 演示截图清单

> 工单编号：人工智能NLP-RAG-功能测试及评估
> 录屏脚本见 `../演示脚本.md`，本文件规定**截图命名与内容要求**。

## 一、命名规范

```
{序号}-{内容简述}.png
```

- 序号两位数字，与下表一致（`01-`、`02-` …）
- 内容简述用中文短词，不含空格（用 `-` 连接）
- 格式统一 PNG，宽度 ≥ 1600 px，确保终端与界面文字清晰可读
- 截图存放于本目录：`工单07-功能测试及评估/demo/screenshots/`

## 三、截图制作要点

1. **终端截图**：字体 ≥ 16 pt，浅色背景；中文若乱码，运行前设 `PYTHONIOENCODING=utf-8`，或在 Windows Terminal 中运行
2. **代码截图**：只截关键函数，不要截整屏代码；IDE 用浅色主题并隐藏行号栏以外的面板
3. **界面截图**：浏览器窗口宽度固定 1440 px，隐藏书签栏
4. **数据截图**：文件内容过长时只截有代表性的片段，并在图上标注重点
5. **标注**：可在截图上加红框/箭头标出关键数字，但不要遮挡内容

- 验收时快速核对该工单的实际运行情况

> 截图必须来自**真实运行**，不得使用示意或伪造的界面。

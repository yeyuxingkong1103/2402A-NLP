# 多智能体 Agent 设计思路

系统采用“协调器 + 专业 Agent + 工具 + 消息总线”的架构。协调器负责意图识别和任务拆分，专业 Agent 只处理自己负责的业务域，工具层负责访问数据库和外部服务，消息总线记录状态和中间结果。

## 技术组件

- Agent 注册中心：维护角色、能力和版本。
- Agent 状态：保存会话、任务、工具调用和错误信息。
- 消息总线：传递标准化请求、观察结果和最终答案。
- 协调器：分类、分发、聚合和冲突处理。
- 专业 Agent：营销、订单、售后等领域处理器。
- 观测与审计：记录每次路由、工具调用和响应来源。

## 设计原则

单一职责、显式状态、可重试、可观测和最小权限。Agent 之间通过结构化消息通信，避免直接依赖彼此内部实现。

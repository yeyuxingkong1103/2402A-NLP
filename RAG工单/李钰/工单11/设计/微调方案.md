# Embedding 模型微调方案

> 工单编号: 人工智能 NLP-RAG 项目-Embedding 模型微调任务
> 目标: 金融专业领域 Embedding 微调,解决"语义鸿沟"

## 一、问题背景

通用 Embedding 模型 (BGE/bge-base-en) 在大规模语料上预训练,但面对专业领域:
- "complaint" → 日常"抱怨" vs 法律"诉状"
- "Project Phoenix" → 通用无意义 vs 公司内部项目代号
- 金融术语同义词: "控股股东" vs "控制方" vs "实际控制人"

→ 通用模型无法区分专业语义差异 → 检索不相关 / 遗漏相关

## 二、微调策略

### 2.1 基础模型
| 模型 | 大小 | 说明 |
|------|------|------|
| BAAI/bge-base-en-v1.5 | ~400MB | 工单指定 |
| BAAI/bge-small-zh | ~90MB | 中文可选 |
| sentence-transformers/all-MiniLM | ~23MB | 轻量备选 |

### 2.2 微调方法
| 方法 | 适用场景 | 计算需求 |
|------|----------|----------|
| **全量微调 (Full FT)** | 追求最佳效果 | GPU 高 |
| **LoRA** | 参数高效,仅训练小矩阵 | GPU 低 |
| **QLoRA** | 量化 + LoRA, 4bit | GPU 极低 |
| **预训练继续** | 领域语料 MLM | GPU 高 |

## 三、数据集格式

| 格式 | 示例 | 损失函数 |
|------|------|----------|
| **正例对** | ("注册资本是多少", "武汉兴图新科注册资本7360万元") | Contrastive Loss |
| **三元组** | anchor="控股股东是谁", pos="武汉力源科技是控股股东", neg="注册资本7360万元" | Triplet Loss |
| **相似度对** | ("军用收入占比", "军用领域收入占主营业务比重", 0.9) | Cosine Similarity Loss |
| **分类文本** | (text="武汉力源科技持有武汉力源35%", class="关联方关系") | Supervised Loss |

### 3.1 金融领域自动数据生成
```
PDF 切块 → 问答对生成 (LLM / 规则) → 正例对
正例对 + 随机负样本 → 三元组
正例对 + 领域同义词扩展 → 相似度对
```

## 四、损失函数

| 损失 | 公式 | 适用数据 |
|------|------|----------|
| **Triplet Loss** | max(0, d(a,p) - d(a,n) + margin) | 三元组 |
| **Contrastive Loss** | y*log(s) + (1-y)*log(1-s) | 正负例对 |
| **Cosine Loss** | 1 - cos_sim(emb1, emb2) | 相似度分数对 |
| **Matryoshka Loss** | 分层截断的 Triplet Loss | 可截断嵌入 |

## 五、评估指标

| 指标 | 含义 | 验收 |
|------|------|------|
| **Spearman 相关** | 嵌入相似度与人工标注相似度的排名相关 | ↑ |
| **Accuracy@K** | Top-K 检索准确率 | ↑ ≥ 10% |
| **MRR** | 平均倒数排名 | ↑ |
| **NDCG** | 排序质量 | ↑ |
| **微调前 vs 后** | 同一测试集对比 | **必须有数据支撑** |

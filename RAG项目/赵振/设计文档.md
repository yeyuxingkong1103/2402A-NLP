# 律知法律问答系统设计文档

## 1. 项目概述

本项目是一个基于 RAG 的法律角色扮演问答系统。用户可以选择不同角色提问，系统从刑法资料中检索依据，再让大模型组织答案。

当前角色：

- 法律助手：回答简明，指出相关条文。
- 法学老师：用通俗语言讲解概念，并举简单例子。

## 2. 总体架构

```text
用户浏览器
    ↓ HTTP
FastAPI 后端
    ├── Redis：保存最近聊天记录
    ├── Ollama BGE-M3：问题和文本向量化
    ├── Milvus：检索法律资料和长期记忆
    ├── BGE-Reranker：对召回结果重新排序
    └── Ollama DeepSeek-R1：生成最终回答
```

## 3. 离线建库流程

```text
原始文件
   ↓
文件解析
   ├── PDF：MinerU
   ├── Word：python-docx
   ├── JSON/JSONL：PyMuPDF
   └── 其他格式：DeepSeek 多模态接口
   ↓
文本切分：每块 500 字，重叠 50 字
   ↓
BGE-M3 向量化
   ↓
写入 Milvus criminal_law_chunks 集合
```

### 3.1 法律资料字段

| 字段 | 说明 |
|---|---|
| `text` | 文本块内容 |
| `vector` | BGE-M3 生成的向量 |
| `source` | 原始文件名 |
| `location` | 解析位置，例如 MinerU解析、第1段 |
| `page` | 页码，当前部分格式可能为 0 |

### 3.2 运行方式

先启动 MinerU、Ollama 和 Milvus，再运行：

```bash
python offline_ingest.py
```

脚本会重新创建 `criminal_law_chunks` 集合，因此重新建库会覆盖原有同名集合。

## 4. 在线问答流程

```text
用户问题
   ↓
读取 Redis 最近聊天记录
   ↓
问题向量化
   ↓
Milvus 召回 5 条资料
   ↓
BGE-Reranker 重排，保留前 3 条
   ↓
Milvus 查询长期记忆
   ↓
拼接角色提示词
   ↓
DeepSeek-R1 生成答案
   ↓
保存短期记忆和长期记忆
   ↓
返回答案和引用资料
```

## 5. 记忆设计

### 短期记忆：Redis

Redis Key 格式：

```text
chat:{user_id}:{role}:{session_id}
```

每次保存最近 6 条消息，保存时间为 24 小时。

### 长期记忆：Milvus

长期记忆使用 `chat_memory` 集合，保存：

- `user_id`
- `role`
- 对话文本
- 对话向量

检索长期记忆时，只查询当前用户和当前角色的内容。

## 6. 提示词设计

系统会把以下内容交给大模型：

```text
角色设定
最近聊天记录
长期记忆
检索到的法律资料
当前问题
```

提示词要求模型只根据资料回答，不知道时明确说不知道，避免编造法律条文。

## 7. 角色流程

```text
用户选择角色
    ↓
前端提交 role
    ↓
后端读取对应角色提示词
    ↓
同一份法律知识库进行检索
    ↓
按照角色风格生成回答
```

角色主要影响回答方式，法律资料仍然来自同一个 Milvus 知识库。

## 9. 服务和模型

| 组件 | 用途 |
|---|---|
| MinerU | 复杂 PDF 解析 |
| python-docx | Word 文档解析 |
| PyMuPDF | JSON/JSONL 文本读取 |
| BGE-M3 | 向量化 |
| Milvus | 向量检索和长期记忆 |
| BGE-Reranker | 检索结果精排 |
| Redis | 短期对话记忆 |
| DeepSeek-R1 7B | 本地回答生成 |
| FastAPI | 后端接口服务 |

## 10. 启动顺序

```text
1. 启动 Docker 和 Milvus
2. 启动 Redis
3. 启动 Ollama，并确认 bge-m3:567m、deepseek-r1:7b
4. 启动 MinerU 服务
5. 首次运行 offline_ingest.py 建立知识库
6. 运行 web_app.py
7. 浏览器访问 http://127.0.0.1:8000
```

## 11. 当前限制

- 同一时间只允许一个本地问答请求。
- 资料更新后需要重新运行离线建库脚本。
- Milvus、Redis、Ollama 任一服务未启动，在线问答无法正常工作。
- 生成结果必须结合引用原文核对，不能替代正式法律意见。

# 工单02 技术文档：基于PDF文档的问答系统优化

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统优化

## 一、优化目标

在工单01 基础版上，从 pdf 解析处理、分块优化、检索优化层面提升检索准确率（目标 ≥90%），
响应时间 ≤3 秒。

## 二、优化方案

| # | 优化项 | 优化前 | 优化后 | 解决的问题 |
|---|---|---|---|---|
| 1 | 页眉页脚清洗 | 每块开头带"公司名+招股意向书+1-1-XX页码"噪音 | 正则清洗噪音行 | 噪音稀释向量语义：实测真值分块（注册资本5,520万）从第14名升至第5名，答案由错变对 |
| 2 | LLM查询扩展 | 用户原句单路检索 | qwen2.5 改写3个等价问法多路召回 | 问法与文档用词不一致（"军用收入"vs"军品收入"） |
| 3 | 多路融合策略 | 单路Top5 | 最大向量相似度为主 + RRF小幅加分 | 纯RRF会稀释单路强命中（实测退步后修正：融合分 = max(向量相似度) + 0.05×RRF） |
| 4 | 关键词重排 | 纯向量分 | jieba关键词命中加权，自动剔除"公司名"等非区分性词（过半候选含有的词） | 向量语义漂移、缺字面证据校验 |
| 5 | 生成侧护栏 | 无 | 同一指标多数值时"以最新现行值为准" | 历史沿革旧值干扰（如注册资 本100万是前身设立时旧值） |

## 三、实验结果（10个验收问题，ground truth 已从原文逐一核对）

| 指标 | 优化前 | 优化后 |
|---|---|---|
| 检索命中率（Top5上下文含关键事实） | 8/10 | 7/10* |
| 回答正确率（答案含关键事实） | 6/10 (60%) | **7/10 (70%)** |

- ✅ 修复：问题34（上游企业 67%→100% 命中，回答✅）、问题543（注册资本，上下文100%命中但旧版答错→新版✅）
- ⚠️ *问题207 检索命中从100%降至0%：优化前未清洗索引的分块恰好包含 p30 募集资金表格整行；
  清洗重分块后该表格行被切断。根因是**表格数据**，非检索策略问题。
- 剩余 3 题（260/33/207）答案均在表格中（p342-343 收入分类表、p30 募集资金用途表）→
  由**工单03 表格解析**解决，形成"文字优化 → 表格解析"的递进链路。

## 四、运行方式

```bash
python run_optimize.py    # 自动构建优化前基线索引、跑10题、生成《优化前后对比结果.md》
```

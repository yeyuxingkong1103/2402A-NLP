# 工单11报告 — Embedding 模型微调

> 工单编号：人工智能NLP-RAG项目-Embedding模型微调任务
> 完成时间：2025 年 8 月

## 一、目标

针对金融领域数据（11 个 PDF），微调 Embedding 模型，提升 RAG 检索精度。

## 二、微调准备

### 2.1 数据集生成

| 项 | 值 |
|----|:---:|
| 数据源 | 11 个 PDF（2 招股书 + 9 年报） |
| 抽取 chunks | 686 个 |
| Q&A 对 | 500 对 |
| 生成模型 | Qwen2.5-VL-3B-Instruct |
| 数据格式 | [{"query": str, "positive": str, "doc": str, "page": int}] |

**样例**：
- Query: 2019年本行主要资产质量指标有哪些变化？
- Positive: 下游供应链...2019 年末，本行主要资产质量指标...
- 来源: 2019年_平安银行_000001_年度报告.pdf 第27页

### 2.2 基础模型

- **BAAI/bge-base-zh-v1.5**（768 维，中文）

## 三、微调策略

### 3.1 损失函数

**MultipleNegativesRankingLoss (MNRL)**：
- 一个 query 对一个 positive，批次内其他 positive 作为负样本
- 温度参数 τ（默认 0.05）

### 3.2 训练参数

| 参数 | 值 |
|------|---|
| epochs | 3 |
| batch size | 16 |
| learning rate | 2e-5 |
| fp16 | True |
| batch sampler | NO_DUPLICATES |

## 四、评估方法

**InformationRetrievalEvaluator**：
- 评估集：训练数据后 10%（50 对）
- 15 个指标

## 五、评估结果

| 指标 | 微调前 | 微调后 | 提升 |
|------|:---:|:---:|:---:|
| Accuracy@1 | 0.7600 | **0.8600** | **+0.1000** |
| Accuracy@3 | 0.8800 | 0.9400 | +0.0600 |
| Accuracy@5 | 0.9000 | 0.9600 | +0.0600 |
| Accuracy@10 | 0.9600 | **1.0000** | +0.0400 |
| Precision@1 | 0.7600 | 0.8600 | +0.1000 |
| Precision@10 | 0.0960 | 0.1000 | +0.0040 |
| Recall@1 | 0.7600 | 0.8600 | +0.1000 |
| Recall@10 | 0.9600 | **1.0000** | +0.0400 |
| **NDCG@10** | 0.8606 | **0.9289** | **+0.0684** |
| **MRR@10** | 0.8290 | **0.9064** | **+0.0774** |
| **MAP@100** | 0.8319 | **0.9064** | **+0.0745** |

## 六、关键发现

1. **NDCG@10 提升 6.84%**：检索排序质量显著提升
2. **MRR@10 提升 7.74%**：第一个相关文档排名更靠前
3. **Accuracy@1 提升 10%**：Top-1 命中率从 76% 提升到 86%
4. **Recall@10 达到 100%**：所有相关文档都能被检索到

## 八、结论

1. **微调效果显著**：11 个指标全面提升
2. **NDCG@10 从 0.86 → 0.93**
3. **MRR@10 从 0.83 → 0.91**
4. **领域适配有效**
5. **可整合到 RAG**：`finetuned_model` 可直接替换 `bge-base-zh-v1.5`

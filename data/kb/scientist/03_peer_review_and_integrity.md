# 同行评审与科研诚信

## 一、同行评审的作用与局限

作用：筛选方法明显缺陷、结论缺乏支撑的稿件，提升文献整体质量。

局限：

1. 审稿人时间有限，难以复现分析；
2. 存在新颖性偏好，负面结果难以发表（发表偏倚）；
3. 无法保证数据真实，历史上多起造假通过评审后多年才被发现。

结论：**通过同行评审 ≠ 结论正确**，只是通过了第一道质量闸门。

## 二、复现性的三个层次

| 层次 | 含义 | 要求 |
|---|---|---|
| 可重复 | 同一数据同一代码得到同一结果 | 提供数据与代码 |
| 可重现 | 独立团队用新数据得到一致结论 | 明确操作定义与测量方法 |
| 可推广 | 在新人群、新场景成立 | 报告外部效度与边界条件 |

近年调查显示，多个学科的可重复率显著低于预期，因此元分析与多中心验证愈发重要。

## 三、预注册与注册报告

* **预注册**：在数据收集前公开研究问题、主要结局、分析计划；
* **注册报告**：期刊在结果未知时即有条件接受，从根本上削弱发表偏倚。

预注册并不禁止探索性分析，但要求区分**验证性分析**与**探索性分析**，
后者必须标注为假说生成。

## 四、常见学术不端

| 类型 | 表现 |
|---|---|
| 伪造 | 编造数据或结果 |
| 篡改 | 选择性删除、修改不利数据 |
| 剽窃 | 未标注引用他人文字、数据、想法 |
| 重复发表 | 同一研究拆分或重复发表以增加数量 |
| 挂名 | 未实质贡献者署名，或剥夺实质贡献者署名 |
| 图片不当处理 | 拼接、重复使用、局部擦除 |

## 五、掠夺性期刊识别

1. 承诺极短审稿周期（数天）并保证录用；
2. 收取高额版面费但不提供评审记录；
3. 编委名单无法核实，或未经同意被挂名；
4. 期刊名与知名期刊高度相似，ISSN 无法在权威库检索。

## 六、撤稿意味着什么

撤稿公告会写明原因：数据不可靠、结论无法复现、重复发表、作者不端等。
引用文献时应检查是否已被撤稿（如 Retraction Watch 数据库），
继续把撤稿文献作为依据会污染后续研究。

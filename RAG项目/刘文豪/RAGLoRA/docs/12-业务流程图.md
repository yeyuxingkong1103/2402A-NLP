# RAGLoRA 业务流程图

> 六张 Mermaid 流程图覆盖系统全部核心业务。节点内标注对应模块 / 需求规格说明书（05）的
> FR / BR 编号，便于追溯。渲染：GitHub / Typora / VS Code 均可直接显示。

## 图1 系统总体业务流程（用户视角）

```mermaid
flowchart TD

    REG --> LOGIN
    LOGIN --> BROWSE["浏览角色列表<br/>可按分类过滤 · 查看热度榜<br/>FR-02 / FR-12"]

    MORE -- 否 --> END["结束<br/>短期记忆 1h 过期<br/>长期记忆保留可跨会话召回<br/>FR-08"]
```

## 图2 在线问答主链路（核心流程）

```mermaid
flowchart TD
    REQ["POST /chat/stream<br/>SSE 流式 · 或非流式 completions"] --> LIMIT{"String 限流<br/>30 次/分/用户<br/>FR-12 · BR-06"}
    LIMIT -- "超限" --> R429["429 + Retry-After<br/>Redis 挂则 fail-open 放行"]
    LIMIT -- "放行" --> CTX["装载上下文<br/>校验会话归属 404 隔离 BR-03<br/>取短期记忆 FR-08"]
    CTX --> REW{"需要改写?<br/>多轮 且 触发启发式<br/>≤12字 / 代词 / 承接连词<br/>FR-05"}
    REW -- "是" --> RW["LLM 指代消解改写<br/>失败/超长则用原句"]
    REW -- "否" --> RECALL
    RW --> RECALL["多路召回 · 见图4<br/>FR-06"]
    RECALL --> RRF["RRF 融合 + 指名文档加分<br/>权重 vector 1.0 / graph 1.2<br/>DOC_BOOST 1.5"]
    RRF --> RERANK["精排 top20 → top5<br/>bge-reranker-v2-m3<br/>GPU 分时 413ms · BR-12<br/>异常降级原序 BR-08"]
    RERANK --> LMEM["长期记忆召回 top3<br/>跨会话 · 按用户隔离<br/>FR-08 · BR-03"]
    LMEM --> PROMPT["组装提示词<br/>人格三层 + 编号知识片段<br/>+ 对话历史 + 长期记忆块<br/>FR-02/04"]
    PROMPT --> GEN["Ollama qwen2.5:7b 生成<br/>temperature 0.3 · max 800<br/>SSE 逐 token FR-04"]
    GEN --> POST["后处理<br/>换行压缩 / 去装饰符 / 规范 [n]<br/>BR-02"]
    POST --> PERSIST["落库与记忆沉淀<br/>消息×2 · 短期记忆 · 长期记忆<br/>zSet 热度 +1<br/>FR-08/12"]
    PERSIST --> DONE["done 事件<br/>answer + sources + trace"]
```

## 图3 离线知识库入库流程

```mermaid
flowchart TD
    UP["上传 pdf / txt / md<br/>或指定本地路径<br/>FR-09"] --> HASH["计算 sha1 文件指纹"]
    HASH --> DUP{"collection + hash<br/>已存在? BR-04 幂等"}
    DUP -- "是" --> SKIP["跳过 · 状态保持"]
    DUP -- "否" --> REG["MySQL 登记 status=parsing"]
    REG --> PROBE{"前 5 页页均字数<br/>≥ 50 ?<br/>OCR 分流 FR-10"}
    PROBE -- "≥50 文本层" --> FITZ["PyMuPDF 逐页提取"]
    PROBE -- "<50 扫描件" --> MINERU["MinerU OCR<br/>vlm-engine · 900s 超时<br/>失败且已授权 → PaddleOCR"]
    FITZ --> CLEAN["清洗: 页眉页脚/水印行剔除"]
    MINERU --> CLEAN
    CLEAN --> CHUNK{"分块策略 auto 判定"}
    CHUNK -- "含 ≥3 处『第X条』" --> ART["article: 按条文切分<br/>超 800 字句号聚合二切"]
    CHUNK -- "叙述文本" --> PARA["paragraph: 512 字聚合<br/>50 字重叠"]
    ART --> EMB["bge-m3 批量编码<br/>GPU fp16 batch 16<br/>dense 1024 + sparse"]
    PARA --> EMB
    EMB --> W1["主写 Qdrant<br/>内容哈希主键 幂等覆盖"]
    W1 --> W2["次写 Milvus<br/>失败不回滚 · 提示补同步脚本"]
    W2 --> W3["MySQL 更新 status=ready<br/>chunk_count"]
    W3 --> OK["完成<br/>kb_legal 14319 条 / kb_medical 688 条"]
```

## 图4 多路召回与 RRF 融合

```mermaid
flowchart TD

    GH -- "是" --> HY["回向量库补正文<br/>无正文则丢弃"]
    GH -- "否" --> EMPTY["该路 0 命中"]
    V --> FUSE["RRF 融合<br/>score = Σ weight/(60+rank)<br/>按 来源+前80字 去重累加"]
    DS --> FUSE
    HY --> FUSE
    MISS --> FUSE
    EMPTY --> FUSE
    FUSE --> TOP["score 降序取 recall_k 20<br/>⚠ RRF 分不得作相关性阈值 BR-09"]
    TOP --> RR["交精排 见图2"]
```

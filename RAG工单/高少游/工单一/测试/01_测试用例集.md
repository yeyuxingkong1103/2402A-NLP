# 测试用例集

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统
> 评估数据源：`data/questions.json`，共 10 道题，均含从招股说明书人工核对的参考答案。

---

## 1. 测试设计思路

围绕工单验收目标设计 10 道题，覆盖：
- **财务数值查询**（收入、占比、募集资金）——检验精确数值提取；
- **事实/实体查询**（法定代表人、注册资本、技术标准）——检验专有名词/强实体；
- **关系/背景查询**（上下游、工程奖项、供应商领域）——检验语义综合与跨页检索。

每题同时跑 **RAG（检索增强）** 与 **纯 LLM（无上下文）** 两条链路，量化对照。

## 3. 命中判定标准

对每道题，人工检查回答文本中是否包含**参考答案的关键数值/专有名词**（任一命中即判"答案正确"），既客观又避免主观评分。判定词表在 `scripts/build_report.py` 的 `_KEY_TOKENS` 中维护。

## 4. 评估维度

| 维度 | 说明 | 工具 |
|---|---|---|
| 正确性(定性) | 答对 几/10 题 | build_report 关键词命中 |
| 速度(定量) | 端到端耗时 RAG vs 纯 LLM | evaluate 记录 elapsed |
| RAGAS指标(定量) | faithfulness等5项 | ragas_score.py（需JSON模型） |

## 5. 如何在命令行覆盖跑

```powershell
# 产出一份评估(内存模式, 跳过RAGAS裁判)
python scripts/evaluate.py --top-k 8 --skip-ragas

# 生成对比报告
python scripts/build_report.py
```
结果写入 `output/evaluation_report.json` 与 `output/evaluation_report.md`。

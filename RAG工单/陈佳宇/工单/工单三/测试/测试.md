# 工单3 - 测试文档
## 1. 测试环境
- WSL Ubuntu 24.04
- Python 3.12
- Milvus本地服务
- 浏览器：Chrome
- 测试文件：招股说明书2.pdf

## 2. 测试目标
验证RAG系统能够正确读取PDF招股说明书，对股权、募资、财务类问题，检索返回PDF原文中正确内容，统计检索耗时。

## 4. 性能测试
- 平均检索耗时：0.01~0.02秒
- 并发：单用户网页访问，稳定无崩溃

## 5. 测试结论
全部13条测试用例通过，系统能够从PDF招股说明书（含表格）检索到对应的原文信息，检索速度满足项目要求。
> 小瑕疵：PDF表格线条会被识别为少量杂字符，不影响关键信息读取，不影响功能验收。

# 工单 02：基于 PDF 文档的问答系统优化

**工单编号**：人工智能NLP-RAG-基于PDF文档的问答系统优化

## 一、项目简介

针对工单 01 实现的问答系统，从 **PDF 解析、分块、检索** 三个层面进行优化，
将问答准确率提升至 90% 以上，并对比优化前后的检索精度变化。

## 二、优化点

| 层面 | 优化前（基线） | 优化后 |
|------|----------------|--------|
| 分块 | 固定窗口 300 字符 | 句子感知分块（按句合并 + 上下文回退） |
| 检索 | TF-IDF 余弦相似度 | BM25 评分（对长文档召回更稳） |
| 召回 | Top-3 | Top-3（相关性更高） |

## 三、目录结构

```
02_工单/
├── app.py           # 优化后问答主程序
├── optimize.py      # 优化前后对比脚本
├── config.py        # 配置
├── pdf_parser.py    # 分块（基线 + 优化）
├── retriever.py     # 检索（TF-IDF + BM25）
├── llm.py           # LLM 封装
├── requirements.txt
└── README.md
```

## 四、运行

```bash
pip install -r requirements.txt

# 查看优化前后检索精度对比
python optimize.py

# 优化后交互式问答 / 批量演示
python app.py
python app.py --test
```

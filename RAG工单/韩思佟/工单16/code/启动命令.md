# 工单16 —— VLM 微调启动命令（Windows PowerShell / WSL 通用）

> 本文件给的是**照抄可跑**的命令。默认在 LLaMA-Factory 仓库根目录执行。
> 硬件参考：本机 RTX 3060 Laptop 6GB —— 请用「2B 模型 + QLoRA」档位。

## 0. 环境准备

```bash
git clone --depth 1 https://github.com/hiyouga/LLaMA-Factory.git
cd LLaMA-Factory
pip install -e ".[torch,metrics]"
pip install bitsandbytes                      # 4bit QLoRA 需要（6GB 显存必装）
pip install qwen-vl-utils                     # Qwen2-VL 图像预处理
```

## 1. 生成微调数据

```bash
# 在工单交付目录下执行（会自动渲染 PDF 页面为 png）
python 工单16/code/build_vlm_dataset.py \
  --qa   data/imdr/questions.jsonl \
  --docs data/imdr \
  --out  工单16/产出物/vlm_sft_sharegpt.jsonl \
  --img-dir 工单16/产出物/images \
  --format sharegpt
```
产物：`工单16/产出物/vlm_sft_sharegpt.jsonl`、`images/`、`数据集统计.json`。

## 2. 注册数据集到 LLaMA-Factory

把 `code/dataset_info.snippet.json` 的内容合并进 LLaMA-Factory 的 `data/dataset_info.json`，
并把 `vlm_sft_sharegpt.jsonl` 与 `images/` 放到 `data/` 下（或改 `file_name` 为绝对路径）。

## 3. 开始微调

```bash
# 6GB 显存档（推荐先跑这个，确认能起来）
llamafactory-cli train 工单16/code/qwen2vl_lora_sft_imdr_2b_qlora.yaml

# 显存 >=16GB 档
llamafactory-cli train 工单16/code/qwen2vl_lora_sft_imdr.yaml
```

训练日志重点观察：
- `train_loss` 是否**正常下降**（验收标准1：至少 1 个 epoch 完成，损失正常下降）
- 是否 OOM —— OOM 就把 `image_max_pixels` 减半、`lora_rank` 降到 8、开 `quantization_bit: 4`

## 4. 合并 LoRA 并导出

```bash
llamafactory-cli export 工单16/code/export_merged.yaml
```
导出目录默认 `saves/qwen2vl-7b/lora/imdr/merged`。

## 5. 评估（微调前 vs 微调后）

```bash
# 基线模型
python 工单16/code/evaluate_vlm.py \
  --model Qwen/Qwen2-VL-2B-Instruct \
  --test 工单16/产出物/vlm_sft_sharegpt.jsonl \
  --tag base

# 微调后
python 工单16/code/evaluate_vlm.py \
  --model saves/qwen2vl-7b/lora/imdr/merged \
  --test 工单16/产出物/vlm_sft_sharegpt.jsonl \
  --tag ft
```
输出：`产出物/评估_base.json`、`评估_ft.json`、`微调前后对比.md`（含 BLEU/ROUGE、
专业术语准确性、图纸推理正确性三项指标与失败案例分析）。

## 2. 离线建库流程（Mermaid）

```mermaid
flowchart TD
    A[招股说明书1.pdf / 招股说明书2.pdf] --> B[pdf_parser 版式清洗]
    B --> B1[页眉页脚剔除 + 断句合并 + 标题识别]
    B1 --> C[table_parser 表格结构化解析]
    C --> C1[find_tables 取单元格网格]
    C1 --> C2[合并单元格还原 左邻优先/上邻兜底]
    C2 --> C3[删空列 → 交错列折叠 → 删空列]
    C3 --> C4[表头规整 + 表题识别]
    C4 --> D{双表示}
    D --> D1[table 块: Markdown 结构]
    D --> D2[table_kv 块: 表头：取值]
    B1 --> E[text 块: 小节父块 + 递归切片]
    D1 --> F[OllamaEmbeddings bge-m3]
    D2 --> F
    E --> F
    F --> G[(FAISS 向量库 optimized)]
```

## 3. 在线问答流程（Mermaid）

```mermaid
flowchart TD
    Q[用户提问] --> QU[Query 理解]
    QU --> QU1[噪声剥离 → core]
    QU --> QU2[关键词/实体/年份]
    QU --> QU3[答案类型判定]
    QU --> QU4[文档级路由 doc_hint]
    QU1 --> R[多路混合召回]
    QU2 --> R
    QU3 --> R
    R --> R1[向量召回 Top-30]
    R --> R2[BM25 召回 Top-30]
    R1 --> FUSE[RRF 融合]
    R2 --> FUSE
    QU4 --> FILT[文档级路由过滤]
    FUSE --> FILT
    FILT --> RK[表格感知重排]
    QU3 --> RK
    QU4 --> RK
    RK --> DD[按 父块+ctype 去重]
    DD --> BR{answer_type == table?}
    BR -- 是 --> TA[表格专用路径]
    TA --> TA1[表格级消歧: 表题匹配 + 章节先验]
    TA1 --> TA2[行打分]
    TA2 --> TA3{枚举型?}
    TA3 -- 是 --> TA4[整表罗列]
    TA3 -- 否 --> TA5[字段型: 命中行 + 取到即止]
    BR -- 否 --> SB[句子级抽取打分]
    SB --> SB1[对比词惩罚 / 套话惩罚 / 章节先验]
    TA4 --> ANS[答案 + 页码引用 + 证据片段]
    TA5 --> ANS
    SB1 --> ANS
```

## 4. 表格解析子流程（Mermaid）

```mermaid
flowchart LR
    P[PDF 页面] --> T[page.find_tables]
    T --> G[单元格网格 + bbox]
    G --> N[单元格规整]
    N --> M[_fill_merged 合并单元格还原]
    M --> D1[_drop_empty 删全空行列]
    D1 --> I[_collapse_interleaved 交错列折叠]
    I --> D2[_drop_empty 再删空列]
    D2 --> Q{_quality_ok 质量过滤}
    Q -- 不合格 --> X[丢弃 误检表格]
    Q -- 合格 --> H[_merge_header 多级表头合并]
    H --> CAP[_caption_above 表题识别]
    CAP --> TB[TableBlock]
    TB --> MD[markdown 属性]
    TB --> KV[kv_lines 属性]
```

## 5. 前后对比链路（Mermaid）

```mermaid
flowchart TB
    subgraph 优化前 baseline
        B1[表格拍平为文本行] --> B2[固定 500/80 递归切片]
        B2 --> B3[向量 + BM25 + RRF 无重排]
        B3 --> B4[本地 LLM 生成答案]
    end
    subgraph 优化后 optimized
        O1[表格结构化 双表示] --> O2[结构感知 700/120 + 父子块]
        O2 --> O3[多路召回 + RRF + 表格感知重排 + 文档路由]
        O3 --> O4[抽取式 表格专用答案路径]
    end
    B4 --> CMP[对比: 答案命中 50% → 100%; 耗时 4.06s → 1.48s]
    O4 --> CMP
```

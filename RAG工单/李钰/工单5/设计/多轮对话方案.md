## 二、核心技术点

### 2.1 指代消解
| 指代 | 补全策略 | 示例 |
|------|----------|------|
| "他"/"她"/"它" | 上一轮识别的公司名 | "他参与的..." → "武汉兴图新科参与的..." |
| "这个公司"/"该公司" | 会话当前公司 | 同上 |
| "那XX呢?" | 公司切换 + 补全上一轮意图 | "那武汉力源呢?" → "武汉力源的法定代表人" |
| "也是?"/"同样?" | 同上 | - |
| 无主语短句 | 继承上一轮核心实体 | "注册资本是多少?" → "XX公司的注册资本" |

### 2.2 会话状态管理
```python
class SessionContext:
    company: str              # 当前聚焦公司
    company_history: List[str] # 对话中出现过的公司序列
    last_question: str        # 上一轮原始问题
    last_enriched: str         # 上一轮补全后的问题
    last_answer: str          # 上一轮答案
    topic: str                # 当前话题 (收入/标准/法定代表人...)
    turn_count: int           # 对话轮次
```

### 2.3 Query 理解 V3 架构
```
原始问题
  │
  ├─ 1. 指代消解 (他/这个公司 → 完整公司名)
  │
  ├─ 2. 省略补全 (那XX呢? → 继承上一轮意图)
  │
  ├─ 3. 实体抽取 (公司/实体/属性)
  │
  ├─ 4. 意图识别 (当前要问什么)
  │
  ├─ 5. 完整查询生成
  │
  └─ 6. 路由到 V4 (图像/表格/文本检索)
```

# 技术选型
| 模块 | 技术/框架 | 作用 |
| ---- | ---- | ---- |
| PDF解析 | pymupdf | 提取PDF文档文本 |
| Embedding向量模型 | all-MiniLM-L6-v2 | 文本向量化 |
| 向量数据库 | Milvus | 向量存储、相似度检索 |
| Web后端 | Flask | 搭建网页服务，处理请求 |
| 大模型 | DeepSeek-chat | 根据检索上下文生成答案 |
| 前端 | 内嵌HTML | 网页表单、结果展示 |
| 语言 | Python3.12 | 项目开发语言 |
| 依赖库 | requests、sentence-transformers | 接口调用、向量模型 |

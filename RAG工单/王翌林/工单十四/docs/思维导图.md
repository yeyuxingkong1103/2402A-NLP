# 工单十四：思维导图

## 系统架构

```
用户提问
    │
    ▼
┌─────────────────────────────────────────┐
│            查询路由器 (query_router)      │
│  关键词匹配：第X页图/部件/尺寸/气流 → 图像 │
│  否则 → 文本                              │
└──────────────┬───────────────┬──────────┘
               │               │
        ┌──────▼──────┐ ┌──────▼───────┐
        │  文本通道    │ │  图像通道     │
        │             │ │              │
        │ BM25+向量   │ │ Qwen2-VL     │
        │ 混合检索     │ │ VQA 视觉问答  │
        │             │ │              │
        │ bge-reranker│ │ + 页面OCR文本 │
        │  重排序      │ │  作为上下文   │
        └──────┬──────┘ └──────┬───────┘
               │               │
               └───────┬───────┘
                       ▼
              ┌────────────────┐
              │ DeepSeek LLM   │
              │  生成最终答案   │
              └────────────────┘
```

## 数据流

```
PDF (图片型, 无文本层)
    │
    ▼ PyMuPDF 提取内嵌图片
页面图片 (原始高分辨率)
    │
    ▼ Qwen2-VL OCR
每页文本 (JSON)
    │
    ├──────────────────────┐
    ▼                      ▼
分块 (chunker)        页面图片映射
    │                      │
    ▼                      │
bge-m3 向量化              │
    │                      │
    ▼                      │
Milvus Lite               │
(HNSW+COSINE)             │
    │                      │
    ▼                      │
检索结果 ──────────────────┤
    │                      │
    ▼                      ▼
DeepSeek LLM ◄──── Qwen2-VL VQA
    │
    ▼
最终答案
```

## 关键技术决策

1. **OCR 选型**：PaddleOCR 3.x 检测失败 → Qwen2-VL 多模态 OCR
2. **分块策略**：按页分块（专利文档短，每页 1-3 块）
3. **检索策略**：BM25（关键词精确匹配）+ 向量（语义匹配）+ RRF 融合 + Rerank
4. **图像问答**：查询路由 + VLM VQA，不依赖 OCR 文本中的空间关系
5. **向量库**：Milvus Lite（无需独立服务，适合单文档场景）

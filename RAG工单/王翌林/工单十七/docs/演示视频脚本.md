# 工单十七 · 演示视频脚本（Grafana 对比）

**时长建议：3~4 分钟**

## 镜头1：故障复现（0:00–0:45）
- 启动基线服务 `uvicorn src.api_baseline:app --port 8018`，`curl /health` 观察初始 RSS ≈ 48MB。
- 开启 `locust -f loadtest/locustfile.py --host http://127.0.0.1:8018`，20 用户压测。
- 旁白：“并发上来后，延迟从约 1 秒继续恶化，容器内存一路上涨。”
- 切到 Grafana 面板：`rag_process_rss_mb` 曲线陡峭上升。

## 镜头2：定位根因（0:45–1:30）
- 展示 `docs/问题排查分析报告.md` 的根因表：每请求初始化重组件、无界缓存、连接不归还、无限流。
- `py-spy top` / `docker stats` 画面一闪。

## 镜头3：优化后（1:30–2:30）
- 切到优化服务 `uvicorn src.api:app --port 8017`，重跑同样 20 并发压测。
- Grafana 对比：延迟平稳、`rag_process_rss_mb` 曲线走平（波动 <10%）。
- 旁白：“单例+连接池+有界缓存+异步队列+并发限流，泄漏消除，延迟反降。”

## 镜头4：数据结论（2:30–3:30）
- 展示 `docs/screenshots/01~04` 四张图：
  - 延迟对比（优化后更低）、吞吐对比（+26%）、内存曲线（泄漏消除）、指标汇总表。
- 达标结论：P95 ≤ 3s、内存波动 ≤10%、无失败。

## 镜头5：运维能力（3:30–4:00）
- 展示 `/metrics` 输出、Prometheus 抓取、Grafana 面板与告警阈值。
- 结束页：工单十七四项任务全部达标。

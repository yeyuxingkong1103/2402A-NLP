# RAG 基于 PDF 文档的问答系统 · 用户手册

> 面向日常使用者，介绍如何启动系统、提问、查看依据与反馈。

---

## 1. 功能简介

本系统基于《招股说明书1.pdf》构建了一个智能问答助手，您可以用**自然语言提问**，系统会先从 PDF 中检索相关信息，再**严格依据文档内容**给出带来源页码的回答。提供以下能力：

- 📝 **文字提问**
- 🎤 **语音提问**（上传音频自动转文字，可选）
- 📚 **答案依据查看**（来源页码 + 相似片段）
- 👍👎 **满意度反馈**
- ⏱️ **响应耗时指标**（检测是否满足 ≤ 3 秒）

---

## 2. 环境准备

### 2.1 前置条件
- 已安装 `langchain2` Conda 环境（Python 3.10）
- 已启动 **Ollama** 服务（`http://localhost:11434`）
- 已拉取模型：
  - `deepseek-r1:1.5b`（生成模型）
  - `bge-m3:567m`（向量模型）

```powershell
# 确认 Ollama 已启动且可访问
curl http://localhost:11434/api/tags
```

### 2.2 安装依赖（首次）
```powershell
conda activate langchain2
pip install -r requirements.txt
```

### 2.3 （可选）语音转文字
```powershell
pip install openai-whisper
```
不安装也不影响使用，语音功能会自动隐藏/提示。

---

## 3. 启动系统

在项目根目录（`工单一`）执行：
```powershell
conda activate langchain2
streamlit run app.py
```
浏览器自动打开 `http://localhost:8501`。首次加载会构建/加载知识库，稍候片刻。

> **提示**：若尚未构建向量库，系统会自动构建；如需一键重建请先在 `scripts/build_kb.py` 目录执行：
> ```powershell
> python scripts/build_kb.py --force
> ```

## 4. 使用步骤

### 4.1 文字提问
1. 在页面顶部输入框输入问题，例如：
   - “报告期内，公司来自军用领域的收入分别是多少？”
   - “公司法定代表人和注册资本是多少？”
   - “本次发行募集资金计划如何使用？”
2. 选择回答模式（侧边栏）：**RAG 检索增强** 或 **纯 LLM 对比**。
3. 点击 **🔍 提问**，等待回答。

### 4.2 语音提问（可选）
1. 展开 **🎤 语音提问** 区域；
2. 上传一段音频（wav / mp3 / ogg 等）；
3. 点击 **转文字**，识别结果会自动填入问题框；
4. 再点击 **提问**。

### 4.3 查看回答依据（仅 RAG 模式）
- 回答下方会显示 **响应耗时** 与是否达标（≤ 3s）。
- 展开 **📚 检索依据**，可查看每条依据的来源**页码**与相似度分数。
- 页面底部给出 **关键数据来源页码** 汇总，方便回溯原文。

### 4.4 反馈
- 对回答点击 **👍 有帮助** 或 **👎 没帮助**，可附加文字说明；
- 反馈保存在 `output/feedback.csv`，可在侧边栏下载查看。

## 5. 常见问题（FAQ）

**Q1：回答提示“根据招股说明书内容无法回答”？**
说明检索到的文档片段确实不含所需信息，这是系统防止编造的机制。可尝试换一种问法或补全公司名/年份等关键信息。

**Q2：首次提问较慢？**
首次需加载知识库与模型。之后提问会明显加快。

**Q3：语音转文字报错？**
确认已安装 `openai-whisper`，且音频格式受支持。

**Q4：想调整检索更准/更快？**
在项目根目录复制 `.env.example` 为 `.env`，调整 `TOP_K`（片段数）、`LLM_MAX_TOKENS`（生成长度）等参数后重启应用。

## 6. 故障排查

| 现象 | 处理 |
|---|---|
| 打不开页面 | 确认 `streamlit` 已装、命令在项目根目录执行 |
| 报连接 `localhost:11434` 失败 | 确认 Ollama 服务已启动 |
| 知识库加载失败 | 执行 `python scripts/build_kb.py --force` 重建 |
| 页面卡在“加载问答引擎” | 等待模型预热；或重启后重试 |

# 工单10 测试

## 容器内验证

```bash
# 1. 进入容器
docker exec -it financial-rag-qa /bin/bash

# 2. 运行验证脚本
python /app/test_deploy.py

# 3. 手动验证
curl http://localhost:5008/api/health
curl -X POST http://localhost:5008/api/ask \
    -H "Content-Type: application/json" \
    -d '{"question":"武汉力源的控股股东是谁?"}'

# 4. 检查卷
docker run --rm -v rag_data:/data alpine ls /data
docker run --rm -v rag_cache:/data alpine ls /data
```

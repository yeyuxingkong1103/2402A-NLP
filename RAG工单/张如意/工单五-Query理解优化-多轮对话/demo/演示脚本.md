## 三、解说要点速记卡（录制时放屏幕边角）

1. **一句话卖点**：多轮对话的难点不在生成，而在「把省略和指代补全成能检索的问题」。
2. **四种能力**：指代消解（第 2 轮）、指代消解 + 话题继承（第 3 轮）、省略句补全 + 主体切换（第 4 轮）、主体延续 + 跨文档（第 5 轮）。
3. **两级设计**：规则快速通道（高频句式，零 LLM 调用）→ LLM 慢通道（自由指代）；规则命中的第 4 轮**微秒级**完成改写，是 3 秒约束的关键。
4. **跨文档**：第 4/5 轮命中《招股说明书2》，靠的是消解后检索式里显式携带公司全称。
5. **可视化**：右侧面板展示「原始问题 → 改写后检索式」，让「系统理解了什么」可见。
6. **可验证**：消融实验证明增益来自 Query 理解；单测断言保证改写逻辑可回归。

## 四、常见演示意外与处置

| 意外 | 处置 |
|------|------|
| 某轮响应慢（网络抖动） | 说明「首次调用受网络影响」，重放一次（缓存命中会很快）；或改用 `--fast` |
| 无 API Key | 第 2/3 轮退化为原问题：明确说明「离线降级行为」，并改为重点演示第 4 轮规则通道 |
| 界面端口被占用 | `python chat_ui.py --port 7861` |
| 终端中文乱码 | 先执行 `chcp 65001` |
| 答案里数字与文档不一致 | 现场打开 PDF 对照页码复核，强调系统标注了来源（不做无依据的辩解） |

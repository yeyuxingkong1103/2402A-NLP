# PDF 文档表格解析及检索优化说明报告

## 1. 项目目标

工单 03 要求在已有 PDF-RAG 问答系统基础上，进一步优化 PDF 表格解析和检索能力，使系统能够针对表格中的财务数据、业务数据、比例和年度对比问题进行准确回答。

## 2. 技术栈

- 页面框架：Streamlit
- RAG 框架：LangChain
- PDF 解析：MinerU
- 向量数据库：FAISS
- 检索策略：文本/表格双索引 + MMR 检索
- Embedding：通义 DashScope `text-embedding-v4`
- LLM：通义千问 `qwen-plus`

## 3. 表格解析优化

系统通过 MinerU 解析 PDF，并启用表格识别能力。MinerU 输出 Markdown 后，程序会自动识别 Markdown 表格行，将连续表格内容抽取为独立表格片段。

表格片段会添加元数据：

- `type: table`
- `table_id`
- `source`

这样在检索依据中可以清楚区分文本依据和表格依据。

## 4. 检索优化

系统构建两个 FAISS 索引：

1. 文本索引：保存普通章节文本。
2. 表格索引：保存表格片段。

当问题包含“表、金额、收入、利润、比例、年度、报告期、万元、亿元”等关键词时，系统会优先检索表格索引，再合并文本索引结果。这样可以提高表格类问题的召回率。

## 5. Prompt 优化

提示词要求模型：

- 严格依据参考资料回答；
- 涉及表格、金额、比例、年份时优先使用表格依据；
- 保留原文单位和数值；
- 资料不足时说明未找到明确依据；
- 不得编造。

## 6. 批量评测

批量问答会输出：

- 问题 ID；
- 问题正文；
- 模型答案；
- 检索依据；
- 依据类型：文本或表格。

输出文件为 `table_optimized_answers.json`。

## 7. 完成情况

本项目已完成 PDF 自动分批解析、Markdown 缓存、表格抽取、文本/表格双索引、表格优先检索、单问题问答、批量问答和答案导出，满足工单 03 的表格解析及检索优化要求。

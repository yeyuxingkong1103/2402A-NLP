## 1. 技术组件

| 组件 | 选型 | 作用 |
|------|------|------|
| 基座 VLM | Qwen2-VL-2B-Instruct | 支持图文输入的多模态生成模型 |
| 微调方法 | LoRA（peft） | 低秩适配，仅训练 0.83% 参数 |
| 训练框架 | transformers + accelerate | Trainer 训练循环、混合精度 |
| 数据格式 | JSONL（image/question/answer） | SFT 监督微调样本 |
| 评估 | 自研 BLEU/ROUGE/术语/图纸指标 | 专业领域评估 |
| 渲染 | PyMuPDF → PNG | 专利页面转图像 |

## 2. 数据格式（接口契约）

`data/train.jsonl` / `data/eval.jsonl` 每行一条：

```json
{
  "question": "在图3中，编号14的部件位于装置的哪个位置？",
  "answer": "顶部",
  "document": "CN100347506C",
  "group": "选择题",
  "is_image": true,
  "image": "CN100347506C/page_11.png"
}
```

字段说明：
- `image`：相对 `data/images/` 的页面图路径；纯文本题为 `null`/缺省。
- `answer`：已将选项字母展开为完整选项文本，便于生成式训练与评估。

## 3. 微调超参（configs/lora_sft.yaml）

| 参数 | 值 |
|------|-----|
| LoRA r / alpha / dropout | 16 / 32 / 0.05 |
| target_modules | q,k,v,o,gate,up,down_proj |
| learning_rate | 1e-4 |
| epochs | 3 |
| batch_size | 1，grad_accum=4 |
| 精度 | fp16 + gradient_checkpointing |
| 图像边长上限 | 384px（控显存/内存） |

## 4. 核心模块接口

### 4.1 微调 `src/finetune.py`

```
python src/finetune.py --epochs N --lr 1e-4 --batch-size 1 --grad-accum 4 [--no-4bit]
```

- 输出：`finetune_output/lora_adapter/`（LoRA 权重）、`finetune_output/train_history.json`（loss 曲线）。

关键类/函数：
- `VlmSFTDataset`：读取 JSONL → 构造 chat 消息 → processor 编码（含 pixel_values/image_grid_thw/mm_token_type_ids）。
- `make_collator`：自定义批处理（tokenizer 补齐文本 + 透传视觉张量）。
- `build_model` / `build_lora`：加载基座 + 挂载 LoRA（冻结视觉塔）。

### 4.2 评估 `src/evaluate.py`

```
python src/evaluate.py --max-eval 18
```

- 指标：`avg_bleu`、`avg_rouge_l`、`exact_acc`、`industry_term_acc`（术语准确性）、`image_exact_acc`（图纸推理命中率）、`latency_per_q_ms`。
- 输出：`docs/screenshots/eval_baseline.json`、`eval_finetuned.json`。

## 5. 关键技术点

1. **多模态张量对齐**：Qwen2-VL processor 同时返回 `pixel_values / image_grid_thw / mm_token_type_ids`，三者必须一同传入模型，否则 M-RoPE 计算报错。
2. **自定义 collator**：`DataCollatorForSeq2Seq` 依赖 tokenizer.pad，而 processor 无 pad 方法；故自行用 tokenizer 补齐文本、cat 视觉张量。
3. **显存/内存控制**：冻结视觉塔、gradient checkpointing、限制图像边长、batch=1，使 8GB 显卡可跑通。

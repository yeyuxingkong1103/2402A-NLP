# 测试材料

本目录用于放置测试截图和测试说明。

建议至少放入以下截图：

1. API 服务启动成功与 `/health` 返回结果；
2. Swagger `/docs` 接口页面；
3. 文档上传或知识库构建结果；
4. 标准问答结果及来源引用；
5. 流式问答效果；
6. 多轮会话或会话历史；
7. 自动化测试执行结果。

截图文件可按以下格式命名：

```text
01-服务启动.png
02-接口文档.png
03-文档上传.png
04-问答效果.png
05-流式输出.png
06-多轮会话.png
07-自动化测试.png
```

测试截图由项目提交人补充，本次整理不生成或伪造测试截图。

# 工单18 实现文档质量评估Skill并集成至智能体工作流｜优化文档
##1.原始痛点
知识库入库前缺少自动化文档质检；大量扫描PDF、重复文档、带敏感信息文档流入，直接导致RAG解析质量差。
1. PDF无法自动区分扫描件/原生文本件，全部使用同一解析器；扫描PDF直接文本提取得到空；
2. 重复、近似版本文档大量入库，向量库冗余；
3. 文档混杂手机号身份证等敏感数据，没有提前发现；
4. 缺少自动化标签，全部文档使用相同解析策略，表格/图纸文档解析效果差。

##2.优化方案
### Skill功能优化
1. PDF识别：全部阈值可配置；扫描页占比判定，输出待确认清单，不完全自动下定论；
2. 重复检测两层策略：MD5精确完全重复；SimHash近似相似度检测，疑似放入待确认人工复核；
3. 敏感检测：命中结果附带原文上下文，方便人工审核；银行卡检测可开关，默认关闭降低误报；
4. 输出结构化报告：统计指标 + 多份待确认/待审核清单 + 每文档分类标签。

### 工作流优化
`document_ingestion_workflow`：调用Skill拿到标签，**路由分发不同解析流水线**
- Clean_Markdown：直接分块入库；
- Scan_PDF：提交OCR解析任务；
- Table_Heavy：表格专用解析；
- Image_Heavy：多模态图纸解析；
- Parse_Failed：标记，人工复核。

### API层
新增对外质检API，外部系统可以调用完成文档质检。

##3.性能优化方向
1. 大批量文档处理：增加进度回调，支持中断恢复；
2. IO并发优化：多线程遍历文档，控制并发数；
3. SimHash计算缓存，避免重复计算；

##4.后续进阶优化
1. 增加更多文档质量维度：乱码检测、损坏文件检测；
2. 敏感检测接入轻量模型，降低正则误报；
3. Skill标准化封装，可以直接导入Cursor/Trae Claude Skill体系；
4. 报告增加可视化图表输出。

# 工单14 修复低质量工业PDF的解析与信息丢失｜优化文档
## 1.原始问题现象
CN100342976C.pdf属于图片扫描型工业专利PDF；使用默认pdf_parser解析，图纸页面没有可复制文本，图纸部件编号、尺寸标记全部丢失；涉及图纸的Q3‑Q6全部回答错误。

## 2.根因定位
1. 解析器选择错误：普通pdf_parser只读取PDF内置可复制文本，扫描图片PDF没有文本流，解析得到空。
2. 未启用OCR识别流水线，图纸图片内部文字、标号无法提取。
3. 布局识别缺陷：图纸图片与配套说明文本分割，分块时分到不同切片，问答上下文图文割裂。
4. OCR对低分辨率图纸小字识别存在乱码；部件标号 `6'` `6''`识别错误。
5. 检索阶段未开启rerank，召回切片存在噪声，优先匹配无关文本。

##3.分层优化方案
### 解析层优化（最重要）
1. 解析方案选择：Paper模式，底层启用`paddleocr_parser.py`OCR解析流水线，逐页识别PDF图片。
2. OCR预处理：图片放大缩放，提升图纸小字识别；开启OCR后处理纠错，修复标号乱码字符。
3. Layout布局识别：开启图文绑定策略，图纸图片块和紧邻的说明文本合并，避免图文分离。

### 分块策略优化
1. chunk_size调大适配专利长文本；增大chunk_overlap；
2. Paper模式：禁止把一张图纸和它的说明文本切分到不同块。

### 检索层优化
1. 调高top‑k召回数量，保证图纸相关片段被召回；
2. 开启Rerank重排序模型，过滤噪声切片，提升图文相关片段优先级。

### 预处理兜底（本地脚本）
使用`pdf_ocr_fix.py`做本地前置OCR，生成带可编辑文本的PDF文件，再上传RAGFlow，降低在线OCR压力。

##4.优化前后对比
|优化项|优化前|优化后|
|---|---|---|
|PDF解析器|pdf_parser（原生文本）|paddleocr_parser OCR扫描解析|
|图纸信息|图纸部件、尺寸全部丢失|图纸部件编号、尺寸全部识别提取|
|图文关系|图纸与说明文本切片割裂|图纸和相邻说明文本合并到同一个切片|
|检索策略|关闭rerank，top‑k默认值|开启rerank，调高top‑k|
|测试通过率|Q3‑Q6全部错误|6条测试用例全部正确|

##5.后续进阶优化方向
1. 针对机械图纸做OCR专项字典，把部件编号、图纸符号加入词典，减少识别错误；
2. 优化figure_parser图纸解析，结构化输出部件‑位置‑尺寸；
3. 多模态RAG：直接传入图片给多模态大模型，不依赖OCR文字识别；
4. 对IMDR数据集大批量PDF做批量预处理流水线。

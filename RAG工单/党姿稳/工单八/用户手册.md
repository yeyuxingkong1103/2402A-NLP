# 用户手册：金融年报 Graph RAG 问答系统

**工单编号：** 人工智能NLP-RAG-基于Graph RAG实现金融问答

## 1. 启动系统

```bash
python app_streamlit.py
```

终端会打印访问地址（如 `http://localhost:8501`，8501 被占用时自动顺延到 8502、8503…），
在浏览器中打开该地址即可。

## 2. 界面说明

界面分为两个标签页：

- **💬 问答（文字/语音）**：提问并查看答案、答案所在的文本块、解析出的图谱结构；
- **🕸️ 知识图谱**：查看从全部年报中解析出的全局知识图谱（实体 + 关系）。

左侧边栏可调整：

| 控件 | 作用 |
|---|---|
| 返回文本块 Top-K | 返回多少个文本块作为答案依据 |
| 图谱扩展跳数 | 沿图谱关系向外扩展的层数（0=只用直接命中的实体） |
| 图谱权重 | 图谱定位结果与向量/全文检索结果的融合权重 |
| 验收问题 | `eval_question.md` 中的 10 个 Question，点击“快捷选择”可直接填入 |

## 3. 如何提问

### 3.1 文字提问
1. 在「输入方式」中选择 **文字**；
2. 在输入框中输入问题（支持中文和英文），例如
   `平安银行的拨备覆盖率是多少？`
3. 点击 **🚀 检索并回答**。

### 3.2 语音提问
1. 在「输入方式」中选择 **语音**；
2. 点击 🎤 录音按钮，说出的问题（如"中国太保的新业务价值是多少"），再次点击停止；
3. 系统自动转写为文字（识别结果会显示在下方），随后点击 **🚀 检索并回答**；
4. 若识别失败（无网络或未安装 `SpeechRecognition`），界面上会提示，请改用文字输入。

## 4. 如何查看结果

点击检索后，界面依次展示：

1. **答案**：由 DeepSeek 依据检索到的文本块生成，答案只使用资料中的信息；
2. **📚 答案所在的文本块**：每个块显示所属年报、页码、融合分数、来源（图谱 / 混合 / 向量全文）。
   点击可展开块内原文；
3. **🔗 解析出的知识图谱结构（命中子图）**：两张表分别列出本轮命中的**实体**（含类型）
   与**关系**（头实体-关系-尾实体），下方为交互式子图（可拖拽、缩放、悬停查看关系）。

## 5. 如何查看知识图谱可视化

切换到 **🕸️ 知识图谱** 标签页：

- 上方为静态图谱图片（`data/knowledge_graph.png`）：节点颜色表示实体类型，
  **红=公司、蓝=指标、绿=数值、紫=人物、橙=职位、青=策略/领域**，公司节点更大；
- 下方为交互式图谱（`data/knowledge_graph.html`）：支持鼠标拖拽节点、滚轮缩放、悬停查看关系名；
- 点击 **🔄 重新渲染图谱** 可依据最新的 `data/graph.json` 重新出图。

若提示“请先运行 graph_builder.py 与 graph_viz.py”，说明图谱尚未构建，请先执行：

```bash
python graph_builder.py
python graph_viz.py
```

## 6. 常见问题

| 现象 | 处理方式 |
|---|---|
| 页面提示端口被占用 | 系统会自动选择空闲端口，以终端打印的地址为准 |
| 首次提问很慢 | 需加载嵌入模型与构建索引，等待一次即可 |
| 语音按钮不可用 | 当前 Streamlit 版本过低（需 ≥1.39），请升级或改用文字输入 |
| 图谱为空或很少 | 运行 `python graph_builder.py` 重新抽取（需可访问 LLM API） |
| 想换成自己的 PDF | 把 PDF 放入 `附件/ccf_competition/pdf`，删除 `data/chunks.json` 后重新运行 `ccf_parser.py` |

## 7. 演示建议流程

1. 打开系统，进入「🕸️ 知识图谱」展示全局图谱与实体类型图例；
2. 回到「💬 问答」，依次提问 `eval_question.md` 中的 10 个 Question，
   展示每题返回的文本块（页码/来源/分数）与命中的实体、关系子图；
3. 演示语音提问一次（如"平安银行的不良贷款率是多少"）；
4. 展示 `evaluation/` 下的评估报告，说明与工单七（无图谱混合检索）的指标对比。

# 部署文档｜招股说明书RAG智能问答系统
## 1. 部署环境准备
### 环境
WSL Ubuntu24.04 / Linux系统
Python >=3.10
Docker（用于部署Milvus向量数据库）

### 1.1 Milvus部署（Docker）
拉取并启动Milvus单机版，默认端口19530，确保Milvus正常运行。
验证Milvus连通：端口19530可访问。

### 1.2 Python虚拟环境准备
```bash
# 创建虚拟环境
python3 -m venv venv_gongdan1
# 激活环境
source venv_gongdan1/bin/activate
# 安装依赖包
pip install flask pymilvus pymupdf numpy openai
## 2. 项目部署步骤

1. 上传全部项目代码到服务器 WSL 目录
2. 激活虚拟环境
3. 启动 Milvus 服务
4. 创建 Milvus 向量集合
python3 create_collection.py
生成模拟招股说明书 PDF 文档
python3 gen_pdf.py
PDF 文档预处理，向量入库
python3 pdf_loader.py
启动 Flask Web 服务
python3 main.py
8. 访问：浏览器打开 `http://服务器IP:7860` 进行问答

## 3. 访问说明

- WSL 内 IP：`172.17.189.52`
- 端口：7860，防火墙放行 7860 端口

## 4. 服务启停

启动：`python3 main.py`
停止：`Ctrl + C`

## 5. 故障排查

1. 无法访问网页：检查 WSL IP，确认 Flask 启动参数 host=0.0.0.0，防火墙放行端口
2. Milvus 连接失败：确认 Milvus docker 容器正常运行，端口 19530 开放
3. 大模型无返回：检查 DeepSeek API 密钥有效性
4. PDF 读取失败：确认`招股说明书.pdf`在项目根目录

## 6. 生产部署说明（本项目为实训工单演示）

生产环境建议使用 Gunicorn 作为 WSGI 服务，搭配 Nginx 反向代理，Milvus 使用集群部署，增加日志采集、接口鉴权。

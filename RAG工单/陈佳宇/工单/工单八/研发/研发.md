# 工单8 基于Graph‑RAG实现金融问答任务｜研发文档
工单编号：人工智能NLP‑RAG‑基于Graph RAG实现金融问答

## 1.开发环境
复用之前创建的虚拟环境`venv_gongdan5`，无需新建虚拟环境。
新增依赖安装：
```bash
pip install networkx pyvis
- `networkx`：内存图数据结构，存储实体、关系三元组。
- `pyvis`：生成交互式知识图谱可视化 HTML 页面。

## 2. 文件说明

1. **pdf_loader.py**
内置模拟金融研报文本，不需要外部 PDF 文件。将长文本按换行分割，过滤长度小于 15 的文本，返回文本块列表。
2. **graph_builder.py**
知识图谱封装类`GraphBuilder`：

- 内部维护`nx.DiGraph()`有向图实例。
- `add_triple()`添加头实体‑关系‑尾实体三元组。
- `build_visual_html()`导出 pyvis 可视化网页。
- `get_graph_info()`获取节点、边统计数量。

3. **main.py**
主程序入口，包含：

- eval_questions 测试问题集合，共 10 条测试用例。
- `build_knowledge_graph_from_text()`：批量添加预置三元组，构建完整知识图谱。
- `graph_retrieve()`检索函数：实现 Graph‑RAG 核心检索逻辑，同时返回图谱三元组和原文片段。
- Flask 网页、接口实现，前端页面提供问答交互。
- 程序启动自动批量运行 10 条 eval 测试用例，终端输出评测结果。

## 3. 开发流程

1. 开发 pdf_loader 模块，加载模拟金融文档文本，输出文本块。
2. 开发 graph_builder 模块，测试添加三元组，验证可视化 HTML 可以正常生成打开。
3. 在 main.py 预置业务三元组，完成知识图谱构建。
4. 实现 graph_retrieve 检索函数，完成图谱 + 原文双路召回。
5. 编写 Flask 前端页面与后端接口，实现网页问答交互。
6. 编写 eval_questions 测试集，实现启动自动批量评测。
7. 调试修复实体匹配、中文关键词匹配 bug，保证问答正常返回结果。

## 4. 开发遇到的问题与解决

1. networkx `edges(data=True)`遍历错误：遍历顺序错误，把字典赋值给实体变量，触发类型报错。修复：正确接收`h,t,edge_data`三个返回值。
2. 中文关键词匹配失效：直接按空格 split 分词，中文句子无空格，无法命中文本。修复：改为字符重叠匹配，不做分词。
3. 网页提交后数据无返回：JS 转义、前后端数据传输调试。
4. 端口冲突：工单 6、7 使用 7860，本项目修改为 7861 端口，避免冲突。

## 3. 别名归并规则（三级）

```
原始名
 │ ① normalize_name()                                   ← 纯字符串层，不做语义判断
 │    · 去首尾空白；连续空白压缩为空（re.sub(r"\s+", "")）
 │    · 全角括号 → 半角：（ ）【 】〔 〕 → ( ) [ ] [ ]
 │    · 去首尾标点：，,。.、；;：:　"'“”‘’《》
 │    · 去尾部「等」「等等」（仅当剩余长度 > 后缀长度 + 1）
 ▼
 │ ② resolve_alias()                                     ← 指代性归并，查表
 │    · 直接命中 PRONOUN_ALIASES（18 条）→ 返回 canonical
 │      例：本公司/公司/股份公司 → 发行人 ；力源信息/力源有限 → 武汉力源信息技术股份有限公司
 │    · 剥离前缀「本公司/贵公司/该公司」后再查表
 │    · 名字以「公司」结尾时，去掉「公司」再查表
 │      例：赵马克 / Mark Zhao → 赵马克(Mark Zhao)
 ▼
 │ ③ char_similarity() ≥ alias_similarity(0.82)          ← 二次归并，容错
 │    · 字符 bigram Dice 系数：2·|A∩B| / (|A|+|B|)
 │    · 名字长度 ≥ alias_min_len(3) 才参与，长度 < 2 直接返回 0（避免「元」「股」误并）
 ▼
规范名 → 图谱节点唯一键
```

**辅助规则**

| 规则 | 说明 | 配置项 |
| --- | --- | --- |
| 归并阈值 | 字符级 Dice ≥ 0.82 判为同一实体 | `graph.alias_similarity = 0.82` |
| 最短参与长度 | 参与归并的名字至少 3 字符 | `graph.alias_min_len = 3` |
| 关系去重 | 同 (head, rel, tail) 合并，置信度累积 | `graph.merge_relation_duplicates = true` |
| 关系过滤 | 置信度低于阈值的边丢弃（默认 0 = 不过滤） | `graph.relation_min_confidence = 0.0` |
| 兜底判类 | 无 LLM 时用启发式猜类型（正则识别日期/比例/金额，后缀识别公司/指标） | `guess_entity_type()` |
| 类型吸附 | LLM 返回非法类型名时吸附到最接近的合法类型 | `coerce_type()`（含 40+ 条同义词映射） |

## 4. 与验收标准 1 的对应关系

工单验收标准 1 要求「**根据 pdf 中的内容**，优化图谱构建中的实体、关系，抽取出准确的实体类型和关系类型」。本设计据此把「准确」拆成四条可核验判据：

| 判据 | 核验方式 | 达标线 |
| --- | --- | --- |
| 类型封闭 | 抽取产物的 `type` 字段必须 ∈ 17 类实体集 / 16 类关系集 | 非法类型数 = 0（非法项经 `coerce_type` 吸附后统计） |
| 头尾相容 | 每条关系过 `relation_allowed()` | 违规关系数 = 0 或如实记录清单 |
| 语料有据 | 每类实体/关系在语料中有实测命中（见 §1/§2 命中块数） | 17 类实体、16 类关系**均有**非零语料依据或已注明「字面 0、表达形式有据」 |
| 别名收敛 | 同一主体在产物中只占 1 个节点 | 归并后节点数 < 归并前节点数，且差额可列示 |

## 5. 抽取提示词构造

类型清单与样例由代码生成，不手写：

- `schema_prompt_block()` → 拼出【实体类型（只能从中选）】+【关系类型（只能从中选）】两段封闭集说明；
- `all_entity_types()` / `all_relation_types()` → 供校验与统计；
- `iter_examples()` → 供文档与提示词复用的 (类型, 说明) 迭代。

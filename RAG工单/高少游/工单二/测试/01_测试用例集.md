# 测试用例集

> **工单编号**：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化
> **被测对象**：优化后 RAG 问答链路（`QAEngine.answer_optimized`）与基线链路（`QAEngine.answer_baseline`）

## 二、性能测试用例

| 用例编号 | 测试项 | 方法 | 通过标准 |
|---|---|---|---|
| PT-01 | 平均响应时间 | `scripts/evaluate.py` 统计 10 题端到端耗时 | ≤ 3 s |
| PT-02 | 最大响应时间 | 同上取 max | ≤ 3 s |
| PT-03 | 检索 Top-1 命中率 | `_rank_metrics` 统计 | 优于基线 |
| PT-04 | 检索 MRR | 同上 | 优于基线 |
| PT-05 | 答案准确率 | `KEY_TOKENS` 命中统计 | ≥ 90% |

> 为避免把模型冷启动计入耗时，评估脚本默认先预热（加载向量库与 embedding 模型），可用 `--no-warmup` 关闭。

## 三、稳定性与容错测试用例

| 用例编号 | 场景 | 输入 | 期望结果 |
|---|---|---|---|
| ST-01 | 空问题 | `""` | 返回兜底提示，不报错 |
| ST-02 | 与文档无关的问题 | "今天天气怎么样？" | 输出"根据招股说明书内容无法回答"，不编造 |
| ST-03 | 超长问题 | 500 字长文本 | 正常返回，不崩溃 |
| ST-04 | 英文提问 | "What is the registered capital?" | 走同一链路并返回结果 |
| ST-05 | 特殊字符 | "注册资本？？？！！！" | 正常解析与回答 |
| ST-06 | 向量库缺失 | 删除 `vector_db/optimized` | 首次访问自动构建 |
| ST-07 | Ollama 未启动 | 停止 Ollama 后提问 | 基线链路返回"（回答失败：…）"提示，优化链路（抽取式）仍可用 |
| ST-08 | 中文路径 | 项目位于含中文的路径 | FAISS 读写正常（临时 ASCII 目录桥接） |
| ST-09 | 长时运行 | 连续 50 次提问 | 耗时稳定，无内存泄漏式增长 |

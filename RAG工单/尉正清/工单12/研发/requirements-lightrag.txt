# 工单编号：人工智能NLP-RAG项目-LightRAG优化
# LightRAG 那一路的依赖 —— 装在**独立环境 rag_gd1** 里
#
# ⚠️ 为什么必须独立环境（详见 优化/过程问题记录.md 问题 2）：
#   这些包会把 huggingface-hub 升到 2.x，而 RAG 基座那个环境 rag_gd 里的
#   FlagEmbedding 1.3.3 硬锁 transformers==4.44.2 / datasets==2.19.0，
#   gradio 4.44.1 又要求 huggingface-hub<1.0 —— 装到一起整条链路全废。
#
# 安装步骤：
#   1) conda create -n rag_gd1 python=3.11 -y && conda activate rag_gd1
#   2) pip install -r requirements-lightrag.txt
#   3) pip install "langchain-community<0.4"      ← 必须，见下
#   4) pip install torch --index-url https://download.pytorch.org/whl/cu126
#
# 或直接执行：bash 部署/install.sh

# ---------- 知识图谱 ----------
lightrag-hku==1.5.7

# ---------- RAGAS 评估 ----------
ragas==0.4.3

#    详见 优化/过程问题记录.md 问题 3。
langchain-community==0.3.31

# ---------- 数值 / 网络 ----------

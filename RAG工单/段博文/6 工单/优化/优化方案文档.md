# 混合检索优化方案文档

> 工单编号：人工智能NLP-RAG-混合检索任务

## 一、优化目标

| 指标 | 目标 | 说明 |
|------|------|------|
| 准确率 | ≥90% | 答案关键词命中率 |
| 召回率 | ≥95% | 检索结果包含期望关键词 |
| 响应时间 | ≤3秒 | 从提问到返回答案 |
| 多语言 | 中英文 | 支持中文和英文问答 |
| 交互 | 多轮对话 | 支持会话历史与指代消解 |

## 二、核心优化点

### 1. 三种检索策略可配置

```
vector    向量检索（bge-m3 嵌入 + Milvus 余弦召回 + 重排）
fulltext  全文检索（倒排索引 BM25 + 多字段加权 + 查询语法）
hybrid    混合检索（向量+全文并行召回 → 融合 → 重排）
```

### 2. 全文检索查询语法

| 语法 | 示例 | 说明 |
|------|------|------|
| 布尔 AND | `武汉 AND 兴图` | 两个词必须同时命中 |
| 布尔 OR | `兴图 OR 力源` | 命中任意一个词 |
| 布尔 NOT | `兴图 NOT 力源` | 排除包含"力源"的文档 |
| 短语匹配 | `"法定代表人"` | 精确子串匹配 |
| 模糊匹配 | `兴图~` | 允许编辑距离≤1 |
| 多字段 | 自动 | title（文档名）/ content（正文）/ type（块类型）加权 |

### 3. 三种重排算法

| 算法 | 原理 | 特点 |
|------|------|------|
| CrossEncoder | bge-reranker-large 交叉编码器 | 精度最高，CPU 约 5s/次 |
| TF-IDF | 词频-逆文档频率余弦相似度 | 轻量，零推理成本 |
| LLM | DeepSeek 批量打分 0-10 | 语义理解最强，可控成本 |

### 4. 三种融合算法

| 算法 | 原理 | 公式 |
|------|------|------|
| RRF | 倒数排名融合 | score = Σ 1/(rank + k) |
| Weighted | 归一化加权平均 | score = w_v·norm(v) + w_f·norm(f) |
| Voting | Borda 计数投票 | 第 i 名得 N-i 票 |

### 5. 运行时配置热更新

- `GET /api/retrieve_config` 查看当前配置
- `POST /api/retrieve_config` 动态修改（立即生效，无需重启）
- 前端配置面板：策略/融合/重排/权重 可视化调节

## 三、架构设计

```
用户 Query
    ↓
Query 改写（多轮指代消解）
    ↓
策略选择（vector / fulltext / hybrid）
    ↓                    ↓
向量召回              全文召回
bge-m3 + Milvus      BM25 倒排索引
余弦相似度           多字段加权+语法
    ↓                    ↓
    └──→ 结果融合 ←──┘
         RRF / Weighted / Voting
              ↓
         重排
    CrossEncoder / TF-IDF / LLM
              ↓
         Top-K → LLM 生成答案
```

## 四、性能优化

| 优化项 | 效果 |
|--------|------|
| LRU 检索缓存 | 重复查询毫秒级返回 |
| 配置变更自动清缓存 | 避免旧策略结果污染 |
| 多字段 BM25 | 标题命中权重 ×3，提升文档级检索精度 |
| 布尔过滤前置 | 减少无效候选进入重排 |
| LLM 重排限流 | 仅对前 N 条候选打分，控制成本 |

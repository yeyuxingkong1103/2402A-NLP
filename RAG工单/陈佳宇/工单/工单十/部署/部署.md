# 工单10 金融问答系统部署｜部署文档
工单编号：人工智能NLP‑RAG 项目‑金融问答系统部署

## 1.环境信息
- 操作系统：Windows10，WSL Ubuntu24.04
- Docker版本：Docker Desktop
- 业务端口：7862
- 镜像名称：graphrag‑finance:v1
- 容器名称：finance‑qa‑service

## 2.项目文件准备
进入工单10/研发目录，确认具备如下文件：
- main.py、graph_builder.py、pdf_loader.py、eval_ragas.py
- Dockerfile、.dockerignore、requirements.txt

## 3.部署步骤
### 步骤1：进入项目目录
```bash
cd /mnt/c/Users/陈/Desktop/工单10/研发
步骤 2：构建 Docker 镜像
docker build -t graphrag-finance:v1 .
> 注意末尾小数点`.`，代表以当前目录作为构建上下文。

### 步骤 3：启动容器（端口映射 + Volume 数据卷持久化）
docker run -d \
--name finance-qa-service \
-p 7862:7862 \
-v $(pwd)/data_output:/app/data_output \
graphrag-finance:v1
参数说明：

- `-d`：后台守护进程运行容器
- `‑‑name finance‑qa‑service`：设置容器名字
- `-p 7862:7862`：宿主机 7862 端口映射容器内部 7862 端口
- `-v $(pwd)/data_output:/app/data_output`：数据卷挂载，容器输出图谱文件持久化保存到宿主机。

### 步骤 4：确认容器运行状态
docker ps
看到容器 STATUS 状态为 Up 即为启动成功。

### 步骤 5：查看容器运行日志
### 步骤 6：访问 Web 问答服务

浏览器访问：`http://127.0.0.1:7862`
输入问题，测试问答功能。

### 步骤 7：验证持久化

查看本地目录`./data_output`，会自动生成`graph_visual.html`图谱可视化文件。
执行停止并删除容器命令：
docker stop finance-qa-service
docker rm finance-qa-service
> 删除容器之后，宿主机`data_output`文件夹内 html 文件仍然保留，验证持久化生效。

## 4. 日常运维命令
# 重启容器
docker restart finance-qa-service
# 进入容器内部调试
docker exec -it finance-qa-service /bin/bash
# 删除镜像
docker rmi graphrag-finance:v1
## 5. 部署注意事项

1. Docker 容器内部自带 Python 环境，**不使用 WSL 主机的 venv_gongdan5 虚拟环境**。venv_gongdan5 仅用于 WSL 本地调试代码。
2. 端口 7862 不要和其他工单端口冲突。
3. Flask 内置服务器仅实训演示，生产环境需要替换为 gunicorn 等 WSGI 服务。
4. 提交版本库，不要上传 Docker 镜像文件，只上传 Dockerfile 等配置脚本。

## 6. 故障排查

1. 网页访问打不开：优先看`docker logs`查看容器报错；确认容器 STATUS 状态是 Up。
2. data_output 没有生成 html：确认代码输出路径是`data_output/graph_visual.html`，volume 挂载命令正确。
3. 镜像构建失败：检查 requirements.txt 包名是否正确，网络是否正常下载 pip 依赖。

# 2025.9-2026.2 招股说明书 RAG 问答系统

## 一、设计

### 1.1 项目简介
本项目旨在基于《招股说明书1.pdf》构建一个 RAG 问答系统，能够针对 PDF 内容进行高效检索与问答，支持 Query 理解、向量检索、LLM 生成和 Web 交互。

### 1.2 功能需求
- PDF 解析：解析 548 页 PDF，提取文字
- Query 理解：意图识别、消歧、分解、抽象
- 检索与生成：向量检索 + 重排 + LLM 生成
- 用户体验：Streamlit 界面，输入问题、展示答案、显示引用
- 对比评估：RAG vs 纯 LLM 对比

### 1.3 技术栈
- PDF 解析：PyMuPDF
- 切分：LangChain RecursiveCharacterTextSplitter
- 嵌入：bge_m3（本地 GPU）
- 向量库：Chroma
- 重排：bge-reranker-base（本地 GPU）
- LLM：DeepSeek API
- 前端：Streamlit
- 评估：人工对比 + RAGAS（尝试）

### 1.4 系统架构
用户 → Streamlit → Query 理解 → 向量检索 → 重排 → DeepSeek 生成 → 返回答案 + 引用

## 二、研发

### 2.1 PDF 解析
- 工具：PyMuPDF
- 结果：548 页，切分 1003 个片段

### 2.2 向量库构建
- 嵌入模型：bge_m3
- 向量库：Chroma
- 写入 1003 条向量
- 解决 Chroma hnsw 索引加载失败：设置 `hnsw:sync_threshold=100000`

### 2.3 RAG 检索与生成
- 检索 Top-10 → 重排 Top-4 → 拼接 Prompt → DeepSeek 生成
- Prompt 要求只根据资料回答，不编造

### 2.4 前端
- Streamlit 单页
- 输入问题 → 同时显示 RAG 和纯 LLM 答案 → 展示引用页码

### 3.3 评估结论
- RAG 10 题中 8 题明显优于纯 LLM
- 纯 LLM 至少 4 题出现事实错误（95、33、543、207），存在明显幻觉
- RAG 每题均给出引用页码，可溯源
- RAG 严格限定 PDF 范围，不混入外部信息

### 3.4 响应时间
- 单题平均约 2-3 秒，满足 ≤ 3 秒要求

### 3.5 RAGAS 评估说明
RAGAS 0.1.15 在 Windows + 中文环境下出现 joblib 编码兼容问题，未能输出有效分数。最终以 10 题人工对比结果作为主要评估依据。

## 四、优化

- 解决 Chroma hnsw 索引加载失败：调整 sync_threshold
- 重排提升相关性：bge-reranker-base
- Prompt 限制幻觉：要求只根据资料回答
- 引用页码：可溯源

# 技术选型说明

> 工单编号: 人工智能 NLP-RAG-基于 PDF 文档的问答系统

## 一、选型原则

1. **轻量化**: 不创建新环境, 复用已有 Python 环境, 减少依赖
2. **可运行**: 所选库稳定易安装, 保证代码可直接运行
3. **简洁性**: 优先标准库与常用三方库, 避免过度工程化
4. **可演示**: 关键功能可端到端演示, 满足验收要求

## 二、核心技术清单

### 1. Web 框架: Flask
- 选择原因: 轻量、上手快、生态成熟
- 用途: 提供 HTTP 接口与页面渲染
- 版本: Flask >= 2.0

### 2. PDF 解析: pdfplumber
- 选择原因: 同时支持文本与表格提取, 对中文友好
- 用途: 解析《招股说明书1.pdf》
- 备选: PyPDF2 (纯文本场景)

### 3. 向量检索: scikit-learn (TF-IDF + 余弦相似度)
- 选择原因: 无需 GPU、无需预训练模型、即装即用
- 用途: 文本块向量化与相似度检索
- 备选: sentence-transformers (效果更好但需下载模型)

### 4. LLM 调用: OpenAI 兼容接口
- 选择原因: 通用性强, 可对接 OpenAI / 本地 Ollama / 其他兼容服务
- 用途: 答案生成与对比基线
- 配置: 通过环境变量 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL` 配置

### 5. 缓存: functools.lru_cache
- 选择原因: 标准库自带, 无需额外依赖
- 用途: 缓存常见问题答案, 优化响应时间

### 6. 数据结构: JSON / Pickle
- 用途: 持久化文本块与向量索引

## 四、环境变量配置

| 变量名        | 说明                          | 示例                          |
| ------------- | ----------------------------- | ----------------------------- |
| LLM_API_KEY   | LLM 服务 API Key              | sk-xxxx                       |
| LLM_BASE_URL  | LLM 服务地址                  | https://api.openai.com/v1     |
| LLM_MODEL     | 使用的模型名                  | gpt-3.5-turbo                 |
| PDF_PATH      | 招股说明书 PDF 路径           | ./招股说明书1.pdf              |

## 五、选型对比说明

| 维度     | 当前方案 (TF-IDF) | 备选方案 (Transformer)        |
| -------- | ----------------- | ----------------------------- |
| 安装难度 | 低                | 高 (需下载模型)               |
| 资源占用  | 低                | 高 (需内存/ GPU)              |
| 检索效果  | 中等              | 较好                          |
| 适用场景  | 演示/原型         | 生产环境                      |

考虑到工单要求"不用创建新环境, 直接生成最简单的代码", 采用 TF-IDF 方案; 在《优化》目录中提供向 Transformer 升级的说明。

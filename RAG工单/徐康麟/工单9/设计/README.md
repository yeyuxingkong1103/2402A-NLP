## 2. 建议阅读顺序

**给验收人**：
1. `验收标准.md` —— 先看达标情况与未达标根因；
2. `优化方案设计.md` §0 + §4 —— 看优化前后数字；
3. `../优化/优化方案与效果.md` —— 逐项「现象 → 根因 → 方案 → 前后数字」；
4. `../测试/测试报告.md` —— 单元测试/对比/响应时间/稳定性/容错/多语言/截图清单。

**给工程接手人**：
1. `系统架构.md` —— 模块与数据流；
2. `评估指标定义.md` —— 口径（改指标前必读，否则对比表会失去意义）；
3. `环境事实.md` §6 —— **已知踩坑清单**（能省下大量重复踩坑时间）；
4. `接口设计.md` + `../研发/README.md` —— 怎么调用与扩展。

# 用户手册

面向使用者（无需编程基础）：如何启动、提问、看结果、看图谱、生成研报与排障。

---

## 一、启动系统

```bash
# 1) 先确认本地大模型服务在跑（答案生成要用）
ollama serve                 # 若已在后台运行可跳过；用 ollama list 可查看已有模型

# 2) 启动界面
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。界面共六个页签：

`💬 问答` ｜ `📝 研报生成` ｜ `🕸 图谱可视化` ｜ `🔗 实体关系` ｜ `📈 评测结果` ｜ `⚙️ 系统状态`

**首次提问会慢一些**（约 30~60 秒）：系统要加载嵌入模型、重排模型并建好检索索引。
之后每次提问通常 **2~3 秒**。建议先打开「⚙️ 系统状态」页看一眼
图谱 / 大模型 / 检索三块是否都是绿的。

## 二、关于 PDF 文档

有两种用法，按需要选：

### 2.1 上传自己的 PDF（推荐，问答页内直接操作）

在「💬 问答」页的 **📄 上传文档（可选）** 区域：

1. 点「上传 PDF，就这份文档提问」，选择本机的 PDF（年报、研报、说明书都可以）；
2. 系统解析并建好**会话级索引**（几百页的年报约 10~20 秒，进度有提示）；
   界面上会显示「文档已就绪：《xxx.pdf》共 N 个文本块」；
3. 保持勾选「**只就上传文档《xxx》提问（不与知识图谱混答）**」，
   然后在问题框提问即可 —— 答案只依据这份文档，并标注页码。

> 上传的文档**不会**写入知识图谱与全局语料库（不影响其他问题），
> 关闭页面或换文件后即失效。扫描件/图片型 PDF（无文本层）会提示无法提取文本。
> 上传文档走与主链路相同的**混合检索（向量 + 关键词）+ Reranker 精排**，
> 实测问「邮储银行2019年末的不良贷款率和拨备覆盖率」→ 正确答出 0.86% / 389.45% 并给出页码。

### 2.2 内置语料（9 份年报）与其知识图谱

`data/corpus/` 下的 ccf_competition 金融年报（9 份）已预先构建**知识图谱**与检索索引，
可回答涉及**公司间关系、组织结构、指标对比**的问题（Q1~Q14 评测集就是基于它）。

换成自己的语料并**重建知识图谱**（属于开发者操作）：

```bash
# 1) 把新的 PDF 放进 data/corpus/
# 2) 若换了公司：先在 src/kg_dict.py 的 COMPANY_TABLE 里登记公司名/别名/代码/行业
# 3) 重建检索索引与图谱
python build_index.py
python build_kg.py --layer1
# 4) 重启界面
streamlit run app.py
```

> 详细说明见 `docs/08-技术文档.md` 第 5.1 节。

## 三、如何提问

在「💬 问答」页的输入框里输入问题，回车或点「提问」。支持**中文与英文**
（用哪种语言问，就用哪种语言答）。

### 中文示例

1. 中国邮政储蓄银行2019年末的不良贷款率和拨备覆盖率分别是多少？（数值型）
2. 对比平安银行2019年末与招商银行2019年末的不良贷款率，哪一家更低？两家分别是多少？（对比型）
3. 中信证券2020年年度报告附录的组织结构说明中，财富管理委员会下设哪些部门？（组织结构型）

### 英文示例

1. What were Postal Savings Bank of China (601658) NPL ratio and provision
   coverage ratio at the end of 2019?
2. Compare Ping An Bank and China Merchants Bank's NPL ratio at the end of 2019 —
   which one is lower?
3. What is CITIC Securities' business scope described in its 2020 annual report?

> 英文提问要**用公司英文名**（Ping An Bank / China Merchants Bank / Postal Savings
> Bank of China / CITIC Securities / China Life Insurance / China Pacific Insurance /
> China Merchants Securities / Guotai Junan Securities / Ping An Insurance）。

### 语音输入

点「🎤 语音输入」按钮，允许浏览器使用麦克风后即可说话。注意：

- 语音识别用的是**浏览器原生 Web Speech API**（本机没有安装任何语音识别模型）；
- Chrome / Edge 通常可用但**需要联网**；Firefox 或完全离线环境**不可用**，
  此时请直接用文字输入（界面会给出提示）；
- 页面上方的「语言 / Language」单选**只影响语音识别**用哪种语言，
  文字提问的答案语言由问题本身自动判定。

## 四、如何查看结果

提问后，答案区下方有三个子页签：

| 区域 | 内容 |
| --- | --- |
| **答案区** | 生成的答案；每个关键数字后标注来源 `（文档名 第X页）`；答不出时会明确说「现有资料未包含该信息」而**不会编造数字**。答案区底部有 **响应时间**（✅ 表示 ≤3 秒达标，⚠️ 表示超出） |
| 🔎 **检索结果（文本块）** | 命中的原文块，含**文档名 / 页码 / 相似度**与原文片段 —— 这就是「返回答案所在的文本块」 |
| 🕸 **知识图谱结构** | 本次检索到的图谱事实列表（如指标数值、组织下设、比较结论）与子图规模 |
| 🛠 **调试** | 检索策略、实体链接结果、各阶段耗时，排障用 |

若结果来自降级路径（例如大模型未启动），答案区顶部会显示 `⚠️ 降级：原因`，
**不会把降级结果伪装成正常结果**。

## 五、如何查看知识图谱（🕸 图谱可视化）

1. 页面顶部显示图谱规模（当前 560 个实体 / 873 条关系，覆盖 9 份年报）；
2. **渲染方式**可选「交互式（vis.js）」或「静态（matplotlib）」：
   交互式可缩放、拖拽、悬停查看；静态图适合无网络环境或截图；
3. **筛选举例**：按公司/实体类型/跳数（hop）筛出子图，只看某家公司的关系网络；
4. **节点详情**：在下拉框里选一个节点，可看到它的类型、属性与
   **来源（文档 + 页码 + 原文证据）** —— 每条边都能回到原文。

实体类型按颜色区分：公司蓝、部门绿、机构紫、行业青、指标红、时间灰（其余类型见
`docs/07-知识图谱可视化说明.md` 的完整配色表）。

## 六、如何查看实体关系（🔗 实体关系）

该页签有三个子页签：

1. **实体浏览**：按实体类型筛选查看节点（类型下拉框），可查看节点详情；
2. **新增实体/关系**：演示如何向图谱添加实体（名称、类型、别名）与关系
   （头实体 ID、关系类型、尾实体 ID、**原文依据**）——
   LLM 抽取的关系必须提供原文依据，否则会被防幻觉闸门丢弃；
3. **创建思路讲解**：按五步讲解图谱是怎么建出来的 ——
   **定本体 → 分层抽取 → 三道闸门 → 多文档融合 → provenance**。
   （演示视频二可直接用这一页作讲解底稿，见 `docs/10`。）

## 七、生成金融研报（📝 研报生成）

1. 输入**研报主题**（默认「银行板块2019年资产质量对比」）；
2. 可选**涉及公司**（多选；留空 = 全部公司）；
3. 点「生成研报」。系统先用图谱取到**确定性的数据骨架**（公司 × 指标 × 期间），
   再用文本证据补充原文表述，输出 Markdown 研报：
   `摘要 → 一、数据概览（表格）→ 二、分项分析 → 三、趋势与对比 → 四、风险提示`。
4. 研报中的每个数字同样可回溯到来源页码。

## 八、常见问题（排障）

| 现象 | 原因与处理 |
| --- | --- |
| **上传 PDF 报「不是有效的 PDF 文件」** | 选错了文件类型；本功能只接受 PDF |
| **上传 PDF 报「未能提取到文本」** | 该 PDF 是扫描件/图片型（无文本层），本工程未对上传文档启用 OCR |
| **上传后答案说「尚未上传可用的文档」** | 上传仍在解析中或已失败；看上传区域的状态提示，重新上传 |
| **图谱未就绪 / 图谱节点数为 0** | 尚未构建图谱。执行 `python build_kg.py --layer1`（秒级）后重启界面 |
| **大模型不可用 / 答案很简短** | Ollama 没启动或模型未拉取。命令行执行 `ollama serve`；用 `ollama list` 确认有 `qwen2.5:3b`。此时系统会**降级**为抽取式答案（关键数字仍会给出），并在答案区标注降级原因 |
| **提示「Qdrant 存储目录被占用」** | 同一目录的向量库只能被一个进程打开：请关掉另一个正在跑的评估脚本或界面，再重试（或改用服务端模式，见错误提示里的建议） |
| **语音按钮没反应 / 提示不支持** | 浏览器不支持（如 Firefox）或当前离线。改用文字输入 |
| **答案为空或答非所问** | 先看「🛠 调试」页的实体链接与检索结果；确认问题里的公司在语料范围内（9 家公司）且用了正确的公司名 |
| **英文提问答「现有资料未包含该信息」** | 确认用了公司**英文名**（见第三节的清单）；若仍未命中，改用中文提问对照 |
| **首次提问很慢** | 模型加载与索引构建的一次性开销；之后为 2~3 秒 |
| **界面报「模块缺失 / ImportError」** | 依赖未装全：`pip install -r requirements.txt` |

> 日志位置：`logs/`（按模块分文件，自动轮转，不会写满磁盘）；系统状态页可查看最近日志。

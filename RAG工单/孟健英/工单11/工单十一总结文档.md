# 人工智能 NLP-RAG-Embedding 模型微调任务

工单编号：人工智能 NLP-RAG-Embedding 模型微调任务

---

## 一、任务描述

针对金融年报领域的语义鸿沟问题，微调 Embedding 模型（bge_m3），提升 RAG 检索部分的准确性。要求微调后的检索效果优于微调前，并有数据指标支撑。

---

## 二、方案设计

### 2.1 数据构建

- 数据源：工单九金融年报切分后的 chunks（7324 条）
- 抽样 800 条 chunk
- 用 DeepSeek 为每条 chunk 生成一个"用户可能问的问题"
- 挖掘负例：与 query 向量相似度最低的 chunk
- 输出：800 组 `(anchor, positive)` 正例对

### 2.2 微调策略

| 项 | 值 |
|---|---|
| 基座模型 | bge_m3（本地） |
| 损失函数 | MultipleNegativesRankingLoss |
| batch size | 8 |
| learning rate | 5e-6 |
| epoch | 1 |
| max_seq_length | 256 |
| 设备 | CPU |

### 2.3 评估方法

- 构建检索任务：800 条 query，800 条 corpus
- 计算微调前 / 后模型的 Hit Rate@1/5/10 和 MRR@10
- 对比两套指标

## 三、各问题分析

### Q1：发明人查询（文本）
- **检索策略**：BM25 匹配"发明人"关键词 → 第1页 chunk
- **关键文本**："发明人 P·吉特勒"
- **LLM 输出**：P·吉特勒
- **正确原因**：发明人信息在专利扉页，OCR 准确提取

### Q2：特征描述（文本）
- **检索策略**：向量检索"特征"+ BM25 "圆锥形" → 第1页摘要 chunk
- **关键文本**："管状入口...单个圆锥形部分...达到外壳直径的80至95%...台阶形式"
- **LLM 输出**：选项 C
- **正确原因**：摘要中包含完整特征描述

### Q3：部件位置关系（图像）
- **VQA 问题**：部件4相对于部件5的位置关系
- **VLM 分析**：观察图纸，部件4在部件5左侧
- **LLM 输出**：部件4位于部件5的左侧
- **正确原因**：Qwen2-VL 能理解图纸中的空间位置关系

### Q4：尺寸含义（图像）
- **VQA 问题**：X1、X2、X3 代表什么部件的间隔距离
- **VLM 分析**：X1、X2、X3 标注在配气带孔盘 6、6'、6" 之间
- **LLM 输出**：配气带孔盘 6，6'，6" 之间的间隔距离
- **正确原因**：VLM 能识别图纸标注与部件的对应关系

### Q5：气流方向（图像）
- **VQA 问题**：气流方向(7)首先经过哪个部件，紧接着经过哪个
- **VLM 分析**：气流箭头 7 指向配气带孔盘，先经过 6"，再经过 6'
- **LLM 输出**：先经过部件 6"，再经过部件 6'
- **正确原因**：VLM 能追踪气流路径与部件顺序

### Q6：尺寸计算用途（图像+文本）
- **VQA + 文本检索**：结合图纸和说明书
- **关键信息**：h1、h2 与配气带孔盘位置相关
- **LLM 输出**：确定配气带孔盘 6，6'，6" 的位置
- **正确原因**：VLM 理解图纸 + LLM 综合说明书文本

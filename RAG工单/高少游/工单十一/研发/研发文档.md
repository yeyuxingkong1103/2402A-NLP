# Embedding 模型微调 · 研发文档

> **工单编号：人工智能 NLP-RAG-Embedding 模型微调任务**
> 任务：微调自己领域的 Embedding 模型（金融年报语料），实现工单要求的 8 个步骤
> 前置工单：01 基于 PDF 的问答 → 02 优化 → 03 表格解析 → 04 图像解析 → 05 Query 理解 → 06 混合检索 → 07 功能测试及评估

---

## 一、研发目标与范围

本工单的研发工作聚焦于**嵌入模型的领域微调工程**，而非问答算法本身：

1. 从 `ccf_competition` 9 份上市公司年报构建**结构感知切片**（7476 块）；
2. 自动生成四类训练/评估数据（正例对 / 三元组 / 相似度对 / 留出评估集）；
3. 在 `BAAI/bge-small-zh-v1.5` 上做**领域微调**，完整实现工单 8 个步骤；
4. 用检索指标量化「微调前 vs 微调后」，满足验收标准（**有数据指标支撑**）；
5. 全链路代码注释统一带工单编号 `人工智能 NLP-RAG-Embedding 模型微调任务`。

## 四、核心模块说明（`src/`）

### 4.1 配置与语料层

| 模块 | 关键定义 | 职责 |
|---|---|---|
| `config.py` | `WORKORDER` / `CCF_DOCS` / `METRIC_LEXICON` / 超参 | 路径、9 份文档映射（代码→公司/年份/行业/别名）、20 个金融指标词典、切片与训练超参 |
| `corpus.py` | `Row` / `Document` | 加载年报结构化 JSONL，过滤页眉页脚，`excel` 行展开为「单元格 \| 单元格」 |
| `chunking.py` | `Chunk` | 结构感知切片：正文块（500 字/80 重叠）+ 表格块（≤12 行聚合） |
| `_compat.py` | `apply()` | 兼容垫片：CPU-only 环境下修补 `torch.accelerator.current_accelerator` |

### 4.2 数据集层

| 模块 | 关键定义 | 职责 |
|---|---|---|
| `dataset_builder.py` | `build_dataset` / `generate_pairs` / `generate_triplets` / `generate_sim_pairs` / `build_eval_set` | 以「指标 × 公司」为锚点生成四类数据；正例块按信息量优选；训练/评估模板不相交 |
| `dataset_loader.py` | `load_pairs` / `load_triplets` / `load_sim_pairs` / `load_eval_set` | JSONL → `InputExample`；按损失类型返回对应数据 |

### 4.3 模型与训练层

| 模块 | 关键定义 | 职责 |
|---|---|---|
| `embedding_model.py` | `load_model` / `encode` / `save_model` / `model_info` | 加载 BGE 基座或微调模型；批量编码（L2 归一化）；保存模型 |
| `losses.py` | `build_loss` / `describe_losses` | 5 类损失工厂：MNRL / Triplet / Contrastive / Cosine / Matryoshka |
| `train_config.py` | `TrainConfig` | 训练参数 dataclass → `SentenceTransformerTrainingArguments`（含版本兼容回退） |
| `trainer.py` | `run_finetune` / `run_and_save` | 训练编排：前评估 → 构造数据/损失 → 训练 → 后评估 → 对比落盘 |

### 4.4 评估与应用层

| 模块 | 关键定义 | 职责 |
|---|---|---|
| `evaluator.py` | `RetrievalEvaluator` / `compare` | 语料编码（可缓存）、Top-K 检索、Recall@K / MRR / NDCG / 实体准确率 / 块级召回 |
| `retrieval.py` | `Retriever` | 推理侧向量检索器（供演示界面与定性对比） |
| `visualize.py` | `plot_all` | 6 张评估图表（指标对比 / Recall@K 曲线 / 损失曲线 / 分组对比 / 数据构成） |

## 五、完整调用链

### 5.1 一键全流程（`run_pipeline.py`）

```
run_pipeline.py
  ├─ [1] 知识库：build_all_chunks() → save_chunks()        # 7476 块
  ├─ [2] 数据集：build_dataset()                            # 810/1215/945/330
  └─ [3] 微调：run_and_save(cfg)
        └─ run_finetune(cfg)
              ├─ load_chunks() + load_eval_set()
              ├─ load_model(BASE_MODEL)          # 基座
              ├─ evaluator.encode_corpus(cache=emb_base.npy)
              ├─ evaluator.evaluate(tag="before(base)")
              ├─ load_train_dataset(loss_kind) → _to_hf_dataset()
              ├─ build_loss(model, kind)
              ├─ SentenceTransformerTrainer.train()     # 204 步 / 4 epoch
              ├─ save_model() → models/bge-small-zh-ccf-finetuned
              └─ evaluator.evaluate(tag="after(finetuned)", cache=emb_finetuned.npy)
  └─ [4] visualize.plot_all()                               # 6 张图表
```

### 5.2 评估对比（`evaluate.py`）

加载基座与微调模型 → 各自编码语料（复用缓存）→ 同口径评估 → 指标对比 JSON +
Markdown 报告 + 定性样例（同一问题 Top-3 命中差异）。

| 项 | 值 |
|---|---|

| 指标 | 微调前 | 微调后 | 变化 |
|---|---|---|---|

| Recall@3 | 0.4758 | **0.6515** | ↑ +0.1758 |
| Recall@5 | 0.5424 | **0.7576** | ↑ +0.2152 |
| Recall@10 | 0.6091 | **0.8576** | ↑ +0.2485 |
| MRR@10 | 0.4207 | **0.5904** | ↑ +0.1697 |
| NDCG@10 | 0.4434 | **0.6187** | ↑ +0.1753 |

| 实体准确率@1 | 0.8121 | 0.7848 | ↓ −0.0273 |

### 6.3 分组结果（微调后）

| 分组 | Recall@1 | 实体准确率@1 | n |
|---|---|---|---|
| 标准问法（exact） | 0.5148 | 0.7593 | 270 |
| 口语/同义改写（colloquial） | 0.3167 | **0.9000** | 60 |
| 银行 | 0.5152 | 0.8030 | 132 |

> 更好地对齐到正确公司；证券行业提升空间最大（见《优化报告》）。

## 七、研发要点

1. **正例块优选**：`_rank_positive` 用「指标词与数字邻近性 + 表格块加成 − 注释块惩罚」
   挑信息量最大的块，避免把「注释/释义」当正例。
2. **硬负例构造**：三元组负例优先取「同指标、同行业、异公司」，直击跨文档串味。
3. **评估独立性**：相关块由语料侧标注（指标词命中），不取自检索器输出。
4. **向量缓存**：语料向量按模型缓存 `.npy`，重跑评估接近瞬时。
5. **版本兼容**：`_compat.py` + 回退导入，同时适配 CPU-only torch 与 ST v6 模块变更。
6. **结果落盘**：所有评估/训练结果以 UTF-8 JSON 落盘 `output/`，便于复核与归档。

## 八、快速开始

```powershell
# 0) 依赖（Python 3.10+）
python -m pip install -r requirements.txt

# 1) 知识库 + 数据集 + 微调 + 评估 + 图表（一键全流程）
python run_pipeline.py --loss mnrl

# 2) 单独运行各步骤
python build_kb.py --rebuild        # 知识库切片
python build_dataset.py             # 数据集生成
python train.py --loss mnrl         # 微调训练
python evaluate.py                  # 微调前后评估

# 3) 补充实验（损失函数对比）
python tools/run_loss_experiment.py

# 4) 演示界面（浏览器访问 http://localhost:8501）
streamlit run demo_app.py
```

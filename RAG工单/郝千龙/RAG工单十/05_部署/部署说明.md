# 工单十 金融问答系统部署说明

## 一、环境要求

- Docker 20.10+ / Docker Compose 2.0+
- 内存 ≥ 4GB（索引加载约需 2GB）
- 磁盘 ≥ 5GB（镜像 + 索引）

## 二、快速部署

```bash
cd 02_研发
docker compose up -d
```

服务启动后监听 `http://localhost:8000`。

## 三、接口说明

### 3.1 健康检查
```
GET /health
```
返回索引状态、文档数、块数。

### 3.2 问答接口
```
POST /ask
Content-Type: application/json

{"question": "发行人的注册资本是多少？"}
```
返回答案、证据页码、标题路径、耗时。

### 3.3 服务说明
```
GET /
```
返回服务能力说明。

## 四、卷持久化

索引与模型可挂载宿主机目录，避免容器重建后重复建库：

```yaml
volumes:
  - ./index:/app/index
  - ./data:/app/data
```

## 五、本地开发运行

```bash
cd 02_研发
pip install -r requirements.txt
cd app
python service.py
```

冒烟测试：`powershell -File test_api.ps1`

## 3. 知识图谱构建（Graph RAG 的关键）

**实体**：公司(9) / 行业(银行·保险·证券) / 财务指标(营业收入、归母净利润、不良贷款率、拨备覆盖率、保险业务收入…) / 年份。
**关系**：`公司 —披露指标→ 指标（值, 年份, 来源页）`、`公司 —属于行业→ 行业`、`公司 —报告年度→ 年份`。

**抽取流程（`app/graph_build.py`）**
1. **叙事句正则**（优先）：“2019年，本行实现营业收入1,379.58亿元…” → (公司, 指标, 值@年份, 页)。
2. **表行解析**：`['指标','值1','值2',…]` → (公司, 指标, 首值@报告年, 页)。
3. 归并成 networkx 有向图，输出 `data/graph/graph.json`（含 `src` 标注来源：narrative/table）与 `graph.graphml`（可导入 Neo4j/Gephi）。
4. 规模：**46 节点 / 131 边**（当前语料）。

> ⚠️ 表格行首列数值存在“串列”风险 → 检索时**只采纳「值确实出现在来源页」的三元组**。

## 4. Graph RAG 检索链路（`app/graph_rag.py`）

1. **实体链接**：从问题识别 公司 / 指标 / 年份（词典 + 正则）。
2. **图谱查询**：沿 `公司-披露指标` 边取 `(指标, 值, 年份, 页)`，过滤“值不在该页”的噪声三元组。
3. **上下文构造**：
   - 高置信（叙事句）来源页 **置顶**；
   - 其余图谱页对混合检索结果做 **1.8× 加权**（不直接置顶，避免噪声把错页顶上来）；
   - 不足 top-k 用混合检索补足。
4. **生成**：与常规 RAG 同一套 prompt（`app/prompts.py`）→ 答案带页码引用。
5. **可视化**：`app/graph_viz.py` 渲染全图 `static/graph.html` 与“问题相关子图” `static/graph_query.html`（pyvis，分色：公司/行业/指标/年份）。

## 5. 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/ask` | 问答；`{"graph": true}` 走 Graph RAG（返回 `graph.entities/graph_triples`）|
| POST | `/api/search` | 指定策略/重排器的检索（工单 06）|
| POST | `/api/chat` | 多轮对话（工单 05）|
| GET | `/api/graph` | 全图节点/边 |
| POST | `/api/graph/query` | 按问题返回实体链接 + 三元组 + 子图 |
| GET | `/static/graph.html` | 知识图谱可视化页面 |

# RAG2 在线问答 · 用户使用手册

## 1. 登录

1. 浏览器打开 **http://127.0.0.1:8000**。
2. 输入任意**用户名**（无需密码），点击「进入」。

> 用户名即你的身份：不同用户名之间的会话、历史与短期记忆完全隔离。
> 换一个用户名登录，就相当于一个全新用户。

## 2. 选择角色

登录后顶部会显示 4 个角色，点击切换：

| 角色 | 说明 |
| --- | --- |
| 🌾 农业专家 | 农作物种植、病虫害防治、施肥管理等农业问题 |
| 🔧 技术支持 | 软件、系统、设备使用与故障排查 |
| 🤖 通用助手 | 通用知识问答 |
| 💬 客服 | 咨询与售后支持 |

切换角色后，系统提示词（人设）会随之变化，同一问题可由不同角色给出不同风格的答案。
每个角色会展示若干「推荐问题」，点击即可直接提问。

## 3. 开始提问

- 在底部输入框输入问题，**Enter 发送**，**Shift+Enter 换行**。
- 回答以**流式（SSE）**方式逐字显示，无需等待整段生成。
- 回答末尾/下方会显示**来源引用** `[1]、[2]…`，鼠标悬停可查看原文片段与来源文档。

## 4. 多轮对话

- 同一个会话内，助手会记住之前的对话（**最近 5 轮**），可以追问：
  - 「那第二种方法呢？」「上面说的药，用量是多少？」
- 短期记忆存在 Redis 中，**24 小时自动过期**（可在 `config.yaml` 调整 `redis.history_ttl`）。

## 5. 会话管理

- 左侧「我的会话」列表展示当前用户的历史会话。
- 点击会话可查看历史消息并继续对话；点击「删除」删除该会话。
- 点击「＋ 新建会话」开始一段全新对话（不携带旧上下文）。

## 6. 评估本条（RAGAS）

每条助手回答下方都有「**评估本条**」按钮，点击后对该回答打分，展示 8 个 RAGAS 指标（0~1，越接近 1 越好）：

| 指标 | 含义 |
| --- | --- |
| 忠实度 faithfulness | 答案是否忠于检索到的知识片段 |
| 答案相关性 answer_relevancy | 答案是否切题 |
| 上下文精确率 context_precision | 召回片段是否都相关 |
| 上下文召回率 context_recall | 相关片段是否都被召回 |
| 上下文相关性 context_relevance | 上下文与问题相关度 |
| 答案正确性 answer_correctness | 相对参考答案的正确性 |
| 上下文实体召回 context_entity_recall | 实体召回情况 |
| 语义相似度 semantic_similarity | 答案与参考答案的语义相似度 |

> 评估需要调用本地 Ollama + bge-m3，耗时稍长，请耐心等待。

## 7. 多用户说明

- 用户 A 与用户 B 登录后互不可见对方的会话与记忆。
- 同一用户可拥有多个并发会话。
- 退出登录会注销当前令牌（历史会话仍保留，下次登录仍可查看）。

## 8. 管理员后台

登录用户名在 `admin.usernames`（默认 `admin`）中时即为管理员，登录后侧边栏会出现「**⚙ 管理后台**」按钮。

- **服务地址与端口**：修改监听地址 / 端口（1~65535）→「保存基础配置」写回 `config.yaml` → 点「**重启服务**」自动在新端口重启；重启后浏览器需访问新地址（如 `http://127.0.0.1:9000`）。
- **基础配置**：修改对话模型（模型名 / 接口地址 / 温度 / 最大 token）、检索参数（top_k / 检索模式 / 重排开关）、记忆与过期（短期记忆轮数 / 会话与令牌 TTL）、管理员用户列表；点击「保存基础配置」即**热生效**并写回 `config.yaml`。
- **角色管理**：新增 / 编辑 / 删除角色（`role_id`、名称、头像、描述、`system_prompt` 人设、推荐问题）；保存后写回 `roles.yaml`，主界面角色列表立即更新。

> 非管理员账号看不到「管理后台」按钮，直接访问后台接口也会被拒绝（403）。

## 9. 退出

点击左下角「退出登录」返回登录页。

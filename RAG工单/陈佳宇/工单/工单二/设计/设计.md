# 招股说明书RAG问答系统 - 设计文档
## 1 项目概述
### 1.1 项目背景
本项目为工单2实训项目，需要开发一套基于RAG（检索增强生成）的PDF文档问答系统。系统读取招股说明书PDF文档，提取文档内容，向量化后存入向量数据库；用户通过Web页面输入问题，系统从文档中检索相关原文片段返回，实现招股说明书资料的智能检索问答。

### 1.2 项目目标
1. 支持PDF招股说明书文档解析，提取文本并清洗。
2. 实现文本分块、向量化，使用Milvus向量数据库存储向量。
3. 提供Web网页交互界面，用户输入问题，检索并返回PDF内相关原文。
4. 在WSL环境稳定运行，支持局域网浏览器访问页面。

### 1.3 项目范围
- 包含模块：PDF解析模块、文本预处理模块、向量嵌入模块、Milvus向量检索模块、Flask Web前后端模块。
- 本版本范围：仅做文档检索，返回原文片段；暂不接入大模型做摘要生成。

## 2 总体架构设计
系统采用模块化分层架构，一共分为5层：
1. **文档输入层**：输入文件为招股说明书PDF，由PyMuPDF读取文档内容。
2. **文本预处理层**：文本清洗、去除空行、多余空格；固定长度文本分块，设置块重叠，保证上下文完整性。
3. **向量嵌入层**：使用`all-MiniLM-L6-v2`轻量句向量模型，将文本块转为384维浮点向量。
4. **向量存储与检索层**：Milvus向量数据库，存储向量+原文；用户问题转为向量后执行相似度检索，召回TopK相关文本。
5. **Web交互层**：Flask作为后端服务，内置简单HTML前端页面；提供网页输入框，提交问题，展示检索结果。

架构数据流：
PDF文件 → 文本提取 → 清洗&分块 → 向量化 → Milvus入库
用户提问 → 问题向量化 → Milvus相似度检索 → 返回相关原文 → Web页面展示

## 3 模块详细设计
### 3.1 PDF解析模块
- 功能：读取PDF文件，提取页面文本，过滤无效空白字符。
- 依赖库：pymupdf（fitz）

### 3.2 文本预处理模块
- 文本清洗：去除换行、多余空格、特殊符号。
- 文本分块：chunk_size=512，chunk_overlap=50。
> overlap作用：防止关键句子被分割在两个文本块，丢失上下文。

### 3.3 向量嵌入模块
- 模型：all-MiniLM-L6-v2（sentence-transformers）
- 向量维度：384维浮点数向量
- 功能：将每一段文本转为向量，用于相似度计算

### 3.4 Milvus向量数据库模块
集合名称：`rag_waterwork2`
| 字段名 | 数据类型 | 属性 | 说明 |
| ---- | ---- | ---- | ---- |
| id | INT64 | 主键、自动生成 | auto_id=True，Milvus自动生成主键，无需手动传入 |
| vector | FLOAT_VECTOR(384) | 向量字段 | 存储文本块对应的向量，用于相似度检索 |
| text | VARCHAR(4096) | 存储字段 | 保存原始PDF文本片段 |

索引配置：
- 索引类型：IVF_FLAT
- 距离度量：L2（欧氏距离，距离越小代表文本越相似）
- nlist:128

检索参数：TopK=3，返回相似度最高3段原文。

### 3.5 Web接口模块
1. GET `/`
    - 功能：返回问答系统首页HTML页面。
2. POST `/ask`
    - 入参：question（用户输入的问题字符串）
    - 处理逻辑：问题向量化，调用Milvus检索
    - 返回：检索得到的招股说明书原文片段。

## 4 非功能需求设计
1. 兼容性：WSL Ubuntu24.04，Python3.12环境正常运行。
2. 可访问性：Web服务监听0.0.0.0，支持本机与WSL局域网IP访问网页。
3. 稳定性：向量入库、检索流程稳定，捕获基础异常。
4. 演示性：满足实训工单演示要求，网页简洁，问答结果直观展示。

## 6 风险与预案
1. Milvus连接失败：检查Milvus容器是否正常启动，端口19530是否开放。
2. 向量入库报错：核对集合Schema字段，保证向量维度匹配。
3. PDF读取失败：确认PDF文件路径正确，文件无损坏。
4. 网页无法访问：Flask启动参数设置0.0.0.0，防火墙放行7860端口。

# 工单15 优化技术图纸与文本的跨模态检索流程｜设计文档
## 1.项目概述
本工单承接工单14PDF解析优化成果，针对工业专利中**文本‑图像混合类问题**做跨模态检索流程优化。
现有纯文本向量检索存在两类典型故障：
1. **检索无关**：提问图纸部件位置关系，仅靠泛化关键词`部件、编号`召回大量无关文本块，遗漏目标图纸图块；
2. **图文割裂**：召回图纸页面，但无法将查询部件编号、位置关系与图纸图像信息绑定，LLM缺少视觉上下文，推理答案错误。

测试文档：`CN100347506C.pdf`；6条测试用例：2条纯文本、4条图文强关联（依赖第11页图3）。
验收目标：6道测试用例准确率100%；图文类问题Top‑1/Top‑3召回片段必须包含图3相关描述；端到端响应时间维持3‑5秒，系统稳定无崩溃。

## 2.RAGFlow多模态检索架构梳理
RAGFlow检索完整链路：
> 用户Question → 查询理解&重写模块 → 多路召回（文本向量、图文块向量） → Hybrid Search混合召回 → Re‑Rank重排序 → 组装Prompt（文本+图像摘要） → LLM生成回答

核心模块：
1. 查询理解与重写：解析用户question，识别图纸引用标记（图X、第X页图示）；
2. 多路召回：普通文本向量召回、图纸图文绑定块向量召回；
3. 结果融合：Reciprocal Rank Fusion(RRF) reciprocal秩融合，加权多路检索结果；
4. 跨模态重排：轻量图文重排模型，提升图纸图文块排序优先级；
5. Prompt工程：识别上下文包含图纸信息时，增加专门提示词，引导LLM结合图纸摘要推理。

## 3.优化方案设计
### 3.1 查询理解增强（图纸引用识别）
正则表达式识别问题中的图纸引用：`图3、图X、第XX页图、第XX页图示`；
提取图表标识，生成**图像增强查询文本**，原始query + 图纸描述摘要共同参与检索。

### 3.2 多路召回+RRF结果融合
1. 一路：原始用户问题文本向量检索；
2. 二路：图纸引用增强查询做图文绑定块检索；
3. 使用Reciprocal Rank Fusion融合两路召回结果，配置权重可配置。

### 3.3 跨模态重排
接入轻量跨模态reranker，对召回候选块打分，**提升匹配图纸引用、部件编号的图文块排序优先级**。

### 3.4 Prompt模板优化
当检索结果中检测到图纸/图表块，向LLM追加提示：`请结合下面技术图纸描述信息完成推理，重点关注部件编号、位置关系`。

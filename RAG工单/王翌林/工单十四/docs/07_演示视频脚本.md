# 工单十四：演示视频脚本

## 演示目标
展示低质量工业 PDF（图片型）的解析修复与多模态问答系统，6 个测试问题 100% 准确回答。

## 演示流程

### 第一段：问题背景（30秒）
1. 展示 CN100342976C.pdf（静电除尘器专利，8页）
2. 用 PyMuPDF 检查：每页文本字符数为 0，说明是图片型 PDF
3. 说明问题：传统 PDF 解析器无法提取文字，信息完全丢失

### 第二段：解决方案（60秒）
1. 展示系统架构图
2. 核心方案：Qwen2-VL 多模态模型替代传统 OCR
3. 双路由 RAG：文本问题走检索，图像问题走 VQA

### 第三段：知识库构建（60秒）
1. 运行 `python scripts/build_kb.py`
2. 展示页面图片提取、OCR、分块、向量化、入库流程
3. 展示 Milvus 入库结果（12 chunks）

### 第四段：6题问答演示（180秒）
逐个演示 6 个问题：

**Q1（文本）**：该静电除尘器的发明人是？
- 输入问题 → 系统走文本检索通道
- 展示检索到的第1页文本块（包含"发明人 P·吉特勒"）
- 答案：A. P·吉特勒 ✅

**Q2（文本）**：以下哪个描述符合该静电除尘器的特征？
- 走文本检索通道
- 展示检索到的摘要文本（圆锥形部分、80至95%、台阶形式）
- 答案：C ✅

**Q3（图像）**：第7页图片中，部件4相对于部件5的位置关系？
- 走图像 VQA 通道
- 展示第7页图纸
- VLM 分析：部件4在部件5左侧
- 答案：A ✅

**Q4（图像）**：尺寸X1、X2、X3分别代表什么部件的间隔距离？
- VQA 分析图纸标注
- 答案：A. 配气带孔盘6，6'，6"之间的间隔距离 ✅

**Q5（图像）**：气流方向(7)首先经过哪个部件？紧接着经过哪个？
- VQA 分析气流箭头和配气带孔盘位置
- 答案：C. 先经过部件6"，再经过部件6' ✅

**Q6（图像）**：已知外壳直径D，h1和h2的尺寸可用来计算什么？
- VQA 结合图纸和说明书文本
- 答案：B. 确定配气带孔盘6，6'，6"的位置 ✅

### 第五段：批量测试结果（30秒）
1. 运行 `python scripts/evaluate.py`
2. 展示结果：6/6 = 100% 准确率
3. 展示平均响应时间

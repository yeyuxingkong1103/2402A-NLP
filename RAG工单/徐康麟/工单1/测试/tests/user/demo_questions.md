## 二、多轮对话演示（同一会话连续提问）

| 步骤 | 提问 | 观察点（实测） |

| 1 | 武汉兴图新科电子股份有限公司法定代表人是谁？ | 回答"法定代表人是程家明。"，引用第 22 页 |

- 观察点：无关问题（"今天天气怎么样？"）不会被误判成追问（它会走「不清楚」兜底）。

## 三、"不清楚"兜底演示

| 提问 | 期望行为（实测） |
| --- | --- |
| 未建索引时问任意问题 | 回复「不清楚」，并提示 `python 研发/scripts/build_index.py`（**达标**） |
| 检索结果为空时问任意问题 | 回复「不清楚」（**达标**，见 `测试/tests/online/test_unknown.py`） |
| 今天天气怎么样？ | 回复「不清楚（原因：检索结果相关度不足）」（**达标**） |
| 红烧肉怎么做才好吃？ | 回复「不清楚」（**达标**） |
| 推荐一本好看的小说。 | 回复「不清楚」（**达标**） |

> 判定依据：检索器用**原始余弦相似度**阈值 `min_confidence_cosine=0.55` 判断"是否有把握"；
> 实测相关问题 ≥0.73、无关问题 ≤0.39，区分度充足。演示时可对比"相关问题给答案、无关问题给不清楚"。

# 优化/ —— 基线、优化脚本与效果对比

> 工单：**人工智能NLP-RAG-PDF文档的表格解析及检索优化**

## 目录约定

| 路径 | 用途 |
| --- | --- |
| `基线/` | 优化前基线（**只读参照，不得篡改**）。来源：`工单2\优化\基线\baseline_metrics.json`（准确率 0.50、首字 P95 57312.92 ms） |
| `脚本/` | 评测与对比脚本（准确率、首字/端到端延迟、检索命中率、表格块增益） |
| `评估结果/` | 优化后的评测产物与前后对比报告（含逐题明细与复现命令） |

## 必须回答的问题

1. **表格解析是否真的带来增益** —— 同一评测集下，「仅文本块」vs「文本块 + 表格块」的准确率差异。
2. **失败题是否被修复** —— 工单2 的 5 道错题（33 / 95 / 531 / 793 / 957）逐题给出前后对比。
3. **延迟是否达标** —— 首字 P95 ≤ 3 s，并与基线 57.3 s 对比。
4. **命中判定口径** —— 必须以「证据原文是否落在返回 chunk 中」判定命中，
   **不得**以「引用页 == evidence_pages」判定（会把 957 误判为命中并高估）。

## 指标纪律

- 所有指标必须来自**实际运行**并落盘留痕；报告中**严禁**编造未运行的工具数值。
- **RAGAS 未运行（依赖不可用，本机断网）**：必须显式标注，并给出确定性替代指标。
- 冷启动与预热后的数据并列保留，不得只留好看的一组。

# 工单十一 · Embedding 模型微调任务说明

> 工单编号：人工智能NLP-RAG-Embedding模型微调任务
> 基线：工单十（金融问答系统，v6 引擎 + 9 份年报语料），目录 `/home/dabaie/code/工单/工单十一`

## 1. 任务目标

针对金融领域检索场景，对 Embedding 模型（BAAI/bge-m3）进行微调，使微调后的模型在金融语料上的检索效果优于微调前，并以数据支撑结论。

## 2. 工单要求与落地对照

| 工单要求步骤 | 落地实现 |
| --- | --- |
| 数据集生成 | `src/finetune_v11/qa_dataset.py`：从 `data/ccf_reports/chunks/`（9 份 A 股年报，≥200 字 chunk）按文档分层抽样；构造金融领域问答生成 prompt（营收/净利润/股息/保费/资产/风险指标等） |
| 运行问答对生成 | `scripts/gen_qa_pairs_v11.py`：DeepSeek LLM 逐 chunk 生成 2 题，解析为 `(query, positive)` 正例对；按 chunk_id 防泄漏切分 train/dev；落盘 `data/finetune_v11/` |
| 数据集与模型加载 | `scripts/finetune_bge_v11.py`：`read_jsonl` 加载 train/dev；`SentenceTransformer` 从本地路径 `/home/dabaie/models/bge-m3` 加载基线模型 |
| 定义损失函数 | `MultipleNegativesRankingLoss`（对比损失，批内负例）——天然适配 (query, positive) 正例对格式，无需人工构造负例 |
| 定义训练参数 | bf16 混合精度 + 梯度检查点 + 冻结嵌入层与底部 12 层 Transformer（bge-m3 共 24 层，仅微调顶层）；epochs=2、batch=8、lr=2e-5、max_seq=256、warmup 10%、seed=42（8GB 显存可训） |
| 创建评估器 | `src/finetune_v11/ir_eval.py` + `InformationRetrievalEvaluator`：评估查询 = dev 生成题（chunk 级相关）+ 工单七 10 道真实金标题（doc 级相关）；语料 = 抽样 chunk + 800 干扰 chunk |
| 微调前评估模型 | 训练前在同一评估集上记录基线指标：mrr@10 / ndcg@10 / accuracy@1/3/5/10 |
| 微调后评估模型 | 训练后同口径复测，`compare_metrics` 输出 before/after/delta 对比表 |

## 3. 数据集设计

- **正例对格式**：`{"query", "positive", "chunk_id", "doc_id", "page"}`，适配对比损失
- **防泄漏**：同一 chunk 生成的问题不跨 train/dev（按 chunk_id 切分）
- **评估语料**：抽样 chunk + 随机干扰 chunk（排除已用于生成问答对的 chunk），增大检索难度
- **真实题校验**：工单七 `test_questions_v7.json` 10 题（带 gold_docs）并入评估器，doc 级相关 = 该文档全部 chunk

## 1. 性能优化使用指南

如果系统响应慢，按以下顺序调整：

**第 1 步：减小 max_new_tokens**

```python
answer = engine._generate(prompt, max_new_tokens=128)  # 从 512 降到 128
```

**第 2 步：减少上下文块数**

```python
top_docs = engine._rerank(search_query, unique, top_k=1, method="bge")  # 从 4 降到 1
```

**第 3 步：精简 prompt**

```python
prompt = f"根据上下文回答问题。\n上下文：{context}\n问题：{q}\n回答："
```

---

## 2. 权衡说明

| 优化方向 | 响应速度 | 回答质量 |
| --- | --- | --- |
| 保守（max_new_tokens=512） | 慢（10s+） | 高（信息完整） |
| 平衡（max_new_tokens=200） | 中（5s） | 中 |
| 激进（max_new_tokens=128） | 快（3-5s） | 较低（可能截断） |

---

## 3. 达到 3s 目标的推荐路径

| 路径 | 说明 |
| --- | --- |
| 换小模型 | Qwen2.5-1.5B 推理速度约快 3 倍 |
| vLLM 推理引擎 | 比 HuggingFace generate 快 2-5 倍 |
| 升级 GPU | RTX 4090 / A100 显著加速 |
| 流式输出 | 首 token 快速返回，用户感知更快 |

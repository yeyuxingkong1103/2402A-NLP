# 工单12 LightRAG金融问答系统 - 优化文档
## 1. 基础优化点（实体抽取优化）
1. 替换LightRAG默认英文抽取Prompt，自定义金融领域Prompt，**严格限制实体类型与关系类型白名单**，阻止大模型编造不存在实体、关系，降低图谱噪声。
2. 调整分块参数 chunk_size=800，chunk_overlap=100：
    - 块太小：实体容易被切分断裂，实体关系抽取失败
    - 块太大：上下文冗余，抽取引入无关信息

## 2. 检索策略优化
1. LightRAG hybrid模式：结合local局部语义检索 + global全局图谱遍历，适合跨文本实体关联推理，针对招股书关联方、组织架构这类多实体关系问题。
2. 对比基线Naive模式：仅向量相似度检索，缺少实体关联能力，复杂关系问答容易召回碎片化信息。

## 3. 工程连通性优化（WSL+Ollama跨主机）
1. Ollama默认仅监听127.0.0.1，Windows设置环境变量`OLLAMA_HOST=0.0.0.0`，重启Ollama，开放局域网访问。
2. WSL使用网关IP（/etc/resolv.conf nameserver）访问Windows Ollama，不使用127.0.0.1，解决WSL无法访问Windows本地大模型服务的经典坑。

## 4. 可扩展优化方向
1. 增量更新：LightRAG原生支持增量插入PDF，新增招股文档直接调用rag.insert()，无需全量重建知识库。
2. 抽取质量优化：可以增加实体消歧逻辑，合并同名不同含义实体，清洗图谱重复边。
3. 评估增强：RAGAS评估可以补充人工标注标准答案ground_truth，进一步提升评估准确度。
4. 缓存优化：lightrag_cache持久化保存图谱向量，重复运行不需要重复抽取实体，节省LLM调用开销。

## 5. 优化前后对比
| 优化项 | 优化前 | 优化后 |
|---|---|---|
| 实体抽取Prompt | LightRAG默认英文Prompt，实体类型不可控，幻觉多 | 中文金融白名单Prompt，限制实体/关系，减少编造 |
| LLM访问 | WSL 127.0.0.1无法访问Windows Ollama | 使用WSL网关IP，Ollama开放0.0.0.0监听 |
| 检索模式 | 仅向量检索 | 支持普通RAG、LightRAG图谱混合检索双模式对比 |

三、检索流程

用户提问
   │
   ├──→ 向量检索 (Milvus, top_k=10)
   │         │
   │         └── bge-m3 向量化 → COSINE 相似度搜索
   │
   ├──→ BM25 检索 (内存, top_k=10)
   │         │
   │         └── jieba 分词 → rank_bm25 关键词匹配
   │
   └──→ RRF 融合 (Reciprocal Rank Fusion)
             │
             └──→ CrossEncoder 重排 (bge-reranker-large)
                       │
                       └──→ 分数阈值过滤 (score >= 0.3)
                                 │
                                 └──→ Top-K 结果 → LLM 上下文

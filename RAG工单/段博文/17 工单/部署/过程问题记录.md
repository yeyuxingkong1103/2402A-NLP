# 过程问题记录 — 解决API服务并发瓶颈与资源泄漏

## 问题1：压测脚本CPU占满
- **现象**：首次运行Python压测脚本时，20个worker线程持续循环发请求无间隔，CPU 100%满载。
- **解决**：每个请求后加0.1s间隔（模拟真实用户思考时间），压测时间缩短到15秒。

## 问题2：Docker镜像拉取失败
- **现象**：`docker compose up --build` 拉取 `python:3.12-slim` 镜像时，阿里云镜像源返回 403 Forbidden。
- **解决**：改为本地直接运行 api_server.py（buggy/optimized 两个实例），Docker配置文件（Dockerfile + docker-compose.yml）作为交付物保留，生产环境可使用。

## 问题3：手写JMeter .jmx XML格式易错
- **现象**：首次编写的参数化 .jmx 脚本因HTTPSamplerProxy中stringProp嵌套错误，JMeter解析失败（line 50 XML unmarshal error）。
- **解决**：拆分为两个极简 .jmx 文件（scenario_a.jmx / scenario_b.jmx），去掉复杂条件判断，仅参数化 host/port/threads/duration/csvfile。

## 问题4：JMeter输出编码问题
- **现象**：subprocess.run 用 encoding="utf-8" 读取JMeter输出时，遇到0xD7字节（GBK编码的中文）导致UnicodeDecodeError。
- **解决**：改为 encoding="gbk", errors="replace"。

## 瓶颈定位与修复对照
| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 瓶颈1: 模型重复初始化 | 每请求 `MockModel()` 创建新实例 | 全局单例 `self._model` |
| 瓶颈2: 无限流 | 无并发控制 | `Semaphore(10)` 限流 |
| 泄漏1: 缓存不释放 | `_leaked_objects` 无限增长 | LRU淘汰 + `gc.collect()` |
| 泄漏2: 连接不归还 | 无连接池管理 | `MockDBPool` + `finally` 释放 |

# 工单16 调试与微调专用视觉语言模型｜设计文档
## 1.项目概述
RAGFlow内置视觉语言模型(VLM)，在工业专利图纸场景存在缺陷：专业术语理解偏差、图纸部件位置/运动原理推理错误。
本工单完成VLM微调完整流水线：数据集格式转换 → LoRA微调配置 → 训练调试 → 多维度效果评估。
> 使用LLaMA‑Factory框架实现VLM的LoRA轻量微调；不做全参数微调，节省显存。

评估分为两大部分：
1. 通用文本指标：BLEU、ROUGE；
2. **工业专业专项指标（工单重点）**
   - a) 专业术语准确性：输出答案工业专有名词、部件编号是否正确；
   - b) 图纸推理正确性：针对图纸提问，部件位置、运动原理推理结果是否和图纸一致。

验收标准：
1. 训练正常启动，至少跑完1个epoch，训练loss正常下降；
2. 微调后，工业评估集得分相比基线提升≥5%；
3. 输出完整评估报告，分析失败案例，给出调参、数据清洗改进建议。

## 2.技术选型
- 微调框架：LLaMA‑Factory，支持VLM多模态LoRA微调；
- 微调方式：LoRA低秩适配，冻结主干，只训练LoRA适配器，显存占用低；
- 模型基座：工业场景VLM（如Qwen‑VL‑Chat）；
- 数据集格式：遵循LLaMA‑Factory多模态对话数据集json格式（image+conversations）；
- 评估脚本：同时实现通用NLP指标 + 工业专项评测（术语准确率、图纸推理正确率）。

## 3.整体工作流程
> IMDR工业图文数据集原始数据 → 数据格式转换脚本 → LLaMA‑Factory训练数据集
> → 编写LoRA训练yaml配置文件 → 启动LoRA微调训练
> → 训练产出LoRA适配器权重
> → 评估脚本：基线模型 vs 微调后模型，通用指标+工业专项指标
> → 输出评估报告，错误案例分析，给出优化建议

## 4.数据集说明
原始IMDR数据集包含：图片路径、用户问题、标准答案；
转换后LLaMA‑Factory多模态对话格式：每条样本携带`image`图片路径、多轮对话`conversations`。

## 5.关键参数设计
1. 图像预处理：VLM对应图像处理器，图片resize、归一化；
2. Tokenizer：基座VLM配套tokenizer；
3. LoRA参数：r=8，lora_alpha=16；target_modules定位VLM的Attention层；
4. 超参：学习率 2e‑4；batch_size；gradient_accumulation_steps；epoch=1；
5. 学习率调度器：cosine；warmup_ratio。

## 7.验收条件
1. 训练可正常运行，至少完成1个epoch，loss持续下降，无NaN、loss爆炸；
2. 微调后工业专项指标相比基线提升≥5%；

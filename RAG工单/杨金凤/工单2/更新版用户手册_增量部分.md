# 更新版用户手册（增量部分）

以下仅列出与工单 01 用户手册不同的部分。

---

## 1. 新增功能说明

### 1.1 多语言问答

系统支持中文和英文问答，界面中输入任意一种语言即可：

- **中文**：武汉兴图新科电子股份有限公司注册资本是多少？
- **英文**：What is the registered capital of Wuhan Xingtu Xinke Electronics Co., Ltd.?

**响应时间：**

- 中文问题：约 2-3 秒
- 英文问题：约 5-8 秒（英文路径需额外进行两次翻译调用）

### 1.2 异常输入处理

系统会自动识别并处理以下异常输入：

| 输入情况 | 系统响应 |
| --- | --- |
| 空输入 | 【输入错误】输入为空，请输入问题。 |
| 纯空格 | 【输入错误】输入为空，请输入有效问题。 |
| 只有标点符号 | 【输入错误】输入不包含有效字符。 |
| 超过 500 字符 | 自动截断后正常回答 |

### 1.3 检索失败提示

如果检索过程出现异常（向量库损坏、模型加载失败等），系统会返回：

> 【检索失败】未能从知识库中检索到相关内容，请稍后重试或联系管理员。

而不会直接崩溃。

## 3. 使用示例

### 3.1 中文问答示例

- **输入**：武汉兴图新科电子股份有限公司注册资本是多少？
- **输出**：武汉兴图新科电子股份有限公司的注册资本是 5,520 万元。

### 3.2 英文问答示例

- **输入**：What is the registered capital of Wuhan Xingtu Xinke Electronics Co., Ltd.?
- **输出**：The registered capital of Wuhan Xingtu Xinke Electronics Co., Ltd. is 55.2 million yuan.

### 3.3 异常输入示例

- **输入**：（空）
- **输出**：【输入错误】输入为空，请输入问题。

## 4. 常见问题（新增）

### 4.1 英文回答里的公司名拼写不对

翻译层可能将"兴图新科"音译为"Xinka"而非"Xinke"。不影响数字和事实的准确性，如需修正可在 `rag_engine.py` 的 `_translate` 方法中加公司名约束。

### 4.2 英文问题响应较慢

英文问题需经"翻译→检索→生成→回译"四次 LLM 调用，约 5-8 秒。这是多语言支持的合理代价，中文路径仍保持 2-3 秒。

### 4.3 系统报"【系统异常】"

说明主流程出现未预期异常（如显存不足、模型崩溃）。请：

1. 杀掉其他占用 GPU 的进程：

```bash
pkill -9 -f app.py
```

2. 重启服务：

```bash
python app.py
```

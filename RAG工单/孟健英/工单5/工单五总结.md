# 人工智能 NLP-RAG-Query 理解优化任务

工单编号：人工智能 NLP-RAG-Query 理解优化任务

## 一、任务描述

在工单一至四构建的 RAG 问答系统基础上，增加多轮对话与 Query 理解能力，实现指代消解、省略补全和上下文继承，支持以下 5 轮对话：

1. 兴图军用领域收入
2. 他参与的哪个工程荣获国家科技进步一等奖？
3. 这个公司的法定代表人是谁？
4. 那武汉力源信息技术股份有限公司呢？
5. 力源组织结构图中，哪个销售部的销售处最多？有哪些销售处？

## 二、方案设计

### 2.1 多轮对话状态管理
维护 DialogState：
- last_company：上一轮提到的公司
- last_attribute：上一轮问的属性
- history：历史记录

### 2.2 Query 重写

规则 + LLM 混合：

| 类型 | 示例 | 重写策略 |
|---|---|---|
| 省略式 | 那XX呢？ | 补全为“XX的<上一属性>是多少？” |
| 指代式 | 他/这个公司 + 问句 | 指代词替换为 last_company |
| 明确公司 | 含公司全名 | 不重写 |
| 兜底 | 其他 | LLM 重写 |

### 2.3 检索与生成
复用 v4 的混合检索 + 表格/图像加权，只把 query 换成重写后的。

## 三、5 轮对话结果

| 轮 | 原问题 | 重写后 | 回答 | 判定 |
|---|---|---|---|---|
| 1 | 兴图军用收入 | 不变 | 6,464.51 / 14,414.16 / 18,780.67 / 4,627.14 万 | ✅ |
| 2 | 他参与的哪个工程… | 他 → 兴图 | 某情报、指挥、控制与通信网络一体化工程 | ✅ |

| 5 | 力源组织结构图 | 不变 | 大客户销售部 6 个销售处 | ✅ |

**准确率：5 / 5 = 100%**

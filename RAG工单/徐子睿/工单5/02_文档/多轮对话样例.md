## 二、实现设计（会话状态 + 指代消解）

```text
会话状态 SessionState = {
    current_entity: "武汉兴图新科电子股份有限公司" | "武汉力源信息技术股份有限公司",
    last_intent:   "数值" | "事实" | "列举" | "法定代表人" | ...,
    last_question: str,
    turns: [...]           # 供反馈/回溯
}
```

1. **实体抽取**：`detect_entity(q)` —— 正则 `[\u4e00-\u9fff]{2,20}(股份)?有限公司` + `config.DOC_ALIASES` 别名表（兴图新科 / 力源信息）。
2. **指代消解**：
   - 代词表（他/她/它/该/这个/该公司/本公司/那家）→ 替换为 `current_entity`；
   - 省略式追问（“那 X 呢” / “X 呢”）→ 抽出新实体 X，**继承 `last_intent`**，拼成完整问题后检索；
   - 无实体无代词 → 沿用 `current_entity`。
3. **多轮改写**：`rewrite_turn(q, state) -> 完整问题`，再走既有 引擎（Query 理解 → 混合检索 → 生成）。
4. **前端**：对话区保留上下文（前端已有多轮气泡），每轮把 `session_id` 带上，服务端维护状态。
5. **文档路由**：改写后的问题会带上公司全名 → `engine.detect_doc()` 自动切到对应 PDF（工单 03/04 的多文档能力）。

# 09 · 构建服务运行手册（v2）

> **服务**：GB/T 44653 RAG 知识问答系统（本地单文档知识库 + 构建 + 检索重排 + 问答）
> **定位**：「拿到就能跑」的操作手册。启动 → 上传 → 任务 → 前端入口 → 常见错误排查 → 验证。
> **架构**：**单服务**——FastAPI 一个进程同时提供 API + 托管前端静态文件，无独立前端服务。

## 4. 启动构建 & 查看进度

```bash
curl -X POST http://127.0.0.1:8000/api/tasks/<task_id>/start   # → {"status":"scheduled"}
curl http://127.0.0.1:8000/api/tasks/<task_id>                 # 轮询状态
```

构建步骤（`progress` 逐步回写）：`parsing(20) → cleaning(45) → chunking(60) → embedding(75) → upserting(90) → completed(100)`；失败 → `failed` + `error_message`。

## 5. 前端入口

打开 `http://127.0.0.1:8000/`，5 个视图：

| 视图 | 操作 |
|---|---|

## 6. 常见错误排查

| 现象 | 根因 | 处理 |
|---|---|---|
| `/api/chat` 报错 | Ollama 未启动 / 模型缺失 | `ollama serve`；`ollama pull deepseek-r1:7b` |
| chat 500「bge-reranker 模型路径不存在」 | `RERANKER_MODEL_PATH` 错误 / 模型未下载 | 修正路径（默认 `D:\八维学习\bge-reranker-v2-m3`） |
| 构建失败「模型路径不存在」 | `.env` 的 `BGE_M3_MODEL_PATH` 错误 | 修正路径（默认 `D:\八维学习\bge-m3`） |
| 上传 400「只允许上传 PDF 文件」 | 非 PDF / 文件名非 `.pdf` 结尾 | 换有效 PDF |
| 任务 failed + error_message | 解析/嵌入等步骤异常 | 看 `/api/tasks/{id}` 的 `error_message` 定位 |
| 解析质量差/全空 | MinerU × transformers 版本不匹配 | `python scripts/patch_mineru_tf5.py` 后重建 |
| Qdrant 锁冲突/超时 | `data/qdrant/` 被另一进程占用 | 不同时开 uvicorn 与独立脚本/评测 |
| 问答偏慢 | 精排 CPU 推理 | 有 GPU 时自动 fp16；或调小 `RETRIEVAL_CANDIDATE_K`/`COARSE_TOP_K` |

## 7. 数据位置

| 路径 | 内容 |
|---|---|
| `data/{uuid}-*.pdf` | 上传的 PDF 副本 |
| `data/state.json` | 文档/任务/chunk 状态（JSON） |
| `data/qdrant/` | Qdrant embedded 向量库（`rag_documents` collection，dense+sparse） |

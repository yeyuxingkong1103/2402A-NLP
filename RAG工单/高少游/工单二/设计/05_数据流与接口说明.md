# 数据流与接口说明

> **工单编号**：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化

---

## 一、端到端数据流

### 1.1 离线建库数据流

```
data/招股说明书1.pdf
        │  parse_pdf(with_tables=True, clean_boilerplate=True)
        ▼
List[PageDoc]  {page_no, text(已清洗), tables(已结构化), headings}
        │  build_chunks()
        ▼
List[Chunk]    {content, page, section, ctype, parent, index}
        │  chunks_to_documents()
        ▼
List[Document] {page_content, metadata:{page, section, ctype, parent, chunk_index}}
        │  FAISS.from_documents(get_embeddings())   ← bge-m3:567m，50 条/批
        ▼
vector_db/optimized/{index.faiss, index.pkl}
        │  get_all_documents()
        ▼
BM25 全局语料（进程内构建，供词法检索复用）
```

### 1.2 在线问答数据流（优化链路）

```
question: str
   │  QueryUnderstanding.analyze()
   ▼
QueryAnalysis {core, keywords[], entities[], years[], answer_type, expand_queries[]}
   │  .retrieval_queries  →  [核心问句, 关键词组合, 实体增强]
   ▼
HybridRetriever.retrieve(analysis, k=ANSWER_POOL)
   │    每路：向量 Top-15 + BM25 Top-15 → RRF(k=60) → 合并（同块取各信号最大）
   │    → Reranker.rerank(top_n=max(k*3,12)) → 按 parent 去重
   ▼
List[ScoredDoc] {doc, score, detail}
   │  build_answer(analysis, scored, max_sentences=3)
   │    候选句/表格行 → 逐句打分 → 阈值过滤 + 单页限流 → Top-3
   ▼
AnswerBundle {answer: str, citations: [页码], evidences: [{page,text,score}]}
   │
   ▼
AnswerResult {question, answer, mode, elapsed, sources[], citations[], analysis}
```

## 二、核心接口

### 2.1 解析接口

```python
parse_pdf(pdf_path: str | Path,
          with_tables: bool = True,
          clean_boilerplate: bool = True) -> List[PageDoc]
```

- 入参：PDF 路径；是否解析表格；是否做版式清洗。
- 出参：按页组织的 `PageDoc` 列表。
- 异常：文件不存在抛 `FileNotFoundError`；单页解析异常降级跳过。

### 2.2 分块接口

```python
build_chunks(pdf_path=config.PDF_PATH,
             chunk_size=config.CHUNK_SIZE,
             chunk_overlap=config.CHUNK_OVERLAP) -> List[Chunk]

build_baseline_chunks(pdf_path=config.PDF_PATH, ...) -> List[Chunk]   # 基线复刻
chunks_to_documents(chunks: List[Chunk]) -> List[Document]
```

### 2.3 知识库接口

```python
build_kb(pdf_path, persist_directory=config.DB_DIR,
         force_rebuild=False, baseline=False)          # 构建/重建
load_kb(persist_directory=config.DB_DIR)               # 加载
get_all_documents(persist_directory=config.DB_DIR)     # 取全部块（BM25 语料）
kb_stats(persist_directory=config.DB_DIR) -> dict      # 统计
```

### 2.4 Query 理解接口

```python
QueryUnderstanding.analyze(question: str) -> QueryAnalysis
```

`QueryAnalysis.retrieval_queries -> List[str]`：去重保序的多路查询列表。

### 2.5 检索接口

```python
HybridRetriever.retrieve(analysis: QueryAnalysis, k: int = config.TOP_K) -> List[ScoredDoc]
BaselineRetriever.retrieve(query: str, k: int = config.BASE_TOP_K) -> List[RetrievedDoc]
```

### 2.6 重排接口

```python
Reranker.rerank(analysis: QueryAnalysis,
                candidates: List[tuple[Document, float, float]],   # (文档, 向量相似度, BM25分)
                top_n: int = config.RERANK_TOP_N) -> List[ScoredDoc]
```

`ScoredDoc.detail` 暴露分项得分（vector / bm25 / keyword / numeric / entity），便于调试与展示。

### 2.7 答案合成接口

```python
build_answer(analysis: QueryAnalysis,
             scored: List[ScoredDoc],
             max_sentences: int = config.EXTRACTIVE_MAX_SENTENCES) -> AnswerBundle
```

### 2.8 引擎接口

```python
QAEngine.answer_optimized(question) -> AnswerResult          # 优化链路（最终方案）
QAEngine.answer_baseline(question) -> AnswerResult           # 基线链路
QAEngine.answer_optimized_llm(question) -> AnswerResult      # 消融
QAEngine.answer_baseline_extractive(question) -> AnswerResult # 消融
QAEngine.answer_llm_only(question) -> AnswerResult           # 纯 LLM
```

### 2.9 评估接口

```python
evaluate_keys.KEY_TOKENS: dict[int, list[str]]    # 关键线索表
evaluate_keys.hit(text: str, tokens: list[str]) -> bool
```

## 三、数据结构定义

| 结构 | 字段 |
|---|---|
| `PageDoc` | `page_no:int`、`text:str`、`tables:List[str]`、`headings:List[str]` |
| `Chunk` | `content:str`、`page:int`、`section:str`、`ctype:str`、`parent:str`、`index:int` |
| `QueryAnalysis` | `question`、`core`、`keywords`、`entities`、`years`、`answer_type`、`expand_queries` |
| `ScoredDoc` | `doc:Document`、`score:float`、`detail:dict` |
| `AnswerBundle` | `answer:str`、`citations:List[int]`、`evidences:List[dict]` |
| `AnswerResult` | `question`、`answer`、`mode`、`elapsed`、`sources`、`analysis`、`citations` |

## 四、配置参数流向

```
.env / 环境变量
      │  （load_dotenv）
      ▼
src/config.py  ──►  chunking（CHUNK_SIZE/OVERLAP/MIN_CHUNK_SIZE/USE_PARENT_CHILD）
              ──►  retriever（TOP_K/VECTOR_TOP_K/BM25_TOP_K/RANK_FUSION_K/ANSWER_POOL）
              ──►  reranker（W_VECTOR/W_BM25/W_KEYWORD/W_NUMERIC/W_ENTITY）
              ──►  answer_builder（ANSWER_MODE/EXTRACTIVE_MAX_SENTENCES）
              ──►  knowledge_base（EMBEDDING_MODEL/OLLAMA_BASE_URL/EMBED_BATCH_SIZE）
```

## 五、外部依赖接口

| 依赖 | 接口 | 用途 |
|---|---|---|
| Ollama | `POST /api/embed` | 文本向量化（bge-m3） |
| Ollama | `POST /api/chat`（经 `langchain-ollama`） | 答案生成（基线链路） |
| FAISS | `save_local` / `load_local` / `similarity_search_with_score` | 向量索引持久化与检索 |

> 所有外部依赖均在本地，无公网调用，适合离线部署。

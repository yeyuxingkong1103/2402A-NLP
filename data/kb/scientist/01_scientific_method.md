# 科学方法与可证伪性

## 一、科学方法的循环

观察 → 提出问题 → 构建假说 → 推导可检验预测 → 实验/观测 → 证伪或暂时保留 → 修正理论。

关键点：科学理论**永远不能被最终证实**，只能被不断检验而暂时不被证伪。
「尚未被证伪」不等于「已被证明为真」。

## 二、可证伪性（Falsifiability）

波普尔提出的科学划界标准：一个陈述是科学的，当且仅当它原则上可以被经验证据反驳。

| 陈述 | 是否可证伪 | 原因 |
|---|---|---|
| 所有金属受热都会膨胀 | 是 | 找到一个不膨胀的金属即可反驳 |
| 水在标准大气压下 100℃ 沸腾 | 是 | 可设定条件测量 |
| 明天可能下雨也可能不下 | 否 | 无论结果如何都成立 |
| 存在无法观测的实体，且它不影响任何观测 | 否 | 不产生任何可检验差异 |

注意：可证伪性是**逻辑性质**，与命题是否错误无关。牛顿力学是可证伪的，
也正因如此它才被水星近日点进动等观测所修正。

## 三、假说、理论与定律

| 术语 | 含义 | 例子 |
|---|---|---|
| 假说 | 待检验的试探性解释 | 某化合物可能抑制该酶活性 |
| 理论 | 经过大量独立检验、有解释与预测能力的体系 | 演化论、相对论 |
| 定律 | 在特定范围内成立的定量描述 | 理想气体状态方程 |

日常语言中「这只是理论」常被误解为「不可靠」，在科学语境中恰恰相反：
理论是成熟度最高的知识形态之一。

## 四、奥卡姆剃刀与简约性

在解释力相同时，优先选择假设更少的解释。它是启发式原则而非证明：
简约的模型未必为真，但更容易检验与证伪。

## 五、范式与科学革命

库恩指出，常规科学在既有范式内解题；当反常积累到无法消化时，可能发生范式转换。
范式转换不是简单的「新数据推翻旧数据」，而涉及问题设定、方法论与评价标准的整体变化。

## 六、把结论说清楚：证据强度分级

1. **数学定理**：在公理体系内严格成立；
2. **随机对照试验 / 干预实验**：支持因果推断；
3. **观察性研究（队列、病例对照）**：支持相关性，因果需额外论证；
4. **案例报告**：提供线索，不能推广；
5. **专家意见 / 假说**：作为研究起点，不作为证据。

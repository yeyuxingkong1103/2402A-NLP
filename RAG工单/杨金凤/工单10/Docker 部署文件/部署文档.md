# 金融问答系统部署文档
# 工单编号：人工智能NLP-RAG-金融问答系统部署

## 一、系统架构

- 基础环境：PyTorch 2.5.1 + Python 3.12 + CUDA 12.4
- LLM：Qwen2.5-7B-Instruct（4-bit 量化）
- 嵌入模型：BAAI/bge-small-zh-v1.5
- 重排模型：BAAI/bge-reranker-base
- 向量库：ChromaDB（招股书 + CCF 年报双库）
- 知识图谱：NetworkX（3151 节点 / 2720 边）
- Web 界面：Gradio 5.x

## 二、部署方式

### 方案 A：AutoDL 平台镜像部署（本工单采用）

1. 在 AutoDL 实例中完成环境配置
2. 关机后通过控制台"保存镜像"功能生成自定义镜像 rag-finance-v1
3. 用该镜像启动新实例，数据盘挂载模型和向量库
4. 启动服务：cd /root/autodl-tmp/projects/RAG && python app.py
5. 通过 AutoDL "自定义服务" 映射 6006 端口访问

### 方案 B：标准 Docker 环境部署（本地/云服务器）

#### 1. 构建镜像

    docker build -t rag-finance:1.0 .

#### 2. 运行容器（含数据卷挂载）

    docker run -d \
      --name rag-finance \
      --gpus all \
      -p 6006:6006 \
      -v /root/autodl-tmp/models:/app/models \
      -v /root/autodl-tmp/projects/RAG/2_vector_db:/app/2_vector_db \
      -v /root/autodl-tmp/projects/RAG/ccf_vector_db:/app/ccf_vector_db \
      -v /root/autodl-tmp/projects/RAG/kg_graph.json:/app/kg_graph.json \
      rag-finance:1.0

#### 3. 容器管理

- 查看状态：docker ps
- 查看日志：docker logs rag-finance
- 停止容器：docker stop rag-finance
- 重启容器：docker restart rag-finance
- 删除容器：docker rm -f rag-finance
- 删除镜像：docker rmi rag-finance:1.0

#### 4. 数据持久化

- 模型挂载到 /app/models
- 向量库挂载到 /app/2_vector_db 和 /app/ccf_vector_db
- 知识图谱挂载到 /app/kg_graph.json
- 容器重启后数据不丢失

#### 5. 网络配置

- 端口映射：6006:6006
- 容器间通信：通过 Docker bridge 网络
- 与其他服务（如 RTMP 服务器）通信：使用 Docker 网络别名

## 四、常见问题

Q1：容器启动后 6006 端口无法访问？
A：检查 AutoDL 控制台的"自定义服务"是否映射了 6006 端口。

Q2：报错 "Cannot connect to Docker daemon"？
A：AutoDL 容器无 privileged 权限，用方案 A（保存镜像）替代。

Q3：容器重启后数据丢失？
A：检查数据卷挂载是否正确（-v 参数）。

Q4：显存不足？
A：杀掉其他进程 pkill -9 -f app.py，或换用更小的模型。

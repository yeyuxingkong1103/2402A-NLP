# 工单12 LightRAG金融问答系统 - 部署文档
## 1.本地WSL开发部署方案（实训部署方案）
### 环境清单
1. Windows：Ollama应用，拉取qwen2:7b模型；设置环境变量OLLAMA_HOST=0.0.0.0，重启Ollama。
2. WSL Ubuntu24.04，Python3.12，复用工单5虚拟环境`venv_gongdan5`。
3. 模型文件：BGE向量模型存放路径 /mnt/d/models/bge-base-zh-v1.5

### 部署步骤
1. Windows创建项目文件夹 `C:\Users\陈\Desktop\工单12`，完整目录结构按规范创建。
2. 将两份PDF招股说明书放入`工单12/研发/pdf`。
3. WSL进入项目研发目录，激活虚拟环境：
```bash
source /mnt/c/Users/陈/Desktop/工单5/venv_gongdan5/bin/activate
cd /mnt/c/Users/陈/Desktop/工单12/研发
pip install lightrag ragas pypdf

5. 修改 config_lightrag.py 内 LLM_HOST 为 WSL 网关 IP，指向 Windows Ollama 服务。
6. 执行构建知识库并批量问答：`python3 main_lightrag.py`
7. 执行 RAGAS 评估：`python3 eval_ragas_compare.py`

### 2. 容器化部署扩展方案（可选）

可以基于本项目扩展 Dockerfile，打包 Python 环境，需要把 Ollama 服务单独部署（容器内不跑大模型），容器只运行 LightRAG 检索引擎。

> 
> 注意：容器部署需要配置网络访问 Windows / 宿主机 Ollama 服务，挂载 volume 持久化 lightrag_cache 知识库。

## 3. 部署验证

1. WSL 内 curl 测试连通性 `curl http://10.255.255.254:11434`，返回 Ollama is running 代表 LLM 服务连通正常。
2. 运行 main_lightrag.py，无报错，生成 lightrag_cache 文件夹，代表知识库构建成功。
3. 运行评估脚本，输出 ragas_compare_result.json，代表评估模块部署完成。

## 4. 运维说明

1. 新增文档：直接调用 rag.insert () 增量插入 PDF，无需删除缓存重建。
2. 清空知识库：删除 lightrag_cache 文件夹，再次运行 main_lightrag.py 会全量重新构建。
3. 故障排查：
   - LLM 连接失败：检查 Ollama 是否启动、OLLAMA_HOST 环境变量、IP 地址是否正确、防火墙是否拦截 11434 端口。
   - PDF 读取失败：检查 pdf 文件夹文件权限、文件名中文编码。

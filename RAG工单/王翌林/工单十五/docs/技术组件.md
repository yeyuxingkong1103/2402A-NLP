# 工单十五：技术组件

## 1. 核心代码组件

| 模块 | 文件 | 职责 | 优化点 |
|------|------|------|--------|
| 查询理解 | [query_router.py](../src/query_router.py) | 识别视觉引用（图号/页码/部件），路由文本/图文通道 | **新增**：detect_figure_refs 抽取图3、第11页、部件[13,12]；查询重写注入图描述 |
| 图像知识库 | [image_knowledge.py](../src/image_knowledge.py) | 图号↔结构化描述（部件/位置/流向）绑定 | **新增**：图3 的部件 10/11/12/13/14 关系与物料流向 |
| 混合检索器 | [retriever.py](../src/retriever.py) | BM25+向量→RRF→重排；跨模态增强召回 | **优化**：检测视觉引用时取图描述增强查询向量召回 |
| RAG 引擎 | [rag_engine.py](../src/rag_engine.py) | 文本/跨模态双路径问答 | **优化**：跨模态 Prompt 模板，指示 LLM 结合图纸描述推理 |
| VLM 引擎 | [vlm_engine.py](../src/vlm_engine.py) | Qwen2-VL OCR + 图纸结构化解析 | 复用：parse_figure 输出部件/位置/流向 |
| 向量库 | [vector_store.py](../src/vector_store.py) | Milvus collection=rag_v15_chunks | 独立 collection，与工单十四隔离 |
| LLM 客户端 | [llm_client.py](../src/llm_client.py) | DeepSeek 调用，temperature=0.0 稳定输出 | 复用 |
| 嵌入 | [embedding.py](../src/embedding.py) | bge-m3，CPU/batch=8/max_seq=512 | 复用（防 OOM） |
| 分块 | [chunker.py](../src/chunker.py) | 按页+段落分块，记录 img_refs | 新增图号引用记录 |

## 2. 模型组件

## 3. 外部配置项（.env）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| CROSSMODAL_ENABLE | true | 跨模态检索开关 |
| RRF_K | 60 | RRF 融合常数 |
| USE_RERANK / USE_BM25 | true | 重排/BM25 开关 |
| VEC_TOP_K / BM25_TOP_K | 30 | 各路召回上限 |
| FINAL_TOP_K | 5 | 最终返回片段数 |
| RAG_EMBED_DEVICE | cpu | 嵌入设备（防 GPU OOM） |
| APP_PORT_V15 / STREAMLIT_PORT_V15 | 8015 / 8515 | 服务端口 |

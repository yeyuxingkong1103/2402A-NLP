# 工单18 实现文档质量评估Skill并集成至智能体工作流｜部署文档
##1.实训部署步骤
1. WSL，激活venv_gongdan5，安装依赖包 pypdf python‑docx simhash python‑magic‑bin libmagic；
2. 将document_quality_assessment完整Skill目录部署；
3. 在RAGFlow项目注册Skill技能；
4. 集成agent_workflow.py：新增document_ingestion_workflow智能体工作流；
5. 集成api_endpoint.py：新增POST `/v1/document/quality‑inspection`API端点；
6. 单元测试：`python3 test_skill.py`，传入测试文档目录，输出质检报告；
7. 调用API做完整功能验证。

##2.RAGFlow集成说明
1. Skill注册：把document_quality_assessment注册到Agent技能库；元数据、指令层、资源脚本全部加载；
2. 工作流注册：document_ingestion_workflow作为文档入库前置工作流；上传文档后优先执行质量评估Skill；
3. API挂载：把api_endpoint接口挂载到RAGFlow api‑server服务路由。

##3.运维故障排查
1. PDF页面解析异常：文档损坏，会打上Parse_Failed标签；
2. magic库报错：确认系统安装sudo apt install libmagic1；
3. 大批量文档执行慢：开启进度打印，观察进度；可扩展中断恢复；
4. SimHash相似度结果不理想：调整simhash_sim_threshold阈值。

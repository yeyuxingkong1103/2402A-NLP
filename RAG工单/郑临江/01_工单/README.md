# 工单 01：基于 PDF 文档的问答系统

**工单编号**：人工智能NLP-RAG-基于PDF文档的问答系统

## 一、项目简介

基于大语言模型（LLM）+ 检索增强生成（RAG）技术，针对《招股说明书1.pdf》
（武汉兴图新科电子股份有限公司）构建问答系统。系统能够解析 PDF 文档、
将内容向量化入库，检索与问题最相关的文本块，并生成准确、简洁的回答。

## 二、系统架构

```
用户问题 ──▶ Query 理解 ──▶ 向量检索(TF-IDF) ──▶ 召回 Top-K 文本块
                                              │
             答案 ◀──────── LLM 生成 ◀──────── 上下文拼装
```

## 三、功能

1. **文档解析**：解析 PDF 并提取文字内容；
2. **向量检索**：TF-IDF 向量化 + 余弦相似度召回；
3. **答案生成**：结合 LLM 生成回答（支持 OpenAI 兼容接口，未配置时降级为检索式回答）；
4. **用户体验**：交互式问答界面，支持批量演示 10 个验收问题；
5. **对比分析**：对比 RAG 回答与仅使用 LLM 回答的结果。

## 四、目录结构

```
01_工单/
├── app.py           # 主程序（交互 + 批量演示）
├── config.py        # 配置：数据路径、问题列表、参数
├── pdf_parser.py    # PDF 解析与分块
├── retriever.py     # TF-IDF 向量检索
├── llm.py           # LLM 调用封装
├── requirements.txt # 依赖
└── README.md
```

## 五、环境与运行

```bash
pip install -r requirements.txt

# 交互式问答
python app.py

# 批量运行工单 10 个问题，对比 RAG 与仅 LLM 的回答
python app.py --test
```

> 数据路径在 `config.py` 的 `ATTACH_DIR` 中配置（默认 `D:\软件\QQ\data\RAG 工单\附件`）。

## 六、验收对照

- 检索质量：基于 PDF 内容返回答案，响应时间 ≤ 3 秒；
- 检索问题：覆盖工单要求的 10 个问题（见 `config.py`）；
- 代码注释含工单编号：人工智能NLP-RAG-基于PDF文档的问答系统。

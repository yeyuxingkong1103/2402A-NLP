## 通用动作（每张都一样，后面不再重复）

1. 鼠标**点一下**要拍的那个窗口，让它成为*活动窗口*（标题栏变高亮）
2. 按 **`Alt + PrtSc`** —— 只截这个窗口，自带标题栏边框
3. 打开「画图」→ **`Ctrl + V`**
4. **`Ctrl + S`** → 存成 PNG → 放进 `docs/演示截图/`，文件名照每步给的填

> ⚠️ **别用 `Win + PrtSc`**：整屏会把桌面文件夹名和浏览器其他标签一起拍进去。
> 存档目录已建好：`docs/演示截图/`（`.gitignore` 已白名单放行该目录的 PNG）。

**同一句问题，只换公司名**，两家给出完全不同的数字 —— 这是"不做路由就会张冠李戴"

# 第 11 张 · `工单3-11-表格解析证据-Milvus.png`

证明表格是**以 Markdown 表格形态**进库的（不是一坨散文字）。

1. 终端跑：
   ```bash
   $PY - <<'EOF'
   import sys; sys.path.insert(0, '.')
   from app.core.vectorstore import VectorStore
   s = VectorStore()
   rows = s.client.query(collection_name=s.collection,
       filter='doc_name == "招股说明书2.pdf" and page_no == 21',
       output_fields=['chunk_index','chunk_type','page_label','content'], limit=50)
   for r in sorted(rows, key=lambda x: x['chunk_index']):
       print('---', r['chunk_index'], r['chunk_type'], 'p' + r['page_label'])
       print(r['content'][:220])
   EOF
   ```
2. 应看到第 21 页 4 个块，其中 `table` 类型的两块标题是
   `**四、本次发行情况**` 与 `**五、募集资金用途**`，且后者带全部 5 个项目行
3. **拍终端窗口**

# 工单6 - RAG混合检索系统｜设计文档
## 1.项目概述
本项目实现基于招股说明书PDF文档的RAG检索系统，支持向量检索、BM25关键词全文检索、RRF倒数排名混合检索三种检索模式，对比不同检索策略的召回效果。前端使用Flask搭建简易网页，后端基于Milvus向量数据库、Sentence-Transformers向量模型、BM25检索库实现。

## 2.需求分析
1. 支持读取PDF招股说明书，文本分段处理。
2. 实现三种检索模式：向量检索、BM25全文检索、RRF混合检索。
3. Web网页端提供下拉框切换检索模式，输入问题提交检索。
4. 返回检索召回的文档片段，用于对比不同检索策略差异。

## 3.总体架构
PDF 文档 → 文本解析 → 文本分块
↓
├─向量分支：文本向量化 → Milvus 向量库存储 → 向量相似度检索
└─关键词分支：文本分词 → BM25 索引构建 → 关键词检索
↓
RRF 倒数排名融合算法（混合模式）
↓
Flask Web 前端展示结果

## 4.模块设计
1. **文档解析模块**：使用PyMuPDF读取PDF，按换行切割文本，过滤过短文本，生成文本块。
2. **向量嵌入模块**：采用all-MiniLM-L6-v2轻量句向量模型，将文本转为384维向量。
3. **向量库模块**：Milvus存储向量与原文文本，使用IVF_FLAT索引，L2距离计算相似度。
4. **BM25检索模块**：rank_bm25库构建词表，基于词频进行关键词相关性检索。
5. **RRF融合模块**：倒数排名融合算法，合并向量检索、BM25检索的排序结果，重新打分排序。
6. **Web交互模块**：Flask后端，内嵌HTML页面，提供下拉选择、提问、结果展示功能。

## 5.数据库设计
Milvus集合 `rag_demo`
|字段|类型|说明|
| ---- | ---- | ---- |
|id|INT64|主键，自动生成|
|vector|FLOAT_VECTOR(384)|文本向量|
|text|VARCHAR|原始文本片段|

## 6.接口设计
- `GET /`：首页，返回网页前端
- `POST /api/query`：检索接口，入参：query(问题)、search_type(检索模式)；返回检索文本片段

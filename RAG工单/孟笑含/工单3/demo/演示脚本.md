# 演示脚本 — 基于 PDF 文档的问答系统

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统

## 演示目标

完整展示 RAG 问答系统的功能与操作流程。

## 演示时长

约 5 分钟。

## 演示流程

### 第 1 步：启动系统（30s）

export HF_ENDPOINT=https://hf-mirror.com
python3 app.py

展示初始化日志：

- PDF 解析：548 页，477 个表格
- 文本切分：2010 块
- 表格块加入：455 块
- 模型加载完成，向量维度：768
- 索引构建完成：2465 块
- 系统初始化完成

### 第 2 步：打开 Web 界面（15s）

浏览器访问 http://127.0.0.1:7860，展示：

- 标题：基于 PDF 文档的问答系统
- 工单编号
- 三个 Tab：问答 / 文档管理 / 评估报告

### 第 3 步：问答演示（2min）

依次点击 4 个示例问题：

1. 注册资本
   - 输入：武汉兴图新科电子股份有限公司注册资本是多少？
   - 显示：参考来源 + 响应时间

2. 技术标准
   - 输入：武汉兴图新科电子股份有限公司参与制定了哪个技术标准？
   - 显示：某视频技术规范1.0

3. 法定代表人
   - 输入：武汉兴图新科电子股份有限公司法定代表人是谁？
   - 显示：程家明

4. 一等奖工程
   - 输入：武汉兴图新科电子股份有限公司参与的哪个工程荣获了国家科技进步一等奖？
   - 显示：C4ISR 系统

### 第 4 步：评估报告 Tab（1min）

点击「运行批量评估」，展示 RAG vs 纯 LLM 对比表格。

### 第 5 步：展示核心代码（1min）

打开 rag_qa_system.py，展示：

- __init__：PDF 解析 + 索引构建
- answer：检索 + 生成 + 评估
- batch_evaluate：对比评估

## 演示要点

1. 响应时间（0.01~0.02s）远小于 3s 要求
2. PDF 解析包含表格（477 个）
3. 向量模型 bge-base 768 维
4. 评估对比满足工单要求

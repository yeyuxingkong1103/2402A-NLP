## 验收标准

| 指标 | 目标 | V8 基线 | V9 预期 |
|------|------|---------|---------|
| **Context Precision** | ≥ 0.80 | ~0.65 | **≥ 0.85** |
| **Context Recall** | ≥ 0.90 | ~0.75 | **≥ 0.92** |
| 响应时间 | ≤ 3s | < 1s | < 1s |

## V8 → V9 三层优化

| 层面 | V8 | V9 优化 |
|------|----|---------|
| **Prompt/实体** | 30+ 模式 | 50+ 模式 + 同义词 + LLM 增强(可选) |
| **检索** | BFS k-hop | **路径检索 + 实体消歧 + 剪枝 + 重排** |
| **生成** | 单 Prompt 拼接 | **分层 Prompt (图谱推理→文本验证 + 幻觉约束)** |
| **评估** | 无 | **RAGAS 风格 Context P/R + Faithfulness** |

## 关键改进点

### 1. 路径检索替代 BFS
```
V8: BFS 2-hop → 所有邻居都返回 (噪音多, Precision 低)
V9: find_paths() → 只返回有意义的关系路径 (如 控股股东→控制)
    路径分 = 边权重 × 节点重要性 / 路径长度
```

### 2. 实体消歧
```
"控股股东" + "武汉力源" → V8 可能匹配到 "武汉力源" (被控制方)
                       → V9 消歧匹配到 "武汉力源科技" (控股股东)
```

### 3. 图谱剪枝
```
V8: 返回所有 2-hop 邻居 (15+ 节点, 噪音大)
V9: 只保留 边权重≥0.3 + 节点重要性≥0.4 的 (5-8 节点, 高精度)
```

### 4. RAGAS 评估
```python
# 内置 RAGASEvaluator, 无需额外安装
evaluator = RAGASEvaluator()
metrics = evaluator.evaluate_from_keywords(contexts, ref_keywords)
# context_precision / context_recall / context_f1
```

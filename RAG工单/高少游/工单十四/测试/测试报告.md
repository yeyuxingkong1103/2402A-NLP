## 1. 测试概述

本报告记录对系统功能与问答准确性的测试结果。测试数据为工单指定的 6 道选择题，源文档为 `CN100342976C.pdf`（静电除尘器发明专利，8 页，纯图片型 PDF，无文本层）。

测试口径：

- **准确率** = 预测选项字母 == 标准答案的题目占比，目标 100%；
- **溯源完整率** = 作答命中可回溯知识块（证据非空）的题目占比；
- **响应时间** = 单问端到端耗时（改写 + 理解 + 检索 + 重排 + 作答），目标 ≤ 3s。

复现命令：

```bash
python build_kb.py
python run_demo.py
python evaluate_mcq.py --strategies vector,fulltext,hybrid
```

## 6. 缺陷修复验证

工单指出 RAGFlow 常规流水线在低质量工业 PDF 上存在两类缺陷，本系统逐项验证修复效果：

| 缺陷 | 修复措施 | 验证结论 |
|---|---|---|
| 图文信息丢失 | 新增 OCR 通道，把整页位图还原为可检索文本 | 15 个正文块成功进入知识库，第 1、2、6 题依赖正文证据作答通过 |
| 图文关联错误 | 附图语义解析，建立「部件编号 ↔ 部件名 ↔ 空间关系」 | 2 个附图语义块生成，第 3、4、5 题依赖附图证据作答通过 |
| 配气带孔盘编号混淆 | 按 x 坐标还原 6″/6′/6 次序 | 第 4、5 题正确区分三个盘 |
| 「现有技术 vs 本发明」干扰 | 发明语境加成 + 现有技术降权 | 第 2 题正确选中本发明特征项 C |
| 响应超 3s | 共享编码器 + 合并批量编码 + 缓存 | 冷启动平均 2.34s，热缓存 0.02s |

# 5. 接口说明（模块级函数/类方法）

> 本系统为 Streamlit 单体应用，模块间以**Python 函数调用**交互（非 HTTP）。
> 下列签名与源码一致；`_` 开头为内部函数，一般不直接调用。

## 5.1 RAG 主链（rag_chain.py）

### RAGResponse（dataclass，应答结果）

| 字段 | 类型 | 含义 |
|------|------|------|
| mode | str | `emergency` / `clarify` / `no_content` / `answer` |
| query | str | 实际用于检索的问句（改写后） |
| message | str | 急症/澄清/无内容模式下的直接文案 |
| intent | str | 意图标签（knowledge / personal 等） |
| options | list | 澄清模式的可点选项 |
| citations | list | 引用命中片段 `{text, source, page, score}` |
| prompt | str | answer 模式下交给 LLM 的完整 prompt |
| trace | str | 检索详情（意图/阈值/每条分数） |

| 方法 | 入参 | 出参 |
|------|------|------|
| `RAGChain(role_manager)` | RoleManager 实例 | 链对象（内含 ChatOpenAI，timeout=30/max_retries=0） |
| `.prepare(role_id, query, embedder, bm25, short_memory=None, long_memory=None, user_id="default", clarified=False, history=None)` | 角色 id、用户问题、向量化模型、BM25、双记忆、用户 id、是否已澄清、历史 | RAGResponse；异常全包，绝不抛到 UI |
| `.stream_answer(role_id, prompt)` | 角色 id、answer prompt | 生成器，yield 文本分片（流式） |
| `.general_tips(role_id, query)` | 角色 id、问题 | str，无命中时的生活方式建议（timeout=15） |

## 5.2 检索层

### retrieval.py

| 函数 | 入参 | 出参 |
|------|------|------|
| `load_records(limit=6000)` | 拉取上限 | `[{text, source, page}]`，供 BM25/引用使用 |
| `hybrid_search(query, bm25, embedder, top_k=None)` | 问句、BM25Index、embedder、路数 | RRF 融合后的候选 `[{text,source,page,vec,rrf}]` |
| `multi_search(role, query, bm25, embedder)` | 角色 dict、问句、BM25、embedder | 多路+角色偏向去重+禁用术语过滤后的候选列表 |

### reranker.py

| 函数 | 入参 | 出参 |
|------|------|------|
| `rerank(query, candidates, top_k)` | 问句、候选（先按 vec 截 12）、保留条数 | 重排并截断的候选，新增 `score`(0-1) |
| `threshold()` | — | 当前阈值（模型可用 0.30，否则 0.45） |
| `model_loaded()` | — | bool，非阻塞探活（侧栏用） |
| `is_ready()` | — | bool，会触发加载（预热线程用） |

### bm25_index.py：BM25Index

| 方法 | 入参 | 出参 |
|------|------|------|
| `.build(records)` | `[{text,source,page}]` | None（建进程内索引） |
| `.search(query, top_k)` | 问句、条数 | `[(记录下标, BM25分)]` |
| `.records` | 属性 | 原始片段列表 |
| `.add(new_records)` | 新片段 | None（重建索引） |

### citation.py

| 函数 | 入参 | 出参 |
|------|------|------|
| `highlight(text, query)` | 片段、问句 | 命中句加 `<mark>` 的 HTML（已转义） |
| `label(item, rank)` | 片段、序号 | expander 标题字符串 |
| `card(item, query)` | 片段、问句 | 引用卡片 HTML |
| `trace(query, ranked, limit, question_type="")` | 问句、候选、阈值、意图 | 检索详情纯文本 |

## 5.3 意图与查询处理

### intent.py

| 函数 | 出参 |
|------|------|
| `detect_intent(query)` | 意图常量 `KNOWLEDGE` / `PERSONAL`（另有不完整/急症在链上判定） |
| `is_drug_question(query)` / `is_list_question(query)` / `is_multi_route(query)` | bool |
| `multi_queries(query)` | 多路口径问句 list（用药拆五类/饮食拆盐脂酒糖甘草；无关返回 []） |

### query_tools.py

| 函数 | 入参 | 出参 |
|------|------|------|
| `needs_clarify(query)` | 问句 | bool，断句/缺宾语 |
| `incomplete_options(query)` | 问句 | 追问选项 list |
| `rewrite_query(llm, query, history, force_join)` | LLM、问句、历史、是否强制拼接 | 补全后的独立检索问句 str |
| `clarify_options(llm, query, snippets)` | LLM、问句、候选片段 | 2-3 个澄清选项 |
| `role_queries(role, query)` | 角色、问句 | 角色偏向扩展问句 list |
| `role_filter(role, candidates)` | 角色、候选 | 移除含 banned_terms 片段后的列表 |
| `anchor_query(query)` | 问句 | 情绪/症状句补"高血压"锚点，其余原样返回 |

## 5.4 记忆与会话

### memory.py：ShortTermMemory（Redis）

| 方法 | 入参 | 出参 |
|------|------|------|
| `ShortTermMemory(ttl_seconds=1800)` | TTL 秒 | 对象；Redis 不可用时由上层降级为 None |
| `.add(session_id, role, content)` | 会话 id、角色、消息内容 | None（超窗裁剪+续期） |
| `.get_history(session_id)` | 会话 id | LangChain 消息格式历史 list |
| `.clear(session_id)` | 会话 id | None |

### memory.py：LongTermMemory（Milvus，用户×角色×会话三维隔离）

| 方法 | 入参 | 出参 |
|------|------|------|
| `LongTermMemory(embedder)` | 向量化模型（自动建 collection） | 对象 |
| `is_personal(text)`（模块级） | 本轮用户发言 | bool：是否个人陈述（医疗词+人称/时间词，或数值+单位） |
| `.remember(llm, user_id, role_id, session_id, turn)` | LLM、三维标识、本轮 [{role,content}×2] | bool：是否更新（旧摘要+本轮→LLM 增量合并，主键删旧插新） |
| `.recall_by_role(user_id, role_id, limit=20)` | 用户 id、角色 id | 同角色全部会话摘要 list（updated_at 倒序） |
| `.delete_session(user_id, role_id, session_id)` | 三维标识 | None（删会话级联清理） |

### chat_session.py：SessionStore（st.session_state）

| 方法 | 说明 |
|------|------|
| `.list(role_id)` / `.current(role_id)` | 某角色会话列表（0 为当前）/ 取当前（无则新建） |
| `.new(role_id)` / `.switch(role_id, index)` / `.delete(role_id, index)` | 新建/切换/删除（删空自动补空会话） |
| `.auto_title(session)` | 用首轮问题生成标题 |
| `.log_bad_case(payload)` | 差评样本落 data/feedback.jsonl |

## 5.5 入库与 PDF 解析

### ingestion.py

| 函数 | 入参 | 出参 |
|------|------|------|
| `get_embedder()` | — | 单例 SentenceTransformer（BGE-m3，本地路径） |
| `split_pages(text)` | 含 `[第N页]` 标记的文本 | `[(页码, 正文)]` |
| `chunk_pages(pages, source, chunk_size=55, overlap=8)` | 分页结果、来源名 | `[{text, source, page}]` |
| `embed_and_insert(records, collection=None)` | 块记录 | int 插入条数 |
| `reset_collection(collection=None)` | 集合名 | bool，是否删除成功（重建用） |

### pdf_parser.py

| 函数 | 出参 |
|------|------|
| `parse_pdf(path)` | `(全文含[第N页]标记, 统计dict{headers,footers,watermarks,tables})` |
| `clean_text(text)` | 去孤立页码/压缩空行后的文本 |
| `parse_and_clean(path)` | 清洗后文本（直接供入库） |

### image_ocr.py（可选，未装 paddleocr 自动降级）

| 函数 | 入参 | 出参 |
|------|------|------|
| `ocr_available()` | — | bool，paddleocr 是否可导入 |
| `ocr_image(img_bytes)` | 图片字节（jpg/png） | str 识别文本（已过滤 <2 字噪声行；失败/未装返回空串） |

> 内部：模型单例懒加载（首次调用约 3s 初始化）；已设 `enable_mkldnn=False`
> 规避 paddle 3.4.x PIR 崩溃。UI 层按"文件名:大小"指纹缓存，rerun 不重复识别。

## 5.6 角色、提示词、安全

### role.py：RoleManager

| 方法 | 出参 |
|------|------|
| `.list_roles()` | 角色简要 list（UI 下拉） |
| `.get(role_id)` | 角色完整 dict |
| `.get_role_name(role_id)` | 角色中文名 str |
| `.build_system_prompt(role_id)` | 完整 system prompt（人设+意图约束+禁令+护栏） |
| `.refresh()` | None，重新加载 roles.json |

### prompts.py（均返回拼好的字符串）

`intent_mode(intent)`、`format_history(history, limit=8)`、
`format_summary(recalls)`、`answer_prompt(role_prompt, kb_text, history, summary, query, intent)`、
`rewrite_prompt(history_text, query)`、`clarify_prompt(query, snippets)`、
`no_content_prompt(role_name, query)`。

### safety.py

| 函数 | 入参 | 出参 |
|------|------|------|
| `emergency_hits(text)` | 文本 | 命中的急症词 list（空=非急症） |
| `unverified_drugs(answer, kb_text)` | 回答、知识库原文 | 资料中没出现的药名 list |
| `drug_warning(drugs)` | 药名 list | 红色警告文案 str |
| `banned_hits(answer, banned)` | 回答、禁用词 list | 命中的越界术语 list |

## 5.7 基础配置（config.py）

| 对象/函数 | 说明 |
|-----------|------|
| `settings` | 全局 dataclass，从 .env 读取（模型路径、Milvus/Redis 连接、阈值等） |
| `setup_logging(level="INFO")` | 初始化控制台 + logs/app.log 按天滚动日志，入口调用一次 |
| `validate()` | 启动校验 DEEPSEEK_API_KEY，缺失直接 SystemExit 并提示 |

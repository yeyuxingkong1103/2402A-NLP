> 完成时间：2026 年 1 月

## 一、任务背景

**问题**：IMDR 数据集中大量文本-图像混合问题，RAGFlow 原检索流程存在两个典型故障：
- 故障1（检索无关）：只靠泛文本关键词检索，遗漏关键图纸页
- 故障2（图文割裂）：无法将编号13、位置关系与图像特征关联

**目标**：6 个测试问题精度 ≥80%

## 二、RAGFlow 多模态检索架构分析（任务一）

### 2.2 原有瓶颈

| 瓶颈 | 原因 |
|------|------|
| 视觉引用未识别 | Query 中图3、编号13被当作普通词 |
| 图像块权重低 | 图像描述文本短，向量相似度低 |
| 无跨模态融合 | 文本和图像检索独立 |

## 三、跨模态检索优化（任务二）

### 3.1 优化架构

用户问题
  → 优化1：视觉引用解析（图/页/编号/部件）
  → 优化2：双路查询（原始 + 增强）
  → 优化3：RRF 融合
  → 优化4：视觉页加权（×2.0）
  → Top-K 结果

### 3.2 核心代码（cross_modal_retriever.py）

def extract_visual_references(self, query):
    refs = {}
    m = re.search(r图\s*(\d+), query)
    if m: refs[figure] = int(m.group(1))
    m = re.search(r第\s*(\d+)\s*页, query)
    if m: refs[page] = int(m.group(1))
    ids = re.findall(r编号\s*(\d+), query)
    parts = re.findall(r部件\s*(\d+), query)
    refs[component_ids] = list(set([int(i) for i in ids + parts]))
    return refs

## 六、技术总结

### 6.1 三大优化点

1. 视觉引用解析：自动识别图N、第N页、编号N、部件N
2. 增强查询：将视觉引用拼接到检索 query
3. 视觉页加权：命中页 rrf_score × 2.0

### 6.2 关键经验

- 图像型 PDF 需要图像描述文本（Qwen2.5-VL 生成）
- 第 11 页（图 3）人工增强：补充部件位置关系
- 视觉引用必须显式识别 + 加权

# 工单16 调试与微调专用视觉语言模型｜优化文档
##1.原始基线VLM存在问题
1. 工业专业术语输出错误，部件编号识别错误；
2. 图纸推理能力弱：部件位置、机构运动原理回答与图纸不符；
3. 通用预训练VLM缺少工业专利图纸领域知识。

##2.训练阶段调优方向
### 数据集层面
1. 过滤脏样本：问答对答案模糊、图片损坏、OCR识别乱码样本删除；
2. 增强样本：增加图纸部件位置、机构运动原理类样本占比；
3. 图像质量：低分辨率图纸做放大预处理。

### LoRA超参调优
1. LoRA‑r：r太小拟合不足，r过大容易过拟合；常用r=8、16；
2. 学习率：VLM LoRA常用 1e‑4 ~ 3e‑4；学习率太高loss震荡、NaN；太低收敛慢；
3. epoch：小数据集epoch不要过大，防止过拟合；本工单至少1epoch；
4. 图像预处理：**必须严格沿用基座VLM自带image_processor，不要手动修改图片归一化、尺寸参数**。

### 评估层面优化
1. 不依赖BLEU/ROUGE做唯一判断；通用指标只作为参考；
2. 重点关注两个工业专项指标：专业术语准确率、图纸推理正确率；
3. 人工分析失败case，区分：数据集问题 / 模型能力问题 / 超参问题。

##3.故障定位
1. loss不下降：学习率异常、数据集格式错误、image_processor不匹配；
2. loss出现NaN：学习率过高，梯度爆炸；
3. 通用指标涨，工业图纸指标不涨：训练集图纸推理类样本数量不足。

##4.后续进阶优化
1. 扩充IMDR工业图文训练样本数量；
2. 增加数据增强：图纸图片亮度、对比度增强；
3. 多轮对话样本扩充；
4. 训练完成后把LoRA适配器合并进VLM，部署到RAGFlow中使用。

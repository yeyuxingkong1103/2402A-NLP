## 3. 功能测试结果

### 3.1 用例与结果

| 用例 | 场景 | 传统 RAG | LightRAG |
|---|---|---|---|
| TC-01 | 首轮独立问句（力源信息发行股数/占比） | PASS | PASS |
| TC-02 | 指代消解（「它」→ 力源信息，募投项目清单） | PASS | PASS |
| TC-03 | 跨文档切换（力源信息 → 兴图新科，军用领域收入） | PASS | PASS |
| TC-04 | 指代消解 + 跨轮记忆（获奖工程） | PASS | PASS |
| TC-05 | 指代消解（法定代表人） | PASS | PASS |
| TC-06 | 多语言（英文提问，中文作答） | PASS | PASS |
| TC-07 | 容错（空输入 / 乱码输入） | PASS | PASS |
| TC-08 | 容错（域外问题应拒答） | **FAIL** | **PASS** |
| TC-09 | 稳定性（连续 50 轮问答） | PASS | PASS |
| TC-10 | 交互（重置会话后再提问） | PASS | PASS |
| **通过率** | | **9/10 = 90%** | **10/10 = 100%** |

### 3.2 关键用例说明

- **TC-01/TC-02**：`本次发行股数为1,670万股，占发行后总股本的比例为25.04%。`；募投项目清单：`仓储及物流中心、研发中心、电子商务平台、扩充产品种类和数量、其他与主营业务相关的营运资金`。
- **TC-03/TC-04**：多轮改写正确完成指代消解（「它」→ 对应公司），跨文档切换无“串味”；TC-04 命中“某情报、指挥、控制与通信网络一体化工程（C4ISR）荣获国家科技进步一等奖”。
- **TC-05**：`法定代表人为程家明。`
- **TC-06**：英文提问 `What is the registered capital of Xingtu Xinke?` → 改写为中文检索式 → `注册资本为5,520.00万元。`
- **TC-07**：空/乱码输入返回拒答文案（“未在……知识库中检索到与该问题相关的内容，请尝试换一种问法”）。
- **TC-08（差异用例）**：域外问题“今天天气如何？适合去爬山吗？”
  - 传统 RAG：错误地返回了招股说明书中“适合中国市场”的无关片段 → **FAIL**；
  - LightRAG：正确拒答 → **PASS**。
  原因：LightRAG 图结构召回对“无实体/无主题命中”的域外问句自然产生空候选，从而触发拒答；这体现了图结构检索在**域外鲁棒性**上的增益。
- **TC-09**：连续 50 轮问答无异常，平均 0.15s，最大约 2.2s（含一次冷启动）。
- **TC-10**：会话重置前 1 轮 → 重置后 0 轮，状态清理正确。

## 4. 检索结果对比（摘要）

16 道验收问题逐题对照详见《检索结果对比.md》。要点：

- **完全命中并给出结构化答案**：Q1（发行股数/占比）、Q2（募投项目清单）、Q3/Q4（关联方）、Q95（技术标准）、Q543（注册资本）、Q531（法定代表人）、Q207（补充流动资金金额）、Q795（获奖工程）等；
- **表格/图形类**：Q5（组织结构图枚举）、Q260/Q33（军用领域收入及占比序列）、Q6（IC 市场增长率）由表格/图形语义块召回；
- **上下游行业**：Q34（上游企业）、Q793（下游行业）经领域关系与行业实体扩展召回；
- **两系统差异**：多数题目答案一致（同一抽取器）；LightRAG 在 Q260（军用领域收入序列表）、Q4（关联方清单）、Q793（下游行业）等**多实体/表格型**问题上因图结构扩展召回更完整而略优；RAG 在 Q2、Q5 上因候选池更“平铺”而略优。

## 5. RAGAS 评估结果（摘要）

| 系统 | 忠实度 | 答案相关性 | 上下文精确率 | 上下文召回率 | 答案正确性 | 综合 |
|---|---|---|---|---|---|---|
| 传统 RAG | 1.0000 | 0.8182 | 0.8550 | 0.9531 | 0.8857 | 0.9024 |
| LightRAG | 1.0000 | 0.8183 | 0.8646 | 0.9531 | 0.8857 | **0.9043** |

逐题：LightRAG 更优 4 题、RAG 更优 3 题、持平 9 题。两系统**忠实度均 1.0000**（答案均可溯源），上下文召回率均 0.9531，LightRAG 上下文精确率提升 +0.0096。

---

## 6. 结论

1. **功能完备**：10 项功能/容错/多语言/稳定性用例，LightRAG 全部通过（10/10），传统 RAG 9/10（域外拒答用例未通过）；
2. **检索有效**：16 道验收问题均给出可溯源的正确答案，RAGAS 综合分 RAG 0.9024 / LightRAG 0.9043；
3. **容错增强**：LightRAG 凭借图结构召回对域外问句具备天然拒答能力，鲁棒性优于传统 RAG；
4. **性能达标**：响应时间满足 ≤3s（详见《性能测试报告.md》）。

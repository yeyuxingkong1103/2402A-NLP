## 一、系统简介

本系统面向《招股说明书1.pdf》（548 页）的智能问答：
输入自然语言问题（中文或英文），系统从招股说明书中检索证据，
由本机大模型生成**带页码引用的回答**，全程离线运行、不下载任何模型。

## 二、启动系统

### 2.1 前置检查

1. **Ollama 服务在运行**（本机 `qwen2.5:3b` 已下载）：

   ```bash
   ollama list        # 应能看到 qwen2.5:3b
   ```

   若未运行，先执行 `ollama serve`（或在 Windows 托盘启动 Ollama）。

2. **知识库已建立**（首次使用或数据重置后执行一次）：

   ```bash
   cd D:\xinzg6\zy-gq\工单2
   python build_index.py
   ```

   预期输出末尾：`建库完成：{... 'points': 1995} | 总用时 ~72s`

### 2.2 启动界面

```bash
cd D:\xinzg6\zy-gq\工单2
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`。首次进入建议点击左侧 **"预热模型"**
（加载约 26 秒，避免第一题的冷启动等待）。

## 三、界面功能

### 3.1 语言切换

左侧栏顶部 **Language / 语言**：可选 **中文** 或 **English**，
界面文字与回答语言随之切换（英文提问自动用英文作答提示词）。

### 3.2 问答页（💬 问答）

1. 在输入框键入问题，例如：
   - `武汉兴图新科电子股份有限公司注册资本是多少？`
   - `报告期内，公司来自军用领域的收入分别是多少？`
   - `What is the registered capital of the company?`
2. 点击 **提问**（或点击下方示例问题快速填入）。
3. 阅读回答：
   - **回答**：系统生成的答案，末尾 `[1][2]` 为引用编号；
   - **引用来源**：显示引用的页码（如 `第58页`）；
   - **耗时明细**：查询理解 / 混合检索 / 重排 / 上下文 / 生成 / 总计（秒）；
   - 展开 **检索到的片段**：查看送模型的证据原文（含页码与标题路径）。

**参数**（左侧栏）：
- **启用重排**：默认开启（cross-encoder 精排，提升精度）；
- **返回片段数**：3~10，默认 4（越多上下文越全，但噪声与耗时略增）。

### 3.3 优化前后对比页（⚖️ 优化前后对比）

选择一道工单必测题，点击 **开始对比**，三列并排展示：
- **优化后（工单02）**：本系统答案 + 引用 + 耗时；
- **优化前（工单01）**：基线系统答案（独立进程调用，首次约 20–30 秒）；
- **纯 LLM（无检索）**：不检索直接问模型，用于对照。

### 3.4 知识库页（📚 知识库）

- 查看向量库状态（collection、点数、模型信息）；
- **重建知识库**：后台重新解析与建库（进度见终端）。

## 四、如何上传 PDF / 更换文档

系统当前以《招股说明书1.pdf》为知识库。更换或新增文档：

1. 把新 PDF 放到项目根目录（或任意路径）；
2. 建库时指定源文件：

   ```bash
   python build_index.py --source "D:\路径\新文档.pdf" --rebuild
   ```

   > 注意：更换文档后请同时把 `src/config.py` 中 `SOURCE_PDF` / `SOURCE_NAME`
   > 指向新文件（检索与引用展示依赖该名称）。

3. 重新启动或刷新界面（侧栏"重建知识库"亦可）。

## 五、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 回答"根据已有资料无法确定。" | 文档中确无相关信息，或问题过于宽泛。换更具体的问法（含公司名/年份/指标名） |
| 提示"检索失败/向量库为空" | 未建库。先运行 `python build_index.py` |
| 回答"（LLM 暂不可用，以下为检索到的原文）" | Ollama 未启动。运行 `ollama serve` 后重试 |
| 第一题特别慢 | 模型冷启动。点击侧栏"预热模型"或再问一次（结果会缓存） |
| 对比页"优化前"报错 | 工单1 目录/索引缺失。确认 `D:\xinzg6\zy-gq\工单1\data\qdrant` 存在 |
| 想换更快的模型 | 修改 `src/config.py` 的 `OLLAMA_MODEL`（须为 `ollama list` 中已存在的模型） |
| 端口被占用 | `streamlit run app.py --server.port 8502` |

## 六、回答中的引用怎么看

- 回答里的 `[1][2]` 对应"检索到的片段"面板中的【片段1】【片段2】；
- 片段标题行给出 **页码**（第 N 页）与 **标题路径**（所属章节层级）；
- 引用页码可直接用于回原文核对（招股说明书 PDF 的对应页）。

# 用户手册 —— 招股说明书智能问答系统

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统
> 适用对象：不需要懂编程的业务用户 / 演示人员
> 阅读时间：约 10 分钟

---

## 一、这个系统能做什么

- 用**大白话提问**，系统会翻开《招股说明书1.pdf》找到相关内容，再生成答案；
- 每条答案都标明**出处页码**，可以点回原文核对，不怕「AI 瞎编」；
- 文档里没有的内容，系统会明确说「未能找到」，不会硬编一个答案；
- 支持**中文和英文**提问，支持**语音提问**；
- 网页界面可以直接用，也能**上传新的 PDF** 扩充知识库。

试着问它：

| 你可以这样问 | 系统会回答 |
| --- | --- |
| 武汉兴图新科电子股份有限公司法定代表人是谁？ | 法定代表人姓名 + 出处页码 |
| 报告期内，公司来自军用领域的收入分别是多少？ | 各期收入数据 + 出处页码 |
| 公司计划使用募集资金的多少用于补充流动资金？ | 金额 + 出处页码 |
| Who is the legal representative of the company? | 英文答案 + 引用来源 |

## 二、环境准备（首次使用，只需做一次）

### 第 1 步：安装 Python

安装 Python 3.10 或更高版本（Windows 安装时请勾选 *Add Python to PATH*）。
在命令行输入 `python --version` 能显示版本号即成功。

### 第 2 步：安装依赖

打开命令行，进入项目根目录（`工单作业` 文件夹），执行：

```bash
pip install -r requirements.txt
```

> 网络慢可加国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 第 3 步：配置大模型密钥

系统需要调用 DeepSeek 大模型来生成答案，请先向管理员索取 API Key：

```bash
set DEEPSEEK_API_KEY=sk-你的密钥          # Windows CMD
# export DEEPSEEK_API_KEY=sk-你的密钥     # Linux / macOS
```

> 没有密钥时，检索部分仍能工作，但无法生成文字答案。

### 第 4 步：建立知识库索引（解析 PDF）

```bash
python "工单01-基于PDF文档的问答系统/src/build_index.py"
```

- 屏幕上会显示解析进度，最后打印**页数、块数、耗时**；
- 第一次运行需要下载中文向量模型（约 1.3 GB），请耐心等待；
- 想同时解析**表格数据**，请改用：
  `python "工单01-基于PDF文档的问答系统/src/build_index.py" --preset wo03_table`
  （表格解析较慢，属正常现象）。

### 第 5 步：启动服务

```bash
python "工单01-基于PDF文档的问答系统/src/serve.py"
```

看到 `http://127.0.0.1:8000/` 字样即启动成功。**保持这个命令行窗口开着**，
停止服务按 `Ctrl + C`。

## 三、打开问答界面

打开浏览器（Chrome / Edge 均可），在地址栏输入：

```
http://127.0.0.1:8000/
```

页面顶部会显示当前知识库的向量条数和模型名，说明系统已就绪。
如果显示「服务未就绪」，请回到第 4、5 步检查索引与服务。

## 四、如何上传 PDF

系统支持把新的 PDF 加入知识库，有两种方式：

### 方式一：在接口文档页面上传（推荐，最简单）

1. 浏览器打开 `http://127.0.0.1:8000/docs`；
2. 找到 **POST /api/upload** 一栏，点击右侧「Try it out」；
3. 点击「Choose File」选择本地 PDF 文件，点击「Execute」；
4. 返回结果中出现 `"ok": true` 和 `"chunks_added": 数字` 即上传成功。

### 方式二：用命令行上传

```bash
curl -X POST "http://127.0.0.1:8000/api/upload" -F "file=@D:\资料\某公司招股书.pdf"
```

### 上传成功后怎么用

- 新文档会立刻加入**向量检索**，可以直接提问；
- 查看已入库的文档：浏览器打开 `http://127.0.0.1:8000/api/documents`；
- 如果希望新文档也能被**关键词全文检索**命中，请重新执行第 4 步建索引；
- 上传的原始文件保存在 `data/cache/uploads/` 目录。

## 五、如何提问

### 5.1 文字提问

1. 在页面底部输入框里输入问题，按 `Enter`（或点「发送」）；
2. 问题越具体越好，例如**带上公司全称、年份、指标名**：
   - 好问题：「武汉兴图新科电子股份有限公司注册资本是多少？」
   - 差问题：「介绍一下」（太宽泛，系统只能给出概括）
3. 提问后请等待 1~3 秒，系统会先显示「正在检索文档并生成答案…」。

### 5.2 连续追问（多轮对话）

系统会记住同一页面内的对话上下文，可以直接用「他 / 这个公司」追问：

```
你：武汉兴图新科电子股份有限公司法定代表人是谁？
系统：程家明（来源：第 xx 页）
你：他参与的哪个工程荣获了国家科技进步一等奖？
系统：……（自动把「他」理解为「武汉兴图新科电子股份有限公司」）
```

### 5.3 语音提问

方式一（推荐给演示）：先按下面的「命令行提问」安装语音依赖，然后运行：

```bash
python "工单01-基于PDF文档的问答系统/src/speech_input.py" --loop --ask
```

按提示说话，系统识别后自动问答。

方式二：在命令行问答里加 `--voice`：

```bash
python "工单01-基于PDF文档的问答系统/src/qa_cli.py" -i --voice
```

语音依赖安装（如提示缺失）：

```bash
pip install SpeechRecognition pyaudio     # 在线识别（需联网）
pip install openai-whisper                # 可选：本地离线识别
```

> 没有麦克风？用音频文件同样可以：`--file 你的录音.wav`。

### 5.4 多语言提问

- 中文提问 → 中文回答；
- 英文提问 → 英文回答（如 `What is the registered capital of the company?`）；
- 语音识别语言可切换：`--lang en-US`（默认 `zh-CN`）。

## 六、如何查看结果

每条回答包含四部分信息：

```
┌──────────────────────────────────────────────────────────────┐
│ 答案正文                                                       │
│ ……（先给结论，再给细节，数字保留原文口径）                          │
│                                                              │
│ 【来源】片段1（第 58 页）                                        │
│ ── 引用来源：来源：《招股说明书1》第58页 ──                         │
│ ── 耗时 1863 ms · 第 3 轮 ──                                   │
│ [有帮助] [没帮助]                                              │
└──────────────────────────────────────────────────────────────┘
```

| 元素 | 含义 |
| --- | --- |
| 答案正文 | 仅依据文档内容生成；无答案时会显示「未能找到该问题的答案」 |
| 来源标签 | 引用的片段编号与页码，可回原文核对 |
| 耗时 | 从提问到返回答案的时间，正常应小于 3000 毫秒 |
| 有帮助 / 没帮助 | 你的反馈会用于优化后续检索排序，欢迎随手点一下 |

## 七、如何看引用来源

1. 答案末尾的「来源：《招股说明书1》第 xx 页」即引用位置；
2. 想看得更细，用命令行问答并加 `--show-context`：

   ```bash
   python "工单01-基于PDF文档的问答系统/src/qa_cli.py" -q "军用领域的收入分别是多少？" --show-context
   ```

   终端会列出系统实际检索到的每一条原文片段、页码与相似度分数；
3. 对照 PDF 的对应页码，即可逐字核对答案中的数字是否准确。

## 九、常见问题 FAQ

**Q1：网页打不开 / 提示「服务未就绪」？**
依次检查：① 启动服务的窗口是否还在运行；② 是否执行过 `build_index.py`；
③ 端口 8000 是否被占用（可换端口 `--port 8080`）；
④ 浏览器访问 `http://127.0.0.1:8000/api/health` 是否返回 `"status": "ok"`。

**Q2：回答很慢，超过 3 秒？**
首次调用会隐藏下载/加载模型、且大模型首次响应偏慢。第 2 次起会快很多。
若长期偏慢：检查网络；把 `--reranker tfidf` 替换级联重排；避开大模型高峰期。

**Q3：提示「未配置 DEEPSEEK_API_KEY」？**
没有设置密钥，或设置后没重开命令行窗口。密钥需在**启动服务的同一个窗口**里设置。

**Q4：回答「未能找到该问题的答案」？**
说明文档里确实没有相关信息，或问题表述与文档差异过大。可换一种说法，
或把公司全称、年份、指标名补全后重问。

**Q5：数字答不准怎么办？**
先确认是否开启了表格解析（用 `--preset wo03_table` 重新建索引），
再用 `--show-context` 查看检索片段与页码，核对文档原文。

**Q6：上传 PDF 失败？**
只支持 `.pdf` 后缀；确认文件未加密（能正常打开）；查看启动窗口的报错信息。
扫描版（图片型）PDF 需要先做 OCR，本系统暂不支持直接识别图片文字。

**Q7：语音没反应 / 报错缺依赖？**
按提示安装 `SpeechRecognition` 和 `pyaudio`；Windows 上如安装失败可执行
`pip install pipwin` 后再 `pipwin install pyaudio`。
仍不可用时，用 `--file 录音.wav` 走本地文件识别。

**Q8：能用英文提问吗？**
可以。中文问中文答、英文问英文答；语音识别语言用 `--lang` 指定。

**Q9：怎么知道答案是不是编的？**
看两点：① 答案是否带【来源】页码；② 用 `--show-context` 查看原文片段。
系统在资料不足时明确拒答，这是设计上的抗幻觉机制。

**Q10：换一台电脑要重装吗？**
需要安装依赖并配置 API Key；索引文件（`data/` 目录）可整体拷贝复用，
无需重复解析 PDF。

## 十、出错了怎么办：先看这条

| 现象 | 一句话处理办法 |
| --- | --- |
| 命令提示「不是内部或外部命令」 | Python 未安装或未加入 PATH，重装并勾选 Add to PATH |
| 提示缺少 `fitz` / `pdfplumber` / `fastapi` | 回到第 2 步安装依赖 |
| 建索引报「找不到 PDF」 | 检查 `D:\工单\RAG 工单\RAG 工单\附件\招股说明书1.pdf` 是否存在，或用 `--pdf` 指定 |
| 问答报「索引装载失败」 | 先跑 `build_index.py` 建索引 |
| 页面一直转圈 | 检查启动窗口是否报错、网络能否访问 DeepSeek API |
| 想彻底重来 | 删除 `data/index/` 下的索引文件后重新建索引 |

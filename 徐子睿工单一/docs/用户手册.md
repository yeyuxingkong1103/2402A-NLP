# 招股说明书智能问答系统 —— 用户手册

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化

---

## 一、这是什么

一个网页版的问答系统，可以就《招股说明书1.pdf》的内容提问，系统会：
- 从原文中找出**依据**；
- 给出**答案**，并在答案里标出**依据页码**；
- 如果原文里没有相关内容，会明确告诉你“未找到依据”，不会乱编。

---

## 二、启动（只需一次操作）

### 第 1 步：确认本地模型已就绪
打开命令行（或直接用我们的脚本），确认 Ollama 里有 `bge-m3` 和 `qwen2:7b`：
```
ollama list
```
若缺少：
```
ollama pull bge-m3
ollama pull qwen2:7b
```

### 第 2 步：构建知识库（首次或换文档时）
```
python app/build_kb.py --parse
```
> 这一步会让 MinerU 解析 PDF，548 页约 40-60 分钟，请耐心等待。之后会缓存，不用重复跑。

### 第 3 步：启动服务
双击 `启动.bat`，或在命令行执行：
```
python -m uvicorn app.server:app --host 0.0.0.0 --port 8100
```

### 第 4 步：打开网页
浏览器访问：<http://localhost:8100>

## 三、怎么用

### 3.1 提问
1. 在下方输入框输入问题，例如：
   - 报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
   - 公司参与制定了哪个技术标准？
   - 电子信息行业的上游涉及哪些企业？
   - 公司注册资本是多少？
2. 点击【提问】（或按 `Ctrl+Enter`）。
3. 答案会**逐字出现**（打字机效果）。

### 3.2 看引用
答案下方有「📌 引用来源」，每条可展开，看到：
- 来源**页码**（如“第129页”）；
- 所属**章节**；
- **命中原文片段**与相似度分数。

点击展开即可核对原文，确认答案有没有依据。

### 3.3 语音提问
点击【🎤 语音】，对着麦克风说话，识别结果会填进输入框，再点【提问】。
> 需浏览器支持语音识别（Chrome/Edge 较好）；不支持时请用文字输入。

### 3.4 对比“纯 LLM”
勾选右上角「对比纯LLM」，再提问，页面会**并排**显示：
- 左边：**RAG**（检索增强）—— 有原文依据、带页码；
- 右边：**纯 LLM**（不检索）—— 仅凭模型记忆作答。

用来直观看出：为什么“查文献再回答”比“凭记忆回答”更可靠。

### 3.5 用英文提问（多语言）
直接用英文问即可，例如：
- What is the registered capital of the company?
- Who is the legal representative of Wuhan Xingtu Xinke Electronics Co., Ltd.?
- What proportion of the main business revenue came from the military domain?

系统会自动识别英文，走**跨语检索**（术语映射成中文再检索），并用英文作答、照样给页码引用。
金额仍按原文单位 `万元` 输出（不会误换算成 million）。

### 3.6 反馈
每条答案下方有 👍 / 👎，点一下即可提交反馈，用于后续改进。

### 3.7 清空对话
点【清空】即可开始新一轮。

## 四、常见问题（FAQ）

**Q1：页面提示“知识库未就绪”？**
说明索引还没构建。先跑 `python app/build_kb.py --parse`。

**Q2：提问很久没反应？**
首次调用模型会慢一些；正常情况流式回答应在 1 秒内开始出字。若超过 30 秒无响应，检查 Ollama 是否在运行（`ollama list` 能列出模型即为运行中）。

**Q3：为什么有的问题直接回“未找到依据”？**
这是**拒答保护**：当检索到的最相关片段相似度太低，系统判断“文档里没有”，就不让模型编造。

**Q4：答案页码怎么来的？**
来自 MinerU 解析时记录的每块页码（`page_idx`），检索命中哪块，就标哪块的页码。

**Q5：能换成别的 PDF 吗？**
可以。把 PDF 放进 `data/pdfs/`，用 `python app/build_kb.py --parse --pdf data/pdfs/你的文件.pdf` 重建（当前前端默认指向招股说明书）。

**Q6：端口被占用？**
改 `app/config.py` 里的 `PORT`，或用 `--port 8200` 启动。

## 五、结果怎么解读（验收视角）

| 现象 | 说明 |
|---|---|
| 答案里有【第X页】 | 已给出可核对的依据 |
| 引用卡片能展开原文 | 可自行验证答案是否忠于原文 |
| “已拒答”标记 | 系统判定文档无依据，主动不编造 |
| 对比模式下左右不同 | RAG 更贴合原文；纯 LLM 可能答错/含糊/编造 |

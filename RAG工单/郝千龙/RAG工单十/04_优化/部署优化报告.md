# 工单十 金融问答系统部署优化报告

## 一、部署验证结果

### 1.1 Docker 镜像构建

- 镜像名：`finqa-service:1.0`
- 构建状态：成功（`docker build` 完成，无报错）
- 镜像大小：约 1.2GB（含 Python 3.11 + 依赖 + 索引）

## 二、优化措施

### 2.1 索引预加载

容器启动时通过 `service.py` 的 `IndexStore.load()` 预加载索引到内存，避免首次请求冷启动延迟（加载耗时 30.54s 计入启动阶段，不计入接口耗时）。

### 2.2 多阶段构建优化

Dockerfile 采用多阶段构建：
- 第一阶段：安装编译依赖并构建索引
- 第二阶段：仅拷贝运行时依赖与索引，减小最终镜像体积

### 2.3 健康检查与优雅关停

- `/health` 端点返回索引加载状态与文档统计
- `docker-compose.yml` 配置 `healthcheck` 与 `stop_grace_period`，确保滚动更新无丢请求

## 1. 六项优化手段

围绕 [01 文档](01_优化前基线与问题分析.md) 归纳的五类根因，本工单落地六项优化：

| # | 优化手段 | 解决的问题 | 源码 |
|---|---|---|---|
| ① | **表格结构化解析** | 表格拍平、行列/表头丢失 | `src/table_parser.py` |
| ② | **表格双表示分块**（`table` Markdown + `table_kv` 键值对） | "表头—取值"分离 | `src/chunking.py` |
| ③ | **文档级路由**（多文档消歧） | 跨文档串味（问力源答兴图） | `src/query_understanding.py` / `src/retriever.py` |
| ④ | **表格感知重排**（加权线性融合 + 表格加成） | 表格块被正文挤占 | `src/reranker.py` |
| ⑤ | **表格专用答案路径**（表格级消歧 + 行打分 + 字段/枚举分流） | 数值密集表难区分、字段被整表淹没 | `src/answer_builder.py` |
| ⑥ | **抽取式合成 + 多级容错降级** | LLM 幻觉、超时 | `src/answer_builder.py` / `src/qa_engine.py` |

## 2. 消融实验设计（2×2）

为**隔离**"检索侧优化"与"答案合成优化"各自的贡献，采用 2×2 设计：

|            | 本地 LLM 生成 | 抽取式合成 |
|------------|--------------|-----------|
| **基线检索** | `baseline` | `baseline_extractive` |
| **优化检索** | `optimized_llm` | `optimized`（最终方案） |

- 基线检索 = 表格拍平 + 固定切片 500/80 + 向量/BM25/RRF（无重排）；
- 优化检索 = 表格结构化双块 + 结构感知切片 700/120 + 多路召回 + 表格感知重排 + 文档路由；
- LLM 生成 = 本地 `deepseek-r1:1.5b`；抽取式 = 原文摘取 + 结构化拼装。

运行：`python scripts\ablation.py` → `output/ablation_report.json/md`。

## 4. 贡献归因

### 4.1 单独优化"答案合成"（8 → 13，+5 题）

把 LLM 生成换成抽取式，**答案命中率 57.1% → 92.9%**，耗时 4.449 s → 0.532 s（**8× 加速**）。

- **收益最大**：基线检索 Top-K 命中率本就有 92.9%（13/14），只是 LLM"捞到了却答不对/编造"。
  换成原文摘取后，这 13 题全部答对。
- 典型：Q3（基线 LLM 把"存在控制关系"答成"融冰投资…"）、Q957/Q793（LLM 长篇跑题）。

### 4.2 单独优化"检索"（8 → 12，+4 题）

表格结构化 + 表格感知重排，**答案命中率 57.1% → 85.7%**。

- 表格块被顶到前面，数值型问题的 Top-1 显著改善（Q33、Q34、Q543、Q207）。
- 但**仅靠检索仍不满分**：Q2、Q260 在"优化检索 + LLM"下依旧错。

### 4.3 二者缺一不可（→ 14/14）

| 题 | 基线+抽取 | 优化+LLM | 优化+抽取 | 结论 |
|---|:---:|:---:|:---:|---|
| Q2（募投项目） | ❌ | ❌ | ✅ | **必须两者兼备**：基线检索召回不到该表（Top-K 也❌），LLM 又会编造 → 需优化检索提供表 + 抽取式拼装 |
| Q260（军用收入） | ✅ | ❌ | ✅ | 优化检索 Top-K 命中，但 **LLM 在数值密集表上答错** → 需抽取式 |

> **关键结论**：检索优化让"该表能进候选"，答案合成优化让"候选能变成正确答案"；
> 对表格类问题，**任一环节短板都会漏答**，二者叠加才达到 100%。

## 5. 各优化手段的定量/定性收益

| 优化 | 直接收益 | 证据 |
|---|---|---|
| ① 表格结构化解析 | 689 张表 / 32,301 单元格结构化，表题识别率 96.2% | `table_stats.json` |
| ② 表格双块 | 786 个键值对块，数值/比例型问题精准召回 | Q260/Q33（金额 vs 占比）分别命中 |
| ③ 文档级路由 | 消除跨文档串味 | Q1~Q4（力源）不再混入兴图数据 |
| ④ 表格感知重排 | Top-1 命中 57.1% → 71.4%，MRR 0.696 → 0.824 | `evaluation_report.json` |
| ⑤ 表格专用答案路径 | 字段型"取到即止"、枚举型整表罗列 | Q3（42.35 单行）、Q4（整表枚举） |
| ⑥ 抽取式 + 容错 | 零幻觉、平均耗时降 8× | 消融表（4.449 s → 0.313 s） |

---

## 6. 结论

1. **答案合成优化贡献最大且最"廉价"**：零推理、8× 加速、+5 题；
2. **检索优化解决"召回不到表"**：+4 题，并提升 Top-1/MRR；
3. **表格类问题是"木桶效应"**：Q2 证明只有检索与合成同时到位才能答对；
4. 最终方案 **100%（14/14）**、平均 **1.475 s**（最大 2.279 s），同时满足准确率与响应时间双验收。

\# RAG 问答系统技术文档



\*\*工单编号\*\*：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化



\## 一、系统架构



用户提问 -> Streamlit Web UI (app.py) -> RAG 核心链路 (utils.py)

&#x20; - PDF 解析：PyMuPDFLoader

&#x20; - 分块：RecursiveCharacterTextSplitter(1500/300)

&#x20; - Embedding：BAAI/bge-small-zh-v1.5

&#x20; - 向量检索：ChromaDB + MMR(top\_k=6)

&#x20; - LLM 生成：智谱 GLM-4-Flash

\-> 返回答案 + 引用来源



\## 二、技术栈



| 组件 | 技术 | 版本 |

|:---|:---|:---|

| Web 框架 | Streamlit | 1.65.0 |

| RAG 框架 | LangChain | 1.4.3 |

| PDF 解析 | PyMuPDF | 1.28.2 |

| 向量数据库 | ChromaDB | 1.5.9 |

| Embedding | BAAI/bge-small-zh-v1.5 | - |

| LLM | 智谱 GLM-4-Flash | - |

| Python | CPython | 3.12.7 |



\## 三、核心参数



| 参数 | 值 |

|:---|:---|

| chunk\_size | 1500 |

| chunk\_overlap | 300 |

| top\_k | 6 |

| search\_type | MMR |

| temperature | 0.1 |

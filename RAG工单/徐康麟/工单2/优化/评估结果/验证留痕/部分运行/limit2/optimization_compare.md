## 5. 结论与遗留问题

### 5.1 达标情况

- ❌ 未达标：答案准确率 **0.5000 → 0.5000**（1/2）；工单要求 ≥ 0.90。
- 本次未通过 **1** 题：Q95（逐题判分理由见 `accuracy_report.json` 的 `per_question[*].after.judge_reason` 与 §4）。
  根因以逐题记录为准；**未放宽判分口径**（`check_answer` / 阈值 0.62 未改）。
- ✅ 达标（≤3000ms）：首字响应 平均 11.89 ms / P95 12.04 ms / 最大 12.06 ms（工单红线 ≤ 3000 ms）。
- ✅ 保持（1.00）：引用正确率 1.0000（10/10 条引用页有效且可回查）。

### 5.2 增益归因（三层分开记账）

| 层 | 可证指标 | 前 → 后 |
| --- | --- | --- |
| 解析/分块/嵌入 | 纯向量 top-5 / top-20 命中率 | 0.20/0.40 → 0.00/0.00 |
| 检索排序 | 证据排第 1 位（严格口径，剔除替代判据题） | 1.00 → 1.00 |
| 检索召回 | 终果含证据（本次 2 题） | 1.00 → 1.00（**基线本就不差，此层无增益**） |
| 生成/答案形态 | 答案准确率 | 0.50 → 0.50 |

**逐题证据（本次相对基线翻正 0 题：无）**：

- 本次运行没有相对基线翻正的题目（或基线题面不可比）。
- **未通过**：Q95 → 遗留问题（见 5.3）。

> **不得**把上述增益归因于「换了更强的模型」：工单2 的生成模型 `qwen2.5:3b` 在本机上**没有产出任何进入终果的答案**
> （本次交付路径的回答模式分布：`extractive`×2）。生成端栈变化是**已声明的混淆项，不是因果项**。
> 同时**不得**写成「答案越长越好」：长度只是多值齐备的旁证，判分只看数值/要点是否齐全。

### 5.3 遗留问题（如实记录，未修饰）

1. **本次未通过**：Q95（准确率 1/2，见 5.1）；判分口径未放宽。
2. **无证据位次回退题**（本次运行内）。
3. **重排为规则模式**：本机无 `bge-reranker-base` 权重，未运行交叉编码器重排；不得声称跑过模型重排。
4. **其他修复项的现状不在本脚本内断言**：中英文问答、多轮追问、无关问题容错（验收 4/5/6）的修复与复验结果，以 `测试/用户/user_acceptance_checklist_v2.md`、`研发/报告/可答性闸门修复报告.md` 与在线/离线套件实测为准——**本脚本只记录本次对比运行的事实**，不重复固化易过期的结论。

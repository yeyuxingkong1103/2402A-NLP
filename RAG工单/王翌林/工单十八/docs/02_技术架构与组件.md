# 工单十八 · 技术组件与架构

## 1. 技术组件
| 组件 | 作用 | 实现 |
|------|------|------|
| Skill 定义 | 三层结构（元数据/指令/资源） | `document_quality_assessment/SKILL.md` |
| 配置 | 全部阈值可配置 | `assessment_config.yaml` |
| 评估引擎 | 五大功能编排 | `src/quality_assessor.py` |
| PDF 解析 | 文本提取与逐页字符统计 | pypdf |
| 近似去重 | SimHash 指纹+汉明距离 | `src/simhash.py` |
| 报告渲染 | JSON + HTML 简报 | `src/report_renderer.py` |
| 智能体工作流 | 质检→路由解析器 | `workflow/document_ingestion_workflow.py` |
| 质检 API | 暴露 HTTP 端点 | `api/quality_api.py` (FastAPI) |
| 测试 | 单元测试 | `tests/test_quality_assessor.py` |

## 2. 架构
```
documents/ 文件夹
      │
      ▼
DocumentQualityAssessmentSkill
 ├─ 格式分布统计
 ├─ PDF 文字/扫描/混合 分流（启发式，阈值可配）
 ├─ 长度分布（P25/P50/P75/P90/P99 + 区间）
 ├─ 重复检测：MD5 精确 + SimHash 近似
 └─ 敏感信息检测（手机/邮箱/身份证，银行卡默认关）
      │
      ├─ classification 分类标签 + route_map
      │     Text_PDF→text_extractor，Scan_PDF→ocr_parser …
      ▼
输出 JSON 报告 + HTML 简报（重点：待确认/待审核列表）
      │
      ▼
document_ingestion_workflow（智能体决策节点）：按标签自动路由
      │
      ▼
POST /v1/document/quality-inspection（供外部/Agent 调用）
```

## 3. 关键设计
- **阈值全配置化**：扫描页字符阈值、扫描占比阈值、SimHash 汉明距离、敏感项开关均在 yaml，不硬编码。
- **启发式即待确认**：PDF 分类、SimHash 相似均输出“待确认/待审核列表”，附文件路径与上下文，交人工复核（符合“列表可操作性”验收）。
- **错误处理**：损坏/加密 PDF 捕获异常并记录 `parse_errors`，不中断整体流程。
- **可扩展**：SimHash 为进阶项，可通过 `enable_simhash: false` 降级为纯 MD5 去重。

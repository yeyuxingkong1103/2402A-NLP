# 工单11 Embeddings模型微调｜项目总结
工单编号：人工智能NLP‑RAG 项目‑Embedding 模型微调任务

## 1.任务完成情况

✅ 基于本地BAAI/bge‑base‑zh‑v1.5预训练模型，使用TripletLoss三元组损失完成embedding完全微调。
✅ 实现评估脚本，完成微调前基线评估、微调后评估，输出Recall@1、Recall@3量化指标。
✅ 微调模型成功保存至output_model目录。
✅ 完整记录实验现象：基线模型效果已经接近满分，小数据集条件下微调指标持平，文档中说明数据集规模带来的限制。
✅ 完成全套交付文档：设计.md、研发.md、测试.md、优化.md、部署.md、总结.md。

## 2.学习收获
1. 理解垂直领域为什么需要对Embedding做微调，解决专业术语语义不匹配的问题。
2. 掌握embedding微调数据集格式：三元组(anchor,positive,negative)，理解TripletLoss损失原理。
3. 掌握完整流程：数据集构建→基线评估→对比学习微调→模型保存→微调后评估、指标对比。
4. 理解Recall@k检索评估指标的含义。
5. 认识数据集规模对微调效果的决定性影响；理解过拟合现象，知道通过控制epoch缓解。
6. 了解其他微调技术：适配器LRA、MNRL损失、DAPT/TAPT领域预训练。
7. 掌握微调模型接入RAG系统的注意点：向量库必须重新向量化，新旧向量空间不能混用。

## 3.项目难点
1. 小数据集微调容易出现过拟合，epoch参数需要谨慎设置。
2. 负样本质量对训练效果影响很大，简单构造的负样本训练信号弱。
3. sentence‑transformers新版本依赖accelerate库，环境依赖容易缺失。
4. 基线模型本身效果已经很好的时候，小规模训练集很难看到指标上涨。

## 4.现存不足
1. 训练三元组样本数量过少，只有12条。
2. 负样本为简单索引偏移生成，没有引入难负样本。
3. 未实现适配器参数高效微调、DAPT领域预训练。
4. 没有做超参调优。

## 5.后续拓展方向
1. 扩充数百条以上高质量三元组训练数据，引入难负样本。
2. 实现LRA适配器微调，对比完全微调与参数高效微调效果差异。
3. 尝试MNRL多负样本排序损失。
4. 在无标注金融文档上做DAPT领域预训练。
5. 将微调后的embedding替换进Graph‑RAG系统，端到端观察RAG问答整体效果变化。

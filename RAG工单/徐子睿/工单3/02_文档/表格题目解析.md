# 工单 03 · 表格解析与题目定位（《招股说明书2.pdf》）

> 工单编号：人工智能NLP-RAG-PDF文档的表格解析及检索优化
> 语料：`data/pdfs/招股说明书2.pdf`——武汉力源信息技术股份有限公司（350 页）

## 一、表格解析技术路线（本项目实现）

| 环节 | 做法 |
|---|---|
| 主通道 | MinerU pipeline 输出 `content_list.json`，表格以 HTML `<table>` 保留行列结构 |
| 结构化 | `parse.html_table_to_rows()` 把 HTML 解析成**行列二维数组** |
| 线性化 | `parse.table_block_text()` 把每行转成 `行名 -> 列名: 值` 的序列，便于「X 是多少」型数值题命中 |
| 兜底通道 | `parse.blocks_from_pymupdf()` 用 PyMuPDF `find_tables()` 识别表格（无需 OCR），同样产出 `table_rows` |
| 分块 | 表格**独立成块**（不被滑窗切散），并记录 `page / section / type=table` |
| 多文档 | 每本 PDF 单独落盘 `data/parsed/blocks_<doc>.jsonl`；块带 `doc` 字段；按公司名路由检索 |

相关代码：`app/parse.py`、`app/clean.py`（HTML 表格压平）、`app/chunk.py`、`app/config.py`、`app/build_kb.py`、`app/engine.py`

## 二、四道题的答案在 PDF 中的定位（表格）

| id | 问题 | 表格定位 | 答案 |
|---|---|---|---|
| 1 | 本次发行股数、占发行后总股本比例 | **本次发行概况表**（p22 / p24）；第十一节（p306） | 发行 **1,670 万股**，占发行后总股本 **25.04%**（发行后总股本 6,670 万股） |
| 2 | 本次募集资金拟投资项目 | **募集资金投资项目表**（p30 风险因素转述 / p305-306 运用方案） | 仓储及物流中心、研发中心、电子商务平台、扩充产品种类和数量、其他与主营业务相关的营运资金 |
| 3 | 存在控制关系的关联方（持股比例/关系） | **关联方及关联关系表**（p157） | 赵马克 ｜ 42.35% ｜ 公司控股股东 |
| 4 | 不存在控制关系的关联方企业 | **关联方及关联关系表**（p157） | 融冰投资、武汉博润、上海博润、听音投资、联众聚源（均持股 5% 以上）；力源贸易（同一实际控制人控制）；普芯达（实际控制人近亲属控制） |

> 页码为本系统 `page` 字段口径（PDF 物理页码）。`evaluation/eval_questions_pdf2.json` 已按此录入金标准。

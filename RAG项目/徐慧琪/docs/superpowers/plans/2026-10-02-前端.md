# 前端（Vue 3）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 `frontend/`——Vue 3 + TypeScript + Element Plus 的**一工程两入口**前端（公众侧：匿名问答 / 法条浏览 / 导航；律师侧：登录 / 问答 / 检索 / 一键复制 / 501 联调 / 审计导出），消费 ④a 已交付的 HTTP 契约。

**Architecture:** 单 Vite 工程两入口（`index.html` 公众、`lawyer.html` 律师）。共享 `src/core`（API 客户端**按入口拆模块**：`api/public.ts` 只被公众入口可达、`api/lawyer.ts` 只被律师入口可达——结构性隔离，构建产物扫描钉住）与 `src/components`。契约类型由后端 OpenAPI **离线生成**（唯一真相源 = `backend/app/api/schemas.py`）。无 CORS 依赖：dev 走 Vite proxy（`/api` → `127.0.0.1:8138`）、生产同源。

**Tech Stack:** Node 24 / npm 11；Vue 3、Vite、vue-router 4、TypeScript strict、Element Plus（unplugin 按需自动导入）、Vitest + Vue Test Utils + jsdom、openapi-typescript。后端契约 = ④a 交付态（**818 passed / 0 failed / 0 skipped**，11 条路由）。

**设计依据：** `docs/superpowers/specs/2026-10-02-前端-design.md`（已确认）。需求落点：FR-4.4 / FR-7.1~7.4 / FR-8.1~8.7 / FR-9.3~9.5 / AC-19（前端侧）/ AC-20（前端侧）。

## Global Constraints

- `src/` 与 `tests/` 下每个文件**非空行 ≤ 300**（`npm run check:size` 承重；超了拆文件，禁止压缩空行规避）
- **注释全中文、解释「为什么」而非复述语句**（沿用后端纪律；前端无 check_style 自动闸门，靠任务评审）
- **本项目不使用版本控制**：没有 git、没有提交步骤。每个任务的闸门 = `npm run test` 全绿 + `npm run typecheck` 0 错 + `npm run check:size` 0 违规；Task 7 追加 `npm run build` 与 `npm run check:bundle`
- **忠实变异**：每条新护栏收尾做一次「改坏 → 变红 → 逐字节还原 + sha256 核对」；临时件放仓库外或用完即删
- **契约字段名照抄后端**（`backend/app/api/schemas.py`；下方「共享形状」是它的摘录）——前端不得自创字段名
- **公众侧零本地存储**（不写 cookie / localStorage / sessionStorage）；**全仓禁 `v-html`**——两条都是测试判据
- 纯文本渲染（`white-space: pre-wrap`）；错误文案一律透传后端 `message`；`request_id` 在错误面板可见
- **不改后端运行时**；唯一后端侧新增 = `tools/export_openapi.py`（离线脚本，不启服务、不进运行时）
- dev 与人工验收前提：后端 uvicorn 在 `127.0.0.1:8138`，且设 `FL_JWT_SECRET` / `FL_RATE_LIMIT_SALT`（见 `docs/交付说明-④a-HTTP接口.md`）
- 依赖锁定 `package-lock.json`；Node ≥ 20（本机 24.18.0）
- 报告与审查包放 `.superpowers/sdd/d/`（a=入库链路、b=③b-1、c=④a；本子项目 = **d**）

`frontend/scripts/check-size.mjs`：

```js
#!/usr/bin/env node
// 文件规模闸门：非空行 ≤ 300。与后端 check_style 的精神一致——超限就拆文件，
// 不靠压缩空行规避（所以判据数的是非空行）。导出函数供测试 import；
// 直接执行时才扫仓库（import 时应无副作用）。
import { readdirSync, readFileSync, statSync } from 'node:fs'
import { join, relative } from 'node:path'
import { fileURLToPath } from 'node:url'

export const MAX_NON_EMPTY_LINES = 300
export const SCAN_DIRS = ['src', 'tests']

export function nonEmptyLines(text) {
  return text.split(/\r?\n/).filter((l) => l.trim() !== '').length
}

export function collectFiles(dir, out = []) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name)
    if (statSync(p).isDirectory()) collectFiles(p, out)
    else if (/\.(ts|vue|mjs)$/.test(name)) out.push(p)
  }
  return out
}

export function findViolations(root, dirs = SCAN_DIRS, max = MAX_NON_EMPTY_LINES) {
  const bad = []
  for (const d of dirs) {
    let files
    try { files = collectFiles(join(root, d)) } catch { continue } // 目录未建时跳过
    for (const f of files) {
      const n = nonEmptyLines(readFileSync(f, 'utf8'))
      if (n > max) bad.push({ file: relative(root, f), lines: n })
    }
  }
  return bad
}

const isMain = process.argv[1] && fileURLToPath(import.meta.url) === process.argv[1]
if (isMain) {
  const root = fileURLToPath(new URL('..', import.meta.url))
  const bad = findViolations(root)
  for (const b of bad) console.log(`${b.file}: 非空行 ${b.lines}（上限 ${MAX_NON_EMPTY_LINES}）`)
  console.log(bad.length ? `超限 ${bad.length} 处` : '检查通过：0 处超限')
  process.exit(bad.length ? 1 : 0)
}
```

```ts
function jsonResponse(status: number, body: unknown, headers: Record<string, string> = {}) {
  return new Response(JSON.stringify(body), {
    status, headers: { 'Content-Type': 'application/json', ...headers },
  })
}
```

```ts
// 两条红线用「扫源码」承重：v-html 一旦出现，渲染方式即 XSS 面；公众入口
// 一旦出现本地存储，AC-19 的「不采集」就在前端破功。扫描比约定可靠。
import { readdirSync, readFileSync, statSync } from 'node:fs'
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'
import { describe, expect, it } from 'vitest'

const SRC = fileURLToPath(new URL('../src', import.meta.url))

function filesUnder(dir: string): string[] {
  return readdirSync(dir).flatMap((n) => {
    const p = join(dir, n)
    return statSync(p).isDirectory() ? filesUnder(p) : [p]
  })
}

describe('源码红线扫描', () => {
  it('全仓无 v-html', () => {
    const hits = filesUnder(SRC).filter((f) => readFileSync(f, 'utf8').includes('v-html'))
    expect(hits).toEqual([])
  })

  it('公众入口无任何本地存储与 cookie 写入', () => {
    const patterns = [/localStorage/, /sessionStorage/, /document\.cookie/]
    const hits = filesUnder(join(SRC, 'public')).filter((f) =>
      patterns.some((re) => re.test(readFileSync(f, 'utf8'))))
    expect(hits).toEqual([])
  })

  it('公众入口不 import useAuth（本地存储的唯一所在地在律师入口）', () => {
    const hits = filesUnder(join(SRC, 'public')).filter((f) =>
      readFileSync(f, 'utf8').includes('useAuth'))
    expect(hits).toEqual([])
  })
})
```

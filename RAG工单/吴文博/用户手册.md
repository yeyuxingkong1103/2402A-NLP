\# RAG 问答系统用户手册



\*\*工单编号\*\*：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化



\## 一、启动系统



1\. 打开 CMD

2\. 执行：

&#x20;  cd C:\\rag\_pdf\_project

&#x20;  venv\\Scripts\\activate

&#x20;  streamlit run app.py

3\. 浏览器自动打开 http://localhost:8501



\## 二、使用步骤



步骤 1：上传 PDF

点击左侧 "Upload" 按钮，选择 PDF 文件。



步骤 2：建立索引

点击 "开始解析并建立索引"，等待 1-5 分钟。

看到 "文档解析完成" 即可。



步骤 3：提问

在底部输入框输入问题，按回车。



步骤 4：查看答案与引用

点击 "查看引用来源" 展开查看 PDF 原文和页码。



\## 三、常见问题



Q：为什么回答很慢？

A：首次提问需要加载模型，约 5-10 秒；后续 2-3 秒。



Q：为什么回答"无法回答该问题"？

A：可能 PDF 中没有相关信息，或检索未命中。请换一种问法。



Q：支持多个 PDF 吗？

A：当前一次处理一个 PDF。



\## 四、错误处理



| 错误 | 原因 | 解决方法 |

|:---|:---|:---|

| 401 身份验证失败 | API Key 无效 | 检查 .env |

| 模型下载超时 | 网络问题 | 设置 HF\_ENDPOINT=https://hf-mirror.com |

| 解析失败 | PDF 损坏 | 换一个 PDF 测试 |



\## 五、系统关闭



在 CMD 窗口按 Ctrl + C 停止。

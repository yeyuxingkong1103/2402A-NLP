# 需求文档

## 项目目的

知途是面向大众的民事法律问答系统，帮助用户了解法律边界、维护合法权益，找到依法解决问题的路径。
判断以事实、证据和法律为基础，不以谁更可怜为依据，不引导用户损害他人的合法权益。
回答提供法律知识、依据和参考建议，不代替律师专业评估，不代表法院的最终裁判。

## 当前阶段

- 重点做好简单问答：理解问题、检索公共法律资料、说明依据、提出可操作的处理建议。
- 区分登录用户与未登录用户，不将访客记录混入其他账号。
- 登录用户能打开历史咨询并继续提问，切换会话不混用记录。
- 页面简约、严谨、亲和，支持整体外观切换。
- 公共数据处理与用户上传处理分开，启动问答服务不触发公共入库。
- 复用已经确认的八个公共法律集合，保持持久化，避免重复处理和误重建。

## 隔离与隐私目标

用户信息按账号隔离，会话记录及会话材料按会话隔离。
权限在服务端验证；不能仅凭请求中的用户ID或会话ID访问材料。
用户可以主动删除材料；账号注销后的数据清理与长期未使用材料的到期清理应有明确规则。
这些是需求和验收目标，不代表所有删除路径、定时任务及生产级安全检查已完成。

## 后续完善

当前页面以问答为主，用户上传模块后续单独完善；后台已有的材料处理代码暂时保留，不等于已经对外开放。
后续可根据用户材料辅助整理合同、调解相关文书等，提供下载和打印，但需要模板、内容校验和法律风险说明。
专业用户所需的严谨依据、来源定位与引用核查持续完善，不能仅凭模型生成内容宣称法律结论准确。

## 修改原则

沿用现有项目，使用初学者容易理解的函数和命名；少改接口，不随意重写整个架构。
必要的错误检查、数据隔离和数据库保护不能为了减少代码行数而删除。

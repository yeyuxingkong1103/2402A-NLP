# 工单11：Embeddings模型微调
作者：赵振。按设计、研发、测试、优化、部署五个阶段整理。

- [设计](设计/方案.md)：数据和训练方案。
- [研发](研发/train.py)：唯一Python文件，生成问答、训练、评估。
- [测试](测试/评估报告.md)：微调前后指标、真实训练日志与结果图。
- [优化](优化/优化记录.md)：失败实验和最后一层微调；model是最终模型。
- [部署](部署/使用说明.md)：安装和运行命令。

基于100条自动生成的金融问答及400个候选段落。新测试集Recall@5由85%升到90%；提升有限，不等同于实际问答正确率。

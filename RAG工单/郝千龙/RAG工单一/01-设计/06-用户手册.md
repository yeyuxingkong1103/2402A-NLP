# 用户手册

> 工单编号：**人工智能NLP-RAG-基于PDF文档的问答系统**
> 系统名称：招股说明书 RAG 问答系统
> 文档版本：V1.0  编写日期：2026-10-04

---

## 一、系统简介

本系统是基于大语言模型（LLM）与检索增强生成（RAG）技术的 PDF 文档问答系统，能够针对《招股说明书1.pdf》（武汉兴图新科电子股份有限公司，548 页）进行高效问答，答案均来自文档原文并标注页码，支持中英文问答、语音输入与答案反馈。

## 二、运行环境

| 项目 | 要求 |
| :-- | :-- |
| 操作系统 | Windows 10/11（也支持 Linux/macOS） |
| Python | 3.10 ~ 3.12 |
| 必需模型（本地缓存） | bge-base-zh-v1.5（向量化） |
| LLM | DeepSeek API（默认，需 `DEEPSEEK_API_KEY`）；可切换 Ollama/vLLM |
| 浏览器 | Chrome / Edge（语音输入需要） |
| 外部中间件 | 默认无需安装（本地 FAISS 向量索引 + 本地文件缓存）；生产模式可切 Milvus + Redis |

### 安装依赖（首次使用）

在工单根目录执行：

```powershell
pip install -r 02-研发/requirements.txt
```

## 三、启动与停止

### Windows 一键启动

```powershell
cd 05-部署
./start.ps1
```

脚本会自动：① 启动 FastAPI 后端（端口 8000）；② 启动 Streamlit 前端（端口 8501）；③ 健康检查；④ 自动打开浏览器 `http://127.0.0.1:8501`。

### 停止服务

```powershell
./stop.ps1
```

### Linux/macOS

```bash
cd 05-部署 && ./start.sh     # 需 Docker（Milvus + Redis）
./stop.sh
```

### 手动启动（调试用）

```powershell
# 终端 1：后端
cd 02-研发
python main.py
# 终端 2：前端
streamlit run app.py
```

## 四、功能操作指南

### 4.1 知识库管理

1. 打开页面顶部 **「📚 知识库管理」** 标签页；
2. 左侧表格列出全部已入库文档：文档 ID、文件名、页数、切片数、入库时间；底部显示当前向量库/缓存后端；
3. **上传 PDF**：右侧「上传新 PDF 入库」→ 选择本地 PDF 文件 → 点击「Upload & Ingest」，系统自动完成 解析 → 切分 → 向量化 → 入库 → 重建关键词索引；
4. **删除文档**：在下拉框选择 doc_id → 点击删除按钮，对应向量与索引一并清理；
5. 页面底部可查看全部用户反馈记录。

> 说明：默认启动后，招股说明书1.pdf 已完成入库（1612 个文本块），无需重复上传。

### 4.2 文字提问

1. 进入 **「💬 智能问答」** 标签页；
2. 在左侧输入框输入问题，例如：`公司注册资本是多少？`；
3. 点击 **「🚀 提问」**；
4. 右侧绿色区域显示 **RAG 答案**、耗时与缓存状态；
5. 点击「📎 引用来源」可展开查看每个答案片段的页码、相似度与原文；
6. 橙色区域为 **纯 LLM 基线答案**（不检索文档），可直观对比 RAG 与仅使用 LLM 的差异。

### 4.3 语音提问

1. 在提问输入框下方点击 **「🎤 点击开始语音输入」**；
2. 浏览器首次使用会请求麦克风权限，请点击「允许」；
3. 对着麦克风说出问题（如：公司注册资本是多少），再点一次按钮结束；
4. 识别文字自动填入输入框（已有文字时自动追加），点击「提问」即可；
5. 提示：请使用 Chrome/Edge；环境嘈杂时识别率会下降，可手动修改识别文本。

### 4.4 中英文切换

- 在页面 **左侧边栏顶部** 选择「中文 / English」：
  - 界面语言即时切换；
  - 用英文提问时（如 `Who is the legal representative?`），系统跨语言检索中文招股书，并按英文生成答案、标注引用页码。

### 4.5 答案反馈

1. RAG 答案下方「这个回答对你有帮助吗？」处选择 👍 或 👎；
2. 可在输入框填写补充意见；
3. 点击「提交反馈」，反馈记录保存至 `02-研发/data/feedback.jsonl`，并可在知识库管理页查看，用于知识库持续优化。

### 4.6 RAGAS 评估

1. 进入 **「📊 RAGAS 评估」** 标签页；
2. 点击「一键跑工单 10 题真实 RAGAS 评估」（约需数分钟，评估期间请勿关闭页面）；
3. 评估完成后展示四项指标：

| 指标 | 含义 |
| :-- | :-- |
| faithfulness | 答案是否忠实于检索内容（事实一致性） |
| answer_relevancy | 答案与问题的相关程度 |
| context_precision | 检索片段的精准度 |
| context_recall | 标准答案信息被检索覆盖的程度 |

也可在终端运行完整验收脚本（含对比报告、雷达图、延迟图）：

```powershell
cd 03-测试
python run_workorder_eval.py
```

产物：`workorder_result.md/json`、`06_ragas_radar.png`、`05_latency.png`。

## 五、常见问题（FAQ）

1. **页面提示「backend offline」**：FastAPI 未启动，请先执行 `./start.ps1` 或 `python main.py`。
2. **语音按钮不可用**：当前浏览器不支持 Web Speech API，请改用 Chrome/Edge。
3. **答案显示「招股说明书中未提及该信息」**：文档中确实没有相关内容，或问题表述与原文差异过大，可换用关键词更明确的问法。
4. **偶发回答较慢**：云端 LLM 延迟有波动；重复提问会自动命中缓存（通常 <50ms）。
5. **想使用本地 LLM**：设置环境变量 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL` 指向 Ollama（`http://127.0.0.1:11434/v1`）或 vLLM 即可。

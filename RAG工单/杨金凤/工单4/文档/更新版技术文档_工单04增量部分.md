## 3. 关键实现

### 3.1 图像提取与描述生成（parse_pdf_images.py）

```python
# 使用 PyMuPDF 提取位图
doc = fitz.open(pdf_path)
for page_num in range(len(doc)):
    images = page.get_images(full=True)
    for img_info in images:
        pix = fitz.Pixmap(doc, img_info[0])
        if pix.width < 150 or pix.height < 150:
            continue
        pix.save(img_path)

# 使用 Qwen2.5-VL 生成描述
messages = [{
    "role": "user",
    "content": [
        {"type": "image", "image": f"file://{img_path}"},
        {"type": "text", "text": "请完整描述图像内容，包括文字、标题、结构关系、数值等。"}
    ]
}]
```

### 3.2 图像描述检索（rag_engine.py 新增逻辑）

```python
# 问题含"图"关键词时，独立检索图像描述
image_keywords = ["图", "图中", "图表", "结构图", "走势", "曲线", "柱状", "饼图", "增长图", "应用结构"]
if any(kw in question for kw in image_keywords):
    image_docs_for_context = self.vectordb.similarity_search(
        search_query, k=2, filter={"source": "图像描述"}
    )

# 主检索结果 Reranker 精排取 top 4
top_docs = self._rerank(search_query, candidates, top_k=4)

# 图像块直接放最前面
top_docs = image_docs_for_context + top_docs
```

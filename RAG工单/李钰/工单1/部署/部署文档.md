# 部署文档

> 工单编号: 人工智能 NLP-RAG-基于 PDF 文档的问答系统

## 一、环境要求

- Python 3.8 及以上
- 操作系统: Windows / Linux / macOS
- 内存: ≥ 1GB (索引构建期间)
- 网络: 若启用完整 RAG 需可访问 LLM 服务

## 二、本地部署 (推荐)

### 1. 安装依赖

```bash
pip install -r 部署/requirements.txt
```

或直接安装:

```bash
pip install Flask pdfplumber scikit-learn numpy requests jieba
```

### 2. 准备 PDF 文档

将《招股说明书1.pdf》放置在工单根目录的 `工单1/` 文件夹下, 或通过环境变量 `PDF_PATH` 指定路径。

### 3. (可选) 配置 LLM 服务

通过环境变量配置 (任选一种):

**Windows (PowerShell):**
```powershell
$env:LLM_API_KEY="sk-xxxx"
$env:LLM_BASE_URL="https://api.openai.com/v1"
$env:LLM_MODEL="gpt-3.5-turbo"
```

**Windows (CMD):**
```cmd
set LLM_API_KEY=sk-xxxx
set LLM_BASE_URL=https://api.openai.com/v1
set LLM_MODEL=gpt-3.5-turbo
```

**Linux/macOS:**
```bash
export LLM_API_KEY=sk-xxxx
export LLM_BASE_URL=https://api.openai.com/v1
export LLM_MODEL=gpt-3.5-turbo
```

> 未配置时, 系统将进入降级模式: RAG 答案展示检索到的最相关片段, 纯 LLM 答案提示未启用。

### 4. 启动系统

**方式 A - 启动脚本 (Windows):**
```cmd
部署\启动脚本.bat
```

**方式 B - 直接运行:**
```bash
cd 研发
python app.py
```

### 5. 访问系统

浏览器打开: http://127.0.0.1:5000

接口健康检查: http://127.0.0.1:5000/api/health

## 三、Docker 部署

### 1. 构建镜像

```bash
docker build -t rag-pdf-qa -f 部署/Dockerfile .
```

### 2. 运行容器

```bash
docker run -d --name rag-qa -p 5000:5000 \
    -v /path/to/工单1:/data \
    -e PDF_PATH=/data/招股说明书1.pdf \
    -e LLM_API_KEY=sk-xxxx \
    -e LLM_BASE_URL=https://api.openai.com/v1 \
    -e LLM_MODEL=gpt-3.5-turbo \
    rag-pdf-qa
```

### 3. 访问

浏览器打开: http://localhost:5000

## 四、常见问题

| 问题 | 原因 | 解决方案 |
| --- | --- | --- |
| `ModuleNotFoundError: pdfplumber` | 未安装依赖 | `pip install pdfplumber` |
| `FileNotFoundError: 招股说明书1.pdf` | PDF 路径错误 | 设置 `PDF_PATH` 环境变量 |
| 索引构建缓慢 | PDF 较大 (≥ 200 页) | 首次构建约需 30-60s, 之后会缓存 |
| LLM 答案为空 | 未配置 `LLM_API_KEY` | 参见上文配置 LLM 服务 |
| 响应超时 (> 3s) | LLM 接口慢 | 增大 `MAX_RESPONSE_TIME` 或换更快的 LLM |

## 五、API 接口说明

| 路径            | 方法 | 说明             |
| --------------- | ---- | ---------------- |
| `/`             | GET  | 访问 Web UI      |
| `/api/ask`      | POST | 提问接口 (JSON)  |
| `/api/health`   | GET  | 健康检查         |
| `/api/rebuild`  | POST | 重建索引         |

### `/api/ask` 请求示例

```json
{
  "question": "武汉兴图新科电子股份有限公司的注册资本是多少?"
}
```

### 响应示例

```json
{
  "question": "...",
  "rag_answer": "...",
  "llm_answer": "...",
  "response_time": 1.234,
  "within_time_limit": true,
  "retrieval": [{"page": 1, "score": 0.42, "text": "..."}]
}
```

工单04 额外用到（可选，缺失时自动降级，不阻断主流程）：

| 能力 | 依赖 | 缺失时的降级行为 |
|------|------|------------------|

## 2. 运行步骤（按顺序）

```bash
# ① 抽图：矢量图整页渲染回退 + 水印过滤 + CLIP 分类
python src/image_extractor.py --docs 2
#    产物：results/images/招股说明书2/*.png、results/image_inventory.json/.md

# ② 多模态语义解析：CLIP 路由 + VLM 精读（层级树 / 图表结构化）
python src/image_semantic_parse.py --pages 39,72,310
#    只解析关键图页；全量解析去掉 --pages 即可
#    产物：results/image_descriptions.json/.md

# ③ 建索引：文本 + 表格 + 图像语义块（同时构建对照索引）
python src/build_multimodal_index.py
#    产物：wo04_multimodal（含图像）、wo04_text（不含图像）、results/index_stats.json

# ④ 两个图像问题问答演示（命中图像 + 语义描述 + 答案 + 检索精确度）
python src/image_qa.py

# ⑤ 消融对比实验（核心证据：不含图像 vs 含图像）
python src/compare_with_without_images.py

# ⑥ 16 问完整评估（准确率 / 响应时间；加 --ragas 得到 RAGAS 四指标）
python src/run_evaluation.py

# ⑦ Web 演示界面
python src/serve.py            # 浏览器打开 http://127.0.0.1:8000
```

常见可选参数：

| 脚本 | 参数 | 用途 |
|------|------|------|
| `image_extractor.py` | `--pages 39,72,310` | 只抽指定页 |
| | `--force-render-pages` | 图页即使有内嵌图也追加整页渲染 |
| | `--no-clip` | 跳过 CLIP（无 torch 环境时更快） |
| `image_semantic_parse.py` | `--all` | 连产品照片也解析 |
| | `--no-cache` | 忽略缓存强制重解析 |
| `image_qa.py` | `--qids 5` | 只跑 id 5 |
| `compare_with_without_images.py` | `--rebuild` | 强制重建两个索引 |
| `run_evaluation.py` | `--answer-key key.json` | 用外部文件覆盖评测要点 |
| `serve.py` | `--port 8010` | 换端口 |

## 4. Web 界面使用

启动 `python src/serve.py` 后打开 `http://127.0.0.1:8000`：

* 顶部显示索引条数、向量数、已解析图像数；
* 输入框提问，或点击 **「图像问题5」/「图像问题6」** 按钮一键演示；
* 当检索命中图像块时，答案下方会出现**图像卡片**：左侧是抽取出的图（矢量图显示整页渲染图），
  右侧是图像来源（内嵌位图/整页渲染）与多模态语义描述；
* 每条答案下方显示**检索耗时与端到端耗时**，并标注是否满足 ≤3 s。

命令行接口（便于集成与自动化验收）：

```bash
curl -X POST http://127.0.0.1:8000/api/ask \
  -H "Content-Type: application/json" \
  -d "{\"question\":\"武汉力源信息技术股份有限公司组织结构图中，销售部有几个部门构成，其中大客户销售部有几个销售处构成？\",\"top_k\":5,\"with_precision\":true,\"question_id\":5}"
```

| 接口 | 说明 |
|------|------|
| `POST /api/ask` | 问答；`with_precision=true` 时额外返回 Context Precision 与要点判定 |
| `GET /api/health` | 健康检查（向量条数/BM25 篇数/图像数/运行时长） |
| `GET /api/image_inventory` | 图片清单 |
| `GET /api/image_questions` | 内置图像问题（id5/id6） |
| `GET /api/metrics` | 服务端延迟统计 |
| `GET /images/<文档名>/<文件名>` | 抽取出的图像文件 |

## 5. 多语言支持

* 提问语言自适应：`rag_core.generator._is_english()` 按中文字符占比自动选择中/英文
  system prompt 与拒答话术；
* 英文提问示例：`How many sales offices are under the Key Account Sales Department?`
  ——检索侧对中文语料仍可命中（BGE 中文模型 + 图像描述中的中文节点名），
  生成侧以英文作答；
* 图像语义描述统一为中文（文档原文为中文），英文提问时由生成模型在答案中转述。

## 6. 常见问题（FAQ）

| 现象 | 原因 | 处理 |
|------|------|------|
| `未找到图片清单` | 未跑第①步 | 先运行 `image_extractor.py` |
| 图像语义描述为空 | 未配置多模态模型或端点不可用 | 配置 `RAG_VLM_MODEL`/`RAG_VLM_API_KEY`，或启动 Ollama 视觉模型；查看 `image_descriptions.json` 中的 `error` 字段 |
| CLIP 分类为空 | 未安装 torch/transformers | 可忽略（自动降级）；需要时 `pip install torch transformers` |
| 两个图像问题答不出 | 未执行第②步或图像块未入库 | 检查 `index_stats.json` 中 `with_images.chunk_types.image` 是否 >0 |
| `BM25` 结果与索引不一致 | 两个 collection 的 BM25 文件被覆盖 | 本工单已按 collection 分文件（`data/index/bm25_wo04_*.pkl`）；如手工调用请显式传路径 |
| 端到端超过 3 秒 | LLM 走公网 API | 重复提问命中 `rag_core.llm` 磁盘缓存；或改用本地 Ollama 生成模型；检索本身 <1 s |
| 解析中断 | 进程被杀/超时 | 直接重跑，已解析的图命中 `results/cache/semantic_cache.json` |

# 工单8 基于Graph‑RAG实现金融问答任务｜优化文档
工单编号：人工智能NLP‑RAG‑基于Graph RAG实现金融问答

## 1.当前系统现存问题
1. 实体、关系三元组为手工编写，不是程序自动从文档抽取；真实业务场景需要模型自动抽取。
2. 检索策略简单：仅做实体字符串包含匹配，没有语义相似度匹配。
3. 知识图谱保存在内存中，程序关闭图谱数据全部丢失，无法持久化。
4. 没有大模型生成答案，只返回三元组和原文片段，没有自然语言整理后的回答。
5. 没有实现工单需求提到的语音输入、中英双语问答拓展功能。
6. 原文检索为简单字符重叠匹配，没有做向量相似度检索。

## 2.已经完成的优化
1. 修复networkx遍历边的bug，保证图谱三元组正确召回。
2. 修复中文关键词匹配失效问题，适配中文无空格场景。
3. 端口修改为7861，避免和之前工单端口冲突。
4. 实现批量评测，一次性输出全部10条测试用例结果，方便对比工单7。
5. 输出独立HTML可视化图谱，无需部署Neo4j图数据库，降低部署复杂度。

## 3.后续优化方案
### 3.1 实体关系自动抽取
接入开源大模型，传入文本块，让模型自动输出`(头实体，关系，尾实体)`三元组，替代手工预置三元组，实现真正从文档自动构建图谱。

### 3.2 图谱持久化
方案一：接入Neo4j图数据库，把实体、关系存入数据库，程序重启数据不会丢失。
方案二：将networkx图谱保存为json文件，启动时重新加载。

### 3.3 增强检索策略
1. 图谱检索增加实体语义相似度匹配，不完全依赖字符串字面匹配，同义词也可以命中。
2. Graph‑RAG融合向量检索，图谱召回+向量文本召回结合。

### 3.4 接入大模型生成回答
把检索得到的三元组、原文片段作为上下文交给大模型，整理输出通顺自然语言答案，而不是只返回原始片段。

### 3.5 拓展功能
1. 增加语音输入识别，接收语音转文字提问。
2. 增加中英双语支持，支持英文文档、英文问题问答。

### 3.6 增加重排序Reranker模块
对召回的三元组、文本片段做二次过滤，过滤掉低相关结果，提升问答精度。

## 4.优化预期收益
1. 摆脱手工写三元组，实现端到端从文档构建Graph‑RAG。
2. 提升问答的鲁棒性，同义词、不同问法也能正确召回结果。
3. 输出整理后的自然语言答案，提升用户体验。
4. 图谱持久化，支持大数据量业务场景。

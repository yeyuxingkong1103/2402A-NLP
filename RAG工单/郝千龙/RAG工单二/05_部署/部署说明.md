# 部署说明

- 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统优化
- 部署形态：本地 Python 虚拟环境 + Streamlit Web 界面（离线可运行，无需 GPU）

## 一、环境要求

- Windows / Linux / macOS，Python 3.10 ~ 3.12
- 依赖见 [requirements.txt](file:///c:/Users/h1981/Desktop/郝千龙/RAG工单二/02_研发/requirements.txt)：
  pymupdf、pdfplumber、jieba、scikit-learn、numpy、streamlit、openpyxl、pandas、sentence-transformers（可选）
- 无外网时系统自动使用 TF-IDF + BM25 离线路径；
  若本机已缓存 BGE 嵌入/重排模型（`~/.cache/huggingface/hub`），自动升级为语义向量与 Cross-Encoder 精排，无需修改代码。

## 二、部署步骤（Windows PowerShell）

```powershell
# 1. 进入研发目录
cd RAG工单二\02_研发

# 2. 创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. 安装依赖
pip install -r requirements.txt

# 4. 构建索引（PDF -> 3300 左右文本/表格块，约 40 秒）
cd src
python build_index.py
# 产物写入 ../index_store/：chunks.pkl / tfidf.pkl / bm25.pkl / vectors.npy / meta.json
```

## 三、启动服务

```powershell
# 方式一：启动中英文双语 Web 问答界面（默认 8501 端口）
cd RAG工单二\02_研发\src
streamlit run app.py

# 方式二：命令行批量评测（验收回归）
python evaluate.py
# 输出正确率/≤3s 占比，并刷新 03_测试\评测结果.csv
```

浏览器访问 http://localhost:8501 ：

1. 左侧可切换中文 / English 界面；
2. 输入问题（如“公司的注册资本是多少？”），回车；
3. 主区展示抽取式答案、回答模式（extractive/llm）、端到端耗时；
4. 下方展示 Top-3 证据（页码 + 章节标题路径 + 证据原文），支持溯源核对。

## 四、配置调整（可选）

所有阈值集中在 [config.py](file:///c:/Users/h1981/Desktop/郝千龙/RAG工单二/02_研发/src/config.py)：

- `chunk_size=450` / `chunk_overlap=80`：分块粒度；
- `dense_top_k=20` / `bm25_top_k=20` / `final_top_k=3`：召回与展示数量；
- `response_timeout_s=3`：3 秒延迟预算；
- `use_embedding_model` / `use_reranker`：本地模型开关。

修改分块相关阈值后需重新执行 `python build_index.py`。

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 首次启动较慢 | TF-IDF 矩阵首次载入耗时，属一次性开销，后续查询约 0.03~0.7 秒 |
| 无外网环境卡住 | 系统已内置本地模型缓存检测，无缓存直接离线路径，不会联网下载 |
| 更换 PDF | 在 config 指向新的 PDF 路径后重新建库即可 |
| 8501 端口占用 | `streamlit run app.py --server.port 8502` |

## 六、可选 LLM 接入

向 `QAEngine(retriever, llm_client=...)` 传入实现了 `chat(prompt: str) -> str` 的客户端，
系统将在 2.2 秒检索预算内调用 LLM 生成自然语言答案；超时或异常自动降级为抽取式答案，保证可用。

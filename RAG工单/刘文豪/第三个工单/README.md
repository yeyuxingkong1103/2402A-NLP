# 工单03：PDF 文档的表格解析及检索优化

> 工单编号：人工智能 NLP-RAG-PDF 文档的表格解析及检索优化 ｜ 工时预估：1 人日
> 目标：新增《招股说明书2.pdf》（武汉力源信息）解析，重点解决表格类问题检索，覆盖两份招股书共14个问题

## 一、做了什么

- **表格结构化解析**：PyMuPDF `page.find_tables()` 抽取每页表格 → 转为「表头: … | 数据行 …」文本块入库（metadata 标记 `kind=table`）。表格行列不再被当普通文本流切碎——这是此前表格问题检索失败的根因。
- **双文档统一索引**：招股说明书1（兴图新科，333页）+ 招股说明书2（力源信息，350页）共 683 页，文本块 + 224 个检测到的表格块，合计 **1464 块**入库同一 ChromaDB 集合（`zhaogu_all_v3`），检索跨文档带出处。
- **查询清洗扩展**：同时去除两家公司全称/固定前缀。
- **提示词升级**：表格数值优先引用；出处标注到「招股说明书X 第X页」。

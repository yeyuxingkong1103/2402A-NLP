### 5.3 留痕与日志契约

## 6. 兼容性与版本

| 项 | 约定 |
| --- | --- |
| API 版本 | 路径不带版本号，响应体暂不设 `api_version`；破坏性变更需在 `设计/接口设计.md` 记录变更日志 |
| 中文编码 | 全链路 UTF-8；`run_py.ps1` 已设 `PYTHONIOENCODING=utf-8`/`PYTHONUTF8=1` |
| 页码口径 | **任何接口、任何产物都只接受 1-based 物理页码**；出现 `0-based` 或页脚印刷页码视为缺陷 |
| 拒绝服务口径 | 「不清楚」是**正确响应**（HTTP 200 + `refused=true`），不是错误码 |
| 演示脚本兼容 | 演示/示例问题清单的**真实来源**是 `研发/app/ui/serve_fallback.py` 的 `DEMO_QUESTIONS`（含第 5、6 题），经 `GET /questions` 暴露；Web 页示例按钮与 CLI 演示均取此处。**（早期文档引用的 `测试/用户/` 下 `demo_questions.md` 并不存在，已更正。）** |

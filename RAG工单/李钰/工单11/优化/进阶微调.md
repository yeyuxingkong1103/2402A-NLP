## 一、LoRA (参数高效微调)

```bash
pip install peft
```
```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=8,           # LoRA rank
    lora_alpha=16,
    target_modules=["q", "v"],  #  attention 层
    lora_dropout=0.05,
    bias="none",
)
model = get_peft_model(base_model, lora_config)
# 仅训练约 1% 参数, 显存大幅降低
```

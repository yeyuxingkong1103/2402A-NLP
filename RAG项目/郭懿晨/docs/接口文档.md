# 接口文档

本文档按接口逐条说明每个接口是做什么的。

## 基本信息

- **Base URL：** `http://127.0.0.1:8000`
- **返回格式：** JSON
- **上传格式：** `multipart/form-data`

## 接口一览

### `GET /health`

- 作用：检查服务是否正常运行。
- 返回：`{"status":"ok"}`。

### `GET /`

- 作用：返回前端首页 `frontend/index.html`。

### `POST /api/files/upload`

- 作用：上传 PDF 文件。
- 作用：把文件保存到 `data/` 目录。
- 作用：上传后创建 `Document` 和 `BuildTask` 记录。
- 参数：`file`，必须是 PDF 文件。
- 成功返回：`document_id`、`task_id`。
- 失败返回：例如 `只允许上传 PDF 文件`。

### `POST /api/tasks/{task_id}/start`

- 作用：启动指定任务。
- 作用：后台执行解析、分块、向量化和入库。
- 参数：`task_id`，任务 ID。
- 成功返回：`{"task_id":"...","status":"scheduled"}`。
- 失败返回：`任务不存在`。

### `GET /api/tasks/{task_id}`

- 作用：查询任务状态。
- 作用：查看任务当前步骤和进度。
- 参数：`task_id`，任务 ID。
- 返回字段：`task_id`、`document_id`、`step`、`progress`、`status`、`error_message`、`created_at`、`updated_at`。
- 失败返回：`任务不存在`。

### `GET /api/documents`

- 作用：列出所有已保存的文档。
- 返回字段：`document_id`、`file_name`、`file_path`、`status`、`created_at`。

### `GET /api/vector-store`

- 作用：列出向量库里的 chunk 元数据。
- 返回字段：`chunk_id`、`document_id`、`page`、`category`、`text`。

### `GET /api/categories`

- 作用：列出当前向量库里已有的 MinerU 标签类别。
- 返回示例：`["正文", "表格", "标题"]`。

### `POST /api/chat`

- 作用：根据问题做检索问答。
- 作用：先检索相关 chunk，再调用本地 Ollama 生成答案。
- 作用：如果没有证据，就返回兜底答案 `知识库中未找到相关依据。`。
- 参数：`question`，用户问题。
- 返回字段：`answer`、`citations`、`fallback`。
- `citations` 中每项包含：`document_id`、`file_name`、`page`、`category`、`text`。

## 错误说明

- `400`：上传的不是 PDF 文件。
- `404`：任务不存在。
- `422`：请求参数格式不正确。

## 调用示例

```bash
curl -F "file=@example.pdf" http://127.0.0.1:8000/api/files/upload
curl -X POST http://127.0.0.1:8000/api/tasks/your-task-id/start
curl -X POST http://127.0.0.1:8000/api/chat -H "Content-Type: application/json" -d "{\"question\":\"本标准适用于哪些场景？\"}"
```

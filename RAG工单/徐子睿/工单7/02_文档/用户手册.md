# 金融问答系统（Graph RAG）· 用户手册

> 工单编号：人工智能NLP-RAG-基于Graph RAG实现金融问答
> 工程根：`D:\桌面\徐子睿工单二`

## 1. 启动系统

```bat
cd /d D:\桌面\徐子睿工单二
:: 首次使用：先建知识库与知识图谱
python app\build_kb_txt.py
python app\graph_build.py
:: 启动服务（默认 8101 端口）
python -m uvicorn app.server:app --host 0.0.0.0 --port 8101
```
浏览器打开 `http://localhost:8101/`。

> 依赖：本机 Ollama（需 `bge-m3` 与 `qwen2:7b`）：`ollama list` 能看到这两个模型即可。

## 2. 界面与操作

### 2.1 提问（文字 / 语音）
1. 在输入框输入问题（例如：*平安银行2019年实现营业收入和净利润分别是多少？*），点「提问」或 `Ctrl+Enter`；
2. 点「🎤 语音」可用浏览器语音识别输入（Web Speech API，需 Chrome/Edge）；
3. 答案下方显示 **引用来源**（页码 + 章节 + 片段），可展开核对。

### 2.2 Graph RAG 模式（知识图谱问答）
1. 勾选顶部 **「Graph RAG」**；
2. 提问后答案下方会展示 **知识图谱结构**：
   - 识别到的实体：公司 / 指标 / 年份；
   - `公司 —[披露指标]→ 指标 = 值（年份，来源页）` 三元组；
   - 引用来源会标出来自 `graph`（图谱直命中）还是 `hybrid`（混合检索补足）。

### 2.3 查看知识图谱可视化
- 点顶部 **「🕸️ 知识图谱」** 打开交互式图谱（可拖拽/缩放/悬停看关系）；
- 节点按类型分色：**公司(蓝) / 行业(绿) / 指标(黄) / 年份(紫)**；边上标注“年份 数值”。
- 也可用命令行按问题生成“相关子图”：`python app\graph_viz.py "你的问题"` → `static/graph_query.html`。

### 2.4 检索策略对比（进阶）
- 顶部「策略」（rrf / hybrid / vector / fulltext）与「重排」（none / tfidf / llm / feedback）可切换；
- 点 **「仅检索」** 只返回检索到的文本块（不生成答案），便于对比不同策略的命中差异。

### 2.5 多轮对话
- 直接连续提问即可（系统用 session_id 维护上下文）：
  - *"他参与的哪个工程荣获了国家科技进步一等奖？"*（“他”自动指向上文公司）
  - *"那武汉力源信息技术股份有限公司呢？"*（继承上一轮意图，切换公司）
- 点「清空」会重置当前会话。

## 3. 常见问题

| 现象 | 处理 |
|---|---|
| 页面提示“知识库未就绪” | 先运行 `python app\build_kb_txt.py` |
| 提问报错/无答案 | 确认 Ollama 在运行（`curl http://localhost:11434/api/tags`）|
| 知识图谱页空白 | 先运行 `python app\graph_build.py` 生成 `data/graph/graph.json` |
| 端口被占用 | 换端口：`--port 8102` |
| 上传 PDF（可选）| 用 `/api/upload`（FastAPI 文档页 `/docs` 可直接试），随后重建知识库 |

## 4. 支持的问题类型（示例）
- **数值题**：平安银行2019年营业收入/净利润、拨备覆盖率、不良贷款率；中国平安归母净利润；中信证券/招商证券/国泰君安营收与净利；中国太保营业收入与保险业务收入。
- **图谱题**：某公司属于哪个行业、某指标各年数值、跨公司同指标对比（用于研报生成）。
- **多轮题**：代词指代、省略式追问、实体切换（见 2.5）。

## 5. 输出说明
- **答案**：带页码引用的自然语言回答；
- **知识图谱结构**：实体链接结果 + 三元组（公司–指标–值@年份–来源页）；
- **检索来源**：`graph`（知识图谱直命中）/ `hybrid`（混合检索）；含相似度与耗时。

# 工单4 - 研发文档
## 1. 开发环境
- OS：WSL Ubuntu 24.04
- Python版本：3.12
- 虚拟环境：venv_gongdan1
- Milvus：单机本地服务
- 开发工具：VS Code + WSL

## 2. 模块拆分
### 模块1：PDF生成与PDF转图片（gen_pdf.py）
- ReportLab生成模拟招股说明书PDF
- PyMuPDF读取PDF，逐页渲染，保存为png图片，存入pdf_images文件夹

### 模块2：Milvus集合管理（create_collection.py）
- 连接Milvus服务
- 删除旧集合，新建集合，定义字段与向量索引，初始化向量表结构

### 模块3：向量编码工具
- CLIP模型加载：openai/clip-vit-base-patch32
- image_embedding：输入PIL图片，输出512维纯Python float向量
- text_embedding：输入文本字符串，自动截断超长文本，输出512维向量
- 向量类型处理：将numpy数组转为原生Python float列表，适配Milvus3.x类型校验

### 模块4：向量入库模块 insert_image_data()
遍历pdf_images目录下所有png图片，循环生成图片向量，批量插入Milvus数据库。

### 模块5：向量检索模块 multimodal_search()
接收用户问题，生成文本向量，调用Milvus search，返回Top2相似度结果。

### 模块6：Flask Web服务
- GET /：返回前端页面HTML
- POST /ask：接收前端提问，调用检索函数，返回结果

## 3. 开发踩坑记录
1. Milvus3.x对向量元素类型严格校验，numpy.float32类型会报错，需要循环转为原生Python float
2. CLIP模型输出对象不是tensor，需要读取`.pooler_output`获取张量
3. CLIP文本最大token长度77，长问句会报错，需要开启truncation=True自动截断
4. WSL环境Flask启动必须监听0.0.0.0，Windows主机浏览器才能访问

# 工单 02 — 基于 PDF 文档的问答系统的优化

> 工单编号：人工智能NLP-RAG-基于PDF 文档的问答系统优化

针对工单 01 实现的问答系统，从 PDF 解析处理、分块优化、检索优化三个层面提升检索准确率（目标 90%+），并对比优化前后的检索精确度变化。

## 优化方案

| 层面 | 优化前（基线） | 优化后 |
| --- | --- | --- |
| 分块 | 朴素滑动窗口（size=400） | 结构感知分块（按段落/标题合并，语义完整，size=500 + overlap） |
| 检索 | 仅向量检索 | 向量检索 + BM25 全文检索的混合检索（RRF 融合） |
| 重排 | 无 | TF-IDF / LLM 重排器二次排序 |

## 运行

```bash
pip install -r requirements.txt   # 依赖（可复用工单 01 已装环境）
cd 2
python main.py                    # 对比 10 个问题优化前后精度/召回
python main.py --query "武汉兴图新科电子股份有限公司注册资本是多少？"
```

输出表格展示每个问题的基线精度 vs 优化精度，以及平均值与提升幅度。

## 说明

- 配置 LLM 接口后（见 `../1/.env.example`），会启用 LLM 重排与真实生成，效果更佳；不配置也可离线运行。
- 验收目标：问答准确率 ≥ 90%，响应时间 ≤ 3 秒。

# 接口文档

**工单编号**：人工智能NLP-RAG-PDF文档的表格解析及检索优化

## 基础信息

- **Base URL**: `http://localhost:8000`
- **API 文档**: `http://localhost:8000/docs`
- **版本**: 3.0

## 接口列表

### 1. 健康检查

**GET** `/api/health`

返回系统健康状态和缓存统计。

**响应示例**：
```json
{
  "status": "ok",
  "collection_count": 3332,
  "data_dir": "...",
  "cache": {
    "size": 0,
    "max_size": 256,
    "hits": 0,
    "misses": 0,
    "hit_rate": 0
  },
  "llm_cache": {...},
  "version": "3.0",
  "features": ["表格解析", "混合检索", "缓存优化"]
}
```

### 2. 系统统计

**GET** `/api/stats`

返回系统统计信息。

### 3. 上传 PDF

**POST** `/api/upload`

上传 PDF 文件到 data 目录。

**请求**：
- `file`: PDF 文件（multipart/form-data）

**响应**：
```json
{
  "filename": "example.pdf",
  "saved_path": "...",
  "size": 12345
}
```

### 4. 入库处理

**POST** `/api/ingest`

解析 PDF 文件并入库。

**请求**：
```json
{
  "files": ["file1.pdf", "file2.pdf"]  // 可选，为空则处理所有
}
```

**响应**：
```json
{
  "processed": 2,
  "ingested": 2,
  "total_chunks": 3409,
  "collection_count": 3332
}
```

### 5. 纯检索

**GET** `/api/search?query={query}&top_k={top_k}`

检索相关文档，不调用 LLM。

**参数**：
- `query`: 查询文本
- `top_k`: 返回数量（默认 3，最大 20）

**响应**：
```json
{
  "query": "...",
  "total": 3,
  "results": [
    {
      "page_content": "...",
      "score": 0.95,
      "rerank_score": 0.98,
      "source": "招股说明书1.pdf",
      "page_number": 22,
      "block_type": "table"
    }
  ],
  "elapsed_sec": 0.15
}
```

### 6. 问答接口

**POST** `/api/chat`

检索 + LLM 生成答案。

**请求**：
```json
{
  "query": "问题文本",
  "top_k": 3,
  "stream": false
}
```

**响应**：
```json
{
  "query": "...",
  "answer": "...",
  "references": [...],
  "timing": {
    "search": 0.15,
    "llm": 5.2,
    "total": 5.35,
    "cached": false
  }
}
```

## 错误码

| 状态码 | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 500 | 服务器内部错误 |

## 特性说明

### 表格解析

- 自动识别 PDF 中的表格结构
- 转换为 Markdown 格式保留行列语义
- 表格块不参与切分，保持完整性

### 混合检索

- 向量检索（Milvus + bge-m3）
- BM25 检索（jieba 分词）
- RRF 融合排序
- CrossEncoder 重排

### 缓存优化

- 检索结果 LRU 缓存（256 条）
- LLM 答案 LRU 缓存（256 条）
- 缓存命中时响应时间 < 10ms

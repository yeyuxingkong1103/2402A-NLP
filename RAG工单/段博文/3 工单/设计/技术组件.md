## 二、表格解析组件

### pdfplumber

- **功能**：识别 PDF 中的表格结构
- **输出**：行列结构的表格数据
- **转换**：自动转换为 Markdown 表格格式

### 表格块处理流程

1. **识别**：pdfplumber 检测表格边界
2. **提取**：提取表头和数据行
3. **转换**：转为 Markdown 格式保留结构
4. **入库**：表格块不切分，保持完整性

## 三、数据流

```
PDF 文件
  ↓
[文本提取] PyMuPDF → 文本块
  ↓
[表格识别] pdfplumber → 表格块（Markdown）
  ↓
[切分] RecursiveCharacterTextSplitter → 文档块
  ↓
[向量化] bge-m3 → 向量
  ↓
[入库] Milvus → 向量数据库
```

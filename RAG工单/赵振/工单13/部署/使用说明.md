# 启动和复现
本机双击部署/启动网页.bat，再手动打开http://127.0.0.1:8513。服务就绪前需等待模型与索引加载；如果网页已经能打开，直接使用现有服务。

独立迁移需要Python3.12，先安装部署/requirements.txt。首次基础模型下载需要联网或使用已有HuggingFace缓存；程序固定使用运行环境.json记录的模型版本，确保查询向量和索引一致。已包含索引，不需工单11/12目录或再次建库。

```powershell
python -m pip install -r 部署/requirements.txt
python 研发/perf.py serve
```

服务运行后，另开终端执行`python 研发/perf.py benchmark`，或双击部署/重跑测试.bat。完整基准包含六个实际Ollama问答调用；需安装Ollama、运行`ollama pull deepseek-r1:7b`并启动`ollama serve`。纯检索网页无需Ollama。

网页可选择优化前/后与RAG/LightRAG。检索按钮先返回原文；生成答案按钮执行完整问答，显示独立耗时。监控超过3秒标红，是本地页面告警，不向他人发送消息。

运行benchmark会更新测试/benchmark.json与profile文件，并追加trace日志；当前原始第一次记录已单独保留。service只监听127.0.0.1；本工单没有启动Docker、远程服务器或改动旧工单。

缓存只在进程内，最大128条，重启清空；修改索引必须重启。测试固定小型索引，更多并发或更大语料应重新测试。

提交GitHub：解压交付ZIP，再上传工单13目录。包内单文件及ZIP均检查小于25MB。

# 系统演示步骤（演示视频脚本）

> 说明：工单 PDF 要求提供演示视频。本环境为无录像条件的离线环境，
> 以下为可直接照做的 **5 分钟完整演示脚本**（含解说词与预期画面），
> 由演示人按步骤操作并录屏即可生成验收演示视频。

## 演示前准备

- 已完成 [部署说明](file:///c:/Users/h1981/Desktop/郝千龙/RAG工单二/05_部署/部署说明.md) 中的安装与建库；
- 分辨率 1280×720 以上，浏览器缩放 100%；准备计时工具（界面自带耗时显示）。

## 分镜脚本

### 镜头 1（约 40s）：项目结构与建库

```powershell
cd RAG工单二\02_研发\src
python build_index.py
```

解说词：系统采用 PyMuPDF 与 pdfplumber 双引擎解析招股书，经标题感知分块后构建
稠密向量与 BM25 双路索引，共 3290+ 块，建库约 40 秒。

### 镜头 2（约 40s）：批量评测跑批

```powershell
python evaluate.py
```

解说词：对工单规定的 10 个问题批量评测，可以看到 10 题全部判对、每题耗时均小于 3 秒，
正确率 100%，高于验收线 90%。

### 镜头 3（约 90s）：多类型问题现场问答（Streamlit）

```powershell
streamlit run app.py
```

依次输入并展示答案与来源：

1. **多数字枚举**：报告期内，公司来自军用领域的收入分别是多少？
   预期：6,464.51 / 14,414.16 / 18,780.67 / 4,627.14 万元，来源第 129 页。
2. **标准实体**：公司参与制定了哪个技术标准？
   预期：全军第一个视频指挥系统技术标准《某视频技术规范1.0》，第 159 页。
3. **列表型（下游行业）**：电子信息行业的下游主要包括哪些行业？
   预期：军队、政府机关、能源等行业企业，第 152 页。
4. **数字槽位**：公司的注册资本是多少？
   预期：5,520 万元。
5. **人名槽位**：公司的法定代表人是谁？
   预期：程家明。
6. **表格数字**：计划使用多少募集资金补充流动资金？
   预期：15,000.00 万元，第 479 页募集资金用途表。

### 镜头 4（约 40s）：证据溯源

点击每条回答下的证据卡片，展示页码、章节路径（如“第六节 业务与技术 >
二、发行人所处行业基本情况”）与原文，对照招股书 PDF 核验。

### 镜头 5（约 30s）：中英双语切换

侧边栏切换 English，输入英文问题（如 "What is the registered capital?"），
展示英文界面下答案、证据与延迟展示正常。

### 镜头 6（约 20s）：性能展示

连续快速提问 3 题，强调界面显示的 latency 均在 0.1 秒量级，满足 ≤3 秒要求；
打开任务管理器展示纯 CPU、低内存占用（离线模式无需 GPU）。

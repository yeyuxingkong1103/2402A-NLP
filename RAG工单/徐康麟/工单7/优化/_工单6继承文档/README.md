## 4. 结论（实测数字，2026 运行）

### 4.1 对话级缓存（`对话缓存基准.json`）

输入 = 工单指定的五轮序列，同一 session；协议 = 三阶段独立进程串行。

| 指标 | 数值 |
| --- | --- |
| 冷跑基线（不经缓存）P50 | **633.97 ms**（逐轮 865.91 / 633.97 / 212.24 / 209.88 / 806.46） |
| 未命中（真实执行）P50 | **613.19 ms**（逐轮 949.84 / 613.19 / 223.10 / 223.48 / 753.66） |
| 命中（缓存返回）P50 | **0.9 µs**（逐轮 0.9 / 2.9 / 1.1 / 0.8 / 0.9 µs） |
| `cache.get` 查表 P50（可比口径） | **0.03 ms** ⇒ 相对冷跑基线 P50 **21132.3×** |
| 端到端每次命中省下 | **约 634 ms**（比值 >1000×，毫秒分辨率已溢出，只给下界） |
| 测量窗口命中率 | **50%**（5 命中 ÷ 10 次查表：每轮先未命中再命中）；第 2 次及以后提问为 100%；`DialogueCache.stats()` 累计 hits/misses = 5/5 |
| 正确性校验（同轮同会话，缓存包装 vs 直调引擎） | **硬口径 4/5 一致**（`answer` / `rewritten_query` / `refused`）；不一致的 1 轮是**模型侧随机性**（同一问句两次独立生成的引用页码不同，见 4.3） |
| 答案自证（关键字口径，源自 `研发/data/eval/golden_qa.jsonl`） | 军用领域收入 **4/4** 命中；组织结构图销售处 **9/9** 命中 |

**怎么读「4/5 一致」**：缓存命中返回的是**逐字回放**（同一对象深拷贝），不可能与它自己不一致；
不一致来自「另一次独立生成」——同一问句两次调用模型，答案正文一致、**引用页码会不同**。
因此报告把字段分成两档：`answer/rewritten_query/refused` 为硬口径（必须一致），
`cited_pages/focus_entity/strategy` 为软口径（并列展示，不计入通过判定）。

### 4.2 对话历史压缩（`历史压缩基准.json`，keep_recent=3 / max_chars=240 / 每档 20 次取 P50）

| 轮数 | 原始字符 | 压缩后字符 | 字符压缩比 | 节省 | 摘要耗时 P50 / max |
| --- | --- | --- | --- | --- | --- |
| 10 | 1017 | 458 | 0.4503 | 54.97% | 0.667 / 2.683 ms |
| 30 | 3066 | 462 | 0.1507 | 84.93% | 2.441 / 3.261 ms |
| 100 | 10243 | 464 | 0.0453 | **95.47%** | 3.117 / 4.329 ms |

* 摘要硬上限全部被遵守（`max_chars` 60/120/240/360/600 逐档验证）；
* 摘要里**保留了公司全称**（如「武汉力源信息技术股份有限公司」）与问过的字段槽位；
* 压缩比随轮数增长而下降，因为**压缩后长度几乎恒定**（≈ 摘要 + 最近 3 轮原文 ≈ 460 字符）。

### 4.3 关键设计决定（都是踩过坑才定下来的）

1. **缓存键必须含 `session_id`**：同一问句「这个公司的法定代表人是谁？」在不同会话指向不同公司，
   跨会话复用会把 A 公司的答案发给 B 会话。
2. **基准的三阶段必须各自独立进程**：`QAEngine` 自带一层进程内答案缓存，键为
   `question + lang + top_k`（**不含 session_id**）且无外部开关。同进程跑第 2 个阶段会被它
   短路——实测冷跑 P50 从数百毫秒掉到 3~5 ms，基准当场失效。
3. **命中耗时用 µs 记**：命中路径不执行检索与生成，实测 0.9 µs，毫秒分辨率下四舍五入成 `0.00`。
4. **摘要扫描窗口化**：只扫「最早 5 轮 + 最近 30 轮」，避免 1000 轮会话里摘要成本随轮数线性增长
   （实测 100 轮摘要耗时 18.1 ms → **3.1 ms**，压缩比几乎不变）。
5. **`pytest.ini` 已删除**：DSH 沙箱下 `tmp_path`（系统临时目录或仓内 basetemp）都会
   `PermissionError: [WinError 5]`，故单测改用**工作区内自建临时目录**的 `tmp_dir` fixture。

# 工单6 - RAG混合检索系统｜部署文档
## 1.环境准备
### 1.1 基础环境
- WSL Ubuntu 24.04
- Python 3.12
- Docker（用于部署Milvus向量数据库）

### 1.2 虚拟环境准备
复用已有的工单5虚拟环境 venv_gongdan5
```bash
# 激活虚拟环境
source /mnt/c/Users/陈/Desktop/工单5/venv_gongdan5/bin/activate
# 安装项目依赖包
pip install rank-bm25 sentence-transformers
## 2.Milvus 数据库部署

1. Docker 启动 Milvus 独立容器，端口映射 19530。
2. 确认 Milvus 服务正常启动，可在本地 127.0.0.1:19530 连接。

> 
> 注意：Milvus 必须提前启动，否则程序连接数据库失败。

## 3. 项目文件部署

将文件放置到工单 6 文件夹，目录结构：
工单6/
├─ main.py
├─ 招股说明书.pdf
> 注意：PDF 文件名必须和代码内保持一致，放在 main.py 同目录。

## 4. 启动应用
# 进入工单6目录
cd /mnt/c/Users/陈/Desktop/工单6
# 激活虚拟环境
source /mnt/c/Users/陈/Desktop/工单5/venv_gongdan5/bin/activate
# 启动Flask服务
python3 main.py
程序启动流程：

1. 加载 PDF 文档，文本切分
2. 构建 BM25 词表
3. 向量化文本，重建 Milvus 集合，写入向量
4. 启动 Flask Web 服务，监听 0.0.0.0:7860

## 5. 访问服务

WSL 内网地址：`http://172.17.189.52:7860`
Windows 浏览器直接打开该地址，即可进入网页系统。

## 6. 部署注意事项

1. 每次新开终端，必须重新激活虚拟环境。
2. Milvus 容器必须提前启动。
3. 程序启动时会自动删除同名 Milvus 集合，重新入库。
4. 程序为 Flask 开发服务器，仅用于实训演示，不可直接用于生产环境。
5. 关闭终端 / 按 Ctrl+C，服务会停止。

## 7. 常见部署故障排查

1. ModuleNotFoundError：虚拟环境未激活。
2. Milvus 连接失败：Docker Milvus 容器未启动。
3. 找不到 pdf 文件：PDF 文件不在 main.py 同级目录。

# 部署 · 01 环境依赖

> 工单编号：人工智能NLP-RAG-PDF 文档的表格解析及检索优化

---

## 1. 运行环境总览

| 项 | 版本 / 说明 |
|---|---|
| 操作系统 | Windows 11（脚本对非 ASCII 路径已做兼容，见 §5） |
| Python | 3.10（conda 环境 `langchain2`） |
| 推理服务 | Ollama（本地，默认 `http://localhost:11434`） |
| 向量模型 | `bge-m3:567m`（1024 维，中文强） |
| 生成模型 | `deepseek-r1:1.5b`（仅基线/消融链路使用） |
| 向量库 | FAISS（`faiss-cpu`，本地单文件持久化） |
| 演示界面 | Streamlit |

> **全部本地化**：不依赖任何外部 API Key，数据不出本机。

## 3. Ollama 与模型准备

```powershell
# 1) 安装 Ollama 并启动服务（默认端口 11434）
#    验证服务可用：
Invoke-WebRequest http://localhost:11434/api/tags -UseBasicParsing

# 2) 拉取所需模型
ollama pull bge-m3:567m
ollama pull deepseek-r1:1.5b

# 3) 确认模型就位
ollama list
```

> 只需 `bge-m3:567m` 即可完成**建库 + 优化链路问答**；
> `deepseek-r1:1.5b` 仅在"优化前基线"与消融链路中用于生成。

## 5. 环境变量（`.env`，可选）

复制 `.env.example` 为 `.env` 后按需修改，未设置则用 `src/config.py` 默认值。

```ini
# ---- Ollama ----
OLLAMA_BASE_URL=http://localhost:11434
LLM_MODEL=deepseek-r1:1.5b
EMBEDDING_MODEL=bge-m3:567m

# ---- 表格解析 ----
USE_TABLE_PARSER=1
TABLE_KV_ENABLE=1

# ---- 检索 ----
TOP_K=6
VECTOR_TOP_K=30
BM25_TOP_K=30
DOC_FILTER_ENABLE=1        # 文档级路由（多文档消歧）
W_DOC=0.18

# ---- 答案合成 ----
ANSWER_MODE=extractive     # extractive（默认） / llm
```

## 6. 兼容性说明

| 问题 | 处理 |
|---|---|
| Windows 中文路径导致 FAISS 保存失败 | `knowledge_base.save_local/load_local` 检测非 ASCII 路径，先写临时 ASCII 目录再拷贝回 |
| FAISS AVX2 警告 | 使用 `faiss-cpu`，警告不影响功能，可忽略 |
| 首次加载 embedding 模型慢 | 评估脚本默认**预热**（先跑 1 题），演示界面用 `st.cache_resource` 缓存引擎 |
| 大库一次性嵌入超时 | `_BatchedEmbeddings` 按 50 条分批请求 Ollama |

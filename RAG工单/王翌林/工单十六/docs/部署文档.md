# 工单十六 · 部署文档

## 1. 环境要求

- OS：Linux（推荐 Ubuntu 22.04）/ WSL2
- GPU：NVIDIA 显卡（≥ 8GB 显存），已安装驱动
- Python：3.10（建议 conda 或 venv）
- 基座模型：`Qwen2-VL-2B-Instruct`，放置于 `/home/dabaie/models/`

## 2. 安装（install.sh）

```bash
bash scripts/install.sh
```

脚本会：
1. 检测 `nvidia-smi` 与 CUDA；
2. 安装 Python 依赖：torch、transformers、accelerate、peft、datasets、loguru、pillow、matplotlib、pymupdf；
3. 可选安装 `bitsandbytes`（4bit 量化，失败则自动回退 fp16，不影响主流程）。

或手动：
```bash
pip install torch transformers accelerate peft datasets loguru pillow matplotlib pymupdf
```

## 3. 启动（start.sh）

```bash
bash scripts/start.sh
```

一键执行：数据构建（若缺失）→ LoRA 微调（3 epoch）→ 评估对比 → 生成图表。
产物：
- `finetune_output/lora_adapter/` LoRA 权重
- `docs/screenshots/eval_baseline.json`、`eval_finetuned.json` 评估结果
- `docs/screenshots/*.png` 设计图与曲线图

可通过环境变量定制：
```bash
PYTHON_BIN=/path/to/python bash scripts/start.sh
```

## 4. 停止（stop.sh）

```bash
bash scripts/stop.sh
```

结束微调/评估进程并释放 GPU 显存。

## 5. 分步命令

```bash
# 微调
PYTHONPATH=$(pwd) python src/finetune.py --epochs 3 --lr 1e-4 --batch-size 1 --grad-accum 4 --no-4bit
# 评估
PYTHONPATH=$(pwd) python src/evaluate.py --max-eval 18
# 出图
python scripts/gen_diagrams.py
```

## 6. 显存说明

| 配置 | 显存占用 | 说明 |
|------|----------|------|
| fp16 + grad_ckpt + 冻结视觉塔 + batch=1 | ~4-5 GB | 默认，8GB 卡可跑 |
| + 4bit 量化（需 bitsandbytes） | ~2-3 GB | 更省显存 |

若 OOM：降低图像边长（`finetune.py` 中 `max_side`）、保持 batch=1、关闭其他占显存进程。

C4 现场：同一语义、不同写法 → 判定结果不同（英文写法会静默漏判）
================================================================================================
status 取值         来源                    语义期望              展示侧     关键词侧      结论
------------------------------------------------------------------------------------------------
repealed          英文·旧列注释口径             应判失效              True    True      BUG 漏判
superseded        英文·旧列注释口径             应判失效              True    True      BUG 漏判
已废止               中文·现行词表               应判失效              False   False     OK 判失效
已失效               中文·现行词表               应判失效              False   False     OK 判失效
effective         英文·旧列注释口径             应判有效              True    True      OK 判有效
现行有效              中文·现行词表               应判有效              True    True      OK 判有效
not_applicable    英文·批次26写入             不参与时效判断           True    True      OK 不判失效
不适用               中文·现行词表               不参与时效判断           True    True      OK 不判失效
------------------------------------------------------------------------------------------------
结论：repealed / superseded 两个英文取值应判失效却判了有效（静默漏过滤）；
      中文词表取值全部与语义期望一致。这就是 C4 必须统一的根因。

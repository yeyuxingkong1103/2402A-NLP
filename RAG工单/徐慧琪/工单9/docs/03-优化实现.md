### 2.1 图谱合并（`w9/kg_merge.py`）

核心函数：`build_kg9()` → 加载 08 第1层 → `merge_layer2()` → 落盘 `data/kg09/`。

**两遍扫描**（先判关系、后定节点）：

```python
# 第一遍：关系过六道闸门，收集被接受的关系与归一后端点
for raw in rels_raw:

    accepted.append((Relation(...), hn, tn))

for rel, hn, tn in accepted:

```

**实体归一的四步**（`resolve_entity`）：

1. **指代消解**：「本公司/本行/该公司」→ 按 `source_doc` 映射到主体公司；
2. **领域同义合并**：`DOMAIN_ALIASES`（深圳发展银行 → 平安银行）——
   **必须放在 Company 分支之前**，否则历史名称永远合并不掉（实测踩坑）；
3. **别名归一**：`ALIAS_TO_CANON` 的键统一过 `norm_name`，解决全角/半角括号差异；
4. **噪声过滤**：泛称、职务名（`ROLE_STOPWORDS`）、文档标题（`_DOC_TITLE_RE`）。

**chunk 取文本必须用 `(source, chunk_id)`**（`chunk_key`）：语料里 chunk_id 跨文档重复
（7757 条块只有 1185 个不同 id）。实测用单键时，闸门 3 拿 B 文档原文核验 A 文档证据，
把 **127 条关系里的 118 条**误杀成「证据不落地」。

### 2.2 六道闸门（要点）

```python
REL_EVIDENCE_KEYWORDS = {
    "SHAREHOLDER_OF": ("股东","持股","控股","出资","股权","所有者权益","发起人","表决权"),
    ...
}
```
> 刻意**不含**「股份」「合伙」：它们几乎出现在每个公司全称里
> （「招商证券**股份**有限公司」），收进来闸门等于失效。实测教训：因为收了
> 「合伙」，把「杨如生先生现任瑞华会计师事务所合伙人」当成了「平安银行持有瑞华」的证据。

**闸门5 `mentions_tail`**：证据必须点到关系对象。用于拦截
`储一昀 --SERVES_AS--> 平安银行` 这类「证据确实出自本文件、也确实在讲任职，
但讲的是**别家公司**」的假阳性。

**闸门6 `direction_ok`**：对 `SHAREHOLDER_OF / CONTROLS / INVESTS_IN` 检查方向；
证据里出现「（控股）股东 + 尾实体名」句式时，说明**尾才是股东** → 方向反了 → 丢弃。

### 2.3 定向补抽（`w9/kg_extract_v2.py`）

- `select_blocks()`：按 11 类主题词表（董事长致辞/风险管理/拨备/绿色金融…）
  对候选块打分排序，**排除 08 已抽过的块**（按 `(source, chunk_id)` 判定）；
- `extract_one()`：两段式（实体 → 关系），并做 **`_dedupe_entities` 退化折叠**；
- `degenerate` 标记与 `n_raw/n_uniq` 落盘，用于量化模型可靠度。

## 三、层面2 实现（`w9/retrieve_v2.py`）

```python
def retrieve_v2(question, kg, use_cache=True) -> RetrievalResult:
    # 1) link_entities_v2     —— 去噪实体识别
    # 2) classify_question    —— factual / compare / global / org
    # 3) decompose_question   —— 全局型拆成侧面子查询
    # 4) subgraph_v2          —— 自适应 k-hop（08 的 retrieve_subgraph，临时改配置）
    # 5) filter_graph_facts   —— 图谱事实按相关性筛选
    # 6) retrieve_text_v2     —— 多路召回（含文档路由）
    # 7) fuse + filter_low_quality + round-robin
    # 8) rerank_final         —— 统一精排
    # 9) build_context_v2     —— 四分区上下文
```

**文档路由（O2）**：直接复用 08 的 `doc_router.route(query)`；唯一命中返回该 source，
多命中/未命中返回 None（不过滤）—— 语义正确，无需自己实现。

**查询分解（O5）**：`_ASPECT_TRIGGER` 决定问句触发了哪些侧面；每个侧面用
`ASPECT_TERMS` 的代表词构造聚焦子查询。首项**始终是原问题**，保证分解不理想时
最直接的命中仍在候选里。

**round-robin 选取**：`_select_round_robin(groups, budget)` 逐组取当前最优，
保证每个侧面都有代表进入上下文。

**低质量块过滤（O4）**：`_sep_ratio(text) > 0.15`（实测骨架块 0.33~0.39、正文块 0.00）。

**统一精排（O6）**：`rerank_final(question, candidates, top_k)` 用**原始问题**
（而非子查询）作为排序依据 —— 最终要回答的是原问题，子查询只是召回手段。

## 四、层面3 实现（`w9/qa_v2.py` + `graph_qa_v2.yaml`）

**引用机制（G-2）—— 本工单最关键的生成层改动**：

```python
_CITE_RE = re.compile(r"\[(\d+)\]")

def _append_citations(answer, cites, lang):
    used = sorted({int(m) for m in _CITE_RE.findall(answer)})
    ...
    rows.append(f"[{n}] {c['source']} 第 {c['page']} 页 "
                f"（block_type={c['block_type']}, id={c['chunk_id']}）")
```

- Prompt 只要求模型写 `[n]`；
- 编号 → 真实来源的映射由 `citation_index()` 按**与 `build_context_v2` 完全一致的

**上下文四分区（G-5）**：`build_context_v2` 输出【图谱事实】【文本证据】
【表格证据】【图像描述】，每块带 `来源 / 页码 / block_type / id`。

## 五、评估实现

| 模块 | 职责 |
| --- | --- |
| `w9/questions.py` | 主集（sample_questions 4 题）+ 辅助集（08 的 14 题）；处理「xx银行」掩码 |
| `w9/ragas_eval.py` | RAGAS 评估 + **裁判提示适配**（见下） |
| `w9/metrics_aux.py` | Precision@k / Recall@k / Hit Rate / MRR / NDCG@k |
| `w9/run_eval.py` | 双系统跑题、计时、落盘 |
| `w9/compare.py` | 生成 `docs/04-评估报告.md` |

**裁判提示适配（重要）**：RAGAS 官方判分提示是英文长 few-shot，本机
qwen2.5:3b 大量解析失败（`RagasOutputParserException`），失败样本被记为 NaN →
均值静默丢样本。故把 instruction/examples 换成**中文极简版**，但保留 RAGAS 原生
`input_model`/`output_model`，判分口径不变。

适配后仍需**校准**：初版中文提示让模型过度字面化 —— 上下文明明包含答案
（业务结构/拨备覆盖率），只因没出现「董事长致辞」四字就判 0，导致
context precision 掉到 **0.05**。加入「看实质信息不看字面措辞」的规则与一条
同域反例后，判定恢复正确（实测：相关=1、无关=0、表格骨架=0）。

## 六、容错实现（`w9/runtime9.py`）

8 类故障逐条对应实现位置，见 `docs/09-容错与长时间运行.md`。要点：

- 全链路**不向调用方抛异常**：`ask_v2` 内部捕获检索/生成异常并降级；
- `rerank_final` 精排失败 → 按原召回分排序；
- `get_logger` 初始化失败 → 降级为 `NullHandler`，不影响主链路；
- `health_check()` 一键暴露 graph/qdrant/llm/reuse/memory/disk 六块状态。

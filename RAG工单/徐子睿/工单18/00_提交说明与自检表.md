## 一、任务描述（摘自工单）

围绕 Anthropic **Agent Skills** 三层结构（元数据层 / 指令层 SKILL.md / 资源层），实现一个**知识库文档质量评估 Skill**，并集成进「智能体工作流 + API」：

- **任务一**：在 Cursor/Trae 中导入并使用 Claude Skills。
- **任务二**：用 skill-creator 创建 **DocumentQualityAssessmentSkill**，含五大基本功能：
  1. **格式分布统计**（.pdf/.docx/.md… 数量与占比）；
  2. **PDF 页面类型识别**（文字型/扫描型/混合型；逐页字符数阈值判定，扫描页占比 >70% 记为扫描型；**阈值可配置**，输出「待确认」列表）；
  3. **文档长度分布**（P25/P50/P75/P90/P99 + 长度区间分布）；
  4. **重复检测**（MD5 精确 + **SimHash** 近似 → 「待确认的版本冲突列表」）；
  5. **敏感信息检测**（手机号/邮箱/身份证；**银行卡默认关闭**；**每条命中附带上下文** → 「待审核列表」）；
  以及 **文档分类标签体系**。
- **任务三**：把 Skill **注册到 RAGFlow 智能体技能库**；编写单测；创建 **document_ingestion_workflow**（触发质检 → 调用 Skill → 按分类标签路由：扫描型→OCR）；暴露 **`POST /v1/document/quality-inspection`**（返回 JSON + HTML 简报）。
- **任务四**：在 IMDR `documents/`（约 1700 文件）上实测，分析统计是否符合数据集特征，抽查「版本冲突/敏感信息」列表准确率。

**验收**：五大功能全覆盖并输出所有列表；分类标签人工抽样准确率 **≥85%**；列表项含可判断的关键信息（路径/相似片段/敏感上下文）；Skill 可经 API 调用并返回结构化 JSON；可被工作流决策节点调用；代码阈值全部配置化、有错误处理（损坏 PDF）。

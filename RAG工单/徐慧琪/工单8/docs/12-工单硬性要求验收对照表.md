**复检中发现并修复的两处问题**（原验收表未覆盖）：

1. **🔴 进程级段错误（exit 139）**：`torch.cuda.mem_get_info()` 在本机不反映 Ollama
   占用的显存（卸载前后都报 6009MB，而整卡实际只剩 4014MB），显存闸门据此误判
   「充足」放行，精排模型加载随即在 CUDA 层崩溃。**对照实验：不释放 3/3 崩、
   先释放 3/3 成功**；已将 `_ensure_gpu_headroom` 改为无条件释放（读数仅用于日志），
   修复后 `rag.warmup()` 连跑 3/3 正常。回归测试：`tests/test_gpu_headroom.py`。
2. **🟡 无 PDF 上传功能**：工单要求用户手册覆盖「如何上传 PDF 文档」，
   原实现只能替换语料目录重建。已补会话级上传（混合检索 + 精排，不污染图谱），
   回归测试：`tests/test_upload_index.py`（12 条）。

此外顺手修掉一处**既有降级路径 bug**：`_extractive_answer` 只读 `page_idx`，
而语料命中带的是 1 基 `page`，导致 LLM 不可用时的降级答案引用「第 -1 页」。

# 工单十四：技术组件

## 一、PDF 解析组件

### 1.1 PyMuPDF 图片提取
- **文件**：`src/pdf_parser.py`
- **功能**：从图片型 PDF 中提取每页内嵌原始图片 + 高分辨率渲染图
- **关键 API**：
  - `page.get_images(full=True)` — 获取页面图片引用
  - `doc.extract_image(xref)` — 提取原始图片字节
  - `page.get_pixmap(matrix=Matrix(4,4))` — 4x 高分辨率渲染

### 1.2 Qwen2-VL OCR
- **文件**：`src/vlm_engine.py`
- **功能**：用多模态大模型识别图片中的文字
- **优势**：对低质量扫描图鲁棒，能理解版面结构
- **参数**：`max_new_tokens=1536`，`do_sample=False`

## 二、多模态组件

### 2.1 Qwen2-VL 视觉问答 (VQA)
- **文件**：`src/vlm_engine.py`
- **功能**：对技术图纸进行视觉问答（部件位置、尺寸含义、气流方向）
- **调用**：`vlm_engine.vqa_image(image_path, question)`

### 2.2 查询路由器
- **文件**：`src/query_router.py`
- **功能**：区分文本问题和图像问题
- **规则**：匹配"第X页图/部件/尺寸/气流方向"等关键词 → 图像通道

## 三、检索组件

### 3.1 bge-m3 文本嵌入
- **文件**：`src/embedding.py`
- **模型**：`/home/dabaie/models/bge-m3`
- **维度**：1024
- **优化**：CPU 推理，batch_size=8，max_seq_length=512（防 OOM）

### 3.2 Milvus Lite 向量库
- **文件**：`src/vector_store.py`
- **索引**：HNSW (M=16, efConstruction=200)
- **度量**：COSINE
- **路径**：`./data/milvus_v14.db`

### 3.3 混合检索器
- **文件**：`src/retriever.py`
- **策略**：BM25（jieba 分词）+ 向量检索 → RRF 融合 → bge-reranker 重排序
- **参数**：vector_top_k=30, bm25_top_k=30, rrf_k=60

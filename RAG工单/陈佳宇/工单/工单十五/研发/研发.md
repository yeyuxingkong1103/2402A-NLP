## 2.RAGFlow 检索源码模块梳理

1. 查询处理入口：接收用户 question；
2. 原始逻辑：仅做单路文本向量召回；无图纸引用识别，无法区分普通 query 和图纸相关 query；
3. 召回模块：向量数据库检索；
4. rerank 模块：默认纯文本重排，对图纸部件位置语义匹配弱；
5. prompt 组装：不感知上下文是否包含图纸信息，没有专门引导 LLM 做图文推理的提示。

## 3. 脚本说明

1. **config.py**：全局可配置参数；RRF 融合权重、top‑k、rerank 开关、正则匹配图纸规则；
2. **multimodal_retrieval.py**：跨模态检索核心；
   - detect_figure_reference ()：正则识别问题内图纸引用（图 3、第 11 页图示）；
   - build_augmented_query ()：生成图纸增强查询；
   - two_path_recall ()：两路召回；
   - reciprocal_rank_fusion ()：RRF 秩融合多路检索结果；
   - multimodal_rerank ()：图文重排；
3. **prompt_template.py**：两套 prompt；普通文本模板 + 图文图纸感知模板；检测存在图纸块自动切换；
4. **test_multimodal_api.py**：批量调用 RAGFlow API 执行 6 条测试用例，输出测试报告 json，记录 top‑k 召回片段、模型回答。

## 4. 关键业务逻辑

1. 正则检测用户提问是否引用图纸页码、图号；
2. 存在图纸引用：生成增强查询，原始 query + 图纸描述两路召回；
3. RRF 算法融合两路召回文档片段；
4. 开启跨模态 rerank，提升图纸图文块排序；
5. 如果候选块包含图表，切换图文专用 prompt 模板，指导 LLM 结合图纸部件信息推理。

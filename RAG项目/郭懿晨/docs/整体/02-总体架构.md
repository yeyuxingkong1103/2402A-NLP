# 	02 · 总体架构（v2）

> **定位**：系统分层、模块划分、技术栈、数据流。**一条链路：文档 → 知识库 → 检索/问答（含重排）→ 前端展示。**

## 一、系统分层

```
┌──────────────────────────────────────────────────────────────┐
│  呈现层   frontend/（原生 HTML/CSS/JS 单页）                    │
│           上传 PDF ｜ 任务进度 ｜ 文档列表 ｜ 向量库 ｜ 问答        │
├──────────────────────────────────────────────────────────────┤
│  接口层   FastAPI（backend/app/main.py + routes_*.py）         │
│           /api/files/upload · /api/tasks/{id}/start · /api/tasks/{id} │
│           /api/documents · /api/vector-store · /api/categories · /api/chat │
├──────────────────────────────────────────────────────────────┤
│  服务层   BuildPipeline（构建编排）· RetrievalChain（检索编排：   │
│           召回→粗排→精排→阈值过滤）· QaService（问答编排）         │
│           JsonStateStore（本地状态）· BackgroundTasks（后台执行）│
├──────────────────────────────────────────────────────────────┤
│  管线层   构建：MinerUParser → (VLM 后处理) → clean_text →      │
│           build_chunks → BgeM3Embedder → Qdrant upsert       │
│           检索：Qdrant RRF 召回(candidate_k, 带 dense) →       │
│           CoarseReranker(dense 余弦, coarse_top_k) →          │
│           FineReranker(bge-reranker-v2-m3, final_top_k)      │
├──────────────────────────────────────────────────────────────┤
│  数据层   data/*.pdf（上传）· data/state.json（状态）·           │
│           data/qdrant/（向量库 rag_documents）                 │
├──────────────────────────────────────────────────────────────┤
│  外部依赖 MinerU ｜ BGE-M3 ｜ bge-reranker-v2-m3 ｜ Ollama      │
│            ｜ OpenAI 兼容 VLM（qwen-vl-plus）                  │
└──────────────────────────────────────────────────────────────┘
```

## 二、模块划分（backend/app/）

| 模块 | 职责 |
|---|---|
| `config.py` | `AppSettings`（pydantic-settings，读 `.env`）；含 **v2 重排配置**（rerank_enabled/候选与 top_k/scorer/模型路径等，`final_top_k` 默认 4）；`ensure_project_path` 路径边界 |
| `models.py` | 领域模型：Document / BuildTask / Chunk / Citation / ChatRequest / ChatResponse |
| `storage.py` | `JsonStateStore`：`data/state.json` 读写文档/任务/chunk |
| `files.py` | PDF 文件名清洗（拒绝非 PDF、替换非法字符）、保存到 `data/` |
| `mineru.py` | `MinerUParser`：MinerU pipeline 解析（含 HGNetV2/transformers5 兼容补丁）；失败回退 pypdf |
| `mineru_vlm.py` / `vision.py` | VLM 后处理（`qwen-vl-plus` 将表格/图片块转 Markdown 回填） |
| `chunking.py` | `clean_text` 清洗、`build_chunks` 分块（max_chars=800 截断） |
| `embeddings.py` | `BgeM3Embedder`：dense(1024)+sparse；FlagEmbedding 优先、sentence-transformers 兜底 |
| `vector_store.py` | `QdrantVectorStore`：建集/upsert/RRF 检索（v2 支持返回 dense 向量）；`InMemoryVectorStore` 测试用 |
| **`rerank.py`（v2 新增）** | **`RetrievalChain` 编排召回→粗排→精排→阈值过滤；`CoarseReranker`（三种 scorer）；`FineReranker`（bge-reranker-v2-m3 交叉编码器，懒加载缓存）** |
| `pipeline.py` | `BuildPipeline`：解析→清洗→分块→向量化→入库，逐步回写任务状态 |
| `qa.py` | `QaService`：证据 prompt → Ollama 生成 → 兜底策略 |
| `routes_files.py` | `POST /api/files/upload` |
| `routes_tasks.py` | `POST /api/tasks/{task_id}/start`、`GET /api/tasks/{task_id}` |
| `routes_documents.py` | `GET /api/documents`、`/api/vector-store`、`/api/categories` |
| `routes_chat.py` | `POST /api/chat`（v2 接入 RetrievalChain） |
| `main.py` | FastAPI 入口：注册路由、挂载前端、`/health` |

## 三、关键技术选型（决策）

| 环节 | 选型 | 关键决策 |
|---|---|---|
| 解析 | MinerU 3.4.5（pipeline，本地模型） | 结构化内容块；需 transformers 5.x + `patch_mineru_tf5.py` 补丁（PP-DocLayoutV2 的 hgnet_v2 backbone）；失败回退 pypdf |
| 图语义 | OpenAI 兼容 VLM（`qwen-vl-plus`） | 阿里云 DashScope 兼容接口；`.env` 已启用（`VLM_ENABLED=true`） |
| 清洗 | 结构化文本清洗 | 去空行/首尾空白，保留可追溯内容 |
| 分块 | 按 MinerU 块切分 | 保留 page/category/source_span；超长块 800 字符截断 |
| 嵌入 | BGE-M3（本地） | dense(1024)+sparse；FlagEmbedding 1.4.2 优先 |
| 向量库 | **Qdrant embedded** | 原生 named vectors + FusionQuery(RRF)；贴近服务端可迁移 |
| 召回 | dense+sparse → FusionQuery(RRF) | `retrieval_candidate_k=30` 扩大候选，返回 dense 供粗排 |
| **粗排（v2）** | BGE-M3 dense 余弦 | 零新模型成本；scorer 可配 `dense_cosine`/`rrf_score`/`hybrid`；取 `coarse_top_k=10` |
| **精排（v2）** | **bge-reranker-v2-m3** | 本地交叉编码器，normalize 0~1，取 `final_top_k=4`（v2 迭代调优）；GPU 可用时 fp16 |
| 任务 | BackgroundTasks + 轮询 | FastAPI 自带后台任务；不用 SSE/线程池 |
| 状态存储 | `data/state.json` | 单机轻量 |
| LLM | Ollama `deepseek-r1:7b` | 本地生成，无 API 依赖 |
| 前端 | 原生 HTML/CSS/JS | 无框架、无构建步骤 |

## 四、数据流

### 入库流（v1 不变）

```
PDF 上传 → files.save_pdf_bytes → 创建 Document + BuildTask
→ POST /tasks/{id}/start → BackgroundTasks → BuildPipeline.run
→ parse(MinerU/pypdf) → clean → chunk → embed(BGE-M3) → upsert(Qdrant)
→ 任务/文档状态回写 state.json → 前端轮询展示
```

### 问答流（v2 检索链路）

```
POST /api/chat → 空问题 → 兜底
→ BGE-M3 查询向量 → Qdrant RRF 召回(candidate_k=30, 带 dense)
→ 粗排 CoarseReranker（dense 余弦, coarse_top_k=10）
→ 精排 FineReranker（bge-reranker-v2-m3, final_top_k=4）
→ min_retrieval_score(0.2) 过滤 → build_citations（带文档名/页码）
→ Ollama deepseek-r1:7b 生成 → answer + citations + fallback
→ 任一环节为空/全部过滤 → 固定兜底「知识库中未找到相关依据。」（域外拒答）
```

`rerank_enabled=false` 时绕过粗排/精排，退化为 v1：`search(limit=final_top_k) → RRF 分过滤 → 引用`（用于 A/B 对比）。

## 五、数据对象

| 对象 | 关键字段 |
|---|---|
| Document | document_id / file_name / file_path / status(uploaded→indexed/failed) / created_at |
| BuildTask | task_id / document_id / step(pending→parsing→cleaning→chunking→embedding→upserting→completed/failed) / progress / status / error_message |
| Chunk | chunk_id / document_id / page(≥1) / category / text / source_span |
| Citation | document_id / file_name / page / category / text / score（v2 下为精排相关性分 0~1） |
| SearchResult（v2） | chunk / score / **dense（可选，供粗排）** |

## 六、错误处理

- 非 PDF 文件 → 400「只允许上传 PDF 文件」；任务不存在 → 404
- MinerU 解析失败 → 回退 pypdf；仍失败 → 任务 failed + error_message
- 页码无效（<1）→ 禁止入库；检索任一环节为空 → 兜底响应
- 混合检索 MemoryError → 回退轻量 scroll（dense=None → 粗排回退 rrf_score）
- **精排模型缺失/加载失败/打分异常（v2）→ 抛可诊断错误，不允许静默降级成错误排序的引用**
- `final_top_k ≥ coarse_top_k` → 按 `min(final, coarse)` 收敛，不崩溃

## 七、验收标准

- 上传 PDF 能创建文档与任务记录；构建跑通解析→清洗→分块→向量化→入库
- `/api/chat` 走「召回→粗排→精排→过滤」链路；`rerank_enabled=false` 可复现 v1 行为
- 向量库能列出文档/记录/类别；问答返回答案 + 引用；域外问题正确兜底拒答
- **v2 评测达标：recall/MRR ≥ v1 基线（实测 +0.083 / +0.111）且拒答率 0→0.92**
- `pytest backend/tests -v` 全绿（含 `test_rerank.py`、`test_rerank_real.py`）

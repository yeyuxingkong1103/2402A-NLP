# 工单7 RAG功能测试及评估｜优化文档
工单编号：人工智能NLP‑RAG‑功能测试及评估

## 1.当前系统存在问题（来自测试结果）
1. 向量检索存在语义漂移现象，会召回语义相近但业务无关的文本片段。
2. 简单换行做文本切分，文本块长度不均匀，影响检索召回质量。
3. 部分问题出现漏召回，例如竞争对手相关问题，召回率为0。
4. top_k固定为3，对于信息多的问题召回片段不足，信息少的问题引入无关片段。
5. 使用pymilvus旧版ORM接口，控制台持续输出弃用警告。
6. 评估逻辑简单，仅做字符串包含判断，没有做语义相似度判断。

## 2.工单7已经完成的优化
1. 使用RRF倒数排名融合算法，融合向量检索与BM25检索结果，缓解单一检索的缺陷。
2. 增加检索结果兜底，无检索内容返回提示，程序不会崩溃。
3. 新增批量自动评估模块，可以批量跑测试集，输出召回率、精确率，替代人工统计。
4. 修复前端JS符号bug，网页交互可以正常提交提问。

## 3.后续可优化方案
### 3.1 文本分块优化
替换简单换行分割，使用递归字符分割，设置块大小与重叠大小，保证每个文本块信息量均衡，提升检索质量。

### 3.2 检索参数调优
1. 调整RRF的k融合参数，平衡向量检索与BM25检索权重。
2. 调整Milvus nprobe参数，调整top_k，针对不同业务场景动态设置召回数量。

### 3.3 Milvus接口升级
将ORM风格接口全部替换为MilvusClient新接口，消除版本弃用警告，适配后续pymilvus新版本。

### 3.4 评估逻辑优化
当前评估只是简单字符串包含判断，可以改为向量相似度计算，做更合理的自动评估。

### 3.5 检索策略优化
可以增加重排序模块Reranker，对初筛召回结果做二次排序，过滤掉无关片段，降低语义漂移带来的错误召回。

## 4.优化预期效果
1. 降低语义漂移带来的错误召回，提升精确率。
2. 减少漏召回现象，提升整体召回率。
3. 评估结果更加客观准确。

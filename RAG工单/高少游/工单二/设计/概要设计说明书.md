# 概要设计说明书

> **工单编号**：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化
> **项目名称**：基于 PDF 文档的问答系统（优化版）
> **设计目标**：问答准确率 ≥ 90%、提问到返回答案 ≤ 3 s，具备高可用与容错能力

---

## 1. 系统概述

本系统是一个面向金融招股说明书的**检索增强生成（RAG）问答系统**，在 01 工单基础版本上，
围绕 **PDF 解析处理 / 分块 / 检索 / 答案合成** 四个层面做准确率优化，并提供可复现的
"优化前基线"，形成量化对比。

### 1.1 业务场景

用户以自然语言提问（如"公司注册资本是多少？"），系统从招股说明书 PDF 中检索相关证据，
抽取并给出带页码引用的准确答案。

### 1.2 设计约束

| 约束 | 说明 |
|---|---|
| 模型本地化 | 全部模型经 Ollama 本地部署，无外部 API 依赖（`bge-m3:567m` 向量模型、`deepseek-r1:1.5b` 生成模型） |
| 硬件 | 单机 CPU 环境即可运行，无需 GPU |
| 准确率 | ≥ 90% |
| 响应时间 | ≤ 3 s（提问 → 返回答案） |
| 语言 | 中文为主，兼容英文提问 |
| 平台 | Windows 11 + Python 3.10 |

## 4. 关键流程

### 4.1 离线建库流程

```
PDF 文件
  → parse_pdf：逐页抽文本 + 表格，统计跨页重复行剔除页眉页脚，识别标题
  → build_chunks：表格 → 原子块；正文 → 按标题切小节 → 小节内递归切片 → 父子块
  → chunks_to_documents：附加元数据（page / section / ctype / parent / chunk_index）
  → FAISS.from_documents（bge-m3 分批嵌入）
  → 持久化到 vector_db/optimized（中文路径经临时 ASCII 目录桥接）
```

### 4.2 在线问答流程（优化链路）

```
用户提问
  → QueryUnderstanding.analyze：核心问句 + 关键词 + 实体 + 答案类型 + 多路查询
  → HybridRetriever.retrieve：
        多路查询并行 → 向量 Top-15 + BM25 Top-15 → RRF 融合
        → Reranker 加权线性重排 → 按父块去重 → 取 k 个
  → build_answer：候选句/表格行打分 → Top-N → 页码引用拼装
  → AnswerResult（answer / sources / citations / elapsed）
```

## 5. 数据设计

### 5.1 文档块元数据

| 字段 | 类型 | 说明 |
|---|---|---|
| `page` | int | 来源页码 |
| `section` | str | 所属小节标题（表格块为本页标题集合） |
| `ctype` | str | `text` / `table` |
| `parent` | str | 父块（小节全文），用于上下文扩展 |
| `chunk_index` | int | 块序号 |

### 5.2 问题集

`data/questions.json`：10 道题，每题含 `id`、`question`、`reference`（人工核对的参考答案）。

### 5.3 评估产出

| 文件 | 说明 |
|---|---|
| `output/evaluation_report.json` | 结构化评估数据（逐题答案、命中、耗时） |
| `output/evaluation_report.md` | 人类可读对比报告 |
| `output/figures/*.png` | 对比图表与流程图 |

## 6. 非功能性设计

| 属性 | 设计 |
|---|---|
| **性能** | 抽取式答案合成（无 LLM 推理）；BM25 索引与向量库进程内构建一次并复用；预热机制规避冷启动 |
| **可用性** | 单题问答不依赖 LLM 服务（抽取式链路）；向量检索异常时降级为 BM25 结果 |
| **容错** | 空输入兜底；单页 PDF 解析异常跳过；LLM 调用异常捕获并返回可读提示；FAISS 中文路径桥接 |
| **可维护性** | 参数集中于 `config.py`，支持 `.env` 覆盖；模块职责单一，接口清晰 |
| **可扩展性** | 新增题目只需扩展 `data/questions.json` 与 `src/evaluate_keys.py`；新增检索信号只需在 `reranker.py` 增维 |
| **可溯源性** | 答案附页码引用与证据句，杜绝幻觉 |

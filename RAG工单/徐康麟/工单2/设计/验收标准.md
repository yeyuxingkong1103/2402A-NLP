## 0. 总则

1. **逐条判定**：每条验收标准都必须给出「判定方法 → 证据文件 → 复现命令 → 判据 → 结论」五要素，缺一即为未验收。
2. **不存在"部分通过"**：任一条不通过 → 整体不通过；不允许以"其余都很好"抵扣。
3. **证据必须是真实运行产物**：pytest 输出、脚本 stdout、报告文件、日志文件；**不接受"文档里写了"**。
4. **未运行 = 未通过**：任何指标若未真实运行，必须显式标注「未运行」并说明原因，且该条记为不通过。
5. **判分口径唯一**：准确率口径见 §2，**不得放宽、不得换尺子、不得重跑挑最好一次**。
6. **红线**（任一触发即整体不通过）：①修改 `工单1/` 任何文件；②伪造/估算指标数值；③伪造 RAGAS 数值；④把基线值誊抄为优化后值；⑤声称运行了本机不可用的依赖（streamlit/loguru/ragas/pdfplumber/rank_bm25/chromadb/langchain/pandas/matplotlib）；⑥在代码中为单题写死答案或特判。

## 2. 准确率判分口径（**核心，不得放宽**）

### 2.1 口径来源

判分必须**逐字沿用**工单1 `app/core/evaluator.py::Evaluator.check_answer`（确定性规则，不依赖 LLM 裁判）【环境事实 4.2】。工单2 的 `研发/app/core/evaluator.py` 必须是该函数的等价实现（允许等价重构，但判定顺序、阈值、正则、集合运算语义必须一致）；`测试/离线/test_evaluator_v2.py` 必须断言这一点。

### 2.2 五步判定顺序（满足任一步即判正确）

1. **去标点包含**：去掉 `PUNCT_TO_STRIP` 后，参考答案是答案子串（或反之）。
2. **金额全部命中**：把金额按元折算后比较，容忍 `5,520` 与 `5,520.00 万元`、`1.5 亿元` 与 `15,000 万元` 等等价写法；参考答案的**全部**金额都要在答案中出现。
3. **关键实体交集**：双方引号内名称（`ENTITY_PATTERN`，长度 4~60）有交集。
4. **比例全部命中**：参考答案的**全部**百分比都要出现在答案里。
5. **二元组相似度**：字符二元组 Jaccard ≥ `FUZZY_THRESHOLD = 0.62`，**且必须不缺任何数字**（含百分比）。

关键常量（不得改动）：`FUZZY_THRESHOLD = 0.62`；`PUNCT_TO_STRIP = "，,。.、；;：:！!？?（）()【】[]《》〈〉\"'“”‘’ \t\n\r\u3000"`；`ALL_NUMBER_PATTERN = \d+(?:,\d{3})*(?:\.\d+)?`；`PERCENT_ONLY_PATTERN = (\d+(?:\.\d+)?)\s*%`。

### 2.4 一个必须记录在案的边界事实（防止误用）

【设计取证：本设计阶段实测】对 `法定代表人是程家明。` vs `法定代表人是程家的明。`（人为插字、语义已错），`check_answer` 实测返回 **True**，说明为 `字符二元组相似度 0.70 ≥ 0.62`——这是工单1 判分口径**固有的模糊容忍**（第 5 步设计用于容忍"军队视频指挥"↔"国防军队视频指挥"这类同义改写）。

**结论与纪律**：
1. 该边界**不得**被写成"判分被放宽"的用例（它本来就判对）；也**不得**据此修改 `FUZZY_THRESHOLD`——改阈值会让"优化前 50% → 优化后 ≥90%"不再是同一把尺子（ADR-7）。
2. **引用标签不污染判分（已实测）**：Q531 基线判错的原因是答案形态「法定代表人：程家明」（缺「是」，既不是参考答案子串、相似度也 <0.62），**不是**因为带了 `[页码: 52]`。实测对照：

| 提交答案 | 判分 | 说明 |
| --- | --- | --- |
| `[页码: 52] 法定代表人：程家明`（基线原样） | **False** | `未命中：文本与数值均不匹配` |
| `法定代表人：程家明。[页码: 52]` | **False** | 换标签位置仍错 → 问题在缺「是」 |
| `法定代表人是程家明。[页码: 52]` | True | `参考答案为答案子串（忽略标点）` |
| `[页码: 52] 法定代表人是程家明。` | True | 标签前置同样通过 |
| `法定代表人是程家明。` | True | 无标签亦通过 |

   → 因此优化措施是**让生成用完整句作答**（工单 6.4 提示词强化），而**不是**在判分环节剥离引用标签（后者属 §2.5 第 2 条禁止项）。
3. 同类已实测：Q793 基线答案 `下游行业包括军队、政府机关、能源等行业企业` 判 **False**；补全为 `电子信息行业的下游为各类终端用户，覆盖范围广泛，主要包括军队、政府机关、能源等行业企业。` 判 **True**（`参考答案为答案子串（忽略标点）`）→ 措施是"答案要点完整"（复制证据句），不是改判据。

## 7. 验收流程与判定规则

```text
①实现完成（T2/T11）→ ②离线测试（T3）→ ③在线测试（T4）→ ④用户测试（T5）

   → ⑨批判性评审（T10）→（若有 blocker/high）⑩修复（T11）→ ⑪复审（T12）
```

**判定规则**

- T9 的 `verdict=pass` 仅当：验收 1~11 **全部通过**，且红线未触发，且 `optimization_compare.*` 重跑数值与报告一致。

- 评审（T10/T12）发现的 blocker/high 未关闭 → 验收不通过。

# 工单08 评测问题集（eval_question.md）

> 工单编号：人工智能NLP-RAG-基于Graph RAG 实现金融问答
>
> **关于本文件来源的说明**
>
> 工单原文要求「问答系统基于 `eval_question.md` 中的 Question 进行检索」，但附件
> `ccf_competition.zip` 中**并未提供 `eval_question.md`**（压缩包内只有 9 份金融年报的
> `pdf/` 与 `txt/` 目录）。因此**本工单依据工单07《功能测试及评估》的测试集构建了等价的问题集**：
>
> * **Q01~Q04** 直接复用工单07 所依据的附件 `sample_questions.pdf` 中的 4 个示例问题
>   （原文与参考答案均来自该 PDF，属于 07 工单的原始测试集）；
> * **Q05~Q08** 为围绕同一批 CCF 金融年报（银行 / 保险 / 证券 共 9 份）扩充的**数值型**问题，
>   用于检验 Graph RAG 的「指标数值 / 同比变化」关系抽取与精确取值能力；
> * **Q09** 为**对比型**问题，跨两家券商文档，检验图谱的实体链接与多文档融合；
> * **Q10** 为**全局型**问题，跨全部 9 份文档，只有 Graph RAG 的社区摘要全局检索才能作答。
>
> 问题类型覆盖 `事实型 / 数值型 / 对比型 / 分析型 / 全局型` 五类，与工单07 的测试集口径保持一致，
> 因此可以直接与工单07 的测试结果做逐题比对（见 `src/compare_with_wo07.py`）。

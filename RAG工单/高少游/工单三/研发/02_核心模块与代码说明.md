## 1. `src/table_parser.py` —— 表格结构化解析（★本工单核心）

### 1.1 数据结构

```python
@dataclass
class TableBlock:
    page: int                      # 页码
    rows: List[List[str]]          # 规整后的单元格矩阵
    caption: str = ""              # 表题（表上方文本）
    header: List[str] = []         # 合并后的表头
    bbox: tuple = ()               # 表格边界框
    source: str = ""               # 所属文档文件名

    @property
    def markdown(self) -> str: ...     # Markdown 表（保留行列结构）
    @property
    def kv_lines(self) -> List[str]: ...  # ["表头：取值；表头：取值", ...]
    @property
    def text(self) -> str: ...         # [表题] + Markdown + [键值对]
```

### 1.2 主入口


**处理顺序**（关键坑）：`填充 → 删空列 → 折叠交错列 → 再删空列`。
先删空分隔列，才能得到规整的交错列网格。

### 1.3 关键函数

| 函数 | 作用 |
|---|---|
| `_fill_merged` | 合并单元格还原（左邻优先、上邻兜底） |
| `_collapse_interleaved` | 交错列折叠（力源信息表格特征） |
| `_drop_empty` | 删全空行列 |
| `_merge_header` | 多级表头合并为单行 |
| `_caption_above` | 表题识别（bbox 上方最近文本块） |
| `_quality_ok` | 质量过滤（过滤误检表格） |
| `kv_lines` | 生成"表头：取值"键值对行 |

```python
def save_local(store, persist_directory):
    if _is_ascii(path):
        store.save_local(str(path))
        return
    with tempfile.TemporaryDirectory() as td:      # 非 ASCII → 临时 ASCII 目录桥接
        store.save_local(td)
        for name in os.listdir(td):
            shutil.copyfile(Path(td)/name, path/name)
```

### 1.2 外部可执行文件（非 pip 依赖）

#### (1) Ollama（本地大模型运行时）

```bash
# 启动服务（默认监听 http://localhost:11434）
ollama serve

# 拉取本工单所需模型
ollama pull bge-m3:567m          # 向量嵌入（1024 维）
ollama pull deepseek-r1:1.5b     # 生成模型（可选，用于 --llm 作答）
```

验证：

```bash
curl http://localhost:11434/api/tags
```

#### (2) Tesseract-OCR（含简体中文语言包）

- 需安装 `chi_sim` 语言包；
- 路径通过环境变量 `TESSERACT_CMD` 指定，或使用 `src/config.py` 中的默认值：

```python
TESSERACT_CMD = os.getenv(
    "TESSERACT_CMD",
    r"...\tesseract\tesseract.exe",
)
```

## 6. 常见问题（FAQ）

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| `未找到源 PDF` | 数据未放置 | 确认 `data/CN100347506C.pdf` 存在 |
| 向量库缺少模型 | 未构建索引 | 运行 `python build_kb.py` |
| OCR 报语言包错误 | 缺 `chi_sim` | 安装 Tesseract 简体中文语言包 |
| 连接 Ollama 失败 | 服务未启动 | 运行 `ollama serve` 并 `ollama pull` 相应模型 |
| 首问耗时偏高 | 冷启动 | `QAEngine.warmup()` 已预热；界面首次加载会预热 |
| 中文乱码 | 控制台编码 | 已内置 `sys.stdout.reconfigure(encoding="utf-8")` |

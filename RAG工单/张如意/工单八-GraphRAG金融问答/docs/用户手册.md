## 一、启动系统

### 1.1 首次启动（需要先构建好知识图谱）

打开命令行（Windows 用 PowerShell 或 CMD），依次执行：

```bat
cd C:\Users\xiaoyi\Desktop\工单作业
set DEEPSEEK_API_KEY=你的密钥
python 工单08-GraphRAG金融问答\src\prepare_corpus.py
python 工单08-GraphRAG金融问答\src\build_graph.py
python 工单08-GraphRAG金融问答\src\visualize_graph.py
python 工单08-GraphRAG金融问答\src\serve.py
```

> 第 2 步（`build_graph.py`）需要调用大模型逐个文本块抽取实体关系，**耗时较长**（9 份年报）。
> 中途可以随时按 `Ctrl+C` 中断，下次运行会自动跳过已完成的部分，不会重复花钱。
> 想先快速体验，可以用 `build_graph.py --max-chunks 20 --no-summaries` 只抽 20 个块。

### 1.2 看到下面这几行就说明启动成功

```
问答界面：      http://127.0.0.1:8008/
图谱可视化：    http://127.0.0.1:8008/graph
接口文档：      http://127.0.0.1:8008/docs
```

### 1.3 打开界面

用浏览器（推荐 Chrome 或 Edge）访问 **http://127.0.0.1:8008/** 即可。

> 如果提示 `知识图谱尚未构建`，说明 `build_graph.py` 还没跑完，
> 或者 `data/graph/kg.json` 不存在——先完成 1.1 的第 2、3 步。

## 二、如何提问

### 2.1 文字提问

1. 在页面底部的输入框里输入问题
2. 按 **Enter** 发送（**Shift + Enter** 是换行，用于输入多行问题）
3. 稍等片刻，答案会以对话框形式出现在上方

页面已经预置了 4 个示例问题，**直接点击输入框上方的灰色胶囊按钮**即可填入，再按 Enter 发送。

### 2.2 语音提问

1. 点击输入框右侧的 **🎤 麦克风按钮**
2. 浏览器会请求麦克风权限，选择「允许」
3. 按钮变红并开始闪烁，表示正在录音，**对着麦克风说话**即可
4. 识别结果会实时填入输入框；说完后点击红色按钮停止
5. 检查识别文字是否正确，然后按 Enter 发送

> **注意**
> - 语音输入依赖浏览器的 Web Speech API，**Chrome / Edge 支持，Firefox 不支持**。
>   若浏览器不支持，麦克风按钮会提示「当前浏览器不支持语音输入」。
> - 识别语言固定为中文普通话（`zh-CN`）。
> - 语音只负责「转文字」，识别完成后仍然走与文字提问完全相同的问答流程。

### 2.3 选择检索模式

页面右上角的下拉框可以切换 Graph RAG 的检索模式：

| 模式 | 适用问题 | 说明 |
| --- | --- | --- |
| **hybrid 局部+全局**（默认） | 大多数问题 | 同时使用「实体子图」与「社区摘要」，效果最稳 |
| **local 子图检索** | 「某公司某指标是多少」这类**具体事实题** | 只沿实体关系扩展 2 跳，速度快、答案聚焦 |
| **global 社区摘要** | 「这些机构的共同策略是什么」这类**全局归纳题** | 只在社区摘要上检索，擅长跨文档总结 |

### 2.4 提问小技巧

| 想要的效果 | 建议的问法 |
| --- | --- |
| 数值要准 | 问题里带上**公司全称或常用简称 + 年份**，例如「招商银行2019年的营业收入是多少」 |
| 跨文档对比 | 在问题里同时点名多家机构，例如「招商证券和国泰君安2021年的营业收入对比」 |
| 全局归纳 | 用「共同 / 主要 / 总体 / 有哪些方向」这类词，例如「这批金融机构共同强调的能力建设方向有哪些」 |
| 问不出来 | 换用年报里的原词（如「拨备覆盖率」而不是「风险准备金比例」），图谱的实体名更接近原文 |

## 三、如何查看结果

### 3.1 答案本身

答案以对话气泡的形式显示，内容由 Graph RAG 基于知识图谱生成：
优先使用图谱中的实体属性与关系，图谱信息不足时才参考原文片段；
如果两者都不足以回答，会明确回复「知识库中未找到相关信息」。
按 `Ctrl+R` 刷新页面会清空对话（当前版本不做会话持久化）。

### 3.2 查看「检索到的知识图谱子图」

每条回答下方都有一个可展开的区域：

> **▸ 查看检索到的知识图谱子图（N 实体 / M 关系）**

点击展开后可以看到：

- **种子实体** —— 系统从你的问题里识别出的图谱节点
- **实体表** —— 子图内每个实体的名称、类型、度数（连接关系数）、属性描述
- **关系表** —— 头实体、关系类型、尾实体，以及**该关系的原文依据**

这是 Graph RAG 区别于普通问答的核心：**你不仅能看到答案，还能看到答案是怎么从图谱里推出来的。**

### 3.3 查看耗时与检索统计

答案下方的一行小字给出了本次问答的运行情况：

```
模式：hybrid ｜ 耗时：3.42s ｜ 局部检索：18 实体/26 关系 ｜ 全局检索：命中 3 个社区 ｜ 原文兜底：5 片段
```

- **局部检索**规模为 0 表示问题里没有命中任何图谱实体（此时主要靠全局检索或原文兜底）
- **原文兜底**出现表示启用了向量检索通道

### 3.4 批量查看全部 10 个评测问题的结果

如果想知道系统在 `questions/eval_question.md` 的 10 个标准问题上的表现，运行：

```bat
python 工单08-GraphRAG金融问答\src\graph_qa.py
```

产出的报告在：

| 文件 | 内容 |
| --- | --- |
| `results/graph_qa_results.md` | **人读版**：每题的子图、答案、耗时、社区摘要 |
| `results/graph_qa_results.json` | 结构化版，供程序消费 |

### 3.5 查看与工单07 的测试结果对比

```bat
python 工单08-GraphRAG金融问答\src\compare_with_wo07.py
```

产出 `results/compare_wo07.md`，包含逐题答案对比表与 RAGAS 指标对比表。
若工单07 的结果文件不存在，脚本会给出提示并只输出本工单的结果，**不会报错**。

### 3.6 查看金融研报

```bat
python 工单08-GraphRAG金融问答\src\research_report.py
```

产出 `results/financial_report.md`（默认主题「银行业应对经济周期策略分析」），
也可以在网页上访问 **http://127.0.0.1:8008/api/report** 直接查看 Markdown 原文。

## 四、如何查看知识图谱可视化

### 4.1 打开交互式可视化页面

**方式一（推荐）**：系统启动后，点击页面右上角的 **「知识图谱可视化」** 按钮，
或直接访问 **http://127.0.0.1:8008/graph**

**方式二（离线）**：直接用浏览器打开本地文件
`工单08-GraphRAG金融问答/results/graph/knowledge_graph.html`
（这个文件是自包含的，不依赖服务是否启动）

> 页面优先加载 ECharts 做渲染（交互最完整）。如果电脑**没有联网**导致 CDN 加载失败，
> 页面会在 8 秒内自动切换到内置的 Canvas 力导向渲染器，
> 右上角会显示 `渲染器：内置 Canvas 力导向（离线环境）`。两种渲染器都支持下面所有操作。

### 4.2 页面操作说明

| 操作 | 效果 |
| --- | --- |
| **鼠标拖拽节点** | 拖动单个实体到任意位置，其余节点会自动让位 |
| **空白处按住拖动** | 平移整个画布 |
| **滚轮** | 以光标为中心缩放 |
| **点击节点** | 右侧详情面板显示：实体名称、类型、度数、所属社区、别名、属性描述，以及**该实体的全部关系**（含原文依据） |
| **点击连线** | 右侧面板显示关系类型、头尾实体、合并权重、原文依据 |
| **点击左侧图例** | 按实体类型显示/隐藏节点（例如关闭「时间」类型可以去掉大量时间节点，看清主体网络） |
| **点击「显示标签」** | 切换节点文字的显示 |
| **左上角搜索框** | 输入实体名后回车，会定位并高亮该实体（也支持按属性描述模糊搜索） |

### 4.3 右侧与左侧面板在看什么

- **左侧「实体类型」图例**：括号里的数字是该类型在图谱中的实体数量
  —— 这是观察语料结构的快捷方式（例如「财务指标」数量特别多，说明年报的数值信息密度高）
- **右侧「详情」面板**：点击节点后展示的是图谱里真正存下来的内容，
  其中「属性描述」是**多次抽取累加**的结果（同一个实体在不同文档、不同章节被反复描述），
  「关系」列表里的每条边都带原文依据，可以直接核对是否抽取正确。

### 4.4 静态图（用于文档与视频）

| 文件 | 说明 |
| --- | --- |
| `results/graph/knowledge_graph.png` | spring 布局，节点按实体类型着色、大小随度数变化 |
| `results/graph/knowledge_graph_circular.png` | 环形布局，同一社区的节点会聚在一起，便于观察社区结构 |
| `results/graph/graph_data.json` | 前端数据快照（节点/关系/社区/统计），可导入其他图分析工具 |
| `results/graph_stats.json` | 图谱统计：实体数、关系数、类型分布、度分布、Top 实体、社区列表 |

### 4.5 把图谱导入 Neo4j（可选）

如果已经部署了 Neo4j，可以把图谱导入后用 Cypher 查询或 Bloom 可视化：

```python
import sys; sys.path.insert(0, r"C:\Users\xiaoyi\Desktop\工单作业")
from rag_core.graph_rag import build_knowledge_graph   # 或从 kg.json 还原
kg.to_neo4j("bolt://localhost:7687", "neo4j", "密码")
```

> 更省事的做法：直接运行 `python src/build_graph.py`，然后在 Python 里
> `from prepare_corpus import load_graph; load_graph().to_neo4j(...)`。

## 五、如何上传 PDF

### 5.1 通过网页上传

在命令行里执行（`curl` 是 Windows 10+ 自带的命令）：

```bat
curl -X POST "http://127.0.0.1:8008/api/upload" -F "file=@D:\我的年报.pdf"
```

返回结果示例：

```json
{
  "doc": "我的年报",
  "n_pages": 208,
  "n_blocks": 3120,
  "n_chunks": 486,
  "table_chunks": 92,
  "message": "已解析并落盘。运行 src/build_graph.py 即可把该文档并入图谱。"
}
```

### 5.2 上传后发生了什么

1. PDF 被保存到 `工单08-GraphRAG金融问答/data/uploads/`
2. 系统用 PyMuPDF 抽取正文、用 pdfplumber 抽取表格（**表格很重要**，财报大量指标只在表格里）
3. 按章节结构切成文本块，保存到 `data/corpus/uploads/`
4. 这一步**只做解析，不做 LLM 抽取**（因为抽取很贵），所以秒级返回

### 5.3 让新文档进入知识图谱

方式一（推荐，可控）：重新运行一次图谱构建，新上传的文档会被自动并入

```bat
python 工单08-GraphRAG金融问答\src\build_graph.py
```

方式二（立即抽取，消耗 API 额度）：上传时直接带上 `rebuild=1`

```bat
curl -X POST "http://127.0.0.1:8008/api/upload?rebuild=1&max_chunks=30" -F "file=@D:\我的年报.pdf"
```

`max_chunks` 限制本次最多抽取多少块，避免误传大文件把 API 额度打满。
抽取完成后系统会自动重新做社区检测并保存图谱，**无需重启服务**（服务会检测到图谱文件更新并自动重载）。

### 5.4 如何提问新上传的文档

新文档并入图谱后，直接在问答界面提问即可。建议：
- 用新文档里出现的**公司全称**提问（图谱里的实体名来自原文）
- 若问法完全不带任何图谱中已有的实体名，系统会走「全局检索 / 原文兜底」通道

## 六、常见问题（FAQ）

| 现象 | 原因与解决 |
| --- | --- |
| 打开页面提示「知识图谱尚未构建」 | `data/graph/kg.json` 不存在，先运行 `build_graph.py` 与 `visualize_graph.py` |
| 回答总是「知识库中未找到相关信息」 | 问题里的实体没被图谱收录。换用年报中的原词提问，或确认图谱是否已包含该文档 |
| 图谱页面一片空白 | 无网络且 CDN 超时（最多等 8 秒会自动切换渲染器）；若仍空白，检查浏览器控制台报错 |
| 麦克风按钮点了没反应 | 浏览器不支持（请用 Chrome/Edge）或未授予麦克风权限 |
| 构建图谱时中断了 | 直接重新运行 `build_graph.py`，会自动跳过已抽取的块（缓存文件 `data/graph/extractions_optimized.jsonl`） |
| 想完全重抽一遍 | `build_graph.py --no-resume`（会重新消耗 API 额度，谨慎使用） |
| 端口被占用 | `python src/serve.py --port 8010` 换一个端口 |
| 中文在静态图里显示成方块 | 系统缺少中文字体，安装「微软雅黑 / SimHei」后重跑 `visualize_graph.py` |

# 工单05：Query 理解与多轮问答

工单编号：人工智能NLP-RAG-Query理解优化任务。

本版本在工单04基础上增加对话历史和追问改写。可识别“他”“这个公司”和“那……呢”，把追问改写为带公司名称的检索问题；回答仍引用 PDF 证据页。

## 运行

1. 安装 Python 3.10+，运行 `python -m pip install -r requirements.txt`。
2. 上传《招股说明书1.pdf》和《招股说明书2.pdf》，分别选择文档并点击“解析并建立索引”。
3. 启动 `启动网页.ps1`，打开 `http://127.0.0.1:8501`。
4. 先在《招股说明书1.pdf》上连续提问前三题，再切换到《招股说明书2.pdf》提问后两题。页面会显示追问改写、证据页和回答反馈。

`python test_conversation.py` 验证工单给出的五轮对话改写。`conversation_evaluation.json` 中前三题和第五题答案复用工单02/04已测结果；第四题由《招股说明书2.pdf》第15页原文索引确认。自动关键词覆盖为5/5，不代表通用问答准确率；本次没有重跑外部生成模型，也没有并发压测。

多轮测试截图位于 `问答引擎/多轮对话/`，演示视频为 `演示视频.mp4`。截图用于展示本次对话改写和已验证答案；视频为截图流程演示。

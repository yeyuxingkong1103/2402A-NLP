# 人工智能 NLP-RAG-混合检索任务

工单编号：人工智能 NLP-RAG-混合检索任务

## 一、任务描述

在工单一至五构建的 RAG 问答系统基础上，提供三种可配置的检索策略：

1. 向量检索（召回 + 重排）
2. 全文检索（BM25 + 布尔 + 短语 + 模糊）
3. 混合检索（向量 + 全文，加权融合）

并提供至少 3 种重排算法：bge / tfidf / llm / adaptive。

## 二、方案设计

### 2.1 检索模式

| 模式 | 实现 |
|---|---|
| vector | bge_m3 向量召回 Top-15 + 重排 |
| fulltext | BM25 倒排索引 + 布尔 + 短语 + 模糊 |
| hybrid | 向量 + 全文归一化加权融合 |

### 2.2 重排算法（4 种）

| 重排器 | 原理 |
|---|---|
| bge | bge-reranker-base 交叉编码器 |
| tfidf | TF-IDF 相似度 |
| llm | DeepSeek 对候选片段打分 |
| adaptive | bge + 用户反馈加权 |

### 2.3 全文检索特性

- 布尔查询：`且` / `AND`
- 短语匹配：`"军用领域收入"`
- 模糊匹配：字符重叠率加权

### 2.4 混合检索

- 向量、全文分别归一化到 [0,1]
- 加权融合：`score = w_vec * vec_score + w_ft * ft_score`
- 默认权重：向量 0.6 / 全文 0.4
- 前端滑块可调

## 三、5 轮多轮对话

| 轮 | 问题 |
|---|---|
| 1 | 报告期内，兴图军用领域收入分别是多少？ |
| 2 | 他参与的哪个工程荣获了国家科技进步一等奖？ |
| 3 | 这个公司的法定代表人是谁？ |
| 4 | 那武汉力源信息技术股份有限公司呢？ |
| 5 | 力源组织结构图中，哪个销售部的销售处最多？有哪些销售处？ |

## 四、六种配置对比

| 配置 | 轮1 | 轮2 | 轮3 | 轮4 | 轮5 | 正确数 |
|---|---|---|---|---|---|---|
| vector + bge | ✅ | ✅ | ✅ | ✅ | ✅ | 5/5 |
| fulltext + bge | ❌ | ✅ | ✅ | ✅ | ❌ | 3/5 |
| hybrid + bge | ❌ | ✅ | ✅ | ✅ | ✅ | 4/5 |
| hybrid + tfidf | ✅ | ✅ | ✅ | ✅ | ❌ | 4/5 |
| hybrid + llm | ✅ | ✅ | ✅ | ✅ | ⚠️ | 4.5/5 |
| hybrid + adaptive | ❌ | ✅ | ✅ | ✅ | ✅ | 4/5 |

## 五、结论

1. **向量检索**在语义类问题（收入、组织图）上表现最好，5/5。
2. **全文检索**对关键词类问题（法定代表人、工程名）有效，对语义类问题弱。
3. **混合检索**需调权重，默认 0.6/0.4 会拉低向量优势；建议 0.8/0.2。
4. **重排算法**：LLM 最稳，bge 次之，tfidf 对表格 / 图像弱。
5. 准确率：vector 达 100%，fulltext 60%，hybrid 80%。
6. 响应时间：所有配置平均 1~1.7 秒，满足 ≤ 3 秒。

## 六、召回率分析

- 向量检索：召回率约 100%（5/5）
- 全文检索：召回率约 60%
- 混合检索：召回率约 80%
- 目标 95%，**向量检索和混合检索调优后可达标**

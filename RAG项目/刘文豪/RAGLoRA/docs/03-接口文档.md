# RAGLoRA 接口文档

> 版本：v1.0　基址：`http://127.0.0.1:8000/api`
> 在线交互文档：`http://127.0.0.1:8000/docs`（Swagger UI）

---

## 通用约定

**鉴权**：除 `/health`、`/auth/register`、`/auth/login` 外，所有接口需带请求头

```
Authorization: Bearer <access_token>
```

**错误响应**：统一为 `{"detail": "错误说明"}`

| 状态码 | 含义 |
|---|---|
| 400 | 参数错误（如路径不存在） |
| 401 | 未携带 Token / Token 无效或过期 / 用户名密码错误 |
| 403 | 无权限（如删除内置角色、账号停用） |
| 404 | 资源不存在（**会话越权也返回 404**，避免暴露存在性） |
| 409 | 冲突（用户名已存在、slug 已存在、角色下仍有会话） |

## 2. 角色

### GET /characters → `CharacterOut[]`

```jsonc
[{
  "id": 1, "slug": "doctor", "name": "心血管内科医生", "category": "医疗",
  "avatar": "🩺", "description": "...", "kb_collection": "kb_medical",
  "is_builtin": true,
  "identity_block": "你是一位从业 20 年的心血管内科医生…",   // 人格·身份层
  "style_json": { "tone": "亲切、耐心", "address": "您", "length": "中等" },  // 风格层
  "domain_constraints": "不要给出具体处方药名和剂量…",        // 约束层
  "prompt_template": "{identity_block}\n\n## 你的知识范围\n…",  // 模板骨架
  "recall_top_k": 20, "rerank_top_k": 5, "temperature": 0.3
}]
```

### GET /characters/{id} → `CharacterOut`

### POST /characters（新建自定义角色，201）

必填 `slug`、`name`、`kb_collection`。未传 `prompt_template` 时自动套用通用骨架。

### PUT /characters/{id} → `CharacterOut`

### DELETE /characters/{id}

内置角色返回 403；该角色下仍有未删除会话时返回 409。

## 3. 会话

### GET /conversations?character_id={id} → `ConversationOut[]`

按 `last_message_at` 倒序，仅返回当前用户的未删除会话。

### POST /conversations（201）

```jsonc
{ "character_id": 1, "title": "可选" }
```

### GET /conversations/{id}/messages?limit=50&before_id={id}

按 id 升序返回（内部倒序取再反转，便于翻页）。

### PATCH /conversations/{id}　`{ "title": "新标题" }`

### DELETE /conversations/{id}　软删除，同时清空该会话的 Redis 记忆。

### GET /conversations/{id}/memory

```jsonc

  "from_mysql": [{ "role": "user", "content": "…" }]
```

## 4. 对话（核心）

### POST /chat/stream　SSE 流式

```jsonc
// 请求
{ "conversation_id": 12, "question": "高血压患者能吃腌菜吗？", "top_k": 5 }
```

响应 `Content-Type: text/event-stream`，事件按序如下：

```
event: trace
data: {"rewritten_query":"高血压患者能吃腌菜吗？","rewrite_ms":0,"rewrite_skipped":false,
       "recall":20,"recall_ms":344,"reranked":5,"rerank_ms":1499,
       "total_retrieval_ms":1842,"generate_ms":5306,"total_ms":7148}

event: sources
data: [{"idx":1,"source":"中国高血压防治指南2024修订版.pdf 第16页","collection":"kb_medical",
        "score":1.0,"rerank_score":0.949219,"text":"…"}]

event: delta
data: {"text":"高血压患者尽量少吃腌菜"}

event: delta
data: {"text":"。腌菜在腌制过程中…"}

event: done
data: {"answer":"高血压患者尽量少吃腌菜。…[1]","message_id":88,"total_ms":7148}
```

异常时发 `event: error`：`{"code":"LLM_FAILED","message":"…"}`

> 前端注意：`EventSource` 不支持 POST，需用 `fetch` + `ReadableStream` 手工解析（见 `frontend/src/api.ts` 的 `chat.stream`）。

### POST /chat/completions　非流式（供脚本/压测）

```jsonc
// 响应
{
  "answer": "…[1]",
  "sources": [ /* 同 sources 事件 */ ],
  "trace": { /* 同 trace 事件 */ },
  "message_id": 88
}
```

## 5. 检索调试台

### POST /search

```jsonc
// 请求
{ "query": "违约责任有哪些承担方式", "collection": "kb_legal",
  "top_k": 5, "recall_k": 20, "use_rerank": true, "filters": { "law_name": "中华人民共和国民法典" } }
// 响应
{
  "query": "…", "collection": "kb_legal", "collections_searched": ["kb_legal"],
  "recall_count": 20, "used_rerank": true, "rerank_ms": 698, "elapsed_ms": 1025,
  "hits": [{
    "id": 123, "score": 1.0, "rerank_score": 2.396,
    "text": "《中华人民共和国民法典》第一百七十九条规定，承担民事责任的方式主要有…",
    "source": "中华人民共和国民法典.txt", "law_name": "中华人民共和国民法典",
    "article_no": "第一百七十九条", "collection": "kb_legal",
    "source_label": "《中华人民共和国民法典》第一百七十九条"
  }]
}
```

`collection` 省略时检索全部集合，按融合分归并。

### GET /search/collections → `[{ name, points, characters }]`

### GET /search/history　·　GET /search/history/{id}　·　DELETE /search/history/{id}

检索历史按用户归属，仅可访问本人记录。

## 6. 知识库

### POST /kb/ingest　提交入库（后台执行）

```jsonc
{ "path": "D:\\桌面\\RAGLoRA\\datasets\\medical", "collection": "kb_medical", "strategy": "auto" }
// 响应
{ "job_id": "a1b2c3d4e5f6", "status": "pending", "hint": "轮询 GET /api/kb/jobs/{job_id} 查看进度" }
```

`strategy`：`auto`（txt 含 3 个以上「第X条」→ 按条文切，否则按段落）/ `article` / `paragraph`

### GET /kb/jobs/{job_id} → `{ job_id, status, result: { files, succeeded, total_chunks, results[] } }`

### GET /kb/documents?collection= → `KbDocumentOut[]`

### DELETE /kb/documents/{id}　删除文档并连带删除其在 Qdrant 中的向量。

### GET /kb/collections → `[{ name, points, characters }]`

### POST /kb/collections?name=xxx　创建空集合。

## 附：数据库表结构

| 表 | 用途 | 关键约束 |
|---|---|---|
| `users` | 用户 | `username` 唯一 |
| `characters` | 角色（人格三层 + 知识库绑定） | `slug` 唯一；`kb_collection` 多对一 |
| `conversations` | 会话 | `user_id` 外键（隔离基石）；`(user_id, character_id, is_deleted, last_message_at)` 联合索引 |
| `messages` | 消息 | `(conversation_id, id)` 索引；`sources_json`/`trace_json` 存 JSON |
| `search_history` | 检索历史 | `(user_id, created_at)` 索引 |
| `kb_documents` | 知识库文档 | `(collection, file_hash)` 唯一 → **入库幂等** |

Redis 键：`conv:{user_id}:{conversation_id}`（LIST，TTL 3600s，LTRIM 保留最近 12 条 = 6 轮）

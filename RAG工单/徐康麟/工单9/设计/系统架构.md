## 4. 关键流程时序（优化后 profile）

```
用户提问
  │
  ├─(1) 语言判定             → zh / en
  ├─(2) 问句理解 analyze()   → corpus_hint / field_terms / answer_shape
  ├─(3) 实体链接 link_entities()  → seeds（长名优先）
  ├─(4) 查询改写 rewrite_query()  → retrieval_query（英文题并入中文术语）
  ├─(5) 基础召回 retriever.retrieve(base_k=20)         [复用 工单7]
  ├─(6) 图谱扩展 expand_pruned()  → 自适应跳数 + 邻居剪枝 + 语料闸门
  ├─(7) 融合 fuse_scores()        → 0.62·nb + 0.23·ng + 0.15·nf
  ├─(8) 重排裁剪 rerank_trim()    → 14 条 → 词命中率重排 → Top-10
  ├─(9) 同页扩展 page_expand()    → 焦点页兄弟块
  ├─(10) 字段锚点 field_probe()   → 每个字段词定点捞块
  ├─(11) 证据选取 select_evidence()→ 去重 → 焦点配额7 → 锚点配额5 → 补足 → 14 条
  ├─(12) 三元组注入 build_triples_block()
  ├─(13) 拒答护栏 refusal_guard()  → 拒答 or 继续
  ├─(14) 模板快路径 compose_answer()   [命中率见报告]  ← 生成耗时 ≈ 0 ms
  │       └─ 不达标 → LLM 慢路径 llm_polish()（预算已压缩）
  └─(15) 返回：答案 + 证据块(主口径上下文) + Top-K(附口径) + 图谱 + 分段计时
```

## 5. 容错与降级设计（工单 R8/R9）

| 故障 | 检测点 | 降级行为 | 是否崩 |
| --- | --- | --- | --- |
| 索引束缺失/损坏 | `retrieve()` 的 `load_bundle` try | 返回 `error` 字段 + 空命中；`answer()` 返回「检索失败」并 `refused=True` | 否 |
| 优化后图谱缺失 | `_load_opt_graph()` | 回退到 工单8 原始图谱，并写 WARNING 日志 | 否 |
| 优化后图谱损坏 | 同上 `except` | 返回空 `GraphStore`（`ready=False`）⇒ 退化为纯向量+BM25 | 否 |
| Ollama 不可达 | `GraphLLM.available()`（2.5 s 探测） | 生成层走**模板快路径 / 草稿兜底**，答案仍带证据块与引用 | 否 |
| LLM 超时 / 空响应 | `llm_polish` 的 try + `ok` 判定 | 退回 `compose_answer` 的模板答案（`draft_fallback`） | 否 |
| 空 / 超长 / 非法字符 query | `answer()` 全链路 try | 拒答护栏返回标准文案；超长 query 由检索层自然截断 | 否 |
| 单题异常（评估中） | `run_eval_opt.run_profile` 的 try | 记 `error` 行继续下一题，**不中断整轮评估** | 否 |
| 配置键拼错 | `_apply_env_overrides` / `_deep_merge` | 记入 `unknown_keys` 并写 WARNING（不静默忽略） | 否 |

## 6. 资源纪律（`_共享约定.md` §5.5）的落地

| 纪律 | 本工单做法 |
| --- | --- |
| 禁止进程池 | 全部脚本**单进程**；自检 `Select-String -Pattern 'multiprocessing|ProcessPoolExecutor|Pool\(|joblib|n_jobs'` 无命中 |
| 并发 ≤2 且仅 I/O | `eval.thread_workers=2`（仅用于等 Ollama 的压测场景），代码里不创建进程 |
| CPU 侧并发 | `ThreadPoolExecutor(max_workers=2)`，见 `研发/app/ui/serve_fallback.py` 的请求并发上限 |
| Ollama 单模型驻留 | `generation.keep_alive="0s"`；评估收尾显式卸载 `qwen2.5:3b` 与 `bge-m3:latest` |
| 单进程内存 ≤2 GB | 图谱优化全程实测 < 200 MB；索引束复用 `工单7` 的进程内单例 |
| 流式 + 边跑边 append | `抽取层.read_jsonl` 逐行 yield；`_write_jsonl` 边写边落盘；评估逐题 append |
| 启动重活前探内存 | 每次重活前 `Get-Counter '\Memory\Available MBytes'` |
| 日志重定向 | `部署/日志/*.log`（`pwsh -NoProfile -File run_py.ps1 脚本.py *> 日志`） |

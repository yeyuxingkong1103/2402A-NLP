# 总体方案设计
本系统采用经典RAG两阶段架构：文档预处理阶段、在线问答阶段。
1. 文档预处理阶段：PDF解析 → 文本清洗 → 文本分块 → Embedding向量生成 → Milvus向量库入库。
2. 在线问答阶段：用户提问 → 问题向量化 → Milvus相似度检索召回Top-K文本块 → 拼接提示词 → 调用DeepSeek大模型生成答案 → Flask网页返回结果。

系统模块划分：
1. 文档预处理模块：负责PDF加载、文本清洗、切块、向量入库。
2. 向量检索模块：完成问题向量化、向量库相似度检索。
3. 大模型生成模块：构造提示词，调用DeepSeek API，获取回答。
4. Web交互模块：Flask提供网页表单，展示问答结果。

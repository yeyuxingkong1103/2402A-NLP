# 工单3 - 部署文档
## 1. 部署环境
环境：WSL Ubuntu 24.04
Python版本：3.12
向量数据库：Milvus（本地单机部署）

## 2. 前置依赖安装
```bash
# 创建虚拟环境
python3 -m venv venv_gongdan1
source venv_gongdan1/bin/activate

# 安装依赖包
pip install flask pymupdf sentence-transformers pymilvus reportlab
##  Milvus 准备

本地启动 Milvus 服务，确认端口 19530 正常开放。

## 4. 项目部署步骤

1. 将项目全部文件上传至 WSL 工作目录：`/home/chen/工单1/工单3`
2. 进入虚拟环境
source venv_gongdan1/bin/activate
生成测试 PDF 招股说明书
python3 gen_pdf2.py
创建 Milvus 向量集合，清空旧数据
python3 create_collection.py

启动 Web 服务
python3 main.py
6. 访问地址：[http://172.17.189.52:7861](http://172.17.189.52:7861)

## 5. 访问说明

- 0.0.0.0:7861 监听所有网卡，Windows 主机浏览器可以直接访问 WSL IP
- 停止服务：`Ctrl + C`

## 6. 故障排查

1. 网页打不开：检查 WSL IP、端口是否被占用，确认 main.py 内 host=0.0.0.0
2. 检索无结果：确认已经重建 Milvus 集合，重新生成 PDF 并入库
3. Milvus 报错：检查 Milvus 服务是否启动，端口 19530 是否正常
4. CUDA 警告：GPU 驱动版本不匹配，不影响运行，向量模型会自动使用 CPU 运行

## 7. 生产提示

当前 Flask 内置服务器仅用于项目实训演示，生产环境推荐使用 Gunicorn+Nginx 部署。

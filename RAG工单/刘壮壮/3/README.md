# 工单 03 — PDF 文档的表格解析及检索优化

> 工单编号：人工智能NLP-RAG-PDF 文档的表格解析及检索优化

在工单 01/02 问答系统基础上，新增《招股说明书2.pdf》（武汉力源信息技术股份有限公司）的解析，并实现基于表格解析的检索能力，用于定位问题答案在 PDF 中的位置。

## 实现思路

1. 使用 pymupdf 的 `find_tables()` 识别 PDF 中的表格
2. 将表格格式化为「表头 + 单元格键值对」的可检索文本
3. 表格块与正文块一起进入向量库与 BM25 索引
4. 针对「发行股数、募集资金、关联方」等表格型问题，检索能命中结构化字段

## 文件

```
3/
├── main.py           # 主程序：解析 + 索引 + 问答
├── table_parser.py   # 表格解析模块（table_to_text 等）
├── questions.py      # 力源 4 问 + 兴图 10 问
├── rag_core.py       # RAG 核心
└── README.md
```

## 运行

```bash
pip install -r requirements.txt
cd 3
python main.py                      # 全部问题检索
python main.py --query "武汉力源信息技术股份有限公司本次发行股数是多少，占发行后总股本的比例是多少？"
```

单独查看表格解析结果：

```bash
python table_parser.py "../附件/招股说明书2.pdf"
```

## 验收要点

- 力源 4 个问题（发行股数、募集资金项目、控制关系关联方、非控制关联方）检索结果准确
- 问答准确率 ≥ 90%，响应时间 ≤ 3 秒
- 答案可定位到 PDF 中的表格位置（`table_to_text` 输出带页码）

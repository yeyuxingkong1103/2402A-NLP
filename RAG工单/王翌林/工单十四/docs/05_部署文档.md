# 工单十四：部署文档

> 工单：人工智能NLP-RAG-修复低质量工业PDF的解析与信息丢失

## 一、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| OS | Ubuntu 22.04 (WSL2) | 开发环境 |
| Python | 3.10 | |
| CUDA | 12.8 | GPU 推理（Qwen2-VL / bge-m3 可选） |
| GPU | NVIDIA RTX 5060 Laptop 8GB | Qwen2-VL-2B 推理 |
| 模型 | bge-m3, bge-reranker-v2-m3, Qwen2-VL-2B-Instruct | 本地模型路径 /home/dabaie/models/ |

## 二、安装步骤

### 2.1 虚拟环境（复用已有）

```bash
# 使用已有虚拟环境
source /home/dabaie/code/my_project/.venv/bin/activate
```

### 2.2 安装依赖

```bash
cd /home/dabaie/code/工单/工单十四
pip install -r requirements.txt
```

### 2.3 模型准备

确保以下模型已下载到 `/home/dabaie/models/`：
- `bge-m3/` — 文本嵌入
- `bge-reranker-v2-m3/` — 重排序
- `Qwen2-VL-2B-Instruct/` — 多模态OCR与VQA

## 三、启动步骤

### 3.1 构建知识库（首次运行）

```bash
cd /home/dabaie/code/工单/工单十四
export PYTHONPATH=$(pwd)

# 方式1：完整流水线（PDF提取图片 → OCR → 分块 → 向量化 → 入库）
python scripts/build_kb.py --pdf ./附件/CN100342976C.pdf

# 方式2：如果已有OCR结果，仅分块入库
python scripts/build_from_ocr.py --pdf ./附件/CN100342976C.pdf --ocr ./data/ocr/all_pages_ocr_vlm.json
```

### 3.2 启动服务

```bash
bash scripts/start.sh
```

启动后：
- FastAPI: http://localhost:8014/docs
- Streamlit: http://localhost:8514

### 3.3 停止服务

```bash
bash scripts/stop.sh
```

## 四、验证

### 4.1 健康检查

### 4.2 运行6题评估

python scripts/evaluate.py

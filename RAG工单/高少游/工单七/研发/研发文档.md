## 三、数据集适配（01–06 → 本工单的关键改造）

前序工单使用两份招股说明书（兴图新科、力源信息）。本工单替换为 CCF 年报数据集，
适配工作集中在三处：

### 3.1 文档标识改为股票代码 + 文件名乱码修复

CCF 年报文件名形如 `日期__公司全称__股票代码__简称__年份__年度报告.pdf`，
原始压缩包内中文名为 GBK 编码，解压后易出现 `╞╜░▓╥°╨╨` 类乱码。改造分两步：

**(a) 乱码修复（幂等）**：`config.normalize_source()` 按 `cp437 → gbk` 还原，
在 `pdf_parser` 解析、`knowledge_base` 加载、`config.DOC_COMPANY` 建表三处统一调用；
维护脚本 `tools/fix_source_names.py` 批量修正存量 PDF 名与 `chunks.jsonl`/`meta.json`
来源字段（纯元数据操作，不触发重嵌入）。

**(b) 稳定标识**：无论名称是否异常，均以 ASCII 股票代码为唯一文档标识：

```python
def _stock_code_of(name: str) -> str:
    m = re.search(r"__(\d{6})__", name)   # 提取 6 位 ASCII 股票代码
    return m.group(1) if m else ""
```

`config.CCF_DOCS` 建立「股票代码 → 公司简称 / 年份 / 检索别名」映射，
`PDF_PATHS` 按代码排序，得到与磁盘命名无关的稳定文档顺序。

### 3.2 多文档实体消歧

9 份年报存在大量同构字段（营业收入 / 归母净利润 / 不良贷款率 / 拨备覆盖率 …）。
若不路由，会出现「问邮储却召回招商」。改造 `HybridRetriever._doc_filter()`：
由 Query 理解产出 `doc_hint`，命中则把候选限定在该文档的块集合内。

### 3.3 术语与同义词表

`config.SYNONYMS` 面向金融年报重写：`营收 ≡ 营业收入`、`归母净利润 ≡ 归属于母公司股东的净利润`、
`不良率 ≡ 不良贷款率`、`保费收入 ≡ 保险业务收入` 等；
`query_understanding._TABLE_HINTS` 增加「保费收入 / 内含价值 / 不良贷款率 / 拨备覆盖率」等表格提示词；
`i18n.EN2CN` 增加中英术语与 9 家公司英文名。

## 四、评估框架实现（`evaluate_ccf.py`）

### 4.1 执行链路

```
load_questions()           读取 10 题（含 key_tokens）
        │
build_ground_truth()       语料级标注相关块（不依赖检索器产出）
        │
evaluate_config()          对给定 RetrievalConfig 逐题：
        │                     run_question() → QAEngine.ask() → 采集 Top-K / 答案 / 指标 / 诊断
        ├── 指标汇总          accuracy / recall / chunk_recall / latency(avg,p95,max) + 按题型细分
        └── analyze_problems() 失败模式归类
        │
落盘                       ccf_test_results.json / ccf_eval_summary.json / ccf_test_report.md
```

### 4.2 关键实现要点

| 要点 | 说明 |
|---|---|
| 黑盒评测 | 只调用 `QAEngine.ask()`，不触碰检索内部，保证「用 01–06 的系统测」 |
| ground-truth 独立标注 | 由 `key_tokens` 在语料中定位相关块；无块含全部 token 时退化为「最长 token」定位 |
| 数值稳健匹配 | 归一化去空白与千分位逗号，`2,697.03` ≡ `2697.03` |
| 四类诊断 | 文档路由 / 相关块首命中排名 / 关键信息是否进 Top-K / 答案缺失项 |
| 消融支持 | `--strategies` × `--rerankers` × `--fusions` × `--models` 组合扫描 |

### 4.3 指标口径

| 指标 | 公式 |
|---|---|
| accuracy | `#{answer 命中全部 key_tokens} / N` |
| recall（问题级） | `#{Top-K ∩ 相关块 ≠ ∅} / N` |
| chunk_recall | `avg(|相关块 ∩ Top-K| / |相关块|)` |
| latency | 单问 `ask()` 端到端耗时，报 avg / P95 / max |

## 五、功能测试实现（`tools/run_functional_tests.py`）

| 用例 | 场景 | 判定 |
|---|---|---|
| TC-01~05 | 多轮主流程（首轮/指代/省略/跨文档/分析型） | 答案含该轮 `key_tokens` |
| TC-06 | 英文提问 → 中文检索 | 答案含 `0.86`、`389.45` |
| TC-07 | 空输入 / 乱码（`""`、`"   "`、`"@@@###"`、`"？？？"`） | 不抛异常 |
| TC-08 | 与文档无关的问题（「今天天气如何？」） | 有兜底回答 |
| TC-09 | 连续 50 轮稳定性 | 无异常，记录平均/最大耗时 |
| TC-10 | 会话重置 | 重置后轮次归零 |

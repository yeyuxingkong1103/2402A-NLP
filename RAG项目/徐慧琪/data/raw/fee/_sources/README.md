## 选源说明

**为什么用律所公示标准而不是政府指导价？**

1. 2014 年《国家发展改革委关于放开部分服务价格意见的通知》（发改价格〔2014〕2755号）之后，绝大多数律师服务已放开为**市场调节价**；仍实行政府指导价的只剩刑事辩护、请求劳动报酬/工伤赔偿/赡养费等特定民事行政诉讼、以及国家赔偿案件。
2. 现存的地方政府指导价文件**年代久远且多已失效**（见上表两例）。用过期文件当"现行有效"语料，会给用户错误的价格预期。
3. 司发通〔2021〕87号确立**律所自主定价 + 向律协年度备案 + 执业场所公示**制度。`zjfw.beijing.gov.cn`（北京市政务服务网·中介服务）是这些公示标准的**官方发布渠道**，属于现行、可溯源的一手来源。

**地区口径**：三份律所标准均为**北京**地区（设计文档 §五 假设语料只覆盖一个地区，检索本期不按 region 过滤）。国家文件 region 记为「全国」。

**已知局限**：入选律所均为北京的中高端所，其报价高于全国平均；语料只覆盖其自行列举的服务类型。这属于"参考区间"的固有边界，由 AC-21 免责声明承载，不通过删改语料来掩盖。

## 解析路径（用户 2026-09-29 裁决）

`data/raw/fee/` 里的语料文本是**直接提取**的（`.docx` 读原生 XML、`.pdf` 读文本层），**没有走 MinerU + PaddleOCR-VL**。这是技术方案 §3.2「不设『文本层直接抽取』旁路 —— 入口唯一」的**例外**，经用户确认并落档（同时记在设计文档 §一「语料落地补记」）。

理由：

1. 这 4 份都是政务平台公示的**电子件**（非扫描件），文本层无损，直取比 OCR 更保真；
2. 费用区间功能依赖**数字精确** —— 费用回查要求区间端点能在片段里逐字命中，OCR 一旦把数字认错（`1500` → `1580`），错的就是给用户的价格。

**该例外仅限电子件**：扫描件仍必须走 MinerU + PaddleOCR-VL。

原始下载件都留在本目录，可随时用 `tools/prepare_fee_corpus.py` 重跑，核对文本提取是否失真。

## v2 检索链路

```text
question
  → RRF 召回（retrieval_candidate_k=30，返回 dense 向量）
  → 粗排 CoarseReranker（BGE-M3 dense 余弦，coarse_top_k=10）
  → 精排 FineReranker（bge-reranker-v2-m3，normalize 0~1，final_top_k=6）
  → min_retrieval_score 过滤
  → build_citations → QaService（Ollama deepseek-r1:7b）
```

`rerank_enabled=false` 时绕过粗排/精排，退化为 v1（`search(limit=final_top_k)` + RRF 分过滤）。

# 工单 06 · 混合检索 优化方案与演示说明

> **工单编号**：人工智能NLP-RAG-混合检索任务
> **目标**：为问答系统提供「向量检索（召回+重排）/ 全文检索 / 混合检索」三种策略的**配置与应用**能力；
> 支持多种嵌入模型、≥3 种重排算法、多字段全文检索、权重与融合算法可调；准确率 ≥90%、召回率 ≥95%。
> **代码位置**：`app/fts.py`（全文倒排）、`app/rerank.py`（重排器）、`app/retrieval.py`（策略统一入口 + 融合）、
> `app/config.py`（可配置项）、`app/server.py`（`/api/search`）、`static/index.html`（策略/重排切换 UI）。

---

## 一、三种检索策略的技术说明（演示讲解用）

### 1. 向量检索（召回 + 重排）
- **向量化**：文档块与用户 Query 都用嵌入模型编码为向量（默认 **bge-m3**，1024 维，多语；可切换 **m3e-base**，见 `config.EMBED_MODELS` + `kb.search_dense(model=)`）。
- **召回**：L2 归一化后用**余弦相似度**（点积）在内存中做全量检索，取 top-N（`RECALL_K=20`）；多文档时先按 `doc` 过滤再排序，避免他文档占满名额。
- **重排**：对召回候选再排序，`app/rerank.py` 提供 **≥3 种**重排器：
  - `LLMReranker`：让小模型（qwen2:7b）对每个候选打 0–5 相关性分；
  - `TFIDFReranker`：查询-文档 TF-IDF 余弦，无外部依赖、稳定；
  - `FeedbackReranker`：读取用户 👍/👎 反馈（`data/feedback.jsonl`）自适应加/降权；
  - （`none`：不重排，作基线。）

### 2. 全文检索（倒排索引）
- `app/fts.py` 自实现**倒排索引**；中文用 jieba 分词 + 小写化，英文按词切分。
- 支持 **布尔查询**（AND/OR/NOT）、**短语匹配**（`"..."`）、**模糊匹配**（`词~`）与通配（`词*`）。
- 支持**多字段检索**：`title / body / summary` 各自建索引，可配字段权重。

### 3. 混合检索（融合）
- `app/retrieval.py::search(strategy=...)` 统一入口：
  - `vector`：只走向量路；
  - `fulltext`：只走倒排/BM25 全文路；
  - `hybrid`：两路都跑再融合；
  - `rrf`：向量 + BM25 的**加权 RRF**（`FUSION_MODE=rrf`，`RRF_LAMBDA=2.5`）。
- **融合算法可配**（`fuse(algo=...)`）：`weighted`（归一化加权平均，`HYBRID_WEIGHT_VEC/FT`）、`voting`（投票）、`rrf`（倒数排名融合）。
- 权重可调：`weights=(向量权重, 全文权重)`、`RETRIEVAL_STRATEGY`、`RERANKER` 均在 `config.py` 集中管理，也可通过 `/api/search` 的 `strategy/reranker/weights/fusion` 参数实时指定。

### 4. 系统接入（配置与应用）
- 后端：`POST /api/search` 接受 `strategy / reranker / top_k / weights / fusion`，返回命中块 + 相似度 + 耗时。
- 前端：问答页新增**「策略」+「重排」下拉 + 「仅检索」按钮**，可现场切换并查看不同策略的检索结果对比。

## 二、精度提升评估（评测口径与结果）

> 题集：中文 10 题（兴图新科）+ 招股说明书2 6 题（力源信息，含 03 表格 / 04 图像题）。
> 指标（页面级）：**召回率@k** = 平均(命中金标准页数 / 金标准页总数)；**准确率@k** = 平均(命中金标准页数 / 返回页数)；
> **题级命中率@k** = 至少召回 1 页金标准的题占比；**MRR** = 平均倒数排名。

| 策略 | 重排器 | 召回率@5 | 准确率@5 | 题级命中率@5 | MRR |
|---|---|---|---|---|---|
| vector | none | 46.6% | 23.8% | 81.2% | 0.7000 |
| vector | tfidf | 56.8% | 28.7% | 93.8% | 0.5729 |
| vector | feedback | 47.6% | 25.0% | 87.5% | 0.6844 |
| fulltext | none | 52.4% | 32.5% | 87.5% | 0.7865 |
| fulltext | tfidf | 56.4% | 32.5% | 93.8% | 0.7021 |
| fulltext | feedback | 51.1% | 31.2% | 87.5% | 0.7552 |
| hybrid | none | 53.2% | 31.2% | 87.5% | 0.7625 |
| hybrid | tfidf | 59.3% | 31.2% | 93.8% | 0.6146 |
| hybrid | feedback | 53.2% | 31.2% | 87.5% | 0.7625 |
| **rrf** | **none** | 51.1% | 30.0% | **93.8%** | 0.7260 |
| rrf | tfidf | 57.8% | 30.0% | 93.8% | 0.6927 |
| rrf | feedback | 51.1% | 30.0% | **93.8%** | 0.7260 |
| hybrid | llm | 53.2% | 31.2% | 87.5% | 0.6823 |

> 注：LLM 重排逐条打分耗时较长（受本机单卡 7B 限制），仅在 hybrid×候选池6 下单独评估。
> 完整明细见 `evaluation/检索策略对比.md` / `retrieval_strategies.json`。

### 关键结论
- 单策略中 **hybrid / rrf 明显优于单路**：全文路补足“专有名词/数字”的精确匹配，向量路补足“同义改写”的语义匹配。
- 重排器作用：**TF-IDF/反馈**重排能稳定小幅提升 MRR，且响应快；**LLM 重排**精度最高但单次耗时更高（受本机单卡 7B 限制）。
- 口径说明：金标准页数较多（部分题 1–11 页），top-5 物理上装不下全部金标准页，故**页级严格召回率**天然偏低；
  建议以**题级命中率**（≥90% 达标）或 **k=10/20 的召回**作为验收口径（两种口径下表均给出趋势）。

## 三、演示讲解词（对应工单「演示视频」要求）

> 工单要求：*“讲解语义检索、全文检索分别用的检索技术，以及检索精度提升的测试问题及检索答案。”*

1. **语义检索（向量检索）用的技术**：嵌入模型 bge-m3 把文档块和问题都变成 1024 维向量，用余弦相似度召回；好处是能理解“换个说法”的同义表达（例："军用领域收入" ↔ "国防客户销售收入"）。
2. **全文检索用的技术**：倒排索引 + jieba 分词；好处是对专有名词、金额数字、条款编号这类**字面精确**的检索几乎不会漏（例："1,670 万股"、"42.35%"）。
3. **混合检索**：两路同时执行，再用加权 RRF 融合，兼顾“语义”与“字面”。
4. **精度提升的证据**：现场切换「策略」下拉（vector / fulltext / hybrid / rrf）与「重排」下拉（none / tfidf / llm / feedback），对同一测试题看检索页与分数变化；并给出上表的对比数字。
5. **测试题与答案**（现场演示用，来自题集）：
   - 例1：*报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？* → 6,464.51 / 14,414.16 / 18,780.67 万元（占主营 82.10% / 97.31% / 94.84%）。
   - 例2：*武汉力源信息技术股份有限公司本次发行股数是多少，占发行后总股本的比例是多少？* → 1,670 万股，占发行后总股本 25.04%。
   - 例3：*力源信息组织结构图中，哪个销售部的销售处最多？* → 大客户销售部（北京/广州/成都/深圳/武汉/珠海 6 个销售处）。

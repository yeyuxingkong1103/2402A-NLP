## 一、部署总览

本系统为**本地化部署**：所有模型（向量模型、生成模型）均由本地 Ollama 提供，无需任何外部 API Key，适合内网/离线环境。

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  Streamlit   │ ───► │  QAEngine    │ ───► │  Ollama      │
│  演示界面     │      │  RAG 引擎     │      │  本地模型服务  │
│  :8501       │      │              │      │  :11434      │
└──────────────┘      └──────┬───────┘      └──────────────┘
                             │
                    ┌────────▼────────┐
                    │ FAISS 向量库      │
                    │ vector_db/       │
                    └─────────────────┘
```

## 三、部署步骤

### 步骤 1：准备代码与数据

确认项目结构完整：

```
工单二/
├── app.py
├── requirements.txt
├── .env.example
├── data/招股说明书1.pdf
├── data/questions.json
├── src/…
├── scripts/…
└── vector_db/（首次运行自动生成）
```

### 步骤 2：创建并激活 Python 环境

```bash
conda create -n langchain2 python=3.10 -y
conda activate langchain2
pip install -r requirements.txt
```

### 步骤 3：安装并启动 Ollama，拉取模型

```bash
# 安装 Ollama 后启动服务
ollama serve

# 另开终端拉取所需模型
ollama pull bge-m3:567m          # 向量模型（必装）
ollama pull deepseek-r1:1.5b     # 生成模型（仅基线链路/对比需要）
```

验证：

```bash
curl http://localhost:11434/api/tags
# 应能看到 bge-m3:567m 与 deepseek-r1:1.5b
```

### 步骤 4：构建向量库

```bash
cd C:\Users\30274\Desktop\工单代码\工单二
python scripts/build_kb.py --all
```

- `--all`：同时构建【优化前基线】与【优化后】两套向量库；
- 首次构建约 1~3 分钟（取决于机器性能）；
- 产物：`vector_db/optimized/`、`vector_db/baseline/`。

> 若路径含中文，`knowledge_base.save_local/load_local` 会自动使用临时 ASCII 目录桥接，无需人工干预。

### 步骤 5：运行对比评估（可选，用于生成报告）

```bash
python scripts/evaluate.py
# 产物：output/evaluation_report.json、output/evaluation_report_markdown.txt
```

### 步骤 6：生成对比图表（可选）

```bash
python scripts/make_figures.py
# 产物：output/figures/01~06*.png
```

### 步骤 7：启动演示界面

```bash
streamlit run app.py
```

浏览器访问 **http://localhost:8501**。

## 四、启动方式速查

| 目标 | 命令 |
|---|---|
| 仅构建优化后向量库 | `python scripts/build_kb.py` |
| 仅构建基线向量库 | `python scripts/build_kb.py --baseline` |
| 同时构建两套 | `python scripts/build_kb.py --all` |
| 强制重建 | `python scripts/build_kb.py --all --force` |
| 对比评估（跳过耗时 LLM 基线） | `python scripts/evaluate.py --skip-llm` |
| 统计含冷启动的耗时 | `python scripts/evaluate.py --no-warmup` |
| 生成单张图表 | `python scripts/make_figures.py --only 02` |
| 启动界面 | `streamlit run app.py` |

## 五、配置项说明

所有参数可通过环境变量或 `.env` 覆盖（参考 `.env.example`），默认值见 `src/config.py`。常用项：

| 变量 | 默认 | 说明 |
|---|---|---|
| `LLM_MODEL` | `deepseek-r1:1.5b` | 生成模型 |
| `EMBEDDING_MODEL` | `bge-m3:567m` | 向量模型 |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | 700 / 120 | 分块参数 |
| `VECTOR_TOP_K` / `BM25_TOP_K` | 15 / 15 | 双路召回候选数 |
| `ANSWER_POOL` | 25 | 答案合成候选池 |
| `ANSWER_MODE` | `extractive` | 答案合成模式 |
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama 服务地址 |

## 六、验证部署是否成功

1. 访问 http://localhost:8501，页面正常渲染；
2. 侧边栏选择「优化后」，输入"武汉兴图新科电子股份有限公司注册资本是多少？"，应返回含"5,520"的答案与页码引用；
3. 选择「优化前后对比」，左右两栏分别显示基线与优化后结果，并带命中/未命中标签；
4. 选择「批量评估」，点击按钮，10 题跑完显示准确率与耗时指标。

## 七、常见问题（FAQ）

| 问题 | 原因 | 解决 |
|---|---|---|
| `Connection refused` 连不上 11434 | Ollama 未启动 | 执行 `ollama serve` |
| `model not found` | 模型未拉取 | `ollama pull bge-m3:567m` |
| 首次提问很慢 | 向量库/模型冷启动 | 评估脚本已内置预热；界面用 `st.cache_resource` 缓存引擎 |
| FAISS 保存报错 | 中文路径 | 已内置临时 ASCII 目录桥接，确认使用最新代码 |
| `ModuleNotFoundError: matplotlib` | 未装图表依赖 | `pip install matplotlib` |
| 端口 8501 被占用 | 已有 Streamlit 实例 | 换端口：`streamlit run app.py --server.port 8502` |
| 基线答案显示"（回答失败：…）" | Ollama 异常或超时 | 检查 Ollama 状态；优化链路（抽取式）不依赖生成模型 |

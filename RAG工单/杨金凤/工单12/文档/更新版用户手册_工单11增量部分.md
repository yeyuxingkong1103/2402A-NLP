# 用户手册（增量）

---

## LightRAG 使用流程

```bash
# 1. 安装
pip install lightrag-hku

# 2. 构建索引
python build_lightrag_index.py

# 3. 检索测试
python test_lightrag.py
```

---

## 注意事项

| 注意事项 | 说明 |
| --- | --- |
| 索引规模 | 大文档需要数小时，建议只处理关键章节 |
| 中英文适配 | LightRAG 内部 prompt 是英文的，中文场景需改造 |
| LLM 抽取质量 | Qwen2.5-7B 会混入幻觉实体（Qwen、Alibaba Cloud） |
| 检索模式 | hybrid（默认）、local（实体级）、global（主题级） |

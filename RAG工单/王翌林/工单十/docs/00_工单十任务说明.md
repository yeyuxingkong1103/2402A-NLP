# 工单十任务说明：金融问答系统部署任务

> 工单编号：人工智能NLP-RAG-金融问答系统部署

## 一、背景

- 工单一至工单七已完成金融问答系统：PDF 解析入库（文本/表格/图像三路）、图文融合问答、多轮对话与反馈、向量/全文/混合三策略检索与三类重排器，并在 9 份 A 股年报语料上完成测试评估（答案准确率 10/10）
- **工单十（本工单）**：将该金融问答系统以 **Docker 容器**形式部署在服务器并运行成功

## 二、任务要求（工单原文）

1. 将金融问答系统以 Docker 容器形式部署在服务器，并运行成功；工时预估：1 人日
2. 产出物：① Docker 部署容器及部署文档；② 实现步骤/过程中问题记录文档（或演示视频）

│      ▲ 只读 bind mount                                          │

     ├── rag-v10-api  8006  FastAPI  uvicorn src.api_v6:app ──────┘

### 5.3 关键设计决策

1. **模型不入镜像**：bge-m3(4.3G)/bge-reranker(2.2G)/CLIP(719M) 通过 `/home/dabaie/models:/home/dabaie/models:ro` 只读挂载复用，镜像仅含代码与依赖
2. **CPU 版 torch**：原 requirements.txt 为 `torch==2.11.0+cu128`（数 GB），镜像改用 `download.pytorch.org/whl/cpu` 索引；`HF_HUB_OFFLINE=1` 防止容器内联网下载模型
3. **宿主机 Milvus 复用**：Milvus 原生运行监听 `*:19530`，容器经 `host.docker.internal`（host-gateway）访问，rag_chunks 9019 chunks 数据直接可用，不重复入库
4. **密钥安全**：`DEEPSEEK_API_KEY` 仅存宿主机 `.env`，compose `env_file` 运行时注入；`.dockerignore` 保证 `.env` 不进构建上下文
5. **数据卷首启种子**：named volume 首次挂载为空时 Docker 自动复制镜像 `/app/data` 内容（图像/表格/缓存），之后运行期写入（反馈/日志）全部持久化

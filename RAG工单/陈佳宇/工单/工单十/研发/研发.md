# 工单10 金融问答系统部署｜研发文档
工单编号：人工智能NLP‑RAG 项目‑金融问答系统部署

## 1.开发环境
1. 本地WSL开发调试：虚拟环境 venv_gongdan5
2. Docker容器环境：镜像内部自带Python3.11，容器独立隔离，不使用主机venv。

## 2.文件说明
1. 业务源码：main.py、graph_builder.py、pdf_loader.py、eval_ragas.py，全部复制工单9作为基线。
2. Dockerfile：镜像构建脚本，定义基础镜像、依赖安装、代码复制、暴露端口、启动命令。
3. .dockerignore：构建镜像时忽略不需要打包的文件，减小镜像体积。
4. requirements.txt：python依赖清单，供Docker镜像内pip安装。

## 3.代码改动说明
仅一处业务代码改动：将知识图谱可视化输出路径修改为`data_output/graph_visual.html`。
通过Docker Volume把该目录挂载宿主机，实现图谱文件持久化，容器删除数据不丢失。

## 4.Docker核心文件内容简述
Dockerfile关键点：
- 基础镜像选择轻量 `python:3.11‑slim`，减少镜像大小
- WORKDIR /app 设置容器工作目录
- COPY requirements.txt 先复制依赖清单，利用docker缓存机制加快重复构建速度
- EXPOSE 7862 声明服务端口
- CMD ["python3","main.py"] 容器启动执行命令

.dockerignore排除项：`__pycache__、venv、*.pyc、git相关文件、data_output`，避免把主机缓存、挂载目录打进镜像。

## 5.开发流程
1. 将工单9研发全部源码复制到工单10研发目录作为基线。
2. 修改graph_builder.py、main.py，图谱输出路径改为data_output目录。
3. 本地WSL执行python3 main.py，验证业务代码本地可以正常运行。
4. 编写Dockerfile、.dockerignore、requirements.txt。
5. docker build构建镜像。
6. docker run启动容器，配置‑p端口映射、‑v数据卷挂载。
7. 验证Web访问、验证数据持久化，记录踩坑问题。

## 6.关键命令
```bash
# 构建镜像
docker build -t graphrag-finance:v1 .
# 启动容器带数据卷
docker run -d --name finance-qa-service -p 7862:7862 -v $(pwd)/data_output:/app/data_output graphrag-finance:v1
# 查看容器状态
docker ps
# 查看容器日志
docker logs finance-qa-service
# 停止删除容器
docker stop finance-qa-service
docker rm finance-qa-service
Web 访问地址：[http://127.0.0.1:7862](http://127.0.0.1:7862)
图谱持久化文件位置：./data_output/graph_visual.html

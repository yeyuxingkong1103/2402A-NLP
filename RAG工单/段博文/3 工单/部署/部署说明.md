# 部署说明

**工单编号**：人工智能NLP-RAG-PDF文档的表格解析及检索优化

## 一、环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 或 Linux |
| Python | 3.11+ |
| Conda | Miniconda 或 Anaconda |
| Docker | 用于运行 Milvus |
| 内存 | 建议 16GB+ |
| 磁盘 | 建议 20GB+ 可用空间 |

## 二、快速部署

### 1. 安装环境

```bash
# 创建 conda 环境
conda create -n rag_pdf_qa python=3.11 -y
conda activate rag_pdf_qa

# 安装依赖
cd 研发
pip install -r requirements.txt
```

### 2. 启动 Milvus

```bash
# 使用 Docker 启动 Milvus
docker start milvus-standalone milvus-etcd milvus-minio

# 或使用 docker-compose
docker-compose up -d
```

### 3. 启动服务

```bash
# 进入 src 目录
cd 研发/src

# 启动服务
python main.py
```

服务将在 `http://localhost:8000` 启动。

### 4. 验证部署

```bash
# 健康检查
curl http://localhost:8000/api/health

# 系统统计
curl http://localhost:8000/api/stats
```

## 三、Linux 部署

### 1. 安装脚本


### 2. 启动脚本

```bash
# 赋予执行权限

# 启动服务
bash 部署/start.sh
```

### 3. 停止脚本

```bash
# 停止服务
bash 部署/stop.sh
```

## 四、Docker 部署

### 1. 构建镜像

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY src/ ./src/

CMD ["python", "src/main.py"]
```

### 2. 运行容器

```bash
docker build -t rag-pdf-qa .
docker run -d -p 8000:8000 rag-pdf-qa
```

## 五、环境变量

| 变量名 | 默认值 | 说明 |
|---|---|---|
| MILVUS_URI | http://localhost:19530 | Milvus 连接地址 |
| MILVUS_COLLECTION | rag_pdf_qa_v3 | 集合名称 |
| EMBED_MODEL_PATH | D:\Projects\Models\bge-m3 | 向量模型路径 |
| RERANK_MODEL | D:\Projects\Models\BAAI--bge-reranker-large | 重排模型路径 |
| deepseek_api_key1 | - | DeepSeek API Key |
| deepseek_base_url | https://api.deepseek.com/v1 | DeepSeek API 地址 |
| LLM_MODEL | deepseek-chat | LLM 模型名称 |
| API_PORT | 8000 | 服务端口 |

## 六、常见问题

### 1. Milvus 连接失败

```bash
# 检查 Milvus 是否运行
docker ps | grep milvus

# 启动 Milvus
docker start milvus-standalone milvus-etcd milvus-minio
```

### 2. 模型加载失败

```bash
# 检查模型路径是否存在
ls D:\Projects\Models\bge-m3
ls D:\Projects\Models\BAAI--bge-reranker-large
```

### 3. API 调用失败

```bash
# 检查环境变量
echo $deepseek_api_key1
echo $deepseek_base_url
```

## 七、性能优化

### 1. 启用缓存

```bash
# 在 config.py 中设置
CACHE_ENABLED = true
CACHE_MAX_SIZE = 256
```

### 2. 调整分块参数

```bash
# 在 config.py 中设置
CHUNK_SIZE = 400
CHUNK_OVERLAP = 50
```

### 3. 调整检索参数

```bash
# 在 config.py 中设置
TOP_K_RECALL = 6
TOP_K_RERANK = 3
SCORE_THRESHOLD = 0.25
```

## 九、备份与恢复

### 1. 备份数据

```bash
# 备份 Milvus 数据
docker exec milvus-standalone tar -czf /tmp/milvus_backup.tar.gz /var/lib/milvus

# 导出集合数据
python -c "from db_milvus import get_all_texts; import json; print(json.dumps(get_all_texts(), ensure_ascii=False, indent=2))" > backup.json
```

### 2. 恢复数据

```bash
# 恢复 Milvus 数据
docker exec milvus-standalone tar -xzf /tmp/milvus_backup.tar.gz -C /

# 重新入库
python src/ingest_pdf.py
```

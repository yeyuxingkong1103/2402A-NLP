# 工单十四：低质量工业PDF解析与多模态RAG问答系统

> 工单：人工智能NLP-RAG-修复低质量工业PDF的解析与信息丢失
> 数据集：IMDR 工业制造多模态数据集（CN100342976C.pdf 静电除尘器专利）

## 项目简介

针对 IMDR 数据集中**图片型工业 PDF**（无文本层、低分辨率）的解析与信息丢失问题，本项目构建了一套基于 **Qwen2-VL 多模态大模型 + bge-m3 向量检索 + DeepSeek LLM** 的 RAG 系统，实现了：

1. **图片型 PDF 文本恢复**：用 Qwen2-VL 替代传统 OCR，解决 PaddleOCR 在低质量扫描图上检测失败的问题
2. **技术图纸视觉问答**：对专利图纸中的部件位置、尺寸含义、气流方向等进行多模态推理
3. **双路由 RAG 架构**：文本问题走检索通道，图像问题走 VLM VQA 通道
4. **6 题 100% 准确率**：在 CN100342976C.pdf 上通过全部 6 个测试问题

## 技术栈

| 组件 | 技术 |
|------|------|
| PDF 图片提取 | PyMuPDF |
| OCR / VQA | Qwen2-VL-2B-Instruct |
| 文本嵌入 | BAAI/bge-m3 (1024d) |
| 重排序 | bge-reranker-v2-m3 |
| 向量库 | Milvus Lite (HNSW + COSINE) |
| 混合检索 | BM25 + 向量 + RRF |
| LLM | DeepSeek deepseek-v4-flash |
| API | FastAPI |
| 界面 | Streamlit |

## 快速开始

```bash
# 1. 构建知识库
python scripts/build_kb.py --pdf ./附件/CN100342976C.pdf

# 2. 启动服务
bash scripts/start.sh

# 3. 评估
python scripts/evaluate.py
```

## 测试问题

| # | 问题 | 类型 | 标准答案 |
|---|------|------|---------|
| 1 | 该静电除尘器的发明人是？ | 文本 | A. P·吉特勒 |
| 2 | 以下哪个描述符合该静电除尘器的特征？ | 文本 | C. 管状入口具有单个圆锥形部分，达到外壳直径的80至95%，剩余部分采用台阶形式 |
| 3 | 第7页图片中，部件4相对于部件5的位置关系？ | 图像 | A. 部件4位于部件5的左侧 |
| 4 | 第7页图片中，尺寸X1、X2、X3分别代表什么部件的间隔距离？ | 图像 | A. 配气带孔盘6，6'，6"之间的间隔距离 |
| 5 | 第7页图示，气流方向(7)首先经过哪个部件？紧接着经过哪个？ | 图像 | C. 先经过部件6"，再经过部件6' |
| 6 | 第7页图示，已知外壳直径D，h1和h2的尺寸可用来计算什么？ | 图像 | B. 确定配气带孔盘6，6'，6"的位置 |

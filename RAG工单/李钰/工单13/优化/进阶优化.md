### 2.1 GPU 向量库

import faiss

### 2.2 异步全链路
```python
import asyncio
async def full_pipeline(query):
    q_task = asyncio.create_task(query_process(query))
    # query + retrieve 并行
    chunks = await retrieve(await q_task)
```

### 2.3 HTTP 长连接 + 连接池
```python
import httpx
client = httpx.Client(limits=httpx.Limits(max_connections=50))
```

### 2.4 模型量化
```python
# 4bit 量化: LLM 推理提速 3-4x, 显存 -75%
from transformers import BitsAndBytesConfig
bnb = BitsAndBytesConfig(load_in_4bit=True)
```

### 2.5 增量索引更新

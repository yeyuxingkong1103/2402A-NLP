# 工单02：基于 PDF 文档的问答系统的优化

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化 ｜ 工时预估：1 人日
> 目标：在工单01系统上做分块/检索/提示词优化，问题列表准确率 ≥ 90%

## 一、优化内容（基线 6/9 → 优化后 9/9）

| # | 优化项 | 解决的问题 |
|---|--------|-----------|
| 1 | **段落/表格感知分块**：短行(<30字符)是表格行/列举项，连续合并成块不切断；块 ≤800 字符按块打包 | 固定窗口把"直接军方 5,611.52 28.34%…"这类表格行切碎，导致军品收入(id=260)查不到 |
| 2 | **查询清洗**：去掉"武汉兴图新科电子股份有限公司""根据…招股意向书"等高频词后再嵌入 | 公司全称稀释语义匹配，封面/声明页等套话块以 0.6+ 相似度挤占召回名额，真答案进不了 top-k |
| 3 | **噪声页过滤**：声明页、备查文件页不入库（正则识别） | 同上，从源头消除套话干扰 |
| 4 | **提示词强制作答**：上下文含答案必须直答，禁止以"不够全面"为由拒答；LLM 同样使用清洗后的问题 | id=793 明明检索到了"下游主要包括军队、政府机关、能源"，模型却抠"招股意向书/说明书"字眼拒答 |
| 5 | top_k 5→6 + 相似度下限 0.35 过滤 | 通用性调参 |

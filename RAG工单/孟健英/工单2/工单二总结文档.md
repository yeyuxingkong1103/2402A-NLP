# 人工智能 NLP-RAG-基于 PDF 文档的问答系统优化

工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统优化

## 一、优化方案

本工单在工单一（基础 RAG 问答系统）的基础上，从 PDF 解析、文本分块、检索策略、Query 理解四个层面进行优化，目标是将问答准确率提升至 90% 以上，同时保持响应时间 ≤ 3 秒。

### 1.1 PDF 解析优化

| 项 | 优化前 | 优化后 |
|---|---|---|
| 解析方式 | `page.get_text()` 纯文本 | `page.get_text("blocks")` 保留段落结构 |
| 页眉页脚 | 混入正文 | 基于重复行统计自动过滤 |
| 结构保留 | 差 | 好 |

优化点：
- 使用 `blocks` 模式提取，保留段落边界；
- 统计全文档高频短行，识别并删除页眉页脚；
- 保留页码元数据，便于答案溯源。

### 1.2 分块优化

| 项 | 优化前 | 优化后 |
|---|---|---|
| chunk_size | 800 | 550 |
| overlap | 100 | 80 |
| 片段数 | 1003 | 1270 |
| 分隔符 | 通用 | 优先按“第X章/第X节”切分 |

优化点：
- 缩小 chunk_size，提升检索粒度；
- 优先在章节标题处切分，减少语义断裂；
- 保留页码元数据，支持引用。

### 1.3 检索优化

| 项 | 优化前 | 优化后 |
|---|---|---|
| 检索方式 | 纯向量检索 | 向量 + BM25 混合检索 |
| 召回数量 | Top-10 | Top-15 |
| 重排 | bge-reranker Top-4 | bge-reranker Top-6 |
| 去重 | 无 | 按内容去重 |

优化点：
- 引入 BM25 关键词检索，弥补向量对数字、专有名词的召回不足；
- 合并向量与 BM25 结果，去重后再重排；
- 重排 Top-6，保证关键信息不丢。

### 1.4 Query 理解优化

优化前：无显式 Query 理解。

优化后：
- 意图识别：数值查询 / 实体查询 / 列表查询 / 事实查询；
- 查询扩展：
  - “军用领域” → “直接军方、间接军方、军用收入”；
  - “收入” → “营业收入、主营业务收入”；
  - “上游” → “上游行业、供应商”；
  - “下游” → “下游行业、客户”。

### 1.5 容错与多语言

- 空输入校验，提示用户输入；
- 检索异常捕获，前端友好提示；
- 支持中文 / 英文问答切换。

## 二、优化前后对比

### 2.1 配置对比

| 维度 | 优化前 v1 | 优化后 v2 |
|---|---|---|
| chunk_size | 800 | 550 |
| overlap | 100 | 80 |

| 页眉页脚 | 未处理 | 已过滤 |

| 重排 | Top-4 | Top-6 |

| 版本 | 正确题数 | 准确率 |

|---|---|
| 优化前 v1 | 约 2~3 秒 |
| 优化后 v2 | 约 1.6 秒 |

满足工单 ≤ 3 秒要求。

## 四、结论

1. 通过 PDF 解析优化、分块优化、混合检索、Query 理解四层优化，问答准确率从 80% 提升至 100%（10/10）。
2. 响应时间平均约 1.6 秒，满足 ≤ 3 秒要求。
3. 系统支持中英文问答、容错提示，稳定性提升。
4. 对比纯 LLM，RAG v2 在 4 道题上纠正了纯 LLM 的事实错误，验证了 RAG 在专业文档问答中的价值。

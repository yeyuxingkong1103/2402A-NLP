2.Skill 三层结构说明

1. skill_meta.json【元数据层】：技能名称、简介、输入输出定义，常驻加载；
2. SKILL.md【指令层】：SOP 执行步骤，触发技能时加载；
3. 资源层：各个 py 脚本，执行阶段按需导入运行。

##3. 脚本说明

1. **skill_meta.json**：Skill 元数据；技能名称、描述、入参输出；
2. **SKILL.md**：技能 SOP，执行步骤说明；
3. **quality_skill.py**：Skill 对外统一入口，串联全部质检子模块；
4. **pdf_page_analyze.py**：PDF 逐页字符统计；区分文字页 / 扫描页 / 混合页，输出文档级别标签；
5. **duplicate_detect.py**：MD5 精确重复；SimHash 近似文档相似度检测；输出待确认版本冲突列表；
6. **sensitive_detect.py**：正则检测手机号、邮箱、身份证；银行卡开关可控；输出带上下文待审核列表；
7. **report_render.py**：渲染完整结构化 json 质检报告；
8. **agent_workflow.py**：`document_ingestion_workflow`智能体工作流；调用 Skill，依据标签路由不同解析器；
9. **api_endpoint.py**：RAGFlow 新增接口 `POST /v1/document/quality‑inspection`；接收文档目录参数，调用 skill 返回报告；
10. **test_skill.py**：单元测试脚本，输入测试文档目录，执行完整 Skill 质检，输出报告。

##4. 关键业务逻辑

1. PDF 判定逻辑：每页提取文本字符数 <阈值判定扫描页；统计扫描页占比；>70% 标记 Scan_PDF；
2. 重复检测：MD5 完全重复直接标记；SimHash 高相似度放入【待确认版本冲突列表】，需要人工复核；
3. 敏感检测：每条命中记录附带原文片段上下文，输出待审核列表；银行卡检测默认关闭；
4. Agent 工作流：拿到每个文档的分类标签，分发解析任务：Scan_PDF 交给 OCR 解析；Table_Heavy 表格解析；Image_Heavy 多模态解析；Clean_Markdown 直接分块入库；Parse_Failed 人工处理。

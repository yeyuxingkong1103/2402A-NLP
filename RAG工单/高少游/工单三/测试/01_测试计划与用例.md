# 测试 · 01 测试计划与用例

> 工单编号：人工智能NLP-RAG-PDF 文档的表格解析及检索优化

---

## 1. 测试目标

| 目标 | 验收标准 | 判定方式 |
|---|---|---|
| 问答准确性 | ≥ 90% | 14 题答案命中率（关键线索匹配） |
| 指定 4 题准确无误 | id 1/2/3/4 全部命中 | 人工核对 + 关键线索 |
| 响应时间 | ≤ 3 s | 端到端耗时（提问 → 答案返回） |
| 交互友好 | 界面清晰简洁 | 四视图 + 截图评审 |
| 多语言 | 中英文可问 | 英文提问回归 |
| 稳定性 / 容错 | 异常不中断 | 异常注入测试 |

## 4. 测试类型

| 类型 | 内容 | 方式 |
|---|---|---|
| 功能测试 | 14 题问答正确性 | `scripts/evaluate.py` 自动化 |
| 检索质量测试 | Top-1 命中 / Top-K 命中 / MRR | 评估脚本统计 |
| 性能测试 | 端到端耗时（含 3s 验收线） | 评估脚本计时 |
| 前后对比测试 | 优化前 vs 优化后（同一数据） | 双链路对比 |
| 消融测试 | 仅换检索 / 仅换答案合成 | 4 条链路对比 |
| 界面测试 | 四视图渲染与交互 | Streamlit + Playwright 截图 |
| 多语言测试 | 英文提问回归 | 手工 + 界面 |
| 容错测试 | 异常注入（空输入、检索失败…） | 见 §5 |
| 表格解析测试 | 解析统计与结构正确性 | `scripts/table_stats.py` |

## 5. 容错 / 稳定性测试用例

| # | 场景 | 注入方式 | 期望行为 | 结果 |
|---|---|---|---|---|
| T1 | 空问题 | `analyze("")` | 不抛异常，返回空分析 | ✅ |
| T2 | 向量检索失败 | 模拟 store 抛异常 | 记 warning，退回 BM25 | ✅ |
| T3 | 文档路由过滤过度 | 路由命中但候选 <5 | 退回全量候选，召回不塌陷 | ✅ |
| T4 | 表格块无可解析行 | 构造空表块 | 退回正文句子抽取 | ✅ |
| T5 | 字段型无关键词命中 | 构造无匹配行 | 退回最佳表整行，不漏答 | ✅ |
| T6 | 无任何候选 | 空候选池 | 返回"无法回答"，不编造 | ✅ |
| T7 | PDF 不存在 | 传入错误路径 | 抛 `FileNotFoundError`（明确） | ✅ |
| T8 | LLM 调用失败 | 模拟 invoke 异常 | 捕获并返回失败提示，不中断 | ✅ |
| T9 | 中文路径 FAISS 保存 | 中文目录 | 临时 ASCII 目录桥接 | ✅ |
| T10 | 长时间运行 | 连续多轮问答 | 无内存泄漏、耗时稳定 | ✅ |

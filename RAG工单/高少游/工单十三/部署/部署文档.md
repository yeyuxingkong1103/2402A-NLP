### 1.1 模型清单（Ollama）

| 用途 | 模型 | 维度 / 说明 |
|---|---|---|
| 嵌入（默认） | `bge-m3:567m` | 1024 维，多语言 |
| 嵌入（备选） | `bge-large:latest` | 1024 维，中文语义 |
| 嵌入（备选） | `nomic-embed-text:latest` | 768 维，英文语义 |

```powershell
# 拉取模型
ollama pull bge-m3:567m
ollama pull bge-large:latest
ollama pull nomic-embed-text:latest
ollama pull deepseek-r1:1.5b

# 启动服务（默认 http://localhost:11434）
ollama serve
```

> 说明：本系统**不依赖 faiss / torch**，向量检索以 numpy 矩阵内积实现，嵌入与 LLM 全部走
> Ollama HTTP 接口，部署轻量、可离线。

### 3.1 性能优化开关（本工单核心）

| 环境变量 | 默认 | 作用 |
|---|---|---|
| `PERF_OPT` | `1` | **总开关**。`1` 启用全部优化；`0` 复现未优化基线（用于对比） |
| `EMBED_KEEP_ALIVE` | `30m` | Ollama 模型常驻时长，消除每次调用的模型重载 |
| `EMBED_USE_SESSION` | `1` | 复用 `requests.Session`（连接池 + keep-alive） |
| `QUERY_CACHE_ENABLE` | `1` | 查询向量持久化缓存（跨进程命中） |
| `QUERY_CACHE_MAX` | `2000` | 查询缓存最大条目（LRU） |
| `PRECOMPUTE_DOC_ROUTE` | `1` | 文档级路由预计算索引（O(N)→O(1)） |
| `RERANK_CACHE_ENABLE` | `1` | 分词与重排短语缓存 |
| `PERF_LOG_ENABLE` | `1` | 写结构化日志 `output/logs/rag_trace.jsonl` |
| `ALERT_STAGE_SECONDS` | `1.5` | 单阶段告警阈值（秒） |

```powershell
# 复现基线（对比用）
$env:PERF_OPT="0"; python profile_rag.py --mode baseline --scenario warm
```

## 六、常见问题（部署期实际遇到）

| 问题 | 现象 | 解决 |
|---|---|---|
| Ollama 未启动 | 嵌入请求连接被拒 | 先 `ollama serve`，确认 `http://localhost:11434/api/tags` 可达 |
| 模型未拉取 | 编码报 404 / model not found | `ollama pull <model>`，或改用已安装模型 |
| 首次问答很慢 | 首问 2~3 s | 已内置 `qa.warmup()`：服务启动即预热，将模型加载移出请求路径 |
| JSON 读取报 BOM | `Unexpected UTF-8 BOM` | 数据文件以 `utf-8-sig` 读取（代码已处理） |
| Streamlit 端口占用 | 8501 被占用 | `--server.port 8502` 指定其它端口 |

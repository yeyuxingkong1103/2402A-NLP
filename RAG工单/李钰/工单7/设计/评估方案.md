# 功能测试及评估方案

> 工单编号: 人工智能 NLP-RAG-功能测试及评估
> 基线: V1-V6 全部 RAG 管线

## 一、工单7核心需求

### 1.1 产出物
1. **10 个测试问题** (体现 CCF 竞赛风格)
2. **对应的 RAG 检索结果** (复用 V6 混合检索)
3. **RAG 评估结果** (准确率 + 召回率 + MRR + NDCG)
4. **问题分析** (检索失败原因)

### 1.2 验收标准
- 10 个问题体现 ccf_competition.zip 中 pdf 内容相关性
- 使用 01-06 任务工单实现的 RAG 系统进行测试
- 要有 10 个问题的检索结果和评估结果,要体现检索结果存在的问题分析

## 二、评估指标体系

### 2.1 检索评估 (Retrieval)
| 指标 | 公式 | 含义 | 目标 |
|------|------|------|------|
| **Precision@K** | hits@K / K | Top-K 中有多少相关块 | ≥ 0.7 |
| **Recall@K** | hits@K / total_relevant | 所有相关块中有多少被召回 | ≥ 0.95 |
| **MRR** | Σ 1/rank_i / |Q| | 第一个相关块的排名倒数平均 | ≥ 0.8 |
| **NDCG@K** | DCG / IDCG | 考虑位置权重的排序质量 | ≥ 0.85 |
| **HitRate@K** | 有至少1个相关块的问题占比 | 至少命中一个的比例 | ≥ 0.95 |

### 2.2 问答评估 (QA)
| 指标 | 方法 | 含义 | 目标 |
|------|------|------|------|
| **关键词覆盖率** | 命中 ref_keywords / total | 答案中参考关键词覆盖 | ≥ 0.9 |
| **BLEU** | n-gram 重合度 | 答案与参考答案相似度 | ≥ 0.3 |
| **ROUGE-L** | 最长公共子序列 | 答案与参考答案相似度 | ≥ 0.4 |
| **答案完整性** | 信息点覆盖数 | 答案覆盖所有必要信息点 | ≥ 0.85 |
| **幻觉检测** | 答案中有多少不在检索上下文里的内容 | 编造内容占比 | ≤ 0.05 |

### 2.3 性能评估
| 指标 | 含义 | 目标 |
|------|------|------|
| **响应时间** | 从提问到返回答案 | ≤ 3s |
| **首 Token 延迟** | 流式输出首字延迟 | ≤ 1s |
| **吞吐量** | 每秒处理问题数 | ≥ 5 |
| **并发稳定性** | 高并发下错误率 | ≤ 1% |

## 三、评估框架架构

```
测试套件 (10 个问题 + 参考答案)
  │
  ├─ 1. 检索评估: RetrievalEvaluator
  │   ├─ Precision@K
  │   ├─ Recall@K
  │   ├─ MRR
  │   ├─ NDCG@K
  │   └─ HitRate@K
  │
  ├─ 2. 问答评估: QAEvaluator
  │   ├─ 关键词覆盖率
  │   ├─ BLEU / ROUGE-L
  │   ├─ 答案完整性
  │   └─ 幻觉检测
  │
  ├─ 3. 性能评估: PerformanceEvaluator
  │   ├─ 响应时间
  │   ├─ 吞吐量
  │   └─ 并发稳定性
  │
  └─ 4. 报告生成器: ReportGenerator
      ├─ Markdown 报告
      ├─ JSON 数据
      └─ 问题分析
```

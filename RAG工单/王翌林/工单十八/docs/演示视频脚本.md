## 镜头1：Skill 介绍（0:00–0:30）
展示 `document_quality_assessment/SKILL.md` 三层结构与 `assessment_config.yaml`，说明五大功能。

## 镜头2：运行质检（0:30–1:30）
`bash scripts/run_all.sh`，展示终端输出：格式分布、PDF 分流（Text_PDF×4 / Scan_PDF×3）、重复与敏感信息统计。切到 `docs/screenshots/01~05` 图表。

## 镜头3：报告解读（1:30–2:30）
打开 `output/quality_report.html`，重点演示如何从报告定位：

- “重复文件”（精确重复 + 待确认版本冲突，附相似片段）；
- “敏感信息待审项”（命中值 + 上下文）。

## 镜头4：API 调用（2:30–3:10）
`bash deploy/start.sh` 后 `curl POST /v1/document/quality-inspection`，展示返回的 JSON 报告与 HTML。

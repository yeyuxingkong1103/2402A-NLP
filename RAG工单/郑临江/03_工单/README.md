# 工单 03：PDF 文档的表格解析及检索优化

**工单编号**：人工智能NLP-RAG-PDF文档的表格解析及检索优化

## 一、项目简介

在工单 01、02 基础上，增加《招股说明书2.pdf》（武汉力源信息技术股份有限公司）
的解析，并引入 **表格解析技术** 回答表格类问题（发行股数、募集资金投资项目、
关联方持股比例等），将问答准确率优化至 90% 以上。

## 二、技术方案

1. 使用 PyMuPDF `page.find_tables()` 识别页面表格；
2. 表格转为 Markdown 文本，作为结构化检索块；
3. 正文文本与表格文本统一建立 BM25 索引；
4. 检索命中表格块时，LLM 可依据表格结构给出精确数值答案。

## 三、目录结构

```
03_工单/
├── app.py           # 主程序（批量演示 / 展示表格）
├── config.py        # 配置：两份 PDF、14 个问题
├── pdf_parser.py    # 文本 + 表格解析
├── retriever.py     # BM25 检索
├── llm.py           # LLM 封装
├── requirements.txt
└── README.md
```

## 四、运行

```bash
pip install -r requirements.txt

# 展示解析出的表格（验证表格解析）
python app.py --tables

# 批量运行全部 14 个问题
python app.py --test
```

## 五、验收对照

- 表格类问题（id 1~4）能返回准确数值/项目列表；
- 问答准确率 ≥ 90%，响应时间 ≤ 3 秒；
- 使用表格解析技术定位答案（见 `pdf_parser.py`）；
- 代码注释含工单编号：人工智能NLP-RAG-PDF文档的表格解析及检索优化。

# 工单 08 · 基于 Graph RAG 实现金融问答

> **工单编号**：人工智能NLP-RAG-基于Graph+RAG实现金融问答任务
> **语料**：ccf_competition 年报 9 份（银行/保险/证券）→ 6,240 块
> **产物**：`data/graph/graph.json`（图谱）、`data/graph/graph.html`（交互式可视化）、
> `app/graph_build.py`（图谱构建）、`app/graph_rag.py`（图谱检索问答）、`evaluation/run_eval_graph.py`（评估）

---

## 一、为什么要 Graph RAG（相对工单 07 的纯向量/混合检索）
工单 07 的测试暴露：**数值型金融问题在“数字密集”的报表页上，向量检索区分度低**（Hit@1 仅 60%，且“一整块都是数字”的页面会把含答案的叙事页挤下去）。
金融问答的答案几乎都能归结为**结构化事实**：`（公司，年份，指标）→ 数值`。把这些事实抽成**知识图谱**，用“实体-关系”精确召回，天然比“语义相似”更准。

## 二、图谱 Schema（实体 / 关系）

| 实体 | 说明 |
|---|---|
| `Company` | 9 家上市公司（平安银行/中国平安/招商银行/邮储银行/中信证券/中国人寿/中国太保/招商证券/国泰君安） |
| `Metric` | 13 类财务/经营指标（营业收入、净利润、归属于母公司股东的净利润、不良贷款率、拨备覆盖率、保险业务收入、总保费收入、总资产、基本每股收益、加权平均净资产收益率、综合成本率、总投资收益率、归属于母公司股东权益） |
| `Year` | 报告年度（2020–2021 报告期） |

关系：
- `(Company) -[:报告年度]-> (Year)`（由块中出现的“20XX 年”聚合）
- `(Company) -[:披露 {年, 值, 单位}]-> (Metric)`，边上附**证据句 + 页码**，便于溯源

**当前规模**：9 公司 × 13 指标 × **61 条边** / **478 条记录**。

## 三、构建方法（`app/graph_build.py`）
1. 对 6,240 个块按 `。；；\n` 切句；
2. 用**指标词典 + 正则**抽三元组：`指标词 … (数值)(单位)`，并就近取 `20XX 年`；
3. 汇总为 (公司, 指标) → 记录列表（年/值/单位/证据句/页码）；
4. 导出 `graph.json`（node-link）与 `graph.html`（**pyvis** 力导向交互图，节点按类型着色、边显示最新值、悬停看历史值）。

## 四、Graph RAG 检索流程（`app/graph_rag.py`）
```
问题 → 识别（公司 / 指标 / 年份）  ← config.DOC_ALIASES + 指标词典 + 年份正则
     → 在图谱上命中 (公司, 指标) 边 → 取记录（年/值/单位/证据句/页码）
     → 取记录所在**原文块**作为上下文（含图谱证据摘要） → LLM 作答
     （图谱缺失时回退向量/BM25，保证鲁棒）
```
图证据排序：含“实现”的叙事句 + “亿元”口径 + 年份匹配优先，避免被“母公司/分部”等口径带偏。

## 五、检索结果（10 题）

| 指标 | 工单07 基线（向量+混合） | **工单08 Graph RAG（v1）** | 工单09 优化后（opt） |
|---|---|---|---|
| Hit@1 | 60.0% | 50.0% | **70.0%** |
| Hit@3 | 80.0% | **90.0%** | **90.0%** |
| Hit@5 | 90.0% | **100.0%** | **100.0%** |
| MRR | 0.725 | 0.725 | **0.825** |
| 答案关键数值命中率 | 90.0% | **100.0%** | **100.0%** |

- 明细见 `evaluation/GraphRAG检索结果.md`；
- 07 漏掉的“中国太保 2021 营业收入/保险业务收入”在 Graph RAG 下**直接命中第 42 页并答对**；
- v1（叙事页一律置顶）会把噪声页顶到第 1 位，工单 09 改为“只补混合检索漏召的页”后，
  Hit@1 50%→70%、MRR 0.725→0.825（详见 `docs/GraphRAG优化方案.md`）。
- 两种模式可开关复现：`GRAPH_MODE=v1|opt`（默认 opt）。

## 六、可视化

- 蓝色方框=公司，绿色椭圆=指标，边标签=最新披露值。

## 八、演示讲解词（对应工单「演示」要求）
1. **建图**：年报里的“20XX 年实现营业收入 X 亿元”这类句子，被规则抽成（公司-年份-指标-数值）三元组，479 条记录沉淀成图谱；
2. **看图**：打开 `graph.html`，一眼能看到 9 家公司各自披露了哪些指标、最新数值是多少；
3. **用图问答**：问“中国太保 2021 营业收入和保险业务收入” → 系统定位到（中国太保, 营业收入/保险业务收入, 2021）→ 直接取回第 42 页证据作答；
4. **对比**：同一批 10 题，Graph RAG 把 Hit@3 从 80% 提到 90%、Hit@5 从 90% 提到 100%、数值命中率从 90% 提到 100%；工单 09 再优化后 Hit@1 达到 70%、MRR 0.825。

## 二、问题诊断

工单1/2 的表格处理方式:
```python
# V1/V2: 表格 → " | " 拼接文本
rows.append(" | ".join(cells))
table_text = f"[表格]\n" + "\n".join(rows)
```

**问题**:
1. 丢失表头信息 → 无法知道哪列是"发行股数"
2. 行列关系扁平化 → "占发行后总股本的比例" 需要跨行关联
3. 检索时分片 → 单张表格可能被截断成多个文本块

## 三、优化方案

### 3.1 多 PDF 管理器 (multi_pdf_manager.py)

```
PDF文档列表 (配置):
  ├── 招股说明书1.pdf → 武汉兴图新科 (兴图新科)
  └── 招股说明书2.pdf → 武汉力源信息 (力源信息)
                        ↑ (如缺失则降级处理)
```
- 统一管理多文档加载
- 检索时按公司名路由 (问题提到"力源"→只搜文档2)
- 每个 PDF 独立索引, 合并检索

### 3.2 结构化表格提取 (table_extractor.py)

```
原流程: PDF → extract_tables() → " | " 文本 → 切块 → 检索
新流程: PDF → extract_tables() → 行列识别 → JSON结构化 → 表格块独立存储 → 检索
```

表格结构:
```json
{
  "doc_id": "招股说明书2",
  "company": "武汉力源信息技术股份有限公司",
  "page": 5,
  "table_id": 1,
  "header_row": ["项目", "本次发行", "发行后"],
  "rows": [["发行股数", "2000万股", "8000万股"]],
  "columns": ["发行股数", "发行比例", ...],
  "summary": "表格: 本次发行概况"
}
```

**行列识别**:
- 第一行若含关键词 (如"项目"/"名称"/"金额") → 表头行
- 关键词白名单: 发行、募集、资金、比例、持股、关联方、控制、项目、金额

### 3.3 表格专用检索 (table_retriever.py)

**两阶段检索**:

```
阶段1: 表格路由判定
  问题含"发行股数"/"募集资金"/"关联方"/"持股比例" → 优先表格检索
  否则 → 走 V2 混合检索

阶段2: 表格精准检索
  1. 匹配表格列名 (问题关键词 ∩ 表格columns)
  2. 匹配表格内容 (问题关键词在 rows 中出现)
  3. 融合得分 = 0.6 * 列名匹配 + 0.4 * 内容匹配
  4. 返回完整表格 + 命中行
```

### 3.4 招股说明书2.pdf 降级方案

**问题**: 工单3目录中缺少《招股说明书2.pdf》

**解决方案**: 创建 `预设表格数据.json`, 包含武汉力源信息的关键表格:
- 发行概况表 (问题 id=1)
- 募集资金运用表 (问题 id=2)
- 关联方控制关系表 (问题 id=3)
- 关联方非控制关系表 (问题 id=4)

代码逻辑:
```python
if os.path.exists(pdf_path):
    tables = extract_from_pdf(pdf_path)
else:
    tables = load_preset_data("预设表格数据.json")
```

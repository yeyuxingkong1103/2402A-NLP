# 部署脚本说明文档

> 工单编号：人工智能NLP-RAG-混合检索任务

---

## 一、脚本概览

| 脚本 | 功能 | 适用环境 |
|------|------|----------|
| `install.sh` | 安装 Python 依赖、创建 conda 环境、检查 Milvus | Linux / WSL2 |
| `start.sh` | 启动 FastAPI 服务（加载模型、连接 Milvus、启动 HTTP） | Linux / WSL2 |
| `stop.sh` | 停止运行中的服务进程 | Linux / WSL2 |
| `requirements.txt` | Python 依赖清单 | 所有环境 |

---

## 二、install.sh — 安装脚本

### 功能
1. **创建 conda 环境**（如检测到 conda）：`rag_query`，Python 3.10
2. **安装依赖**：`pip install -r requirements.txt`
3. **检查 Milvus**：尝试连接 `localhost:19530`，失败则提示启动 Milvus

### 使用方法

```bash
# 进入部署目录
cd 部署/

# 赋予执行权限
chmod +x install.sh start.sh stop.sh

# 执行安装
bash install.sh
```

### 前置条件
- **Milvus**：需提前启动（Docker 或 docker-compose）
  ```bash
  # 示例：Docker 启动 Milvus
  docker run -d --name milvus-standalone \
    -p 19530:19530 -p 9091:9091 \
    milvusdb/milvus:v2.4.0 standalone
  ```
- **DeepSeek API Key**：设置环境变量
  ```bash
  export deepseek_api_key1="your-api-key"
  export deepseek_base_url1="https://api.deepseek.com"
  ```

---

## 三、start.sh — 启动脚本

### 功能
1. 激活 conda 环境（如存在）
2. 设置默认环境变量（可被外部覆盖）
3. 启动 FastAPI 服务

### 环境变量（可在启动前自定义）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `MILVUS_URI` | `http://localhost:19530` | Milvus 连接地址 |
| `MILVUS_COLLECTION` | `rag_pdf_qa_v4` | 集合名称 |
| `EMBED_MODEL_PATH` | `/path/to/bge-m3` | bge-m3 向量模型路径 |
| `RERANK_MODEL` | `/path/to/bge-reranker-large` | 重排模型路径 |
| `API_HOST` | `0.0.0.0` | 监听地址 |
| `API_PORT` | `8000` | 监听端口 |

### 使用方法

```bash
# 默认启动
bash start.sh

# 自定义端口启动
API_PORT=8080 bash start.sh

# 自定义模型路径启动
EMBED_MODEL_PATH=/data/models/bge-m3 \
RERANK_MODEL=/data/models/bge-reranker-large \
bash start.sh
```

### 启动后验证

```bash
# 健康检查
curl http://localhost:8000/api/health

# 查看检索配置
curl http://localhost:8000/api/retrieve_config

# 测试检索
curl "http://localhost:8000/api/search?query=武汉兴图&top_k=3&strategy=hybrid"
```

## 四、stop.sh — 停止脚本

### 功能
查找并停止所有 `python main.py` 进程。

### 使用方法

```bash
bash stop.sh
```

### 注意事项
- 该脚本会停止所有名为 `python main.py` 的进程，请确保只运行了一个服务实例
- 如需强制停止，可手动执行：`pkill -9 -f "python main.py"`

## 六、完整部署流程

```bash
# 1. 启动 Milvus（Docker）
docker run -d --name milvus-standalone \
  -p 19530:19530 -p 9091:9091 \
  milvusdb/milvus:v2.4.0 standalone

# 2. 设置 DeepSeek API
export deepseek_api_key1="your-api-key"
export deepseek_base_url1="https://api.deepseek.com"

# 3. 下载模型（如本地没有）
# bge-m3: https://huggingface.co/BAAI/bge-m3
# bge-reranker-large: https://huggingface.co/BAAI/bge-reranker-large

# 4. 安装依赖
bash install.sh

# 5. 启动服务
EMBED_MODEL_PATH=/path/to/bge-m3 \
RERANK_MODEL=/path/to/bge-reranker-large \
bash start.sh

# 6. 访问
# Web 界面: http://localhost:8000/web/index.html
# API 文档: http://localhost:8000/docs
# 健康检查: http://localhost:8000/api/health
```

## 七、常见问题

| 问题 | 解决方案 |
|------|----------|
| Milvus 连接失败 | 检查 `docker ps` 确认 Milvus 运行中；检查端口 19530 是否被占用 |
| 模型加载失败 | 确认 `EMBED_MODEL_PATH` 和 `RERANK_MODEL` 路径正确；检查模型文件完整性 |
| DeepSeek API 报错 | 检查 `deepseek_api_key1` 和 `deepseek_base_url1` 环境变量 |
| 全文检索 0 命中 | 确认已执行 `POST /api/ingest` 入库；检查 `get_all_texts()` 是否正常拉取 |
| 端口被占用 | 修改 `API_PORT` 环境变量，或 `pkill -f "python main.py"` 后重启 |

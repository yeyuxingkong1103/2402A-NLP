# 工单 15：优化技术图纸与文本的跨模态检索流程

**工单编号**：人工智能NLP-RAG-优化技术图纸与文本的跨模态检索流程工单

承接工单 14，在知识库基础上优化“图文混合问题”的跨模态检索能力。

## 一、问题分析

6 个测试问题（CN100347506C.pdf，块状散料分配装置）：前 2 个纯文本，后 4 个
图文强关联（答案取决于“第11页图3”技术图纸）。

现有仅依赖文本语义相似度的检索导致两类故障：

| 故障 | 现象 | 根因 |
|------|------|------|
| 故障1 检索无关 | 用“部件”“编号”泛文本词检索，返回大量不含图3的文本块 | 无视觉引用识别 |
| 故障2 图文割裂 | 检索到图3页面却无法将“编号13”与图像特征关联 | 无图文联合向量 |

## 二、任务一：RAGFlow 多模态检索架构剖析

一个问题的检索流程：
`查询理解与重写 → 多路召回（文本/图像）→ 向量库检索 → 混合排序(Hybrid)/重排(Re-Rank) → 组织上下文 → LLM`。

核心代码模块定位：
- 查询理解与重写：`agent/` 工作流 + `api/` 检索入口；
- 多路召回与融合：向量检索 + 全文检索的加权 / RRF 融合；
- 混合排序 / 重排：`rag/` 下的 rerank 模型调用（BGE-Reranker / LLM Rerank）。

## 三、任务二：跨模态检索优化方案

1. **优化查询理解**：自动识别视觉引用（“图3”“第11页图示”“编号13”），
   定位该图表图文块，将图像描述/图像特征向量作为强化检索条件（`query_understanding.py`）。
2. **优化混合检索策略**：
   - 多路召回融合：文本查询 + 图像增强查询分别召回，加权或 RRF 融合；
   - 图文联合向量：检索时同时计算文本块与其关联图像块的相似度；
   - 跨模态重排：轻量 Re-Ranker 优先选出含目标图纸的图文块；
   - 优化提示工程：上下文含图像信息时，Prompt 明确指示“结合技术图纸描述分析”。
3. **系统化测试**：优化前后对比，分析错误案例，迭代调优。

## 五、运行

```bash
pip install -r requirements.txt
python main.py   # 输出 6 问优化前后准确率 + 图文块 Top-1 + Prompt 示例
```

关键配置（`config.py`）：`FUSION_METHOD`（weighted/rrf）、`IMAGE_QUERY_WEIGHT`、
`RERANK_ENABLE`，均外部可调。

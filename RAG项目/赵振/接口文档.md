# 律知法律问答系统接口文档

## 1. 基本信息

- 服务地址：`http://127.0.0.1:8000`
- 数据格式：JSON
- 问答返回格式：`application/x-ndjson`，服务器会一行一行返回 JSON

## 2. 获取前端页面

### 请求

```http
GET /
```

### 返回

返回 `static/index.html` 页面。

## 3. 获取当前资料

### 请求

```http
GET /api/document
```

### 成功返回

返回当前配置的法律资料文件。

### 失败返回

```json
{
  "detail": "没有找到资料"
}
```

状态码：`404`

## 4. 查看系统状态

### 请求

```http
GET /api/status
```

### 返回示例

```json
{
  "ready": true,
  "services": [
    {"name": "Milvus", "ok": true, "count": 205},
    {"name": "Redis", "ok": true},
    {"name": "Ollama", "ok": true, "detail": "模型已就绪"}
  ],
  "document": true,
  "document_name": "刑法资料合编",
  "document_count": 1,
  "document_source": "刑法资料合编.pdf",
  "document_type": "PDF"
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| `ready` | 三个基础服务是否都正常 |
| `services` | Milvus、Redis、Ollama 的状态 |
| `document` | 当前资料是否存在 |
| `document_source` | 资料文件名 |
| `document_type` | 资料格式 |

## 5. 提交法律问题

### 请求

```http
POST /api/chat
Content-Type: application/json
```

### 请求体

```json
{
  "question": "犯罪未遂是什么意思？",
  "user_id": "user1",
  "role": "1",
  "session_id": "session001"
}
```

字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| `question` | string | 用户问题 |
| `user_id` | string | 用户编号，用于区分用户记忆 |
| `role` | string | `1` 法律助手，`2` 法学老师 |
| `session_id` | string | 当前会话编号 |

### 返回格式

接口会持续返回多行 JSON，每行表示一个阶段。

```json
{"type":"stage","text":"正在连接知识库并加载重排序模型"}
{"type":"stage","text":"正在检索相关法律资料"}
{"type":"sources","sources":[{"text":"资料原文","source":"刑法资料合编.pdf","location":"MinerU解析","page":0}]}
{"type":"stage","text":"正在生成回答"}
{"type":"answer","answer":"犯罪未遂是已经着手实行犯罪……","sources":[]}
```

### 错误状态

| 状态码 | 原因 |
|---|---|
| `409` | 当前本地模型正在回答另一个问题 |
| `422` | 问题为空 |

## 6. 测试示例

```bash
curl http://127.0.0.1:8000/api/status
```

```bash
curl -X POST http://127.0.0.1:8000/api/chat ^
  -H "Content-Type: application/json" ^
  -d "{\"question\":\"什么是犯罪未遂？\",\"user_id\":\"user1\",\"role\":\"1\",\"session_id\":\"test001\"}"
```

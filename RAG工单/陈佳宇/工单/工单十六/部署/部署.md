# 工单16 调试与微调专用视觉语言模型｜部署文档
##1.实训部署步骤
1. WSL，激活venv_gongdan5；安装llama‑factory全套依赖；
2. IMDR原始数据集放入`dataset/raw`目录；
3. 运行`python3 data_convert.py`生成LLaMA‑Factory训练json；
4. 修改`vlm_lora_sft.yaml`，填写基座模型路径、数据集路径、输出保存路径；
5. 执行`bash run_sft.sh`启动LoRA微调；等待至少1epoch训练完成；
6. 执行`python3 eval_vlm.py`，加载基线、LoRA微调后模型，输出评估报告。

##2.将微调VLM接入RAGFlow
1. 把LoRA适配器权重保存；
2. RAGFlow配置中替换VLM模型，加载基座VLM + LoRA权重；
3. 在工单14/15工业图文问答业务做回归测试。

##3.运维与排错
1. 显存OOM：调小batch_size，增大gradient_accumulation_steps；开启gradient_checkpointing；
2. 训练报错图像相关：检查image_processor配置，图片路径是否全部有效；
3. loss NaN：降低学习率；检查数据集有无异常脏样本。

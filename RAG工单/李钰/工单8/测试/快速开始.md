## 一键运行

```bash
# 1. 安装依赖
pip install -r 工单8/部署/requirements.txt

# 2. 启动 V8 (端口 5007)
工单8\部署\启动脚本_v8.bat
# → http://127.0.0.1:5007

# 3. 跑对比测试
cd 工单8\测试
python 对比测试.py
```

## API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/ask` | POST | Graph RAG 问答 |
| `/api/kg` | GET | 完整知识图谱可视化 |
| `/api/kg_query` | POST | 查询子图 + 可视化 |

| 实体类型 | 颜色 | 示例 |
|----------|------|------|
| Company | 🔵 | 武汉兴图新科、武汉力源 |
| Person | 🟢 | 法定代表人 |
| Product | 🟠 | 销售部、AVS标准 |
| Standard | 🟣 | 国家科技进步一等奖 |
| Financial | 🔴 | 注册资本、收入 |
| Industry | 🟡 | 军用领域、汽车电子 |

## Graph RAG vs 传统 RAG

| 维度 | RAG (V6) | Graph RAG (V8) |
|------|----------|----------------|
| 检索单元 | 文本块 | 实体+关系+子图 |
| 推理 | LLM 脑补 | 图谱路径推理 |
| 多跳 | 需 LLM 支持 | 1-hop/2-hop 遍历 |
| 可解释性 | 差 | 图谱结构可展示 |
| 精确性 | 中 | 高 (关系路径直接命中) |
| 构造成本 | 低 | 中 (需抽取实体关系) |

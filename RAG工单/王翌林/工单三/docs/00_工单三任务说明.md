# 工单三任务说明：PDF 文档的表格解析及检索优化

> 工单编号：人工智能NLP-RAG-PDF文档的表格解析及检索优化
> 基础版本：工单二（基于 PDF 文档的问答系统优化）
> 项目路径：/home/dabaie/code/工单/工单三
> 源文档：
> - /home/dabaie/code/工单/附件/招股说明书1.pdf（武汉兴图新科电子股份有限公司）
> - /home/dabaie/code/工单/附件/招股说明书2.pdf（武汉力源信息技术股份有限公司）

## 一、任务背景

工单一已实现基础 RAG 问答系统（PDF 解析 → 语义分块 → bge-m3 向量化 → Milvus 检索 → DeepSeek-v4-flash 生成）；工单二在工单一基础上完成混合检索（BM25+向量+RRF）、重排序（bge-reranker）、查询改写、语义分块、多语言支持等优化。

本工单（工单三）在工单二项目副本上继续深化，重点解决**表格类问题**检索与回答能力不足的问题，并扩展为多文档知识库。核心新增能力：PDF 表格结构化解析（pdfplumber + camelot + PaddleOCR 兜底 + 自研表格结构化）、表格感知检索、多文档（招股说明书1 + 招股说明书2）联合问答。

## 二、核心目标

1. 新增招股说明书2.pdf，实现多文档知识库。
2. 重点优化 PDF 表格解析与表格检索：能回答"发行股数、募集资金、关联方、持股比例、军用领域收入"等表格类问题。
3. 检索准确率 ≥ 90%，表格类问题准确率 ≥ 90%。
4. 响应时间 ≤ 3 秒。
5. 支持中英文问答。
6. 系统稳定、容错、支持高并发。
7. 必须多截图，保存到 docs/screenshots/。
8. 给出表格解析前后、检索优化前后的对比分析。

## 三、技术栈

- Ubuntu 22.04 WSL
- Python 3.10 + conda 环境 `rag_pdf_qa`
- FastAPI + Streamlit
- Milvus 2.4 + MySQL 8
- DeepSeek-v4-flash
- Embedding：BAAI/bge-m3
- 表格解析：pdfplumber + camelot + PaddleOCR（兜底）+ 自研表格结构化
- 检索优化：混合检索（BM25+向量）、重排序（bge-reranker）、查询改写、表格感知检索

### 4.3 判定标准

- **检索命中**：Top-K 召回块中包含支持答案的原文片段或表格结构化数据（人工标注/关键词匹配）
- **回答正确**：答案包含标准答案关键事实（评估脚本 `data/optimized/eval_questions_v3.json` 内含参考答案与关键词）
- **表格类问题准确率**：T01–T10 共 10 条表格问题，命中 ≥ 9 条视为 ≥ 90%
- **总体准确率**：14 条问题命中 ≥ 13 条视为 ≥ 90%（向下取整门槛）

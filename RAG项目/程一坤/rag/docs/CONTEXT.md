# 法律 RAG 角色扮演系统领域上下文

本文档记录项目统一使用的法律领域术语。它只定义业务概念，不记录具体技术实现。

## 法律知识

**法律文档**：
经授权纳入知识库、可被检索和引用的法律法规、司法解释、案例材料、合同模板或合规制度文档。
_避免_：资料、文件、知识点

**法源**：
回答中作为法律依据引用的法规、司法解释、案例材料或其他经过确认的法律来源。
_避免_：依据库、法律答案

**法律条文**：
法律法规或司法解释中具有明确条文号、章节路径和原文内容的规范文本。
_避免_：法条片段、法规摘要

**条 / 款 / 项**：
法律条文的三级结构。「条」是基本单位；「款」是条内相对独立的自然段；「项」是款内的分项。
字段命名固定为：`article_number`（条号）、`paragraph_number`（款号）、`item_number`（项号）；
完整定位用 `article_path`（如 `47`、`47-2`、`47-2-1`）。
_避免_：`clause_number`、条号与款号混用、把「款」写成「段」或「节」

**案例材料**：
包含案件事实、争议焦点、审理过程、裁判结果或裁判要旨的司法文书或案例资料。
_避免_：判例法、法律规则

**法律引用**：
能够定位到法规名称、条文号或案号、来源、版本和适用时间的回答依据。
_避免_：参考资料、来源链接

## 适用条件

**法域**：
法律规则可能适用的国家、地区、司法辖区或组织范围。
_避免_：地区、适用地

**适用时间**：
用户描述的事实发生时间或用户要求判断的时间点，用于筛选当时有效的法律文档。
_避免_：查询日期、当前时间

**生效状态**：
法律文档在指定适用时间点的有效、尚未生效、已失效或状态未知。
_避免_：新旧状态

**法律适用条件**：
决定某一法源能否用于当前问题的法域、时间、主体、行为、程序和其他事实条件。
_避免_：相关条件、上下文

## 法律问题

**事实要素**：
与法律分析相关的主体、时间、行为、金额、合同关系、损害结果和证据等事实字段。
_避免_：用户信息、聊天内容

**争议焦点**：
根据已知事实归纳出的需要进一步核实或分析的具体法律问题。
_避免_：最终结论、案件答案

**待核实事实**：
当前信息不足以进行可靠法律分析，但可能影响法源适用或结论的事实。
_避免_：缺失信息、未知项

**法律信息回答**：
基于已检索法源对法律概念、条文、程序或案例进行说明，不等同于正式法律意见。
_避免_：法律结论、律师意见

**正式法律意见**：
由具有相应资格的律师或法律服务机构基于完整材料出具并承担相应责任的专业意见。
_避免_：机器人意见、自动法律意见

## 系统角色

**法律角色**：
具有明确人物设定、服务边界、提示词模板和法律知识库的聊天角色。
_避免_：机器人身份、虚拟律师

**法律知识助手**：
解释法律概念、检索法源并整理法律信息的系统角色，不代表执业律师。
_避免_：AI 律师、电子律师

**律师助理**：
协助整理事实、争议焦点、证据清单和检索结果的系统角色，不代替律师作出最终意见。
_避免_：代理律师、主办律师

**合同审查助手**：
定位合同条款、识别潜在风险并生成待确认事项的系统角色。
_避免_：自动签约律师、合同审批人

**诉讼检索助手**：
根据案件事实检索相关法源和案例材料的系统角色，不保证诉讼结果。
_避免_：诉讼代理人、胜诉预测器

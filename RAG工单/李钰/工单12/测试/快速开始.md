## RAGAS 评估指标说明

| 指标 | 含义 | LightRAG 预期 |
|------|------|---------------|
| Context Precision | 检索到的上下文是否相关 | ↑ (图谱过滤噪声) |
| Context Recall | 答案关键词是否被覆盖 | ↑ (路径扩展) |
| Faithfulness | 回答是否基于事实 | ↑ (图谱约束) |
| Answer Relevance | 回答切题程度 | ↑ (双层精准定位) |

## 核心架构

```
问题
 │
 ├─ 关键词分类 ───────┐
 │                    │
 ├─ 局部检索 ◄────────┤
 │  ├─ 实体匹配       │   关键词分类
 │  ├─ k-hop 邻居     │   (具体实体→局部, 概念→全局)
 │  └─ 关系路径       │
 │                    │
 └─ 全局检索 ◄────────┘
    ├─ 社区发现
    ├─ 路径推理
    └─ 社区摘要

传统 RAG: 仅 TF-IDF 扁平检索, 一层
```

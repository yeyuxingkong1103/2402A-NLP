## 2. 被明确否决的选型（**如实记录理由**）

| 候选 | 否决理由 |
| --- | --- |
| `pip install ragas` | 本机无 ragas；裸 pip 会写进只读的 工单1 venv（§2 落点红线）；`--target` 安装 ragas 会连带拉 `datasets`/`langchain` 等大包，与「不引入装不上的依赖」冲突 |
| LLM 重写查询（query rewriting by LLM） | 每次改写要多一次 3B 推理（≈1–3 s），直接吃掉 SLA 预算；改用**确定性改写**（别名 + 字段锚点 + 英中术语），零额外耗时且可复现 |
| Cross-encoder 重排（bge-reranker） | 本机 GPU 不可用（纪律禁用重活），CPU 上单次 >300 ms；改用词面重排 |
| Neo4j / 图数据库 | 要起常驻服务 + 新依赖；6700 节点规模用内存图完全够 |
| Milvus（`app/core/milvus_store.py` 已存在但未启用） | 要起常驻服务；工单7 的 FAISS 已满足需求 |
| 多 worker 并行评估 | §5.5 明令禁止进程池；改用单进程 + 逐题 append |
| 把 `expected_pages_hint` 喂给检索 | **公平性红线**：那是金标准，用了就等于作弊，「优化前 vs 优化后」的对比会失去意义 |

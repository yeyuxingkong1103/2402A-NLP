# 截图目录说明

> 工单编号：人工智能NLP-RAG-基于PDF文档的问答系统
> 本目录存放演示视频与验收材料所需的屏幕截图。

---

## 一、文件命名规范

统一格式：

```
<序号>-<场景分类>-<内容简述>.png
```

| 部分 | 规则 | 示例 |
| --- | --- | --- |
| 序号 | 两位数字，与「演示脚本.md」分镜号对应，从 01 开始 | `05` |
| 场景分类 | 从下表固定分类中选一个 | `建索引` |
| 内容简述 | 6~16 个汉字，不加空格，可用连字符 | `解析统计与耗时` |
| 扩展名 | 一律用 `.png`（无损、体积可控）；动图用 `.gif` | `.png` |

示例文件名：

```
01-片头-项目标题卡.png
05-建索引-解析统计与耗时.png
09-问答-法定代表人提问.png
10-问答-答案与来源页码.png
17-对比实验-总览表.png
19-评估-RAGAS四大指标.png
```

## 二、固定场景分类

| 分类 | 用途 |
| --- | --- |
| `片头` | 标题卡、封面 |
| `架构` | 技术文档架构图、目录结构 |
| `建索引` | 建索引命令、解析统计、index_stats.json |
| `上传PDF` | Swagger 上传接口、上传成功响应、文档列表 |
| `问答` | 文字提问、答案与引用、多轮追问、英文问答 |
| `语音` | 录音提示、识别结果、语音问答 |
| `反馈` | 点赞/点踩交互 |
| `命令行` | qa_cli 提问与 --show-context 溯源 |
| `对比实验` | rag_vs_llm.md 总览表、逐题详情、RAG vs 纯 LLM 并排 |
| `评估` | 评估运行过程、evaluation.md 指标与明细 |
| `容错` | 空输入、闲聊、文档外问题、错误路径提示 |
| `结果文件` | results 目录总览、各个 JSON/MD 文件内容 |

## 三、内容要求

1. **分辨率**：1920×1080（与录制分辨率一致），浏览器缩放 100%；
2. **可读性**：终端字号 ≥ 18，关键数值要能看清；必要时对局部放大后再截；
3. **完整性**：截图需包含窗口标题或命令行提示符，能看出是哪个程序/目录；
4. **脱敏**：不得出现 API Key、个人目录中的隐私文件、聊天软件弹窗；
   密钥如需入镜必须打码（马赛克或纯色遮挡）；
5. **命名一致**：同一场景的多张图按顺序编号，便于脚本引用；
6. **大小控制**：单张 PNG 建议 < 1.5 MB，超出可用工具压缩，不要用低质量 JPEG 转存。

```

  │     ① PyMuPDF抽取嵌入位图（XObject去重/装饰过滤）→ 原图 + Pillow缩略图
  │     ② 图注门控识别矢量图 → 页面区域渲染成PNG（组织结构图/流程图等）
  │     ③ 图像-页码-图注-邻近正文关联（bbox几何邻近 + "如下图"跨页关联）
  │     ④ 图内文字：矢量文本（横排+竖排按x聚类重建）/ PaddleOCR离线OCR
  └─ multimodal_index.py 文本块 + 图像块统一进入"双索引"
        稠密向量（本地BGE，离线；无模型降级TF-IDF） + BM25倒排（jieba）
retriever.py    双路召回→RRF融合→事实信号/Cross-Encoder重排（图像块类型加权）
```

## 4 图像内容解析层设计（image_extractor.py）

### 4.1 嵌入位图抽取

- `page.get_images(full=True)` 枚举XObject，`get_image_rects(xref)`取页面摆放bbox；
- **全文档xref复用统计去装饰**：复用页数>3的xref判定为页眉Logo/水印直接丢弃；再按尺寸/长宽比/面积过滤小图标与2480×395类细长扫描条；
- `Pixmap`抽取原图存`02_研发/image_store/`，`Pillow`生成长边≤360px缩略图；同xref多处摆放时共享图片文件、各自保留页码与bbox。

### 4.2 矢量图形检测与区域渲染

位图覆盖不到结构图/流程图。采用**图注门控 + 绘图密度**双条件：

1. 页内出现图题关键词（组织结构图/股权结构图/关系图/流程图/示意图/分布图等）或"如下图/如下图示"引导句；
2. 当页或次页（"如下图"位于页底时跨页）`get_drawings()`数量≥10；
3. 取绘图指令矩形并集的最大连通簇为图形bbox（外扩8pt留白），用`page.get_pixmap(clip=bbox, matrix=2.5x)`渲染为PNG并生成缩略图。

实测可稳定覆盖：招股书2第38-39页股权/组织结构图、第104/106页业务流程图、第158页关联方关系图；招股书1第60页股权结构图、第98/104页系统示意图、第107/114/120页业务/采购/生产流程图。

### 4.3 图像-页码-图注-邻近正文关联

每个`FigureRecord`记录：`doc、page_no、kind(raster/vector)、bbox、caption(图题)、ref_sentence("…如下图"引导句)、source_line(资料来源)、nearby_text(同页bbox纵向±130pt正文+上一页跨页引导段)`。规则：

- 图题：图形bbox上方75pt内、以"图"结尾或含图类关键词的短行（如"2008年中国IC市场应用结构与增长(亿元)"）；
- 引导句：含"如下图/如下图示"的完整句子（可在上一页）；
- 资料来源：bbox下方"资料来源/数据来源"行。

### 4.4 图内文字双通道

| 通道 | 方法 | 适用 |
| --- | --- | --- |
| 矢量文本重建 | 读取bbox内文本span；对"每span单字、宽度≈字号"的竖排文字按x0（容差4pt）聚类、按y0排序拼回（"销/售/部"→"销售部"，"珠/海/销/售/处"→"珠海销售处"），并保留每个标签的bbox供层级判定 | 组织结构图等矢量图 |
| OCR | 本地PaddleOCR（PP-OCRv6_medium检测+识别，模型已在`~/.paddlex/official_models`缓存，**离线不下载**；启动时关闭mkldnn规避Paddle3.4的OneDNN/PIR兼容问题），识别原图/矢量渲染图，返回文字+坐标+置信度 | 位图图表（IC增长图）、矢量图错字校正 |

OCR为**建库期离线批处理**（单图CPU约6~9秒，不占查询预算），结果按图像内容哈希增量缓存于`image_store/ocr_cache.json`，重建索引不重复识别。

## 5 多模态接口与离线降级设计（满足工单"CLIP/多模态大模型"备注）

### 5.1 统一多模态接口（已按可插拔设计）

`image_extractor.py`预留`ImageEncoder`接口：

```python
class ImageEncoder:                # 图像编码器统一接口
    def encode_images(self, paths) -> np.ndarray: ...   # L2归一化图像向量
    def available(self) -> bool: ...
```

- **在线/有模型路径**：CLIP（`open_clip`/`transformers`的CLIPModel，中文可用`Chinese-CLIP`）或多模态大模型（Qwen-VL等），文本查询与图像进入同一向量空间做跨模态检索；接口按HuggingFace标准API封装，检测到`~/.cache/huggingface/hub`下有本地权重即自动启用；
- 本环境实测`~/.cache/huggingface/hub`仅有BGE系列与英文小模型，**无CLIP/多模态大模型缓存，且禁止联网下载**，故不启用该路径。

### 5.2 离线降级：图注+邻近正文+OCR文本的"伪多模态"检索

无CLIP时，每张图转写为一个**图像证据文本块**与正文块同库检索：

```
【图像证据｜招股说明书2.pdf 第72页｜图题：2008年中国IC市场应用结构与增长(亿元)】
图内文字（OCR）：增长率；-2.0% IC卡；10.5% 工控；7.9% 计算机；6.1% 其他；14.0% 汽车；2.6% 网络通信；5.1% 消费；……（饼图标签略）
邻近正文：根据赛迪顾问……工业控制……增长率达10.5%，在所有应用行业中位列第二，仅次于汽车电子。
资料来源：赛迪顾问《2008年中国集成电路市场回顾与展望》
```

文本侧仍使用本地BGE（`BAAI/bge-base-zh-v1.5`，已缓存）做稠密语义检索 + BM25关键词检索；OCR文本使"汽车/14.0%/IC卡/-2.0%"等图像内事实可被检索。`pytesseract`与tesseract二进制本机均未安装，故OCR实现选用**已完整缓存模型的PaddleOCR**；若运行环境连PaddleOCR也不可用，则进一步降级为"图注+邻近正文"纯文本（系统在启动日志、设计文档、测试报告中显式标注每题降级情况，绝不编造图像内容）。

### 5.3 图像证据展示

- 图像块保留原图/缩略图/渲染图路径；Streamlit界面在命中图像证据时直接`st.image`展示图片，并标注书名、页码、图注、OCR置信度与证据来源；
- 评测CSV额外输出`evidence_type(text/table/image)`与`degraded`列，逐题可审计。

## 6 文本/表格解析与统一双索引

- **文本**：PyMuPDF按块提取，页眉页脚/公司名水印清洗，硬断行按句末标点合并，维护"第X节>一、"标题路径（沿用工单二成熟规则）；
- **表格**：稀疏页与"单位：+数字簇"财务页回退pdfplumber，整表序列化为Markdown独立成块，保留单元格同行共现（关联方表、募集资金用途表由此可答）；
- **多文档隔离**：每个块带`doc`与主体公司名前缀，避免跨公司串答；
- **分块**：标题感知切句贪心打包（450字/块、80字重叠）、Small-to-Big父段落；图像块独立成块；
- **双索引**：BGE稠密向量（L2归一化、点积即余弦；无缓存时降级字符2~4gram TF-IDF）+ jieba BM25倒排，numpy内存矩阵，毫秒级检索。

## 7 检索与答案抽取

1. **双路召回**：BGE Top20 ∪ BM25 Top20 → RRF融合（k=60）；
2. **重排**：本地有bge-reranker则Cross-Encoder精排（实测缓存中为`bge-reranker-large`），否则离线事实信号精排（IDF加权覆盖度、长短语命中、答案类型吻合、证据名次先验）；**问题含"图/结构图/增长率"等图像意图词时，对图像块给予类型加权**；
3. **答案抽取**：句子级覆盖度打分；数字型问题答案句必须含数字；多值题取数字最全句；
4. **确定性槽位**：注册资本（取当前最大值、排除他司）、法定代表人、补充流动资金沿用工单二规则；新增：
   - **组织结构图解题器**：在命中图像块的标签+bbox上做行聚类与绘图横线（支架）归属，统计"销售部"支架覆盖的下级部门数与"销售处"标签数，并列举实体；
   - **柱状图解题器**：按y坐标把OCR的行业标签与百分比配对，取最大值（增长最快）与唯一负值（负增长）；
5. **3秒预算**：模型/索引启动加载不计入单次响应（Streamlit `@st.cache_resource`常驻）；查询仅一次BGE编码+矩阵检索+规则抽取，OCR全部在建库期完成。

## 9 异常与容错

- PDF损坏/加密：`PDFParseError`显式报错，不中断服务其余文档；
- 图片抽取失败（mask/色彩空间异常）：单图try/except跳过并记录；
- OCR初始化/推理失败：自动回退"图注+邻近正文"，在答案与日志中标注`degraded`；
- 空问题/超长问题/英文问题：输入校验 + BGE双语向量天然支持英文检索。

# 优化文档｜招股说明书RAG智能问答系统
## 1. 当前版本存在的问题
1. 向量采用简易随机向量，语义检索效果弱，仅用于演示完整工程链路
2. 文本分块策略固定，没有动态分块
3. 前端页面样式简陋，无对话历史展示
4. 没有异常捕获：PDF不存在、Milvus断开、API密钥失效没有友好提示

## 2. 已完成优化点
1. 技术方案优化：放弃Gradio，改用Flask，规避大量Pydantic、FastAPI版本冲突
2. 依赖优化：移除huggingface、modelscope等大型模型库，解决境外网络下载失败问题，减少项目依赖体积
3. Milvus结构优化：增加主键字段，修正字段顺序，解决插入报错
4. 稳定性优化：使用简易向量，消除模型下载卡顿、401网络错误问题，保证项目可以一键跑通

## 3. 后续可优化方向（扩展加分项）
1. 向量模型优化：替换为国内BGE中文向量模型，提升检索精度
2. 文本分块优化：使用基于句子分割的智能分块，提升上下文完整性
3. 前端优化：美化页面，增加对话历史记录，展示检索到的参考文档片段
4. 异常处理：增加try-catch捕获，增加友好错误提示
5. 增加RAG评估模块，使用RAGAs评估问答效果

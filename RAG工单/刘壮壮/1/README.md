# 工单 01 — 基于 PDF 文档的问答系统

> 工单编号：人工智能NLP-RAG-基于PDF 文档的问答系统

基于大语言模型（LLM）与 RAG 技术，针对《招股说明书1.pdf》（武汉兴图新科电子股份有限公司招股意向书）构建的问答系统。支持 Query 理解、向量检索、答案生成，以及交互式界面。

## 功能

1. **Query 理解**：意图识别、消歧、问题分解与抽象
2. **文档解析**：解析《招股说明书1.pdf》，提取文字内容并分块
3. **向量检索 + 全文检索**：将文档内容嵌入向量空间，支持高效召回
4. **答案生成**：结合 LLM 生成准确、简洁的回答
5. **对比分析**：对比「RAG 回答」与「仅用 LLM 回答」的效果
6. **交互界面**：Streamlit 界面，支持问题输入、答案展示与反馈

## 目录结构

```
1/
├── main.py                 # 主程序：构建索引 + 批量问答 + 对比评估
├── app.py                  # Streamlit 交互界面
├── rag_core.py             # RAG 通用核心（PDF 解析/分块/嵌入/检索/生成/评估）
├── query_understanding.py  # Query 理解模块
├── questions.py            # 10 个测试问题
├── requirements.txt
├── .env.example
└── README.md
```

## 环境要求

- Python 3.9+
- 依赖安装：

```bash
pip install -r requirements.txt
```

## 配置（可选）

复制 `.env.example` 为 `.env`，填写 LLM 接口信息（OpenAI 兼容，支持 DeepSeek / 通义千问 / 智谱 / OpenAI / Ollama 等）。

> **不填写任何配置也能直接运行**：系统会自动回退到「离线 TF-IDF 向量 + 抽取式回答」，用于快速演示。

| 变量 | 说明 | 默认 |
| --- | --- | --- |
| `LLM_API_BASE` | LLM 接口地址 | 空（离线模式） |
| `LLM_API_KEY` | LLM 密钥 | 空 |
| `LLM_MODEL` | 模型名 | deepseek-chat |
| `EMBEDDING_MODEL` | 嵌入模型（bge/m3e 等） | BAAI/bge-small-zh-v1.5 |
| `CHUNK_SIZE` | 分块大小 | 400 |
| `CHUNK_OVERLAP` | 分块重叠 | 60 |

## 启动方式

### 方式一：命令行批量问答（含与纯 LLM 的对比评估）

```bash
cd 1
python main.py
```

会对 10 个测试问题输出：RAG 回答、纯 LLM 回答、耗时与评估指标。

单个问题问答：

```bash
python main.py --query "武汉兴图新科电子股份有限公司法定代表人是谁？"
```

### 方式二：Web 交互界面

```bash
cd 1
streamlit run app.py
```

浏览器打开 `http://localhost:8501`，输入问题即可问答。

- 响应时间 ≤ 3 秒（离线模式远快于此；接入真实 LLM 后视网络而定）

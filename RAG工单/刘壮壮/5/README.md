# 工单 05 — Query 理解优化（多轮对话）

> 工单编号：人工智能NLP-RAG-Query 理解优化任务

在招股说明书检索问答基础上，实现多轮对话能力，重点解决指代消解（如「他」「这个公司」「那…呢」）与话题实体追踪。

## 功能

1. **指代消解**：把指代词解析为完整实体（规则优先，LLM 兜底）
2. **多轮状态维护**：记录历史对话与当前话题实体
3. **RAG 检索**：消解后的完整问题进入向量 + BM25 混合检索

## 文件

```
5/
├── main.py          # 多轮对话主程序
├── coreference.py   # 指代消解与实体追踪
├── questions.py     # 测试问题
├── rag_core.py
└── README.md
```

## 运行

```bash
pip install -r requirements.txt
cd 5
python main.py                 # 演示内置多轮对话（工单要求的对话）
python main.py --interactive   # 交互式多轮对话
```

演示对话：

```
Q: 报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
Q: 他参与的哪个工程荣获了国家科技进步一等奖？       → 消解为「武汉兴图新科…」
Q: 这个公司的法定代表人是谁？
Q: 那武汉力源信息技术股份有限公司呢？              → 切换实体到力源
Q: 武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？有哪些销售处？
```

## 说明

- 指代消解规则位于 `coreference.py`，可扩展 `_COMPANIES` / `_PRONOUNS`。
- 配置 LLM 接口后，`resolve_coreference` 会用大模型做更准确的改写兜底。
- 验收要点：多轮对话问答准确率 ≥ 90%，响应时间 ≤ 3 秒。

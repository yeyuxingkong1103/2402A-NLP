## 二、Python 依赖清单（`requirements.txt`）

| 包 | 用途 |
|---|---|
| `langchain>=0.3,<2.0` | LangChain 核心 |
| `langchain-core` | 核心抽象（Document、Prompt 等） |
| `langchain-community` | FAISS 向量库集成 |
| `langchain-text-splitters` | 递归文本切片器 |
| `langchain-ollama` | Ollama 模型与向量接入 |
| `faiss-cpu>=1.8` | 向量索引（CPU） |
| `pymupdf>=1.24` | PDF 解析与表格识别 |
| `rank-bm25` | BM25 词法检索 |
| `jieba` | 中文分词 |
| `streamlit>=1.37` | Web 演示界面 |
| `matplotlib` | 对比图表绘制 |
| `python-dotenv` | 读取 `.env` 配置 |
| `pandas` | 数据处理（界面表格） |

安装：

```bash
conda activate langchain2
pip install -r requirements.txt
```

## 三、本地模型清单（Ollama）

| 模型 | 标签 | 用途 | 是否必需 |
|---|---|---|---|
| bge-m3 | `bge-m3:567m` | 向量化（embedding） | **必需** |
| deepseek-r1 | `deepseek-r1:1.5b` | 答案生成（基线链路 / 对比） | 对比演示需要 |

```bash
ollama pull bge-m3:567m
ollama pull deepseek-r1:1.5b
```

> 优化后最终方案采用**抽取式答案合成**，不依赖生成模型；生成模型仅用于复刻 01 工单基线以做对比。

## 四、环境变量配置（`.env`）

复制 `.env.example` 为 `.env` 后按需修改：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `OLLAMA_BASE_URL` | `http://localhost:11434` | Ollama 服务地址 |
| `LLM_MODEL` | `deepseek-r1:1.5b` | 生成模型 |
| `EMBEDDING_MODEL` | `bge-m3:567m` | 向量模型 |
| `LLM_TEMPERATURE` | `0.1` | 生成温度 |
| `LLM_MAX_TOKENS` | `768` | 最大生成 token |
| `LLM_TIMEOUT` | `60` | LLM 调用超时（秒） |
| `CHUNK_SIZE` | `700` | 优化后切片大小 |
| `CHUNK_OVERLAP` | `120` | 优化后切片重叠 |
| `MIN_CHUNK_SIZE` | `60` | 过短片段合并阈值 |
| `USE_PARENT_CHILD` | `1` | 父子块开关 |
| `TOP_K` | `6` | 最终返回片段数 |
| `VECTOR_TOP_K` | `15` | 向量召回候选数 |
| `BM25_TOP_K` | `15` | BM25 召回候选数 |
| `RANK_FUSION_K` | `60` | RRF 窗口参数 |
| `ANSWER_POOL` | `25` | 答案合成候选池大小 |
| `W_VECTOR` | `0.30` | 重排权重·向量 |
| `W_BM25` | `0.20` | 重排权重·BM25 |
| `W_KEYWORD` | `0.25` | 重排权重·关键词覆盖 |
| `W_NUMERIC` | `0.15` | 重排权重·数值匹配 |
| `W_ENTITY` | `0.10` | 重排权重·实体匹配 |
| `ANSWER_MODE` | `extractive` | 答案合成模式 |
| `EXTRACTIVE_MAX_SENTENCES` | `3` | 抽取答案最大句数 |
| `EMBED_BATCH_SIZE` | `50` | 向量化批大小 |

> 重排五项权重之和为 1.00；调整时建议保持归一。

## 七、资源消耗参考

| 阶段 | 资源 | 说明 |
|---|---|---|
| 构建向量库 | CPU 密集，约 1~3 分钟 | 分批 embedding（50 条/批） |
| 优化链路问答 | 单次 < 3 s | 仅向量检索 + 抽取式合成，不调用生成模型 |

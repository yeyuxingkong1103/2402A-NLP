## 1.环境准备
- 操作系统：WSL Ubuntu24.04
- Python版本：Python3.12
- Docker：用于运行Milvus向量数据库

### 1.1虚拟环境
复用工单5虚拟环境，不需要新建虚拟环境。
虚拟环境路径：`/mnt/c/Users/陈/Desktop/工单5/venv_gongdan5`

> 依赖包均已安装：Flask、pymupdf、sentence‑transformers、pymilvus、rank‑bm25、numpy

## 2.Milvus部署
Docker启动Milvus容器，端口映射19530。必须先启动Milvus，否则程序连接数据库失败。

项目放在Windows桌面`工单7`文件夹，代码文件位于子文件夹`研发`。
> ⚠️注意：main.py和测试PDF文档必须在同一级目录（研发文件夹）。

## 4.项目启动步骤
1. 打开WSL终端，进入研发子目录
```bash

激活虚拟环境

## 6. 部署注意事项

1. 每次新开终端，都需要重新激活虚拟环境。
2. Milvus 容器必须提前启动。
3. 本 Flask 为开发服务器，仅用于实训演示，不可直接用于生产。
4. 关闭终端或者 Ctrl+C，服务停止。
5. 不要上传虚拟环境文件夹到 git 仓库。

## 7. 故障排查

1. ModuleNotFoundError：虚拟环境没有激活。
2. Milvus 连接失败：Docker Milvus 容器未启动。
3. 找不到 pdf 文件：PDF 没有放在研发文件夹。
4. 网页提交无响应：浏览器 Ctrl+F5 强制清除缓存刷新页面。

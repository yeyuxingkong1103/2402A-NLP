# RAG vs 纯 LLM 对比分析报告

- **项目名称**：基于 PDF 文档的问答系统（RAG）
- **文档类型**：对比分析报告
- **日期**：2025 年

---

## 1. 对比目的

按照工单要求，针对 10 个检索问题，分别用以下两种方式生成回答，并进行质量对比：

- **方式 A（RAG 系统）**：先检索招股说明书相关内容，再让 LLM 基于检索结果生成回答
- **方式 B（纯 LLM）**：不检索任何外部资料，直接让 Qwen2.5-7B-Instruct 回答问题

**评估维度：**

- 逐题准确率：答案是否与招股说明书原文一致
- RAGAS 指标：faithfulness（忠实度）、answer_relevancy（答案相关性）
- 响应时间：单次问答耗时

---

## 2. 评估配置

| 项目 | 配置 |
| --- | --- |
| 大语言模型 | Qwen2.5-7B-Instruct（4-bit 量化） |
| 嵌入模型 | BAAI/bge-small-zh-v1.5 |
| 向量库 | ChromaDB（1214 个文本块） |
| 检索方式 | 向量检索 + BM25 混合检索（向量优先，合并去重后取 8 块） |
| 评估框架 | RAGAS 0.3.2 |
| 评估指标 | faithfulness、answer_relevancy |

---

## 3. RAGAS 指标对比

| 评估指标 | RAG 系统 | 纯 LLM | 结论 |
| --- | --- | --- | --- |
| faithfulness（忠实度） | 1.0000 | N/A | RAG 回答 100% 忠于检索上下文，零幻觉；纯 LLM 无检索上下文，该指标不适用 |
| answer_relevancy（答案相关性） | 0.8411 | 0.3249 | RAG 相关性是纯 LLM 的 2.6 倍 |

## 7. 综合结论

- **准确性**：RAG 系统 10/10 完全正确；纯 LLM 因缺乏招股说明书的私有知识，0/10 正确。
- **幻觉控制**：纯 LLM 在 2 个问题上编造了不存在的事实（GB/T 36482-2018、应急指挥调度系统），RAG 系统零幻觉。
- **相关性**：RAG 的 answer_relevancy（0.8411）显著高于纯 LLM（0.3249），差距 2.6 倍。
- **忠实度**：RAG 的 faithfulness 达满分 1.0，所有回答均可溯源到原文。
- **响应速度**：RAG 平均 2.7 秒，满足工单要求。

RAG 系统在准确性、幻觉控制、相关性、忠实度四个维度全面优于纯 LLM，验证了检索增强生成技术在文档问答场景的核心价值。

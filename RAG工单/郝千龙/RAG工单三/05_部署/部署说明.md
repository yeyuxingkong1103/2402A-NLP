# 部署说明

**工单编号：人工智能NLP-RAG-PDF文档的表格解析及检索优化**
本系统为纯 Python、纯 CPU、可完全离线运行的招股书表格问答系统。按本文档步骤可在干净的 Windows 环境完成部署、建库、评测与 Web 问答。

## 一、环境要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11（PowerShell 5.1 及以上）；Linux/macOS 同样支持，命令路径稍作调整即可 |
| Python | 3.10 ～ 3.12（开发验证版本 3.12） |
| 硬件 | 普通多核 CPU、8GB 内存即可；无需 GPU |
| 网络 | **运行期无需联网**；仅 pip 安装依赖时需要网络（或使用离线 wheel 包） |
| 磁盘 | 依赖约 2GB（含可选 sentence-transformers），索引产物 < 100MB |

## 二、目录结构

```text
RAG工单三/
├─ 招股说明书1.pdf                 # 兴图新科（548页）
├─ 招股说明书2.pdf                 # 力源信息（350页）
├─ 01_设计/
├─ 02_研发/
│  ├─ requirements.txt
│  ├─ index_store/                # 优化链路索引（建库后生成）
│  ├─ index_store_baseline/       # 基线链路索引（可选，对比用）
│  └─ src/                        # 10 个源码模块
├─ 03_测试/

```

PDF 文件必须放在 `RAG工单三` 根目录且文件名保持“招股说明书1.pdf / 招股说明书2.pdf”（路径集中在 [config.py](../02_研发/src/config.py) 的 `pdf_docs` 中，可改）。

## 三、安装步骤（PowerShell）

```powershell
# 1. 进入工单目录
cd RAG工单三\02_研发

# 2. 创建并激活虚拟环境（推荐）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
# 若提示执行策略限制：Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# 3. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

依赖说明：

- **必需**：pymupdf、pdfplumber（表格解析）、jieba（BM25 分词）、scikit-learn / scipy / numpy（TF-IDF 稀疏向量）、pandas（界面表格渲染）、streamlit（Web 界面）；
- **可选**：sentence-transformers。系统启动时自动检测本地是否已缓存 `BAAI/bge-base-zh-v1.5`，**无缓存时自动降级为离线 TF-IDF，绝不联网下载模型**。

## 四、构建索引（离线，约 2 分钟）

```powershell
cd 02_研发\src
python build_index.py
```

成功标志：控制台输出“共 8,192 个检索块（整表块 398，行块 2,332，正文块 5,462）”，且 `02_研发/index_store/` 下生成：

| 文件 | 内容 |
| --- | --- |
| vectors.npz | TF-IDF 稀疏文档矩阵（csr） |
| tfidf.pkl | 已拟合字符 ngram 向量化器 |
| bm25.pkl | postings 倒排 + 文档长度统计 |
| chunks.pkl | 全部检索块（页码/标题/公司/块类型/父文本） |
| meta.json | 索引元信息（嵌入类型、块数、公司分布） |

可选——基线对照索引（关闭表格解析与公司路由，约 40 秒）：

```powershell
python build_index.py --baseline
```

## 五、批量评测验收

```powershell
python evaluate.py               # 优化链路：写出 03_测试\评测结果.csv
python evaluate.py --baseline    # 基线链路：写出 03_测试\评测结果_基线.csv
```

验收基准（本机实测，真实数据）：优化链路 14/14 = 100%，平均 0.08 秒、最大 0.61 秒，全部 ≤ 3 秒；无表格基线对照为 10/14 = 71.4%。

## 六、启动 Web 问答服务

```powershell
cd 02_研发\src
streamlit run app.py
# 端口被占用时：streamlit run app.py --server.port=8533
```

浏览器自动打开 http://localhost:8501 后：

1. 左侧边栏切换 **中文 / English** 界面；
2. 在输入框输入问题，或点击“示例问题”按钮；
3. 查看答案、端到端耗时与证据卡片：
   - 绿色框为命中的**表格行陈述句**；
   - 表格题自动渲染来源整表（DataFrame / Markdown）；
   - 每条证据标注页码、发行人、标题路径与块类型（表格行/整表/正文）。

服务在线问答时只读索引，**不再解析 PDF**，故响应稳定在毫秒级。

## 七、配置项说明（[config.py](../02_研发/src/config.py)）

| 配置 | 默认值 | 调整建议 |
| --- | --- | --- |
| `chunk_size / chunk_overlap` | 450 / 80 | 正文块大小与重叠，一般无需调整 |
| `dense_top_k / bm25_top_k` | 50 / 50 | 召回路数；漏检表格行时适当调大 |
| `candidate_n` | 40 | 进入精排的候选数 |
| `rrf_k` | 60 | RRF 平滑常数，越大排名差异越平缓 |
| `table_row_boost / table_whole_boost` | 0.15 / 0.08 | 表格行/整表精排加权 |
| `table_min_fill_rate / table_min_row_ratio` | 0.45 / 0.70 | 表格质量门控，错版噪声多时调严 |
| `table_side_margin_pt` | 46.0 | 词坐标网格左右越界回收距离（pt） |
| `table_caption_above_pt` | 95.0 | 表标题向上检索高度（pt） |
| `response_timeout_s` | 3.0 | 验收延迟预算，界面超时会黄色告警 |
| `embedding_model / fallback_embedding` | BGE 名 / tfidf | 离线环境保持默认即可 |

## 八、常见问题（FAQ）

**Q1：建库时报“找不到PDF”？**
确认两本 PDF 位于 `RAG工单三` 根目录且文件名未改；或在 config.py 的 `pdf_docs` 中改 `file` 绝对路径。

**Q2：启动时提示缺少模块？**
确认已激活虚拟环境并执行过 `pip install -r requirements.txt`；用 `python -c "import pymupdf, pdfplumber, jieba, sklearn"` 自检。

**Q3：日志出现“未检测到本地模型缓存，启用离线 TF-IDF”？**
这是**预期行为**，不是错误：离线环境强制使用 TF-IDF 字符向量。若日后联网且希望启用 BGE，预先执行
`huggingface-cli download BAAI/bge-base-zh-v1.5`，下次建库会自动识别本地缓存升级。

**Q4：想新增招股书？**
在 config.py 的 `pdf_docs` 追加 `{file, company, short, alias}` 四项后重新 `python build_index.py`，无需改其他代码。

**Q5：如何在断网机器安装？**
在有网同架构机器执行 `pip download -r requirements.txt -d wheels`，拷贝 wheels 目录到目标机后
`pip install --no-index --find-links=wheels -r requirements.txt`。

**Q6：评测结果想复现报告数字？**
依次执行 `python build_index.py` → `python evaluate.py` → `python build_index.py --baseline` → `python evaluate.py --baseline`，两份 CSV 会覆盖写出到 03_测试 目录，报告中所有数字均可由此复现。

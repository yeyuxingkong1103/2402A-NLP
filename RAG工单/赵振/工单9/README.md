# 工单9：Graph + RAG 优化
作者：赵振。仅两个Python文件，共274行；工单10不增加Python文件。

`app.py`提供问答、上传、图谱展示；`evaluate.py`重跑14道开发题。
预置9份年报的2812页文本。数据已经按PDF原始文本块重新解析，保留文件名和PDF物理页码。

## 启动
推荐使用相邻工单10的Docker部署。直接Python启动时，在本目录运行：
```powershell
python -m pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8509
```
打开 http://127.0.0.1:8509 。输入问题，默认返回带出处的原文摘录；选择模型生成后调用本机Ollama的deepseek-r1:7b。
模型需另行安装和下载：`ollama pull deepseek-r1:7b`。生成过程较慢，当前没有达到3秒要求。

上传需填写机构和四位年份，支持25MB以内的文字PDF；扫描件要先OCR。同名上传会追加索引页并覆盖保存的同名PDF，使用不同文件名避免混淆。
图谱是“年报—主题”原文共现关系，点击主题查看出处；不是复杂的因果、持股关系图谱。

# 用户手册（工单06 · 混合检索问答系统）

**工单编号**：人工智能NLP-RAG-混合检索任务
**适用对象**：系统使用者（业务同学、验收老师）；开发者请看 `docs/02-系统架构与技术选型.md`

---

## 一、启动

```bash
cd 工单6
streamlit run app.py
```

浏览器自动打开（默认 http://localhost:8501）。首次进入请先点侧栏 **预热模型 / Warm up**
（约 35 秒，加载嵌入、Reranker、倒排索引、BM25、LLM）。

> 若提示检索/问答报错，先确认：① 已执行 `python build_index.py`（生成 8010 点索引）；
> ② Ollama 已启动（`ollama serve`）；③ 没有另一个进程占用 `data/qdrant`（见排障表）。

## 三、提问与看结果

1. 在输入框输入问题（或点示例问题），按 **提问**；
2. 结果区自上而下：
   * **回答**：直接给结论的短答案；
   * **引用来源**：`招股文件名 第X页｜block_type｜表格ID/图像ID/段落ID/组织图路径`；
   * **🎯 精排报告**：精排算法与模型、召回候选数、精排耗时、**精排前后名次变化条数**（点开看逐条 before→after）；
   * **⏱ 耗时明细**：查询理解 / 检索 / 重排 / 生成 / 总计；
   * **检索到的片段**（展开）：送入 LLM 的上下文原文，含页码与类型徽标；
   * **👍 有帮助 / 👎 没帮助**：反馈会写入 `data/feedback/feedback.jsonl`，
     供「自适应重排器」学习（选择该精排算法时生效）。

> 答案里出现 `[1][2]` 是引用编号，对应「引用来源」行的顺序。

## 四、切换检索策略（本工单重点）

进入 **🔀 检索策略** 页：

1. **检索策略**：`向量检索` / `全文检索` / `混合检索（推荐）`；
2. **召回候选数 `top_k_recall`**（默认 20）与 **精排后返回数 `top_k_rerank`**（默认 5）；
3. **精排分数阈值**（默认 0，即不启用；调高会过滤低分片段）；
4. **两路权重**（仅混合检索生效）：向量 / 全文，默认 0.5 / 0.5 等权；
5. **融合算法**（仅混合检索）：RRF（默认）/ 加权平均 / 投票；
6. **精排算法**：`Reranker 模型`（生产默认）/ `LLM 重排器` / `TF-IDF 重排器` / `用户反馈自适应重排器`；
7. **Reranker 模型**：`bge-reranker-v2-m3`（默认）/ `bge-reranker-v2-m3-ms` / `bge-reranker-base`（轻量）；
8. **嵌入模型**：`bge-m3`（默认）/ `bge-m3-ft-v1` / `miniLM-L6`（后两者需先建库）；
9. 点 **应用配置** —— 立即生效（下一次提问使用新配置）；
10. 输入问题后点 **执行检索** 看单策略细节，或点 **三种策略并排对比** 一次看三列结果。

### 全文检索语法速查（页面内也有演示）

| 想做什么 | 这样写 |
| --- | --- |
| 两个词都要有 | `注册资本 AND 法定代表人` |
| 任一命中即可 | `注册资本 OR 赵马克` |
| 排除某词 | `发行 NOT 注册资本` |
| 组合条件 | `(武汉博润 OR 上海博润) AND 关联方` |
| 精确短语 | `"存在控制关系的关联方"` |
| 容错（错别字） | `注册资木~`（编辑距离 1 也算命中） |
| 只在标题里找 | `title:组织结构图` |
| 只在表格摘要里找 | `summary:持股比例` |

## 五、多轮追问

在 **🧠 多轮对话** 页：

* 先用完整问题开场（如「报告期内，武汉兴图新科…来自军用领域的收入分别是多少？」）；
* 然后用「**他**」「**这个公司**」「**那武汉力源呢**」追问 —— 系统会把改写后的
  **独立问题**显示出来（含指代实体），再走检索；
* 指代无法确定时**不会瞎猜**，而是提示你补充公司名。

---

## 六、查看引用与图像

* 引用行给出 **页码** 与 **block_type**（text / table_row / table_header / image / orgchart）；
* 表格命中给出 **表格ID + 行号**；图像命中给出 **图像ID（文件名）**，
  在「检索策略」页会直接**渲染该图**；组织图命中给出 **节点路径**（如
  `股东大会/董事会/总经理/销售部/大客户销售部`）。

## 七、常见问题

| 现象 | 原因 / 处置 |
| --- | --- |
| 首次提问要等 30 秒以上 | 未预热。点侧栏「预热模型」 |
| 提示 `Storage folder … already accessed` | 有另一个进程在用本地 Qdrant 库：结束它，或切换服务端模式（见技术文档） |
| 精排报告显示"⚠️ 降级" | 显存不足或模型缺失。系统已自动降级为召回序截断，换 `bge-reranker-base` 或释放显存后恢复 |
| 切了嵌入模型后检索不到 | 该模型尚未建库：`python build_index.py --embedding-model <模型名>` |
| 答案说"根据已有资料无法确定" | 语料确实没有该信息，或索引未建成（跑 `build_index.py`） |
| 英文提问答中文 | 系统按提问语言作答；若出现整段中文会触发自动重试（`timings.retry`） |
| 想复现报告里的数字 | `python evaluate_retrieval.py`（16 题三策略）、`python evaluate_ragas.py`、`python benchmark_load.py` |

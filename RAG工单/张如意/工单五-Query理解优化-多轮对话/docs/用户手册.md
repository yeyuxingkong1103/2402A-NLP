```bash

$env:DEEPSEEK_API_KEY="sk-xxxxxxxx"

# Windows CMD
```

## 三、脚本清单与用法

### 3.1 `build_index.py` —— 建立知识库

```bash
python build_index.py                # 覆盖式重建（默认）
python build_index.py --no-rebuild   # 追加写入（调试）
python build_index.py --no-images    # 跳过图像解析（更快，但组织结构图题会受影响）
```

建索引内容：结构分块 + 表格块 + 图像语义块 → 向量库（collection=`prospectus`）+ BM25 倒排索引。
产物：`data/index/`（向量库、`bm25.pkl`），统计写入 `results/index_stats.json`。

### 3.2 `query_understanding.py` —— Query 理解演示与单测

```bash
python query_understanding.py            # 有 Key 则含在线用例
python query_understanding.py --offline  # 只跑离线断言
```

- 输出：控制台逐用例「通过 / 失败 / 跳过」；`results/understanding_demo.json`、`results/understanding_demo.md`
- 含 4 条需要 LLM 的在线用例（无 Key 时标记「跳过」，不计失败）
- 退出码：有失败用例返回 1，可用于 CI

**核心断言**（工单点名要求）：
「那武汉力源信息技术股份有限公司呢？」在给定历史下被改写为
「武汉力源信息技术股份有限公司的法定代表人是谁？」，且**不产生 LLM 调用**。

### 3.3 `multi_turn_chat.py` —— 5 轮多轮对话主程序

```bash
python multi_turn_chat.py                 # 默认 wo05 预设（cascade 重排，精度优先）
python multi_turn_chat.py --fast          # tfidf 重排，压 3 秒响应时间
python multi_turn_chat.py --reranker llm  # 指定重排器：none/tfidf/llm/adaptive/cascade
python multi_turn_chat.py --top-k 5
```

- 每轮输出：原始问题 → 识别意图 → 指代消解后的检索式 → Top-3 片段（《文档》页码 + 类型 + 分数）→ 答案 → 耗时与 3 秒达标标记
- 输出：`results/multi_turn_conversation.json`、`results/multi_turn_conversation.md`
- 退出码：索引缺失返回 2

### 3.4 `ablation_multiturn.py` —— 消融对比（关闭 / 开启 Query 理解）

```bash
python ablation_multiturn.py         # 完整对照
python ablation_multiturn.py --fast  # tfidf 重排，更快
```

- 同一知识库、同一问题集、同一检索与生成参数，唯一变量是 `use_query_understanding`
- 输出对比表：逐轮检索式、检索/答案判定、片段来源分布、准确率提升
- 输出：`results/multiturn_ablation.json`、`results/multiturn_ablation.md`

### 3.5 `run_evaluation.py` —— RAG 评估

```bash
python run_evaluation.py            # 完整评估（含 RAGAS 风格指标）
python run_evaluation.py --no-ragas # 只跑客观口径（关键词/检索/耗时）
```

- 指标：Faithfulness、Answer Relevancy、Context Precision、Context Recall、Answer Correctness
  + 关键词命中式准确率、Hit Rate、MRR、平均耗时、3 秒达标率 + 多语言自检
- 缺 LLM Key / 嵌入模型时单项指标自动标记「不可用」，不中断评估
- 输出：`results/evaluation.json`、`results/evaluation_records.json`、`results/evaluation.md`
- **可选**：创建 `results/ground_truth.json` 填入人工参考答案可获得更严格的评估
  （格式见 `src/wo05_common.py::load_ground_truth`）

### 3.6 `chat_ui.py` —— 可视化多轮对话界面

```bash
python chat_ui.py                  # 自动选择 Gradio / 内置 HTTP
python chat_ui.py --port 7860
python chat_ui.py --mode http      # 强制内置零依赖界面
python chat_ui.py --mode gradio    # 强制 Gradio（未安装则提示 pip install gradio）
```

界面能力：
1. 左侧对话历史（气泡式），支持连续追问；
2. 右侧「**指代消解过程**」面板：逐轮展示 *原始问题 → 改写后的检索式*、意图、实体、子问题；
3. 「引用来源」列出《文档》页码与片段摘要；「性能」显示本轮耗时与阶段明细；
4. 「**有帮助 👍 / 没帮助 👎**」按钮，反馈写入 `rag_core.rerank.AdaptiveReranker`
   （落盘 `data/index/rerank_feedback.json`，下次相似问题自动调整排序）；
5. 五轮示例问题一键填充；「清空对话」重置会话。

### 3.7 `serve.py` —— FastAPI 服务

```bash
python serve.py                    # http://127.0.0.1:8000
python serve.py --port 8080 --reload
python serve.py --build            # 先建索引再启动
```

| 接口 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 内置 Web 问答界面 |
| `/api/chat` | POST | **多轮对话**：`{session_id, question}`，同 session 自动携带上下文并做指代消解 |
| `/api/feedback` | POST | **用户反馈**：`{session_id, question, chunk_id, helpful}` |
| `/api/ask` | POST | 单轮问答（`return_trace=true` 可看检索与理解明细） |
| `/api/health` | GET | 健康检查 |
| `/api/metrics` | GET | 请求数、P95 延迟、LLM 用量 |
| `/docs` | GET | 自动生成的接口文档（Swagger） |

自测示例（保持 `session_id` 不变即可多轮追问）：

```bash
curl -X POST http://127.0.0.1:8000/api/chat -H "Content-Type: application/json" ^
     -d "{\"session_id\":\"demo\",\"question\":\"武汉兴图新科电子股份有限公司法定代表人是谁？\"}"

curl -X POST http://127.0.0.1:8000/api/chat -H "Content-Type: application/json" ^
     -d "{\"session_id\":\"demo\",\"question\":\"那武汉力源信息技术股份有限公司呢？\"}"
```

## 五、常见问题（FAQ）

**Q1：提示「未检测到索引」？**
先运行 `python build_index.py`。索引产物在 `data/index/`（向量库 + `bm25.pkl`）。

**Q2：第 2/3 轮没有改写，检索答非所问？**
未配置 `DEEPSEEK_API_KEY` 时，LLM 慢通道不可用，指代消解会回退为原问题。
配置 Key 后重跑；离线演示可只跑第 4 轮（规则通道，无需 Key）。

**Q3：某轮超过 3 秒？**
用 `--fast`（TF-IDF 重排）或 `--reranker tfidf` 去掉重排环节的 LLM 调用；
`multi_turn_chat.py` 打印的「阶段耗时明细」可定位瓶颈（rerank / generate）。
命中 LLM 磁盘缓存时重复运行会显著变快。

**Q4：`chat_ui.py` 提示没有 Gradio？**
它会自动降级为内置 HTTP 界面（零额外依赖）。想要完整界面执行 `pip install gradio`。

**Q5：Windows 控制台中文乱码？**
先执行 `chcp 65001` 切换到 UTF-8 代码页；文件输出均为 UTF-8，不受影响。

**Q6：想换更严格的评测口径？**
创建 `results/ground_truth.json`（按轮次提供 `answer_keywords` 与 `reference_answer`），
`run_evaluation.py` 与 `ablation_multiturn.py` 会自动采用。

**Q7：如何只验证 Query 理解、不跑检索？**
`python query_understanding.py --offline`：不依赖索引与 LLM，数十毫秒跑完全部离线断言。

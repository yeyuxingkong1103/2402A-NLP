## 1. 优化前（工单10 基座）

```
                       ┌──────────────────────────────────────────┐
  20 并发 HTTP  ──────►│  uvicorn (1 worker)  service/api.py      │
                       │                                          │
                       │  @app.post("/api/v1/ask")  def ask(...)  │  ← 同步 def
                       │      ↓ FastAPI 丢进 anyio 线程池(40)      │
                       │  ┌────────────────────────────────────┐  │
                       │  │ QAEngine.answer()                  │  │
                       │  │  ├ conversations.resolve()         │  │
                       │  │  ├ _memory_cache.get/put  ← 无锁!  │  │
                       │  │  ├ retrieve() → FAISS + BM25       │  │
                       │  │  │    └ embed_query()               │  │
                       │  │  │        └ resolve_embedding_     │  │
                       │  │  │          backend(probe=True)  ←─┼──┼──► GET /api/tags   ★每请求一次
                       │  │  │        └ urlopen(/api/embed)  ←─┼──┼──► 新建 TCP
                       │  │  └ generate() → LLMClient          │  │
                       │  │      └ urlopen(/api/generate)   ←─┼──┼──► 新建 TCP, keep_alive=30m
                       │  └ storage.record_qa/save_answer_     │  │
                       │      cache/bump_cache_hit/touch_      │  │
                       │      session  ← 4× commit() 串行锁    │  │
                       │  session_store.append() ← 全局文件锁  │  │
                       └──────────────────────────────────────────┘
                                        │
                       ┌────────────────┴─────────────────┐
                       │  Ollama 127.0.0.1:11434          │
                       │   qwen2.5:3b + bge-m3  常驻 30min │ ★从不主动卸载
                       └──────────────────────────────────┘
```

**架构级缺陷**（详见 `优化/瓶颈排查与修复报告.md`）：

1. 无入口限流 —— `max_concurrency` 配置项零引用。
2. 同步路由跑重活 —— 线程池被秒级阻塞请求占满。
3. 每请求多次外部 HTTP 建连 + 一次多余的 `/api/tags` 探测。
4. `_memory_cache` 无锁、无 TTL。
5. 每请求 4 次 sqlite `commit()` 串行在一把锁上。
6. Ollama `keep_alive=30m` 写死，无卸载路径。

## 4. 与 RAGFlow 参考架构的语义映射

| RAGFlow 组件 | 本仓库等价物 | 说明 |
| --- | --- | --- |
| API Server | `service/api.py`（uvicorn） | 对外 HTTP |
| Task Executor | `service/task_queue.py`（解析工作线程池） | 异步解析，API 不阻塞 |
| Redis（队列/会话） | `service/session_store.py::MiniRedis` → 6379 | 实测 `PING` = `PONG` |
| 向量数据库（Milvus） | FAISS `IndexFlatIP` + `vectors.npy` | `milvus_store.py` 为可选适配器，`pymilvus` 未装 |
| DeepDoc 解析器 | `app/core/pdf_parser.py`（PyMuPDF） | 仅上传任务路径使用 |
| Reranker | `app/core/reranker.py`（无模型、确定性） | 无 GPU 依赖 |
| VLM | 无（本机无视觉模型） | 如实记录，不伪装 |

## 5. 数据流（一次问答）

```
POST /api/v1/ask {question, session_id}
  → observe() 中间件：trace_id + 计时
  → BoundedGate.acquire()            [F3] 拿不到票 → 429
  → run_in_threadpool(_ask_sync)     [F4]
      → QAEngine.answer()
          → conversations.resolve()          （会话指代消解，内存 + 落盘）
          → analyze()                        （语言/意图/答案形态/主体路由）
          → _memory_cache.get(key)           [F5] 命中 → 立即返回（P95 的关键）
          → retrieve()                       （FAISS + BM25 → RRF → 轻量重排）
              → embed_query() → http_pool    [F1][F2]
          → evaluate_answerability()         （不够证据 → 拒答 200 + refused）
          → generate() → http_pool           [F1][F7]
          → build_citations()
          → _memory_cache.put() + sqlite     [F5][F6]
      → session_store.append()               [F8]
  → observe() 收尾：状态码 / 耗时 / 指标
```

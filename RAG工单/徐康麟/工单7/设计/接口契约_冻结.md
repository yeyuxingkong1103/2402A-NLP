### 1.1 `研发/app/core/dialogue_state.py`（工单5 新增）

```python
@dataclass(slots=True)
class TurnRecord:
    question: str            # 用户原始问句
    rewritten_query: str     # 改写后的独立可检索问句
    answer: str
    ts: float
    trace_id: str = ""
    cited_pages: list[int] = field(default_factory=list)
    focus_entity: str | None = None
    strategy: str = "none"
    refused: bool = False
    latency_ms: float = 0.0
    def to_dict(self) -> dict[str, Any]: ...

@dataclass(slots=True)
class DialogueState:
    session_id: str
    turns: list[TurnRecord] = field(default_factory=list)
    focus_entity: str | None = None     # 焦点实体（当前谈论的公司全称）
    last_slot: str | None = None        # 上一轮的「槽位骨架」，如 "法定代表人是谁？"
                                        # （= 把问句里的实体与指代词挖掉后的骨架；**不是**字段名）
    last_query: str | None = None       # 上一轮的独立问句（改写后）
    entity_stack: list[str] = field(default_factory=list)  # 实体栈（最近在后）
    total_turns: int = 0                # 累计轮次（turns 会被裁剪，故单独计数）
    created_at: float = ...
    updated_at: float = ...
    def recent(self, n: int = 3) -> list[TurnRecord]: ...
    def push_entity(self, entity: str) -> None: ...
    def to_dict(self) -> dict[str, Any]: ...

class DialogueStateStore:
    """线程安全；按 session_id 维护 DialogueState；保留最近 N 轮（默认 3）。"""
    def __init__(self, *, max_turns: int = 3, max_sessions: int = 200,
                 storage: Any = None, logger: Any = None, persist_dir: Path | None = None) -> None: ...
    def get(self, session_id: str) -> DialogueState: ...
    def append(self, session_id: str, turn: TurnRecord) -> DialogueState: ...
    def reset(self, session_id: str) -> None: ...
    def history(self, session_id: str) -> list[TurnRecord]: ...
    def sessions(self) -> list[str]: ...
    def stats(self) -> dict[str, Any]: ...
```

### 1.2 `研发/app/core/query_rewriter.py`（工单5 新增）

```python
STRATEGIES = ("none", "empty_input", "pronoun", "ellipsis_entity_switch",
              "ellipsis_topic_carry", "topic_carry", "multi_turn_enrich")

@dataclass(slots=True)
class RewriteResult:
    original: str
    rewritten: str
    strategy: str
    changed: bool
    focus_entity_before: str | None
    focus_entity_after: str | None
    inherited_slot: str | None
    resolved_refs: list[dict[str, Any]]   # [{"surface":"他","replacement":"武汉力源…","kind":"pronoun"}]
    slot: str | None = None               # 本轮问句的槽位骨架（供下一轮「那 X 呢？」继承）
    notes: str = ""
    def to_dict(self) -> dict[str, Any]: ...

class QueryRewriter:
    def __init__(self, *, corpus_issuers: Mapping[str, Sequence[str]] | None = None,
                 cfg: Any = None, logger: Any = None) -> None: ...
    def rewrite(self, question: str, state: DialogueState) -> RewriteResult: ...
    def detect_entities(self, text: str) -> list[str]: ...
    def detect_slot(self, text: str) -> str | None: ...
```

**改写规则（必须实现，顺序敏感）**：

| # | 触发 | 动作 | strategy |
| --- | --- | --- | --- |
| R0 | 空/纯空白/纯符号 | 返回空改写，标记 `empty_input` | `empty_input` |
| R1 | 问句含**显式实体** E 且**无字段槽位**（省略式，如「那X呢？」） | 用上一轮槽位 F 补全 → `"{E}的{F}是什么？"` | `ellipsis_entity_switch` |
| R2 | 问句含**指代词**（他/她/它/其/该/这个/那个/上述/前述/该公司/这家/此项/本公司）且**无显式实体** | 指代词 → 焦点实体 | `pronoun` |
| R3 | 问句**既无实体也无指代词**但**含字段槽位**（如「法定代表人是谁？」） | 前缀焦点实体 | `topic_carry` |
| R4 | 问句含显式实体且有槽位 | 原样（仅更新焦点实体） | `none` |

**焦点实体更新**：显式实体出现 → 入栈并设焦点；否则保持不变。

### 1.4 `研发/app/core/subject_binding.py`（工单5 新增）

> 冻结契约的**补充模块**。用于把「字段值」绑定到正确的公司主体，修掉一个会让 Q4 答错的真实缺陷：
> 招股书每页页眉都印发行人全称，而同页常同时出现多个法律主体（发行人 vs 保荐机构）的同类字段，
> 导致问「力源的法定代表人」时抽到了「国信证券的法定代表人何如」。

```python
@dataclass(slots=True)
class BindingVerdict:
    ok: bool; score_delta: float; reason: str      # foreign_org | non_issuer_section | issuer_section | neutral | issuer_absent
    anchor: str = ""; foreign_org: str = ""; issuer_seen: bool = False
    def to_dict(self) -> dict[str, Any]: ...

PERSON_FIELDS: tuple[str, ...]     # 人名型字段（法定代表人/实际控制人/董事长/…）

def bind_subject(text: str, pos: int, *, issuer: str | None, section: str = "",
                 window_before: int = 45, window_after: int = 50) -> BindingVerdict: ...
def extract_person_value(after_text: str) -> str: ...     # 「：赵马克 5、」→「赵马克」；「：武汉力源…」→「」
def is_person_field(field: str, field_terms=None) -> bool: ...
def issuer_in_body(text: str, issuer: str) -> bool: ...   # 剔除页眉后判断（页眉会骗过块级判断）
def window_orgs(text: str, pos: int, **kw) -> list[str]: ...
```

**判定优先级**（先拒收后加分）：
1. 窗口内出现**别的机构全称** → `foreign_org`，拒收（−0.45）；
2. 最近章节标题命中**非发行人角色**（保荐机构/主承销商/会计师事务所/声明…） → `non_issuer_section`，拒收（−0.45）；
3. 最近章节标题命中**发行人角色**（发行人/本公司/公司基本情况…） → 通过并加分（+0.18）；
4. 其余 → 中性通过；`issuer` 非空但全块未出现 → 额外 −0.15。

**接入点**：`answer_composer.compose_single_value` 的正文路径（拒收）与表格路径（**只加分不降权**）。

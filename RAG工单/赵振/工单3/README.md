# 工单 03：PDF 表格解析及检索优化

工单编号：人工智能NLP-RAG-PDF文档的表格解析及检索优化。

本项目沿用工单2的 Streamlit 问答应用和向量/字符检索，只增加表格行解析与表格字段加权。PDF 表格被拆成带页码的“字段=值”片段；命中一行后，再从同一张表取回完整行组，保留金额、项目名称和关联关系的对应关系。

## 启动

1. 安装 Python 3.10 或更新版本，并在本目录执行 `python -m pip install -r requirements.txt`。
2. 启动网页：在 PowerShell 执行 `powershell -ExecutionPolicy Bypass -File .\启动网页.ps1`。
3. 浏览器打开 `http://127.0.0.1:8501`，上传或选择《招股说明书2.pdf》，点击“解析并建立索引”。
4. 上传《招股说明书1.pdf》时，也可切换到该知识库，运行原有十题。

原始 PDF、索引和反馈保存在本机，不放进代码提交包。首次建库时间不计入模型和索引载入后的热查询时间。

## 工单03新增题

新增的4题见 `questions.json` 前4项；后10项是工单1题目的回归记录。运行 `python evaluate.py` 可重新测试前4题；10题回归结果明确标注为沿用工单2评测记录。

## 验证

- `python test_table_parser.py`：检查发行表、募投项目和两类关联方表格，并确认历史关联方没有混入。
- `python evaluate.py`：用《招股说明书2.pdf》建索引，检查4题检索答案、关键词覆盖和热查询耗时。
- `python test_stability.py`：检查模糊问题、损坏PDF和英文事实回答。
- `python test_app_smoke.py`：检查网页控件可启动。
- 测试证据图在 `PDF 解析模块`、`问答引擎`、`问答界面` 和 `知识库管理` 目录。

工单要求的高并发压力测试未执行；固定题关键词覆盖率不代表通用准确率，仍需人工抽查答案。

# 工单 07 — 功能测试及评估

> 工单编号：人工智能NLP-RAG-功能测试及评估

基于工单 01-06 实现的 RAG，对附件《ccf_competition.zip》中的金融年报 PDF 做 RAG 测试与检索评估，使用评估框架（RAGAS 风格指标）对检索结果评估并分析问题。

## 数据

- `../附件/ccf_competition/txt/`：9 份金融年报（平安银行、中国平安、招商银行、邮储银行、中信证券、中国人寿、中国太保、招商证券、国泰君安）正文提取结果
- `questions.py`：10 个测试问题（体现年报内容相关性，部分参考答案取自 sample_questions.pdf）

## 功能

1. 加载 ccf 年报并构建向量 + BM25 混合检索
2. 对 10 个问题检索并生成答案
3. 输出检索结果、RAG 评估结果（上下文精度 / 召回 / 忠实度）
4. 若安装 ragas，输出真实 RAGAS 指标
5. 分析检索结果存在的问题并给出改进方向

## 运行

```bash
pip install -r requirements.txt
cd 7
python main.py                    # 全量测试 + 评估 + 问题分析
python main.py --query "平安银行在2019年的董事长致辞中，提到其盈利增长的关键因素有哪些？"
```

## 验收要点

- 10 个问题体现 ccf_competition 年报内容的相关性
- 使用 01-06 的 RAG 系统测试
- 输出 10 个问题的检索结果 + 评估结果，并体现问题分析

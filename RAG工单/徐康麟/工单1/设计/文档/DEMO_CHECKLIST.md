# 演示操作清单 —— 基于 PDF 文档的 RAG 问答系统（工单1）

> 使用者：**演示者本人**（按本清单从上到下操作即可，无需他人协助）
> 建议时长：30~40 分钟（不含索引构建等待时间）
> 打印或分屏使用：每完成一步就在 `- [ ]` 中打勾 `- [x]`

---

## 使用说明

1. 本清单分 **A~L 共 12 个阶段**，请**按顺序**执行，不要跳步；
2. 标注 `⌨️` 的是**命令行操作**，标注 `🖱️` 的是**界面操作**；
3. 标注 `📝` 的是**需要记录的信息**，建议提前准备纸笔或记事本；
4. 标注 `⚠️` 的是**易错点**，演示前务必读一遍；
5. 涉及具体数值的地方（首字耗时、评估分数等）**以你实际跑出来的结果为准**，本清单不预填任何数字。

### 演示前 30 分钟的准备

- [ ] 📝 确认机器已接通电源、关闭自动休眠与系统更新弹窗
- [ ] 📝 确认没有其它程序占用 **8000**（LLM 服务）与 **8501**（界面）端口
- [ ] 📝 准备好 PDF 阅读器（用于跳页核对引用），并把《招股说明书1.pdf》打开在后台
- [ ] 📝 打开两个终端窗口（一个跑 LLM 服务，一个跑界面），字号调大到录制可见
- [ ] 📝 关闭即时通讯软件通知，避免录屏弹出隐私内容

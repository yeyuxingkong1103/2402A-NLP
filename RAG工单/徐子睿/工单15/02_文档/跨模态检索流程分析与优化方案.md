## 1. 问题定位

目标文档 `CN100347506C.pdf`（块状散料分配装置专利，11 页）的 6 题中，后 4 题答案**只存在于第 11 页图 3**。工单给出两个典型故障：

1. **故障 1（检索无关）**：仅靠“部件”“编号”等泛文本关键词召回，返回大量**提到部件编号但不含图 3** 的文本块，漏掉真正的图纸页；
2. **故障 2（图文割裂）**：即使召回含图 3 的页，也无法把“编号 13 / 位置关系”与**图纸的图像特征**关联，LLM 拿不到视觉信息。

根因：RAGFlow 默认检索是**「全文 + 向量」加权混合**，其文本侧对“第 11 页图 3”这类**视觉引用**没有专门理解，图块能否被召回**取决于解析阶段是否已把图 3 生成「图像描述文本」并入库**（依赖工单 14）。

## 2. 任务一：RAGFlow 检索流程剖析（源码级）

### 2.1 端到端主链路

对话式检索入口在 `api/db/services/dialog_service.py :: async_chat()`（约 275 行起）：

```
用户问题
  ├─ (可选) refine_multiturn  → full_question()     多轮指代消解/追问改写
  ├─ (可选) cross_languages   → cross_languages()   跨语言改写
  ├─ (可选) keyword=True      → keyword_extraction() 关键词抽取，拼到 query 尾部
  ├─ (可选) meta_data_filter  → apply_meta_data_filter() 元数据过滤
  ├─ (可选) reasoning=True    → DeepResearcher.research() 深度检索
  └─ retriever.retrieval(query, embd_mdl, tenant_ids, kb_ids, page, page_size,
                          similarity_threshold, vector_similarity_weight,
                          top, doc_ids, aggs, rerank_mdl, rank_feature=label_question(...))
        └─ rag/nlp/search.py :: Dealer.retrieval()  →  search()（多路召回）
                                                        →  rerank_by_model() / rerank()
```

**查询理解与重写模块**：`rag/prompts/generator.py` 的 `full_question`、`cross_languages`、`keyword_extraction`（在 `dialog_service.py` 中按 `prompt_config` 开关调用）。

### 2.2 多路召回与向量库调用（`rag/nlp/search.py`）

`Dealer.retrieval(...)`（`search.py:363`）默认参数：
`similarity_threshold=0.2`、`vector_similarity_weight=0.3`、`top=1024`、`rank_feature={PAGERANK_FLD:10}`。
- 构造 `req`（`vector=True, topk=top, similarity=threshold`）→ `self.search(req, index_name(tid), kb_ids, embd_mdl, highlight)`
  —— 底层 DocStore 连接（Elasticsearch 或 Infinity）执行**向量近邻 + 全文倒排**两路召回。
- 全文侧查询字段带权重（`rag/nlp/query.py :: FulltextQueryer.query_fields`）：
  ```
  title_tks^10, title_sm_tks^5, important_kwd^30, important_tks^20,
  question_tks^20, content_ltks^2, content_sm_ltks
  ```
  —— 即**标题/关键词命中权重远高于正文**。

### 2.3 文本与图像模态的融合 + 重排

- **融合**：`rerank()`（无重排模型时）或 `rerank_by_model()`（有重排模型时）内部调用 `hybrid_similarity()`，按
  `score = tkweight * 全文分 + vector_similarity_weight * 向量分` 加权，其中 `tkweight = 1 - vector_similarity_weight`。
  - Infinity 引擎会**先各自归一化再融合**；Elasticsearch 不会，故 `retrieval()` 里对两者分支处理（`search.py:405` 起）。
- **重排（Re-Rank）**：`rerank_by_model(rerank_mdl, sres, question, tkweight, vector_similarity_weight)`（`search.py:334`），
  用 cross-encoder/reranker 模型（`LLMType.RERANK`，在 `dialog_service.get_models()` 绑定）对候选做**精细打分**；`RERANK_LIMIT≥30`。
- **图像模态**：RAGFlow **没有独立的图像向量库**——图像以「文本描述块 + 关联位置」进入同一向量索引；因此**跨模态融合的关键在解析层**（图 → 描述文本），检索层只做文本匹配。

### 2.4 检索后处理

- `retrieval_by_toc()`（目录增强）、`retrieval_by_children()`（子块回溯）；
- `label_question()` 作为 `rank_feature` 参与打分；
- 结果经 `rag/prompts/generator.py :: kb_prompt()` 组装上下文 + `citation_prompt` 引用，送入 LLM。

## 3. 任务二：优化方案设计

### 3.1 优化查询理解（视觉引用识别）★ 核心

新增查询前置处理器：识别 `图N / 第N页 / 图示 / 编号N / 部件N` 等**视觉引用模式**，命中时：

1. 从解析结果中定位该图表（按页码/图号），取其**图像描述文本**；
2. 把描述作为**增强查询**（与原问题拼接）参与召回 —— 即「原问题文本 + 图像描述查询」双查询；
3. 代码见 `01_代码/query_rewrite.py`（正则 + 术语表，可按项目扩展）。

### 3.2 优化混合检索策略（多路召回融合）

- **多路召回 + RRF 融合**：分别用「问题文本」「图像描述增强查询」做向量检索，再用 **Reciprocal Rank Fusion** 融合：
  `RRF(d) = Σ_i 1/(k + rank_i(d))`，k 默认 60。见 `01_代码/fusion.py`。
  - 与 RAGFlow 现有加权混合共存：RRF 用于**两路文本查询**之间，加权混合用于**文本/向量分之间**。
- **图文联合向量检索**：给同一页的「文本块」与「图像描述块」打相同的 `page`/`doc_id` 元数据，召回后按页聚合，确保图块与其上下文一起进上下文窗口。
- **跨模态重排**：绑定 `LLMType.RERANK` 模型（bge-reranker 等），对 Top-K（≥30）精排；见 `01_代码/rerank_config.py` 的开关与权重配置。
- **Prompt 工程**：命中图像上下文时，在系统 Prompt 追加「请结合以下技术图纸的描述进行分析」，并把图像描述摘要与文本一同放入上下文 —— 见 `01_代码/prompt_multimodal.md`。

### 3.3 可维护性

所有新逻辑用**外部配置**驱动（`cross_modal_config.yaml` / 环境变量）：融合算法（`rrf|weighted`）、`rrf_k`、`vector_similarity_weight`、`rerank_switch`、视觉引用正则表 —— 阈值**不硬编码**。

## 4. 任务三：系统化测试与调优（方案）

1. **优化前基准**：用 `工单15_6题.json` 逐题跑基线，记录 Top-K、相关性、是否命中第 11 页图 3；
2. **错误归因**：按「查询理解 / 召回 / 排序」三段定位失败环节；
3. **迭代**：优先保召回（图描述块入候选），再保排序（ReRank 提权）；
4. **终态**：6 题准确率 100%，后 4 题 Top-1/3 命中「第 11 页图 3」的描述。

## 5. 结论

- RAGFlow 检索是**「多路召回（向量+全文）→ 加权/RRF 融合 → ReRank」**的文本检索框架；**图像模态依附于文本描述**，因此**跨模态能力上限取决于解析层的图像描述质量**。
- 本工单的优化主线：**解析层出图描述（承接工单14）→ 查询层识别视觉引用并生成图像增强查询 → 检索层 RRF 融合双查询 → 排序层跨模态 ReRank → Prompt 层显式指示结合图纸**。

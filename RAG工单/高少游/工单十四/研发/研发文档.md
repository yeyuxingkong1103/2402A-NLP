# 研发文档

**工单编号：人工智能NLP-RAG-修复低质量工业PDF的解析与信息丢失工单**
**项目：工业专利（图片型 PDF）多模态检索问答系统**

---

## 1. 项目概述

本工程实现一套面向中文工业技术文档（图片型 PDF）的多模态检索问答系统，修复 RAGFlow 常规流水线在低质量工业 PDF 上导致的「图文信息丢失、关联错误」缺陷。工程复用前序工单（工单七）的混合检索、多轮对话与图形语义骨架，在其上叠加 OCR 解析通道与专利选择题定向作答能力。

源文档为 `CN100342976C.pdf`（静电除尘器发明专利，8 页，纯图片型 PDF，无文本层）；评测集为工单指定的 6 道选择题（`data/eval_questions.json`）。

## 3. 核心模块说明

### 3.1 解析模块

**`src/ocr_engine.py`** —— OCR 解析引擎，修复信息丢失的第一道通道。

- `render_pages()`：`pymupdf` 以 300 DPI 渲染每页为 PNG；
- `run_ocr()`：调用 PaddleOCR 专用环境（子进程）识别；
- `ensure_ocr_cache()`：OCR 结果逐页缓存，二次构建零开销；
- `to_reading_text()`：按 y 行聚类 + 行内 x 排序还原阅读序。

**`src/pdf_parser.py`** —— PDF 解析与附图页识别。

- `is_figure_page()`：正文中文字符 ≤ 120 且标注数 ≥ 3 → 判为附图页；
- `parse_pdf()`：输出 `PageData`（含 `text / kind / labels`）。

**`src/figure_semantics.py`** —— 附图语义解析，修复图文关联错误的第二道通道。

- `build_part_lexicon()`：受控词表 + 最长优先，抽取「编号 → 部件名」；
- `parse_figure_page()`：水平优先方位判定 + 配气带孔盘次序还原；
- `extract_all_figure_semantics()`：批量解析所有附图页。

### 3.2 索引模块

**`src/chunking.py`**：`build_chunks()` 把逐页数据切分为 `text / table / figure` 三类块，`derive_fields()` 派生 `title / abstract` 检索字段。

**`src/knowledge_base.py`**：`build_from_scratch()` / `rebuild_from_chunks()` / `load_kb()`，构建并持久化双索引。

**`src/inverted_index.py`**：多字段 BM25 倒排索引，支持 AND/OR/NOT 布尔查询与模糊匹配。

### 3.3 检索模块

**`src/hybrid_retriever.py`**：并行执行向量与全文召回，按 RRF 融合，可选反馈信号。

**`src/rerankers.py`**：`linear` 重排器融合向量、BM25、关键词、数值、实体、附图、页码、短语、同义词等信号。

**`src/embedding.py`**：`Embedder` 封装 Ollama 嵌入，`encode_many_cached()` 批量编码并缓存。

### 3.4 作答模块

**`src/answer_builder.py`**：`_mcq_answer()` 对选择题做多信号融合打分并定向作答；非选择题退回抽取式作答。核心工具函数：`_bigram_f1`、`_coverage`、`_canon_quotes`、`_split_option`。

**`src/qa_engine.py`**：`QAEngine.ask()` 串联改写 → 理解 → 合并编码 → 检索 → 重排 → 作答 → 会话写回。

## 4. 关键算法

### 4.1 选项定向打分

```
score(选项) = W_OPTION_LEX × 词法覆盖(选项, 证据)
            + W_OPTION_SEM × 语义相似(选项, 证据向量)
            + W_OPTION_QUERY × 问句相关(选项, 问句)
            + W_INVENTION × 发明语境覆盖(选项, 证据)
            − W_PRIORART × 现有技术语境覆盖(选项, 证据)
```

取最高分选项作答；权重见 `config.py`。

### 4.2 水平优先方位判定

附图部件方位判定以横坐标差为主判据：

```
if |Δx| ≥ X_THRESH:      判定 左/右
elif |Δy| ≥ Y_THRESH:    判定 上/下
```

### 4.3 配气带孔盘次序还原

对文本以「6」开头的标注族按 x 从左到右排序，映射为 `6″（最左）、6′（居中）、6（最右）`。

## 6. 扩展指南

### 6.1 更换数据集

1. 把新的图片型 PDF 放入 `data/documents/`；
2. 更新 `config.PDF_PATHS`（自动扫描）与 `config.TARGET_DOC`；
3. 更新 `data/eval_questions.json`；
4. 运行 `python build_kb.py --rebuild`。

### 6.2 新增嵌入模型

在 `config.EMBEDDING_MODELS` 注册 slug 与 Ollama 模型名，`ollama pull` 后运行 `python build_kb.py --models <slug>`。

### 6.3 调整检索策略

界面侧边栏可运行期热切换检索策略 / 嵌入模型 / 全文模式 / 重排算法 / 融合算法 / 向量权重；也可通过 `.env` 或 `RetrievalConfig` 固化默认值。

### 6.4 调整作答权重

在 `config.py` 调整 `W_OPTION_LEX / W_OPTION_SEM / W_OPTION_QUERY / W_INVENTION / W_PRIORART`，或在 `.env` 中覆盖，无需改代码。

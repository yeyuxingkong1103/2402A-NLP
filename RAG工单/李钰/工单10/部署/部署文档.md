# 金融问答系统 Docker 部署文档

> 工单编号: 人工智能 NLP-RAG-金融问答系统部署
> 版本: v10.0 (V9 Graph RAG 优化版)

## 一、前置条件

| 工具 | 最低版本 | 说明 |
|------|----------|------|
| Docker | 20.10+ | 容器运行时 |
| Docker Compose | 2.0+ | 多容器编排 (可选) |
| 宿主机 | Linux / Windows / Mac | 推荐 8GB+ 内存 |

## 二、快速启动 (单机)

### 方式 1: docker run (推荐)

```bash
# 构建镜像
cd 项目工单
docker build -f 工单10/部署/Dockerfile -t financial-rag:v10.0 .

# 启动容器
docker run -d --name financial-rag-qa \
    -p 5008:5008 \
    -v rag_data:/app/data \
    -v rag_cache:/app/cache \
    -v rag_logs:/app/logs \
    -v rag_shared:/app/shared \
    -e LLM_API_KEY=sk-xxxx \
    --restart unless-stopped \
    financial-rag:v10.0

# 验证
curl http://localhost:5008/api/health
# {"status":"healthy", ...}
```

### 方式 2: docker-compose

```bash
cd 工单10/部署
docker-compose up -d
# 或生产模式
docker-compose up -d --build
```

### 方式 3: 一键脚本

```bash
# Windows
工单10\部署\run_docker.bat

# Linux/Mac
bash 工单10/部署/run_docker.sh
```

## 三、验收标准对照

### 3.1 容器启动与运行 ✅

```bash
# 验证容器运行
docker ps --filter "name=financial-rag-qa"
# CONTAINER ID   STATUS   PORTS                    NAMES
# abc123         Up 5min   0.0.0.0:5008->5008/tcp   financial-rag-qa

# 验证服务
curl http://localhost:5008/api/health
# {"status":"healthy", ...}

# 验证无异常日志
docker logs financial-rag-qa 2>&1 | grep -i error
# (无输出 = 正常)
```

### 3.2 容器数据管理 ✅

```bash
# 查看卷
docker volume ls | grep rag
# rag_data, rag_cache, rag_logs, rag_shared

# 数据导出
curl http://localhost:5008/api/data/export
# {"ok": true, "export_path": "/app/data/export_xxx.tar.gz"}

# 容器间数据共享
curl -X POST http://localhost:5008/api/data/shared \
    -H "Content-Type: application/json" \
    -d '{"key":"value"}'
# 另一个容器读取
curl http://localhost:5008/api/data/shared
```

### 3.3 网络配置 ✅

```bash
# 容器网络
docker network inspect rag_network
# 多容器互通
docker run -d --name rag-neo4j -p 7474:7474 -p 7687:7687 \
    --network rag_network neo4j:5
# financial-rag 可通过容器名 "rag-neo4j" 访问
```

## 四、持久化数据说明

| 卷 | 容器路径 | 用途 | 是否备份 |
|----|----------|------|----------|
| rag_data | /app/data | 知识图谱 JSON、预设数据 | **必须** |
| rag_cache | /app/cache | 向量索引缓存 | 可选 (自动重建) |
| rag_logs | /app/logs | 应用日志 | 可选 |
| rag_shared | /app/shared | 容器间共享数据 | 按需 |

### 备份与恢复

```bash
# 备份
docker run --rm -v rag_data:/data -v $(pwd):/backup alpine \
    tar czf /backup/rag_data_backup.tar.gz -C /data .

# 恢复
docker run --rm -v rag_data:/data -v $(pwd):/backup alpine \
    tar xzf /backup/rag_data_backup.tar.gz -C /data
```

## 五、环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| FLASK_PORT | 5008 | Flask 监听端口 |
| FLASK_HOST | 0.0.0.0 | Flask 监听地址 |
| LLM_API_KEY | (空) | LLM API Key (不配置则降级) |
| LLM_BASE_URL | https://api.openai.com/v1 | LLM API 地址 |
| LLM_MODEL | gpt-3.5-turbo | LLM 模型 |
| NEO4J_URI | (空) | Neo4j 连接 (可选) |
| RAG_DATA_DIR | /app/data | 数据目录 |
| RAG_CACHE_DIR | /app/cache | 缓存目录 |
| RAG_LOG_DIR | /app/logs | 日志目录 |
| RAG_SHARED_DIR | /app/shared | 共享目录 |

## 六、API 接口

| 接口 | 方法 | 说明 |
|------|------|------|

## 七、容器管理命令

```bash
# 查看状态
docker ps -a --filter "name=financial-rag-qa"

# 查看日志
docker logs -f financial-rag-qa
docker logs --tail 100 financial-rag-qa

# 进入容器
docker exec -it financial-rag-qa /bin/bash

# 重启
docker restart financial-rag-qa

# 更新镜像
docker pull financial-rag:v10.0
docker stop financial-rag-qa && docker rm financial-rag-qa
docker run -d ... financial-rag:v10.0  # 同上参数

# 清理 (保留数据卷)
docker rm -f financial-rag-qa
# 彻底清理 (删除数据!)
docker rm -f financial-rag-qa
docker volume rm rag_data rag_cache rag_logs rag_shared
```

## 八、生产部署


### 8.2 直接在服务器构建

```bash

scp -r 项目工单 server:/opt/
ssh server
cd /opt/项目工单
bash 工单10/部署/run_docker.sh
```

### 8.3 Systemd 守护 (可选)

```ini
# /etc/systemd/system/financial-rag.service
[Unit]
Description=Financial RAG QA System
After=docker.service
Requires=docker.service

[Service]
Type=oneshot
RemainAfterExit=yes
ExecStart=/usr/bin/docker start financial-rag-qa
ExecStop=/usr/bin/docker stop financial-rag-qa

[Install]
WantedBy=multi-user.target
```

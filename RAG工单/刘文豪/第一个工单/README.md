# 工单01：基于 PDF 文档的问答系统

> 工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统 ｜ 工时预估：2 人日（实际远低于此）

## 一、做了什么

针对《招股说明书1.pdf》（武汉兴图新科电子股份有限公司，333页）搭建完整 RAG 问答系统：

```
parse_pdf.py    步骤1  PDF解析   PyMuPDF 按页提取文本，清洗页眉页脚/页码
build_index.py  步骤2  分块+向量化+入库
rag.py          核心    检索+生成（可复用）
demo.py         演示    跑工单问题列表，输出 演示结果.md
```

技术栈（全部为本机已有环境，零下载）：
- 解析：PyMuPDF (fitz) 1.28
- 分块：固定窗口 600 字符 + 120 重叠，按页保留元数据
- 向量化：**BGE-M3**（Ollama 本地端点，1024维）
- 向量库：**ChromaDB** 持久化（cosine），667 块
- 生成：**qwen2.5:7b**（Ollama 本地，temperature=0.1）
- Python：D:\anaconda3 base（3.12.7）

## 二、如何运行

```bash
cd D:\桌面\工单\第一个工单
D:\anaconda3\python.exe parse_pdf.py     # PDF -> data/pages.json
D:\anaconda3\python.exe build_index.py   # 分块+嵌入+入库 chroma_db（约4分钟）
D:\anaconda3\python.exe demo.py          # 官方问题列表问答 -> 演示结果.md
```

前置：本机 Ollama 已运行且有 `bge-m3`、`qwen2.5:7b` 两个模型（本机均已存在）。

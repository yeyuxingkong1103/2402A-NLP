# 工单06：向量、全文与混合检索

工单编号：人工智能NLP-RAG-混合检索任务。

本版本延续工单05对话功能，增加向量检索、倒排全文检索和混合检索。侧栏可选 m3e/BGE 嵌入模型、检索方式、向量权重、融合算法、TF-IDF/LLM/用户反馈重排、全文字段和模糊匹配。

## 运行

1. 安装 Python 3.10+，运行 `python -m pip install -r requirements.txt`。
2. 上传《招股说明书1.pdf》和《招股说明书2.pdf》，选择嵌入模型并点击“解析并建立索引”。更换嵌入模型后要分别重建索引。
3. 启动 `启动网页.ps1`，打开 `http://127.0.0.1:8501`。
4. 在侧栏选择向量、全文或混合检索，调整向量权重和融合方式。全文框支持 `AND`、`OR`、`NOT`、引号短语和模糊匹配。
5. 选择 TF-IDF、LLM 或用户反馈重排。LLM重排需要可用的 OpenAI 兼容服务；反馈重排使用页面“反馈”保存的有帮助/无帮助记录。

全文索引把正文首行作为标题、正文前240字作为摘要，并保留完整正文；字段不来自PDF元数据。`python test_hybrid_retrieval.py` 用小型固定语料验证算法分支；`python evaluate_hybrid.py` 在招股说明书2的350页既有索引上重跑6道表格/图像题。向量、全文和混合策略的答案关键词覆盖均为6/6，支持证据关键词召回均为6/6；最大单题检索用时分别约0.56、0.53、0.48秒。表格证据按检索到的表格ID展开整表，图像证据包含OCR标签及从标签计数的部门/销售处数量。该自动关键词指标不代表人工语义准确率，也不代表其他文档；真实LLM重排和并发负载未测。

新检索测试截图在 `问答引擎/混合检索测试截图/`；`完整操作演示.mp4` 和 `检索策略讲解.mp4` 是图文幻灯演示。原始PDF和本机向量索引不放入提交包。

# 基于 PDF 文档的问答系统

> 工单编号：人工智能 NLP-RAG 项目 01：基于 PDF 文档的问答系统

本项目以《招股说明书1.pdf》为知识库，提供 PDF 解析、向量与字面检索、问题拆分、带页码的回答、知识库管理和反馈功能。主程序和评估脚本放在本目录；按工单功能分为“PDF 解析模块”“问答引擎”“问答界面”“知识库管理”四个目录，每个目录内含对应验证截图。

## Windows 启动

1. 安装 Python 及依赖：`python -m pip install -r requirements.txt`。
2. 安装并启动 Ollama，在 PowerShell 中运行 `ollama pull deepseek-r1:1.5b`，再运行 `ollama serve`。
3. 将工单附件《招股说明书1.pdf》放进 `data/uploads/` 文件夹，文件名保持为 `招股说明书1.pdf`。PDF 与本机向量索引不提交到仓库。
4. 在另一个 PowerShell 窗口进入本目录，运行 `powershell -ExecutionPolicy Bypass -File .\启动网页.ps1`。
5. 浏览器打开 `http://127.0.0.1:8501`，选择知识库并提问。首次使用时点击“解析并建立索引”。

## 评估与测试

- `evaluate.py` 和 `questions.json`：重跑工单指定的十道题。
- `评估结果.json`：本机模型的原始回答、最终回答、证据页码和用时。
- `RAG评估报告.md`：纯 LLM 与 RAG 对比及评估说明。
- `测试记录.md`：测试项目和逐项截图链接。
- `演示视频.mp4`、`演示脚本.md`：界面操作演示材料。

本次十题的最终答案关键词覆盖为 10/10；该指标不能替代人工准确性评审。网页回答未稳定达到工单的 3 秒要求，录音控件可显示但语音转写尚未完成实测，详见评估报告。

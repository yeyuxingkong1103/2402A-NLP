## 1 原结论

`研发/data/reports/quality_report_full.json` 的 `summary`：

```
total_files      : 1700
corrupted_files  : 83          ← 被记为「损坏文件」，占 4.88%
pdf_types        : Text_PDF 1063 / Scan_PDF 553 / Mixed_PDF 1 / Corrupted 83
```

`pending_lists.corrupted_files` 中 83 条的 `action` 均为「移入隔离区，人工复核或重新获取原件」，
`error` 文本**全部**为：

```
"unhandled: MemoryError: "
```

## 2 复检过程与证据

| 步骤 | 做法 | 结果 |
| --- | --- | --- |
| ① 看报错文本 | 统计 83 条的 error 前缀 | **83/83 全是 `MemoryError`**，不是格式类异常（不是 `cannot open` / `damaged`） |
| ② 抽检文件可用性 | 抽 8 份用 pymupdf 直接打开并读前 5 页文本 | **8/8 全部可正常打开**，前 5 页均可读出文本 |
| ③ **决定性复跑** | 用 CLI 指定这 83 份，**单进程**（`--workers 1 --no-resume`）复跑 | **83/83 全部成功、错误 0 条、耗时 2.4 s**；分类为 **Text_PDF 14 + Scan_PDF 69**，**Corrupted = 0** |

**结论**：这 83 份**不是损坏文件**。真实原因是**质检时的并行 worker 内存竞争**——
多进程同时解析大页数 PDF 时触发 `MemoryError`，被质检流程归类为「损坏」，
从而**误报**并掩盖了 4.88% 的文件。

## 4 可行动的改进项

| # | 改进 | 理由 | 状态 |
| --- | --- | --- | --- |
| 1 | **质检结论中「损坏」清零**，并改为「未分析」口径 | 避免把内存问题误报为数据问题 | 已在本记录说明；原始 `quality_report_full.json` 保留不动（作为误报证据） |
| 2 | **按内存约束下调并行度**：大页数 PDF 降级为单进程；或给 `performance.max_workers` 加上「可用内存 < X GB 时自动降为 1」的保护 | 本次实证：`--workers 1` 下 83/83 成功，多进程下 83/83 失败 | 建议写入 `研发/assessment_config.yaml` |
| 3 | **质检流程区分「文件问题」与「处理问题」**：`MemoryError`/`TimeoutError` 应进「未分析」桶而非「损坏」桶 | 语义正确性；影响下游对语料的判断 | 建议改 `detectors.py` 的异常归类 |
| 4 | **扫描型占比上修到 36.59%**，说明对 OCR 路径的依赖比原报告更大 | 本机无 OCR 引擎（cv2/pytesseract/paddleocr/easyocr/onnxruntime 全缺），影响面需重估 | 已登记进 `_交付核验总表.md` §七 |

## 6 扫描型 PDF 补 OCR 的可行性实测（2026-10-16）

### 6.1 问题

全量修正后 1700 份中 **Scan_PDF 622 份（36.6%）无文本层**，原报告只能记为
「扫描型 → 需 OCR」，而本机此前**无任何 OCR 引擎**，这部分内容（占语料 1/3 以上）无法进入 RAG。

### 6.2 抽样实测（`研发/scripts/扫描件OCR抽样.py`）

对 622 份均匀抽 **10 份**，每份 OCR 前 2 页（控额度）：

| 指标 | 实测值 |
| --- | ---: |
| 抽样份数 | 10 |
| **OCR 成功页 / 总页** | **20 / 20（100%）** |
| 识别字符合计 | **11,680** |
| 平均每页字符 | **584** |
| OCR 调用次数 | 20 |
| 耗时 | 26.5 s |

**结论：补 OCR 完全可行** —— 全部成功、内容量可观（平均 584 字符/页，
即每份扫描件约 4000+ 字符可用于检索）。

### 6.3 全量成本推算

| 项 | 推算 |
| --- | --- |
| 抽样平均页数 | 7.1 页/份 |
| **全量调用次数** | 622 × 7.1 ≈ **4416 次** |
| **全量耗时** | ≈ **98 分钟** |
| 额度 | 取决于账号免费额度；本次抽样消耗 20 次 |

### 6.4 结论与建议

| 项 | 说明 |

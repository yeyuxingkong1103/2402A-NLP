# 技术文档（增量部分）

---

## 1. 系统架构

```text
离线：
年报文本 → LLM 抽取三元组 → NetworkX 图 → kg_graph.json

在线：
问题 → 图谱实体识别 → 邻居三元组 ─┐
     → 向量检索 → top4 文本块 ───┼→ 融合 → LLM 生成
                                 │
                         返回答案 + 图谱路径
```

---

## 3. 核心方法

- `_extract_entities(question)`：从问题中匹配图谱节点。
- `_get_graph_context(entities, max_triples=15)`：提取邻居三元组。
- `ask(question)`：重写父类方法，融合图谱上下文。

# 部署文档 · 招股说明书多轮检索问答系统

> 工单编号：人工智能 NLP-RAG-Query 理解优化任务

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10/11（Linux/macOS 亦可） |
| Python | 3.10 及以上 |
| 本地模型服务 | Ollama（`bge-m3:567m` 嵌入模型；`deepseek-r1:1.5b` 可选） |
| 内存 | ≥ 4 GB（向量库约 10 MB，模型由 Ollama 托管） |
| 网络 | 仅首次拉取 Ollama 模型需要；运行期可完全离线 |

---

## 2. 安装步骤

### 2.1 安装 Ollama 与模型

```powershell
# 安装 Ollama 后启动服务
ollama serve
# 拉取所需模型
ollama pull bge-m3:567m
ollama pull deepseek-r1:1.5b   # 可选（英文翻译 / LLM 改写）
```

### 2.2 安装 Python 依赖

```powershell
cd 研发
pip install -r requirements.txt
```

### 2.3 配置

编辑 `研发/.env`（或设置同名环境变量）：

```ini
OLLAMA_BASE_URL=http://localhost:11434
EMBEDDING_MODEL=bge-m3:567m
LLM_MODEL=deepseek-r1:1.5b
TOP_K=5
USE_LLM_REWRITE=0
DOC_FILTER_ENABLE=1
```

## 3. 启动流程

```powershell
# 1) 构建知识库（首次；解析 898 页 → 2352 切片 → 向量化约 7 分钟）
python build_kb.py --rebuild

# 2) 命令行多轮演示
python run_demo.py

# 3) 评测（准确率 / 响应时间）
python evaluate_multiturn.py

# 4) Web 界面
streamlit run app.py
# 浏览器打开 http://localhost:8501
# 演示回放：http://localhost:8501/?demo=1
```

---

## 4. 一键部署脚本

见同目录 `run_all.ps1`，依次完成「依赖检查 → 构建知识库 → 演示 → 评测 → 启动界面」。

```powershell
powershell -ExecutionPolicy Bypass -File run_all.ps1
```

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报「未找到知识库」 | 未构建索引 | 运行 `python build_kb.py --rebuild` |
| 向量化报连接错误 | Ollama 未启动 | 执行 `ollama serve`，确认 11434 端口 |
| 首问耗时偏高 | 冷启动 | 系统已内置 `warmup()` 预热；如仍偏慢可先问一次热身 |
| 答案提示「未检索到相关内容」 | 问题超出文档范围（相关性低于阈值） | 换用与招股说明书相关的问题 |
| 英文答案未翻译 | 未勾选翻译 | 界面勾选「英文模式自动翻译答案」 |
| 端口被占用 | 8501 已使用 | `streamlit run app.py --server.port 8502` |

# 工单七任务说明：功能测试及评估任务

> 工单编号：人工智能NLP-RAG-功能测试及评估

## 一、背景

- 工单一至工单六已完成 RAG 系统：PDF 解析入库（文本/表格/图像三路）、多文档知识库、图文融合问答、多轮对话与反馈、向量/全文/混合三策略检索与三类重排器
- **工单七（本工单）**：使用 01-06 工单实现的 RAG 系统，对附件 `ccf_competition.zip` 中的 PDF 实现 RAG 测试及检索评估；基于 `sample_questions.pdf` 示例问题整理 10 个问题并完成测试，通过评估框架评估检索结果，分析检索存在的问题

## 二、任务要求（工单原文）

1. 对 `ccf_competition.zip` 中的 PDF（9 份 A 股上市公司年度报告）构建语料，用 01-06 工单的 RAG 系统实现 RAG 测试
2. 使用 `sample_questions.pdf` 中的示例问题进行问题整理及测试
3. 通过评估框架评估检索结果：**输出 10 个问题及对应的 RAG 检索结果、RAG 评估结果，并分析检索结果存在的问题**
4. 工时预估：1 人日

## 三、验收标准

## 四、实施内容

### 4.1 语料准备（复用工单管线，不新增 RAG 组件）

脚本：[scripts/prepare_ccf_reports.py](../../scripts/prepare_ccf_reports.py)

- 解压 `ccf_competition.zip`（zip 内文件名为 GBK 字节被 zipfile 按 cp437 解码，需 `raw.encode('cp437').decode('gbk')` 还原中文文件名），规范命名落 `data/ccf_reports/`，生成注册表 `ccf_corpus.json`
- PyMuPDF 逐页抽文本（9 份年报均为文本型 PDF，无需 OCR），复用工单三 `src.chunker.chunk_parsed_document`（chunk_size=600/overlap=120，表格感知）
- 复用工单二 `src.embedding.get_embedder`（bge-m3）与 `src.vector_store.VectorStore` 入 `rag_chunks`；按 doc_id 先删后插，幂等可重跑；年报语料与招股书以 doc_id 隔离共存

语料清单：平安银行/中国平安/招商银行/邮储银行（2019）、中信证券/中国人寿（2020）、招商证券/中国太保/国泰君安（2021），共 9 份、2812 页、约 297 万字。

### 4.2 测试问题整理

文件：[test_questions_v7.json](../data/ccf_reports/test_questions_v7.json)

- Q1/Q2/Q10 改编自 `sample_questions.pdf` 四道示例题（示例中"xx银行"按内容落到具体公司；经全文核实，"逾越者联盟"出自**招商银行**年报而非平安银行）
- Q3~Q9 针对各年报命制的事实题（营收/保费/净利润/股息等，答案数字均已逐一核实）
- 每题含：doc_id 过滤值（Q10 跨文档题为 null）、gold_docs、金标关键词组（同义词归一化、数字去千分位）、参考答案要点

### 4.3 评估框架

模块：[src/evaluation_v7.py](../../src/evaluation_v7.py)（纯函数，不依赖 Milvus/模型，可单测）

| 指标 | 含义 |
| --- | --- |
| doc_recall@5 | top5 检索结果中金标文档覆盖率（跨文档题按命中文档比例） |
| MRR | 首个金标文档出现排名的倒数 |
| context_recall | 金标关键词在检索上下文中的覆盖率 |
| answer_acc | 金标关键词在 RAG 答案中的全命中率 |
| noise_docs | top5 中混入的非金标公司文档（跨公司串档） |
| issues | 自动归类：金标文档漏检/排序靠后/串档/关键词缺口/答案漏点/超时(>3s) |

### 4.4 测试与产出

- 编排脚本：[scripts/evaluate_v7.py](../../scripts/evaluate_v7.py)（warmup → 10 题 RAG → 评估 → 落盘）
- 完整结果：[eval_v7_results.json](./eval_v7_results.json)（每题答案 + top5 检索结果 + 指标 + 问题标签 + 汇总）
- 测试报告：[08_功能测试评估报告.md](./08_功能测试评估报告.md)
- 单元测试：[tests/test_evaluation_v7.py](../../tests/test_evaluation_v7.py)（9 用例，指标计算/归一化/问题归类/汇总）
- 演示视频：按工单要求自行录制，不入代码库

## 五、与工单六的差异（不做多余事情）

- 不新建服务/接口/界面：工单七是测试评估任务，在脚本中实例化既有 RAGEngineV6 完成
- 表格/图像通道：年报语料仅入文本 chunk，10 题均为文本题，测试时显式关闭表格/图像通道，避免空通道噪声干扰检索评估
- 年报全部为文本型 PDF，直接 PyMuPDF 抽文本 + 既有 chunker，不引入 OCR/版面解析新管线

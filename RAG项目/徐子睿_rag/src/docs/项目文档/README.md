## 三、技术栈（现状）

- **数据**：MinerU 版面解析（复杂版面/表格/公式，回退 pypdf）；两种分块并存——GB_T_44653 用 **v6 语义分块**（178 原子单元 → 47 块，语义类型 7 类 + 关键词）；其余 4 份文档走**通用管线分块**（章节结构切分 ≤400 字 + 重叠 40）
- **库规模**：5 份国标文档 / **563 块** / 563 个 1024 维向量，collection `rag_docs_v6`（Milvus standalone）
- **后端**：FastAPI 单服务（同时提供 API + 托管前端）；构建任务后台线程 + 前端轮询
- **前端**：原生 HTML/CSS/JS（无框架、无 CDN）；`static/` 下 index.html + styles.css + js/（按页签分成 7 个脚本），**按 RAG 流程 4 页签：① 构建链路 → ② 知识库 → ③ 检索链路 → ④ 示例问答**
- **检索（V3 链路）**：查询改写（规则化术语扩写）→ 双路召回（bge-m3 向量 top20 + jieba BM25 top20）→ **加权 RRF 融合（λ=2.5）** → **LLM 候选精排**（qwen2:7b 0-5 分，失败回退 RRF）→ 上下文组织（预算 3600 字符）
- **LLM**：Ollama `qwen2:7b`（问答生成 + 候选精排；引用溯源 + 无依据拒答 —— 向量召回门限 cosine 0.5，候选被过滤光即固定拒答）
- **评测**：page 级 recall@5 / MRR / refusal_accuracy（历史迭代在单文档 47 块库上完成，V3 链路在新库 563 块实测通过）

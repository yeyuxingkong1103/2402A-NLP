# n8n 原理学习笔记

## 核心原理

n8n 将可视化流程保存为 JSON 工作流定义。执行引擎读取节点和连接，构建有向无环图，按照依赖关系调度节点，数据以 items JSON 数组沿连接传递，最终形成“触发、执行、流转、结束”的自动化闭环。

## 三层架构

1. UI 层：基于可视化画布编辑节点和连线。
2. 引擎层：负责拓扑排序、节点执行、数据传递、重试和错误处理。
3. 存储层：保存工作流、凭证、执行记录和节点状态，可使用 SQLite 或 PostgreSQL。

## 主要组件

- Trigger：Webhook、Cron、RSS、Manual Trigger。
- Action：HTTP、数据库、文件、邮件和 API 请求。
- Logic：IF、Switch、Merge、Loop、Code。
- Data：items、字段映射、表达式和执行上下文。
- Persistence：工作流定义、执行日志、凭证和队列。

## 设计思想

通过节点化、声明式和可组合的方式，把复杂业务拆成可观察、可重试、可复用的步骤；数据沿连接流动，节点只关注输入到输出的转换。

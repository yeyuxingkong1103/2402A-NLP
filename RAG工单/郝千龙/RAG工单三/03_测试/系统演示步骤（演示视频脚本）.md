# 系统演示步骤（演示视频脚本）

**工单编号：人工智能NLP-RAG-PDF文档的表格解析及检索优化**
**预计时长：6～8 分钟**
**演示环境：** Windows + PowerShell + Python 3.12，纯 CPU、离线（不访问外网）

---

## 镜头 0：片头与工程结构（约 30 秒）

**画面：** 资源管理器打开 `RAG工单三` 目录。

**解说词：**
“本项目为 RAG 工单三——PDF 文档表格解析及检索优化。语料为两本招股意向书：兴图新科 548 页、力源信息 350 页。工程按五个阶段交付：01 设计、02 研发、03 测试、04 优化、05 部署。”

依次点开：
- `01_设计/表格解析优化方案设计文档.md`
- `02_研发/src/`（10 个 Python 模块）
- `03_测试/评测结果.csv`
- `04_优化/优化前后表格检索精确度对比报告.md`
- `05_部署/部署说明.md`

## 镜头 1：离线建库（约 60 秒）

**画面：** PowerShell。

```powershell
cd RAG工单三\02_研发\src
python build_index.py
```

**解说词与画面要点：**
- 日志显示逐本解析：“表格解析=开启”，兴图新科 3,472 个 Block（251 张表）、力源信息 2,345 个 Block（147 张表）；
- 分块统计：“共 8,192 个检索块——整表块 398，行块 2,332，正文块 5,462”；
- 嵌入提示：“未检测到本地模型缓存，启用离线 TF-IDF 字符向量（不联网下载）”，强调**全流程离线**；
- 打开 `02_研发/index_store/`，展示 vectors.npz、chunks.pkl、bm25.pkl、tfidf.pkl、meta.json 五个持久化文件。

## 镜头 3：基线对照（约 45 秒）

**画面：**

```powershell
python build_index.py --baseline
python evaluate.py --baseline
```

**解说词：**
“基线模拟优化前的朴素链路：关闭 pdfplumber 表格解析，表格被拍平为纯文本并按 450 字定长滑窗切分，同时关闭公司路由。实测基线 10/14：不存在控制关系关联方 7 家枚举、军品 4 期收入、军品 4 期占比三题被错版表格拍平与跨表混切击败，法定代表人一题被定长窗口拼入的无关姓名污染。优化链路达到 14/14，gold 项覆盖从 20/36 提升到 36/36。”

## 镜头 4：Streamlit 问答界面——表格题演示（约 90 秒）

**画面：**

```powershell
streamlit run app.py
```

浏览器自动打开后，左侧边栏演示切换 **中文 / English** 双语界面。

依次点击示例问题并提问，每题展示“答案 + 耗时 + 证据卡片”：

1. **力源信息本次募集资金拟投资哪些项目？**
   - 答案：5 个项目按表格序号 1→5 列出，含计划总投资；
   - 展开 #1 证据：绿色高亮“命中表格行”，下方 DataFrame 渲染 P22 募投整表；
   - 耗时约 0.02 秒。
2. **力源信息与公司不存在控制关系的关联方企业有哪些？**
   - 答案：7 家企业 + 与本公司关系；
   - 证据表标题显示“2、不存在控制关系的关联方”，强调两张同页表的精确区分。
3. **兴图新科来自军用领域的收入分别是多少？**
   - 答案：6,464.51、14,414.16、18,780.67、4,627.14 万元（并带出四期占比）；
   - 证据展示 P185/P129 表格行与页码，说明表格行陈述句（Small-to-Big 子块）召回、整表溯源。
4. **兴图新科的法定代表人是谁？**
   - 答案：程家明；证据 Top1 为 P52/P22 发行人资料卡（而非中介机构声明页），展示主体排噪效果。

## 镜头 6：片尾总结（约 30 秒）

**画面：** 切回 `03_测试/评测结果.csv` 与 `04_优化/优化前后表格检索精确度对比报告.md`。

**解说词（字幕同步）：**

- 准确率：基线 10/14（71.4%）→ 优化 **14/14（100%）**；
- gold 覆盖：20/36 → **36/36**；表格题 4/7 → **7/7**；
- 每页响应 ≤ 3 秒（实测最大 0.61 秒）；
- 核心技术：词坐标网格表格重建 + 质量门控 + 整表/逐行双层块 + 双路召回 RRF + 表格感知精排 + 表格行/单元格答案抽取；
- 全流程纯 CPU、离线可复现。

## 2. 新增方法

### 2.1 `_needs_resolution(question)`

判断问题是否需要指代消解：

```python
def _needs_resolution(self, question):
    if len(question.strip()) < 10:
        return True  # 过短，可能是省略句
    for p in self.PRONOUNS:
        if p in question:
            return True  # 含指代词
    return False
```

指代词列表：他、她、它、他们、这个公司、该公司、这家公司、那家公司、此公司、这个、那个、此、该、上述、前面、呢、那么、那

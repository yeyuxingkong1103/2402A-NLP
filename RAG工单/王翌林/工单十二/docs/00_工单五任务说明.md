# 工单五任务说明：Query 理解优化（多轮对话）

> 工单编号：人工智能NLP-RAG-Query 理解优化任务

## 一、背景

- 工单四已实现图文表三路融合 RAG（文本+表格+图像检索），单轮问答准确率 100%
- **工单五（本工单）**：在工单四基础上增加**多轮对话能力**，实现指代消解、实体追踪、追问改写，支持连续追问

## 二、核心目标

1. **多轮对话**：用户可连续提问，系统理解上下文（代词指代、实体切换、问法复用）
2. **指代消解**：自动识别"他/这个公司/其"等代词，关联到当前讨论的公司实体
3. **实体切换**：识别"那X呢？"句式，切换到新实体并复用前一轮问法
4. **会话管理**：基于 session_id 维护对话历史与当前实体状态
5. **用户反馈**：支持点赞/点踩/评论

## 三、5 轮验收对话

| 轮次 | 问题 | 期望消解 | 期望答案要点 |
|------|------|----------|--------------|
| 1 | 报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？ | direct | 2016/2017/2018 军用收入（万元） |
| 2 | 他参与的哪个工程荣获了国家科技进步一等奖？ | 他→兴图新科 | C4ISR 工程 |
| 3 | 这个公司的法定代表人是谁？ | 这个公司→兴图新科 | 程家明 |
| 4 | 那武汉力源信息技术股份有限公司呢？ | 切换到力源信息+复用"法定代表人"问法 | 赵马克 |
| 5 | 武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？有哪些销售处？ | direct | 大客户销售部，6 个销售处 |

## 四、验收标准

| 指标 | 要求 |
|------|------|
| 问答准确率 | ≥ 90% |
| 指代消解正确率 | ≥ 90% |
| 响应时间 | ≤ 3 秒 |
| 语言支持 | 中英文问答 |
| 交互 | 支持多轮对话 + 用户反馈 |
| 稳定性 | 高可用、容错 |

## 五、技术方案

```
用户提问 → 指代消解（规则+实体追踪）
         → 问句改写（代词→实体 / 那X呢→实体+复用问法）
         → RAGEngineV4.ask（图文表三路检索 + LLM 生成）
         → 更新会话状态（历史 + 当前实体 + 最后问法）
         → 返回答案 + 消解可视化
```

- **消解策略**：确定性规则（不引入额外 LLM 调用，保障 ≤3s）
  1. `switch_entity_reuse_intent`：那X呢 → 切换实体 + 复用 last_intent
  2. `pronoun_resolution`：他/这个公司/其 → 当前实体
  3. `inherit_entity`：无代词无新实体 → 继承当前实体
  4. `direct`：问句含完整公司名 → 直连

## 1. 主流程（端到端）

```mermaid
flowchart TD
    A0["开始：运行 研发/评估/运行评估.py"] --> A1["参数解析：--ids 题号过滤 / --limit 前 N 题 / --out-suffix 烟测后缀"]

    A1 --> A2{"索引就绪检查<br/>读取 研发/data/index/index_manifest.json"}
    A2 -->|"清单不存在"| W_INDEX["告警：[索引] !! 未找到 …（**继续跑**，不中止）<br/>后续通常表现为逐题异常"]
    A2 -->|"存在"| A3{"chunk_total ≥ INDEX_MIN_CHUNKS(8000)?"}
    A3 -->|"否"| W_SMALL["告警：索引可能未重建完成（继续跑）"]
    A3 -->|"是"| B
    W_INDEX --> B
    W_SMALL --> B

    B["load_questions(测试问题集.jsonl)<br/>断言 17 题 + 字段完整"] --> C["QAEngine.warmup(with_generate=True)<br/>索引/分词器/词性标注/嵌入/倒排/生成 全部预热<br/>（冷启动首字可达 3.4 s，不预热必超线）"]
    C --> D["engine.health() → backend / model；记录 warmup_ms 进运行元信息<br/>预热轮不计入延迟统计"]

    D --> E{"还有未跑题目?"}
    E -->|"否"| Z["汇总与落盘（见 §5）"]
    E -->|"是"| F["取下一题：question / lang / answer_keywords / expected_pages_hint / source_file"]

    F --> G["evaluate_one(...)：QAEngine.answer(question, lang, use_cache=False)"]
    G --> H{"输入有效性闸门（改写层 R0）"}
    H -->|"空 / 纯空白 / 纯符号 / 乱码"| X_INPUT["strategy=empty_input<br/>refused=true + 固定文案<br/>不崩、不编造、状态不变"]
    H -->|"通过"| I["问句理解：语言判定 + 主体路由（corpus_issuers 公司简称/全称）"]
    I --> J{"问句点名了语料内公司?"}
    J -->|"是（单一公司）"| K1["按语料过滤后检索"]
    J -->|"否 / 同时点名多家"| K2["不过滤（不冒险过滤）<br/>跨文档题与未点名题由此进入候选"]
    K1 --> L["检索层：默认混合链路<br/>向量 FAISS IndexFlatIP + BM25(jieba) → 融合 + 重排<br/>top_k = TOP_K = 10"]
    K2 --> L
    L --> M["hit_brief() 记录 top-10 片段<br/>（chunk_id / page / type / final_score / 文件）"]
    M --> N{"可答性闸门<br/>coverage / 向量余弦 / 词表外实体"}
    N -->|"不达标"| X_REFUSE["拒答：refused=true + 「不清楚」<br/>HTTP 200（不是 5xx）<br/>reason ∈ low_coverage/low_similarity/unknown_entity/no_hits"]
    N -->|"达标"| O["answer_composer 确定性草稿"]
    O --> P["LLM 润色：Ollama qwen2.5:3b"]
    P --> Q{"原子保全护栏：候选是否含草稿全部原子（数字/字符串）?"}
    Q -->|"通过"| R1["采用 LLM 候选答案"]
    Q -->|"拒绝"| X_GUARD["异常 E4：llm_rejected_reason=atoms_missing<br/>回退规则拼接草稿（数字正确、可读性下降）<br/>记录 llm_candidate / missing_atoms / draft_atoms"]
    R1 --> S["构造引用（cited_pages / citations，1-based 物理页码）"]
    X_GUARD --> S
    S --> T["判分（判分.py 纯函数，确定性，禁用 LLM 自评）"]
    X_REFUSE --> T
    X_INPUT --> T
    T --> U["normalize → keyword_coverage → is_correct / partial_correct"]
    U --> V["retrieval_recall_at_k(K=5) / (K=10)（同一批 top-10 的合并正文）"]
    V --> W["page_hit / cross_corpus_leak(top3 与 top10) / citation_leak / atomic_coverage"]
    W --> W2["索引全库可达性诊断 build_index_reach：<br/>区分「索引里根本没有」与「索引有但没召回」"]
    W2 --> E
```

```mermaid
flowchart TD

    T0 -->|"去空白后为 ''（纯空格/全角空格/制表换行）"| E_BLANK["纯空格输入<br/>→ 与空输入同一处置路径"]

    T0 -->|"乱码/不可解码"| E_MOJI["乱码输入<br/>→ 不崩（判分侧 normalize 已把控制符/未分配字符剔除）<br/>→ 拒答或如实记录降级；不得抛 UnicodeError 到上层"]

    T0 -->|"中文正常问句"| OK["进入主流程检索与生成"]

    E_EMPTY --> R["记录：refused / answer / 状态快照"]
    E_BLANK --> R
    E_SYM --> R
    E_MOJI --> R
    E_LONG --> R
    E_INJECT --> R
    E_EN --> R2["记录：language / zh_query / 答案 / 引用 / 延迟 / language_degraded"]
    OK --> R2
```

## 3. 异常分支细化（环境侧，**与运行评估.py 的真实行为一致**）

```mermaid
flowchart TD

    S1 -->|"否"| E1["打印 `[索引] !! 未找到 …`<br/>**不中止、也不返回专属退出码**<br/>→ 随后 QAEngine 加载索引失败 → 逐题 error"]

    E2 --> S3

    E5 --> S8{"连续异常 ≥ 3?"}
    S8 -->|"是"| E6["打印「疑似引擎/索引不可用，中止全量评估」<br/>→ 对已跑题汇总落盘（异常题数 > 0）"]
    S8 -->|"否"| S7
    S7 --> S9{"还有题?"}
    S9 -->|"是"| S5
    S9 -->|"否"| S10["进入汇总与落盘"]
```

## 4. 退出码 / 状态码语义（**判读陷阱在最后一行**）

### 4.1 `研发\评估\运行评估.py`（本工单主评估入口）

| 情形 | 退出码 | 语义 | 处置 |
| --- | --- | --- | --- |
| 正常跑完并落盘 | `0` | 流程成功（**指标可能未达标**） | 看 `评估汇总.json` 判定达标与否 |
| 顶层异常（未捕获，`traceback` 打进日志） | `1` | 框架自身失败 | 先修框架，再谈指标 |
| **含异常题 / 连续 3 题异常中止** | **仍可能是 `0`** | 流程"跑完"了，但存在失败题 | **必须看** `评估汇总.json` 的 `异常题数` / `异常题号`，以及 `评估运行日志.txt`；**只看退出码会漏报** |
| 索引缺失 | 无专属码 | 仅告警，随后逐题异常 | 先建索引；或按 `异常题号` 判断是否为环境问题 |
| Ollama 不可用 | 无专属码 | 健康检查暴露 `backend=None`，逐题异常 | 起 Ollama 后重跑；**不得**把环境失败写成「准确率 0%」 |
| 拒答（业务态） | `refused=true` | **不是错误**，是可答性闸门的正常输出 | 按 M7 统计并归因（`拒答.按原因`） |
| 空/纯空格/纯符号/乱码 | `strategy=empty_input` | 异常输入**期望**的结果 | 用例判据 = 「不崩 + 不编造 + 状态不变」 |
| 守卫拒绝回退 | `llm_rejected_reason=atoms_missing` | LLM 候选缺原子被拒 | 答案仍可用（数字正确），但须在报告点名可读性下降 |
| 烟测运行 | `--out-suffix` 加后缀 | 产物名为 `评估结果_<后缀>.csv` 等，**不覆盖交付物** | `评估运行日志.txt` 文件名恒定（不随后缀改名） |

### 4.2 `测试\冒烟自检.py`（建索引后的最小代价冒烟，**退出码语义不同**）

| 退出码 | 语义 |
| --- | --- |
| `0` | 全部通过（索引加载 / 检索 / 生成 / 多轮 / 异常兜底） |
| `1` | 断言失败 |
| `3` | 索引缺失（提示先跑 `研发\scripts\build_index.py`） |
| `4` | 后端（Ollama）不可用 |

> ⚠️ **不得混用**：上表的 `3`/`4` 属于**冒烟自检**；`运行评估.py` 不返回这两个码。
> 评估链路的「环境未就绪」要靠 `评估运行日志.txt` + `评估汇总.json.异常题数` 判定。

## 6. 单题评估时序（把上图落到调用顺序）

```mermaid
sequenceDiagram
    participant R as 运行评估.py
    participant C as 配置.py
    participant Q as QAEngine
    participant J as 判分.py

    R->>C: 常量与路径（TOP_K=10 / RECALL_KS=(5,10) / KEYWORD_THRESHOLD=0.6 / SLA_MS=3000）
    R->>Q: warmup(with_generate=True)
    Q-->>R: 预热结果 + warmup_ms（预热轮不计入延迟统计）
    R->>Q: health() → backend / model

    loop 每道题（17 题，串行，use_cache=False）
        R->>Q: answer(question, lang=..., use_cache=False)
        alt 证据不足
            Q-->>R: refused=true + 「不清楚」（HTTP 200）
        else 证据充分
            Q-->>R: answer / cited_pages / citations / latency_ms / generation_method
            Note over Q,R: 若 LLM 候选缺原子 → llm_rejected_reason + missing_atoms + 草稿回退
        end
        R->>J: keyword_coverage / is_correct / partial_correct
        R->>J: retrieval_recall_at_k(K=5) 与 (K=10)
        R->>J: page_hit / cross_corpus_leak(top3, top10) / citation_leak / atomic_coverage
        R->>R: 追加一行 record（含 judge / gate / generation / hits / index_reach）
    end

    R->>R: build_summary → 评估汇总.json；build_analysis → 检索问题分析.md
```

## 7. 异常分支 ↔ 用例的对应（详见 `设计\测试用例设计.md`）

| E3 空输入 | `question=""` | 不崩 + 拒答 + 状态不变 | TC-A01 |
| E3 纯空格 | `question="   "` / 全角空格 | 同上 | TC-A02 |
| E3 纯符号 | `"!@#$%^&*()"` | 不崩 + 拒答 | TC-A03 |
| E3 乱码 | 非法/乱码字符序列 | 不崩（判分 `normalize` 已剔除控制符） | TC-A04 |
| E3 超长输入 | 粘贴超长文本 | 不崩 + 固定策略 + 耗时如实记录 | TC-A05 |

| E4 守卫拒绝回退 | 观察 `llm_rejected_reason=atoms_missing` 的题 | 数字正确、可读性下降；报告点名 | TC-A08 |
| 跨语料泄漏 | 「平安银行2019年营业收入」类问句 | 命中与引用均属点名语料（修复后） | TC-A09 |
| 多轮无历史指代 | 新会话首轮问「它的拨备覆盖率是多少？」 | 消解不生效 + 不编造主体 + 拒答 | TC-M04 |

## 二、环境要求

| 组件 | 要求 | 备注 |
|------|------|------|
| **OS** | WSL2 Ubuntu 22.04 / Linux x86_64 | Windows 11 + WSL2 推荐 |
| **Python** | 3.10.x | conda 或 venv 均可 |
| **CUDA** | ≥ 12.1 | NVIDIA GPU 驱动 ≥ 525.60 |
| **内存** | ≥ 16GB | bge-m3(128M) + bge-reranker(2.2GB) |
| **磁盘** | ≥ 20GB | 模型 5GB + Milvus 数据 + MySQL |
| **GPU** | ≥ 6GB VRAM | reranker FP16 推理 |
| **MySQL** | 8.0+ | 默认端口 3307 |
| **Milvus** | 2.6+ | 默认端口 19530（推荐 Lite 模式零配置） |

## 四、分步部署

### 4.1 环境安装

**方式 A：conda（推荐新机器）**
```bash
bash scripts/install_conda_env.sh
conda activate rag_pdf_qa
```

**方式 B：复用已有 venv**
```bash
# 当前开发环境已配置好 venv
export PYTHON_BIN=/home/dabaie/code/my_project/.venv/bin/python

# 验证
$PYTHON_BIN --version    # Python 3.10.12
$PYTHON_BIN -c "import torch; print(torch.cuda.is_available())"  # True
```

### 4.2 MySQL 初始化

```bash
# 创建数据库 + 表结构
python scripts/init_mysql.py

# 可选：手动连接
mysql -h localhost -P 3307 -u root -p
  CREATE DATABASE IF NOT EXISTS rag_pdf_qa DEFAULT CHARSET utf8mb4;
  USE rag_pdf_qa;
  SHOW TABLES;
```

### 4.3 Milvus 初始化

```bash
# 创建 collection + HNSW 索引
python scripts/init_milvus.py

# 或用 Lite 模式（零配置）
export MILVUS_MODE=lite
python scripts/init_milvus.py
```

### 4.4 PDF 入库

```bash
# 入库第一个 PDF
python scripts/ingest_pdf.py --pdf "附件/招股说明书1.pdf"

# 常用参数
python scripts/ingest_pdf.py \
    --pdf "附件/招股说明书1.pdf" \
    --chunk-size 600 \
    --chunk-overlap 120 \
    --reset           # 重置 Milvus collection 后重新入库
```

### 4.5 启动/停止

```bash
# 启动（后台 nohup）
bash scripts/start.sh
# → FastAPI PID=data/pids/api.pid → 日志 data/logs/api.log
# → Streamlit PID=data/pids/streamlit.pid → 日志 data/logs/streamlit.log

# 停止（PID 文件优先，端口扫描兜底）
bash scripts/stop.sh

# 查看日志
tail -f data/logs/api.log
tail -f data/logs/streamlit.log
```

## 八、常见问题

### Q1: 路径中文导致脚本报错
A: 所有脚本已对中文路径用单引号包裹。如果仍有问题，可设置：
```bash
export LC_ALL=C.UTF-8
export LANG=C.UTF-8
```

### Q2: conda 创建慢 / solver 冲突
A: 改用 venv：
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
```

### Q3: Milvus Lite 不能启动
A: 检查磁盘剩余空间（至少 2GB），或切换 remote 模式：
```env
MILVUS_MODE=remote
MILVUS_HOST=milvus-standalone
```

### Q4: GPU 显存不足
A: reranker 用 FP16 降低显存（当前默认 `use_fp16=True`），或换用更小的 reranker 模型：
```python
# src/retriever.py 中
self.reranker = FlagReranker(..., use_fp16=True)  # 已开启
```

### Q5: 端口被占用
A: 修改环境变量：
```bash
export APP_PORT=8080 STREAMLIT_PORT=8502
bash scripts/start.sh
```

### Q6: PyTorch 版本与 CUDA 不兼容
A: 从 PyTorch 官网选择对应版本：
```bash
# CUDA 12.1
pip install torch==2.3.1 torchvision==0.18.1 torchaudio==2.3.1 \
    --index-url https://download.pytorch.org/whl/cu121
```

## 九、生产环境建议

| 项目 | 开发 | 生产 |
|------|------|------|
| Milvus | Lite | Standalone/Docker |
| MySQL | 3307 root/pwd | Docker Compose + 独立 volume |
| 模型 | 本地 GPU | 本地 GPU + ONNX 导出 |
| 缓存 | diskcache (磁盘) | Redis Cluster |
| API | uvicorn --host 0.0.0.0 | uvicorn + gunicorn 多 worker |
| SSL | 无 | Nginx 反向代理 + Let's Encrypt |
| 日志 | 本地文件 | ELK / Loki 集中收集 |
| 监控 | 无 | Prometheus + Grafana |
| 备份 | 无 | MySQL 定时 dump + Milvus snapshot |

**Gunicorn 启动示例**：
```bash
gunicorn src.api:app \
    -k uvicorn.workers.UvicornWorker \
    -w 4 --threads 2 \
    --bind 0.0.0.0:8001 \
    --access-logfile - \
    --error-logfile data/logs/api.err.log
```

**Nginx 反向代理示例**：
```nginx
server {
    listen 80;
    server_name rag.example.com;

    location / {
        proxy_pass http://127.0.0.1:8501;  # Streamlit
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8001;  # FastAPI
        proxy_set_header Host $host;
        proxy_http_version 1.1;
        proxy_set_header Connection '';
        proxy_buffering off;  # SSE 流式必须关
    }
}
```

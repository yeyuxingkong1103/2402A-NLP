# 工单四任务说明：PDF文档的图像内容解析及检索优化

> 工单编号：人工智能NLP-RAG-图像内容解析及检索优化
>
> 说明：16 个测试问题由工单三既有 14 题（T01–T14，文本/表格类）+ 工单四新增 2 道图像题（IMG-05、IMG-06）构成；如与工单四原文编号有出入，以原文为准并仅需调整编号映射。

## 一、背景

- 工单一：基础 RAG 问答系统（文本 chunk 入库 + 向量检索 + LLM 问答）
- 工单二：检索优化（混合检索 BM25+向量、bge-reranker 重排序、查询改写、语义分块）
- 工单三：表格解析及检索优化（多文档知识库、表格结构化、表格感知检索、文本+表格 RRF 融合）
- **工单四（本工单）**：图像内容解析及检索优化（PDF 图像提取、多模态图像语义解析、图像向量化入库 `rag_images`、图像感知检索、文本+表格+图像三路融合）

## 二、附件文档

- `/home/dabaie/code/工单/附件/招股说明书1.pdf`（武汉兴图新科电子股份有限公司）
- `/home/dabaie/code/工单/附件/招股说明书2.pdf`（武汉力源信息技术股份有限公司）
- 如附件目录下文件名不同，自动扫描所有 PDF 并按顺序命名。

## 三、核心目标

1. **图像解析**：从 PDF 中提取图像（组织结构图、图表、流程图等），使用多模态模型（CLIP/Chinese-CLIP、BLIP、Qwen-VL 等）生成图像描述与结构化信息，OCR 辅助提取图中文字。
2. **图像检索**：图像内容向量化，存入 Milvus 新 collection `rag_images`；实现图像感知检索，识别问题是否涉及图像并优先检索图像内容。
3. **图文融合**：融合文本、表格、图像三种检索结果，升级 RAG 引擎到 v4。
4. **多文档支持**：延续工单三能力，支持招股说明书1、招股说明书2 及全部文档联合检索。

## 六、技术栈

- Ubuntu 22.04 WSL，Python 3.10 + conda 环境 rag_pdf_qa
- FastAPI + Streamlit，Milvus 2.4 + MySQL 8，DeepSeek-v4-flash
- Embedding：BAAI/bge-m3；重排序：bge-reranker
- 表格解析：pdfplumber + camelot + PaddleOCR（兜底）+ 自研表格结构化
- 图像解析：PyMuPDF 提取图像 + CLIP/Chinese-CLIP 图像嵌入 + BLIP/Qwen-VL 生成图像描述 + OCR 辅助
- 优化：混合检索（BM25+向量）、重排序、查询改写、表格感知检索、图像感知检索

# 工单16 调试与微调专用视觉语言模型｜总结文档
##1.任务完成情况
✅ 完成IMDR工业图文数据集转换脚本，输出LLaMA‑Factory多模态对话数据集；
✅ 编写VLM LoRA微调yaml配置文件、训练启动脚本run_sft.sh；
✅ 使用LLaMA‑Factory完成VLM LoRA轻量微调，成功运行至少1个epoch，loss正常下降；
✅ 实现评估脚本，除BLEU、ROUGE通用指标外，实现工单要求两大工业专项指标：专业术语准确率、图纸推理正确率；
✅ 对比基线原始VLM与微调后模型；工业专项指标提升达到≥5%；
✅ 输出评估报告，记录失败案例，给出数据清洗、超参数调优建议。

##2.学习收获
1. VLM视觉语言模型针对垂直工业领域，需要做领域微调；LoRA轻量微调，不需要全参数训练，降低显存开销。
2. 多模态数据集格式要求严格：图片路径+对话conversations；图像预处理必须和基座模型保持一致。
3. **垂直领域不能只看BLEU、ROUGE通用NLP指标；需要设计业务专项评测指标（本工单：术语准确率、图纸推理正确性）**。
4. 训练故障排查：loss不下降、loss NaN、OOM的常见原因与解决手段。

##3.现存不足
1. 实训数据集规模有限；
2. 图纸推理类样本占比可以进一步提升；
3. 未完成把微调后VLM完整接入RAGFlow做端到端业务回归。

##4.后续拓展方向
1. 扩大IMDR训练集样本；图纸图片做图像增强；
2. 调优LoRA r、alpha、学习率，做多组超参对比实验；
3. 将LoRA微调后的VLM完整替换RAGFlow内置VLM，跑工单14‑15全部测试用例做端到端回归。

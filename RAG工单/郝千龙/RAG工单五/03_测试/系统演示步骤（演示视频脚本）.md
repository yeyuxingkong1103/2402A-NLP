## 演示流程（5 轮，对应工单 PDF 指定对话）

### 第 1 轮：军用收入（术语归一）

**输入**：
```
报告期内，武汉兴图新科电子股份有限公司来自军用领域的收入分别是多少？
```

**系统展示**：
- 改写后查询：`报告期内，武汉兴图新科电子股份有限公司来自国防领域的收入分别是多少？`
- 答案：`公司来自军用领域的收入分别为6,464.51 万元、14,414.16 万元、18,780.67 万元和4,627.14 万元`
- 证据页码：36

**讲解要点**：用户说“军用”，招股书原文用“军用领域”，系统在检索时做术语归一（军用↔国防），同时答案抽取时双向扩展，确保命中正确段落。

---

### 第 2 轮：指代消解“他”

**输入**：
```
他参与的哪个工程荣获了国家科技进步一等奖？
```

**系统展示**：
- 改写后查询：`武汉兴图新科电子股份有限公司参与的哪个工程荣获了国家科技进步一等奖？`
- 答案：`某情报、指挥、控制与通信网络一体化工程（C4ISR 系统）荣获国家科技进步一等奖`
- 证据页码：157

**讲解要点**：“他”指代上一轮的话题实体“武汉兴图新科电子股份有限公司”，系统通过实体栈完成指代消解。

---

### 第 3 轮：指代消解“这个公司”

**输入**：
```
这个公司的法定代表人是谁？
```

**系统展示**：
- 改写后查询：`武汉兴图新科电子股份有限公司的法定代表人是谁？`
- 答案：`法定代表人为 程家明。`
- 证据页码：72

**讲解要点**：“这个公司”同样指代兴图，实体栈维持最近话题实体。

---

### 第 4 轮：省略补全“那…呢”

**输入**：
```
那武汉力源信息技术股份有限公司呢？
```

**系统展示**：
- 改写后查询：`那武汉力源信息技术股份有限公司的法定代表人是谁`
- 答案：`法定代表人为 赵马克。`
- 证据页码：345

**讲解要点**：问句省略了意图，系统继承上一轮意图“法定代表人”，并补全新实体“武汉力源信息技术股份有限公司”。

---

### 第 5 轮：组织结构图销售处

**输入**：
```
武汉力源信息技术股份有限公司组织结构图中，哪个销售部的销售处最多？有哪些销售处？
```

**系统展示**：
- 改写后查询：（原句）
- 答案：
  ```
  销售处最多的销售部：大客户销售部（共 6 个销售处）。
  公司全部销售处共 6 个：武汉销售处、广州销售处、珠海销售处、深圳销售处、北京销售处、成都销售处。
  ```
- 证据页码：39

**讲解要点**：系统通过矢量连线几何重建组织结构图，识别出 6 个销售处全部隶属“大客户销售部”，并回答了“哪个销售部最多”和“有哪些销售处”两个子问题。

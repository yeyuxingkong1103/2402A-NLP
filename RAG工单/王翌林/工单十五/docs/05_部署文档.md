# 工单十五：部署文档

## 环境要求
- Linux（WSL Ubuntu-22.04 验证通过）
- Python 3.10（conda/venv）
- CUDA（Qwen2-VL 推理，RTX 5060 验证）
- Milvus 2.4 standalone（远程，端口 19530）或 Milvus Lite（自动降级）

## 部署步骤

### 1. 安装环境
```bash
cd 工单十五
bash scripts/install.sh
```
脚本会：检查 Python venv → 安装 requirements.txt → 验证 torch+cuda → 检查本地模型。

> 模型需预先放置于 `/home/dabaie/models/`：bge-m3、bge-reranker-v2-m3、Qwen2-VL-2B-Instruct。

### 2. 配置 .env
```bash
DEEPSEEK_API_KEY=sk-xxx          # 必填
MILVUS_HOST=localhost
MILVUS_PORT=19530
RAG_EMBED_DEVICE=cpu             # 建议 cpu 防 OOM
VLM_DEVICE=cuda
APP_PORT_V15=8015
STREAMLIT_PORT_V15=8515
```

### 3. 构建知识库（一键）
```bash
bash scripts/init_all.sh
```
或分步：
```bash
python scripts/build_kb.py --pdf ./附件/CN100347506C.pdf
```

### 4. 启动服务
```bash
bash scripts/start.sh
# FastAPI: http://localhost:8015/docs
# Streamlit: http://localhost:8515
```

### 5. 停止服务
```bash
bash scripts/stop.sh
```

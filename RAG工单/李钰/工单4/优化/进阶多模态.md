## 一、V4 当前方案

| 能力 | 实现 | 依赖 |

| 图像提取 | PDF 内嵌图像 + 预设描述 | PyMuPDF (可选) |

## 二、进阶方案

### 2.1 CLIP 跨模态检索 (安装即启用)
```bash
pip install sentence-transformers
```
- 自动加载 `clip-ViT-B-32` 模型
- 支持 query_text ↔ image_path 向量相似度
- 首次运行下载 ~300MB, 后续缓存

### 2.2 多模态 LLM 图像理解
```bash
# 设置环境变量
set VISION_API_KEY=sk-xxxx
set VISION_BASE_URL=https://api.openai.com/v1
set VISION_MODEL=gpt-4o-vision-preview
```

### 2.3 表格-图像联合解析
PDF 中常见: 表格 + 图注在同页, 图像标题与表格数据关联
```python
# 改进: 表格所在页的图像视为同一语义单元
page_chunks = 表格 + 图像 + 文字 联合建模
```

### 2.4 图像 OCR + 结构化
对组织结构图/增长图中的文字做 OCR:
```bash
pip install easyocr  # 中文效果好
# 或 paddleocr (百度)
```

### 2.5 图表专用理解
- **组织结构图**: 用图神经网络 (GNN) 理解节点关系
- **柱状图/折线图**: 用 chart2text 模型提取数值
- **饼图**: 识别扇区 → 百分比映射

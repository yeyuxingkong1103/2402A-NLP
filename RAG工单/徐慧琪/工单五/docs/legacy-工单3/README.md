# 工单3 文档存档（legacy）

本目录存放**从工单3（上游基线）原样继承**的四篇文档。
工单5 的 `docs/` 采用连续编号（01–09），工单3 的这四篇与新编号重名但内容不同，
故移到此目录存档，**内容一字未改**。

| 文件 | 说明 | 工单5 里对应什么 |
| --- | --- | --- |
| `05-表格解析与检索专项说明.md` | 工单3 的表格全链路：识别→结构化→入库→检索→生成 | 表格能力**已继承**（`src/table_parser.py` / `table_chunker.py` 原样保留），工单5 未改动；本工单的专项说明是 `docs/05-多轮Query理解专项说明.md` |
| `06-答案定位报告.md` | 工单3 的 14 题逐题答案定位（PDF/页/表/行） | 由 `src/answer_location.py` 生成，工单5 保留该工具；本工单的逐轮证据是 `docs/06-验收序列逐轮报告.md` |
| `07-演示录制脚本.md` | 工单3 的演示视频分镜与口播 | 工单5 的脚本是 `docs/08-演示录制脚本.md` |
| `08-工单验收对照表.md` | 工单3 的验收逐条对照 | 工单5 的是 `docs/09-工单验收对照表.md` |

**为什么保留**：工单5 的验收标准要求「优化前 vs 优化后」对比，
这四篇是「优化前」的**一手证据**（尤其是 `06-答案定位报告.md` 的 14/14 定位结果，
是工单5 的单轮基线能力的直接来源）。删除它们会让对比失去依据。

**注意（已处理）**：`src/answer_location.py` 原先把报告写到 `docs/06-答案定位报告.md`，
而工单5 的 `docs/06` 已被逐轮报告占用。工单5 起该脚本的**默认输出路径已改到本目录**
（`docs/legacy-工单3/06-答案定位报告.md`），不会再覆盖工单5 的交付文档。

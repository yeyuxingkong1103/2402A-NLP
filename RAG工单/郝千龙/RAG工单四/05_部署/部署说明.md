# 部署说明

# 工单四 招股说明书图文智能问答系统（图像内容解析及检索优化）

- 工单编号：人工智能NLP-RAG-图像内容解析及检索优化
- 适用环境：Windows 10/11（PowerShell），纯CPU，全程离线
- 验证环境：Windows + Anaconda Python 3.12.7

---

## 一、环境要求

### 1.1 硬件

| 项目 | 最低配置 | 验证配置 |
|---|---|---|
| CPU | 4核 x86_64 | 多核主流CPU |
| 内存 | 8GB（建议16GB） | 16GB |
| 磁盘 | 约3GB（模型缓存+索引+图片库） | — |
| 网络 | **建库与问答均不需要联网** | 离线 |

### 1.2 软件与本地模型

- Python 3.10–3.12（验证版本3.12.7）；
- Python依赖见 `02_研发/requirements.txt`：
  pymupdf、pdfplumber、jieba、scikit-learn、numpy、pandas、openpyxl、
  streamlit、Pillow、sentence-transformers、transformers；
  可选：paddleocr、paddlepaddle（离线OCR，不装则自动降级）。
- 已在本机缓存、无需联网下载的模型：
  - 嵌入模型 `BAAI/bge-base-zh-v1.5`（位于 `~/.cache/huggingface/hub`）；
  - 重排模型 `BAAI/bge-reranker-large`（可选开关，CPU上默认关闭）；
  - OCR模型 PP-OCRv6（det/rec，位于 `~/.paddlex/official_models`）。

> 无上述本地缓存时系统会自动降级：嵌入→字符2–4gram TF-IDF；OCR→图注+邻近正文，
> 均不触发联网下载；但准确率不再保证达到验收值，请在部署机预先准备好模型缓存。

## 三、分步部署（干净环境）

### 步骤1：准备Python环境

```powershell
conda create -n rag4 python=3.12 -y
conda activate rag4
cd RAG工单四\02_研发
pip install -r requirements.txt
```

### 步骤2：确认离线模型缓存

```powershell
# 嵌入模型目录应存在
dir "$env:USERPROFILE\.cache\huggingface\hub\models--BAAI--bge-base-zh-v1.5"
# PaddleOCR模型目录应存在（启用OCR时）
dir "$env:USERPROFILE\.paddlex\official_models"
```

如从离线安装包迁移模型，将上述目录整体复制到目标机相同位置即可。

### 步骤3：建库（OCR批处理，仅执行一次）

```powershell
cd RAG工单四\02_研发\src
python build_index.py
```

- 首次全量建库在纯CPU上约20–30分钟（PDF解析约2分钟、78张位图+5张矢量图OCR约20分钟、
  BGE编码约9分钟）；
- OCR结果按图片md5增量缓存于`image_store\ocr_cache.json`，中断后重跑自动续算；
- 成功标志：日志输出`建库完成`，`02_研发\index_store`生成4个索引文件，
  `image_store`包含83张图像证据原图/缩略图。

### 步骤4：批量回归验收

```powershell
python evaluate.py
```

预期输出：

```text
答案正确率：16/16 = 100.0%（验收线90%）
响应≤3s占比：16/16 = 100%
降级答案数：0/16
```

明细写入 `03_测试\评测结果.csv`。

### 步骤5：启动问答服务

```powershell
streamlit run app.py
```

浏览器打开 `http://localhost:8501`：

- 左侧栏可切换 中文/English；
- 提问后展示答案、端到端耗时、≤3秒达标徽标、Top-3证据；
- **图像证据卡片直接渲染原图**（组织结构图/柱状图等），标注文档、页码、图题、
  双路检索名次；降级答案显示黄色提示条。

## 四、常用配置调整（`02_研发/src/config.py`）

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `enable_ocr` | True | 仅建库期生效；False时跳过PaddleOCR走纯图注降级 |
| `fallback_embedding` | "bge" | 改"tfidf"强制使用TF-IDF（优化基线实验/无模型环境） |
| `use_reranker` | False | True启用bge-reranker-large（纯CPU下单题约8–10秒，会超3秒SLA，慎用） |
| `response_timeout_s` | 3.0 | 验收SLA阈值（评测/界面徽标使用） |
| 图像过滤阈值 | 宽高≥90px/面积≥12000/长宽比0.4–4.5/xref复用≤3页 | 换语料时可在此调参 |
| `image_chunk_boost` | 0.35 | 图像类问题对图像证据块的精排加分 |

修改配置后需重新执行`python build_index.py`（仅嵌入相关配置变更时，
OCR走缓存可大幅提速）。

## 五、常见问题（FAQ）

1. **日志出现`NotImplementedError ... onednn_instruction.cc`？**
   Paddle 3.4 OneDNN兼容缺陷，代码已内置`FLAGS_use_mkldnn=0`与`enable_mkldnn=False`，
   如仍出现请确认环境变量未被外部覆盖。

2. **BGE首次编码进程零CPU挂死？**
   PaddlePaddle先于torch加载会造成OpenMP/MKL运行时冲突。`build_index.py`已在导入
   paddle相关模块前预加载torch；自建脚本若同时使用两套库，请保持相同导入顺序。

3. **启动报`matmul ... dimension mismatch`？**
   索引嵌入方式（BGE/TF-IDF）与当前加载器不一致。删除`index_store`后重新建库；
   正常流程下保存BGE索引时会自动清理遗留的`tfidf.pkl`。

4. **图像证据图题关联为空？**
   部分图题不含"图"字（如"2008年中国IC市场应用结构与增长(亿元)"），已由图表特征
   短行规则覆盖；新样式图题可在`config.figure_title_pattern`与
   `image_extractor._associate_text`的chart_title_re中补充。

5. **端口8501被占用？**
   `streamlit run app.py --server.port 8502`。

6. **能否断网运行？**
   可以。代码统一设置`HF_HUB_OFFLINE=1/TRANSFORMERS_OFFLINE=1`，全部模型走本地缓存，
   缺失时自动降级且不发起网络请求。

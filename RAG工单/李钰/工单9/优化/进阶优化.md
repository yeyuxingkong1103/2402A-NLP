## 二、正式 RAGAS 框架

```bash

```
```python
from ragas import evaluate
from ragas.metrics import context_precision, context_recall, faithfulness, answer_relevancy
from datasets import Dataset

data = Dataset.from_dict({
    "question": ["武汉力源的控股股东是谁?"],
    "answer": ["控股股东是武汉力源科技(持股35%)"],
    "ground_truth": ["武汉力源科技持股35%,是控股股东"],
    "contexts": [["武汉力源科技是武汉力源的控股股东(持股35%)"]],
})

result = evaluate(data, metrics=[context_precision, context_recall, faithfulness])
print(result)
```

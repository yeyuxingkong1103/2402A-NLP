# Embedding 模型微调 · 部署文档

> **工单编号：人工智能 NLP-RAG-Embedding 模型微调任务**
> 任务：在本机（CPU）环境部署并跑通 Embedding 模型微调全流程
> 前置工单：01–07（RAG 问答系统与检索评估）

---

## 一、部署目标

把「Embedding 模型微调」项目在一台**无 GPU 的 Windows 主机**上从零部署并跑通，产出：

1. 结构感知知识库（7476 块）；
2. 四类训练/评估数据集；
3. 微调后的领域嵌入模型；
4. 微调前后检索指标对比（满足验收标准）。

## 三、部署步骤

### 3.1 获取代码

```
研发/
├── src/  data/  vector_db/  models/  output/  tools/
├── build_kb.py  build_dataset.py  train.py  evaluate.py
├── run_pipeline.py  demo_app.py  requirements.txt  README.md
```

> `data/ccf_txt/` 需包含 9 份年报结构化文本（JSONL），可从附件 `ccf_competition` 的
> 解析结果复制；亦可运行 `python tools/prepare_data.py` 自动复制。

### 3.2 安装依赖

```powershell
# 建议使用国内镜像加速
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

关键依赖（`requirements.txt`）：

| 依赖 | 版本 | 用途 |
|---|---|---|
| torch | ≥2.2,<2.7 | 深度学习框架（CPU 版） |
| transformers | ≥4.40 | 模型与训练参数 |
| sentence-transformers | ≥3.0 | 嵌入模型微调框架 |
| datasets | ≥2.19 | 训练数据集封装 |
| accelerate | ≥0.30 | 训练加速后端 |
| scikit-learn / numpy | ≥1.3 / ≥1.26 | 指标与数值计算 |
| jieba | 0.42.1 | 中文分词（可选） |
| matplotlib / pillow / opencv-python-headless | — | 图表 / 截图 / 视频 |
| streamlit | ≥1.30 | 演示界面 |
| python-dotenv / requests | — | 配置 / HTTP |

### 3.3 配置模型镜像

代码已在 `src/embedding_model.py` 中默认设置：

```python
os.environ.setdefault("HF_ENDPOINT", "https://hf-mirror.com")
```

基座模型 `BAAI/bge-small-zh-v1.5` 首次运行自动下载并缓存（`HF_HOME` 默认 `~/.cache/huggingface`
或环境变量指定目录）。

### 3.4 一键跑通全流程

```powershell
python run_pipeline.py --loss mnrl
```

执行内容：知识库 → 数据集 → 微调（含前/后评估）→ 图表。预计耗时约 **11 分钟**（CPU）。

### 3.5 分步执行（可选）

```powershell
python build_kb.py --rebuild        # 1) 知识库切片 -> 7476 块
python build_dataset.py             # 2) 数据集生成 -> 810/1215/945/330
python train.py --loss mnrl         # 3) 微调训练 -> models/bge-small-zh-ccf-finetuned
python evaluate.py                  # 4) 微调前后评估 -> output/eval_compare.json
python tools/run_loss_experiment.py # 5) 损失函数对比实验（Triplet）
```

### 3.6 启动演示界面

```powershell
streamlit run demo_app.py
# 浏览器访问 http://localhost:8501
```

## 六、常见问题（部署向）

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: torch` | 未安装依赖 | 执行 3.2 安装依赖 |
| `Cannot access accelerator device when none is available` | CPU-only 环境下 `torch.accelerator` 报错 | 代码已内置 `_compat.py` 垫片，**无需手动处理** |
| 模型下载超时 | 直连 huggingface.co | 已默认 `HF_ENDPOINT=hf-mirror.com` |
| `warmupcosine is not a valid SchedulerType` | Transformers v5 枚举名变更 | 代码已改用 `cosine`，见《问题记录》问题 4 |
| 训练很慢 | CPU 训练 | 属预期；小模型 512 维，204 步约 8 分钟 |

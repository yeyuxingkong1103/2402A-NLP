# Graph RAG 金融问答方案

> 工单编号: 人工智能 NLP-RAG-基于 Graph RAG 实现金融问答
> 基线: V7 (完整评估框架)

## 一、工单8核心需求

### 1.1 核心技术: Graph RAG
```
传统 RAG: 文本切块 → 向量化 → 相似度检索
Graph RAG: 实体/关系抽取 → 知识图谱 → 图谱路径检索 + 文本检索融合
```

### 1.2 产出物
1. **知识图谱构建**:从 PDF 中抽取金融实体 + 关系
2. **Graph RAG 检索**:问题 → 实体链接 → 子图检索 → 文本检索融合
3. **知识图谱可视化**:展示实体、关系、子图
4. **问答界面**:支持文字输入 + 图谱可视化

### 1.3 验收标准
- 知识图谱可视化:实体、关系展示
- eval_question.md 检索结果 (比对工单7)
- 交互友好 + 多语言

## 二、Graph RAG 架构

```
PDF 文档
  │
  ├─ PDF 解析 → 文本块
  │
  ├─ 实体抽取 (NER)
  │   ├─ 公司/机构: 武汉兴图新科、武汉力源...
  │   ├─ 人物: 法定代表人、董事长...
  │   ├─ 产品/技术: AVS编解码、军用系统...
  │   ├─ 财务数据: 注册资本7360万元...
  │   └─ 事件/关系: 参与制定、持股、控制...
  │
  ├─ 关系抽取 (RE)
  │   ├─ (公司, 法定代表人, 人物)
  │   ├─ (公司, 持股比例, 关联方)
  │   ├─ (公司, 参与制定, 标准)
  │   └─ (公司, 主营, 产品)
  │
  └─ 构建知识图谱 (NetworkX / Neo4j)
       │
       ├─ 节点: 实体 (带类型/属性)
       └─ 边: 关系 (带类型/来源chunk)

用户问题
  │
  ├─ 实体链接 → 图谱节点
  │
  ├─ 子图检索 (Graph Traversal)
  │   ├─ 邻居节点 (1-hop / 2-hop)
  │   ├─ 关系路径
  │   └─ 子图 + 关联文本块
  │
  ├─ 文本检索融合 (V6 混合检索)
  │
  └─ LLM 生成答案 + 引用图谱结构
```

## 五、检索融合策略

```
Graph RAG 得分 = 0.5 × GraphScore + 0.3 × TextScore + 0.2 × LLMRerank

GraphScore:
  - 实体链接命中数
  - 子图相关性 (邻居数/关系类型)
  - 图谱边的重要性

TextScore:
  - V6 混合检索分数 (向量+全文)

最终: 图谱节点关联的文本块优先返回
```

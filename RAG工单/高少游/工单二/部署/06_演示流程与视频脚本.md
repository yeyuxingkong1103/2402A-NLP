## 二、现场手动演示流程（推荐 5 分钟）

> 演示前准备：启动 Ollama（`ollama serve`）、构建向量库（`python scripts/build_kb.py --all`）、启动界面（`streamlit run app.py`），浏览器打开 http://localhost:8501 。

### 步骤 1：介绍系统（30 s）

- 展示首页：标题、工单编号、优化目标；
- 说明四个模式：优化后 / 优化前（基线）/ 优化前后对比 / 批量评估。

### 步骤 2：优化后单题问答（60 s）

1. 侧边栏「从题目列表选择」选 **Q543：注册资本是多少？**
2. 保持「优化后（结构分块 + 混合检索 + 重排 + 抽取式）」模式；
3. 展示：答案含"5,520.00 万元"与"法定代表人，程家明"，附**页码引用**（第22页、第52页）；
4. 展开「检索到的依据片段」，说明每段带页码、块类型与得分。

> 注意：**首次提问为冷启动**（需加载向量模型，可能 10 s 左右）；演示前建议先随便问一句完成预热，之后单题耗时稳定在 2 s 内。

### 步骤 3：优化前后对比（90 s）

1. 「问答模式」切到 **优化前后对比**；
2. 选 **Q531：法定代表人是谁？**；
3. 展示左栏（橙色，优化前基线）：耗时 16.95 s、**未命中**、无有效答案；
4. 展示右栏（绿色，优化后）：耗时 2.139 s、**命中**、给出"程家明"与页码引用；
5. 说明差异根因：基线用推理型大模型生成，慢且幻觉；优化后用抽取式合成，快且可溯源。

### 步骤 4：批量评估（90 s）

1. 「问答模式」切到 **批量评估**；
2. 点击「开始批量评估（10 题）」，等待进度条跑完（约 1~3 分钟，因基线需调用大模型）；
3. 展示结果表格与三张指标卡：优化前准确率 60%、优化后 100%、优化后平均耗时约 1.1 s。

### 步骤 5：讲解优化方案与图表（60 s）

- 打开《优化/01_优化方案.md》讲解四层优化点；
- 打开《优化/04_优化路径图.png》《优化/05_核心指标对比图.png》展示优化前后变化；
- 打开《测试/05_逐题命中对比图.png》《测试/06_响应时间对比图.png》说明逐题表现。

## 三、演示要点提示

| 要点 | 说明 |
|---|---|
| 预热 | 冷启动约 10 s，演示前先问一题预热，避免误判超时 |
| 优化后无需大模型 | 抽取式链路不依赖 `deepseek-r1`，即使生成模型慢也不影响指标 |
| 页码引用 | 每条答案都标注来源页码，可当场翻 PDF 核对 |
| 批量评估耗时 | 基线链路每题调用大模型，10 题约需 1~3 分钟，属正常 |

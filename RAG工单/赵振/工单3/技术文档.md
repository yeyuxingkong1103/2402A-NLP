# 技术说明

## 表格解析

`rag.py` 用 PyMuPDF `page.find_tables()` 读取每页表格，将行单独保存为带 PDF 页码、表格编号和字段映射的片段。表格和正文共用原有向量检索及字符级 TF-IDF；发行、募投、控制关联方、非控制关联方问题会提高相应表格片段的排序。

答案通过被检索到的 `table_id` 取回同表数据行。这样既使用检索结果定位证据，也避免只取一行导致漏掉募投项目或关联方名单。页码按 PDF 的物理页序计数，含封面；因此PDF第22页的印刷页脚为21，第157页的印刷页脚为156。

## 主要文件

- `rag.py`：解析、建索引、检索和答案抽取。
- `app.py`：选择/上传 PDF、建立知识库、提问和查看页码证据。
- `questions.json`：4道表格题和10道旧题回归清单。
- `evaluation_results.json`：本次4题检索结果及沿用的10题回归数据。

## 边界

表格检测适用于文本型 PDF。扫描图片 PDF 需要 OCR，本工单未要求新增 OCR。高并发资源消耗没有做压力测试。

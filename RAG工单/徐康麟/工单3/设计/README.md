# 设计/ —— 方案与设计文档

> 工单：**人工智能NLP-RAG-PDF文档的表格解析及检索优化**
> 本目录只放 **Markdown 文档**，不放代码、不放运行产物。

## 应包含

| 主题 | 说明 |
| --- | --- |
| 总体架构 | 解析 → 分块 → 索引 → 混合检索 → 生成 → 引用 的链路与模块边界 |
| 表格解析方案 | `pymupdf page.find_tables()` 的归一化规则（相邻 `None` 合并/向前填充、格内换行归一化、转 Markdown） |
| 分块策略 | 文本块与表格块的分块粒度、元数据字段（文件名/页码/块类型/表标题） |
| 检索方案 | BM25（自实现）+ 向量（numpy 精确检索）混合与融合权重、重排 |
| 生成与引用 | 可插拔 LLM 后端（ollama → openai 兼容 → extractive）、`[文件名: 页码]` 引用约束、无依据回「不清楚」 |
| 多轮对话 | 会话状态、指代消解、上下文注入长度 |
| 接口契约 | `app/core` 对外函数签名与数据结构（供 UI 与测试共用） |

## 约束提醒

- 依赖事实以 `部署/配置/环境事实.md`（归档正本）为准；缺失依赖一律自实现或替代（见该文 §2.2）。
- 指标必须可复现，**严禁**写入未实际运行的数值（尤其 RAGAS）。

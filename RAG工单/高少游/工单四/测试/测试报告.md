## 4. 图像类问题（本工单重点）

### 4.1 id 5 · 组织结构图

- **问题**：武汉力源信息技术股份有限公司组织结构图中，销售部有几个部门构成，其中大客户销售部有几个销售处构成？
- **系统答案**：销售部由 4 个部门构成（电话及网络销售部、渠道销售部、大客户销售部、国际贸易部）；其中大客户销售部由 6 个销售处构成（珠海、深圳、北京、武汉、广州、成都销售处）。
- **命中线索**：销售部、大客户销售部、4、6（全部命中）
- **来源页码**：第 38、39 页（图形内容解析）
- **说明**：图形区域经「母线归属法」还原为有向层级树，根节点为「股东大会」，逐级展开至销售部及其 6 个销售处。

### 4.2 id 6 · IC 市场应用结构与增长图

- **问题**：从 2008 年中国 IC 市场应用结构与增长图中可以看出，增长率最快的是哪个行业？负增长的是哪个行业？
- **系统答案**：增长率最快的是汽车行业（14.0%）；负增长的是 IC 卡行业（-2.0%）。
- **命中线索**：汽车、IC 卡（全部命中）
- **来源页码**：第 72、310 页（图形内容解析）
- **说明**：图形经高清渲染 → 去水印前处理 → OCR → 标签—数值配对，得到各行业增速后派生结论。

## 6. 稳定性与容错测试

| 用例 | 输入 / 场景 | 预期 | 实测 |
|---|---|---|---|
| 空输入 | 空字符串 | 提示「请输入问题」，不进入检索 | ✅ 通过 |
| 超短输入 | “？” | 正常返回或提示，无异常 | ✅ 通过 |
| 跨文档问题 | 含公司名的问题 | 按公司别名路由到正确文档，无串味 | ✅ 通过 |
| CLIP 缺失 | `CLIP_ENABLE=0` | 降级为纯文本检索，主链路可用 | ✅ 通过 |
| OCR 缺失 | 未安装 rapidocr | 跳过图表数值配对，保留层级语义 | ✅ 通过 |
| 向量库未构建 | 删除 vector_db | 界面提示先运行 `build_kb.py` | ✅ 通过 |
| 文档解析异常 | 图形解析抛错 | 捕获异常，仅用文本/表格块建库 | ✅ 通过 |

## 四、评估方法

### 4.1 关键词覆盖率
对每个问题, 预设标准答案关键词列表。计算答案中命中关键词的比例:

```
覆盖率 = 命中关键词数 / 标准关键词总数
```

### 4.2 V1 → V2 提升计算
```
提升 = V2 覆盖率 - V1 覆盖率
```

### 4.3 达标判定
- V2 平均关键词覆盖率 ≥ 90% → 准确率达标
- V2 响应时间 ≤ 3s/题 → 性能达标

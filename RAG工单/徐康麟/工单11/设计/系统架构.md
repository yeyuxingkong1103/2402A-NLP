## 2. 模块划分（`研发/src/`）

| 模块 | 职责 | 关键接口 |
| --- | --- | --- |
| `config.py` | 路径与超参统一加载（JSON 配置 + 环境变量覆盖） | `Config().path(key)` / `.hyper_get(*keys)` |
| `text_utils.py` | 归一化、分句、Jaccard、文档名解析、关键词命中 | `normalize_text` / `jaccard` / `parse_doc_name` |
| `generate_dataset.py` | 语料 → 数据集（三种格式 + 统计 + MD5） | `build_dataset(cfg)` |
| `losses.py` | 4 种损失 + 组合损失工厂 | `build_loss(cfg) -> (module, kind, desc)` |
| `encoder.py` | 模型加载/冻结/编码/落盘（含 OOM 折半重试） | `EmbeddingModel.encode()` / `.save()` |
| `train.py` | CPU 训练循环、日志、损失曲线、检查点 | `train(cfg, **overrides)` |
| `evaluator.py` | 指标实现（纯 numpy，可单测） | `retrieval_metrics` / `similarity_stats` |
| `evaluate.py` | 微调前后对照、真实索引端到端检索、对比表 | `compare(cfg)` |
| `plot.py` | PIL 折线图/柱状图（本机无 matplotlib） | `line_chart` / `bar_chart` |
| `benchmark_cpu.py` | CPU 吞吐标定（训练规模决策依据） | `main()` |
| `inspect_corpus.py` | 语料勘察（分块/类型/字符数/指标命中率） | `main()` |

## 3. 关键设计点

1. **零强依赖**：不依赖 accelerate / peft / datasets / pandas / matplotlib，全部自实现，避免联网装包挂死。
2. **只读复用**：工单1（解释器+底座权重）、工单7（语料+索引+真题）一律绝对路径只读引用，不复制大文件。
3. **配置化**：所有阈值（margin、序列长度、留出比例、抽样规模、时间预算、线程数）都在 `部署/配置/*.json`。
4. **可追溯**：数据集带 MD5 指纹与统计；评估结果带模型路径、维度、耗时；截图页脚标注来源文件。
5. **容错**：语料损坏行跳过并计数、Ollama/网络失败降级、内存不足自动折半批大小、训练异常仍落盘检查点。
6. **CPU 纪律**：`torch.set_num_threads(6)`，纯 CPU，不触碰 RTX 2060。

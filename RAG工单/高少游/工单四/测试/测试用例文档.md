## 3. 判定规则

- **答案准确率**：系统答案文本中命中该题任一「关键线索」（去空白、全角逗号归一化后子串匹配）即判为答对。
- **检索命中**：返回的候选片段文本中包含任一关键线索。
- **响应时间**：从提问到生成答案的墙钟耗时（`time.time()` 差值）。

## 4. 执行方式

```powershell
cd 研发
python evaluate.py                 # 优化链路 16 题
python evaluate.py --baseline      # 追加基线（LLM）对照
python evaluate.py --ablation      # 追加消融对照
```

产出：`output/eval_results.json`、`output/评测报告.md`、`output/figures/*.png`。

工单编号：人工智能 NLP-RAG-PDF 文档的表格解析及检索优化

---

## 一、任务描述

在工单一、工单二构建的 RAG 问答系统基础上，新增《招股说明书 2.pdf》（武汉力源信息技术股份有限公司）的解析，并通过表格解析技术，实现对以下 4 道力源问题的准确检索：

1. 本次发行股数及占发行后总股本比例
2. 本次募集资金拟投资项目
3. 存在控制关系的关联方及持股比例
4. 不存在控制关系的关联方企业

同时保留工单二对兴图 10 题的检索能力，合计 14 题，目标准确率 ≥ 90%，响应 ≤ 3 秒。

---

## 二、优化方案

### 2.1 表格解析

- 使用 PyMuPDF `page.find_tables()` 提取表格；
- 每张表转成 Markdown 格式，保持行列结构；
- 表格独立成 chunk，标记 `type: "table"`；
- 正文使用 `get_text("blocks")`，标记 `type: "text"`。

### 2.2 多 PDF 支持

- 两份 PDF 统一入库，metadata 增加 `source` 字段；
- 按问题中的公司名自动路由：
  - 含“力源” → `source="liyuan"`
  - 含“兴图” → `source="xingtu"`

### 2.3 检索优化

- 向量 + BM25 混合检索；
- 表格优先：问题含“股数、比例、关联方、募投、项目、持股”时，表格 chunk 加权 +0.2；
- bge-reranker 重排 Top-6；
- 查询扩展：
  - “发行股数” → 发行股数、总股本、发行后总股本
  - “募集资金” → 募集资金、募投项目、投资项目
  - “关联方” → 关联方、控股股东、持股比例

### 2.4 Query 理解

- 意图识别：数值查询 / 实体查询 / 列表查询 / 事实查询
- 查询扩展 + 公司路由

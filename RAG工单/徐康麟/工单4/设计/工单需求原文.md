## 提示词：基于RAG的PDF图像内容解析与问答系统实现

**任务编号**：人工智能NLP-RAG-图像内容解析及检索优化
**目标**：快速构建一个最基本的RAG问答系统，能够解析两个招股说明书PDF（含图像内容），并回答指定问题列表。**速度优先，实现可运行原型即可**。

---

### 一、背景与输入数据
已有两个PDF文档：
- **招股说明书1.pdf**：武汉兴图新科电子股份有限公司（科创板）
- **招股说明书2.pdf**：武汉力源信息技术股份有限公司（创业板）

文档中既包含文本，也包含图像（如组织结构图、市场增长图等）。系统需要能够解析这些图像中的信息，并结合文本进行检索问答。

### 二、核心需求
1. **RAG流程**：文档加载 → 文本/图像内容提取 → 向量化 → 检索 → 生成答案。
2. **图像解析**：必须使用多模态模型（如CLIP或多模态大模型）提取图像中的文本/语义，与文本内容一起存入向量库。
3. **问答能力**：支持中文问答，对工单中列出的所有问题（见下方列表）能返回准确答案，准确率≥90%。
4. **性能**：从提问到返回答案时间≤3秒。
5. **交互**：提供简单的命令行或Web界面（如Gradio）即可，支持中英文。

### 三、代码结构（必须包含以下五个中文文件夹）
```
project/
├── 设计/          # 设计文档：架构图、技术选型、流程图
├── 研发/          # 核心代码：文档解析、图像处理、向量库、检索、生成
├── 测试/          # 测试脚本与测试用例（包含工单问题列表）
├── 优化/          # 简单优化（如缓存、批量处理），可选
└── 部署/          # 部署脚本（如FastAPI服务、Dockerfile、运行说明）
```

### 四、技术栈建议（追求速度，可自由选择但优先轻量）
- **PDF文本提取**：`pdfplumber` 或 `PyPDF2`
- **图像提取**：`PyMuPDF` (fitz) 提取图像，用 **CLIP** 或多模态大模型（如 `Qwen-VL`、`BLIP`）生成图像描述或OCR
- **向量化**：`sentence-transformers` 中文模型（如 `text2vec-base-chinese`）或 `OpenAI Embeddings`（若可用）
- **向量数据库**：`FAISS`（内存型，速度快）
- **检索**：相似度搜索，Top-K=3
- **生成模型**：本地小模型（如 `ChatGLM3-6B`、`Qwen-7B`）或调用API（如 `DeepSeek`、`OpenAI`），若速度优先可先用规则模板生成
- **框架**：`LangChain` 或 `LlamaIndex` 加速开发
- **Web界面**：`Gradio` 或 `Streamlit`（快速搭建）

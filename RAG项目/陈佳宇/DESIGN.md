# 基于RAG的角色扮演系统 - 设计文档

## 1. 需求分析

### 1.1 业务目标
构建基于RAG技术的角色扮演对话系统，用户可选择不同角色（虚拟朋友、医生、律师等）进行多轮对话，系统基于角色知识库给出准确、无幻觉的回答。

### 1.2 功能需求
- 用户管理：登录、多用户隔离
- 角色管理：多角色切换、角色独立知识库
- 对话功能：多轮对话、上下文记忆
- 知识库：动态添加、PDF/TXT导入、分块存储
- 检索能力：混合检索（稠密+关键词）、重排序
- 系统接口：HTTP API、Swagger文档
- 系统监控：日志记录、健康检查
- 效果评测：RAG指标评估

### 1.3 业务流程
用户登录 → 选择角色 → 输入问题 → Query改写 → 混合检索 → 重排序 → 拼接提示词 → 大模型生成 → 后处理 → 返回回答（同时保存到Redis记忆）

## 2. 技术架构

### 2.1 整体架构
客户端 → FastAPI接口层 → MySQL（用户/角色）、Redis（对话记忆）、Milvus（向量库）、DeepSeek（大模型）

### 2.2 核心模块

#### 向量检索模块（vector_store_milvus.py）
- 稠密向量检索：bge-base-zh → Milvus AUTOINDEX
- BM25关键词检索：rank_bm25 + jieba分词
- 混合检索：两路结果合并去重
- 重排序：bge-reranker-base交叉编码器打分

#### 文档处理模块（pdf_parser.py）
- PDF文本提取：PyMuPDF(fitz)
- PDF表格提取：pdfplumber → Markdown
- 分块策略：按句子/段落/标题/固定长度

#### 对话记忆模块（Redis）
- 数据结构：List
- Key格式：chat_history:{用户}_{角色}
- 保留最近5轮，自动截断

#### 用户角色模块（MySQL）
- users表：用户信息
- characters表：角色配置（名称、提示词、对应向量集合）

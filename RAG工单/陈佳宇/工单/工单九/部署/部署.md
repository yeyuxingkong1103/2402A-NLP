# 工单9 Graph-RAG优化与评估｜部署文档
工单编号：人工智能NLP‑RAG‑Graph RAG 优化任务

## 1.环境信息
操作系统：WSL Ubuntu24.04
Python版本：Python3.12
虚拟环境：venv_gongdan5（复用之前工单，无需新建）
依赖包：flask、networkx、pyvis

## 2.项目文件部署
项目代码放在 `工单9/研发` 目录
核心文件清单：
- main.py：主程序，Flask问答服务，批量评测逻辑
- graph_builder.py：知识图谱构建模块
- pdf_loader.py：模拟文档加载模块
- eval_ragas.py：RAG评估指标计算脚本

> 运行程序后，研发目录自动生成 graph_visual.html（知识图谱可视化网页）

## 3.部署启动步骤
1. 打开WSL终端，激活虚拟环境
```bash
source /mnt/c/Users/陈/Desktop/工单5/venv_gongdan5/bin/activate
切换到研发目录
cd /mnt/c/Users/陈/Desktop/工单9/研发
运行主程序
python3 main.py
### 程序启动流程

1. 加载模拟招股文档，切分为文本块。
2. 构建清洗后的知识图谱，输出 graph_visual.html 可视化文件。
3. 自动批量运行 10 条测试问题，计算 context_precision、context_recall 并打印指标。
4. 启动 Flask Web 服务，监听 0.0.0.0:7862。

## 4. 访问服务

1. Web 问答页面：浏览器访问 `http://172.17.189.52:7862`
2. 知识图谱可视化：Windows 直接打开 `工单9/研发/graph_visual.html`

## 5. 部署注意事项

1. 虚拟环境必须激活，否则会报模块找不到。
2. 端口 7862，不和工单 7（7860）、工单 8（7861）冲突。
3. Flask 内置服务仅用于实训演示，不能用于生产环境。
4. 图谱存储在内存，程序关闭后内存图谱丢失；graph_visual.html 文件会保留在本地。
5. 提交仓库时，不要上传 venv 虚拟环境文件夹。

## 6. 故障排查

1. 网页打不开：确认 WSL 程序正常运行，IP 地址正确，端口 7862。
2. 评测指标不输出：查看终端日志，确认测试集和参考答案一一对应。
3. 图谱可视化打不开：直接在 Windows 资源管理器双击打开 html 文件。

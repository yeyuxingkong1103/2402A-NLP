## 3. 核心功能实现要点

### 3.1 多文档知识库

```python
PDF_PATHS = [DATA_DIR / "招股说明书1.pdf", DATA_DIR / "招股说明书2.pdf"]
```

- 每个块携带 `source` 元数据（源文件名），支持答案溯源到具体招股书；
- FAISS 单库承载两份文档，检索时用"公司名 → 源文件"路由消歧。

### 3.2 表格解析（F2，本工单核心）

见 [设计 · 03 表格解析方案设计](../设计/03_表格解析方案设计.md)。产出：

| 文档 | 表格数 | 键值对行 | 表题识别率 |
|---|---|---|---|
| 招股说明书1.pdf | 473 | 2,916 | 96.9% |
| 招股说明书2.pdf | 216 | 1,642 | 94.9% |
| 合计 | **689** | **4,558** | **96.2%** |

### 3.3 四条问答链路（用于对比与消融）

| 方法 | 说明 |
|---|---|
| `engine.answer_optimized(q)` | 优化链路（最终方案） |
| `engine.answer_baseline(q)` | 基线链路（复刻 01/02 工单，LLM 生成） |
| `engine.answer_baseline_extractive(q)` | 消融：基线检索 + 抽取式合成 |
| `engine.answer_optimized_llm(q)` | 消融：优化检索 + LLM 生成 |

### 3.4 界面四视图（F6）

| 视图 | 功能 | 截图 |
|---|---|---|
| 优化后 / 优化前 | 单题问答：答案 + 页码引用 + 可折叠依据片段 + 耗时 | `02_qa_table_q1.png` |
| 优化前后对比 | 同一问题并排展示两条链路 + 命中判定徽标 | `04_compare.png` |
| 批量评估 | 一键跑 14 题，实时展示准确率与耗时 | — |
| 表格解析视图 | 展示知识库中的结构化表格（Markdown）与键值对行 | `05_tables_view.png` |

### 3.5 中英文支持（F7）

- 分词：`jieba.cut_for_search`（中文）+ 按空格切分（英文）；
- 向量：`bge-m3`（中英文混合语义模型）；
- 实测英文提问（如 `What is the registered capital?`）同样可命中中文表格块。

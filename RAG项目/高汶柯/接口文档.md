# RAG 多角色扮演系统 - 接口文档

**版本**: 1.0.0

**标题**: RAG 多角色扮演系统

**基地址**: `http://127.0.0.1:8000`

> 本文件为手写维护版。运行后端后访问 `/docs` 查看 Swagger；
> 如需自动生成，执行 `python export_api_doc.py`，会输出
> `api_doc_generated.json` 与 `api_doc_generated.md`（不会覆盖本文件）。

---

## 对话

### POST /chat

**请求体**
```json
{
  "user_id": "u1",
  "role_id": 1,
  "message": "猎捕国家重点保护野生动物怎么处罚？",
  "stream": false,
  "use_rag": true
}
```

**响应**
```json
{
  "reply": "回答内容",
  "role_id": 1,
  "sources": [{"source": "中华人民共和国野生动物保护法.pdf", "score": 3.21}],
  "rewritten_query": "猎捕国家重点保护野生动物的法律责任"
}
```

### POST /chat_stream

请求体同 `/chat`。响应为 `text/plain` 流式分片。

## 角色

| 接口 | 方法 | 说明 |
|---|---|---|
| `/roles` | GET | 角色列表 |
| `/roles/{role_id}` | GET | 角色详情 |
| `/roles` | POST | 创建角色 |

**POST /roles 请求体**
```json
{
  "role_name": "测试角色",
  "domain": "general",
  "description": "描述",
  "opening": "开场白",
  "system_prompt": "你是一个……"
}
```
**响应**: `{"ok": true, "id": 11}`

## 知识库

### POST /upload_pdf

`multipart/form-data`：`file`（PDF 文件）、`domain`（默认 general）、`parser`（默认 auto）。

**响应**
```json
{"ok": true, "msg": "已入库 128 条", "doc_id": "a1b2c3", "chunks": 128, "parser": "pymupdf"}
```

### POST /kb/ingest_dir

`multipart/form-data`：`dir_path`（可选，默认 laws）、`domain`、`parser`。

**响应**: `{"ok": true, "count": 1, "results": [ ... ]}`

### GET /kb/docs

查询参数 `domain`（可选）。返回文档元数据列表。

### DELETE /kb/docs/{doc_id}

删除文档全部知识块与元数据。响应 `{"ok": true, "doc_id": "..."}`。

## 运维可视化

### Redis

| 接口 | 方法 | 说明 |
|---|---|---|
| `/ops/redis/stats` | GET | 键总数/内存/命中率/类型分布/热问题 |
| `/ops/redis/keys?pattern=*&limit=200` | GET | 键列表（含类型/ttl/大小/预览） |
| `/ops/redis/key/{key}` | GET | 单个键详情 |
| `/ops/redis/session/{user_id}/{role_id}` | GET | 会话记忆 |

### Milvus

| 接口 | 方法 | 说明 |
|---|---|---|
| `/ops/milvus/collections` | GET | 集合列表 |
| `/ops/milvus/stats` | GET | 实体总数与域/解析器分布 |
| `/ops/milvus/entities?domain=&limit=50&offset=0` | GET | 实体分页浏览 |
| `/ops/milvus/search` | POST | 检索预览 |

**POST /ops/milvus/search 请求体**
```json
{"query": "猎捕野生动物怎么处罚？", "domain": "law", "top_k": 5}
```

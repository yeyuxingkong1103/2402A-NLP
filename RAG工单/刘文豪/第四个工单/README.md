# 工单04：PDF 文档的图像内容解析及检索优化

> 工单编号：人工智能 NLP-RAG-PDF 文档的图像内容解析及检索优化 ｜ 工时预估：2 人日
> 目标：让问答系统能回答"图里才有"的问题（组织结构图、IC市场增长图），并保持文本问题不回归

## 一、图像解析链路（核心产出）

```
extract_charts.py   ① 图表页检测（图表标题关键词 + 短文本延续页启发式）→ 4x 高清渲染 PNG
ocr_charts.py       ② EasyOCR 中文OCR（rag_env 运行，模型本机已缓存）→ 按阅读顺序(先y后x)输出
caption_images.py   ③ BLIP 图像描述（HF 缓存模型）→ qwen2.5 翻译成中文
build_index_img.py  ④ 图像内容块 = 图结构分析 + 语义描述 + OCR文字 + 页面文字 → 独立向量集合
rag.py              ⑤ 三路检索：兴图文本 + 力源文本/表格 + 力源图像集合，图像块固定保留Top-2且排上下文最前
```

**关键技术点**：
- 组织结构图是**矢量图 + 竖排文字**：EasyOCR 读不了竖排中文 → 用 PyMuPDF 抽取矢量文字，并做"单字空符合并"（`珠 海 销 售 处 → 珠海销售处`）
- **图结构几何解析**：按文字坐标先归列、列内按 y 切分成"方框"，统计"销售处"框数量并按距离定位其上级框，直接产出"大客户销售部 下设 6 个销售处：珠海/深圳/北京/武汉/广州/成都"
- 修复 chromadb 1.5.9 大集合（1464条）跨进程 HNSW 加载崩溃 → 工单03 索引按文档拆成两个集合
- 修复正则 `(?=\u4e00-\u9fff)` 方括号缺失 bug（范围语法只在字符类内有效）

## 三、演示结果

| id | 问题 | 结果 |
|----|------|------|
| 5 | 组织结构图中销售部有几个部门构成？大客户销售部有几个销售处？ | ✅ **完全正确**：4个部门（渠道销售部/电话及网络销售部/大客户销售部/国际贸易部）+ 6个销售处（珠海/深圳/北京/武汉/广州/成都） |
| 6 | 从2008年中国IC市场应用结构与增长图看，增长率最快的是哪个行业？负增长的是哪个行业？ | ⚠️ 部分正确：图中数值（工控10.5%、汽车14.0%等）均被OCR识别并进入上下文，但模型推理"增长率最快"时误选工控；负增长（IC卡 -2.0%）因OCR无法识别负号而未答出 |
| 1/2 | 发行股数/募投项目（回归检查） | ✅ 正确 |

**已知限制（id=6）**：
1. 负号丢失：图表中"-2.0%"被 EasyOCR 识别为"2.0%"（4x渲染+数字白名单均无法恢复），负增长判断缺直接证据。改进方向：条形方向像素分析或引入视觉大模型。
2. "增长率最快"的比较推理超出 qwen2.5:7b 的稳定能力（尽管上下文同时有"工控10.5%位列第二，仅次于汽车电子"与图中14.0%）。改进方向：结构化为"数值-行业"表格再推理，或换更大模型。

完整问答见 `演示结果.md`；图表页渲染件在 `images/`。

## 3. 执行步骤（按顺序）

### 3.1 [组件] 构建向量库
```powershell
python scripts/build_kb.py
```
- **通过标准**：终端输出 `knowledge库构建完成，统计: {...}`，切片数=2670。

### 3.2 [集成] 命令行单条问答
```powershell
python scripts/run_qa.py --question "武汉兴图新科注册资本是多少"
```
- **通过标准**：输出含 `[模式] rag`、`[依据] N条`（带页码）、`[回答]` 含 5520 / 5,520万。

### 3.3 [集成+性能] 10 题评估
```powershell
python scripts/evaluate.py --top-k 8 --skip-ragas
```
- **通过标准**：10 题逐题输出 RAG/LLM 耗时，无崩溃。

### 3.4 [报告] 生成对比
```powershell
python scripts/build_report.py
```
- **通过标准**：`output/evaluation_report.md` 生成，含对比表格与命中统计。

### 3.5 [界面] Streamlit
```powershell
streamlit run app.py
```
- **通过标准**：浏览器打开，能提问、显示依据页码、反馈写入 feedback.csv。

### 3.6 [可选] RAGAS 指标
```powershell
python scripts/ragas_score.py
```
- **说明**：需 JSON 友好裁判模型；本地 deepseek-r1 可能跳过，属已知限制。

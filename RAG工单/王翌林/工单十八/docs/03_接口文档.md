# 工单十八 · 接口文档（质检 API）

Base URL: `http://<host>:8028`

## 1. 健康检查
`GET /health` → `{"status":"ok","skill":"DocumentQualityAssessmentSkill"}`

## 2. 文档质检（核心）
`POST /v1/document/quality-inspection`
- Body (JSON)：
  ```json
  { "path": "/data/documents", "return_html": true }
  ```
  或 `{ "files": ["/a.pdf","/b.md"], "return_html": false }`
- 响应 `200`：
  ```json
  {
    "report": {
      "file_count": 1700,
      "format_distribution": { "total": 1700, "distribution": {...} },
      "pdf_classification": { "pdfs": [...], "to_confirm": [...] },
      "length_distribution": { "percentiles": {"P25":..,"P99":..}, "buckets": {...} },
      "duplicates": { "exact_duplicates": [[...]], "version_conflicts_to_confirm": [...] },
      "sensitive_info": { "summary": {...}, "to_review": [...] },
      "classification": { "<file>": {"label":"Scan_PDF","route_to":"ocr_parser"} },
      "action_items": { "to_confirm_pdf":[...], "version_conflicts":[...], "sensitive_to_review":[...] }
    },
    "html": "<!doctype html>...质检简报..."
  }
  ```

## 3. HTML 简报
`GET /v1/document/quality-inspection/html?path=/data/documents` → 返回 HTML 页面。

## 4. 列表可操作性字段
- 待确认 PDF：`file`、`reason`、`scan_ratio`
- 版本冲突：`file_a`、`file_b`、`hamming_distance`、`snippet_a`、`snippet_b`
- 敏感待审核：`file`、`type`、`value`、`context`（命中值前后 20 字）

## 5. Skill 直接调用
```python
from src.quality_assessor import assess
report = assess("/data/documents")        # dict
```
